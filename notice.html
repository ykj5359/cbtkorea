개선 기출문제 페이지가 더 가볍고 빨라졌습니다2026-10-29
  • 사용하지 않는 요소를 정리해 기출문제 페이지 용량을 약 30% 줄였습니다.
  • 각 회차 상단에 시행일·문항 수·출제 과목 안내를 추가했습니다.
  • 이전 회차 / 다음 회차 버튼으로 같은 종목의 다른 회차로 바로 이동할 수 있습니다.
  • 종목별 전체 회차 목록과 자격증 가이드 바로가기를 추가했습니다.
  • 없는 주소로 들어왔을 때 시험을 바로 검색할 수 있는 안내 페이지를 만들었습니다.
개선 검색 결과에 시험명과 회차가 정확히 표시됩니다2026-10-28

기출문제 페이지 제목이 모두 같게 표시되던 문제를 고쳤습니다. 이제 검색 결과와 브라우저 탭에 "전기기사 필기 기출문제 (2003-03-16)"처럼 시험명과 회차가 표시됩니다. 검색 결과에 반영되기까지는 몇 주가 걸릴 수 있습니다.

신규 대출중개인 자격시험 문제 279문항 추가2026-10-23

대출성 상품 판매대리·중개업자 자격인증평가 대비 단원별 문제를 새로 수록했습니다.

  • 금융기초 · 금융소비자보호 · 금융상품 · 고객관리 4과목, 48단원 279문항
  • 전 문항 정답과 해설 제공, 채점·오답노트·북마크 기능 그대로 사용 가능
  • 국가자격이 아니므로 실전 CBT(뀨-Net CBT) 모의시험에는 포함되지 않습니다.

개선 메인 화면 시험 검색 개선2026-10-23
  • 검색어 입력 후 Enter 또는 검색 버튼을 누르면 결과 목록으로 자동 이동합니다.

개선 기출문제 해설 복원 (약 91만 문항)2026-10-08

[해설] 버튼을 눌러도 내용이 보이지 않던 문제를 해결했습니다. 약 91만 6천 문항의 해설을 다시 볼 수 있습니다.

  • 자동 생성된 해설에는 "AI 참고 해설" 표시가 붙어 있습니다. 오류가 있을 수 있으니 참고용으로 활용해 주세요.
  • 해설이 없는 일부 문항은 "해설이 준비되지 않았습니다"로 안내됩니다.
  • 원본 파일이 손상된 ERP 회계 2급 이론 2016년 12월 10일 회차는 목록에서 삭제했습니다.
