4. 메탄(CH4) 1Nm3 연소에 소요되는 이론공기량이 9.52Nm3이고, 실제공기량이 11.43Nm3 일 때 공기비(m)는 얼마인가?

  3. 1.3
  4. 1.2
(정답률: 67%)

    연소에 사용된 연료의 열량은 LPG의 총발열량 x 사용량입니다.
    즉, 1000kg의 LPG를 연소시키면 1000kg x 12980kcal/kg = 12980000kcal의 열량이 발생합니다.

    따라서 보일러의 실제 효율은 11250000kcal / (12980000kcal + 18000kcal) x 100% = 84.6% 입니다.
