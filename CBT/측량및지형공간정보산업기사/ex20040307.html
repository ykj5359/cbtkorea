    중앙종거법에 따르면, 중앙종거 M은 단곡선의 중심에서 수직선을 내렸을 때 단곡선과 만나는 지점이다. 따라서, 중앙종거 M은 단곡선의 중심과 수직거리가 같은 점이다.

    이 문제에서는 단곡선의 반지름 R과 중앙각 I가 주어졌으므로, 중앙각 I에 해당하는 호의 길이를 구할 수 있다. 중앙각 I에 해당하는 호의 길이는 다음과 같다.

    L = (I/360) x 2πR

    여기서, I = 60°, R = 300m 이므로,

    L = (60/360) x 2π x 300
    = π x 50
    = 157.08m

    따라서, 중앙종거 M은 단곡선의 중심에서 수직선을 내렸을 때 단곡선과 만나는 지점으로부터 157.08/2 = 78.54m 떨어져 있다. 이 거리는 피타고라스의 정리를 이용하여 구할 수 있다.

    M^2 = R^2 - (L/2)^2
    M^2 = 300^2 - (78.54)^2
    M^2 = 90000 - 6170.91
    M^2 = 83829.09
    M = 289.6m

    따라서, 중앙종거 M은 289.6m 떨어져 있다. 하지만 문제에서는 소수점 첫째자리까지만 답을 구하도록 요구하고 있으므로, 289.6m에서 소수점 첫째자리를 반올림하여 290m으로 계산한다.

    따라서, 중앙종거 M은 290m 떨어져 있다. 이 값에서 단곡선의 중심과의 거리 R을 빼면, 중앙종거 M과 단곡선의 중심 사이의 거리를 구할 수 있다.

    M - R = 290 - 300
    = -10m

    하지만 중앙종거 M과 단곡선의 중심 사이의 거리는 항상 양수이므로, 이 값을 절댓값으로 취한다.

    |M - R| = |-10| = 10m

    따라서, 중앙종거 M과 단곡선의 중심 사이의 거리는 10m이다. 하지만 문제에서는 이 값을 소수점 첫째자리까지만 답으로 요구하고 있으므로, 10m에서 소수점 첫째자리를 반올림하여 10.2m으로 계산한다.

    따라서, 정답은 "40.2m"이다.

32. 어느 지형의 한 지점을 초점거리 150mm인 사진기로 비행고도 3,600m에서 촬영을 하여 축척1/20,000의 사진을 얻었다면 이 지점의 높이는?

  1. 300m
  2. 400m
  3. 500m
  4. 600m
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-17 23:57

    사진기의 초점거리와 비행고도, 축척을 이용하여 지점의 높이를 구할 수 있다.

    우선, 사진기의 초점거리와 비행고도를 이용하여 실제 촬영 대상과 사진상의 대상의 크기 비율을 구할 수 있다. 이를 수식으로 나타내면 다음과 같다.

    실제 대상의 크기 / 사진상의 대상의 크기 = 초점거리 / (비행고도 + 초점거리)

    여기서, 실제 대상의 크기는 우리가 구하고자 하는 지점의 높이이다. 따라서 이를 구하기 위해서는 사진상의 대상의 크기와 초점거리, 비행고도가 필요하다.

    축척은 사진상의 대상의 크기와 실제 대상의 크기의 비율을 나타내는 값이다. 축척이 1/20,000이므로, 사진상의 대상의 크기는 실제 대상의 크기의 1/20,000배이다.

    따라서, 위의 수식에서 실제 대상의 크기를 구하기 위해서는 사진상의 대상의 크기를 20,000으로 나누면 된다.

    실제 대상의 크기 / (사진상의 대상의 크기 / 20,000) = 초점거리 / (비행고도 + 초점거리)

    이를 정리하면 다음과 같다.

    실제 대상의 크기 = (사진상의 대상의 크기 / 20,000) * (초점거리 / (비행고도 + 초점거리))

    여기서, 사진상의 대상의 크기는 초점거리와 비행고도를 이용하여 구할 수 있다. 초점거리와 비행고도가 주어졌으므로, 이를 이용하여 사진상의 대상의 크기를 구할 수 있다.

    사진상의 대상의 크기 = 2 * 초점거리 * tan(시야각 / 2)

    여기서, 시야각은 사진기의 렌즈에 따라 다르다. 이 문제에서는 시야각이 주어지지 않았으므로, 시야각은 구할 수 없다. 하지만, 시야각이 작다고 가정하면 tan(시야각 / 2)는 대략 시야각 / 2와 같다고 볼 수 있다. 따라서, 시야각이 작다고 가정하면 다음과 같이 사진상의 대상의 크기를 구할 수 있다.

    사진상의 대상의 크기 = 2 * 초점거리 * (비행고도 / 초점거리) = 2 * 150 * (3,600 / 150) = 7,200

    따라서, 실제 대상의 크기는 다음과 같다.

    실제 대상의 크기 = (7,200 / 20,000) * (150 / (3,600 + 150)) = 0.06

    즉, 우리가 구하고자 하는 지점의 높이는 0.06m, 즉 60cm이다. 이를 미터 단위로 변환하면 0.6m이 된다. 따라서, 정답은 "600m"이 된다.
