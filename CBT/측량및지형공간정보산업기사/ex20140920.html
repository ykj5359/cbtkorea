8. 그림과 같이 2차포물선에 의하여 종단곡선을 설치하려 한다면 C점의 계획고는? (단, A점의 계획고는 50.00m 이다.)

  1. 40.00m
  2. 50.00m
  3. 51.00m
  4. 52.00m
(정답률: 60%)
  • 30 CBT 기출문제AI

    2023-04-17 23:32

    주어진 그림에서 A점의 계획고는 50.00m이고, B점과 C점은 2차포물선에 의해 결정된다. 따라서, B점과 C점의 x좌표는 동일하고 y좌표는 다르다.

    먼저, B점의 y좌표를 구해보자. B점은 2차포물선의 꼭짓점이므로, 2차포물선의 방정식을 이용하여 B점의 y좌표를 구할 수 있다.

    2차포물선의 일반식은 y = ax^2 + bx + c 이다. 여기서, A점의 좌표 (0, 50.00)을 대입하여 c를 구할 수 있다.

    50.00 = a(0)^2 + b(0) + c
    c = 50.00

    또한, B점은 2차포물선과 x축이 만나는 지점이므로, B점의 y좌표는 0이다. 따라서, B점의 x좌표를 구해보자.

    2차포물선의 꼭짓점은 x = -b/2a 에 위치한다. 따라서, B점의 x좌표는 -b/2a 이다.

    또한, B점은 A점과 C점의 중간지점이므로, B점의 x좌표는 (0 + xC)/2 이다.

    따라서, -b/2a = (0 + xC)/2 이므로, xC = -b/a 이다.

    이제 C점의 y좌표를 구해보자. C점은 2차포물선과 B점을 지나므로, 다음 두 식을 만족해야 한다.

    yC = axC^2 + bxC + c
    yC = 0

    위의 두 식을 이용하여 b를 구할 수 있다.

    0 = a(xC)^2 + bxC + c
    b = -c/xc

    따라서, b = -50.00/xC 이다.

    이제 C점의 y좌표를 구해보자.

    yC = axC^2 + bxC + c
    yC = axC^2 - 50.00

    따라서, C점의 계획고는 yC + 50.00 이므로,

    C점의 계획고 = axC^2 - 50.00 + 50.00 = axC^2

    따라서, C점의 계획고를 구하기 위해서는 xC를 구하면 된다.

    xC = -b/a = -(-50.00/xC)/a
    xC^2 = 50.00/a
    a = 50.00/xC^2

    따라서, C점의 계획고는

    yC = axC^2 - 50.00 = (50.00/xC^2)xC^2 - 50.00 = 0.00

    즉, C점의 계획고는 0.00m이다.

    따라서, 정답은 "51.00m"이 아니라 "52.00m"이다.

  2. 3.5mm
  3. 4.5mm
  4. 5.5mm
(정답률: 62%)

    tanθ = x / h

    여기서 θ는 비행기에서 교량까지의 각도입니다. 이 각도는 사진기의 초점거리와 상관없이 항상 일정합니다. 따라서 이 식을 이용하여 x를 구할 수 있습니다.

    x = h * tanθ

    tanθ = x / h = (7500 / 2) / 3000 = 1.25

    마지막으로 x를 구해보면,

    x = h * tanθ = 3000 * 1.25 = 3750

    따라서, 비행기에서 촬영한 사진에서 교량의 길이는 3750mm입니다. 이를 다시 초점거리와 관련된 크기로 변환하면,
