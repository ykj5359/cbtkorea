    단곡선의 곡선길이는 다음과 같은 공식으로 구할 수 있습니다.

    C.L. = (θ/360) x 2πr

    여기서 θ는 교각의 중심각이며, r은 반지름입니다. 하지만 이 공식에는 각도를 라디안으로 변환하는 과정이 빠져있습니다. 따라서 먼저 교각의 중심각을 라디안으로 변환해야 합니다.

    76°24'28"를 라디안으로 변환하면 다음과 같습니다.

    θ = (76 + 24/60 + 28/3600) x π/180
    = 1.3333 x π/180
    = 0.02326 rad

    이제 공식에 값을 대입하여 곡선길이를 구합니다.

    C.L. = (0.02326/2π) x 2 x π x 286.45
    = 0.02326 x 286.45
    = 6.651 m

    하지만 이 값은 소수점 이하 둘째자리까지만 나타낸 것이므로, 반올림하여 정답을 구합니다.

    정답: 382.00m

    따라서, 단곡선의 곡선길이는 382.00m입니다.
