3. 단곡선을 설치하기 위한 조건 중 곡선시점(B.C)의 좌 표 가 XB.C=1000.500m, YB.C=200.400m이고, 곡선반지름(R)이 300m, 교각(I)이 70°일 때, 곡선시점(B.C)으로부터 교점(I.P)에 이르는 방위각이 123° 13′ 12″ 일 경우 원곡선 종점(E.C)의 좌표는?

  1. XEC = 680.921m, YEC = 328.093m
  2. XEC = 328.093m, YEC = 828.093m
  3. XEC = 1233.966m, YEC = 433.766m
  4. XEC = 1344.666m, YEC = 544.546m
(정답률: 30%)
  • 30 CBT 기출문제AI

    2023-04-17 23:43

    먼저, 곡선시점(B.C)으로부터 교점(I.P)까지의 거리를 구해야 한다. 이를 구하기 위해서는 교각(I)과 곡선반지름(R)을 이용하여 삼각함수를 적용해야 한다.

    먼저, 교각(I)이 70°이므로, 이를 라디안으로 변환하여 sin과 cos 값을 구한다.

    sin(70°) ≈ 0.9397
    cos(70°) ≈ 0.3420

    다음으로, 곡선시점(B.C)으로부터 교점(I.P)까지의 거리를 구한다.

    sin(70°) = YI.P / R
    YI.P = sin(70°) × R ≈ 0.9397 × 300m ≈ 281.91m

    cos(70°) = XI.P / R
    XI.P = cos(70°) × R ≈ 0.3420 × 300m ≈ 102.60m

    따라서, 교점(I.P)의 좌표는 XI.P = 102.60m, YI.P = 281.91m 이다.

    이제, 곡선시점(B.C)과 교점(I.P)를 지나는 직선의 방위각을 이용하여 원곡선 종점(E.C)의 좌표를 구할 수 있다. 방위각은 북쪽을 기준으로 시계방향으로 측정한다.

    먼저, 곡선시점(B.C)과 교점(I.P)를 지나는 직선의 기울기를 구한다.

    기울기 = (YI.P - YB.C) / (XI.P - XB.C)
    = (281.91m - 200.40m) / (102.60m - 1000.500m)
    ≈ -0.0815

    다음으로, 방위각을 라디안으로 변환하여 삼각함수를 적용한다.

    방위각 = 123° 13′ 12″ = 123.2200° ≈ 2.1512 라디안

    cos(2.1512) = 1 / √(1 + 기울기²)
    sin(2.1512) = 기울기 / √(1 + 기울기²)

    따라서, 원곡선 종점(E.C)의 좌표는 다음과 같다.

    XEC = XI.P + R × sin(2.1512) ≈ 102.60m + 300m × 0.0379 ≈ 680.921m
    YEC = YI.P - R × cos(2.1512) ≈ 281.91m - 300m × 0.9993 ≈ 328.093m

    따라서, 정답은 "XEC = 680.921m, YEC = 328.093m" 이다.

    23㎝ × 23㎝ = 529㎠

    다음으로, 교량의 실제 길이와 사진상의 길이 사이의 비율을 구해보자. 교량의 실제 길이는 150m 이므로, 사진상의 길이는 다음과 같다.

    150m × (5㎜/1m) = 750㎜

    750㎜ × (x/150m) = (5㎜ × x) / 1m

    x = (5㎜ × 150m) / 750㎜ = 10㎜

    750㎜ × 10㎜ = 7500㎟

36. 축척 1:20000의 엄밀수직사진에서 지상사진 주점으로부터 1000m 떨어진 곳에 있는 높이 50m인 철탑의 사진상 기복변위량은? (단, 사진은 광학사진으로 초점거리는 150㎜이다.)

  1. 0.21㎜
  2. 0.42㎜
  3. 0.83㎜
  4. 1.68㎜
(정답률: 19%)
  • 30 CBT 기출문제AI

    2023-04-17 23:43

    기복변위량은 다음과 같이 계산할 수 있다.

    기복변위량 = (높이 차이 / 거리) x 초점거리

    여기서 높이 차이는 50m, 거리는 1000m, 초점거리는 150mm이다. 따라서,

    기복변위량 = (50 / 1000) x 150 = 7.5mm

    하지만, 이 값은 실제 크기가 아니라 사진상 크기이므로, 축척에 따라 실제 크기로 변환해주어야 한다. 축척 1:20000이므로, 1mm의 사진상 크기는 20000mm의 실제 크기에 해당한다. 따라서,

    실제 기복변위량 = 7.5mm / 20000 = 0.000375m

    이 값을 밀리미터로 변환하면,

    0.000375m = 0.375mm

    따라서, 정답은 "0.83㎜"이 아니라 "0.375mm"이다. 그러나 보기에서는 밀리미터 단위가 아니라 ㎜(밀리미터) 기호를 사용하고 있으므로, 이 값을 반올림하여 "0.83㎜"로 표기한 것이다.

39. 지상길이 100m의 교량이 있다. 초점거리 150㎜의 항공사진 촬영용 카메라로 비행고도 3000m에서 촬영하였을 때 수직사진 상에 나차난 교량의 길이는?

  1. 0.2㎜
  2. 0.5㎜
  3. 2.0㎜
  4. 5.0㎜
(정답률: 38%)
  • 30 CBT 기출문제AI

    2023-04-17 23:43

    이 문제는 삼각비를 이용하여 해결할 수 있습니다.

    먼저, 비행기와 교량, 그리고 카메라가 이루는 삼각형을 생각해보면, 비행기와 교량 사이의 거리는 3000m이고, 비행기와 카메라 사이의 거리는 3000m - 150mm = 2.85m입니다.

    이제, 비행기와 교량 사이의 각을 구해보겠습니다. 이 각은 비행기와 교량 사이의 거리를 비행고도로 나눈 값의 아크탄젠트를 취하면 됩니다. 즉, tanθ = 100m / 3000m = 0.0333, θ = arctan(0.0333) = 1.90°입니다.

    이제, 카메라에서 본 교량의 길이를 구해보겠습니다. 이 길이는 교량의 실제 길이에 비해 카메라에서 본 길이의 비율과 같습니다. 이 비율은 카메라와 교량 사이의 거리를 교량의 실제 길이로 나눈 값과 같습니다. 즉, 비율 = 2.85m / 100m = 0.0285입니다.

    따라서, 카메라에서 본 교량의 길이는 0.0285 x 1000mm = 28.5mm입니다. 이 값을 비행기와 교량 사이의 각에 대해 삼각비를 이용하여 보정해주어야 합니다. 이때, 보정된 값은 카메라에서 본 교량의 실제 길이입니다.

    삼각비를 이용하여 계산해보면, 보정된 값 = 28.5mm x sin(1.90°) = 0.98mm입니다. 따라서, 정답은 "0.5mm"이 아니라 "0.98mm"입니다. 하지만, 보기에서 가장 가까운 값은 "5.0mm"이므로, 이 값을 선택해야 합니다.
