4. 목적지 호스트의 IP Address가 동일 네트워크상에 있는지 확인하기 위해 사용하는 방법은?

    2023-04-15 15:11

    Subnet Mask는 IP 주소를 네트워크 부분과 호스트 부분으로 나누는 역할을 합니다. 따라서 목적지 호스트의 IP Address가 동일 네트워크상에 있는지 확인하기 위해서는 해당 IP Address와 송신자의 IP Address의 네트워크 부분이 동일한지를 비교해야 합니다. 이를 위해 Subnet Mask를 사용합니다. Subnet Mask는 IP 주소의 네트워크 부분을 나타내는 비트와 호스트 부분을 나타내는 비트로 이루어져 있으며, 두 IP Address의 네트워크 부분을 AND 연산하여 결과가 동일한지를 확인합니다. 결과가 동일하다면 해당 호스트는 동일한 네트워크상에 위치한 것입니다.

6. OSPF 프로토콜이 최단경로 탐색에 사용하는 기본 알고리즘은?

  1. Bellman-Ford 알고리즘
  2. Dijkstra 알고리즘
  3. 거리 벡터 라우팅 알고리즘
  4. Floyd-Warshall 알고리즘
(정답률: 45%)
  • 30 CBT 기출문제AI

    2023-04-15 15:11

    OSPF 프로토콜이 최단경로 탐색에 사용하는 기본 알고리즘은 Dijkstra 알고리즘이다. 이 알고리즘은 출발점에서부터 각 노드까지의 최단 경로를 찾는 알고리즘이며, 경로의 가중치가 음수가 아닐 때 사용한다. Bellman-Ford 알고리즘은 음수 가중치를 가진 경로도 처리할 수 있지만, OSPF 프로토콜에서는 음수 가중치를 사용하지 않기 때문에 Dijkstra 알고리즘이 적합하다. 거리 벡터 라우팅 알고리즘은 경로 정보를 주기적으로 교환하며 최단 경로를 찾는 방식이고, Floyd-Warshall 알고리즘은 모든 노드 쌍 간의 최단 경로를 찾는 알고리즘이다.
