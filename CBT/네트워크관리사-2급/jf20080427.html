  3. C Class를 사용하는 IP Address의 Subnet Mask는 “255.255.255.0” 으로 항상 고정시켜야 한다.
  4. 인터넷 접속을 위한 기본 프로토콜이지만 좀 더 편리하게 이용하기 위해서는 이외에도 NetBEUI 프로토콜이 추가로 필요하다.

    2023-04-15 15:13
