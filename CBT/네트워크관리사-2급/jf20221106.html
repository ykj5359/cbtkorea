15. 다음 조건을 만족하는 tcpdump 명령어는 무엇인가?

  1. tcpdump -c 20 -w http.cap port 80
  2. tcpdump -n 20 -w http.cap port 80
  3. tcpdump -c 20 -f http.cap port 80
  4. tcpdump -n 20 -f http.cap port 80
(정답률: 56%)
  • 30 CBT 기출문제AI

    2023-04-19 09:53

    주어진 조건에 따르면, 20개의 패킷을 캡처하고, 포트 80을 사용하는 HTTP 트래픽만 캡처하여 http.cap 파일에 저장해야 한다. 따라서 정답은 "tcpdump -c 20 -w http.cap port 80"이다.

    - "-c 20": 20개의 패킷을 캡처한다.
    - "-w http.cap": 캡처한 패킷을 http.cap 파일에 저장한다.
    - "port 80": 포트 80을 사용하는 트래픽만 캡처한다.

    다른 보기들은 "-n" 옵션을 사용하여 DNS 이름을 해석하지 않는다는 것과 "-f" 옵션을 사용하여 필터 파일을 지정하는 것이다. 이 조건에서는 이러한 옵션이 필요하지 않으므로 정답은 "tcpdump -c 20 -w http.cap port 80"이다.

  2. 전자기장 확산이나 케이블 손실로 인한 신호 감쇠를 보상해 주기 때문에 여러 대의 Repeater를 써서 먼 거리까지 데이터를 전달하는 것이 가능하다.
  3. 근거리 통신망을 구성하는 세그먼트들을 확장하거나 서로 연결하는데 주로 사용한다.
  4. 네트워크를 확장하면서 충돌 도메인을 나누어 줄 수 있는 장비가 필요한데 이럴 때 Repeater를 사용하여 충돌 도메인을 나누어 네트워크의 성능을 향상시킨다.
