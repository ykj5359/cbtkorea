15. 다음 그림은 TCP 기능 중 3Way-Handshake를 설명한 그림이다. Host간 연결 성립(Established)을 위한 Process에서 Host B에서 HOST A에 전달하는 flag bit는 무엇인가?

  2. ACK – FIN
  3. SYN – FIN
  4. PSH - ACK
(정답률: 72%)
  • 30 CBT 기출문제AI

    2023-04-19 02:40

    정답: "SYN – ACK"

    3Way-Handshake는 TCP 연결을 성립하기 위한 과정으로, Host A가 SYN(Synchronize) Flag bit를 전송하면, Host B는 이를 받아들이고 ACK(Acknowledge) Flag bit와 함께 SYN Flag bit를 전송합니다. 이후, Host A는 ACK Flag bit를 전송하여 연결을 성립합니다. 따라서, Host B에서 HOST A에 전달하는 flag bit는 "SYN – ACK" 입니다.
