26. 다음은 Hartley-Shannon의 Channel Capacity에 관련된 수식이다. 각각의 기호에 대한 설명으로 옳지 않은 것은?

  1. 그림참조 : 채널의 대역폭
  2. I(X;Y) : 샘플 X 의 엑스트로피
  3. P : 전송되는 신호의 최대전력
  4. N : 부가되는 잡음의 평균전력
(정답률: 50%)
  • 30 CBT 기출문제AI

    2023-04-15 15:15

    정답 : "I(X;Y) : 샘플 X 의 엑스트로피"

    해설 :

    - C : 채널 용량 (Channel Capacity)
    - B : 채널의 대역폭 (Bandwidth of the channel)
    - S/N : 신호 대 잡음비 (Signal-to-Noise Ratio)
    - N : 부가되는 잡음의 평균전력 (Average power of the noise)
    - P : 전송되는 신호의 최대전력 (Maximum power of the transmitted signal)

    위의 수식에서 각각의 기호는 다음과 같은 의미를 가진다.

    - C : 채널이 전송할 수 있는 최대 정보량 (Maximum amount of information that can be transmitted by the channel)
    - B : 채널이 가지고 있는 대역폭 (The bandwidth of the channel)
    - S/N : 채널에서 전송되는 신호 대 잡음비 (The signal-to-noise ratio of the channel)
    - N : 채널에서 부가되는 잡음의 평균전력 (The average power of the noise added to the channel)
    - P : 전송되는 신호의 최대전력 (The maximum power of the transmitted signal)

    따라서, 옳지 않은 것은 "I(X;Y) : 샘플 X 의 엑스트로피" 이다. 이는 수식과는 관련이 없는 개념이다.

  3. UTP : 케이블 세그먼트의 최대 길이는 185M이다.
  4. STP : 케이블에 피복이 있어 UTP 보다 간섭에 강하다.
