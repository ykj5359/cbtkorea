1. IP Header의 내용 중 TTL(Time To Live)의 기능을 설명한 것으로 옳지 않은 것은?

  1. IP 패킷은 네트워크상에서 영원히 존재할 수 있다.
  2. 일반적으로 라우터의 한 홉(Hop)을 통과할 때마다 TTL 값이 '1' 씩 감소한다.
  3. Ping과 Tracert 유틸리티는 특정 호스트 컴퓨터에 접근을 시도하거나 그 호스트까지의 경로를 추적할 때 TTL 값을 사용한다.
  4. IP 패킷이 네트워크상에서 얼마동안 존재 할 수 있는가를 나타낸다.
(정답률: 86%)

    2023-04-19 10:00

    정답: "IP 패킷은 네트워크상에서 영원히 존재할 수 있다."

    TTL(Time To Live)은 IP 패킷이 네트워크 상에서 얼마나 오래 존재할 수 있는지를 나타내는 값이다. 일반적으로 라우터의 한 홉(Hop)을 통과할 때마다 TTL 값이 '1' 씩 감소하며, TTL 값이 0이 되면 해당 패킷은 폐기된다. Ping과 Tracert 유틸리티는 특정 호스트 컴퓨터에 접근을 시도하거나 그 호스트까지의 경로를 추적할 때 TTL 값을 사용한다. 따라서 IP 패킷은 네트워크상에서 영원히 존재할 수 없다.

7. UDP에 대한 설명으로 옳지 않은 것은?

  2. OSI 7 계층 모델에서 전송 계층에 속한다.

(정답률: 74%)
  • 30 CBT 기출문제AI

    2023-04-19 10:00

    UDP는 종단 간의 흐름제어를 위해 Dynamic Sliding Window 방식을 사용하지 않는다. UDP는 비연결형 프로토콜로, 데이터그램 방식으로 데이터를 전송하며, 오류 검사를 위한 체크섬만을 제공한다. 따라서 UDP는 데이터의 신뢰성을 보장하지 않으며, TCP와 비교하여 최소한의 오버헤드를 갖는 작은 헤더를 갖는다는 것은 맞지만, 데이터의 정확성과 안정성보다는 전송 속도와 실시간성이 중요한 경우에 사용된다.

12. MAC Address를 IP Address로 변환시켜주는 Protocol은?

  1. RARP
  2. ARP
  3. TCP/IP
  4. DHCP
(정답률: 75%)
  • 30 CBT 기출문제AI

    2023-04-19 09:48

    RARP는 Reverse Address Resolution Protocol의 약자로, MAC Address를 IP Address로 변환시켜주는 프로토콜입니다. ARP는 반대로 IP Address를 MAC Address로 변환시켜주는 프로토콜이며, DHCP는 IP Address를 자동으로 할당해주는 프로토콜입니다. TCP/IP는 인터넷 통신에 사용되는 프로토콜의 집합이므로, MAC Address를 IP Address로 변환시켜주는 프로토콜과 직접적인 연관이 없습니다. 따라서, MAC Address를 IP Address로 변환시켜주는 Protocol은 RARP입니다.
