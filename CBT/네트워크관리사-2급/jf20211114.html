(정답률: 84%)

    UDP는 비연결형 프로토콜이기 때문에 확인 응답 번호(Acknowledgment Number) 필드가 포함되지 않습니다. 이 필드는 TCP에서 사용되며, 데이터를 전송할 때 상대방이 데이터를 받았는지 확인하기 위해 사용됩니다. UDP는 데이터를 전송만 하고 확인 응답을 받지 않기 때문에 이 필드가 필요하지 않습니다. 따라서 UDP 헤더에는 소스 포트(Source Port) 주소, 목적지 포트(Destination Port) 주소, 체크섬(Checksum) 필드만 포함됩니다.

2. ARP 캐시에 대한 설명으로 옳지 않은 것은?

  1. 각 호스트는 ARP Request를 보내기 전에 ARP 캐시에서 해당 호스트의 하드웨어 주소를 찾는다.
  2. ARP 캐시는 새로운 하드웨어가 네트워크에 추가된 경우 갱신된다.
  3. ARP 캐시의 수명이 유한하여 무한정 커지는 것을 방지한다.
  4. 중복된 IP가 발견된 경우 ARP 캐시는 갱신되지 않는다.
(정답률: 79%)
  • 30 CBT 기출문제AI

    2023-04-15 15:07

    "중복된 IP가 발견된 경우 ARP 캐시는 갱신되지 않는다."라는 설명이 옳지 않은 것은, ARP 캐시는 IP 주소와 매칭되는 MAC 주소를 저장하는데, 중복된 IP 주소가 발견되면 해당 IP 주소와 매칭되는 MAC 주소를 갱신하여 ARP 캐시를 업데이트한다. 따라서 중복된 IP 주소가 발견되면 ARP 캐시는 갱신된다.
