6. 주택에서 작업순서에 따른 부엌 작업대의 배치 순서로 옳은 것은?

  1. 준비대 → 개수대 → 조리대 → 가열대 → 배선대
  2. 준비대 → 조리대 → 개수대 → 가열대 → 배선대
  3. 준비대 → 조리대 → 가열대 → 개수대 → 배선대
  4. 준비대 → 가열대 → 개수대 → 조리대 → 배선대
(정답률: 87%)
  • 30 CBT 기출문제AI

    2023-04-12 15:34

    정답은 "준비대 → 개수대 → 조리대 → 가열대 → 배선대" 입니다.

    - 준비대: 식재료를 손질하고 조리하기 전에 필요한 도구와 식재료를 준비하는 공간으로, 조리 전에 가장 먼저 사용됩니다.
    - 개수대: 식재료를 썰거나 자르는 등의 손질 작업을 하는 공간으로, 준비한 식재료를 다듬는 작업이 필요하기 때문에 준비대 다음으로 사용됩니다.
    - 조리대: 다듬은 식재료를 조리하는 공간으로, 개수대에서 다듬은 식재료를 조리하기 때문에 개수대 다음으로 사용됩니다.
    - 가열대: 조리한 음식을 가열하는 공간으로, 조리대에서 조리한 음식을 가열하기 때문에 조리대 다음으로 사용됩니다.
    - 배선대: 전기, 가스, 수도 등의 배선이 필요한 가전제품을 설치하는 공간으로, 가열대에서 가열한 음식을 보관하거나 전기, 가스, 수도 등의 배선이 필요한 가전제품을 설치하기 때문에 가열대 다음으로 사용됩니다.
