16. Clarke와 Carbon의 식 에서 N은 목적 유전자가 클론된 형질전환주를 알기위해 필요한 전체 재조합 형질 전환주(recombinant transformant)의 수, P는 재조합주에 원하는 유전자가 들어갈 확률, f는 총 게 놈 크기에 대한 제한절편(restriction fragment)크기의 비이다. 인간 β-hemoglobin의 유전자 크기는 1.5kb 짜리 제한절편을 몇 개 clone 해야 하는가?

  1. 4.4 x 106
  2. 9.2 x 106
  3. 1.⑤ x 107
  4. 2.23 x 107
(정답률: 62%)
  • 30 CBT 기출문제AI

    2023-04-15 19:57

    주어진 식에서 f는 제한절편의 크기 비율이므로, 인간 β-hemoglobin 유전자의 크기가 1.5kb이므로 f는 1.5kb를 제한절편 크기로 나눈 값이 된다. 따라서 f = 1.5kb / 4kb = 0.375이 된다.

    N은 목적 유전자가 클론된 형질전환주를 알기 위해 필요한 전체 재조합 형질 전환주(recombinant transformant)의 수이므로, N = ln(1-P) / ln(1-f) 이다. 여기서 ln은 자연로그를 의미한다.

    따라서, N = ln(1-1/2n) / ln(1-0.375) 이다. 이를 계산하면 N = 9.2 x 106이 된다. 따라서 정답은 "9.2 x 106"이다.
