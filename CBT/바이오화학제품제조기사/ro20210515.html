4. 10-6 N NaOH 수용액의 pH는?

  1. 8
  2. 10
  3. 12
  4. 14
(정답률: 83%)
  • 30 CBT 기출문제AI

    2023-04-15 20:02

    NaOH는 강염기이므로 수용액에서 OH- 이온의 농도가 높아지게 됩니다. 따라서 pH는 14에서 OH- 이온의 로그값을 빼면 구할 수 있습니다.

    pOH = -log[OH-] = -log[10^-6] = 6

    pH = 14 - pOH = 14 - 6 = 8

    따라서, 10^-6 N NaOH 수용액의 pH는 8입니다.

  2. 0.67
  3. 1.0
  4. 1.5

    2023-04-15 20:03

    먼저 이온교환 평형식을 쓰면 다음과 같다.

    B+ + 2A+-R ↔ A+-R + 2B+

    여기서 R은 이온교환수지의 활성화된 부분을 나타낸다. 이 식에서 선택도는 다음과 같이 정의된다.

    αB/A = (B+의 이온교환평형상수) / (A+의 이온교환평형상수)

    이 문제에서는 A+의 농도와 잔류농도가 주어졌으므로 A+의 이온교환평형상수를 구할 수 있다. 이를 구하기 위해서는 이온교환수지의 이온교환용량을 계산해야 한다.

    이온교환수지 1 g 당 이온교환용량 = 5 meq/g = 0.0⑤ eq/g

    따라서 2 g의 이온교환수지에는 0.01 eq의 이온교환용량이 있다. 이 중에서 A+이 차지하는 비율은 다음과 같다.

    A+의 이온교환용량 = (100 mM) × (100 mL) × (0.001 L/mL) × (1 mol/L) × (1 eq/mol) = 0.01 eq

    따라서 A+이 차지하는 비율은 1:1이다. 이를 이용하여 A+의 이온교환평형상수를 구할 수 있다.

    [A+] / [B+] = 1 / K

    K = [B+] / 0.04

    αB/A = KB / KA = KB × [A+] / [B+] = [B+] / (0.04 × KA)

    여기서 KA는 A+의 이온교환평형상수이므로 1이다. 따라서

    αB/A = [B+] / 0.04

    이 문제에서는 선택도가 0.44이므로 다음과 같은 식이 성립한다.

    0.44 = [B+] / 0.04

    [B+] / [A+] = K

    여기서 [A+] = 0.04 M이므로

    K = [B+] / 0.04 = 0.0176 / 0.04 = 0.44

    따라서 B+의 이온교환평형상수는 0.44이다. 따라서 정답은 "0.44"이다.

  2. 4.5
  3. 8.0
  4. 10
(정답률: 47%)

    2023-04-15 20:02

    겉보기 Km값은 다음과 같은 식으로 계산된다.

    v = Vmax[S]/(Km + [S])

    여기서 [S]는 기질 농도, Vmax는 최대 속도, Km은 Michaelis-Menten 상수이다. 덱스트린은 경쟁적 저해 물질이므로, 이 반응에서 [S]는 전분 농도와 덱스트린 농도의 합으로 대체된다.

    v = Vmax[전분]/(Km + [전분] + Ki[덱스트린])

    v는 반응 속도, [전분]은 전분 농도, [덱스트린]은 덱스트린 농도, Ki는 저해분해상수이다. 이제 [전분] = 3.0 mg/mL, [덱스트린] = 4.0 mg/mL, Km + [전분] = 6.0 mg/mL, Ki = 8.0 mg/mL을 대입하면,

    v = Vmax[전분]/(6.0 + 8.0) = 0.5Vmax[전분]/7.0

    따라서, 겉보기 Km(amylase) = (Km + Ki)/[1 + [덱스트린]/Ki] = (3.0 + 8.0)/(1 + 4.0/8.0) = 4.5

    즉, 덱스트린 농도가 증가하면 Ki/[덱스트린] 값이 감소하므로, 겉보기 Km값이 증가한다.

  2. 32%
  3. 75%
  4. 97%

    불량품을 양품으로 판정하는 비율이 더 높기 때문에, 양품으로 판정된 제품 중에서 실제로 불량인 비율이 높아진다. 따라서, 불량품으로 판정된 제품이 실제로 불량일 확률은 25%이다. 이는 베이즈 정리를 이용하여 계산할 수 있다.

    P(불량|불량판정) = P(불량판정|불량) * P(불량) / P(불량판정)

    = 0.1 * 0.04 + 0.2 * 0.96

    = 0.192

    P(불량|불량판정) = 0.1 * 0.04 / 0.192

    = 0.25

    따라서, 실습생이 불량으로 판정한 제품이 실제로 불량일 확률은 25%이다.

96. 시판 제품의 포장중량은 100±2 g으로 관리되고 있다. 이 제품의 평균중량이 100.5 g, 표준편차가 0.5 g일 때, 최소공정능력지수 (CPK)는?

  1. 1.0
  2. 2.0
  3. 3.0
  4. 4.0
(정답률: 60%)
  • 30 CBT 기출문제AI

    2023-04-15 20:02

    CPK = min[(USL-μ)/(3σ), (μ-LSL)/(3σ)]

    여기서, USL = 102 g, LSL = 98 g

    CPK = min[(102-100.5)/(3*0.5), (100.5-98)/(3*0.5)] = min[1, 1] = 1.0

    따라서, 최소공정능력지수 (CPK)는 1.0이다. 이는 공정이 꽤나 안정적이며, 제품의 중량이 꽤나 정확하게 유지되고 있다는 것을 의미한다.
