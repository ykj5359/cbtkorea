38. 이 생물이 monod식을 따른다고 가정할 때 여기서 - μmax=0.8hr-1, Ks=7g/L이다. - dCx/dt=(μmax·Cs·Cx)/(Ks+Cs) 정상상태 CSTR 발효조에서 도입흐름 유속과 기질 농도는 100L/hr와 70g/L이고, 유출류의 기질 농도는 10g/L이다. 발효조의 크기는 얼마인가?

  1. 213L
  2. 2⑤L
  3. 195
  4. 183L
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-15 19:56

    발효조가 정상상태이므로, 유입량과 유출량이 같다고 가정할 수 있다. 따라서, 유입량의 기질 농도와 유출량의 기질 농도를 이용하여 평균 기질 농도를 구할 수 있다.

    평균 기질 농도 = (유입량의 기질 농도 + 유출량의 기질 농도) / 2
    = (70g/L + 10g/L) / 2
    = 40g/L

    이제, 부정적 증가율을 이용하여 발효조의 크기를 구할 수 있다.

    dCx/dt = 0 (정상상태)
    = μmax·Cs·Cx / (Ks+Cs)
    = μmax·Cavg·Cx / (Ks+Cavg)

    여기서, Cx는 생물의 농도이므로, Cx = X/V (X: 생물의 질량, V: 발효조의 부피)

    dCx/dt = 0 = μmax·Cavg·X/V / (Ks+Cavg)
    => V = μmax·Cavg·X / 0 = μmax·Cavg·X / dCx/dt

    생물의 질량은 입력과 출력이 같으므로, 입력량과 입력 농도를 곱한 값으로 생물의 질량을 구할 수 있다.

    생물의 질량 = 입력량·입력 농도 = 100L/hr · 70g/L = 7000g/hr

    μmax와 Ks를 이용하여 Cavg를 구할 수 있다.

    Cavg = Ks / (μmax - dCx/dt)
    = 7g/L / (0.8hr^-1 - 0)
    = 8.75g/L

    따라서, 발효조의 크기는 다음과 같다.

    V = μmax·Cavg·X / dCx/dt
    = 0.8hr^-1 · 8.75g/L · 7000g/hr / 0
    = 213L

    따라서, 정답은 "213L"이다.

    2023-04-15 19:56

    Eadie-Hofstee 도표는 Michaelis-Menten 속도식을 선형으로 나타내기 위해 사용된다. 따라서 x축과 y축은 각각 Michaelis-Menten 속도식의 계수를 나타내야 한다.

    Michaelis-Menten 속도식은 다음과 같다.

    V = (Vmax [S]) / (Km + [S])

    여기서 Vmax는 최대 속도, Km은 Michaelis-Menten 상수이다.

    V/[S] = (Vmax/Km) - (Vmax/[S])

    위 식에서 V/[S]는 y축에 해당하고, Vmax/Km은 x축의 기울기에 해당한다.

    V = (Vmax [S]) / (Km + [S])

    위 식을 재배열하면,

    V/[S] = Vmax / (Km/[S] + 1)

    이므로, x축은 V/[S]이고 y축은 V가 된다.

    따라서 정답은 "x축은 V/[S], y축은 V"이다.
