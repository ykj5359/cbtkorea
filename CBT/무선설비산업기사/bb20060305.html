  1. 10
  2. 4
  3. 0.02
  4. 0.08
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-15 19:24

    전압이득이 50이므로 출력전압은 입력전압의 50배가 된다. 따라서, 왜율은 출력전력/입력전력 = 50/51 = 0.98이 된다. 이를 2[%]로 개선하려면, 왜율을 1.02로 만들어야 한다.

    부퀘환율 β는 출력전압의 변화량/입력전압의 변화량으로 정의된다. 따라서, β = ΔVout/ΔVin 이다.

    입력전압의 변화량은 걸어주는 전압의 변화량으로 대체할 수 있다. 따라서, ΔVin = Vin x (부퀘환율 - 1)이 된다.

    따라서, β = ΔVout/ΔVin = (Vin x 전압이득 x 부퀘환율) / (Vin x (부퀘환율 - 1)) = 전압이득 / (부퀘환율 - 1)이 된다.

    이를 β = 0.08로 만들기 위해서는, 전압이득 50을 β = 0.08로 나누어 계산하면 된다.

    따라서, β = 전압이득 / (부퀘환율 - 1) = 50 / (0.08 + 1) = 47.17이 된다.

    따라서, 정답은 0.08이다.

    $A_{eff} = frac{lambda^2}{4pi}G_{max}$
