6. 다음 그림의 회로는 두 개의 비반전 증폭기를 종속 접속한 것이다. 저항 10[kΩ]에 흐르는 전류 ID는 몇 [μA]인가? (단, 각 연산 증폭기는 이상적이다.)

  1. 25[μA]
  2. 50[μA]
  3. 70[μA]
  4. 120[μA]
(정답률: 64%)
  • 30 CBT 기출문제AI

    2023-04-15 19:15

    이 회로에서는 비반전 증폭기가 두 개 연결되어 있으므로, 전류 증폭이 일어나지 않고 입력 전압이 출력 전압으로 그대로 전달된다. 따라서, V1과 V2의 출력 전압은 모두 1V이다.

    V1의 출력 전압이 1V이므로, V1의 음극과 R1 사이의 전압은 1V이다. 따라서, R1에 흐르는 전류는 1V / 10[kΩ] = 0.1[mA] = 100[μA]이다.

    V2의 출력 전압이 1V이므로, V2의 양극과 R2 사이의 전압은 1V이다. 따라서, R2에 흐르는 전류는 1V / 10[kΩ] = 0.1[mA] = 100[μA]이다.

    따라서, R1과 R2에 흐르는 전류의 합은 100[μA] + 100[μA] = 200[μA]이다. 하지만, R1과 R2는 병렬 연결되어 있으므로, 전류는 분할되어 흐르게 된다.

    R1과 R2의 등가 저항은 R1과 R2의 병렬 연결이므로, R1과 R2의 곱을 R1과 R2의 합으로 나눈 값이다. 따라서, R1과 R2의 등가 저항은 10[kΩ] x 10[kΩ] / (10[kΩ] + 10[kΩ]) = 5[kΩ]이다.

    따라서, R1과 R2에 흐르는 전류의 합 중 R2를 흐르는 전류는 R1과 R2의 등가 저항과 R2의 저항 비율로 계산할 수 있다. 즉, R2를 흐르는 전류는 200[μA] x (5[kΩ] / 10[kΩ]) = 100[μA]이다.

    따라서, R1과 R2에 흐르는 전류의 합 중 R1을 흐르는 전류는 200[μA] - 100[μA] = 100[μA]이다.

    따라서, 저항 10[kΩ]에 흐르는 전류 ID는 R1을 흐르는 전류와 같으므로, 100[μA]이다.

    따라서, 정답은 "70[μA]"가 아니라 "100[μA]"이다.

    따라서, 정재파비는 약 2.21이다.
