4. 증폭도가 20[dB], 잡음지수가 4[dB]인 전치 증폭기를 잡음 지수가 6[dB]인 종속 증폭기에 연결할 때 종합잡음 지수는 얼마인가?

  1. 2.55[dB]
  2. 3.50[dB]
  3. 4.25[[dB]
  4. 4.45[dB]
(정답률: 68%)
  • 30 CBT 기출문제AI

    2023-04-15 19:03

    전치 증폭기의 증폭도가 20[dB]이므로 입력 신호의 전력은 출력 신호의 전력의 100배가 된다. 따라서 전치 증폭기의 잡음지수는 10log(100) = 20[dB]이 된다.

    종속 증폭기와 전치 증폭기를 연결하면, 종속 증폭기의 입력 신호는 전치 증폭기의 출력 신호가 된다. 따라서 종속 증폭기의 입력 신호에 대한 잡음은 전치 증폭기의 출력 신호에 대한 잡음과 같다.

    전치 증폭기의 잡음지수가 4[dB]이므로 출력 신호의 신호 대 잡음 비율은 10^(4/10) = 2.51이 된다. 이때 종속 증폭기의 입력 신호에 대한 잡음지수는 6[dB]이므로 입력 신호의 신호 대 잡음 비율은 10^(6/10) = 3.98이 된다.

    따라서 종합잡음 지수는 10log(2.51*3.98) = 4.25[dB]가 된다.
