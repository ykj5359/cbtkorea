  4. 3,850,000원
(정답률: 70%)
  • 30 CBT 기출문제AI

    2023-04-18 01:53

    월 매출액 = 고객 수 x 객단가
    고객 수 = 90명
    객단가 = 35,000원
    월 매출액 = 90 x 35,000 = 3,150,000원

    상품의 마진율이 20%이므로, 상품의 원가는 80%이다.
    따라서, 상품의 원가 = 35,000 x 0.8 = 28,000원
    상품의 이익 = 35,000 - 28,000 = 7,000원
    고객 한 명당 상품의 이익 = 7,000 x 20% = 1,400원
    따라서, 월 상품 이익 = 90 x 1,400 = 126,000원

    따라서, 월 매출액은 3,150,000원이다.
