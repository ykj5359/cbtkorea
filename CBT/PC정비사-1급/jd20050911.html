  4. COM, EXE, BAT
(정답률: 82%)

49. PC를 업그레이드 하고자 할 때 먼저 교체할 일반적인 순서로 옳게 나열한 것은?

  4. RAM - CPU - VGA - Main Board - HDD
(정답률: 67%)

    2023-04-14 ⑤:36

    PC를 업그레이드 할 때 일반적인 순서는 Main Board - CPU - RAM - VGA - HDD 순서이다. 이는 다음과 같은 이유로 설명할 수 있다.

    1. Main Board: Main Board는 모든 하드웨어 구성 요소를 연결하는 중심 역할을 하기 때문에, 업그레이드를 시작하기 전에 먼저 Main Board를 교체해야 한다.

    5. HDD: HDD는 데이터를 저장하는 요소이다. 따라서 HDD를 업그레이드하면 더 많은 데이터를 저장할 수 있고, 빠른 데이터 전송 속도를 경험할 수 있다.
