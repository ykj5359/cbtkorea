8. 운영체제의 발달과정 순서로 올바른 것은?

  1. ④ → ③ → ② → ①
  2. ① → ② → ③ → ④
  3. ① → ③ → ④ → ②
  4. ④ → ② → ③ → ①
(정답률: 61%)
  • 30 CBT 기출문제AI

    2023-04-14 ⑤:18

    운영체제의 발달 과정은 크게 4단계로 나눌 수 있습니다.

    ① 일괄처리 시스템: 초기에는 컴퓨터가 하나의 작업을 처리할 때마다 모든 입출력 장치를 초기화하고 작업을 수행하는 방식이었습니다. 이후 일괄처리 시스템이 등장하여 여러 작업을 한꺼번에 처리할 수 있게 되었습니다.

    ③ 시분할 시스템: 여러 사용자가 동시에 컴퓨터를 사용할 수 있도록 하기 위해 시분할 시스템이 등장하였습니다. 이를 통해 각 사용자는 자신만의 컴퓨터를 사용하는 것처럼 느낄 수 있게 되었습니다.

    ④ 개인용 컴퓨터: 이전까지는 대형 컴퓨터를 여러 사용자가 공유하는 형태였지만, 개인용 컴퓨터가 등장하면서 각 개인이 자신만의 컴퓨터를 소유하게 되었습니다.

    ② 분산 시스템: 인터넷과 같은 통신 기술의 발전으로 분산 시스템이 등장하였습니다. 이를 통해 여러 대의 컴퓨터가 연결되어 하나의 시스템처럼 동작할 수 있게 되었습니다.

    따라서, 올바른 정답은 "① → ③ → ④ → ②" 입니다.
