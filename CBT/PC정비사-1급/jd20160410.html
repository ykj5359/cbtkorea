19. CPU 클럭을 계산하는 방법으로 올바른 것은?

  1. 시스템 클럭 + 배율
  2. 시스템 클럭 * 배율
  3. 시스템 클럭 / 배율
  4. 시스템 클럭 = 배율
(정답률: 75%)
  • 30 CBT 기출문제AI

    2023-04-14 ⑤:17

    정답은 "시스템 클럭 * 배율"이다.

    CPU 클럭은 CPU가 일정 시간 동안 몇 번의 연산을 수행하는지를 나타내는 속도이다. 이때, CPU 클럭은 시스템 클럭과 배율에 의해 결정된다.

    시스템 클럭은 CPU가 동작하는 기본 클럭 속도를 의미하며, 이는 CPU 제조사에서 미리 설정된 값이다.

    배율은 CPU 클럭을 시스템 클럭보다 높게 설정하는 값으로, CPU 제조사에서 제공하는 설정값 중 하나이다.

    따라서, CPU 클럭은 시스템 클럭과 배율의 곱으로 계산된다. 예를 들어, 시스템 클럭이 2GHz이고 배율이 4인 CPU의 클럭은 8GHz가 된다.

    1. 각 자리수를 2의 거듭제곱으로 변환한다.
    - (1)번째 자리: 2^4 = 16
    - (2)번째 자리: 2^3 = 8
    - (3)번째 자리: 2^2 = 4

    - (1)번째 자리: 1 x 16 = 16
