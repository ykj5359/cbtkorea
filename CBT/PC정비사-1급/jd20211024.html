2. Linux에서 모든 파일의 목록과 자세한 사항을 내림차순으로 정렬하기 위한 명령은?

  1. ls –alc
  2. ls -alk
  3. ls –alr
  4. ls -alu
(정답률: 49%)
  • 30 CBT 기출문제AI

    2023-04-14 ⑤:06

    정답은 "ls –alr"입니다.

    - "ls –alc": 모든 파일의 목록과 자세한 사항을 보여주며, 파일 크기를 바이트 단위로 표시하고, 파일 목록을 수정 시간순으로 정렬합니다.
    - "ls -alk": 모든 파일의 목록과 자세한 사항을 보여주며, 파일 크기를 킬로바이트 단위로 표시하고, 파일 목록을 파일 크기순으로 정렬합니다.
    - "ls –alr": 모든 파일의 목록과 자세한 사항을 보여주며, 파일 목록을 역순으로 정렬합니다.
    - "ls -alu": 모든 파일의 목록과 자세한 사항을 보여주며, 파일 목록을 액세스 시간순으로 정렬합니다.

    따라서, 모든 파일의 목록과 자세한 사항을 내림차순으로 정렬하기 위해서는 "ls –alr"을 사용해야 합니다.

5. 리눅스 명령을 이용하여 ICQA 디렉터리와 그 하위 디렉터리까지 모든 파일을 메시지없이 강제로 삭제하기 위한 명령은?

  1. rm –i ICQA
  2. rm -ir ICQA
  3. rm –rf ICQA
  4. rm -ra ICQA
(정답률: 58%)
  • 30 CBT 기출문제AI

    2023-04-14 ⑤:06

    정답은 "rm –rf ICQA"이다.

    - "rm –i ICQA": ICQA 디렉터리와 그 하위 디렉터리의 모든 파일을 삭제하기 전에 각 파일을 삭제할 것인지 물어보는 메시지가 나오므로, 메시지 없이 강제로 삭제할 수 없다.
    - "rm -ir ICQA": "-i" 옵션은 각 파일을 삭제하기 전에 물어보는 메시지를 나타내며, "-r" 옵션은 하위 디렉터리를 포함하여 모든 파일을 삭제한다. 하지만 "-i" 옵션 때문에 메시지 없이 강제로 삭제할 수 없다.
    - "rm –rf ICQA": "-r" 옵션은 하위 디렉터리를 포함하여 모든 파일을 삭제하며, "-f" 옵션은 강제로 삭제한다. 따라서 메시지 없이 강제로 삭제할 수 있다.
    - "rm -ra ICQA": "-r" 옵션은 하위 디렉터리를 포함하여 모든 파일을 삭제하며, "-a" 옵션은 숨김 파일까지 모두 삭제한다. 하지만 "-i" 옵션과 달리 메시지 없이 강제로 삭제할 수 없다.

57. 오류검출 부호가 아닌 것은?

  1. 해밍 부호
  2. 패리티 부호
  3. 2-5진 부호
  4. 3초과 부호
(정답률: 43%)
  • 30 CBT 기출문제AI

    2023-04-14 ⑤:03

    오류검출 부호는 데이터 전송 중에 발생할 수 있는 오류를 검출하고 수정하는 기술이다.

    1. 해밍 부호: 데이터의 비트에 일정한 규칙을 적용하여 오류를 검출하고 수정하는 부호이다.

    2. 패리티 부호: 데이터의 비트 중에서 1의 개수가 짝수인지 홀수인지를 검사하여 오류를 검출하는 부호이다.

    3. 2-5진 부호: 2진수나 5진수를 사용하여 데이터를 부호화하는 방식으로, 오류 검출 기능은 없다.

    4. 3초과 부호: 이 부호는 존재하지 않는다.

    따라서, 3초과 부호는 오류검출 부호가 아니기 때문에 정답이다.

60. 다음 기억소자 중 전원 공급이 중단되면 기억 내용이 지워지는 것은?

  1. EPROM
  2. EEPROM
  3. Flash Memory
  4. Cache RAM
(정답률: 30%)
  • 30 CBT 기출문제AI

    2023-04-14 ⑤:04

    Cache RAM은 CPU와 메인 메모리 사이에 위치하여 빠른 데이터 전송을 위해 사용되는 기억소자입니다. 전원 공급이 중단되면 기억 내용이 지워지는 휘발성 기억장치이기 때문에, 다른 기억소자들과 달리 전원이 끊어지면 데이터가 유지되지 않습니다. 따라서 Cache RAM은 전원이 유지되는 동안에만 유효한 데이터를 저장할 수 있습니다.
