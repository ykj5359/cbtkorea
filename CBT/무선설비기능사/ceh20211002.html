1. 저항 양단에 90[V]의 전압을 인가했을 때 30[A]전류가 흐른다. 이 때 저항 값은 얼마인가?

  1. 1[Ω]
  2. 3[Ω]
  3. 30[Ω]
  4. 60[Ω]
(정답률: 69%)
  • 30 CBT 기출문제AI

    2023-04-12 14:04

    오옴의 법칙에 따라 전압과 전류, 저항은 다음과 같은 관계가 성립합니다.

    전압 = 전류 x 저항

    여기서 전압은 90[V], 전류는 30[A]로 주어졌으므로 저항을 구할 수 있습니다.

    저항 = 전압 / 전류 = 90[V] / 30[A] = 3[Ω]

    따라서 정답은 "3[Ω]"입니다.

11. 아래의 발진회로에서 TP1에 나타나는 출력 주파수는 약 얼마인가?

  1. 130[Hz]
  2. 650[Hz]
  3. 780[Hz]
  4. 3.9[kHz]
(정답률: 48%)
  • 30 CBT 기출문제AI

    2023-04-12 14:04

    TP1은 Q1의 컬렉터와 R3의 접점으로 구성되어 있습니다. Q1은 NPN 트랜지스터로서, 베이스에 인가되는 입력 신호가 양수일 때 컬렉터와 에미터 사이의 전류가 흐릅니다. 이 때 R3은 컬렉터와 전원 사이에 연결되어 있으므로, 전압이 상승하게 됩니다.

    입력 신호가 사인파일 때, Q1의 베이스에 인가되는 전압은 사인파의 주파수와 일치합니다. 따라서 Q1의 컬렉터와 R3의 접점에서 출력되는 전압도 사인파의 주파수와 일치하게 됩니다.

    R3의 저항값은 1kΩ이며, C1의 용량은 0.1μF입니다. 이 때, RC 회로의 컷오프 주파수는 다음과 같이 계산됩니다.

    f_c = 1 / (2πRC) = 1 / (2π x 1kΩ x 0.1μF) ≈ 1591[Hz]

    따라서, 출력 주파수는 컷오프 주파수보다 작아집니다. 그리고 입력 신호의 주파수가 출력 주파수보다 작을수록 출력 신호의 왜곡이 적어집니다.

    보기에서 주어진 선택지 중에서는 650[Hz]가 가장 적절한 선택지입니다. 이는 컷오프 주파수보다 작은 값이며, 입력 신호의 주파수가 출력 주파수보다 작기 때문입니다.

14. 어떤 회로의 응답이 vo(t)=V(1-e-OM)[V]일 때 시정수로 알맞은 것은?

  1. 0.1[sec]
  2. 0.5[sec]
  3. 5[sec]
  4. 10[sec]
(정답률: 19%)
  • 30 CBT 기출문제AI

    2023-04-12 14:04

    시정수(Ts)는 0에서 90%의 상승시간을 의미합니다. 따라서 vo(t)가 V의 90%에 도달하는 시간을 구하면 됩니다.

    vo(t) = V(1-e-OM)
    0.9V = V(1-e-OM)
    0.9 = 1-e-OM
    e-OM = 0.1
    -OM = ln(0.1)
    M = -ln(0.1)/O

    시정수(Ts) = M/4 = (-ln(0.1)/4O)

    따라서, Ts는 10[sec]입니다.
