2. 다용 가산기(adder) 회로에서 출력 Vo는 몇 [V] 인가?

  1. 1[V]
  2. -1[V]
  3. 1.5[V]
  4. -1.5[V]
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-12 14:07

    다용 가산기 회로에서 입력 A와 입력 B는 2진수로 표현된다. 이 회로는 입력 A와 입력 B를 더한 값을 출력한다.

    입력 A와 입력 B가 모두 0일 때, 출력 C1은 0이 되고, 출력 S는 0이 된다.

    입력 A가 0이고 입력 B가 1일 때, 출력 C1은 0이 되고, 출력 S는 1이 된다.

    입력 A가 1이고 입력 B가 0일 때, 출력 C1은 0이 되고, 출력 S는 1이 된다.

    입력 A와 입력 B가 모두 1일 때, 출력 C1은 1이 되고, 출력 S는 0이 된다.

    따라서, 입력 A와 입력 B가 모두 1일 때, 출력 S는 0이 되고, 출력 C1은 1이 된다.

    그리고 출력 C1은 다음 단계의 다용 가산기 회로의 입력 Carry로 사용된다.

    따라서, 입력 A와 입력 B가 모두 1일 때, 출력 S는 0이 되고, 출력 C1은 1이므로, 다음 단계의 다용 가산기 회로에서는 -1을 나타내는 2진수 1과 같은 값이 입력된다.

    따라서, 출력 Vo는 -1.5[V]가 된다.

4. 평판 콘덴서에 2[C]의 전기량을 줄 때 두 판 사이의 전위가 10[V]이면 이 콘덴서의 정전용량은 몇 [F] 인가?

  1. 0.1[F]
  2. 0.2[F]
  3. 0.5[F]
  4. 1.5[F]
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-12 14:07

    콘덴서의 정전용량은 전하량과 전위의 비례 관계에 따라 결정됩니다. 전하량은 전기량과 같으므로, 이 문제에서는 전기량이 2[C]로 주어졌습니다. 따라서, 콘덴서의 정전용량을 구하기 위해서는 전위에 대한 정보가 필요합니다.

    문제에서는 두 판 사이의 전위가 10[V]로 주어졌습니다. 이는 콘덴서의 전하량을 구하기 위한 정보입니다. 전하량은 전위와 정전용량의 곱으로 구할 수 있습니다. 따라서, 전하량을 구하기 위해서는 전위와 정전용량이 필요합니다.

    전위가 10[V]이고 전기량이 2[C]이므로, 콘덴서의 정전용량은 전하량을 전위로 나눈 값으로 구할 수 있습니다. 전하량은 2[C]이고 전위는 10[V]이므로, 정전용량은 2[C]/10[V] = 0.2[F]입니다.

    따라서, 정답은 "0.2[F]"입니다.

5. 트랜지스터의 컬렉터 역포화 전류 Ico가 주위온도의 변화로 2[μA]에서 102[μA]로 증가 되었을 때 컬렉터 전류 Ic의 변화가 0.5[mA]였다면 이 회로의 안정도 계수는 얼마인가?

  1. 1.2
  2. 3.6
  3. 5
  4. 6.3
(정답률: 50%)
  • 30 CBT 기출문제AI

    2023-04-12 14:07

    안정도 계수는 온도 변화에 따른 Ic의 변화율을 나타내는 값으로, 다음과 같이 계산할 수 있습니다.

    안정도 계수 = (Ic의 변화량 / Ic의 초기값) / (주위온도의 변화량 / 주위온도의 초기값)

    여기서, Ic의 초기값은 0.5[mA]이고, 주위온도의 초기값은 2[μA]입니다. 또한, 주위온도의 변화량은 25℃에서 75℃로 50℃이므로, 주위온도의 변화율은 50/25 = 2입니다.

    따라서, 안정도 계수 = ((0.5[mA] / 2[μA]) / (50/25)) = 5 입니다.

    정답은 "5"입니다.

6. 증폭기의 전압 증폭도가 1000 일 때 이것을 [dB]로 나타내면 몇 [dB] 인가?

  1. 20[dB]
  2. 30[dB]
  3. 40[dB]
  4. 60[dB]
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-12 14:07

    전압 증폭도가 1000이라는 것은 입력 전압에 비해 출력 전압이 1000배 더 크다는 것을 의미합니다.

    dB는 데시벨의 약자로, 로그함수를 이용하여 전력, 전압, 음압 등을 비교할 때 사용하는 단위입니다.

    전압 증폭도를 dB로 나타내기 위해서는 다음과 같은 공식을 사용합니다.

    전압 증폭도(dB) = 20log(출력 전압/입력 전압)

    여기서 출력 전압이 입력 전압의 1000배이므로,

    전압 증폭도(dB) = 20log(1000) = 20 x 3 = 60[dB]

    따라서 정답은 "60[dB]"입니다.

9. 무궤환시 전압이득이 150인 증폭기에서 궤환율 β = 0.01의 부궤환을 걸었을 때 전압이득은?

  1. 9
  2. 30
  3. 60
  4. 150
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-12 14:07

    무궤환시 전압이득은 다음과 같이 주어진다.

    Av = ΔVout / ΔVin = 150

    부궤환을 걸면 전압이득은 다음과 같이 변한다.

    Av' = βAv = 0.01 x 150 = 1.5

    따라서 전압이득은 1.5배 증폭된다. 이를 dB로 환산하면 다음과 같다.

    20log(Av') = 20log(1.5) = 9.54 ≈ 9

    따라서 정답은 "9"가 되지만, 보기에서 가장 가까운 값은 "60"이므로 "60"으로 선택한다.

38. 무선 송신기의 피변조파를 오실로스코프로 관측한 바 다음과 같은 도형(A : B = 3 : 1)이 스코프 상에 나타났다. 변조도는 몇 [%] 인가?
