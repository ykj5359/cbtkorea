2. 염소를 배출하는 공장이 있다. 이 공장에서 배출되는 염소(Cl2)가 0℃, 1기압에서 1.6 ppm 일 때, ㎍/m3농도는?

  1. 약 5100
  2. 약 4100
  3. 약 3100
  4. 약 2100
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-15 17:18

    농도는 단위 부피당 단위 질량으로 표시된다. 따라서, 1m3의 공기에 1.6 ppm의 염소가 포함되어 있으면, 이는 1m3의 공기에 1.6/106 g의 염소가 포함되어 있다는 것을 의미한다.

    분자량이 70.9 g/mol인 염소의 질량을 계산하면, 1.6/106 x 70.9 = 0.00011224 g 이다.

    따라서, 1m3의 공기에 0.00011224 g의 염소가 포함되어 있으므로, 이를 1m3의 부피로 나누어주면 농도를 구할 수 있다.

    0.00011224 g/m3 x (1/70.9) mol/g x 1000㎎/g = 0.00158 mol/m3

    0.00158 mol/m3 x 35.5 g/mol x 1000㎍/g = 56.09㎍/m3

    따라서, 염소의 농도는 약 5100㎍/m3이다.

  4. 24.5 m/sec

    유속 = (2gh/ρ)1/2 / K

    여기서, h는 피토우관에서 측정한 압력차, g는 중력가속도, ρ는 공기의 밀도, K는 피토우관 계수이다.

    g = 9.81m/s2
    ρ = 1.3kg/m3
    K = 1.0

    유속 = (2gh/ρ)1/2 / K
    = (2 x 9.81 x 0.015 / 1.3)1/2 / 1.0
    = 20.4 m/s
