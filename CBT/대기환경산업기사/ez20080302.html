    Deacon 식은 다음과 같다.

    V2/V1 = (h2/h1)^p

    여기서 V1은 기준이 되는 지상 44m에서의 풍속, V2는 구하고자 하는 지상 11m에서의 풍속, h1은 기준이 되는 높이인 44m, h2는 구하고자 하는 높이인 11m이다. p는 풍속지수로, 문제에서 주어진 값은 0.25이다.

    따라서, 문제에 대입하면 다음과 같다.

    V2/7.5 = (11/44)^0.25

    V2 = 7.5 x (11/44)^0.25

    V2 = 5.3m/s

    따라서, 정답은 "5.3m/s"이다.

9. SO2가 유효고 100m 인 굴뚝으로부터 150g/s의 속도로 배출되고 있다. 굴뚝 높이에서의 풍속은 5m/s이고, 대기의 안정도는 D 이다. 이 때 굴뚝으로부터 1000m 거리에서의 지표중심선상의 농도(ppb)는? (단, 안정도 D 일 때 1000m 지점의 δy = 68m, δz = 32m, 농도계산은 이용하며, 표준상태로 가정)

  1. 64.5 ppb
  2. 33.2 ppb
  3. 11.6 ppb
  4. 5.6 ppb
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-15 17:18

    먼저, SO2의 배출량과 굴뚝 높이에서의 풍속을 이용하여 굴뚝에서 나오는 SO2의 농도를 계산할 수 있다. 이는 다음과 같다.

    C0 = Q / (u * A)

    여기서, C0는 굴뚝에서 나오는 SO2의 농도(ppm), Q는 배출량(g/s), u는 굴뚝 높이에서의 풍속(m/s), A는 굴뚝 단면적(m2)이다.

    위 식에 값을 대입하면,

    C0 = 150 / (5 * π * (0.5)2) = 19.1 ppm

    다음으로, 안정도 D일 때 1000m 지점의 농도를 계산하기 위해 다음 식을 이용한다.

    C = C0 * exp(-y2 / (2 * δy2) - z2 / (2 * δz2))

    여기서, C는 지표중심선상의 농도(ppb), y는 수직 방향 거리(m), z는 수평 방향 거리(m)이다.

    위 식에 값을 대입하면,

    C = 19.1 * exp(-10002 / (2 * 682) - 0 / (2 * 322)) = 11.6 ppb

    따라서, 정답은 "11.6 ppb"이다.

17. 굴뚝의 현재 유효고가 55m 일 때, 최대 지표농도를 절반으로 감소시키기 위해서는 유효고도(m)를 얼마만큼 더 증가시켜야 하는가? (단, Sutton 식을 적용하고, 기타 조건은 동일하다고 가정)

  2. 32.0m
  3. 22.8m
  4. 11.4m
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-15 17:18

    Sutton 식은 다음과 같다.

    C = Q / (u * A * sqrt(2 * g * H))

    여기서 C는 배기가스 농도, Q는 배기가스 유량, u는 배기가스 속도, A는 굴뚝 단면적, g는 중력가속도, H는 유효고이다.

    최대 지표농도를 절반으로 감소시키기 위해서는 C를 0.5로 설정해야 한다.

    그리고 다른 조건들은 동일하므로, 식을 다음과 같이 정리할 수 있다.

    H1 / H2 = (C2 / C1)^2

    여기서 H1은 현재 유효고인 55m이고, H2는 최대 지표농도를 절반으로 감소시키기 위해 필요한 유효고이다.

    C1은 현재 배기가스 농도이고, C2는 최대 지표농도를 절반으로 감소시키기 위한 배기가스 농도이다. 따라서 C2는 0.5이다.

    그리고 다시 Sutton 식에 대입하여 C1을 구할 수 있다.

    C1 = Q / (u * A * sqrt(2 * g * H1))

    여기서 Q, u, A, g는 모두 동일하므로, C1은 H1에 반비례한다.

    따라서 H1 / H2 = (C2 / C1)^2 = (0.5 / C1)^2

    이를 H2에 대해 정리하면 다음과 같다.

    H2 = H1 * sqrt(C1^2 / 0.25) = H1 * 2 * C1

    여기서 C1은 Sutton 식에 대입하여 구할 수 있다.

    C1 = Q / (u * A * sqrt(2 * g * H1)) = 0.1

    따라서 H2 = H1 * 2 * C1 = 55 * 2 * 0.1 = 11m

    즉, 유효고를 11m 더 증가시켜야 최대 지표농도를 절반으로 감소시킬 수 있다.

    따라서 정답은 "11.4m"이다.

21. 다음 조건을 이용한 가스크로마토그래프법에서 분리관의 HETP는?

  1. 1.25mm

  4. 6.5mm

    2023-04-15 17:18

    HETP는 Height Equivalent to a Theoretical Plate의 약자로, 이론상의 하나의 플레이트와 같은 효과를 내는 분리관의 길이를 의미합니다.

    가스크로마토그래프법에서 HETP는 다음과 같은 식으로 계산됩니다.

    HETP = L/N

    여기서 L은 분리관의 길이, N은 분리관 내에서의 이론상의 플레이트 수를 나타냅니다.

    이론상의 플레이트 수 N은 다음과 같은 식으로 계산됩니다.

    N = 16 (tR/w)^2

    여기서 tR은 샘플의 정지시간, w는 샘플이 분리관 내에서 이동하는 폭을 나타냅니다.

    주어진 그림에서 샘플의 정지시간은 0.5cm이고, 폭은 0.2cm입니다. 이를 이용하여 이론상의 플레이트 수를 계산하면 다음과 같습니다.

    N = 16 (0.5cm/0.2cm)^2 = 16 (2.5)^2 = 100

    따라서 HETP는 다음과 같이 계산됩니다.

    HETP = L/N = 4mm/100 = 0.04mm/plate

    여과속도 = 집진공기량 / 여과면적

    여기서 집진공기량은 20m3/s이고, 여과면적은 백필터의 표면적으로 구할 수 있다.
