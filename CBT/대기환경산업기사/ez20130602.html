    효율 = 유용출력 / 입력출력

    입력출력 = 유용출력 / 효율

    유용출력 = 축동력 x 속도

    입력출력 = 축동력 x 속도 / 효율

    축동력 = (200 x 12,000) / (0.75 x 102) = 23,529 Nm/hr

    60은 분당을 초당으로 변환하기 위한 상수이다.

    속도 = 23,529 / (12,000 x 60) = 0.0328 m/s

    입력출력 = 유용출력 / 효율 = 773.4 / 0.75 = 1,031.2 W
