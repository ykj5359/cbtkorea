2. 지상 44m에서 풍속이 7.5m/s 일 때, 지상 11m높이에서의 풍속은? (단, Deacon식 적용, 풍속지수 p는 0.25)

  1. 5.3m/s
  2. 5.7m/s
  3. 6.2m/s
  4. 6.9m/s
(정답률: 73%)
  • 30 CBT 기출문제AI

    2023-04-15 17:03

    Deacon식은 지상과 고도에 따른 풍속 간의 관계를 나타내는 식입니다. 이 식에 따르면, 지상에서의 풍속(V1)과 고도(h1)가 주어졌을 때, 다른 고도(h2)에서의 풍속(V2)는 다음과 같이 구할 수 있습니다.

    V2 = V1 * (h2/h1)^(1/7)

    따라서 이 문제에서는 V1 = 7.5m/s, h1 = 44m, h2 = 11m 이므로,

    V2 = 7.5 * (11/44)^(1/7) = 5.3m/s

    따라서 정답은 "5.3m/s" 입니다.

28. 굴뚝의 150℃인 배출가스를 피토우관으로 측정한 결과 동압이 20mmH2O였을 때 유속은? (단, 습한 배출가스 빌도는 1.3kg/Sm3, 피토우관 계수는 0.8790이다.)

  4. 21.6 m/sec
(정답률: 62%)

    2023-04-15 17:03

    유속은 다음과 같이 계산할 수 있다.

    유속 = (2gh/ρ)1/2 / C

    여기서,
    - g는 중력가속도 (9.81 m/s2)
    - h는 피토우관의 높이차 (m)
    - ρ는 유체의 밀도 (kg/m3)
    - C는 피토우관 계수

    먼저, 배출가스의 밀도는 1.3kg/Sm3이므로, 1m3당 1.3kg의 배출가스가 발생한다. 따라서, 1초당 배출되는 가스의 부피는 다음과 같다.

    부피 = 유량 / 밀도 = 1 / 1.3 = 0.7692 m3/s

    이제, 피토우관의 높이차를 구해보자. 동압이 20mmH2O이므로, 압력차는 다음과 같다.

    압력차 = 20 / 1000 = 0.02 mH2O

    여기서, 1mH2O는 9.80665 Pa이므로, 압력차는 다음과 같다.

    압력차 = 0.02 x 9.80665 = 0.19613 Pa

    따라서, 피토우관의 높이차는 다음과 같다.

    h = 압력차 / (밀도 x g) = 0.19613 / (1.3 x 9.81) = 0.015 m

    마지막으로, 피토우관 계수를 곱해주면 유속을 구할 수 있다.

    유속 = (2gh/ρ)1/2 / C = (2 x 9.81 x 0.015 / 1.3)1/2 / 0.8790 = 19.0 m/sec

    따라서, 정답은 "19.0 m/sec"이다.
