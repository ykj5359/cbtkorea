2. 굴뚝 직경 2m, 굴뚝 배출가스 속도 5m/s, 굴뚝 배출가스 온도 400Km, 대기온도 300K, 풍속3m/s일 때 연기 상승높이(m)는? (단, )

  1. 142.6m
  2. 152.3m
  3. 168.5m
  4. 198.2m
(정답률: 65%)
  • 30 CBT 기출문제AI

    2023-04-15 16:40

    이 문제는 연기의 상승높이를 구하는 문제로, 연기의 상승력과 대기의 저항력을 고려하여 계산해야 한다.

    먼저, 연기의 상승력은 다음과 같이 계산할 수 있다.

    상승력 = (배출가스 속도)^2 x (굴뚝 단면적) x (배출가스 밀도 - 대기 밀도) x g / (4 x 대기 밀도)

    여기서, 배출가스 밀도는 온도와 압력에 따라 변화하므로, 이 문제에서는 단순화를 위해 대기 밀도와 같다고 가정한다. 따라서,

    배출가스 밀도 - 대기 밀도 = 0

    그리고, g는 중력가속도로 9.8m/s^2이다.

    따라서, 상승력 = (5m/s)^2 x (π x 1m^2) x (0) x 9.8m/s^2 / (4 x 1.2kg/m^3) = 21.7N

    다음으로, 대기의 저항력은 다음과 같이 계산할 수 있다.

    저항력 = (1/2) x (대기 밀도) x (연기 속도)^2 x (연기 단면적) x (공기 저항 계수)

    여기서, 공기 저항 계수는 연기의 형태와 표면 상태에 따라 달라지므로, 이 문제에서는 0.5로 가정한다.

    따라서, 저항력 = (1/2) x (1.2kg/m^3) x (3m/s)^2 x (π x 1m^2) x (0.5) = 6.8N

    마지막으로, 연기의 상승높이는 상승력과 저항력의 차이에 따라 결정된다.

    상승높이 = (상승력 - 저항력) x (굴뚝 높이) / (상승력 + 저항력)

    따라서, 상승높이 = (21.7N - 6.8N) x (2m) / (21.7N + 6.8N) = 152.3m

    따라서, 정답은 "152.3m"이다.

16. 먼지농도가 160μg/m3이고, 상대습도가 70%인 상태의 대도시에서의 가시거리는 몇 km인가? (단, A=1.2)

    가시거리는 대기 중 먼지와 수증기의 농도에 영향을 받는다. 이 문제에서는 먼지농도와 상대습도가 주어졌으므로, 가시거리를 구하기 위해서는 먼지와 수증기의 영향을 모두 고려해야 한다.

    가시거리는 다음과 같은 식으로 구할 수 있다.

    여기서 NTU는 Number of Transfer Units로, 흡수탑의 전체 전달 단위 수를 나타내는 값이다. C0, C1, C2는 각각 흡수탑의 상단, 중간, 하단에서의 불화수소 농도를 나타내는 값이다.

    NTU = 0.44 / 0.4 = 1.1
