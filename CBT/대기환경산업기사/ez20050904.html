9. 굴뚝 직경이 3m, 배출속도가 10m/sec, 배출온도 500K 대기온도 27℃, 풍속 4.2m/sec 일 때, 다음 공식을 이용하여 계산한 유효상승고(Δh)?

  1. 226.33m
  2. 258.45m
  3. 308.87m
  4. 347.98m
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-15 17:20

    유효상승고(Δh) = (Q/(πr^2 * V)) * ((T+273)/298) * (1-(T+273)/(T+273+0.5*V^2)) * (1+(0.5*V^2)/(Cp*(T+273)))

    여기서,
    Q = 배출량 = πr^2 * V * ρ * C
    ρ = 대기의 밀도 = 1.225 kg/m^3
    C = 배출가스의 열용량 = 10⑤ J/kgK
    r = 굴뚝의 반지름 = 1.5m
    V = 풍속 = 4.2m/sec
    T = 배출온도 = 500K

    따라서,
    Q = π(1.5^2) * 10 * 1.225 * 0.⑤ = 13.68 m^3/sec
    Cp = 10⑤ J/kgK
    Δh = (13.68/(π*(1.5^2)*4.2)) * ((500+273)/298) * (1-(500+273)/(500+273+0.5*(4.2^2))) * (1+(0.5*(4.2^2))/(10⑤*(500+273)))
    = 226.33m

    따라서, 유효상승고(Δh)는 226.33m이다.
