2. A 혼합가스 성분을 분석한 결과 CO2 가 7%이고 나머지가 N2로 구성되어 있다면 이 혼합가스의 밀도는?

  1. 1.3 kg/Sm3
  2. 1.5 kg/Sm3
  3. 2.0 kg/Sm3
  4. 2.3 kg/Sm3
(정답률: 67%)
  • 30 CBT 기출문제AI

    2023-04-15 17:15

    CO2의 분자량은 44 g/mol이고, N2의 분자량은 28 g/mol이다. 따라서 이 혼합가스의 분자량은 CO2와 N2의 비율에 따라 다음과 같이 계산할 수 있다.

    분자량 = (0.07 × 44 g/mol) + (0.93 × 28 g/mol) = 29.96 g/mol

    이제 이 혼합가스의 밀도를 구하기 위해 다음과 같은 공식을 사용할 수 있다.

    밀도 = (분자량 × 압력) / (기체상수 × 온도)

    압력과 온도는 문제에서 주어지지 않았으므로, 일반적으로 기준 압력과 기준 온도를 사용한다. 기준 압력은 보통 1 atm이고, 기준 온도는 보통 0℃ 또는 273 K이다. 따라서 이 문제에서도 기준 압력과 기준 온도를 사용하여 밀도를 계산할 수 있다.

    기체상수는 모든 기체에 대해 동일하므로, R = 0.0821 L·atm/mol·K로 가정한다.

    밀도 = (29.96 g/mol × 1 atm) / (0.0821 L·atm/mol·K × 273 K) = 1.3 kg/Sm3

    따라서 정답은 "1.3 kg/Sm3"이다.

9. 대기가 매우 불안정한 조건에서 지상 10m에서의 풍속이 2m/sec 이면 100m에서는 몇 m/sec인가? (단, Deacon의 식을 이용하면 계산하고, 이 조건에서의 풍속지수는 0.2 이다.)

  1. 10.6
  2. 8.1
  3. 6.3
  4. 3.2
(정답률: 73%)
  • 30 CBT 기출문제AI

    2023-04-15 17:15

    Deacon의 식은 다음과 같다.

    V2/V1 = (h2/h1)^α

    여기서 V1은 지상에서의 풍속, V2는 높이가 h2인 곳에서의 풍속, α는 대기 안정도에 따라 변하는 상수이다.

    이 문제에서는 대기가 매우 불안정하므로 α는 0.3이 된다.

    따라서,

    V2/2 = (100/10)^0.3

    V2 = 2 x 10^(0.3 x log10(10))

    V2 = 3.2

    즉, 지상 10m에서의 풍속이 2m/sec일 때, 100m에서의 풍속은 3.2m/sec가 된다.

    Coh = (O.D / 0.01) * (1 / L)

    2023-04-15 17:15

    집진율 = (Q/C) x (1 - e^(-KAC/Q))

    집진율 = (240/6.47) x (1 - e^(-K x 250 x 1/240/6.47))

    0.99 = (240/6.47) x (1 - e^(-K x 250 x 1/240/6.47))

    K = 0.0006

    이제 출구농도를 구하기 위해 다음 식을 이용한다.

    출구농도 = (집진율 x C) / (Q x (1 - e^(-KAC/Q)))

    출구농도 = (0.99 x 6.47) / (240 x (1 - e^(-0.0006 x 250 x 1/240)))

    출구농도 = 0.152 g/m^3

    따라서 정답은 0.152이다.
