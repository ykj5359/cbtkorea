    먼지 채취를 위한 측정점수는 굴뚝 내부의 속도와 먼지 농도에 따라 결정된다. 일반적으로 굴뚝 내부의 속도는 10m/s 이하로 유지되어야 하며, 먼지 농도는 50mg/m³ 이하로 유지되어야 한다.

    따라서 이 문제에서는 굴뚝 내부의 속도와 먼지 농도를 계산하여 측정점수를 결정해야 한다.

    먼저, 굴뚝 내부의 속도를 계산해보자. 굴뚝 내부의 속도는 다음과 같이 계산된다.

    v = (4Q)/(πD²)

    여기서 Q는 유출량, D는 굴뚝의 직경이다.

    먼지 채취를 위해서는 유출량이 일정하게 유지되어야 하므로, 유출량은 굴뚝 내부의 속도에 비례한다. 따라서 유출량을 1로 가정하고, 굴뚝 내부의 속도를 계산해보자.

    v = (4 x 1)/(π x 2.2²) ≈ 0.25m/s

    굴뚝 내부의 속도가 10m/s 이하로 유지되어야 하므로, 이 조건은 만족한다.

    다음으로, 먼지 농도를 계산해보자. 먼지 농도는 다음과 같이 계산된다.

    C = (Q x C₁)/(v x A)

    먼지 농도를 50mg/m³ 이하로 유지하려면, C₁는 다음과 같이 계산된다.

    C₁ = (50 x v x A)/Q

    여기서 Q는 1로 가정하고, A는 다음과 같이 계산된다.

    A = π x (2.2/2)² ≈ 3.8m²

    따라서,

    C₁ = (50 x 0.25 x 3.8)/1 ≈ 47.5mg/m³

    먼지 농도가 50mg/m³ 이하로 유지되므로, 이 조건도 만족한다.

    따라서, 이 문제에서의 측정점수는 16이다.

  2. 10.5
  3. 14.5
  4. 18.5

    먼저, 유입계수와 속도압을 이용하여 후드의 속도를 구한다.

    유입계수 = 유량 / (후드면적 x 속도)

    속도 = 유량 / (후드면적 x 유입계수)

    여기서, 후드면적은 알려지지 않았으므로, 일반적으로 사용되는 후드면적 대비율을 이용하여 근사값을 구한다. 대부분의 후드는 직사각형 모양이며, 이 경우 후드면적 대비율은 0.7 정도이다.

    후드의 속도 = 유량 / (0.7 x 유입계수)

    속도압 = 22.5 mmH2O

    속도압 = 0.00278 x 밀도 x 속도^2

    여기서, 밀도는 공기의 밀도인 1.2 kg/m^3으로 가정한다.

    22.5 = 0.00278 x 1.2 x 속도^2

    속도 = 16.5 m/s

    이제, 후드의 속도를 이용하여 압력손실을 계산한다.

    압력손실 = (속도^2 x 밀도 x 후드면적 x 손실계수) / 2

    여기서, 손실계수는 후드의 형태와 유동특성에 따라 달라지며, 일반적으로 0.5 ~ 1.0 사이의 값을 가진다. 여기서는 0.5로 가정한다.

    압력손실 = (16.5^2 x 1.2 x 0.7 x 0.5) / 2

    압력손실 = 14.5 mmH2O

    따라서, 정답은 "14.5"이다.
