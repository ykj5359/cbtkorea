5. 10[Ω]과 15[Ω]의 저항을 병렬로 하고 50[A]의 전류를 흘렸을 때, 저항 15[Ω]에 흐르는 전류는 얼마인가?

  1. 10[A]
  2. 20[A]
  3. 30[A]
  4. 40[A]
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-12 20:32

    병렬 회로에서는 전압은 동일하고 전류는 각 분기마다 달라집니다. 따라서 전류의 합을 구해서 각 분기의 전류를 구할 수 있습니다.

    병렬 회로에서 전류의 합은 각 저항의 역수의 합으로 구할 수 있습니다. 따라서,

    1/10 + 1/15 = 3/30 + 2/30 = 5/30 = 1/6

    전류의 합은 50[A] 이므로, 각 분기의 전류는 다음과 같습니다.

    10[Ω] 분기: 50[A] x (1/6) x (10/1) = 83.33[A]
    15[Ω] 분기: 50[A] x (1/6) x (15/1) = 125[A]

    따라서, 저항 15[Ω]에 흐르는 전류는 125[A] 이므로, 정답은 "125[A]"가 됩니다.

19. 회로에서 리플함유율이 2%이다. Vd= 250V일 때 △V는 몇 V 인가? (단, △V는 실효값임)

  1. 2
  2. 5
  3. 7.5
  4. 12.5
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-12 20:32

    리플함유율은 (Vmax - Vmin) / (Vmax + Vmin) 으로 계산할 수 있습니다. 여기서 Vmax는 정전압값, Vmin은 최소전압값을 의미합니다.

    Vd= 250V일 때, 정전압값은 Vd = 250V입니다.

    리플함유율이 2%이므로, (Vmax - Vmin) / (Vmax + Vmin) = 0.02 입니다.

    이를 정리하면, Vmax = 1.01Vmin 입니다.

    그림에서 보면, Vmin은 220V이므로, Vmax는 1.01 x 220V = 222.2V 입니다.

    따라서, △V = (Vmax - Vmin) / √2 = (222.2V - 220V) / √2 = 1.4V 입니다.

    하지만 문제에서 △V는 실효값으로 주어졌으므로, 1.4V / √2 = 0.99V 입니다.
