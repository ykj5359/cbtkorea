7. 양수량 매분 5[m3], 총양정 6[m]를 양수하는데 필요한 구동용 전동기의 출력[KW]은 약 얼마인가? (단,펌프효율은 70[%]이고 상수 K는 1.1이다.)

  1. 5.4
  2. 7.7
  3. 47
  4. 52
(정답률: 82%)
  • 30 CBT 기출문제AI

    2023-04-17 14:45

    펌프효율은 70[%]이므로, 유체의 역학적인 에너지 손실이 30[%] 발생한다는 것을 의미한다. 따라서, 펌프가 이동시키는 유체의 총양정은 70[%]만큼만 상승하게 된다. 따라서, 실제로 펌프가 이동시키는 유체의 총양정은 6[m] x 0.7 = 4.2[m]이 된다.

    양수량은 5[m3]이므로, 이를 이동시키기 위해서는 5[m3] / 4.2[m] = 1.19 회의 이동이 필요하다.

    구동용 전동기의 출력은 다음과 같이 계산할 수 있다.

    구동용 전동기의 출력[KW] = (유체의 중량 x 중력가속도 x 총양정 x 이동회수) / (펌프효율 x 상수 K)

    여기서, 유체의 중량은 밀도 x 체적으로 계산할 수 있으며, 이 경우에는 물의 밀도를 1000[kg/m3]으로 가정하면 된다.

    따라서, 구동용 전동기의 출력은 다음과 같이 계산할 수 있다.

    구동용 전동기의 출력[KW] = (1000[kg/m3] x 5[m3] x 9.81[m/s2] x 4.2[m] x 1.19) / (0.7 x 1.1) = 7.7[KW]

    따라서, 정답은 "7.7"이다.

10. 루소 선도가 그림과 같이 표시되는 광원의 하반구 광속은 약 얼마인가?

  1. 471 [ℓ m]
  2. 940 [ℓ m]
  3. 1880 [ℓ m]
  4. 7500 [ℓ m]
(정답률: 55%)
  • 30 CBT 기출문제AI

    2023-04-17 14:42

    이 그림은 루소 선도를 이용하여 광원의 광속을 구하는 문제이다. 루소 선도에서는 광원의 위치와 광속을 나타내는 선분을 그린 후, 이를 이용하여 광속을 구한다.

    이 문제에서는 광원의 하반구 광속을 구해야 하므로, 루소 선도에서 광원의 위치를 아래쪽으로 향하도록 그린다. 그리고 광원에서 떨어진 거리를 측정하여 루소 선도 상에 표시한다.

    하지만 이 문제에서는 광속을 [ℓ m] 단위로 표시해야 하므로, 10.0 cm/s 를 [ℓ m] 단위로 변환해야 한다. 1 cm = 10^-2 m 이므로, 10.0 cm/s = 10^-2 m/s 이다.

    따라서 광속은 10^-2 [m/s] 이며, 이를 [ℓ m] 단위로 변환하면 471 [ℓ m] 이 된다. 따라서 정답은 "471 [ℓ m]" 이다.

    즉, Zp = (1/Z1 + 1/Z2 + ... + 1/Zn)^-1

    여기서 n은 병렬로 연결된 변압기의 개수이다.

    따라서 이 문제에서는 두 개의 변압기가 병렬로 연결되어 있으므로,

    Zp = (1/Z1 + 1/Z2)^-1

    Z1 = 0.08j

    Z2 = 0.09j

    Zp = (1/0.08j + 1/0.09j)^-1

    KVA = |V|^2 / |Zp|

45. 전압 2200[V], 무부하 전류 0.088[A]인 변압기의 철손이 110[W]이었다. 자화전류는?

  2. 약 0.038[A]
  3. 약 0.0724[A]
  4. 약 0.088[A]
(정답률: 4%)
  • 30 CBT 기출문제AI

    2023-04-17 14:45

    철손은 전류가 흐르면서 발생하는 열로 인해 발생하는 손실이다. 따라서 철손은 전류와 비례한다.

    전압과 무부하 전류를 알고 있으므로, 변압기의 피상 전력을 구할 수 있다.

    피상 전력 = 전압 x 무부하 전류 = 2200[V] x 0.088[A] = 193.6[W]

    실제 전력은 철손으로 인해 피상 전력보다 작다. 따라서 철손을 빼면 실제 전력을 구할 수 있다.

    실제 전력 = 피상 전력 - 철손 = 193.6[W] - 110[W] = 83.6[W]

    실제 전력 = 전류 x 전압 x cos(θ)

    cos(θ)는 역률로, 변압기의 효율을 나타낸다. 일반적으로 변압기의 역률은 0.9 ~ 0.98 사이이다. 여기서는 역률을 0.9로 가정한다.

    83.6[W] = 전류 x 2200[V] x 0.9

    전류 = 83.6[W] / (2200[V] x 0.9) = 0.042[A]

    하지만 이는 자화전류와 철손을 모두 포함한 값이다. 따라서 자화전류를 구하기 위해서는 철손을 빼줘야 한다.

    자화전류 = 전류 - 철손 / 전압 = (0.088[A] - 0.042[A]) / 2200[V] = 0.046[A] / 2200[V] = 약 0.0724[A]

    따라서 정답은 "약 0.0724[A]"이다.
