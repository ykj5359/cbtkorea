4. 효율 80%의 전열기로 1kWh의 전기량을 소비하였을 때 10L의 물을 몇 [℃] 올릴 수 있는가?

  1. 588
  2. 688
  3. 58.8
  4. 68.8
(정답률: 77%)
  • 30 CBT 기출문제AI

    2023-04-17 14:25

    1kWh는 1000W의 전력을 1시간 동안 사용한 것이므로, 1시간 동안 800W의 열을 발생시킬 수 있습니다. 따라서, 10L의 물을 1℃ 올리기 위해서는 약 4184J의 열이 필요합니다. 800W의 열을 발생시키는 전열기로 1시간 동안 발생시킬 수 있는 열은 800W x 3600s = 2,880,000J입니다. 따라서, 10L의 물을 1℃ 올리기 위해서는 4184J x 10℃ = 41,840J의 열이 필요하므로, 이를 발생시키기 위해서는 41,840J ÷ 2,880,000J = 0.0145시간이 필요합니다. 이를 분으로 환산하면 0.0145시간 x 60분/1시간 = 0.87분이 됩니다. 따라서, 10L의 물을 1kWh의 전기를 사용하여 80% 효율의 전열기로 1℃ 올릴 수 있는 시간은 0.87분이며, 이 때 물의 온도 상승량은 1℃입니다. 따라서, 10L의 물을 1kWh의 전기를 사용하여 80% 효율의 전열기로 68.8℃ 올릴 수 있습니다.

  1. 1.0
  2. 1.2
  3. 1.5
  4. 1.8
(정답률: 16%)
  • 30 CBT 기출문제AI

    2023-04-17 14:25

    인덕턴스는 다음과 같은 공식으로 계산된다.

    L = (μ * d) / (π * ln(D/d))

    여기서, L은 인덕턴스, μ는 자기유도율, d는 가공선의 직경, D는 가공선의 외경이다.

    주어진 문제에서는 인덕턴스와 파동 임피던스만 주어졌으므로, 자기유도율을 구해야 한다.

    자기유도율은 다음과 같은 공식으로 계산된다.

    μ = μ0 * μr

    여기서, μ0는 자유공간의 자기유도율이고, μr은 상대유도율이다. 상대유도율은 주어지지 않았으므로, 일반적으로 사용되는 구리의 상대유도율인 1.0004를 사용한다.

    따라서, μ = μ0 * 1.0004 = 4π × 10^-7 * 1.0004 = 1.2566 × 10^-6 H/m이다.

    가공선의 직경과 외경은 주어지지 않았으므로, 일반적으로 사용되는 1 cm 직경의 가공선을 가정한다. 이 경우, d = 0.01 m, D = 0.0127 m이다.

    따라서, L = (μ * d) / (π * ln(D/d)) = (1.2566 × 10^-6 * 0.01) / (π * ln(0.0127/0.01)) = 1.0 mH/km이다.
