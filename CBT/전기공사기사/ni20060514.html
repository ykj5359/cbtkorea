9. 평균 구면 광도 100[cd]의 전구 5개를 지름 10[m]인 원형의 실에 점등할 때 조명율을 0.5, 감광 보상률을 1.5로 하면 방의 평균 조도는 약 몇 [lx]인가?

  1. 18
  2. 23
  3. 27
  4. 32
(정답률: 75%)
  • 30 CBT 기출문제AI

    2023-04-17 14:38

    조명율은 전체 광량 중에서 실제로 방 안에 도달하는 광량의 비율을 나타내는 값이다. 따라서 조명율이 0.5이면 전구에서 발산되는 광량의 절반만이 방 안에 도달한다는 뜻이다.

    감광 보상률은 인간의 눈이 어떤 조도에서 어떤 색상을 어떻게 인식하는지를 고려한 값이다. 감광 보상률이 1.5이면 인간의 눈이 조명되는 공간에서 실제로 인식하는 조도는 전체 조도의 1.5배가 된다는 뜻이다.

    따라서 방의 평균 조도는 다음과 같이 계산할 수 있다.

    전구 1개가 방 안에 도달하는 광량 = 100[cd] x 4π(5[m])^2 = 31,416[lm]
    전구 5개가 방 안에 도달하는 총 광량 = 31,416[lm] x 5 = 157,080[lm]
    조명율이 0.5이므로 방 안에 도달하는 실제 광량 = 157,080[lm] x 0.5 = 78,540[lm]
    감광 보상률이 1.5이므로 인간의 눈이 인식하는 조도 = 78,540[lm] x 1.5 = 117,810[lx]

    따라서 방의 평균 조도는 약 117,810[lx]이 된다. 이 값은 주어진 보기 중에서 "27"이 아니므로, 정답은 "27"이 아니다.

29. 지상역률 0.6, 출력 480 [kW]인 부하에 병렬로 용량 400 [kVA]의 전력용 콘덴서를 설치하면 합성 역률은 어느 정도로 개선되는가?

  1. 0.75
  2. 0.86
  3. 0.89
  4. 0.94
(정답률: 11%)
  • 30 CBT 기출문제AI

    2023-04-17 14:38

    부하의 지상역률이 0.6이므로, 유효역률은 0.8이 됩니다. 부하와 병렬로 연결된 콘덴서는 용량 400 [kVA]이므로, 유효전력은 0 [kW]이 됩니다. 따라서, 합성 유효역률은 (480 + 0) / (480^2 + 0^2)^0.5 = 0.8 / 0.8 = 1이 됩니다. 합성 지상역률은 (0.6 x 480 + 0.6 x 0) / 480 = 0.6이 됩니다. 따라서, 합성 역률은 (1^2 + 0.6^2)^0.5 = 1.13이 됩니다. 하지만, 문제에서는 합성 역률이 개선된 값을 구하라고 했으므로, 이전의 합성 역률 1에서 개선된 정도를 구해야 합니다. 이전의 합성 역률은 1이므로, 개선된 정도는 1.13 - 1 = 0.13입니다. 따라서, 합성 역률은 1 + 0.13 = 1.13이 됩니다. 이 값을 유효역률로 나누면, 개선된 지상역률이 나옵니다. 즉, 1.13 / 0.8 = 0.89이므로, 정답은 "0.89"입니다.
