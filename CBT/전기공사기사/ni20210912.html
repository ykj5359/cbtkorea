5. 25℃의 물 10ℓ를 그릇에 넣고 2㎾의 전열기로 가열하여 물의 온도를 80℃로 올리는 데 20분이 소요되었다. 이 전열기의 효율(%)은 약 얼마인가?

  1. 59.5
  2. 68.8
  3. 84.9
  4. 95.9
(정답률: 41%)
  • 30 CBT 기출문제AI

    2023-04-17 14:10

    전열기의 효율은 출력(전열기가 전달한 열의 양)을 입력(전열기에 공급된 전기의 양)으로 나눈 값입니다.

    먼저, 전열기가 전달한 열의 양을 구해야 합니다. 이를 위해서는 열의 전달량을 나타내는 공식인 Q = mcΔT를 사용합니다. 여기서 m은 물의 질량, c는 물의 비열, ΔT는 온도 변화량입니다.

    m = 10kg (물의 밀도는 1kg/L이므로)
    c = 4.18J/g℃ (물의 비열)
    ΔT = 80℃ - 25℃ = 55℃

    Q = mcΔT = 10kg x 4.18J/g℃ x 55℃ = 2299kJ

    다음으로, 전열기에 공급된 전기의 양을 구해야 합니다. 이를 위해서는 전력과 시간을 곱하는 공식인 E = Pt를 사용합니다. 여기서 P는 전력, t는 시간입니다.

    P = 2kW = 2000W
    t = 20min = 1200s

    E = Pt = 2000W x 1200s = 2400000J

    마지막으로, 전열기의 효율을 구합니다.

    효율 = (전달된 열의 양 / 공급된 전기의 양) x 100%
    = (2299kJ / 2400000J) x 100%
    = 0.0958 x 100%
    = 9.58%

    따라서, 보기에서 정답이 "95.9"인 이유는 계산 결과를 반올림하여 나타낸 것입니다.
