  2. 4.33
  3. 6.66
  4. 8.66
(정답률: 77%)
  • 30 CBT 기출문제AI

    2023-04-17 14:36

    조명률은 전등이 발산하는 광속 중에서 실제로 방 안으로 들어오는 광속의 비율을 나타내는 값이다. 따라서 1000[lm]의 광속을 발산하는 전등이 10개 있으므로 총 광속은 10000[lm]이다. 이 중에서 실제로 방 안으로 들어오는 광속은 조명률이 0.5이므로 5000[lm]이다.

6. 지름이 3[cm] 길이 1.2[m]인 관형 광원의 직각 방향의 광도를 504[cd]라고 하면 이 광원 표면 위의 휘도[sb]는?

  1. 5.6
  2. 4.4
  3. 2.6
  4. 1.4
(정답률: 49%)
  • 30 CBT 기출문제AI

    2023-04-17 14:33

    휘도는 광원이 발하는 광속(광량)을 단위 면적으로 나눈 것이므로, 다음과 같이 계산할 수 있다.

    휘도 = 광속 / 면적

    광속은 광도와 면적을 이용하여 다음과 같이 계산할 수 있다.

    광속 = 광도 x 면적

    면적은 반지름을 이용하여 다음과 같이 계산할 수 있다.

    면적 = π x 반지름^2

    따라서, 휘도는 다음과 같이 계산할 수 있다.

    휘도 = (광도 x π x 반지름^2) / (π x 반지름^2)

    반지름이 1.5[cm]인 경우, 면적은 다음과 같다.

    면적 = π x (1.5[cm])^2 = 7.07[cm^2]

    광속은 다음과 같다.

    광속 = 504[cd] x 7.07[cm^2] = 3569.68[lm]

    따라서, 휘도는 다음과 같다.

    휘도 = 3569.68[lm] / 1.2[m]^2 = 2486.78[cd/m^2]

    이 값을 반올림하면 1.4가 된다.

64. 그림과 같은 4단자 회로의 4단자 정수 A, B, C, D에서 C의 값은?

  1. 1-jωC
  2. 1-ω2LC
  3. jωL(2-ω2LC)
  4. jωC
(정답률: 8%)
  • 30 CBT 기출문제AI

    2023-04-17 14:33

    주어진 4단자 회로는 복소수 전달함수를 이용하여 해결할 수 있습니다. 전달함수는 출력 전압과 입력 전압의 비율을 나타내며, 이 회로에서는 Vc/Va를 구하면 됩니다.

    회로를 분석해보면, Va는 직렬로 연결된 R과 L을 통과한 후 병렬로 연결된 C와 R을 거쳐 Vc로 전달됩니다. 따라서 전달함수는 다음과 같이 구할 수 있습니다.

    Vc/Va = (1/jωC) // (R + jωL + 1/jωC)

100. 과전류 차단기로 저압전로에 사용하는 퓨즈를 수평으로 붙인 경우의 동작 특성으로 옳은 것은? (단, 정격전류는 30A라고 한다.)

  1. 정격전류의 1.1배의 전류에 견딜 것
  2. 정격전류의 1.6배로 60분이상 견딜 것
  3. 정격전류의 1.8배로 120분이내에 용단될 것
  4. 정격전류의 2배의 전류로 10분안에 용단될 것
(정답률: 12%)

    2023-04-17 14:35

    정답은 "정격전류의 1.1배의 전류에 견딜 것"이다.

    퓨즈는 전류가 과부하되어 회로에 손상을 줄 때 차단하는 역할을 한다. 이때, 퓨즈의 동작 특성은 정격전류 이상의 전류가 흐를 때 얼마나 빠르게 차단되는지를 나타내는데, 이는 퓨즈의 용량에 따라 결정된다.

    따라서, 이 문제에서는 정격전류가 30A이므로, 퓨즈의 용량이 33A 이상이어야 정격전류의 1.1배의 전류에 견딜 수 있다. 이는 퓨즈의 용량이 작을수록 더 빠르게 차단되므로, 용량이 높을수록 더 많은 전류를 견딜 수 있다.
