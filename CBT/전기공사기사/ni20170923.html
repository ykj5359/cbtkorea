3. 경사각, 미끄럼 마찰계수 μ의 경사면위에서 중량 M(kg)의 물체를 경사면과 평행하게 속도ｖ(m/s)로 끌어올리는 데 필요한 힘 는?

  1. F=9.8M(sinθ+μscosθ)
  2. F=9.8M(cosθ+μssinθ)
  3. F=9.8Mv(sinθ+μscosθ)
  4. F=9.8Mv(cosθ+μssinθ)
(정답률: 59%)
  • 30 CBT 기출문제AI

    2023-04-17 14:17

    물체를 끌어올리는 힘은 중력과 마찰력의 합력이다. 중력은 물체의 무게인 Mg이고, 마찰력은 미끄럼 마찰계수와 수직방향의 힘인 N의 곱이다. 경사면 위에서의 수직방향의 힘은 Mgsinθ이고, 수평방향의 힘은 Mgcosθ이다. 따라서 마찰력은 μsN = μsMgcosθ이다. 이를 합하면 F = Mgsinθ + μsMgcosθ = 9.8M(sinθ + μscosθ)가 된다. 따라서 정답은 "F=9.8M(sinθ+μscosθ)"이다.

5. 반경 r, 휘도가 B 인 완전 확산성 구면 광원의 중심에서 h되는 거리의 점 P에서 이 광원 의 중심으로 향하는 조도의 크기는 얼마인가?

  1. πB
  2. πBr2
  3. πBr2h
  4. πBr2/h2
(정답률: 72%)
  • 30 CBT 기출문제AI

    2023-04-17 14:15

    조도는 광원에서 나오는 광량을 단위 면적으로 받는 양으로 정의된다. 따라서 광원에서 나오는 총 광량은 4πr2B 이다. 이 광량은 구면의 표면 전체에 고르게 분포되므로, P에서 광원으로 향하는 조도는 P에서의 거리에 반비례한다. 따라서 P에서의 조도는 다음과 같다.

    조도 = (4πr2B) / (4πh2 + r2)

    여기서 4πr2B는 광원에서 나오는 총 광량이고, 4πh2 + r2는 P에서의 거리에 비례하는 면적이다. 이 면적은 P에서의 거리가 작을수록 작아지므로, P에서의 조도는 P에서의 거리가 작을수록 커진다. 따라서 P에서의 조도는 P에서의 거리에 반비례한다는 것을 알 수 있다.

    따라서 조도 = (4πr2B) / (4πh2 + r2) = πBr2 / h2 이다. 따라서 정답은 "πBr2/h2" 이다.

  4. 3.2

    안전율은 설계하중을 지지물 기초가 견딜 수 있는 최대 하중으로 나눈 값이다. 따라서 안전율이 무관하려면 설계하중이 지지물 기초가 견딜 수 있는 최대 하중의 1/2 이하여야 한다.

    지지물 기초가 견딜 수 있는 최대 하중은 다음과 같이 계산한다.

    지지물 기초가 견딜 수 있는 최대 하중 = 지지물 기초의 단면적 x 허용 인장응력

    여기서 지지물 기초의 단면적은 땅에 묻는 깊이와 지지물 기초의 너비에 따라 결정된다. 허용 인장응력은 철근 콘크리트주의 재료 특성에 따라 결정된다.

    따라서 땅에 묻는 깊이를 x 라고 하면,

    지지물 기초의 단면적 = x x 너비

    허용 인장응력 = 재료 특성에 따라 결정

    지지물 기초가 견딜 수 있는 최대 하중 = x x 너비 x 허용 인장응력

    안전율이 무관하려면,

    설계하중 = 지지물 기초가 견딜 수 있는 최대 하중 / 2

    8.2kN = x x 너비 x 허용 인장응력 / 2

    따라서 x x 너비 = 16m x 1m = 16m²

    허용 인장응력은 문제에서 주어지지 않았으므로, x x 너비를 최소화하는 값을 찾아야 한다.

    x x 너비 = 16m²

    너비를 최소화하려면, x를 최대화해야 한다.

    x = √(16m² / 너비)
