    σ = (M * c) / I

    여기서,

    M = 5,000kgfㆍcm
    I = 5cm3 = 5,000mm3 (1cm3 = 1,000mm3)
    c = 수평재의 높이 / 2 = 10cm / 2 = 5cm

    따라서,

    σ = (5,000 * 5) / 5,000 = 5kgf/cm2

    σ = 5kgf/cm2 * 100cm/m * 1/9.81m/s2 = 50N/m2 = 50Pa

    σ = 50Pa / 9.81Pa/kgf/cm2 = 5.1kgf/cm2
