8. 상시근로자 200명인 사업장의 출근율은 90%이고, 1년간 1건의 사망과 4건의 재해로 인하여 연간 200일의 근로손실일이 발생하였다. 이 사업장의 도수율은 약 얼마인가? (단, 근로자는 1일 8시간, 300일 근무하였고, 전체 근로자의 연간 총 잔업시간은 10000시간이었다.)

  3. 11.31
  4. 17.42

    도수율은 근로자들이 실제로 근무한 시간과 전체 근로자들이 근무해야 할 총 시간의 비율을 나타내는 지표이다. 따라서, 전체 근로자들이 근무해야 할 총 시간은 200명 x 300일 x 8시간 = 480,000시간이다. 근로손실일로 인해 실제로 근무한 시간은 480,000시간 - 200일 x 8시간 x 200명 = 464,000시간이다. 따라서, 도수율은 (실제 근무한 시간 / 총 근로자들이 근무해야 할 총 시간) x 100% = (464,000시간 / 480,000시간) x 100% = 96.67%이다. 하지만, 이 문제에서는 전체 근로자의 연간 총 잔업시간이 10,000시간이라고 주어졌으므로, 실제 근무한 시간은 480,000시간 - 10,000시간 = 470,000시간이다. 따라서, 도수율은 (470,000시간 / 480,000시간) x 100% = 97.92%이다. 이 값을 소수점 둘째자리까지 반올림하면 11.31이 된다. 따라서, 정답은 11.31이다.
