    조도(lux) = 광량(flux) / 수신면적(m²)

  3. 0.950
  4. 0.955
(정답률: 48%)

    공극비는 다음과 같은 식으로 구할 수 있습니다.

    공극비 = (1 - (흙 입자의 비중 / 밀도)) x (포화도 / (1 - 포화도)) x (1 - 함수비)

    여기에 주어진 값들을 대입하면,

    공극비 = (1 - (2.7 / 2.65)) x (0.8 / (1 - 0.8)) x (1 - 0.28) = 0.945

    따라서 정답은 0.945입니다.
