  3. 1300 kgf

    안전대의 지름과 너비가 주어졌으므로, 안전대의 단면적을 계산할 수 있습니다. 안전대의 단면적은 다음과 같습니다.

    단면적 = π x (지름/2)^2 - (π x ((지름/2)-너비)^2)
    = π x (250/2)^2 - (π x ((250/2)-100)^2)
    = 49062.5 mm^2

    인장력 = 중량 / (2 x 중심거리)

    = 3000/1000
    = 3 kN

    인장강도 = 인장력 / 안전대의 단면적 x 10
    = 3 / 49062.5 x 10
    = 0.0000612 kN/mm^2
    = 61.2 kgf/mm^2

    따라서, 인장강도는 1500 kgf입니다.
