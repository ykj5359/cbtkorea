    최종 체적 = 100L
    초기 농도 = 50% = 0.5
    초기 체적 = 우리가 찾는 양 = x

    0.00⑤ × 100 = 0.5 × x
    0.⑤ = 0.5x
    x = 0.⑤ ÷ 0.5
    x = 0.1

98. 물깊이 5cm로 담수한 논 1ha에 10%유효성분을 가진 어떤 제초제를 제품량으로 3Kg/10a 처리시 1ha의 물속에 함유될 제초제의 농도는?

  1. 0.6ppm
  2. 0.9ppm
  3. 6ppm
  4. 9ppm
(정답률: 43%)
  • 30 CBT 기출문제AI

    2023-04-16 22:59

    1ha는 10,000m²이므로, 1m²당 5cm의 물이 담겨있으면 0.⑤m³의 물이 필요하다. 따라서 1ha에는 10,000 x 0.⑤ = 500m³의 물이 필요하다.

    제품량으로 3Kg/10a 처리하므로, 1ha에는 3Kg x (100/10) = 30Kg의 제초제가 필요하다.

    유효성분이 10%이므로, 30Kg 중 유효성분은 30Kg x 0.1 = 3Kg이다.

    따라서 1ha의 물속에 함유될 제초제의 농도는 3Kg/500m³ = 0.006Kg/m³ 이다.

    1Kg/m³ = 1000ppm 이므로, 0.006Kg/m³ = 6ppm 이다. 따라서 정답은 "6ppm"이다.
