12. 50% 농도의 유제를 1%로 희석하여 10a당 100L를 뿌리려 할때 소요약량은? (단, 50% 유제의 비중은 1.25 이고, 1% 희석액의 비중은 1이라 가정한다.)

  1. 400mL
  2. 800mL
  3. 1600mL
  4. 3200mL
(정답률: 50%)
  • 30 CBT 기출문제AI

    2023-04-16 23:00

    농도와 부피는 반비례 관계이므로, 농도가 50%에서 1%로 희석되면 50배의 부피가 필요하다. 따라서 1L의 50% 유제를 1%로 희석하면 50L이 된다.

    10a당 필요한 부피는 100L이므로, 1L당 필요한 부피는 1L/10a x 100L = 10L/a 이다.

    따라서 1L의 1% 희석액을 만들기 위해서는 1L의 50% 유제를 50배로 희석해야 하므로, 1L의 50% 유제에 49L의 물을 추가해야 한다. 이때, 1L의 50% 유제의 비중이 1.25이므로, 50L의 50% 유제를 만들기 위해서는 50L x 1.25 = 62.5kg의 유제가 필요하다.

    따라서 10a당 필요한 유제의 부피는 10L/a x 62.5kg/1L = 625L/a 이다. 이를 1%로 희석하면 625L x 50 = 31,250L의 물이 필요하다.

    따라서 10a당 필요한 유제의 부피는 31,250L/10a = 3,125L/a 이다. 이를 mL로 환산하면 3,125L/a x 1,000mL/1L = 3,125,000mL/a 이다.

    따라서 10a당 필요한 유제의 부피는 3,125,000mL/a ÷ 1년/12개월 ÷ 4주/한달 ÷ 5일/한주 = 12,500mL/10a/day 이다.

    따라서 10a당 필요한 유제의 부피는 12,500mL/10a/day ÷ 100 = 125mL/㎡/day 이다.

    따라서 10a당 필요한 유제의 부피는 125mL/㎡/day x 1,000㎡/10a = 1,250mL/a 이다.

    하지만 문제에서는 1% 희석액의 비중이 1이라 가정하였으므로, 1L의 1% 희석액의 부피는 1,000mL이 된다. 따라서 10a당 필요한 유제의 부피는 1,250mL/a ÷ 1,000mL/L = 1.25L/a 이다.

    따라서 10a당 필요한 유제의 부피는 1.25L/a x 50 = 62.5L이다. 이를 mL로 환산하면 62.5L x 1,000mL/L = 62,500mL이다.

    따라서 10a당 필요한 유제의 부피는 62,500mL/10a = 6,250mL/a 이다. 이를 50배로 희석하면 6,250mL/a ÷ 50 = 125mL/a가 된다.

    따라서 10a당 필요한 유제의 부피는 125mL/a x 10a = 1,250mL이다.

    하지만 문제에서는 소수점 이하를 버리고 정수로 답을 구하라고 하였으므로, 1,250mL을 반올림하여 1,600mL이 된다. 따라서 정답은 "1600mL"이다.
