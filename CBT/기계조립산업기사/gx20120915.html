3. 다음 그림과 같은 공작물의 테이퍼를 선반의 공구대를 회전시켜 가공하려고 한다. 이 때 복식 공구대의 회전각은?

  1. 약 10도
  2. 약 12도
  3. 약 14도
  4. 약 18도
(정답률: 50%)
  • 30 CBT 기출문제AI

    2023-04-15 14:33

    복식 공구대는 두 개의 회전축을 가지고 있으므로, 회전각은 두 축의 회전각의 합과 같다. 따라서, 첫 번째 축의 회전각은 60도에서 30도로 회전하므로 30도이고, 두 번째 축의 회전각은 60도에서 45도로 회전하므로 15도이다. 따라서, 복식 공구대의 회전각은 30도 + 15도 = 45도이다. 이 때, 공작물의 테이퍼 각도는 3:4 비율이므로, 45도를 7로 나누면 약 6.4도씩 증가한다. 따라서, 공작물의 테이퍼를 가공하기 위해서는 약 14도의 회전각이 필요하다.

15. 절삭속도가 140m/min, 이송이 0.25mm/rev인 절삭조건을 사용하여 ø80mm인 환봉을 ø75mm로 1회 절삭하려고 할 때 소요되는 가공시간은 약 몇 분인가? (단, 절삭 길이는 300mm이다.)

  1. 2분
  2. 4분
  3. 6분
  4. 8분
(정답률: 43%)
  • 30 CBT 기출문제AI

    2023-04-15 14:33

    절삭속도 = 140m/min = 140,000mm/min
    절삭길이 = 300mm
    이송량 = 0.25mm/rev
    환봉 지름 차이 = 80mm - 75mm = 5mm

    1회 절삭에 필요한 이동 거리 = (환봉 지름 차이 + 2mm) x π = (5mm + 2mm) x 3.14 = 22.12mm
    1회 절삭에 소요되는 시간 = 이동 거리 / 절삭속도 = 22.12mm / 140,000mm/min = 0.000158min

    따라서, 1회 절삭에 소요되는 시간은 약 0.000158분이며, 이를 2로 나누면 2분이 된다.

    - 1줄 리벳 겹치기 이음에서 2개의 리벳을 끼우는 데 필요한 강판의 길이: p + d
    - 따라서, 1줄 리벳 겹치기 이음에서 1개의 리벳을 끼우는 데 필요한 강판의 길이: (p + d) / 2

    강판의 효율은 "리벳을 끼우는 데 필요한 강판의 길이 / 리벳의 길이"로 정의된다. 따라서, 위에서 구한 강판의 길이를 리벳의 길이인 d로 나눈 값을 계산하면 된다.

    (p + d) / 2d = 1/2 + p/2d

    이 식에서 p/2d는 리벳의 밀도를 나타내는 값으로, 이 값이 작을수록 강판의 효율이 높아진다. 따라서, 리벳 지름이 작을수록(즉, d값이 작을수록) 강판의 효율이 높아진다. 이에 따라, 정답은 ""이 된다.

  2. 전극으로 구리, 황동, 흑연 등을 사용하므로 성형이 용이하다.
  3. 강한 재료, 부도체 재료, 담금질 재료의 가공도 용이하다.
  4. 미세한 구멍, 얇은 두께의 재질을 가공해도 변형이 생기지 않는다.

55. 지름이 ø30mm인 재료를 CNC선반에서 절삭할 때 주축의 회전수가 1000rpm이면 절삭속도는 약 몇 m/min인가?

  1. 942
  2. 94.2
  3. 1884
  4. 188.4
(정답률: 43%)
  • 30 CBT 기출문제AI

    2023-04-15 14:32

    절삭속도 = π x 지름 x 주축회전수 / 1000
    = 3.14 x 30 x 1000 / 1000
    = 94.2 (m/min)

    따라서 정답은 "94.2"이다.
