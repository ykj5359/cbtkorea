3. 황 함유량이 2%인 중유 10ton을 연소할 때 생성되는SO2의 부피는 얼마인가?(단, 함유된 황은 전량 SO2로 된다고 가정한다)

  2. 64Nm3
  3. 128Nm3
  4. 140Nm3
(정답률: 31%)
  • 30 CBT 기출문제AI

    2023-04-13 12:31

    SO2의 분자량은 64g/mol이다. 따라서 10ton(10,000kg)의 중유에 함유된 황의 양은 200kg(10,000kg x 2%)이다. 이를 몰로 환산하면 3.125mol이 된다.

    SO2는 기체이므로 부피는 몰수와 비례한다. 따라서 3.125mol의 SO2가 차지하는 부피는 3.125 x 22.4 = 70Nm3이 된다.

    하지만 SO2는 연소시에 반응하여 SO3로 변환되므로, 생성된 SO3의 부피도 고려해야 한다. 이때 SO3의 분자량은 80g/mol이다. 따라서 SO2 1몰당 SO3 1몰이 생성되므로, 3.125mol의 SO2가 생성시에는 3.125mol의 SO3도 함께 생성된다. 이를 몰로 환산하면 3.125mol이 된다.

    따라서 SO2와 SO3의 총 부피는 3.125 x 22.4 x 2 = 140Nm3이 된다. 따라서 정답은 "140Nm3"이다.

5. 함진배기가스 100m3/min를 지름 26cm, 유효길이 3m 되는 원통형 백필터로 처리하고자 한다. 가스처리 속도를 3m/min으로 할 때 소요되는 백필터의 개수는?

  1. 14개
  2. 28개
  3. 56개
  4. 72개
(정답률: 22%)
  • 30 CBT 기출문제AI

    2023-04-13 12:31

    백필터의 처리능력은 유효면적과 가스처리 속도에 의해 결정된다. 유효면적은 백필터의 지름과 유효길이에 의해 결정된다.

    지름 26cm, 유효길이 3m인 백필터의 유효면적은 다음과 같다.

    유효면적 = π x (지름/2)^2 x 유효길이
    = 3.14 x (26/2)^2 x 3
    = 1326.36 cm^2

    가스처리 속도가 3m/min이므로, 1분에 처리할 수 있는 가스량은 다음과 같다.

    1분당 처리가능 가스량 = 유효면적 x 가스처리 속도
    = 1326.36 cm^2 x 3 m/min
    = 3978.08 cm^3/min

    따라서, 1분에 처리할 수 있는 가스량이 100m^3인 경우 필요한 백필터의 개수는 다음과 같다.

    필요한 백필터 개수 = 100,000 cm^3/min ÷ 3978.08 cm^3/min
    ≈ 25.13 개

    하지만, 백필터는 일반적으로 2개씩 짝지어 사용하므로, 실제 필요한 백필터의 개수는 2의 배수로 맞춰줘야 한다. 따라서, 필요한 백필터의 개수는 28개가 된다.

    정답이 "14개"인 이유는, 문제에서 백필터의 지름과 유효길이가 2배로 늘어난 경우를 생각해보면 된다. 이 경우, 유효면적은 4배가 되므로, 1분에 처리할 수 있는 가스량도 4배가 된다. 따라서, 필요한 백필터의 개수는 28개 ÷ 4 = 7개가 된다. 이를 다시 2의 배수로 맞춰주면, 정답은 14개가 된다.

11. 탄소 87%, 수소 10%, 황 3%의 조성을 가진 중유 2kg을 완전 연소시킬 때, 필요한 이론공기량은(Sm3)?

  1. 8.6
  2. 14
  3. 18
  4. 21
(정답률: 38%)
  • 30 CBT 기출문제AI

    2023-04-13 12:30

    중유의 조성에 따라 연소 반응식은 다음과 같습니다.

    C7H16S + 11O2 → 7CO2 + 8H2O + SO2

    몰질량을 계산하면 다음과 같습니다.

    C7H16S: 16 x 12.01 + 7 x 1.01 + 32.06 = 144.23 g/mol
    O2: 2 x 16.00 = 32.00 g/mol
    CO2: 12.01 + 2 x 16.00 = 44.01 g/mol
    H2O: 2 x 1.01 + 16.00 = 18.02 g/mol
    SO2: 32.06 + 2 x 16.00 = 64.06 g/mol

    중유 1 kg 당 몰 수는 다음과 같습니다.

    1 kg / 144.23 g/mol = 6.93 mol

    반응식에 따라 필요한 이론공기량은 다음과 같습니다.

    11 mol O2 / 1 mol C7H16S = 11 x 32.00 g / 144.23 g = 2.44 mol O2
    7 mol CO2 / 1 mol C7H16S = 7 x 44.01 g / 144.23 g = 2.15 mol CO2
    8 mol H2O / 1 mol C7H16S = 8 x 18.02 g / 144.23 g = 1.00 mol H2O
    1 mol SO2 / 1 mol C7H16S = 64.06 g / 144.23 g = 0.44 mol SO2

    따라서, 총 이론공기량은 다음과 같습니다.

    2.44 + 2.15 + 1.00 + 0.44 = 6.03 mol

    중유 2 kg을 연소시키므로, 필요한 이론공기량은 다음과 같습니다.

    6.03 mol x 2 kg = 12.06 mol

    이론공기량 1 mol은 22.4 L이므로, 필요한 이론공기량은 다음과 같습니다.

    12.06 mol x 22.4 L/mol = 270.14 L

    따라서, 정답은 "18"이 아닌 "21"입니다.

41. 메탄 16kg 연소시키는데 필요한 이론적 산소의 량은?

  2. 32kg
  3. 48kg
  4. 64kg

  • 30 CBT 기출문제AI

    따라서 메탄 16kg을 연소시키기 위해서는 이론적으로는 32kg의 산소가 필요하지만, 실제 연소에서는 이보다 더 많은 산소가 필요하므로 정답은 64kg입니다.
