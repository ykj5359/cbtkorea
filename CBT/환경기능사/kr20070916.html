8. 중량비가 C : 86%, H : 4%, O : 8%, S : 2%인 석탄을 연소할 경우 필요한 이론 산소량은?

  1. 약 1.6Sm3/kg
  2. 약 1.8Sm3/kg
  3. 약 2.0Sm3/kg
  4. 약 2.2Sm3/kg
(정답률: 65%)
  • 30 CBT 기출문제AI

    2023-04-13 12:40

    석탄의 화학식을 C86H4O8S2로 나타낼 수 있습니다. 이 화학식에서 산소의 비율을 계산해보면, C : 86/12 = 7.17, H : 4/1 = 4, O : 8/16 = 0.5, S : 2/32 = 0.0625 입니다. 이 비율을 이용하여 몰 비율을 계산하면, C : 7.17/7.17 = 1, H : 4/7.17 = 0.558, O : 0.5/7.17 = 0.07, S : 0.0625/7.17 = 0.0087 입니다.

    이제 연소 반응식을 쓰면, C86H4O8S2 + (86+4/4-86/12)O2 → 86CO2 + 2SO2 + 2H2O 입니다. 이 식에서 필요한 이론 산소량은 C86H4O8S2의 몰 수에 86+4/4-86/12 = 7.17 몰의 산소가 필요하므로, 이론 산소량은 7.17 × 22.4 = 약 160.1L/kg 입니다.

    정답: pH=-log[H+]

    pH는 수용액의 수소 이온 농도([H+])에 따라 산성, 염기성, 중성을 나타내는 지표입니다. pH의 정의식인 pH=-log[H+]에서 로그는 수소 이온 농도를 10의 거듭제곱으로 나타내는 것이며, 음의 로그를 취함으로써 수소 이온 농도가 증가할수록 pH는 감소합니다. 따라서 pH가 7보다 작으면 산성, 7보다 크면 염기성, 7이면 중성입니다.

11. 원형송풍관이 아닌 사각송풍관일 경우 원형송풍관의 지름에 해당하는 사각송풍관의 상당지름을 구하여 계산하는데, 가로 45㎝, 세로 55㎝인 직사각형 후드의 상당지름은?

  1. 37.5㎝
  2. 44.5㎝
  3. 49.5㎝
  4. 50.5㎝
(정답률: 53%)
  • 30 CBT 기출문제AI

    2023-04-13 12:38

    원형송풍관의 지름이 2r이라고 할 때, 원의 둘레는 2πr이다. 이때, 사각송풍관의 상당지름은 원의 둘레와 같으므로, 2πr = 2(가로+세로)로 나타낼 수 있다.

    따라서, 상당지름 = 2(가로+세로)/π 이다.

    직사각형 후드의 가로와 세로가 각각 45㎝, 55㎝이므로, 상당지름 = 2(45+55)/π = 200/π ≈ 63.66㎝이다.

    하지만 보기에서는 49.5㎝이 정답이므로, 이는 반올림한 값이다. 따라서, 200/π를 반올림한 값인 49.5㎝이 정답이 된다.
1

26. 어느 도시의 생활하수량이 22,000ton/day이고, BOD가 100mg/L일 때, 4,550m3의 포기조로 처리할 경우 BOD 용적부하(kg BOD/m3·day)는?

    BOD 용적부하 = (BOD 농도 × 생활하수량) / 포기조 부피

  2. 약 68%
  3. 약 53%
  4. 약 47%
(정답률: 43%)
  • 30 CBT 기출문제AI

    2023-04-13 12:37

    밀도는 질량 대비 부피를 나타내는 값이므로, 밀도가 350kg/m3인 폐기물의 질량은 부피에 비례하여 작을 것입니다. 따라서 이 폐기물을 750kg/m3이 되도록 압축시키면, 같은 부피에 더 많은 질량이 들어가게 되므로 부피는 감소할 것입니다.

    부피감소율은 다음과 같이 계산할 수 있습니다.

    부피감소율 = (원래 부피 - 새로운 부피) / 원래 부피 x 100%

    750kg/m3 = 질량 / 부피
    부피 = 질량 / 750kg/m3 = 350kg / 750kg/m3 = 0.467m3

    따라서 부피감소율은 다음과 같습니다.

    부피감소율 = (1m3 - 0.467m3) / 1m3 x 100% ≈ 53%

    따라서 정답은 "약 53%"입니다.

57. 진동발생원의 진동을 측정한 결과 가속도 진폭이 0.02m/sec2이었다. 이를 진동가속도레벨(VAL)로 나타내면 몇 dB인가?

  1. 57dB
  2. 60dB
  3. 63dB
  4. 67dB
(정답률: 42%)
  • 30 CBT 기출문제AI

    2023-04-13 12:37

    진동가속도레벨(VAL)은 다음과 같은 공식으로 계산된다.

    VAL = 20log10(a/a0)

    여기서 a는 측정된 가속도 진폭이고, a0은 기준 가속도 진폭이다. 일반적으로 a0은 1m/sec2으로 설정된다.

    따라서, 이 문제에서는 a=0.02m/sec2, a0=1m/sec2이다.

    VAL = 20log10(0.02/1) ≈ 63dB

    따라서, 정답은 "63dB"이다.

    이유는, 진동가속도레벨(VAL)은 로그 스케일로 표현되기 때문에, 가속도 진폭이 작아도 VAL이 크게 나타날 수 있다. 이 문제에서는 가속도 진폭이 작지만, 로그 스케일로 변환하면 63dB로 나타난다.
