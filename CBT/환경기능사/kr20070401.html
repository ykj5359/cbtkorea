13. 효율 90%인 전기집진기를 효율 99%가 되도록 개조하고자 한다. 개조 전보다 집진극의 면적을 몇 배로 늘려야 하는 가? (단, Deutsch-Anderson식 적용)

  1. 2배
  2. 3배
  3. 4배
  4. 9배
(정답률: 39%)
  • 30 CBT 기출문제AI

    2023-04-13 12:39

    Deutsch-Anderson식은 효율을 나타내는 식으로, 개조 전의 효율을 η1, 개조 후의 효율을 η2, 집진극 면적의 배율을 n이라고 할 때 다음과 같이 나타낼 수 있다.

    η2 = η1 x (1 + (n-1)/η1)

    여기서 η1 = 0.9, η2 = 0.99으로 대입하면,

    0.99 = 0.9 x (1 + (n-1)/0.9)

    식을 정리하면,

    n-1 = 0.1 x 0.9 / 0.09

    n-1 = 1

    n = 2

    따라서, 집진극 면적을 2배로 늘려야 개조 전보다 효율이 99%가 되도록 개조할 수 있다.

    탄소(C)와 산소(O)의 화학식은 CO2이며, 이 화학식에서 탄소 1몰과 산소 2몰이 결합합니다. 따라서 탄소 1몰을 연소시키기 위해서는 산소 2몰이 필요합니다.

    탄소의 몰량은 12g/mol이며, 1kg은 1000g이므로 탄소 1kg은 몰량으로 환산하면 1000g/12g/mol = 83.33mol입니다.

    산소의 몰량은 16g/mol이며, 탄소 1kg을 연소시키기 위해서는 산소 2몰이 필요하므로 2 x 16g/mol = 32g의 산소가 필요합니다.

    따라서 정답은 0.032kg x 83.33mol = 2.67kg이며, 반올림하여 2.7kg입니다.
