80. 다음 중 입방정계의 축길이와 사이각으로 옳은 것은?

  1. a = b ≠ c, α = β = γ = 90°
  2. a ≠ b ≠ c, α = β = γ = 90°
  3. a = b = c, α = β = γ = 90°
  4. a = b = c, α = β = 90°, γ = 120°
(정답률: 알수없음)
