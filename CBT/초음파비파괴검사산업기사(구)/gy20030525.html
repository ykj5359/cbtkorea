5. 그림은 경사각탐촉자의 단면도이다. 강재 중에 횡파만 전파시키기 위해서는 아크릴 쐐기의 각도를 어느 범위로 조정하면 되는가? (단, 아크릴수지 내의 종파속도는 2730m/s, 강재 중의 종파속도는 5900m/s, 횡파속도는 3230m/s)

  1. 14° ≤ α ≤ 36°
  2. 28° ≤ α ≤ 57°
  3. 35° ≤ α ≤ 80°
  4. 24° ≤ α ≤46°
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-18 21:34

    아크릴 쐐기에서 발생한 종파는 강재 내부로 전파될 때 횡파로 변환되어야 한다. 이를 위해서는 아크릴 쐐기에서 발생한 종파의 진폭이 강재 내부에서 횡파로 변환될 때 최대가 되어야 한다. 이는 스넬의 법칙에 의해 아크릴 쐐기와 강재 경계면에서의 입사각과 굴절각이 일정한 각도를 이루어야 한다는 것을 의미한다. 이 각도를 구하기 위해 아크릴수지 내의 종파속도와 강재 중의 종파속도, 그리고 횡파속도를 이용하여 스넬의 법칙을 적용하면 다음과 같다.

    sin(입사각) / sin(굴절각) = 종파속도(강재) / 종파속도(아크릴수지)

    sin(90-α) / sin(θ) = 5900 / 2730

    sin(θ) = 2730 / 5900 * cos(α)

    sin(θ) = 0.4627 * cos(α)

    θ = sin^-1(0.4627 * cos(α))

    횡파속도는 다음과 같이 구할 수 있다.

    횡파속도 = sqrt(종파속도^2 - 세로파속도^2)

    횡파속도(강재) = sqrt(5900^2 - 3230^2) = 4680.5m/s

    횡파속도(아크릴수지) = sqrt(2730^2 - 0^2) = 2730m/s

    따라서, 아크릴 쐐기의 각도 α가 28° ≤ α ≤ 57° 일 때, 아크릴 쐐기에서 발생한 종파가 강재 내부로 전파될 때 최대의 횡파 진폭을 가지게 된다. 이 범위를 벗어나면 횡파 진폭이 감소하여 전달 효율이 떨어지게 된다.
