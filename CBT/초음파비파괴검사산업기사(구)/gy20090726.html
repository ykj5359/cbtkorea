(정답률: 알수없음)

    파장 = 속도 / 주파수 이므로, 주파수가 같을 때 파장은 속도에 반비례한다. 따라서, 아크릴에서의 파장은 강재에서의 파장보다 길어야 한다.

    강재에서의 파장 = 5900 / 4 = 1475m
    아크릴에서의 파장 = 2730 / x

    강재와 아크릴에서의 파장이 같으려면,

    1475 = 2730 / x
    x = 2730 / 1475
    x = 1.85

    따라서, 약 1.8MHz의 주파수를 아크릴에 사용해야 한다. 정답은 "1.8"이다.

3. 그림과 같이 수직탐촉자를 합성수지 쐐기를 이용하여 45° 경사각 탐촉자를 만들어 강 용접부를 탐상하고자 한다. 그림에서 a 를 약 몇 도로 가공하여야 하는가? (단, 각 매질에서의 음파속도는 합성수지 : 종파 2600m/s, 횡파 1200m/s 강 : 종파 5900m/s, 횡파 3200m/s 이다.)

  1. 8.3°
  2. 15.4°
  3. 18.2°
  4. 35.1°
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-18 21:45

    수직탐촉자를 합성수지 쐐기를 이용하여 45° 경사각 탐촉자를 만들기 위해서는 합성수지와 강 사이의 경계면이 45° 각도를 이루도록 가공해야 한다. 이 때, 경계면의 각도는 다음과 같이 구할 수 있다.

    먼저, 합성수지와 강의 경계면에서 반사파가 발생할 때, 반사파는 합성수지와 강에서 각각 진행속도가 다르므로 경계면에서 굴절(refraction)이 일어난다. 이 때, 굴절각은 다음과 같이 스넬의 법칙을 이용하여 구할 수 있다.

    sin(입사각) / sin(굴절각) = 진행속도(합성수지) / 진행속도(강)

    여기서, 입사각은 45°이고, 진행속도는 문제에서 주어졌으므로, 굴절각을 구할 수 있다. 즉,

    sin(굴절각) = 진행속도(강) / 진행속도(합성수지) * sin(입사각)
    = 5900 / 2600 * sin(45°)
    = 1.77

    굴절각은 sin(굴절각) = 1 / n (n은 굴절률) 이므로, 합성수지와 강의 굴절률을 이용하여 굴절각을 구할 수 있다. 합성수지와 강의 굴절률은 각각 다음과 같다.

    합성수지의 굴절률 = sin(45°) / sin(입사각) = 1 / sin(45°) ≈ 1.414
    강의 굴절률 = sin(a) / sin(45°) (a는 가공각도)

    따라서, 굴절각은 다음과 같다.

    sin(a) / sin(45°) = 1.77
    sin(a) = 1.77 * sin(45°)
    a = arcsin(1.77 * sin(45°))
    ≈ 35.1°

    따라서, 가공각도 a는 약 35.1°이다.
