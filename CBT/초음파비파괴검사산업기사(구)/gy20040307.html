2. 강재에 대한 굴절각이 60도인 경사각 탐촉자로 회주철을 검사할 때의 굴절각은 몇 도인가? (단, 강재에서의 횡파 속도는 3,200m/sec, 탐촉자 쐐기 재질의 종파속도는 2,800m/sec이고, 회주철에서의 횡파속도는 2,400m/sec이다.)

  4. 약 70도

    강재에서의 횡파 속도는 3,200m/sec이고, 탐촉자 쐐기 재질의 종파속도는 2,800m/sec이므로, 탐촉자가 강재에 닿았을 때 경사각 60도로 굴절되어 회주철을 향해 진행하면서 굴절각이 변화한다. 이때, 굴절각은 다음과 같은 식으로 계산할 수 있다.

    sin(입사각) / sin(굴절각) = 종파속도(강재) / 종파속도(회주철)

    여기서, 입사각은 90도 - 경사각 = 30도이다. 따라서,

    sin(30도) / sin(굴절각) = 3,200 / 2,400

    sin(굴절각) = sin(30도) x (2,400 / 3,200) = 0.5 x 0.75 = 0.375

    굴절각은 sin의 역함수인 arcsin을 이용하여 구할 수 있다.

    굴절각 = arcsin(0.375) = 약 22.5도

    하지만, 이 값은 회주철에서의 굴절각이므로, 다시 강재로 돌아와서 굴절되는 과정에서 굴절각이 변화한다. 이때, 회주철에서의 굴절각이 22.5도이므로, 강재에서의 입사각은 다음과 같다.

    sin(입사각) / sin(60도) = 2,800 / 2,400

    sin(입사각) = sin(60도) x (2,400 / 2,800) = 0.866 x 0.857 = 0.743

    입사각 = arcsin(0.743) = 약 49도

    따라서, 강재에서의 굴절각은 60도에서 49도로 감소하므로, 약 40도가 된다.

10. 초음파의 파장이 1mm이고 진동자의 직경이 10mm인 탐촉자로 강재를 초음파탐상시 발생하는 근거리음장은 몇 mm인가？(단, 강재내에서 초음파의 속도는 5000m/sec로 가정)

    근거리음장은 다음과 같이 계산할 수 있다.

    근거리음장 = 진폭 / (2π × 파장)

    여기서 진폭은 진동자의 직경인 10mm이다.

    따라서,

    근거리음장 = 10mm / (2π × 1mm) ≈ 1.59mm

    하지만, 강재내에서 초음파의 속도가 5000m/sec이므로, 초음파의 파장은 다음과 같이 계산할 수 있다.

    파장 = 속도 / 주파수

    여기서 주파수는 초음파의 진동수이다. 초음파의 진동수는 초당 진동수이므로, 초음파의 주파수는 다음과 같이 계산할 수 있다.

    주파수 = 속도 / 파장

    따라서,

    주파수 = 5000m/sec / 0.001m = 5MHz

    따라서, 초음파의 파장은 다음과 같이 계산할 수 있다.

    파장 = 5000m/sec / 5MHz = 1mm

    따라서, 근거리음장은 다음과 같이 계산할 수 있다.

    근거리음장 = 10mm / (2π × 1mm) ≈ 1.59mm

    따라서, 정답은 "25"가 아니라 "1.59"이다.
