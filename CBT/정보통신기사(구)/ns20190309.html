10. 다음 그림과 같은 회로에서 결합계수가 0.5이고, 발진주파수가 200[kHz]일 경우 C의 값은 얼마인가? (단, π=3.14 이고, L1=L2=1[mH]로 기징한다.)

  1. 211.3[uF]
  2. 211.3[pF]
  3. 422.6[uF]
  4. 422.6[pF]
(정답률: 68%)
  • 30 CBT 기출문제AI

    2023-04-19 08:26

    먼저, 결합계수 K는 다음과 같이 계산된다.

    K = M / √(L1L2)

    여기서 M은 상호 인덕턴스이며, 문제에서 L1 = L2 = 1[mH]로 주어졌으므로 M = k√(L1L2) = k[mH]이다. 따라서, K = k / √2 = 0.5이므로 k = 0.5√2 = 0.707이다.

    다음으로, 발진주파수 f0는 다음과 같이 계산된다.

    f0 = 1 / (2π√(L1C))

    여기서 L1 = 1[mH], f0 = 200[kHz]로 주어졌으므로, C = 1 / (4π2f02L1) = 211.3[pF]이다.

    따라서, 정답은 "211.3[pF]"이다.
