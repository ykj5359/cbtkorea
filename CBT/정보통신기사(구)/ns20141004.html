9. 다음 그림과 같은 회로에서 결합계수가 0.5이고, 발진주파수가 200[kHz]일 경우 C의 값은 얼마인가? (단, π=3.14이고, L1=L2=1[mH]로 가정한다.)

  1. 211.3[μF]
  2. 211.3[pF]
  3. 422.6[μF]
  4. 422.6[pF]
(정답률: 64%)
  • 30 CBT 기출문제AI

    2023-04-19 08:33

    먼저, 결합계수 K는 다음과 같이 계산된다.

    K = M / √(L1L2)

    여기서 M은 상호 인덕턴스이며, 문제에서는 L1 = L2 = 1[mH] 이므로 M = kL1L2 = 1[mH] × 0.5 = 0.5[mH] 이다.

    따라서, K = 0.5[mH] / √(1[mH] × 1[mH]) = 0.5 이다.

    다음으로, 발진주파수 f0는 다음과 같이 계산된다.

    f0 = 1 / (2π√(L1C))

    여기서 C는 우리가 구해야 할 값이다.

    문제에서 f0 = 200[kHz] 이므로, 이를 대입하여 C를 구하면 다음과 같다.

    200[kHz] = 1 / (2π√(1[mH] × C))

    2π√(1[mH] × C) = 1 / 200[kHz]

    √(1[mH] × C) = 1 / (2π × 200[kHz])

    1[mH] × C = (1 / (2π × 200[kHz]))^2

    C = (1 / (2π × 200[kHz]))^2 / 1[mH]

    C = 211.3[pF]

    따라서, 정답은 "211.3[pF]" 이다.

  • 30 CBT 기출문제AI

    2023-04-19 08:38

    정답: "A+(BㆍC) = (A+B)(A+C)"이 부울대수의 정리가 성립되지 않는 것이다.

    이유: 부울대수의 정리 중 "AㆍB = A(A+B)"은 분배법칙을 의미한다. 즉, A를 B와 곱한 것과 A를 A와 B의 합한 것과 곱한 것이 같다는 것이다. 이는 수학에서의 곱셈과 덧셈의 분배법칙과 유사하다.

    예를 들어, A=1, B=0이라고 하면 "AㆍB = A(A+B)"는 다음과 같이 표현할 수 있다.

    1ㆍ0 = 1(1+0)

    0 = 1

    하지만 이는 부울대수에서는 성립하지 않는다. 부울대수에서는 0과 1이라는 값만 존재하며, 덧셈은 OR 연산, 곱셈은 AND 연산으로 표현된다. 따라서 "A+(BㆍC) = (A+B)(A+C)"와 같은 식은 부울대수에서는 성립하지 않는다.
