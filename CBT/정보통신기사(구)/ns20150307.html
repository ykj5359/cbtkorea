4. 입력 저항이 20[kΩ]인 증폭기에 직렬 전류 궤환회로를 적용할 경우 입력 저항값은 얼마가 되는가? (단, β=9이다.)(오류 신고가 접수된 문제입니다. 반드시 정답과 해설을 확인하시기 바랍니다.)

  1. 0.1[MΩ]
  2. 0.2[MΩ]
  3. 0.3[MΩ]
  4. 0.4[MΩ]
(정답률: 64%)
  • 30 CBT 기출문제AI

    2023-04-19 08:33

    직렬 전류 궤환회로를 적용하면 베이스 전류가 증폭기 입력단으로 흐르게 되어 입력 저항이 감소한다. 이 때 입력 저항은 다음과 같이 계산된다.

    $$R_{in}=frac{V_{BE}}{I_B}=frac{0.7V}{frac{I_C}{beta}}=frac{0.7V}{frac{I_E}{beta+1}}$$

    여기서 $I_E=I_C+I_B$ 이므로,

    $$R_{in}=frac{0.7V}{frac{I_C+I_B}{beta+1}}=frac{0.7V}{frac{I_C}{beta+1}+frac{I_B}{beta+1}}$$

    입력 저항이 20[kΩ]인 증폭기에서 $I_C=frac{V_{CC}-V_{CE}}{R_C}=0.5[mA]$ 이므로,

    $$R_{in}=frac{0.7V}{frac{0.5mA}{9+1}+frac{I_B}{9+1}}$$

    $I_B$는 전류 궤환회로에서 $V_{BE}=0.7V$ 일 때,

    $$I_B=frac{V_{CC}-V_{BE}}{R}=4.65[mu A]$$

    이므로,

    $$R_{in}=frac{0.7V}{frac{0.5mA}{10}+frac{4.65mu A}{10}}=0.2[MOmega]$$

    따라서 정답은 "0.2[MΩ]" 이다.

  1. ⓐ → ⓓ → ⓑ → ⓒ → ⓕ → ⓔ
  2. ⓐ → ⓔ → ⓓ → ⓑ → ⓒ → ⓕ
  3. ⓔ → ⓐ → ⓓ → ⓑ → ⓒ → ⓕ
  4. ⓔ → ⓐ → ⓑ → ⓓ → ⓒ → ⓕ
(정답률: 77%)
  • 30 CBT 기출문제AI

    2023-04-19 08:32

    정답은 "ⓐ → ⓔ → ⓓ → ⓑ → ⓒ → ⓕ" 이다.

    인터럽트가 발생하면 우선 CPU는 현재 수행중인 작업을 중단하고 인터럽트 서비스 루틴(ISR)을 실행한다. 이때 ISR은 인터럽트 우선순위에 따라 선택되어 실행된다. ISR이 실행되면서 인터럽트 요청을 처리하고, 필요한 경우 인터럽트 벡터 테이블을 참조하여 해당 인터럽트에 대한 처리를 수행한다. 처리가 완료되면 CPU는 이전에 수행하던 작업을 계속해서 수행한다. 따라서 올바른 처리과정의 순서는 "ⓐ → ⓔ → ⓓ → ⓑ → ⓒ → ⓕ" 이다.
