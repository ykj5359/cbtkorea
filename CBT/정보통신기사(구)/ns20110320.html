62. 전송선로의 무왜조건이 되기 위한 1차 정수 R,C,L,G의 관계식은?

  1. RL = 2CG
  2. RC = LG
  3. RG = LC
  4. RG = 2L
(정답률: 64%)
  • 30 CBT 기출문제AI

    2023-04-19 08:11

    전송선로에서 R은 저항, C는 캐패시턴스, L은 인덕턴스, G는 전도도를 나타내는 값입니다. 이 값들은 전송선로의 특성 임피던스를 결정하는데 사용됩니다.

    전송선로에서 전압과 전류는 다음과 같은 관계식을 가집니다.

    V = IZ

    여기서 Z는 전송선로의 특성 임피던스를 나타내며, 다음과 같이 정의됩니다.

    Z = R + jωL + 1/(jωC) + G

    여기서 j는 허수단위, ω는 각주파수를 나타냅니다.

    전송선로에서 무왜조건이란, 전송선로의 입력단과 출력단에서 반사파가 발생하지 않는 상태를 말합니다. 이를 위해서는 전송선로의 특성 임피던스가 입력 임피던스와 출력 임피던스와 일치해야 합니다.

    즉, Zin = Zout = Z

    이를 만족하기 위해서는 다음과 같은 관계식이 성립해야 합니다.

    RL = 2CG

    RC = LG

    RG = LC

    RG = 2L

    여기서 RL은 전송선로의 적정 임피던스, RC는 전송선로의 임피던스 매칭을 위한 적정 용량, LG는 전송선로의 손실, RG는 전송선로의 임피던스 매칭을 위한 적정 저항을 나타냅니다.

    따라서 RC = LG가 무왜조건이 되는 이유는, 전송선로의 입력 임피던스와 출력 임피던스가 일치하기 위해서는 전송선로의 임피던스 매칭을 위한 적정 용량과 전송선로의 손실이 일치해야 하기 때문입니다. 이를 수식으로 나타내면 다음과 같습니다.

    1/(jωC) + G = jωL

    jωC = 1/(jωL - G)

    ω^2C^2 = 1/(ω^2L^2 - G^2)

    RC = 1/ωC

    LG = G/ω^2L^2 - G^2

    따라서 RC = LG가 성립하면, 전송선로의 입력 임피던스와 출력 임피던스가 일치하게 됩니다.

  2. 결과를 정규화시킨다.

    정답은 "가수의 위치를 조정한다." 이다.

    Floating Point 표현에서는 가수와 지수를 이용하여 수를 표현한다. 따라서 곱셈 알고리즘에서는 먼저 가수를 곱하고, 지수를 더하여 결과를 얻는다. 이후에는 결과를 정규화시켜서 지수와 가수를 적절하게 조정한다. 이때 가수의 위치를 조정하는 것은 아니고, 가수의 값을 조정하여 정규화시키는 것이다.

    0(zero) 인지의 여부를 조사하는 것은 곱셈 알고리즘 이후에 수의 부호를 결정하기 위한 과정이다.
