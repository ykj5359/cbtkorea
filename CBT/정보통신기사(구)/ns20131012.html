14. 십진수 10.375를 2진수로 변환하면?

  4. 1011.110(2)

    정수부분인 10을 2진수로 변환하면 1010(2)가 됩니다.

    0.375 x 2 = 0.75 → 0
    0.75 x 2 = 1.5 → 1
    0.5 x 2 = 1.0 → 1
