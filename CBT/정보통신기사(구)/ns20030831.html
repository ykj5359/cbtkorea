6. 다음 부울대수의 정리 중 틀린 것은?

  1. x (x + y ) = y
  3. x + yz = (x+y )(x+z )
  4. x + xy = x
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-19 08:22

    정답: "x + yz = (x+y )(x+z )"가 틀린 부울대수 정리입니다.

    이유: "x + yz = (x+y )(x+z )"는 분배법칙을 이용한 부울대수 정리입니다. 하지만 이 정리는 일반적으로 성립하지 않습니다. 예를 들어, x=0, y=1, z=1일 때, 왼쪽 식은 1이고 오른쪽 식은 0이므로 같지 않습니다.

    "x (x + y ) = y"는 x가 참일 때와 거짓일 때를 각각 나눠서 증명할 수 있습니다.

    - x가 참일 때: x(x+y) = x*1 = x 이므로, x(x+y) = y는 x=y인 경우에만 성립합니다.
    - x가 거짓일 때: x(x+y) = 0*1 = 0 이므로, 어떤 y값이 와도 항상 성립합니다.

    따라서, "x (x + y ) = y"는 x=y일 때 성립하는 부울대수 정리입니다.

13. Ic = 12[㎃]인때 VCE = 6[V]이고, β = 100, VBE = 0.7[V]라고 하고 역포화 전류 (reverse saturation current)를 무시하는 경우 Rc를 구하시오.

  1. Rc = 1.5[㏀]
  2. Rc = 1[㏀]
  3. Rc = 500[Ω]
  4. Rc = 100[Ω]
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-19 08:22

    먼저, 다음과 같은 회로를 고려할 수 있습니다.



    여기서, 전류 증폭을 위해서는 베이스 전류 Ib가 필요합니다. 이는 다음과 같이 구할 수 있습니다.

    Ib = Ic / β = 12[㎃] / 100 = 0.12[㎃]

    따라서, 베이스-에미터 저항 RBE를 구할 수 있습니다.
