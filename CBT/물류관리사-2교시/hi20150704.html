5. A회사 제품의 연간 총 수요는 20,000개이고, 단위당 구매비용은 10원이다. 주문비용(Order cost)은 50원/회이고, 단위당 연간 재고유지비용(Inventory holding cost)은 구매비용의 20%이다. 경제적주문량(EOQ: Economic Order Quantity) 모델에서 연간 재고유지비용과 연간 주문비용의 합은?

  1. 1,000원
  2. 1,500원
  3. 2,000원
  4. 2,500원
  5. 3,000원
(정답률: 53%)
  • 30 CBT 기출문제AI

    2023-04-15 19:37

    EOQ 모델에서 연간 주문비용과 연간 재고유지비용의 합은 다음과 같이 계산할 수 있다.

    - 연간 주문비용 = (연간 총 수요 / 경제적주문량) x 주문비용
    - 연간 재고유지비용 = (경제적주문량 / 2) x 단위당 구매비용 x 재고유지비율

    여기서 경제적주문량(EOQ)은 다음과 같이 계산할 수 있다.

    - EOQ = √((2 x 연간 총 수요 x 주문비용) / (단위당 구매비용 x 재고유지비율))

    따라서, 주어진 조건에 대입하여 계산하면 다음과 같다.

    - EOQ = √((2 x 20,000 x 50) / (10 x 0.2)) = 1,000
    - 연간 주문비용 = (20,000 / 1,000) x 50 = 1,000
    - 연간 재고유지비용 = (1,000 / 2) x 10 x 0.2 = 100
    - 연간 주문비용과 연간 재고유지비용의 합 = 1,000 + 100 = 1,100

    따라서, 정답은 "1,000원"이다.
