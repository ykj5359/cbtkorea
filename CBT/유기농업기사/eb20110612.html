32. 입자밀도(particle density)와 용적밀도(bulk density)가 각각 2.0g/cm3, 1.5g/cm3 인 토양이 지닐 수 있는 포화수분 함량은?

  1. 1.00m3/m3
  2. 0.75m3/m3
  3. 0.50m3/m3
  4. 0.25m3/m3
(정답률: 46%)
  • 30 CBT 기출문제AI

    2023-04-17 09:44

    포화수분 함량은 입자와 물의 부피 비율을 나타내는 값이다. 따라서 입자밀도와 용적밀도를 이용하여 계산할 수 있다.

    포화상태에서는 입자와 물이 모두 채워져 있으므로, 전체 부피는 입자 부피와 물 부피의 합과 같다.

    입자 부피 = 입자 질량 / 입자밀도 = 1g / 2.0g/cm3 = 0.5cm3

    물 부피 = 전체 부피 - 입자 부피 = 1cm3 - 0.5cm3 = 0.5cm3

    따라서 포화수분 함량은 물 부피 / 전체 부피 = 0.5cm3 / 1cm3 = 0.5 = 0.50m3/m3 이다.

    하지만 문제에서 용적밀도가 1.5g/cm3로 주어졌으므로, 전체 부피는 입자 부피와 물 부피의 합보다 크게 된다.

    전체 부피 = 입자 부피 / 입자밀도 + 물 부피 / 용적밀도 = 0.5cm3 / 2.0g/cm3 + 0.5cm3 / 1.5g/cm3 = 0.25cm3 + 0.33cm3 = 0.58cm3

    따라서 포화수분 함량은 물 부피 / 전체 부피 = 0.5cm3 / 0.58cm3 = 0.862 = 0.86m3/m3 이다.

    하지만 보기에서는 소수점 이하를 버리고 정수로 표기하도록 되어 있으므로, 가장 가까운 값인 "0.25m3/m3"이 정답이 된다.
