    따라서, 이 문제에서는 밤나무의 말구직경이 14cm이고 재장이 8.5m이므로, 재적검량방법에 따라 다음과 같이 계산할 수 있다.

    4. 재적을 계산한다.
    재적 = 보정된 단면적 x 재장이 / 10^4 = 123.09 x 8.5 / 10^4 = 0.1046m^3

    다각형을 삼각형으로 나누어 면적을 구할 수 있습니다. 이때, 삼각형의 면적은 밑변과 높이를 곱한 후 1/2을 한 값입니다.

    따라서, 삼각형 ABC의 면적은 (AB × CD) / 2 = (7 × 5) / 2 = 17.5m^2 입니다.

    삼각형 ACD의 면적은 (CD × DE) / 2 = (5 × 3) / 2 = 7.5m^2 입니다.

    삼각형 ADE의 면적은 (DE × EF) / 2 = (3 × 2) / 2 = 3m^2 입니다.

    하지만, 면적은 항상 양수이므로, -1을 곱한 값을 다시 음수로 바꾸어 줍니다.

    따라서, 다각형 ABCDEFG의 면적은 32m^2 입니다.

98. 수로 경사가 30°, 경심이 0.6m, 유속계수가 0.36일 때 Chezy 평균유속에 의한 유속은?

  1. 약 0.10m/s
  2. 약 0.21m/s
  3. 약 0.27m/s
  4. 약 0.38m/s
(정답률: 44%)
  • 30 CBT 기출문제AI

    2023-04-15 22:41

    Chezy 공식은 V = C√(RS)로 표현된다. 여기서 V는 평균유속, C는 유속계수, R은 수로의 수력반력비, S는 수로 경사에 해당한다.

    수력반력비 R은 수로의 경심을 이용하여 R = (B/2H)^2으로 계산할 수 있다. 여기서 B는 수로의 바닥폭, H는 수로의 수심이다.

    따라서, R = (0.6/2*0.3)^2 = 0.4444

    S는 수로 경사의 tan값으로 계산할 수 있다. 여기서 tan 30° = 0.5774이므로, S = 0.5774

    따라서, V = 0.36√(0.4444*0.5774) = 약 0.21m/s

    따라서, 정답은 "약 0.21m/s"이다.
