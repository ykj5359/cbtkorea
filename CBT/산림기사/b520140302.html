17. 다음 조건으로 파종량을 계산하면 약 몇 kg 인가? (단, 파종상 면적 500m2, 순량율 90%, 발아율 60%, 실중 500g, 남겨둘 묘목본수 400/m2, 묘목잔존율 80%)

  1. 131 kg
  2. 231 kg
  3. 331 kg
  4. 431 kg
(정답률: 61%)
  • 30 CBT 기출문제AI

    2023-04-15 22:45

    파종량 = (면적 x 파당 씨앗 수 x 실중 x 순량율 x 발아율 x 묘목잔존율 - 묘목본수) / 1000

    면적 = 500m²
    파당 씨앗 수 = 500g / 1kg x 1000 / 500m² = 2,000개/m²
    실중 = 500g
    순량율 = 90%
    발아율 = 60%
    묘목본수 = 400/m²
    묘목잔존율 = 80%

    파종량 = (500m² x 2,000개/m² x 500g x 90% x 60% x 80% - 400/m²) / 1000
    = (360,000,000 - 160,000) / 1000
    = 359,840 / 1000
    ≈ 359.84 kg

    하지만 문제에서 "남겨둘 묘목본수"가 있으므로, 이를 고려해야 한다. 남겨둘 묘목본수는 400/m² 이므로, 실제 파종할 씨앗 수는 2,000 - 400 = 1,600개/m² 이다. 따라서 파종량은 다음과 같다.

    파종량 = (500m² x 1,600개/m² x 500g x 90% x 60% x 80% - 400/m²) / 1000
    = (288,000,000 - 160,000) / 1000
    = 287,840 / 1000
    ≈ 287.84 kg

    따라서 정답은 "231 kg"가 아니라, "287.84 kg"이다.
