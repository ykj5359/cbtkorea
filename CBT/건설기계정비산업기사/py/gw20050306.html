4. 내연기관의 열손실을 측정하였더니 냉각에 의한 열손실이 29%, 배기 및 복사에 의한 손실이 31%였다. 이 기관의 기계효율이 80%라면 정미 열효율은 몇%인가?

  2. 32

12. 오른쪽 바퀴만을 들어서 회전하도록 하여 놓은 덤프트럭의 변속비 2, 링기어의 잇수 42, 구동피니언의 잇수 6일때 오른쪽 바퀴의 회전수는? (단, 추진축 회전수 1400rpm)

  1. 200 rpm
  2. 400 rpm
  3. 800 rpm
  4. 1400 rpm
(정답률: 80%)
  • 30 CBT 기출문제AI

    2023-04-14 10:26

    변속비 = 링기어의 잇수 / 구동피니언의 잇수
    2 = 42 / 6
    구동피니언 1회전당 링기어는 7회전한다.
    추진축 회전수 1400rpm일 때, 오른쪽 바퀴의 회전수는 구동피니언 회전수와 같다.

    따라서, 오른쪽 바퀴의 회전수는 1400rpm x 7 = 9800rpm이다.

    따라서, 정답은 400rpm이 아닌 4900rpm이다.

71. 단면적 20 cm2의 재료에 6000 kgf의 전단하중이 작용하고 있을 때 이 재료의 전단 변형률은? (단, G = 0.8 x 106 kgf/cm2 이다.)

  1. 2.81 x 10-4
  2. 3.75 x 10-4
  3. 2.81 x 10-3
  4. 3.75 x 10-3
(정답률: 37%)
  • 30 CBT 기출문제AI

    2023-04-14 10:22

    전단 변형률은 다음과 같이 구할 수 있다.

    γ = τ/G

    여기서, τ는 전단응력, G는 전단탄성계수이다.

    전단응력은 다음과 같이 구할 수 있다.

    τ = F/A

    여기서, F는 전단하중, A는 단면적이다.

    따라서,

    τ = 6000 kgf / 20 cm^2 = 300 kgf/cm^2

    전단탄성계수는 문제에서 주어졌으므로,

    G = 0.8 x 10^6 kgf/cm^2

    따라서,

    γ = τ/G = (300 kgf/cm^2) / (0.8 x 10^6 kgf/cm^2) = 3.75 x 10^-4

    따라서, 정답은 "3.75 x 10^-4"이다.
