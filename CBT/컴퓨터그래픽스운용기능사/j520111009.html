  1. 작은 문자일 수록 안티앨리어싱 처리를 하면 가독성이 높아진다.
  2. 저해상도의 비트맵 이미지에서 나타나는 계단현상을 부드럽게 처리하는 방식이다.
  3. 문자의 경우 12pt 이상의 크기에서 적용시키는 것이 좋다.
  4. 문자의 안티앨리어싱 적용여부는 배경색, 문자 크기, 문자 폰트에 따라 결정하는 것이 좋다.
(정답률: 59%)

    2023-04-12 23:11

    "작은 문자일 수록 안티앨리어싱 처리를 하면 가독성이 높아진다."이 부분이 틀린 것입니다. 오히려 큰 문자일수록 안티앨리어싱 처리를 하면 가독성이 높아집니다. 작은 문자는 이미 충분히 부드럽게 보이기 때문에 안티앨리어싱 처리를 하면 오히려 가독성이 떨어질 수 있습니다.

59. 기억된 정보를 읽어낼 수는 있으나 변경시킬 수 없는 메모리이며, 주로 부팅 시 필요한 프로그램이나 변경될 소지가 없는 데이터 메모리로 사용되는 것은?

  1. RAM
  2. ROM
  3. Hard Disk
  4. Web hard
(정답률: 68%)
  • 30 CBT 기출문제AI

    2023-04-12 23:11

    ROM은 Read-Only Memory의 약자로, 읽기만 가능하고 쓰기가 불가능한 메모리입니다. 따라서 기억된 정보를 읽어낼 수는 있지만 변경시킬 수 없습니다. 이러한 특성 때문에 주로 부팅 시 필요한 프로그램이나 변경될 소지가 없는 데이터 메모리로 사용됩니다.
