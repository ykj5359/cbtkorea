58. 컴퓨터의 주기억 장치의 연산단위에 대한 크기의 순서를 바르게 배열한 것은?

  1. bit < byte < kilobyte < Gigabyte < Terabyte
  2. byte < bit < kilobyte < Terabyte < Gigabyte
  3. bit < byte < kilobyte < Terabyte < Gigabyte
  4. bit < byte < Terabyte < Gigabyte < Kilobyte
(정답률: 84%)
  • 30 CBT 기출문제AI

    2023-04-12 23:07

    정답은 "bit < byte < kilobyte < Gigabyte < Terabyte" 입니다.

    - bit: 컴퓨터에서 가장 작은 단위로, 0 또는 1의 값을 가집니다.
    - byte: 8개의 bit가 모여서 이루어진 단위로, 문자나 숫자 등을 표현할 수 있습니다.
    - kilobyte: 1024 byte가 모여서 이루어진 단위로, 작은 이미지나 문서 등을 저장할 수 있습니다.
    - Gigabyte: 1024 kilobyte가 모여서 이루어진 단위로, 대용량의 파일이나 동영상 등을 저장할 수 있습니다.
    - Terabyte: 1024 Gigabyte가 모여서 이루어진 단위로, 매우 큰 데이터를 저장할 수 있습니다.

    따라서, bit가 가장 작은 단위이고, byte는 8개의 bit가 모여서 이루어진 단위이므로 bit보다 크며, kilobyte는 byte보다 크고, Gigabyte는 kilobyte보다 크며, Terabyte는 Gigabyte보다 크기 때문에 "bit < byte < kilobyte < Gigabyte < Terabyte" 순서가 올바릅니다.
