55. 다음 컴퓨터연산의 기본단위의 크기가 바르게 설정된 것은?

  1. Byte < Bit < Kilobyte < Megabyte
  2. Kilobyte < Terabyte < Megabyte < Gigabyte
  3. Bit < Byte < Kilobyte < Megabyte
  4. Kilobyte < Megabyte < Terabyte < Gigabyte
(정답률: 86%)
  • 30 CBT 기출문제AI

    2023-04-12 22:54

    정답은 "Bit < Byte < Kilobyte < Megabyte" 입니다.

    - Bit: 컴퓨터에서 정보를 처리하는 가장 작은 단위
    - Byte: 8개의 비트가 모여서 이루어지는 단위
    - Kilobyte: 1024바이트로 이루어진 단위
    - Megabyte: 1024킬로바이트로 이루어진 단위

    따라서, Bit가 가장 작은 단위이고, Byte는 8개의 비트가 모여서 이루어지므로 Bit보다 큰 단위이며, Kilobyte는 1024바이트로 이루어져 있으므로 Byte보다 큰 단위이고, Megabyte는 1024킬로바이트로 이루어져 있으므로 Kilobyte보다 큰 단위입니다.
