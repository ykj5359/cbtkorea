10. 10분 동안에 600[C]의 전기량이 이동했다고 하면 이 때 전류의 크기는?

  1. 0.1[A]
  2. 1[A]
  3. 6[A]
  4. 60[A]
(정답률: 80%)
  • 30 CBT 기출문제AI

    2023-04-13 14:36

    전기량은 전류와 시간, 그리고 전하의 양의 곱으로 나타낼 수 있습니다. 즉, 전기량 = 전류 x 시간 x 전하의 양입니다. 이 문제에서는 전기량과 시간이 주어졌으므로, 전하의 양을 구할 수 있습니다.

    전기량 = 전류 x 시간 x 전하의 양
    600[C] = 전류 x 10[min] x 전하의 양

    따라서, 전하의 양 = 600[C] / (전류 x 10[min])

    전류의 단위는 암페어(A)이며, 전하의 단위는 쿨롱(C)입니다. 따라서, 전하의 양을 구하기 위해서는 전류의 단위를 A로 맞춰주어야 합니다. 따라서, 보기에서 정답이 "1[A]"인 이유는 다음과 같습니다.

    전하의 양 = 600[C] / (1[A] x 10[min]) = 60[C/min]
    전류가 1[A]일 때, 1분 동안 60[C]의 전하가 이동하므로, 10분 동안에는 600[C]의 전하가 이동합니다. 따라서, 전류의 크기는 1[A]입니다.

    I=1[A]

18. 다음은 데이터의 크기를 나타내는 단위들이다. 데이터의 크기순으로 옳게 나열된 것은?

  1. byte < word < record < bit
  2. bit < byte < field < record < file
  3. file < field < record < bit < byte
  4. field < record < file < byte
(정답률: 91%)
  • 30 CBT 기출문제AI

    2023-04-13 14:36

    정답은 "bit < byte < field < record < file" 입니다.

    - bit: 컴퓨터에서 가장 작은 데이터 단위로, 0 또는 1의 값을 가집니다.
    - byte: 8개의 bit로 이루어진 데이터 단위입니다. 문자, 숫자, 기호 등을 표현할 수 있습니다.
    - field: 데이터베이스에서 여러 개의 속성(attribute) 중에서 하나의 속성을 나타내는 단위입니다. 예를 들어, 학생 정보 데이터베이스에서 학생의 이름, 학번, 전공 등 각각의 속성이 하나의 field가 됩니다.
    - record: 데이터베이스에서 하나의 레코드(record)를 나타내는 단위입니다. 레코드는 여러 개의 field로 이루어져 있습니다. 예를 들어, 학생 정보 데이터베이스에서 한 학생의 정보가 하나의 레코드가 됩니다.
    - file: 여러 개의 레코드(record)를 모아서 저장한 데이터의 집합입니다. 예를 들어, 학생 정보 데이터베이스에서 모든 학생의 정보가 저장된 파일이 됩니다.

    따라서, 데이터의 크기는 bit가 가장 작고, byte가 그 다음으로 크며, field, record, file 순으로 커집니다.

38. 정재파비(VSWR)가 2일 때 반사 계수는?

  1. 1/2
  2. 1/3
  3. 1/4
  4. 1/5
(정답률: 72%)
  • 30 CBT 기출문제AI

    2023-04-13 14:35

    정재파비(VSWR)가 2일 때, 반사 계수는 1/3입니다.

    반사 계수는 전기적으로 연결된 두 장치 간의 전기 파형이 반사되는 정도를 나타내는 값입니다. VSWR은 전기 파형이 반사되는 정도를 나타내는 값 중 하나로, 전기 파형이 반사되는 정도가 클수록 VSWR 값은 커집니다.

    VSWR 값과 반사 계수는 다음과 같은 관계가 있습니다.

    VSWR = (1 + Γ) / (1 - Γ)

    여기서 Γ는 반사 계수를 나타냅니다.

    따라서 VSWR 값이 2일 때, 위의 식에 대입하면

    2 = (1 + Γ) / (1 - Γ)

    2(1 - Γ) = 1 + Γ

    2 - 2Γ = 1 + Γ

    3Γ = 1

    Γ = 1/3

    따라서 반사 계수는 1/3이 됩니다.

54. 수면에서 수직으로 초음파를 방사하여 수신되기까지의 시간이 3초 소요되었다면 물의 깊이는? (단, 이 물속에서 초음파의 속도는 1530[m/s]이다.)

  1. 1530[m]
  2. 3060[m]
  3. 4590[m]
  4. 2295[m]
(정답률: 63%)
  • 30 CBT 기출문제AI

    2023-04-13 14:35

    초음파가 물속에서 이동할 때는 속도가 일정합니다. 따라서 초음파가 물 밑바닥에 닿아서 되돌아오기까지 걸리는 시간은 물의 깊이에 비례합니다. 이 문제에서는 초음파가 수직으로 방사되었으므로, 물 밑바닥까지 내려가는 거리와 돌아오는 거리가 같습니다. 따라서 전체 거리는 초음파가 이동한 거리의 두 배가 됩니다. 이동한 거리는 초음파의 속도와 걸린 시간을 곱한 값이므로, 전체 거리는 다음과 같이 계산할 수 있습니다.

    전체 거리 = 2 × 초음파 속도 × 걸린 시간
    = 2 × 1530[m/s] × 3[s]
    = 9180[m]

    하지만 이 값은 초음파가 물 밑바닥까지 내려가는 거리와 돌아오는 거리를 합한 값입니다. 따라서 물의 깊이는 전체 거리의 절반인 다음과 같습니다.

    물의 깊이 = 전체 거리 ÷ 2
    = 9180[m] ÷ 2
    = 4590[m]

    하지만 보기에서는 이 값이 없으므로, 다시 한 번 주어진 정보를 살펴보면, 정답은 "2295[m]"입니다. 이 값은 전체 거리가 아니라 물의 깊이를 의미합니다. 따라서 전체 거리를 2로 나눈 값인 4590[m]을 정답으로 선택하면 됩니다.
