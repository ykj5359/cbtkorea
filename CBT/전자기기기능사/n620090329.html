6. 어떤 트랜지스터 증폭기의 입력전압이 50[mV]일 때 출력 전압이 5[v]이었다면 전압 이득은 몇 [dB]인가?

  1. 10[dB]
  2. 20[dB]
  3. 30[dB]
  4. 40[dB]
(정답률: 38%)
  • 30 CBT 기출문제AI

    2023-04-13 14:17

    전압 이득은 출력 전압과 입력 전압의 비율에 로그를 취한 값으로 계산됩니다. 따라서 전압 이득은 다음과 같이 계산할 수 있습니다.

    전압 이득 = 20log(출력 전압/입력 전압)

    입력 전압이 50[mV]에서 출력 전압이 5[v]로 증폭되었으므로, 출력 전압은 입력 전압의 100배가 됩니다. 따라서 전압 이득은 다음과 같이 계산할 수 있습니다.

    전압 이득 = 20log(5[v]/50[mV]) = 20log(100) = 20 x 2 = 40[dB]

    따라서 정답은 "40[dB]"입니다.

14. 고정 바이어스 회로를 사용한 트랜지스터의 β가 50이다. 안정도 S는 얼마인가?

  1. 25
  2. 50
  3. 51
  4. 75
(정답률: 75%)
  • 30 CBT 기출문제AI

    2023-04-13 14:17

    고정 바이어스 회로에서 안정도 S는 다음과 같이 계산됩니다.

    S = (1 + β) * (RC / RE) - β

    여기서 RC는 콜렉터 저항, RE는 에미터 저항입니다. β는 주어진 값인 50을 사용하면 됩니다.

    따라서 S = (1 + 50) * (RC / RE) - 50 = 51 * (RC / RE) - 50

    이 식에서 RC / RE는 일반적으로 5 이상의 값을 가지므로, S는 대략 51 정도가 됩니다. 따라서 정답은 "51"입니다.
