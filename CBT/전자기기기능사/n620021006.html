7. 그림과 같은 발진회로가 지속 발진을 하기 위한 트랜지스터의 전류증폭률 hfe는 어떤 조건이어야 하는가?

  3. hfe = ω2 L2 C2
  4. hfe = ω L C2
(정답률: 49%)
  • 30 CBT 기출문제AI

    2023-04-13 13:56

    이 발진회로는 양의 피드백을 가지고 있으며, 트랜지스터는 발진신호를 증폭시켜 피드백 회로에 보내어 지속적인 발진을 유지합니다. 따라서 트랜지스터의 전류증폭률 hfe는 피드백 회로에서 발진신호를 증폭시키는 역할을 하므로, 이 값이 크면 클수록 발진신호가 더욱 강력하게 증폭되어 지속적인 발진이 가능해집니다.

    ω = 1 / √(L C2)

    hfe = - β / (1 - β A)

    hfe ≈ - β

16. 이미터 접지 증폭회로에서 바이어스 안정지수 S 는 얼마인가? (단, 고정 바이어스임)

  1. 1-β
  2. 1+β
  3. 1-α
  4. 1+α
(정답률: 75%)
  • 30 CBT 기출문제AI

    2023-04-13 13:53

    이미터 접지 증폭회로에서 바이어스 안정지수 S는 1+β입니다.

    이유는 다음과 같습니다.

    이미터 접지 증폭회로에서 바이어스 안정지수 S는 출력 전압(Vout)과 입력 전압(Vin)의 비율로 정의됩니다.

    S = Vout / Vin

    고정 바이어스를 사용하므로, 입력 전압(Vin)은 일정합니다.

    증폭기의 전압 이득은 β입니다. 따라서 출력 전압(Vout)은 입력 전압(Vin)에 β를 곱한 값이 됩니다.

    Vout = βVin

    따라서,

    S = Vout / Vin = βVin / Vin = β

    하지만, 이는 바이어스가 고정되어 있을 때의 안정지수이므로,

    S = 1 + β

    가 됩니다.

    즉, 바이어스 안정지수 S는 증폭기의 전압 이득 β에 1을 더한 값입니다.
