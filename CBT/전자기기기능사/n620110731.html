4. 교류의 최대치가 Vm일 때 전파정류회로의 무부하 시 직류출력(평균) 전압 값은 얼마인가?

  1. Vm/√2
  2. Vm/2
  3. Vm/π
  4. (2Vm)/π
(정답률: 51%)
  • 30 CBT 기출문제AI

    2023-04-13 14:29

    전파정류회로에서 무부하 시 직류출력 전압 값은 다음과 같이 구할 수 있다.

    Vdc = Vm / π

    이는 다음과 같은 이유로 설명할 수 있다.

    전파정류회로에서 전압은 정현파 형태로 주기적으로 변화하며, 이를 수식으로 나타내면 다음과 같다.

    V(t) = Vm sin(ωt)

    여기서 ω는 각주파수이다. 이 전압을 다이오드로 정류하면 다음과 같은 식이 나온다.

    Vout = |V(t)| = |Vm sin(ωt)|

    이때, 전압의 평균값은 다음과 같이 구할 수 있다.

    Vdc = (1/T) ∫0T Vout dt

    여기서 T는 주기이다. 위 식을 계산하면 다음과 같다.

    Vdc = (2Vm / π)

    따라서, 전파정류회로의 무부하 시 직류출력 전압 값은 (2Vm / π)이다.

13. 다음 그림의 회로에서 합성저항은 몇 [Ω]인가?

  1. 20
  2. 40
  3. 60
  4. 80
(정답률: 72%)
  • 30 CBT 기출문제AI

    2023-04-13 14:28

    합성저항은 병렬저항의 합과 직렬저항의 합으로 구할 수 있습니다.

    먼저, R1과 R2는 직렬저항으로 합성저항은 R1 + R2 = 20 + 40 = 60 [Ω]입니다.

    그리고 R3과 합성저항은 병렬저항으로, 합성저항은 R3과 병렬일 때 전체 저항과 같으므로,

    1/합성저항 = 1/R3 + 1/60

    1/합성저항 = (60 + R3) / (60 * R3)

    60 * R3 / (60 + R3) = 합성저항

    위 식에서 R3 = 80 [Ω]이므로, 합성저항은 60 [Ω]입니다.

    따라서, 정답은 "60"입니다.
