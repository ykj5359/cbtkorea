    H = (4/5) * (I / L)

    H = (4/5) * (I / L) = (4/5) * (I / 0.10312) = 7.726 * I

    자분탐상검사를 위해서는 자화전류가 충분히 크게 흐르도록 해야 합니다. 이를 위해서는 봉재의 자기장을 충분히 강하게 만들어야 합니다. 자기장은 전류와 봉재의 길이, 지름 등에 따라 결정됩니다. 따라서 이 문제에서는 봉재의 길이와 지름이 주어졌으므로, 전류만 구하면 됩니다.

    자기장의 강도는 다음과 같은 식으로 계산됩니다.

    B = μ₀ * n * I

    여기서 B는 자기장의 강도, μ₀는 자유공간의 자기유도율(4π × 10^-7), n은 감은 코일의 개수, I는 자화전류입니다.

    A = π * r^2 = π * (2.54cm)^2 = 20.27cm^2

    이제 자기장의 강도를 구하기 위해, B = μ₀ * n * I 식을 I에 대해 정리합니다.

    I = B / (μ₀ * n) = (5000G) / (4π × 10^-7 * 5) = 3,183A

  2. 54
  3. 90
  4. 150
(정답률: 알수없음)

    2023-04-18 18:45

    역률은 다음과 같이 계산할 수 있다.

    역률 = 유효전력 ÷ 피상전력

    피상전력 = 전압 × 전류 = (80V + 30V) × 300A = 33,000W

    역률 = 유효전력 ÷ 피상전력 = 9000W ÷ 33,000W ≈ 0.2727 ≈ 27.27%
