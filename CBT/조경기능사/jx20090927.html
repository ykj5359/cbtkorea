36. 뿌리분의 직경을 정할 때 그 계산식이 바른 것은? (단, A : 뿌리분의 직경, N : 근원직경, d : 상록수와 낙엽수의 상수0

  1. A = 24 + (N - 3) × d
  2. A = 22 + (N + 3) × d
  3. A = 26 + (N - 3) × d
  4. A = 20 + (N + 3) × d
(정답률: 89%)
  • 30 CBT 기출문제AI

    2023-04-12 19:14

    정답은 "A = 24 + (N - 3) × d" 입니다.

    이유는 다음과 같습니다.

    뿌리분의 직경은 근원직경과 상록수와 낙엽수의 상수 d에 따라 결정됩니다.

    뿌리분의 직경은 근원직경에서부터 시작하여 지면 아래로 내려가면서 점점 더 넓어지기 때문에, 근원직경과 뿌리분의 직경 사이에는 일정한 관계가 있습니다.

    이 관계식은 다음과 같습니다.

    A = N + (N - 2) × d

    여기서 A는 뿌리분의 직경, N은 근원직경, d는 상록수와 낙엽수의 상수입니다.

    하지만 이 관계식은 지면 아래로 내려갈수록 뿌리분의 직경이 더 커지는 것을 고려하지 않았기 때문에, 보다 정확한 값을 얻기 위해서는 이 식을 약간 수정해야 합니다.

    따라서, 보다 정확한 식은 다음과 같습니다.

    A = 24 + (N - 3) × d

    이 식은 근원직경이 1일 때 A가 24가 되도록 설정한 것입니다. 이렇게 하면 지면 아래로 내려갈수록 뿌리분의 직경이 더 커지는 것을 고려할 수 있습니다.

    먼저 자연석의 부피를 구해야 합니다. 평균 뒷길이가 20cm 이므로, 높이는 20cm, 길이와 너비는 알 수 없습니다. 하지만 자연석을 쌓을 면적이 100m2 이므로, 이를 이용하여 부피를 구할 수 있습니다.

    면적 = 길이 × 너비
    100m2 = 길이 × 너비

    자연석의 높이는 20cm 이므로, 부피는 다음과 같습니다.

    부피 = 면적 × 높이
    부피 = 100m2 × 0.2m
    부피 = 20m3

    자연석의 단위중량이 2.5t/m3 이므로, 총 중량은 다음과 같습니다.

    총 중량 = 부피 × 단위중량
    총 중량 = 20m3 × 2.5t/m3
    총 중량 = 50t

    자연석을 쌓을 때의 공극률이 30% 이므로, 실제 필요한 자연석의 양은 다음과 같습니다.

    실제 필요한 자연석의 양 = 총 중량 ÷ (1 - 공극률)
    실제 필요한 자연석의 양 = 50t ÷ (1 - 0.3)
    실제 필요한 자연석의 양 = 71.43t

    조경공 1명이 1t의 자연석을 쌓을 수 있으므로, 필요한 조경공의 수는 다음과 같습니다.

    필요한 조경공의 수 = 실제 필요한 자연석의 양 × 2.5명/t
    필요한 조경공의 수 = 71.43t × 2.5명/t
    필요한 조경공의 수 = 178.58명

    하지만 조경공은 인력이 끊임없이 필요한 일이므로, 올림하여 179명으로 계산합니다.

    노임단가는 43,800원이므로, 조경공의 노무비는 다음과 같습니다.

    조경공의 노무비 = 필요한 조경공의 수 × 노임단가
    조경공의 노무비 = 179명 × 43,800원
    조경공의 노무비 = 7,834,200원

    따라서, 조경공의 노무비는 3,832,500원이 아닌 7,834,200원입니다.
