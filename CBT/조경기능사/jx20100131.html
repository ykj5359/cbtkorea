8. 지면보다 1.5m 높은 현관까지 계단을 설계하려 한다. 단면을 30cm로 적용할 때 필요한 계단수는?(단, 2a+b=60cm 으로 지정한다.)

  1. 10단 정도
  2. 20단 정도
  3. 30단 정도
  4. 40단 정도
(정답률: 68%)
  • 30 CBT 기출문제AI

    2023-04-12 19:14

    먼저 계단의 높이는 1.5m이므로 150cm이다. 계단의 단수를 n이라고 하면, 계단의 높이는 n x 30cm이 되어야 한다. 따라서 n x 30cm = 150cm 이므로 n = 5이다.

    그러나 이 계단은 2a+b=60cm의 단면을 가져야 한다. 따라서 계단의 밑면과 윗면의 길이를 각각 a와 b라고 하면, 2a+b=60cm이 성립해야 한다.

    n=5일 때, 계단의 밑면과 윗면의 길이를 각각 a와 b라고 하면, a = 10cm, b = 40cm이 된다. 이는 2a+b=60cm을 만족하므로, 5단의 계단을 설계할 수 있다.

    따라서 정답은 "10단 정도"이다.

20. 다음 중 석재의 비중을 구하는 식은?

  1. A/B+C
  2. A/B-C
  3. C/A-B
  4. B/A+C
(정답률: 66%)
  • 30 CBT 기출문제AI

    2023-04-12 19:14

    석재의 비중은 밀도(density)와 같으며, 밀도는 단위 부피당 질량으로 정의됩니다. 따라서 석재의 밀도는 다음과 같이 구할 수 있습니다.

    밀도 = 질량 / 부피

    질량은 석재의 무게를 의미하며, 부피는 석재의 크기에 따라 달라집니다. 따라서 석재의 밀도를 구하기 위해서는 먼저 석재의 부피를 구해야 합니다.

    석재의 부피는 다음과 같이 구할 수 있습니다.

    부피 = 길이 x 너비 x 높이

    따라서 석재의 밀도는 다음과 같이 구할 수 있습니다.

    밀도 = 질량 / (길이 x 너비 x 높이)

    주어진 식에서 A는 석재의 무게를 의미하며, B는 석재의 길이, C는 석재의 너비, 그리고 D는 석재의 높이를 의미합니다. 따라서 석재의 부피는 B x C x D이며, 석재의 밀도는 A / (B x C x D)입니다.

    따라서 정답은 A/B-C입니다.
