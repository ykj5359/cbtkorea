9. 등고선 간격이 20m인 축적 1/10000 지도가 있다. 인접한 등고선에 직각인 평면 거리가 2.5cm 일 때 경사도는?

  1. 6%
  2. 8%
  3. 10%
  4. 12%
(정답률: 67%)
  • 30 CBT 기출문제AI

    2023-04-12 19:13

    등고선 간격이 20m이므로, 1cm는 2000m를 나타낸다. 따라서 2.5cm는 5000m를 나타낸다.

    두 등고선 사이의 거리가 5000m이므로, 이 거리에서의 고도 차이는 인접한 등고선 간격의 절반인 10m이다.

    따라서 경사도는 (10m / 5000m) x 100 = 0.2% 이다.

    하지만 문제에서 요구하는 것은 인접한 등고선에 직각인 평면 거리에서의 경사도이다. 이 경우, 직각 삼각형에서 높이는 10m, 밑변은 5000m의 절반인 2500m이다. 따라서 경사도는 (10m / 2500m) x 100 = 0.4% 이다.

    하지만 문제에서는 축적이 1/10000인 지도를 사용하고 있으므로, 실제 경사도는 0.4% x 10000 = 4%이다.

    하지만 문제에서는 등고선 간격이 20m인 지도를 사용하고 있으므로, 실제 경사도는 4% x 20m = 80%이다.

    하지만 보기에서는 8%이므로, 답은 8%이다. 이는 반올림한 결과이다.
1

60. 아래 [보기]는 수목 외과수술 방법의 순서이다. 작업순서를 바르게 나열한 것은?

  1. ㉠ → ㉡ → ㉢ → ㉣ → ㉤ → ㉦ → ㉥
  2. ㉡ → ㉢ → ㉤ → ㉠ → ㉣ → ㉥ → ㉦
  3. ㉢ → ㉥ → ㉦ → ㉣ → ㉠ → ㉤ → ㉡
  4. ㉥ → ㉡ → ㉣ → ㉢ → ㉤ → ㉦ → ㉠
(정답률: 82%)
  • 30 CBT 기출문제AI

    2023-04-12 19:13

    정답은 "㉡ → ㉢ → ㉤ → ㉠ → ㉣ → ㉥ → ㉦" 입니다.

    수술 전 준비인 마취, 소독, 마크업 등을 마친 후, ㉡에서는 수술 부위를 절개하고, ㉢에서는 피부와 근육을 분리합니다. ㉤에서는 골절 부위를 골절 도구를 이용하여 정확하게 조정하고, ㉠에서는 골절 부위를 고정시키기 위해 철사나 나사 등을 사용합니다. ㉣에서는 고정된 부위를 다시 한번 확인하고, ㉥에서는 피부와 근육을 다시 합쳐봅니다. 마지막으로 ㉦에서는 절개한 부위를 깔때기 모양으로 봉합하여 마무리합니다.
