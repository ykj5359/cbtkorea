96. 용액 1ℓ에 AgNO3 18.0g 가 녹아 있다. 이 용액의 N 농도를 구하시오? (AgNO3 = 170)

  4. 0.162 N
(정답률: 44%)
  • 30 CBT 기출문제AI

    2023-04-16 13:17

    N 농도는 몰농도와 동일하다. 따라서,

    몰농도 = 몰수 / 용액의 부피

    AgNO3의 몰수는 질량 / 몰질량 = 18.0 / 170 = 0.106 mol 이다.

    용액의 부피는 1ℓ 이므로,

    N 농도 = 0.106 mol / 1ℓ = 0.106 N

    따라서, 정답은 "0.106 N" 이다.
