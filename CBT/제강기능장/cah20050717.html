56. 다음 데이터로부터 통계량을 계산한 것 중 틀린 것은?

  1. 중앙값(Me) = 24.3
  2. 제곱합(S) = 7.59
  3. 시료분산(s2) = 8.988
  4. 범위(R) = 7.6
(정답률: 61%)
  • 30 CBT 기출문제AI

    2023-04-12 11:14

    제곱합(S) = 7.59이 틀린 것입니다.

    제곱합(S)는 각 데이터와 평균값의 차이를 제곱한 값의 합으로 계산됩니다. 따라서 S = (19.5-24.3)2 + (21.8-24.3)2 + (23.1-24.3)2 + (25.2-24.3)2 + (27.5-24.3)2 = 22.14 입니다.

    시료분산(s2)은 제곱합을 자유도(n-1)로 나눈 값으로 계산됩니다. 따라서 s2 = S/(n-1) = 22.14/4 = 5.535 입니다.

    범위(R)는 최대값과 최소값의 차이로 계산됩니다. 따라서 R = 27.5-19.9 = 7.6 입니다.

    중앙값(Me)은 데이터를 크기순으로 나열했을 때 가운데 위치한 값으로 계산됩니다. 따라서 Me = 23.1 입니다.
