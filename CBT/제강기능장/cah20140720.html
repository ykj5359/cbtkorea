47. np관리도에서 시료군 마다 시료수(n)는 100 이고, 시료군의 수(k)는 20, ∑np=77이다. 이때 np관리도의 관리상한선(UCL)을 구하면 약 얼마인가?

  1. 8.94
  2. 3.85
  3. 5.77
  4. 9.62
(정답률: 34%)
  • 30 CBT 기출문제AI

    2023-04-12 11:25

    np관리도의 관리상한선(UCL)은 UCL = np̄ + 3√np̄(1-p̄) 이다. 여기서 p̄는 모든 시료에서 발생한 불량률의 평균이다.

    ∑np=77 이므로, np̄ = ∑np / n*k = 77 / (100*20) = 0.0385
    p̄는 모든 시료에서 발생한 불량률의 평균이므로, p̄ = np̄ / n = 0.0385 / 100 = 0.000385

    따라서, UCL = np̄ + 3√np̄(1-p̄) = 0.0385 + 3√(0.0385*(1-0.000385)) = 9.62

    따라서, 정답은 "9.62"이다.
