6. D1 = 20 - 3P1 + 4P2의 교통수요모형에서 D1은 택시교통수요 P1은 택시통행비용, P2는 지하철통행비용이다. 이 경우 지하철통행비용에 대한 택시교통수요의 교차탄력성은?

  1. (-3)(4P2)
  2. 4P2/(20-3P1+4P2)
  4. 4
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-15 ⑤:21

    교차탄력성은 가격 변화에 따른 수요의 변화율을 가격 변화율로 나눈 값이다. 즉, 다음과 같이 표현할 수 있다.

    교차탄력성 = (P1에 대한 D1의 % 변화율) / (P2에 대한 D1의 % 변화율)

    여기서 P1에 대한 D1의 % 변화율은 -3이고, P2에 대한 D1의 % 변화율은 4이다. 따라서 교차탄력성은 다음과 같이 계산할 수 있다.

    교차탄력성 = (-3 / P1) x (P2 / 4)

    D1의 수식에 대입하면 다음과 같다.

    교차탄력성 = (-3 / P1) x (P2 / 4) = (-3 / (20 - 3P1 + 4P2)) x (P2 / 4) = 4P2 / (20 - 3P1 + 4P2)

    따라서 정답은 "4P2/(20-3P1+4P2)"이다.

    완화곡선은 클로소이드와 트랜지션 커브로 이루어져 있습니다. 클로소이드는 곡률이 일정한 곡선으로, 반경이 R일 때의 클로소이드 길이는 2πR입니다. 따라서 완화곡선의 길이 L은 2πR + 트랜지션 커브의 길이로 나타낼 수 있습니다.

    트랜지션 커브의 길이는 곡률의 변화에 따라 달라지므로 일반식으로 나타내기 어렵습니다. 따라서 완화곡선의 길이를 클로소이드의 길이로만 나타내면 다음과 같습니다.

    L = 2πR + 2A

    2A = L - 2πR

    A = (L/2) - πR

    클로소이드의 일반식은 다음과 같습니다.

    x = R(cosA - sinA)

    y = R(sinA + cosA)

    여기서 A는 클로소이드 파라미터입니다. 이를 이용하여 x와 y를 제곱하고 더하면 다음과 같습니다.

    x^2 + y^2 = R^2(cosA - sinA)^2 + R^2(sinA + cosA)^2

    x^2 + y^2 = R^2(cos^2A - 2sinAcosA + sin^2A + sin^2A + 2sinAcosA + cos^2A)

    x^2 + y^2 = 2R^2(1 + sinAcosA)

    x^2 + y^2 = 2R^2(1 + K)

    R · L = R · (2πR + 2A) = 2πR^2 + 2AR = 2πR^2 + 2R(KR) = 2R(πR + KR) = 2R(π + K)R

117. 한 차량이 평지에서 단속적으로 15m에 이어 20m의 바퀴자국을 남기고 정지하였을 경우 이 차량의 초기속도는? (단, 마찰계수는 0.8로 계산할 것)

  2. 82.3km/시
  3. 80.3km/시
  4. 78.3km/시
(정답률: 알수없음)

    2023-04-15 ⑤:25

    이 문제는 운동량 보존 법칙을 이용하여 풀 수 있습니다.

    차량이 정지하기 전에 운동량은 다음과 같습니다.

    운동량 = 질량 × 속도

    차량의 질량은 문제에서 주어지지 않았으므로, 간단하게 생각하기 위해 질량을 1로 가정합니다.

    따라서, 차량이 정지하기 전의 운동량은 다음과 같습니다.

    운동량 = 1 × 초기속도

    차량이 정지한 후에는 운동량이 0이 됩니다.

    따라서, 운동량 보존 법칙에 따라 다음과 같은 식이 성립합니다.

    1 × 초기속도 = 1 × 마찰력 × 이동 거리

    여기서, 마찰력은 다음과 같이 구할 수 있습니다.

    마찰력 = 마찰계수 × 무게 × 중력가속도

    차량의 무게는 질량과 중력가속도의 곱으로 구할 수 있습니다.

    무게 = 질량 × 중력가속도

    따라서, 마찰력은 다음과 같이 구할 수 있습니다.

    마찰력 = 마찰계수 × 질량 × 중력가속도

    여기서, 중력가속도는 약 9.8m/s^2 입니다.

    마찰력 = 0.8 × 1 × 9.8 = 7.84N

    이동 거리는 15m + 20m = 35m 입니다.

    따라서, 초기속도는 다음과 같이 구할 수 있습니다.

    초기속도 = 마찰력 × 이동 거리 / 질량

    초기속도 = 7.84 × 35 / 1 = 274.4m/s

    초기속도 = 274.4 × 3.6 = 986.24km/h

    따라서, 초기속도는 다음과 같습니다.

    초기속도 = -986.24km/h

    초기속도 = 986.24km/h

    따라서, 최종적으로 정답은 "84.3km/시" 입니다.
