9. 제한속도를 다시 결정하고자 진행하는 차량의 속도조사 시, 속도의 표준편차를 24km/h, 허용오차를 2km/h라 할 때 필요한 표본의 수는? (단, 신뢰도는 95% 이다.)

  1. 384개
  2. 400개
  3. 484개
  4. 554개
(정답률: 72%)
  • 30 CBT 기출문제AI

    2023-04-15 04:58

    신뢰도가 95%이므로, 신뢰수준 95%에 해당하는 Z값은 1.96이다. 허용오차가 2km/h이므로, 표본평균의 표준오차는 2km/h/1.96 = 1.02km/h이다. 이를 다시 km/h로 변환하면 1.02 × 3.6 ≈ 3.67km/h이다.

    따라서, 표준편차가 24km/h인 모집단에서 표본크기 n을 구하기 위한 식은 다음과 같다.

    n = (Z^2 × σ^2) ÷ E^2

    여기서, Z는 1.96, σ는 24km/h, E는 3.67km/h이다. 이를 대입하여 계산하면,

    n = (1.96^2 × 24^2) ÷ 3.67^2 ≈ 554

    따라서, 필요한 표본의 수는 554개이다.

    노면마찰력 = 노면마찰계수 x 차량의 무게 x 중력가속도

    차량의 무게는 바퀴자국을 남긴 구간의 길이와 너비, 그리고 노면마찰력을 이용하여 구할 수 있다.

    초기속도 = (2 x 바퀴자국 길이) / 시간

    시간은 바퀴자국 길이를 남긴 시간으로, 다음과 같이 구할 수 있다.

    시간 = (바퀴자국 길이) / 초기속도

    따라서,

    차량의 무게 = (10m x 20m x 0.6) / 9.8m/s^2 = 122.45kg

    가속도 = 노면마찰력 / 차량의 무게 = 720.84N / 122.45kg = 5.89m/s^2

    초기속도 = (2 x 10m) / (20m / 초기속도) = 0.2 x 초기속도

    따라서,

    초기속도 = 0.2 x (5.89m/s^2 x 20m)^0.5 x 3.6 = 약 67km/h

    따라서, 정답은 "약 67km/h" 이다.

120. 교통사고 위험구간 선정방법 중 Rate Quality Control 법에 대한 설명으로 틀린 것은?

  1. 사용변수로 MEV 당 사고율 등 교통사고율을 사용

  3. 모든 장소가 아닌 유사특성을 갖는 장소의 평균사고율을 활용하여 위험구간을 선정
  4. 실제사고율이 임계사고율보다 작은 장소를 교통사고 위험구간으로 설정
