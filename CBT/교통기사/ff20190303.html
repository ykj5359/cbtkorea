11. 지하철과 버스에 대한 효용함수 및 통행특성 자료가 아래와 같을 때, 로짓모형을 이용한 교통수단별 선택확률이 모두 옳은 것은? (단, 효용함수 V=-0.06(0.5X1+0.002X2))

  1. 버스:42.1%, 지하철:57.9%
  2. 버스:47.9%, 지하철:52.1%
  3. 버스:52.1%, 지하철:47.9%
  4. 버스:57.9%, 지하철:42.1%
(정답률: 60%)
  • 30 CBT 기출문제AI

    2023-04-15 04:55

    로짓모형에서 선택확률은 다음과 같이 계산된다.

    P(지하철 선택) = exp(V지하철) / (exp(V지하철) + exp(V버스))

    P(버스 선택) = exp(V버스) / (exp(V지하철) + exp(V버스))

    따라서, V지하철 = -0.06(0.5X1+0.002X2) = -0.03X1 - 0.00012X2

    V버스 = -V지하철 = 0.03X1 + 0.00012X2

    각각의 통행특성을 대입하여 계산하면 다음과 같다.

    V지하철 = -0.03(100) - 0.00012(200) = -3.6

    V버스 = 3.6

    따라서,

    P(지하철 선택) = exp(-3.6) / (exp(-3.6) + exp(3.6)) = 0.421

    P(버스 선택) = exp(3.6) / (exp(-3.6) + exp(3.6)) = 0.579

    따라서, 정답은 "버스:57.9%, 지하철:42.1%" 이다. 버스 선택 확률이 더 높은 이유는 버스의 효용함수 계수가 양수이기 때문이다. 즉, X1 (거리)이 증가할수록 버스 선택 확률이 높아진다. 반면, X2 (환승횟수)는 효용함수 계수가 매우 작기 때문에 선택 확률에 큰 영향을 미치지 않는다.

    마찰력 = 마찰계수 × 수직방향의 힘 = 마찰계수 × 중력 × sin(편경사각)

113. 어느 자동차가 경사가 3%인 도로에서 급제동하였더니 제동거리로 36m로 정차하였다. 이 차량의 제동 직전의 속도는? (단, 노면과 타이어 간의 마찰계수는 0.7이다.)

  2. 약 73km/h
  3. 약 82km/h
  4. 약 98km/h

    제동 거리는 다음과 같이 구할 수 있다.

    제동 거리 = (제동 직전 속도)^2 / (2 * 마찰계수 * 중력가속도 * 경사각)

    여기서 중력가속도는 9.8m/s^2이다.

    36 = (v^2) / (2 * 0.7 * 9.8 * 0.03)

    36 = (v^2) / 2.⑤8

    v^2 = 74.088

    v = 약 8.6m/s = 약 31km/h

119. 중량이 2000kg인 차량이 30km/h로 달리다가 정차 중인 1000kg 중량의 차량과 충돌하여 얼마의 거리를 밀고 나가 정차하였다면 충돌 직후의 속도는?

  1. 5km/h
  2. 10km/h
  3. 15km/h
  4. 20km/h
(정답률: 50%)
  • 30 CBT 기출문제AI

    2023-04-15 04:57

    운동량 보존 법칙에 따라, 충돌 전과 후의 운동량은 동일해야 한다. 따라서, 2000kg 차량의 운동량은 2000kg x 30km/h = 60000kg·km/h 이다. 충돌 후, 차량은 정지하므로 운동량은 0이 된다. 충돌한 1000kg 차량의 운동량은 1000kg x v (v는 충돌 직후의 속도) 이다. 따라서, 2000kg 차량과 충돌한 1000kg 차량의 운동량의 합은 0이 되어야 한다.

    60000kg·km/h = 1000kg x v

    v = 60000kg·km/h ÷ 1000kg = 60km/h ÷ 3 = 20km/h

    따라서, 충돌 직후의 속도는 20km/h 이다.

120. 차량 A가 25m를 활주한(skidding) 후 12m 높이의 언덕에서 추락하였다. 추락 후 노면에 떨어진 지점까지의 수평거리가 15m일 경우 차량 A의 초기속도는? (단, 중력가속도는 9.8m/sec2, 마찰계수는 0.7이다.)

  1. 약 75.1km/h
  2. 약 78.5km/h
  3. 약 80.1km/h
  4. 약 83.5km/h
(정답률: 37%)
  • 30 CBT 기출문제AI

    2023-04-15 04:57

    먼저, 차량 A가 활주한 거리를 구해보자.

    활주 거리 = (초기속도)2 / (2 * 마찰계수 * 중력가속도)

    25 = (초기속도)2 / (2 * 0.7 * 9.8)

    (초기속도)2 = 25 * 2 * 0.7 * 9.8

    초기속도 = 35.1m/s

    이제, 차량 A가 추락한 높이를 구해보자.

    추락 높이 = 12m

    노면에 떨어진 지점까지의 수평거리 = 15m

    이를 이용하여, 차량 A의 초기속도를 구해보자.

    초기속도 = √(2 * 중력가속도 * 추락높이 + (활주거리 + 수평거리)2 / 2)

    초기속도 = √(2 * 9.8 * 12 + (25 + 15)2 / 2)

    초기속도 = 75.1m/s

    따라서, 정답은 "약 75.1km/h" 이다.
