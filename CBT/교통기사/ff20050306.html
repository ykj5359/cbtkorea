11. 버스(B)와 지하철(S)간의 선택행태를 분석하고자 자료를 수집하여 계산한 결과, UB(버스의 효용함수)는 -0.18, US(지하철의 효용함수)는 -1.15가 산출되었다. Logit모형을 이용하여 각 교통수단의 선택할 확률을 구한 값은?

  1. PB = 0.55, PS = 0.45
  2. PB = 0.72, PS = 0.28
  3. PB = 0.86, PS = 0.14
  4. PB = 0.91, PS = 0.09
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-15 ⑤:21

    로짓모형에서 각 교통수단의 선택확률은 다음과 같이 계산된다.

    PB = exp(UB) / [exp(UB) + exp(US)] = exp(-0.18) / [exp(-0.18) + exp(-1.15)] = 0.72

    PS = exp(US) / [exp(UB) + exp(US)] = exp(-1.15) / [exp(-0.18) + exp(-1.15)] = 0.28

    따라서, 정답은 "PB = 0.72, PS = 0.28" 이다. 이유는 로짓모형에서 선택확률은 각 교통수단의 효용함수에 의해 결정되며, 지하철의 효용함수가 더 작기 때문에 선택확률이 더 낮게 나타난다.

    가속차로의 길이 = (초기속도 × 시간) + (1/2 × 가속도 × 시간²)

    최종속도를 얻기 위해 필요한 시간은 다음과 같다.

    시간 = (최종속도 - 초기속도) / 가속도

    가속차로의 길이 = (0 × 7.92) + (1/2 × (100 / 3.6) × 7.92²) = 190.08m
