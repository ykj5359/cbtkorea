45. 설계속도가 60km/h인 도로의 곡선부를 설계하고자 한다. 횡방향마찰계수가 0.4, 편경사가 6%일 때 차량이 안전하게 주행할 수 있는 최소곡선반경은 얼마로 하여야 하는가?

  1. 약 62m
  2. 약 67m
  3. 약 72m
  4. 약 77m
(정답률: 62%)
  • 30 CBT 기출문제AI

    2023-04-15 ⑤:04

    차량이 안전하게 주행하기 위해서는 중력과 마찰력이 균형을 이루어야 한다. 따라서, 중력과 마찰력의 크기를 비교해보면 된다.

    중력 = 차량의 질량 x 중력가속도 = 1000kg x 9.8m/s^2 = 9800N
    마찰력 = 횡방향마찰계수 x 수직방향의 노력 = 0.4 x 중력 x sin(6°) ≈ 0.4 x 9800N x 0.1 ≈ 392N

    따라서, 마찰력이 중력보다 작아야 안전하게 주행할 수 있다. 최소곡선반경을 R이라고 하면, 마찰력은 다음과 같이 표현할 수 있다.

    마찰력 = 차량의 질량 x (센트리펄력 / R)

    여기서 센트리펄력은 다음과 같이 표현할 수 있다.

    센트리펄력 = 차량의 질량 x (선속도^2 / R)

    선속도는 m/s 단위이므로, 설계속도를 m/s 단위로 변환해야 한다.

    설계속도 = 60km/h = 16.67m/s

    따라서, 마찰력과 센트리펄력을 비교해보면 다음과 같다.

    차량의 질량 x (선속도^2 / R) = 차량의 질량 x (센트리펄력 / R) x 횡방향마찰계수 x sin(6°)

    선속도 = R x 각속도
    각속도 = 선속도 / R

    따라서, 센트리펄력은 다음과 같이 표현할 수 있다.

    센트리펄력 = 차량의 질량 x (선속도^2 / R) = 차량의 질량 x (R x 각속도)^2 / R = 차량의 질량 x R x 각속도^2

    따라서, 마찰력과 센트리펄력을 비교해보면 다음과 같다.

    차량의 질량 x R x 각속도^2 = 차량의 질량 x (센트리펄력 / R) x 횡방향마찰계수 x sin(6°)

    각속도 = 선속도 / R = 16.67m/s / R

101. 어느 차량이 주행 중 도로를 벗어나 9m 아래의 계곡으로 떨어져 도로 끝에서 수평거리 20m인 지점에 추락하였다. 이 차량이 도로를 벗어날 때의 주행속도는 얼마인가? (단, 중력가속도 g=9.8m/sec2으로 가정한다.)

  2. 약 27km/h
  3. 약 53km/h
  4. 약 75km/h
(정답률: 57%)

    2023-04-15 ⑤:03

    이 문제는 에너지 보존 법칙을 이용하여 풀 수 있다. 차량이 도로를 벗어나기 전의 운동 에너지는 차량의 질량(m)과 주행속도(v)의 제곱에 비례한다. 따라서, 차량이 도로를 벗어날 때의 운동 에너지는 1/2mv^2이다.

    추락한 후에는 차량의 운동 에너지가 중력 에너지로 변환된다. 추락한 높이는 9m이고, 중력가속도는 9.8m/sec^2이므로, 차량이 땅에 닿을 때의 중력 에너지는 mgh = 9 x 9.8 x 9 = 793.8m이다.

    따라서, 정답은 "약 53km/h"이다.

112. 한 차량이 50m 거리를 미끄러져 주차한 차량과 충돌하였으며 충돌 후 두 차량이 18m 미끄러져 정지하였다. 양 차량의 무게가 동일할 때 주행차량의 초기 속도는?(단, 마찰계수는 0.5이다.)

  1. 136.4km/h
  2. 124.5km/h
  3. 113.5km/h
  4. 108.2km/h
(정답률: 59%)
  • 30 CBT 기출문제AI

    2023-04-15 ⑤:03

    두 차량이 충돌하면서 생기는 마찰력은 다음과 같다.

    F = μN

    여기서 N은 두 차량의 무게의 합이고, μ는 마찰계수이다. 따라서 마찰력은 다음과 같다.

    F = 0.5N

    두 차량이 충돌하면서 생기는 운동량은 보존된다. 따라서 주행차량의 초기 운동량은 다음과 같다.

    mv = (m + m)u

    여기서 v는 충돌 후 두 차량의 속도이고, u는 주행차량의 초기 속도이다. 충돌 후 두 차량이 18m 미끄러져 정지하므로, v는 다음과 같다.

    v^2 = u^2 + 2as
    v^2 = u^2 + 2(18m)(9.8m/s^2)
    v^2 = u^2 + 352.8m^2/s^2
    v = sqrt(u^2 + 352.8m^2/s^2)

    따라서 주행차량의 초기 운동량은 다음과 같다.

    2mu = mv
    2mu = m(sqrt(u^2 + 352.8m^2/s^2))
    4m^2u^2 = m^2(u^2 + 352.8m^2/s^2)
    3m^2u^2 = 352.8m^2/s^2
    u^2 = 352.8m^2/s^2 / 3m^2
    u^2 = 117.6m^2/s^2
    u = sqrt(117.6m^2/s^2) = 10.84m/s

    따라서 주행차량의 초기 속도는 다음과 같다.

    u = 10.84m/s = 38.94km/h

    하지만, 이 문제에서는 주행차량이 50m 거리를 미끄러져 주차한 차량과 충돌했다고 했으므로, 주행차량의 초기 속도는 다음과 같다.

    u = sqrt(2as) = sqrt(2(50m)(9.8m/s^2)) = 31.30m/s = 112.68km/h

    따라서 정답은 "124.5km/h"가 아니라 "113.5km/h"이다.

120. 사고경험에 기초한 사고 위험 지점 선정을 위한 기법 중 사고율 통계적 방법(Rate Quality Control Method)에서는 다음의 식을 사용하는데, 여기서 RC가 의미하는 것은?

  1. 평균사고율
  2. 총교통사고율
  3. 증가사고율
  4. 임계사고율

    RC는 임계사고율(Critical Accident Rate)을 의미한다. 이는 사고가 발생하는 위험성이 높은 지점을 판단하기 위한 기준값으로, 일정 기간 동안 해당 구간에서 발생한 사고 건수를 해당 구간의 교통량으로 나눈 비율을 의미한다. 따라서, 임계사고율이 높을수록 해당 구간에서 사고가 발생할 위험이 높다는 것을 의미한다. 따라서, 정답은 "임계사고율"이다.
