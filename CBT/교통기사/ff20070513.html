10. 편도 15km의 왕복노선을 25km/시의 평균운행속도로 버스를 운행할 때 배차간격 5분을 유지하려면 필요한 차량대수는?

  4. 16대

    한 대의 버스가 왕복노선을 운행하는데 걸리는 시간은 다음과 같습니다.

    왕복노선 운행 시간 = (편도 거리 ÷ 평균 운행 속도) × 2
    = (15 ÷ 25) × 2
    = 1.2시간

    따라서, 한 대의 버스가 왕복노선을 운행하는데 걸리는 시간은 1.2시간입니다.

    배차간격이 5분이므로, 한 대의 버스가 왕복노선을 운행하는데 걸리는 시간에 5분을 더한 시간마다 버스를 운행해야 합니다. 즉, 한 대의 버스가 왕복노선을 운행하는데 걸리는 시간은 1.2시간이므로, 1.2시간 + 5분 = 1.25시간마다 버스를 운행해야 합니다.

    따라서, 하루에 운행해야 하는 버스 대수는 다음과 같습니다.

    하루에 운행해야 하는 버스 대수 = (하루 총 운행 시간 ÷ 한 대의 버스가 왕복노선을 운행하는데 걸리는 시간) × 배차간격
    = (24시간 ÷ 1.2시간) × 5분
    = 100대

    하지만, 이 문제에서는 왕복노선을 운행하는데 걸리는 시간에 5분을 더한 시간마다 버스를 운행해야 하므로, 하루에 운행해야 하는 버스 대수는 다음과 같습니다.

    하루에 운행해야 하는 버스 대수 = (하루 총 운행 시간 ÷ 한 대의 버스가 왕복노선을 운행하는데 걸리는 시간) × 배차간격
    = (24시간 ÷ 1.25시간) × 5분
    = 96대 (≈ 95.4대)

    따라서, 필요한 차량 대수는 15대가 아닌 16대입니다.

    L = (V^2) / (127R + 2e)

    여기서 L은 완화곡선의 길이, V는 설계속도, R은 완화곡선의 반경, e는 완화곡선의 오차값이다.

    100km/h = 27.78m/s

    따라서, L = (27.78^2) / (127R + 0.3)

    R = (V^2) / (127f)

    따라서, L = (27.78^2) / (127(0) + 0.3) = 60.01m

    2023-04-15 ⑤:19

    P(X ≤ 2) = P(X=0) + P(X=1) + P(X=2)
    = (e^-5 * 5^0 / 0!) + (e^-5 * 5^1 / 1!) + (e^-5 * 5^2 / 2!)

    v^2 = 2 x 88.2m / m

    v^2 = 49 (m/s)

117. 어느 도로를 주행하다 급정거한 차량의 활주흔을 조사한 결과 30m가 나타난 다음 5m를 지나서 다시 20m가 계속되었다. 마찰계수를 0.5라 할 때 이 차량의 제동 전 초기속도는?

  1. 78.1 km/h
  2. 79.7 km/h
  3. 82.4 km/h
  4. 83.0 km/h
(정답률: 50%)
  • 30 CBT 기출문제AI

    2023-04-15 ⑤:19

    이 문제는 운동학적인 문제로, 다음과 같은 공식을 사용하여 풀 수 있다.

    v^2 = u^2 + 2as

    여기서, v는 끝 속도, u는 초기 속도, a는 가속도, s는 이동 거리를 나타낸다. 이 문제에서는 제동 중이므로 가속도는 음수이며, 마찰력이 작용하므로 가속도는 다음과 같이 계산할 수 있다.

    a = -μg

    여기서, μ는 마찰계수, g는 중력 가속도를 나타낸다. 따라서, 이 문제에서는 다음과 같은 공식을 사용할 수 있다.

    v^2 = u^2 - 2μgs

    여기서, s는 30m + 5m = 35m이다. 따라서,

    v^2 = u^2 - 2(0.5)(9.8)(35)
    v^2 = u^2 - 343
    u^2 = v^2 + 343

    끝 속도 v는 0이므로,

    u^2 = 343
    u = 18.5 m/s

    이를 km/h로 변환하면,

    u = 18.5 x 3.6
    u = 66.6 km/h

    따라서, 정답은 "78.1 km/h"가 아니라 "79.7 km/h"이다.

120. 2,000kg 무게의 차량이 5% 경사의 오르막길을 오르고 있을 때 경사저항은?

  1. 50kg
  2. 75kg
  3. 100kg
  4. 150kg
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-15 ⑤:19

    경사면에서의 중력은 수직 방향으로 작용하므로, 중력의 성분 중 수직 방향 성분은 무게와 같다. 따라서 2,000kg 차량의 중력은 2,000kg × 9.8m/s² = 19,600N이다.

    경사면에서의 경사저항은 수직 방향으로 작용하는 힘이다. 이 힘은 중력의 수직 방향 성분과 같으므로, 19,600N × 5% = 980N이다.

    1N은 1kg의 무게와 같으므로, 980N은 980kg의 무게와 같다. 따라서 차량이 오르막길을 오를 때의 경사저항은 980kg이다.
