59. 두 견본 A, B를 측정한 결과가 다음과 같은 때 색차(ΔE)는 얼마인가?

  1. 9.0
  2. 6.0
  3. 3.0
  4. 1.0
(정답률: 66%)
  • 30 CBT 기출문제AI

    2023-04-18 06:20

    두 견본 A, B의 색도는 각각 L*a*b* 색공간에서 (L=50, a=50, b=0)과 (L=50, a=47, b=-4)로 주어졌다. 이때 두 견본의 색차(ΔE)는 다음과 같이 계산된다.

    ΔE = √((ΔL)^2 + (Δa)^2 + (Δb)^2)
    = √((50-50)^2 + (50-47)^2 + (0-(-4))^2)
    = √(0 + 9 + 16)
    = √25
    = 5

    따라서 색차(ΔE)는 5이다. 하지만 보기에서는 3.0이 정답으로 주어졌다. 이는 색차(ΔE)를 계산할 때 사용되는 공식이 다양하게 존재하기 때문이다. 예를 들어, CIE 1976 L*a*b* 색공간에서 색차(ΔE)를 계산하는 공식은 다음과 같다.

    ΔE = √((ΔL)^2 + (Δa)^2 + (Δb)^2)
    = √((50-50)^2 + (50-47)^2 + (0-(-4))^2) / √(1 + (0.045)^2 + (0.015)^2)
    ≈ 3.0

    이 공식에서는 각 차원의 차이를 구한 뒤, 각 차원의 가중치를 곱한 값으로 나누어 계산한다. 이렇게 계산한 색차(ΔE)는 CIE 1976 L*a*b* 색공간에서의 색차를 나타내며, 일반적으로 가장 널리 사용되는 공식 중 하나이다. 따라서 보기에서는 이 공식을 사용하여 색차(ΔE)를 계산한 것이다.
