  2. 174mgO2/L
  3. 208mgO2/L
  4. 232mgO2/L
(정답률: 66%)
  • 30 CBT 기출문제AI

    2023-04-16 15:50

    암모니아성 질소와 아질산성 질소는 생물학적 산소요구량(BOD)과 화학적 산소요구량(COD)을 모두 가지고 있으므로, 총 산소요구량(TCOD)을 계산해야 한다.

    TCOD = BOD + COD

    따라서, TCOD = 42mg/L + 14mg/L = 56mg/L 이다.

    따라서, 산소요구량은 56mg/L x 4 = 224mgO2/L 이다.

    보기에서 가장 가까운 값은 "208mgO2/L" 이므로 정답은 "208mgO2/L" 이다.

2. 어떤 폐수의 BOD5가 100mg/L이고, 10을 밑으로 한 탈산소계수(K1)가 0.1/day라면 BOD3 및 BODu는?

  1. BOD3：64mg/L, BODu：123mg/L
  2. BOD3：73mg/L, BODu：126mg/L
  3. BOD3：64mg/L, BODu：143mg/L
  4. BOD3：73mg/L, BODu：146mg/L
(정답률: 85%)
  • 30 CBT 기출문제AI

    2023-04-16 15:55

    BOD3는 3일 동안의 생물학적 산소 요구량을 의미하며, BODu는 무기질화합물을 이용한 생물학적 산소 요구량을 의미한다.

    BOD3를 구하기 위해서는 BOD5를 K1로 나눈 후, 3일 동안의 감소량을 계산해야 한다. 따라서, BOD3 = BOD5 / (1 + K1 x 3) = 100 / (1 + 0.1 x 3) = 73mg/L 이다.

    BODu를 구하기 위해서는 BOD5에서 BOD3을 뺀 후, 이를 1.5배 한 값을 더해준다. 따라서, BODu = (BOD5 - BOD3) x 1.5 + BOD3 = (100 - 73) x 1.5 + 73 = 146mg/L 이다.

    따라서, 정답은 "BOD3：73mg/L, BODu：146mg/L" 이다.

3. 어느 공장에서 BOD 200mg/L인 폐수 500m3/day를 BOD 4mg/L, 유량 200,000m3/day의 하천에 방류할 때 합류점의 BOD(mg/L)는?

  1. 4.20
  2. 4.49
  3. 4.72
  4. 4.84
(정답률: 79%)
  • 30 CBT 기출문제AI

    2023-04-16 15:48

    BOD는 유기물의 분해에 의해 생기는 생물학적 산소 요구량을 나타내는 지표이다. 따라서 BOD가 높을수록 물의 오염도가 높다는 것을 의미한다.

    이 문제에서는 BOD 200mg/L인 폐수 500m3/day를 BOD 4mg/L, 유량 200,000m3/day의 하천에 방류할 때 합류점의 BOD를 구하는 문제이다.

    이를 계산하기 위해서는 다음과 같은 공식을 사용한다.

    (원래 BOD x 원래 유량 + 추가 BOD x 추가 유량) ÷ (원래 유량 + 추가 유량) = 합류점 BOD

    여기서 원래 BOD는 200mg/L, 원래 유량은 500m3/day, 추가 BOD는 4mg/L, 추가 유량은 200,000m3/day이다.

    따라서 계산하면 다음과 같다.

    (200mg/L x 500m3/day + 4mg/L x 200,000m3/day) ÷ (500m3/day + 200,000m3/day) = 4.49mg/L

    따라서 정답은 "4.49"이다.

4. Bacteria(C5H7O2N) 10g의 이론적인 COD값(g)은? (단, 반응생성물은 CO2, H2O, NH3이다.)

  1. 10.2
  2. 12.2
  3. 14.2
  4. 16.2
(정답률: 86%)
  • 30 CBT 기출문제AI

    2023-04-16 15:56

    COD란 화학적 산소 요구량(Chemical Oxygen Demand)의 약자로, 물 속에 존재하는 유기물의 양을 측정하는 지표 중 하나이다. COD값은 유기물이 산화될 때 소비되는 산소의 양을 측정하여 구한다.

    Bacteria(C5H7O2N)가 산화될 때 생성되는 반응 생성물은 CO2, H2O, NH3이다. 이 반응식은 다음과 같다.

    C5H7O2N + 5O2 → 5CO2 + 4H2O + NH3

    이 반응식에서 유기물인 Bacteria(C5H7O2N)의 몰질량을 구하면 다음과 같다.

    Bacteria(C5H7O2N)의 몰질량 = 5 × 12.01 + 7 × 1.01 + 2 × 16.00 + 14.01 = 113.14 g/mol

    따라서, 10g의 Bacteria(C5H7O2N)은 몰질량을 구하여 다음과 같이 몰수로 환산할 수 있다.

    10g / 113.14 g/mol = 0.0884 mol

    이제 반응식에서 유기물 1 몰당 소비되는 산소의 몰수를 구해보자. 반응식에서 유기물 1 몰당 소비되는 산소의 몰수는 5 몰이다. 따라서, 0.0884 mol의 유기물이 소비하는 산소의 몰수는 다음과 같다.

    0.0884 mol × 5 mol = 0.442 mol

    마지막으로, 소비된 산소의 몰수를 산소의 몰질량으로 환산하여 COD값을 구할 수 있다. 산소의 몰질량은 32.00 g/mol이다. 따라서, 0.442 mol의 산소가 소비될 때 생성되는 이론적인 COD값은 다음과 같다.

    0.442 mol × 32.00 g/mol = 14.2 g

    따라서, 이 문제에서 정답은 "14.2"이다.

6. CH3COOH 150mg/L를 함유하고 있는 용액의 pH는? (단, CH3COOH의 이온화상수 Ka=1.8 × 10-5)

  2. 3.7
  3. 4.2
  4. 4.7
(정답률: 65%)
  • 30 CBT 기출문제AI

    2023-04-16 15:55

    CH3COOH은 약산이므로 이온화 반응식은 다음과 같다.

    CH3COOH + H2O ⇌ CH3COO- + H3O+

    Ka = [CH3COO-][H3O+]/[CH3COOH]

    Ka = 1.8 × 10-5

    [CH3COOH] = 150mg/L = 0.15g/L

    가정 : [CH3COO-] ≈ [H3O+]

    Ka = [CH3COO-][H3O+]/[CH3COOH]

    1.8 × 10-5 = x2/0.15

    x = [H3O+] = [CH3COO-] = 0.0038M

    pH = -log[H3O+] = -log(0.0038) = 3.7

    따라서, 정답은 "3.7"이다.

    1차 반응속도식은 다음과 같습니다.

    rate = k[A]

    여기서 k는 속도상수, [A]는 반응물의 농도입니다.

    k = 0.1386/day

    ln[A] = -0.1386/day x 5일 + ln[100mg/L]

    ln[A] = ln[70.7mg/L]

    [A] = 70.7mg/L

    따라서 정답은 "70.7 mg/L"입니다.
