6. 하천의 수질이 다음과 같을 때 이 물의 이온강도는?

  1. 0.⑤5
  2. 0.065
  3. 0.075
  4. 0.085
(정답률: 69%)
  • 30 CBT 기출문제AI

    2023-04-16 15:41

    이온강도는 각 이온의 농도와 전하량을 고려하여 계산된 값입니다. 이 문제에서는 다양한 이온들의 농도가 주어졌으므로, 이온강도를 계산할 수 있습니다.

    이온강도를 계산하는 식은 다음과 같습니다.

    이온강도 = Σ (각 이온의 농도 x 전하량의 제곱) / (1 + 상수 x 각 이온의 농도)

    여기서 상수는 이온의 크기와 전하에 따라 달라지는 상수이며, 이 문제에서는 0.1로 가정합니다.

    따라서, 각 이온의 농도와 전하량을 계산하여 이온강도를 구하면 다음과 같습니다.

    Na+ : 0.01 M x (1)^2 = 0.01
    K+ : 0.0⑤ M x (1)^2 = 0.0⑤
    Ca2+ : 0.002 M x (2)^2 = 0.008
    Mg2+ : 0.001 M x (2)^2 = 0.004
    Cl- : 0.02 M x (-1)^2 = 0.02
    SO42- : 0.003 M x (-2)^2 = 0.012
    HCO3- : 0.01 M x (-1)^2 = 0.01

    이를 식에 대입하여 계산하면,

    이온강도 = (0.01 + 0.0⑤ + 0.008 + 0.004 + 0.02 + 0.012 + 0.01) / (1 + 0.1 x (0.01 + 0.0⑤ + 0.008 + 0.004 + 0.02 + 0.012 + 0.01))
    = 0.075

    따라서, 이 문제에서 물의 이온강도는 0.075입니다.
