11. Bacteria(C5H7O2N) 18g의 이론적인 COD(g)는? (단, 질소는 암모니아로 분해됨을 기준)

  2. 약 28.8
  3. 약 32.3
  4. 약 37.5
(정답률: 63%)
  • 30 CBT 기출문제AI

    2023-04-16 15:33

    Bacteria(C5H7O2N)의 이론적인 COD(g)는 다음과 같이 계산할 수 있다.

    1. Bacteria(C5H7O2N)의 분자량 계산

    C: 5 x 12.01 = 60.⑤
    H: 7 x 1.01 = 7.07
    O: 2 x 16.00 = 32.00
    N: 1 x 14.01 = 14.01

    총 분자량 = 60.⑤ + 7.07 + 32.00 + 14.01 = 113.13 g/mol

    2. Bacteria(C5H7O2N)의 이론적인 COD(g) 계산

    Bacteria(C5H7O2N)의 이론적인 COD(g)는 분자량을 4로 나눈 값과 질소가 암모니아로 분해될 때 생성되는 COD(g)를 더한 값이다.

    따라서, Bacteria(C5H7O2N)의 이론적인 COD(g) = 28.28 + 2.29 = 30.57

  4. 100만원 이하
