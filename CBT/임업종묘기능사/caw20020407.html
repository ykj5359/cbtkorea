  1. 66.6%
  2. 72.4%
  3. 76.9%
  4. 81.4%
(정답률: 64%)
  • 30 CBT 기출문제AI

    2023-04-12 17:24

    효율은 (제거한 후 중량 ÷ 원래 중량) × 발아율로 계산할 수 있습니다.

    따라서, (24.49 ÷ 27.70) × 87% = 0.869 × 0.884 = 0.769 또는 76.9%가 됩니다.

    즉, 협잡물을 제거한 후의 종자 중량은 원래 중량의 약 88.4%이며, 이 중에서 87%가 발아했으므로 전체적인 효율은 76.9%가 됩니다.

  3. 25.5%
  4. 35.5%
(정답률: 80%)

    2023-04-12 17:24

    정삼각형의 넓이는 한 변의 길이를 a라고 하면 (a^2 * √3) / 4 이고, 정사각형의 넓이는 한 변의 길이를 a라고 하면 a^2 이다.

    따라서, 정삼각형 식재와 정사각형 식재의 넓이 비율은 다음과 같다.

    (a^2 * √3) / 4 : a^2

    = √3 / 4 : 1

    ≈ 1.732 / 4 : 1

    ≈ 0.433 : 1

    즉, 정삼각형 식재는 정사각형 식재보다 약 43.3% 더 많은 면적을 차지한다.

    (a * √3 / 2) / a : a / a

    = √3 / 2 : 1

    ≈ 1.732 / 2 : 1

    ≈ 0.866 : 1

    즉, 한변의 길이가 같은 정삼각형 식재는 한 변의 길이가 같은 정사각형 식재보다 약 13.4% 더 긴 변을 가지므로, 면적 비율에서는 약 43.3% 더 많은 면적을 차지하지만, 실제로 필요한 면적에서는 약 13.4% 더 많은 식재가 필요하다.

    이유는 다음과 같습니다. 먼저, 각 대립유전자가 가지는 특성을 A와 a로 나타내겠습니다. 이 때, A와 a는 서로 상호작용하여 표현형을 결정합니다.

    - AA : Aa : aa = 1 : 2 : 1

    이 때, 각각의 개체는 두 개의 대립유전자를 가지므로, 두 번째 대립유전자도 Aa 형태를 가진다고 가정합니다. 따라서, F2 세대에서는 다음과 같은 분리비가 나타납니다.

    - AA : Aa : Aa : aa = 1 : 2 : 1 : 1
