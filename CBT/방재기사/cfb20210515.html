  4. 15.21

    코일러-쿨롱 공식은 다음과 같다:

    tan(φ) = (1 - sin(φ)) / (1 + sin(φ))

    여기서, φ는 내부마찰각을 라디안으로 변환한 값이다.

    φ = tan-1(tan(10)) ≈ 0.1745 라디안

    다음으로, 사면의 안정성을 판단하는 공식은 다음과 같다:

    H = (2C / γ) * (tan(φ) / (1 - sin(φ)))

    따라서, 주어진 조건에서 H를 계산하면:

    H = (2 * 1.0 / 1.8) * (tan(0.1745) / (1 - sin(0.1745))) ≈ 14.41m

    따라서, 정답은 "14.41"이다.
