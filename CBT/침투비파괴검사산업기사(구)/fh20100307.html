80. AW200(A)인 교류용접기를 사용할 때, 무부하 전압은 80V, 아크 전압이 30V일 경우 역률과 효율은? (단, 내부 손실은 4kW이다.)

  1. 역율 : 62.5% 효율 : 60%
  2. 역율 : 30% 효율 : 25%
  3. 역율 : 80% 효율 : 90%
  4. 역율 : 84.4% 효율 : 75%
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-18 19:53

    역률은 유효전력과 피상전력의 비율을 나타내는 값이다. 유효전력은 실제로 작업을 하는데 사용되는 전력이고, 피상전력은 전체적으로 사용되는 전력이다. 따라서 역률이 높을수록 실제로 작업을 하는데 사용되는 전력이 많아지므로 효율도 높아진다.

    무부하 전압이 80V이므로, 피상전력은 80V x 200A = 16kW이다. 내부 손실이 4kW이므로, 유효전력은 16kW - 4kW = 12kW이다. 아크 전압이 30V이므로, 아크 전류는 (80V - 30V) / 200Ω = 0.25A이다. 따라서 역률은 12kW / (80V x 0.25A) = 0.625 = 62.5%이다.

    효율은 유효전력 / 피상전력으로 계산할 수 있다. 따라서 효율은 12kW / 16kW = 0.75 = 75%이다. 하지만, 문제에서는 내부 손실이 4kW이므로, 실제로 출력되는 전력은 12kW - 4kW = 8kW이다. 따라서 효율은 8kW / 16kW = 0.5 = 50%이다. 따라서 보기에서 정답은 "역율 : 62.5% 효율 : 60%"이다.
