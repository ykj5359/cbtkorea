15. 부피로는 메탄 80%, 에탄 15%, 프로판 4%, 부탄1%인 혼합기체가 있다. 이 기체이 공기 중에서의 폭발한계는 약 몇 vol%인가? (단, 공기 중 단일 가스의 폭발하한계는 메탄 5vol%, 에탄 2vol%, 프로판 2vol%, 부탄 1.8vol%이다.)

  2. 3.8
  3. 4.9
  4. 6.2
(정답률: 76%)
  • 30 CBT 기출문제AI

    2023-04-16 08:22

    혼합기체의 폭발한계는 각 가스의 폭발한계와 비례하여 결정된다. 따라서 이 문제에서는 각 가스의 부피 비율과 폭발한계를 고려하여 계산해야 한다.

    먼저, 각 가스의 부피 비율을 계산해보자.

    - 메탄: 80% = 0.8
    - 에탄: 15% = 0.15
    - 프로판: 4% = 0.04
    - 부탄: 1% = 0.01

    이제 각 가스의 폭발한계와 부피 비율을 고려하여 폭발한계 범위를 계산해보자.

    - 메탄: 5vol% ~ 15vol%
    - 폭발한계 범위: 10vol%
    - 혼합기체에서의 폭발한계 범위: 0.8 x 10vol% = 8vol% ~ 12vol%
    - 에탄: 2vol% ~ 7vol%
    - 폭발한계 범위: 5vol%
    - 혼합기체에서의 폭발한계 범위: 0.15 x 5vol% = 0.75vol% ~ 1.75vol%
    - 프로판: 2vol% ~ 10vol%
    - 폭발한계 범위: 8vol%
    - 혼합기체에서의 폭발한계 범위: 0.04 x 8vol% = 0.32vol% ~ 0.64vol%
    - 부탄: 1.8vol% ~ 8.4vol%
    - 폭발한계 범위: 6.6vol%
    - 혼합기체에서의 폭발한계 범위: 0.01 x 6.6vol% = 0.066vol% ~ 0.132vol%

    따라서, 혼합기체의 폭발한계 범위는 8vol% ~ 12vol%, 0.75vol% ~ 1.75vol%, 0.32vol% ~ 0.64vol%, 0.066vol% ~ 0.132vol% 이다. 이 범위들을 모두 고려하여 최종적인 폭발한계 범위를 계산하면 다음과 같다.

    - 최소 폭발한계: 0.066vol%
    - 최대 폭발한계: 12vol%

    따라서, 혼합기체의 공기 중에서의 폭발한계는 약 0.066vol% ~ 12vol% 이다. 이 중에서 정답은 "3.8"이다.

  3. 0.31
  4. 1.25
(정답률: 36%)

    2023-04-16 08:22

    구리선의 저항은 다음과 같은 식으로 구할 수 있다.

    R = ρ * L / A

    여기서 R은 저항, ρ는 고유저항, L은 길이, A는 단면적이다. 이 식에서 L과 A는 변하지 않기 때문에, 주어진 문제에서는 ρ가 변하는 것이다.

    0.25 = 0.0043 * L / A
    A = 0.0043 * L / 0.25

    R' = ρ' * L / A

    R' = 0.0043 * L / A' = R * (1 + αΔT)
    A' = 0.0043 * L / R' = A * (1 + αΔT)
    ρ' = ρ * (1 + αΔT)

    여기서 α는 선도마늘의 온도계수이고, ΔT는 온도 변화량이다. 구리의 경우 α는 0.00393이다.

    주어진 문제에서는 ΔT가 60도이므로,

    ρ' = 0.0043 * (1 + 0.00393 * 60) = 0.0⑤5

    따라서, 주위온도가 75도일 때의 저항은 다음과 같다.

    R' = 0.0⑤5 * L / A = 0.0⑤5 * L / (0.0043 * L / 0.25) = 0.32

    따라서, 가장 가까운 값은 0.31이다.
