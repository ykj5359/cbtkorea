3. 다음 중 컴퓨터의 처리 속도 단위를 빠른 순서부터 나열한 것은?

  1. ms - ㎲ - ns - ps
  2. ps - ns - ㎲ - ms
  3. ㎲ - ps - ms - ns
  4. ns - ms - ps - ㎲
(정답률: 83%)
  • 30 CBT 기출문제AI

    2023-04-12 08:49

    정답은 "ps - ns - ㎲ - ms" 입니다.

    처리 속도의 단위는 초당 처리하는 연산의 개수를 나타내는 것으로, 단위가 작을수록 빠른 속도를 의미합니다.

    - ps (피코초) : 1/1조초 (10^-12 초)
    - ns (나노초) : 1/10억초 (10^-9 초)
    - ㎲ (마이크로초) : 1/100만초 (10^-6 초)
    - ms (밀리초) : 1/1000 초

    따라서, ps가 가장 작은 단위이므로 가장 빠른 속도를 나타내며, 그 다음으로 ns, ㎲, ms 순으로 나열됩니다.
