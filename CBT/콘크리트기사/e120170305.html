    체가름 시험결과에서 굵은 골재의 최대치수(Gmax)는 25mm이다. 이 값을 이용하여 굵은 골재의 조립률(FM)을 구하면 다음과 같다.

    FM = (무게합 ÷ 부피합) × (1000 ÷ 밀도)

    무게합 = 1000g + 1000g + 1000g = 3000g
    부피합 = 420cm³ + 420cm³ + 420cm³ = 1260cm³
    밀도 = 2.7g/cm³

    FM = (3000 ÷ 1260) × (1000 ÷ 2.7) ≈ 7.11

    따라서, 굵은 골재의 최대치수(Gmax)조립률(FM)은 "25mm, 7.11"이다.

61. 복철근 콘크리트 단면에 압축철근비 ρ'=0.015가 배근된 경우 순간처짐이 30mm일 때, 1년이 지난 후의 전체 처짐량은? (단, 작용하중은 지속하중이며 시간경과계수 ξ=1.4임)

  1. 24mm
  2. 30mm
  3. 42mm
  4. 54mm
(정답률: 47%)
  • 30 CBT 기출문제AI

    2023-04-18 12:55

    초기 순간처짐이 30mm이므로, 이를 이용하여 단면의 굽힘응력을 구할 수 있다.

    순간처짐 = (굽힘모멘트) / (2차모멘트)

    30 = (M) / (1/12bh^3)

    M = 1/12bh^3 * 30 = 2.5bh^3

    여기서, 압축철근비 ρ' = 0.015 이므로, 단면의 굽힘중심축까지의 거리 c는 다음과 같다.

    c = h/2 - (ρ' * h * d') / (1 - ρ')

    여기서, d'는 압축철근의 직경이다.

    c = h/2 - (0.015 * h * d') / (1 - 0.015)

    전체 처짐량은 시간경과계수 ξ를 고려하여 다음과 같이 구할 수 있다.

    전체 처짐량 = (순간처짐 * ξ) + (지속하중 * t * ξ / (EA))

    여기서, E는 콘크리트의 탄성계수, A는 단면의 면적이다.

    지속하중은 압축철근의 잔류응력으로, 다음과 같이 구할 수 있다.

    지속하중 = (압축철근의 항복응력) * (압축철근의 면적) / (콘크리트의 항복응력)

    압축철근의 항복응력은 다음과 같다.

    fy = 0.85 * f'c / γs

    여기서, f'c는 콘크리트의 고강도압축강도, γs는 강도감소계수이다.

    콘크리트의 항복응력은 다음과 같다.

    fyt = 0.69 * fy

    따라서, 지속하중은 다음과 같다.

    지속하중 = (0.69 * fy * As) * (d' / (1 - ρ')) / (0.85 * f'c)

    여기서, As는 압축철근의 면적이다.

    전체 처짐량을 구하기 위해 필요한 모든 값들을 구했으므로, 이를 대입하여 계산하면 다음과 같다.

    전체 처짐량 = (30 * 1.4) + ((0.69 * fy * As) * (d' / (1 - ρ')) / (0.85 * f'c) * 365 * 24 * 3600 * 1.4 / (E * A))
