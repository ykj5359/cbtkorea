    원래 잔골재 체적 = 수정된 잔골재 체적 / (1 - 잔골재 5mm체 잔류율)

    시방배합 체적 = 잔골재량 + 굵은골재량

    수정된 잔골재 체적 = (잔골재량 + 굵은골재량) - 굵은골재 체적

    수정된 잔골재량 = 원래 잔골재 체적 / (1 - 굵은골재 5mm체 통과율)

    원래 잔골재 체적 = (770 + 950) / (1 - 0.04) - 950 = 15750

    따라서, 입도보정에 의한 잔골재량은 약 772.5kg/m3이다.

    Na2O의 몰 질량 = 23.0 x 2 + 16.0 = 62.0 g/mol

    인장철근의 기본 정착길이는 다음과 같이 계산할 수 있다.

    Idb = (fck / 2fu) x D

    여기서, fck는 콘크리트의 허용 인장강도, fu는 철근의 극한 인장강도, D는 철근의 공칭지름이다.

    Idb = (26 / 2x400) x 25.4 = 0.331mm

    즉, 인장철근 D25의 기본 정착길이는 0.331m 또는 331mm이다.

    하지만, 실제 현장에서는 보통 안전성을 고려하여 기본 정착길이의 1.5배 이상을 적용한다. 따라서, 정답은 0.331 x 1.5 = 0.4965m 또는 496.5mm이다.
