1. 15Kw의 전동기로 12m/min의 속도로 권상할 경우 권상하중은? (단, 전동기를 포함한 크레인의 효율은 65%이다.)

  1. 5ton
  2. 10ton
  3. 15ton
  4. 20ton
(정답률: 40%)
  • 30 CBT 기출문제AI

    2023-04-12 20:14

    전동기의 출력은 15kW이므로, 크레인의 효율이 65%이므로 실제로 사용 가능한 출력은 15kW x 0.65 = 9.75kW입니다.

    속도는 12m/min이므로, 이에 필요한 힘은 다음과 같습니다.

    힘 = (중량) x (중력가속도) x (속도)

    여기서 중력가속도는 9.8m/s^2입니다.

    따라서,

    (중량) = (힘) / (중력가속도 x 속도)

    = (9.75kW) / (9.8m/s^2 x 12m/min x 60s/min)

    = 5.01ton

    따라서, 권상하중은 약 5ton입니다.
