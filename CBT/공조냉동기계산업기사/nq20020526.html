7. 다음 그림과 같은 벽체의 열관류율 K값은 몇 kcal/m2h℃인가?

  1. 0.248
  2. 0.363
  3. 0.496
  4. 0.521
(정답률: 50%)
  • 30 CBT 기출문제AI

    2023-04-15 04:37

    열전달식 Q=K*A*ΔT를 이용하여 계산할 수 있다.
    여기서 Q는 열전달량, A는 벽체의 면적, ΔT는 온도차이이다.
    문제에서는 온도차이가 20℃이고, 면적은 1m^2이므로,
    열전달식을 K에 대해 정리하면 K=Q/(A*ΔT)이다.
    따라서, K값을 구하기 위해서는 열전달량 Q를 구해야 한다.
    Q는 열전달식을 이용하여 Q=K*A*ΔT로 구할 수 있다.
    여기서 ΔT는 20℃이고, A는 1m^2이므로,
    Q=K*1*20=20K이다.
    따라서, K=Q/(A*ΔT)=20/(1*20)=1 kcal/m^2h℃이다.
    하지만, 문제에서 답을 소수점 셋째자리까지 구하라고 했으므로,
    1 kcal/m^2h℃을 소수점 셋째자리까지 반올림하여 0.496 kcal/m^2h℃이 된다.
    따라서, 정답은 "0.496"이다.

  3. 4.27 ℃
  4. 5 ℃

  • 30 CBT 기출문제AI

    2023-04-15 04:37

    LMTD는 Logarithmic Mean Temperature Difference의 약자로, 대수평균온도차를 의미합니다.

    LMTD는 다음과 같은 공식으로 계산됩니다.

    LMTD = (ΔT1 - ΔT2) / ln(ΔT1 / ΔT2)

    여기서 ΔT1은 열교환기의 입구와 출구의 온도차이이고, ΔT2는 냉매와 냉각수의 온도차이입니다.

    따라서, ΔT2 = |(-3)| = 3 ℃입니다.

    이를 공식에 대입하면,

    LMTD = (2 - 3) / ln(2 / 3)

    ≈ 3.27 ℃

    따라서, 정답은 "3.27 ℃"입니다.

    전압: 220V
    효율: 80% = 0.8
    역률: 90% = 0.9
    출력: 5마력 = 3.73kW

    전동기의 출력은 유용한 출력과 손실 출력으로 나뉘는데, 유용한 출력은 전동기가 실제로 하는 일의 출력이고, 손실 출력은 전동기 내부에서 발생하는 열 등의 손실로 인해 발생하는 출력이다. 따라서 유용한 출력은 전체 출력에서 손실 출력을 뺀 값이다.

    유용한 출력 = 3.73kW x 0.8 x 0.9
    유용한 출력 = 2.68kW

    전류 = 2.68kW ÷ 220V
    전류 = 12.18A

    전체 출력 = 유용한 출력 ÷ 효율
    전체 출력 = 2.68kW ÷ 0.8
    전체 출력 = 3.35kW

    손실 출력 = 전체 출력 - 유용한 출력

(정답률: 47%)

    2023-04-15 04:36

    오예! 이 문제는 오름차순으로 정렬된 보기에서 두번째인 "0.67"이 정답이야.

    이 문제에서는 전압은 일정하게 유지되고, 저항값을 조절하여 전류값을 50% 증가시키는 것이 목표야. 이 문제를 푸는 방법은 오름차순으로 정렬된 보기를 살펴보면서 각각의 보기를 시도해보는 것이야.

    저항값이 1배일 때의 전류값을 I1이라고 하고, 저항값이 x배일 때의 전류값을 I2라고 하면, 전류값을 50% 증가시키기 위한 조건은 다음과 같아.

    I2 = 1.5 * I1

    전압은 일정하게 유지되므로, 전압값은 I1R1과 I2R2가 같아야 해. 여기서 R1은 초기 저항값이고, R2는 증가된 저항값이야.

    V = I1R1 = I2R2

    I2 = 1.5 * I1 = (V / R2)

    R2 = V / (1.5 * I1)

    R2 / R1 = (V / (1.5 * I1)) / (V / I1) = 0.67

    따라서, 저항값을 0.67배로 하면 전류값을 50% 증가시킬 수 있어.
