9. 31℃의 외기와 25℃의 환기를 1 : 2의 비율로 혼합하고 바이패스 팩터가 0.16인 코일로 냉각 제습할 때 코일 출구온도(℃)는? (단, 코일의 표면온도는 14℃ 이다.)

  2. 16
  3. 27
  4. 29
(정답률: 60%)
  • 30 CBT 기출문제AI

    2023-04-15 04:11

    바이패스 팩터(Bypass Factor)는 냉각 코일을 통과하는 공기 중 일부가 코일을 우회하여 직접 냉각되지 않고 바이패스 되는 비율을 나타내는 값입니다. 따라서 바이패스 팩터가 작을수록 냉각 효율이 높아지며, 바이패스 팩터가 0이면 모든 공기가 코일을 통과하여 냉각됩니다.

    이 문제에서는 외기와 환기를 1:2의 비율로 혼합하여 사용하므로, 혼합 공기의 온도는 (31+25+25)/3 = 27℃ 입니다. 이 혼합 공기가 코일을 통과하면서 냉각되므로, 코일 출구온도는 27℃보다는 낮아질 것입니다.

    코일의 표면온도는 14℃이므로, 혼합 공기가 코일을 통과하면서 27℃에서 14℃로 냉각됩니다. 이때 바이패스 팩터가 0.16이므로, 코일을 통과하는 공기 중 84%가 직접 냉각되고, 나머지 16%는 바이패스 되어 냉각되지 않습니다.

    따라서, 코일 출구온도는 27℃에서 84%만큼 냉각된 값인 27 - 0.84 x (27-14) = 16℃이 됩니다. 따라서 정답은 "16"입니다.

10. 습공기 5000 m3/h를 바이패스 팩터 0.2인 냉각코일에 의해 냉각시킬 때 냉각코일의 냉각열량(kW)은? (단, 코일 입구공기의 엔탈피는 64.5 kJ/kg, 밀도는 1.2 kg/m3, 냉각코일 표면온도는 10℃이며, 10℃의 포화습공기 엔탈피는 30 kJ/kg 이다.)

    냉각코일에 의해 냉각되는 공기의 엔탈피 변화량은 다음과 같다.

    ∆h = 입구공기 엔탈피 - 출구공기 엔탈피

    입구공기 엔탈피는 문제에서 주어졌으므로, 출구공기 엔탈피를 구하면 된다. 출구공기의 상태는 냉각코일에 의해 냉각되므로, 냉각코일의 표면온도와 공기의 상대습도를 이용하여 포화습공기의 엔탈피를 구하고, 이를 이용하여 출구공기의 엔탈피를 계산할 수 있다.

    냉각코일의 표면온도는 10℃이므로, 냉각되는 공기의 온도도 10℃일 것이다. 따라서, 출구공기의 상대습도를 구하기 위해서는 냉각코일의 표면온도와 포화습공기의 온도(10℃)를 이용하여 포화수증기압을 구해야 한다.

    포화수증기압은 표준 상태에서의 수증기압과 같은 방식으로 계산할 수 있다.

    포화수증기압 = 610.78 * exp(17.27 * 10 / (237.3 + 10)) = 1228.5 Pa

    따라서, 냉각코일에 의해 냉각된 공기의 상대습도는 다음과 같다.

    상대습도 = (배기수증기압 / 포화수증기압) * 100% = (1 - 바이패스 팩터) * 100% = 80%

    냉각된 공기의 밀도는 1.2 kg/m^3이므로, 냉각코일을 통과한 공기의 질량유량은 다음과 같다.

    질량유량 = 부피유량 * 밀도 = 5000 * 1.2 / 3600 = 16.67 kg/s

    따라서, 출구공기의 엔탈피는 다음과 같다.

    출구공기 엔탈피 = 입구공기 엔탈피 - ∆h = 64.5 - (16.67 * (64.5 - 30) / 3600) = 61.8 kJ/kg

    냉각코일에 의해 냉각된 공기의 냉각열량은 다음과 같다.

    냉각열량 = 질량유량 * (입구공기 엔탈피 - 출구공기 엔탈피) / 1000 = 16.67 * (64.5 - 61.8) / 1000 = 0.045 kW

    먼저, 수증기의 분압과 대기압의 합이 전체 대기압과 같다는 것을 이용하여 수증기의 분압을 구해보자.

    전체 대기압 = 수증기의 분압 + 건조공기의 분압

    100 kPa = 1.5 kPa + 건조공기의 분압

    건조공기의 분압 = 100 kPa - 1.5 kPa = 98.5 kPa

    절대습도 = 0.015 / (1 - 0.015) = 0.015 / 0.985 = 0.015228

    따라서, 주어진 보기에서 정답은 0.0095 이다.

    감쇠율은 진동 시스템(예: 스프링, 전기 회로 등)이 얼마나 빠르게 진정되는지를 나타내는 값이에요.

    여기서:
