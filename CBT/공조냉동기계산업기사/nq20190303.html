    송풍기(팬)의 유사 법칙 정리:

    1. 유량(Q) 은 회전수(N) 또는 임펠러 직경(d)에 비례

    Q2 = Q1 × (N2 / N1)

    Q2 = Q1 × (d2 / d1)



    2. 정압(P) 은 회전수(N)의 제곱 또는 직경(d)의 제곱에 비례

    P2 = P1 × (N2 / N1)²

    P2 = P1 × (d2 / d1)²





    ---

    선택지 검토:

    1. 1번: Q2 = (N2 / N1) × Q1 → 맞음


    2. 2번: Q2 = (d2 / d1)³ × Q1 → 틀림 (유량은 직경에 1차 비례)


    3. 3번: P2 = (N2 / N1)³ × P1 → 틀림 (압력은 회전수에 2차 비례)


    4. 4번: P2 = (d2 / d1)² × P1 → 맞음



    결론: 정답은 3번 (틀린 공식).
