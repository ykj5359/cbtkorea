2. 건구온도 32℃, 절대습도 0.02kg/kg의 공기 5000CMH와 건구온도 25℃, 절대습도 0.002kg/kg 의 공기 10000CMH가 혼합 되었을 때 건구온도는 약 몇 ℃인가?

  1. 25.6℃
  2. 27.3℃
  3. 28.3℃
  4. 29.6℃
(정답률: 60%)
  • 30 CBT 기출문제AI

    2023-04-15 04:24

    혼합 공기의 건구온도는 각각의 공기의 건구온도와 비례적으로 결정된다. 따라서, 건구온도가 높은 공기의 비중이 높을수록 혼합 공기의 건구온도는 높아진다.

    먼저, 건구온도 32℃, 절대습도 0.02kg/kg의 공기 5000CMH와 건구온도 25℃, 절대습도 0.002kg/kg의 공기 10000CMH가 혼합되었을 때, 두 공기의 비중은 다음과 같다.

    - 건구온도 32℃, 절대습도 0.02kg/kg의 공기: 5000 / (5000 + 10000) = 0.333
    - 건구온도 25℃, 절대습도 0.002kg/kg의 공기: 10000 / (5000 + 10000) = 0.667

    따라서, 혼합 공기의 건구온도는 다음과 같이 계산할 수 있다.

    (32℃ x 0.333) + (25℃ x 0.667) = 27.3℃

    따라서, 정답은 "27.3℃"이다.
