10. 심전도 기록지 속도가 50[mm/s]일 때 평균 RR 간격이 10[mm]일 경우의 심박수는?

  1. 100[BPM]
  2. 150[BPM]
  3. 200[BPM]
  4. 300[BPM]
(정답률: 65%)
  • 30 CBT 기출문제AI

    2023-04-12 17:14

    심전도 기록지 속도가 50[mm/s]이므로 1초 동안 50[mm]의 거리를 기록합니다. 따라서 10[mm]의 RR 간격은 0.2초를 의미합니다. 이를 1분으로 환산하면 0.2초 동안의 심박수가 몇 번인지 계산할 수 있습니다.

    1분 = 60초
    0.2초 동안의 심박수 = 1 / 0.2 = 5번
    1분 동안의 심박수 = 5 x 60 = 300[BPM]

    따라서 정답은 "300[BPM]"입니다.
1

60. 프로그램은 여러 개의 부 프로그램으로 이루어지는데 자주 수행되는 작업을 단위 프로그램으로 독립시킨 후 메인루틴(Main-Routine)이나 다른 부 프로그램에서 필요할 경우 호출하는 프로그래밍 기법은?

  1. 루핑(Looping)
  2. 라이브러리(Library)
  3. 서브루틴(Sub-Routine)
  4. 구조적 프로그래밍(Structured Programming)
(정답률: 80%)
  • 30 CBT 기출문제AI

    2023-04-12 17:14

    프로그램을 여러 개의 부분으로 나누어 작성하면 코드의 재사용성이 높아지고 유지보수가 용이해집니다. 이때 자주 수행되는 작업을 독립시킨 부분을 서브루틴이라고 합니다. 서브루틴은 메인루틴이나 다른 부 프로그램에서 필요할 때 호출되어 실행되며, 실행이 끝나면 호출한 곳으로 돌아갑니다. 이러한 서브루틴을 이용하면 코드의 중복을 줄이고 프로그램의 구조를 보다 명확하게 만들 수 있습니다. 따라서 정답은 "서브루틴(Sub-Routine)"입니다.
