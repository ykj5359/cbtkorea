2. 렌터블 비(rentable ratio)가 75%이고, 대실면적이 6000m2인 사무소의 연면적은 얼마인가?

  1. 4500m2
  2. 6000m2
  3. 8000m2
  4. 1⑤00m2
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-14 19:14

    렌터블 비가 75%이므로, 대실면적의 75%가 실제 임대 가능한 면적이다. 따라서, 임대 가능한 면적은 6000m2 x 0.75 = 4500m2 이다.

    하지만, 문제에서 묻는 것은 연면적이므로, 임대 가능한 면적 이외에도 공용면적 등이 포함된 전체 면적을 구해야 한다.

    임대 가능한 면적이 4500m2 이므로, 임대 가능한 면적의 비율은 4500m2 / 전체 면적 이다. 이를 식으로 나타내면,

    75% = 4500m2 / 전체 면적

    전체 면적 = 4500m2 / 0.75

    전체 면적 = 6000m2 / 0.75

    전체 면적 = 8000m2

    따라서, 정답은 "8000m2" 이다.
