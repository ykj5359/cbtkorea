    (m1 x h1) + (m2 x h2) = (m1 + m2) x h3

    여기서, m은 각각의 공기의 질량, h는 각각의 공기의 엔탈피를 나타냅니다. 건구온도가 주어졌으므로, 엔탈피는 다음과 같이 구할 수 있습니다.

    h = cp x T

    (m1 x T1) + (m2 x T2) = (m1 + m2) x T3

    여기서, T1은 26℃, T2는 32℃입니다. 질량은 부피와 밀도를 이용하여 구할 수 있습니다.

    m = V x ρ
