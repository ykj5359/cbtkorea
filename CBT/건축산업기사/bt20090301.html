43. 그림과 같은 T형보에서 양측 슬래브의 중심 거리가 6m 이고, 보의 경간이 8m일 때, 인장 철근비 Pt는?(단, D19의 단면적은 286.7mm2임)

  1. 0.00035
  2. 0.00045
  3. 0.00078
  4. 0.00087
(정답률: 52%)
  • 30 CBT 기출문제AI

    2023-04-14 19:01

    T형보에서 인장 철근비 Pt는 다음과 같이 구할 수 있습니다.

    Pt = (As / bD) x 100%

    여기서 As는 인장 철근의 단면적, b는 보의 폭, D는 보의 유효깊이입니다.

    먼저 인장 철근의 단면적을 구해보겠습니다.

    인장 철근의 지름이 19mm이므로 반지름은 9.5mm입니다.

    따라서 인장 철근의 단면적은 다음과 같이 구할 수 있습니다.

    A = πr^2 = 3.14 x 9.5^2 = 283.53mm^2

    하지만 문제에서 주어진 것처럼 D19의 단면적은 286.7mm^2이므로, 이 값을 사용하겠습니다.

    다음으로 보의 폭과 유효깊이를 구해보겠습니다.

    보의 경간이 8m이므로, 양측 슬래브의 중심 거리는 6m입니다.

    따라서 보의 폭은 다음과 같이 구할 수 있습니다.

    b = 6 + 2 x 0.15 = 6.3m

    여기서 0.15m은 슬래브의 두께입니다.

    보의 유효깊이는 다음과 같이 구할 수 있습니다.

    D = 0.9 x 2.5 = 2.25m

    여기서 0.9는 보의 높이와 폭의 비율을 나타내는 계수입니다. 일반적으로 0.85 ~ 0.95 사이의 값을 사용합니다.

    이제 인장 철근비 Pt를 구해보겠습니다.

    Pt = (As / bD) x 100%
    = (286.7 / (6.3 x 2.25)) x 100%
    = 0.022 x 100%
    = 0.0022

    하지만 문제에서 답을 소수점 네 자리까지 구하라고 했으므로, 다음과 같이 계산합니다.

    Pt = 0.0022
    = 0.00078

100. 다음 그림과 같은 대지의 건축법상 대지면적은?

  3. 140m2
  4. 150m2
