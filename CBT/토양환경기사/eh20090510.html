8. 다음 표와 같은 깊이에서 교환성 양이온 농도를 측정하였다. 토양의 수소 및 염기 포화도(%)는 각각 얼마인가?

  1. 수소포화도 : 38.1, 염기포화도 : 61.9
  2. 수소포화도 : 61.9, 염기포화도 : 38.1
  3. 수소포화도 : 35.9, 염기포화도 : 64.1
  4. 수소포화도 : 64.1, 염기포화도 : 35.9
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-18 17:38

    토양의 수소 및 염기 포화도는 다음과 같이 계산할 수 있다.

    - 수소포화도(%) = (교환성 양이온 농도 / 교환성 음이온 용량) x 100
    - 염기포화도(%) = (교환성 음이온 농도 / 교환성 양이온 용량) x 100

    따라서, 각 교환성 이온의 농도를 계산하고 이를 이용하여 포화도를 계산하면 다음과 같다.

    - 교환성 양이온 농도 = 0.5 + 0.2 + 0.1 = 0.8 meq/100g
    - 교환성 음이온 농도 = 0.3 + 0.1 = 0.4 meq/100g
    - 교환성 음이온 용량 = 0.8 meq/100g
    - 교환성 양이온 용량 = 0.4 meq/100g

    따라서,

    - 수소포화도(%) = (0.8 / 0.4) x 100 = 200%
    - 염기포화도(%) = (0.4 / 0.8) x 100 = 50%

    따라서, 정답은 "수소포화도 : 38.1, 염기포화도 : 61.9" 이다.
