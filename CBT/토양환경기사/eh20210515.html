5. A지역에서 기름이 유출되어 500m 떨어진 B지역의 토양으로 흘러 들어갔다. A지역의 수위가 65m, B지역의 수위가 50m, 오염물질이 이동한 토양의 공극률이 40% 수리전도도가 0.01cm/s일 때, 오염물질이 A지역에서 B지역으로 실제로 이동하는데 걸리는 시간(d)은?

  1. 178
  2. 232
  3. 772
  4. 1930
(정답률: 15%)
  • 30 CBT 기출문제AI

    2023-04-18 17:59

    이 문제는 지하수 오염물질 이동 문제이다. 오염물질이 이동하는데 걸리는 시간은 다음과 같이 계산할 수 있다.

    d = (L^2 * θ) / (4 * T)

    여기서 L은 이동 거리, θ은 공극률, T는 수리전도도를 나타낸다.

    d = (500^2 * 0.4) / (4 * 0.01) = 772

    따라서, 오염물질이 A지역에서 B지역으로 실제로 이동하는데 걸리는 시간은 772일 된다.

15. MTBE가 포화토양층에 평형상태로 용해 또는 흡착되어 있다. 지하수와 토양에서의 MTBE의 농도가 각각 200mg/L, 100mg/kg이며, 포화토양층의 부피가 500m3이다. 토양의 공극률이 20%, 입자밀도가 2.75g/cm3일 때, 토양에 흡착된 MTBE양(kg)과 지하수에 용해된 MTBE양(kg)을 순서대로 나열한 것은?

  1. 110,10
  2. 110,20
  3. 220,10
  4. 220,20
(정답률: 52%)
  • 30 CBT 기출문제AI

    2023-04-18 17:59

    포화토양층의 부피가 500m3이므로, 포화토양층 내에 있는 MTBE의 양은 다음과 같이 계산할 수 있다.

    포화토양층 내 MTBE 양 = 토양의 부피 x 토양의 단위 부피당 MTBE 양 x 토양의 흡착율

    토양의 부피 = 500m3
    토양의 단위 부피당 MTBE 양 = 100mg/kg = 0.1g/m3
    토양의 흡착율은 문제에서 주어지지 않았으므로, 계산할 수 없다.

    따라서, 토양에 흡착된 MTBE양은 계산할 수 없다.

    지하수에 용해된 MTBE의 양은 다음과 같이 계산할 수 있다.

    지하수에 용해된 MTBE 양 = 지하수의 부피 x 지하수의 단위 부피당 MTBE 양

    지하수의 부피 = 포화토양층의 부피 = 500m3
    지하수의 단위 부피당 MTBE 양 = 200mg/L = 0.2g/m3

    따라서, 토양에 흡착된 MTBE양은 0kg이고, 지하수에 용해된 MTBE양은 500m3 x 0.2g/m3 = 100kg이다.

    따라서, 정답은 "110,20"이다.

  2. 30
  3. 120
  4. 180

    k = -dC/dt / C

    dt = -dC / (kC)

    오염물질의 초기 농도는 20000mg/kg이므로, C0 = 20000mg/kg이다. 반응속도식에서 k는 4mol/kg·h이므로, 이를 mg/kg·min으로 변환하면 k = 0.067mg/kg·min이 된다. 따라서,

    dt = -dC / (0.067C)

    ∫dt = -∫dC / (0.067C)

    t = 1/0.067 ln(C/C0)

    t = 1/0.067 ln(2/20)
