13. 벤젠이 포화토양층에 평형상태로 용해 또는 흡착되어 있다. 지하수와 토양에서의 벤젠의 농도는 각각 10mg/L, 50mg/kg이며, 포화토양층의 부피는 2500m3이다. 토양 공극률이 0.44, 토양입자밀도가 3.50g/cm3일 경우 토양에 흡착된 벤젠의 양(kg)은?

  1. 215
  2. 225
  3. 235
  4. 245
(정답률: 45%)
  • 30 CBT 기출문제AI

    2023-04-18 18:03

    먼저, 포화토양층의 부피와 토양 공극률, 토양입자밀도를 이용하여 포화토양층의 질량을 구해야 한다.

    포화토양층의 부피 = 2500m3
    토양 공극률 = 0.44
    토양입자밀도 = 3.50g/cm3 = 3500kg/m3

    따라서, 포화토양층의 질량은 다음과 같이 구할 수 있다.

    포화토양층의 질량 = 포화토양층의 부피 x 토양 공극률 x 토양입자밀도
    = 2500m3 x 0.44 x 3500kg/m3
    = 3850000kg

    이제, 토양에 흡착된 벤젠의 양을 구할 수 있다. 흡착된 벤젠의 양은 토양의 총 질량과 토양에서의 벤젠 농도를 이용하여 구할 수 있다.

    흡착된 벤젠의 양 = 포화토양층의 질량 x 토양에서의 벤젠 농도
    = 3850000kg x 50mg/kg
    = 192500000mg
    = 192500g
    = 192.5kg

    따라서, 정답은 "245"이다.
