    2023-04-18 17:58

    Thiem 방정식은 다음과 같다.

    Q = 2πT(h1 - h2) / ln(r2/r1)

    여기서, Q는 유량, T는 대수층의 투수량계수, h1과 h2는 각각 양수정으로부터 10m, 20m 이격된 지점의 수위퍼텐셜, r1과 r2는 각각 양수정으로부터 10m, 20m 이격된 지점까지의 반경이다.

    이 문제에서는 Q, h1, h2가 주어졌으므로, T를 구하기 위해서는 r1과 r2를 구해야 한다.

    r1 = (2A/π + r22)1/2

    r2 = (2A/π)1/2

    여기서, A는 대수층의 단면적이다.

    A = 5 × 2π × r1 = 10πr1

    따라서,

    r1 = (2A/π + r22)1/2 = (20r22 + r24)1/2

    Q = 2πT(h1 - h2) / ln(r2/r1)

    3.0×10-3 = 2πT(12 - 15) / ln(r2/r1)

    ln(r2/r1) = -2.944

    r2/r1 = e-2.944 = 0.⑤2

    r1 = (20r22 + r24)1/2

    0.⑤2r1 = (20r22 + r24)1/2

    0.002704r12 = r24

    r2 = (0.002704r12)1/4

    r2 = 10.6m

    따라서, 대수층의 투수량계수 T는 다음과 같다.

    T = Qln(r2/r1) / 2π(h1 - h2)

    T = 0.08ln(10.6/5.6) / 2π(12 - 15)

    T = 3.0×10-3

    따라서, 정답은 "3.0×10-3"이다.
