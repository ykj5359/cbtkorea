6. 공극률 0.2, 다시안 유속(Darcian velocity) 0.2cm/hr인 포화대수층의 공극에서 실제 지하수가 이동하는 속도(cm/hr)는?

    A(식토)는 입자의 크기가 가장 작아서 표면적이 가장 많이 존재하므로 비표면적이 가장 크다. B(미사)는 입자의 크기가 A보다 크지만 C보다 작아서 비표면적이 중간 정도이다. C(양질사토)는 입자의 크기가 가장 크기 때문에 표면적이 적어 비표면적이 가장 작다.

59. 오염지하수를 2m 두께의 반응벽체로 처리하고자 한다. 지하수Darcy속도가 4m/d인 조건에서 반응벽체 내 체류시간을 6시간으로 설계하고자 할 경우 반응벽체의 공극률은?

  1. 0.40
  2. 0.45
  3. 0.50
  4. 0.55
(정답률: 58%)
  • 30 CBT 기출문제AI

    2023-04-18 17:53

    체류시간은 반응벽체 내에서 오염물질이 머무는 시간을 의미한다. 따라서 체류시간은 반응벽체의 두께와 Darcy속도에 비례한다. 이 문제에서는 체류시간이 6시간이 되도록 반응벽체의 두께를 결정해야 한다.

    체류시간 = 반응벽체 두께 / Darcy속도

    6시간 = 반응벽체 두께 / 4m/d

    반응벽체 두께 = 24m

    반응벽체의 공극률은 반응벽체 내의 빈 공간의 비율을 의미한다. 공극률이 높을수록 반응벽체 내에서 물의 이동이 자유로워지므로 오염물질의 처리 효율이 높아진다. 반면 공극률이 낮을수록 물의 이동이 제한되므로 처리 효율이 낮아진다.

    공극률 = (반응벽체 전체 부피 - 반응벽체 내 고정물질 부피) / 반응벽체 전체 부피

    반응벽체 전체 부피 = 반응벽체 두께 x 단면적

    단면적은 문제에서 주어지지 않았으므로 간단하게 1m²로 가정한다.

    반응벽체 전체 부피 = 24m x 1m² = 24m³

    반응벽체 내 고정물질 부피는 문제에서 주어지지 않았으므로 가정할 수 없다. 따라서 고정물질 부피를 고려하지 않고 공극률을 계산한다.

    공극률 = (반응벽체 전체 부피 - 반응벽체 내 고정물질 부피) / 반응벽체 전체 부피

    공극률 = (24m³ - 0) / 24m³ = 1

    하지만 고정물질이 존재할 경우 실제 공극률은 1보다 작아지므로, 이 문제에서는 보기 중에서 가장 작은 값인 "0.50"이 정답이 된다.
