  2. 26.9
  3. 73.1
  4. 95.0
(정답률: 80%)

    염기포화도(%)는 양이온교환용량 중에서 염기성 이온(Ca2+, Mg2+, K+, Na+)이 차지하는 비율을 나타내는 지표이다. 따라서 염기성 이온의 총 합을 양이온교환용량으로 나눈 후 100을 곱해주면 된다.

    염기성 이온의 총 합 = 40 + 25 + 20 + 10 = 95
    양이온교환용량 = 40 + 25 + 20 + 10 + 15 + 20 = 130

    염기포화도(%) = (95/130) x 100 = 73.1

    따라서 정답은 "73.1"이다.

2. 관정의 직경이 50cm, 수심이 10m인 경우 일정한 유량으로 양정을 할 경우 관정의 수위가 일정시간 경과 후 4m에 도달하였다. 이 때의 관정 유량(m3/sec)은? (단, 관정은 자유수면에 위치, 투수계수=0.1cm/sec, 영향반경 = 1000m)

  1. 0.023
  2. 0.032
  3. 0.048
  4. 0.064
(정답률: 60%)
  • 30 CBT 기출문제AI

    2023-04-18 18:⑤

    이 문제는 다음과 같은 공식을 사용하여 풀 수 있습니다.

    Q = KAΔh

    여기서 Q는 유량, K는 투수계수, A는 관의 단면적, Δh는 수위차이입니다.

    먼저, 관의 단면적을 구해야 합니다. 관의 반지름은 25cm이므로, 단면적은 다음과 같습니다.

    A = πr^2 = 3.14 x 0.25^2 = 0.19625 m^2

    다음으로, 수위차이를 구해야 합니다. 처음 수위는 0m이고, 일정시간 경과 후 수위가 4m가 되었으므로, Δh는 4m입니다.

    마지막으로, 투수계수와 영향반경을 이용하여 K값을 구해야 합니다. 투수계수는 0.1cm/sec이므로, m/sec로 변환하면 0.001m/sec입니다. 영향반경은 1000m이므로, K값은 다음과 같습니다.

    K = 0.001 / 1000 = 0.000001 m/sec

    이제 모든 값을 공식에 대입하여 유량을 구할 수 있습니다.

    Q = KAΔh = 0.000001 x 0.19625 x 4 = 0.000000785 m^3/sec

    소수점을 정리하면, Q는 0.000785 m^3/sec입니다. 이 값을 소수점 네 자리까지 반올림하면 0.032가 됩니다. 따라서 정답은 "0.032"입니다.

5. 지하수의 수리전도도가 2.0×10-3cm/sec이고, 공극비(e : void ratio)가 0.25일 때 지하수의 평균선형유속(cm/sec)은? (단, 동수구배=0.001, Darcuy의 법칙 적용)

  1. 1.0×10-5
  2. 5.0×10-5
  3. 5.0×10-7
  4. 8.0×10-7
(정답률: 41%)
  • 30 CBT 기출문제AI

    2023-04-18 18:⑤

    Darcy의 법칙에 따르면 지하수의 평균선형유속은 다음과 같이 계산할 수 있다.

    Q = KIA

    여기서 Q는 유량, K는 수리전도도, I는 수위경사, A는 횡단면적이다. 공극비는 다음과 같이 정의된다.

    e = Vv / Vs

    여기서 Vv는 공극부피, Vs는 고체부피이다. 공극비는 0.25이므로, 고체부피는 공극부피의 4배이다.

    Vs = 4Vv

    따라서 횡단면적은 다음과 같이 계산할 수 있다.

    A = Vs / L

    여기서 L은 유속의 방향에 수직인 단위길이이다. 이 문제에서는 L=1로 가정한다. 따라서 횡단면적은 다음과 같다.

    A = 4Vv

    수위경사는 유속의 방향에 수직이므로, I=0이다. 따라서 유량은 다음과 같다.

    Q = KIA = 0

    따라서 평균선형유속은 0이다. 따라서 보기에서 정답인 "1.0×10-5"은 올바르지 않다.
