7. 두께가 50mm인 강용접부를 초음파탐상시 [그림]과 같이 CRT 화면에 결함 지시파가 나타났다. 이 때 나타난 결함은 탐상면으로부터 얼마 깊이에 존재하는 결함인가? (단, 탐촉자의 굴절각은 60°이고 CRT 화면에서 시간축은 100mm 로 보정되어 있다.

  1. 10mm
  2. 20mm
  3. 30mm
  4. 40mm
(정답률: 84%)
  • 30 CBT 기출문제AI

    2023-04-12 10:06

    결함 지시파가 나타난 위치에서 탐촉자에서 나가는 파선은 각도 60°로 굴절되어 진행됩니다. 이때 결함 지시파가 나타난 위치에서 탐촉자에서 나가는 파선은 수직으로 진행되어야 합니다. 따라서 결함은 파선이 굴절된 각도만큼 탐상면 아래에 위치하게 됩니다.

    결함 지시파가 나타난 위치에서 CRT 화면까지의 거리는 100mm이므로, 파선이 굴절된 각도가 60°이므로 결함은 100mm * tan(60°) = 173.2mm 아래에 위치합니다.

    하지만 문제에서 묻는 것은 결함이 탐상면으로부터 얼마 깊이에 존재하는가이므로, 결함이 탐상면으로부터의 깊이를 구해야 합니다.

    강재의 초음파 속도는 약 6,000m/s이므로, 50mm 두께를 지나갈 때 걸리는 시간은 50mm / 6,000m/s = 0.0083s입니다.

    결함 지시파가 나타난 위치에서 결함까지의 거리는 CRT 화면에서 결함까지의 거리에서 100mm을 빼면 됩니다. 따라서 결함까지의 거리는 173.2mm - 100mm = 73.2mm입니다.

    결함까지의 거리를 지나는 시간은 0.0083s이므로, 결함까지의 거리를 지나는 속도는 73.2mm / 0.0083s = 8,831.3m/s입니다.

    결함이 탐상면으로부터의 깊이는 속도 * 시간 = 8,831.3m/s * 0.0083s = 73.2mm입니다.

    따라서 정답은 "30mm"입니다.

59. c관리도에서 k=20인 군의 총부적합(결정)수 합계는 58이었다. 이 관리도의 UCL, LCL을 구하면 약 얼마인가?

  1. UCL=6.92, LCL=0
  2. UCL=4.90, LCL=고려하지 않음
  3. UCL=6.92, LCL=고려하지 않음
  4. UCL=8.01, LCL=고려하지 않음
(정답률: 62%)

    2023-04-12 10:06

    c관리도에서 k=20인 군의 총부적합(결정)수 합계가 58이므로, 평균적으로 부적합(결정)수는 2.9개이다. 이 때, 부적합(결정)수는 이항분포를 따르므로, 표준편차는 다음과 같다.

    σ = √(np(1-p)) = √(20×0.145×0.855) ≈ 2.34

    UCL = 2.9 + 3×2.34 ≈ 8.01
    LCL = 2.9 - 3×2.34 ≈ 고려하지 않음
