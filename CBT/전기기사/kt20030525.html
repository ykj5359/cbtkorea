9. 자유공간 중에서 자계 H =xz2a x[A/m]일 때 0 ≤ x ≤ 1, 0≤z≤1, y=0인 면을 통과하는 전전류는 몇 A 인가?

  1. 0.5
  2. 1.0
  3. 1.5
  4. 2.0
(정답률: 31%)

    2023-04-17 15:57

    자유공간에서 전류 밀도는 J = σE 이므로, 전기장 E를 구해야 한다. 자계 H와 전기장 E는 다음과 같은 관계를 가진다.

    H = (1/μ)B = (1/μ)(μ0H + M) = μ0H + J

    E = ρJ

    여기서 ρ는 자유공간의 전기저항률이다. 따라서,

    E = ρ(μ0H + J)

    y=0인 면을 통과하는 전전류는 x 방향으로 흐르는 전류와 z 방향으로 흐르는 전류의 합이다. x 방향으로 흐르는 전류는 Jx = σEx 이고, z 방향으로 흐르는 전류는 Jz = σEz 이다. 따라서,

    전전류 = Jx + Jz = σ(Ex + Ez)

    Ex와 Ez를 구하기 위해 H를 구한다. 자계 H는 다음과 같다.

    H = xz^2aμ0

    따라서,

    μ0H = xz^2aμ0

    J = σ(μ0H + J) = σ(xz^2aμ0 + J)

    E = ρ(μ0H + J) = ρ(xz^2aμ0 + J)

    Ex = E·x/|E| = ρ(xz^2aμ0 + J)·x/|ρ(xz^2aμ0 + J)| = xz^2aμ0 + J/|xz^2aμ0 + J|

    Ez = E·z/|E| = ρ(xz^2aμ0 + J)·z/|ρ(xz^2aμ0 + J)| = xz^2aμ0 + J/|xz^2aμ0 + J|

    따라서,

    전전류 = σ(Ex + Ez) = σ[(xz^2aμ0 + J)/|xz^2aμ0 + J| + (xz^2aμ0 + J)/|xz^2aμ0 + J|]

    = 2σ(xz^2aμ0 + J)/(xz^2aμ0 + J)

    = 2σ/(xz^2aμ0/J + 1)

    = 2/(xz^2a + 1)

    여기서 σ = 1/ρ 이므로,

    전전류 = 2/(xz^2a + 1) = 2ρ/(xz^2aρ + 1)

    = 2/(xz^2aμ0 + ρ)

    x, z, a, ρ, μ0는 모두 1 이므로,

    전전류 = 2/(1+1) = 1

    따라서 정답은 "1.0"이다. "0.5"가 나오는 이유는 오차가 발생한 것으로 추정된다.

16. 균일하게 자화된 체적 0.01m3인 막대 자성체가 500A.m2인 자기모멘트를 가지고 있을 때, 이 막대 자성체의 자속밀도가 500mT이었다면 이 막대 자성체내의 자계의 세기는 몇 kA/m 인가?

  2. 328
  3. 338
  4. 348
