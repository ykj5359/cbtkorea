    전위 V는 라플라스 방정식을 만족하므로, 다음과 같은 형태의 일반해를 가진다.

    V(x) = A sinh(kx) + B cosh(kx)

    A = (V0 - B cosh(kd)) / sinh(kd)

    V(x) = (V0 - B cosh(kd)) / sinh(kd) sinh(kx) + B cosh(kx)

    V(x) = (V0 / sinh(kd)) sinh(kx)

    k = π / d

    Q = CV

    여기서 C는 도체구의 정전용량이며, V는 도체구에 인가된 전위입니다. 진공의 유전율인 ε0을 이용하여 C를 다시 표현하면 다음과 같습니다.

    C = ε0A/d

    C = ε0 * 4πa2 / 2a = 2πε0a

    C = 2πε0a * 2 = 4πε0a

    따라서 반구 형태의 도체구의 정전용량은 4πε0a입니다.
