7. 100회 감은 코일과 쇄교하는 자속이 1/10 초 동안에 0.5Wb에서 0.3Wb로 감소했다. 이 때 유기되는 기전력은 몇 V인가?

(정답률: 75%)

    $e = -Nfrac{Deltaphi}{Delta t}$

    여기서 N은 코일의 밀도, $Deltaphi$는 자속의 변화로 인한 자기유속의 변화량, $Delta t$는 자속 변화에 걸린 시간이다.

    $e = -Nfrac{0.2Wb}{1/10s} = -2N Wb/s$

    여기서 N은 코일의 밀도이므로, 단위 길이당 코일의 밀도를 나타내는 것이 일반적이다. 예를 들어, 만약 코일의 길이가 1m이고 밀도가 1000바퀴/m이라면, N은 1000이 된다.

    주어진 라플라스 변환함수 F(s)를 부분분수 분해하면 다음과 같다.

    F(s) = (s+2)/(s^2 + 9)

    여기서 분모의 근은 s = 3i, -3i 이므로, 이를 이용하여 역변환 함수 f(t)를 구할 수 있다.

    f(t) = (1/2πi) ∫[c-i∞, c+i∞] F(s) e^(st) ds

    = (1/2πi) [ ∫[c-i∞, c+i∞] (s+2)/(s^2 + 9) e^(st) ds + ∫[c-i∞, c+i∞] 2/(s^2 + 9) e^(st) ds ]

    분모의 근을 구하기 위해 다음과 같이 표현한다.

93. 345kV 가공전선이 154kV 가공전선과 교차하는 경우 이들 양 전선 상호간의 이격거리는 몇 m 이상인가?

  1. 4.48
  2. 4.96
  3. 5.48
  4. 5.82
(정답률: 42%)
  • 30 CBT 기출문제AI

    2023-04-17 15:52

    이격거리는 전선간의 최소 수평거리와 최소 수직거리의 합으로 계산된다.

    345kV 가공전선과 154kV 가공전선이 교차하는 경우, 이들 양 전선은 수직으로 교차하므로 최소 수직거리는 0이 된다. 따라서 이격거리는 전선간의 최소 수평거리와 같다.

    전선간의 최소 수평거리는 전선의 지름과 전선간의 각도에 따라 달라지는데, 이 경우에는 전선의 지름이 주어지지 않았으므로 가장 일반적인 경우인 전선간의 각도가 90도일 때의 최소 수평거리를 사용한다.

    이 경우, 최소 수평거리는 다음과 같이 계산된다.

    최소 수평거리 = (345kV 가공전선 지름 + 154kV 가공전선 지름) x tan(45도)

    = (3.53cm + 2.54cm) x 1

    = 6.07cm

    따라서, 이격거리는 6.07cm 이상이어야 한다. 이 중에서 가장 가까운 값은 5.48이므로 정답은 5.48이 된다.
