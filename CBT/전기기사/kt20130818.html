3. 환상철심에 권수 100회인 A 코일과 권수 400회인 B 코일이 있을때 A의 자기인덕턴스가 4[H]라면 두 코일의 상호인덕턴스는 몇 [H]인가?

    두 코일의 상호인덕턴스는 다음과 같이 계산할 수 있습니다.

    M = k * sqrt(L1 * L2)

    여기서 k는 상수이며, L1과 L2는 각각 A 코일과 B 코일의 자기인덕턴스이고, sqrt는 제곱근을 의미합니다.

    $$C = frac{epsilon A}{d}$$

    여기서 $C_1$과 $C_2$는 각각 하나의 평행 평판의 전기용량이다. 따라서 주어진 문제에서 두 개의 평행 평판의 전기용량은 다음과 같다.

    $$C_2 = frac{epsilon_2 A}{d_2} = frac{epsilon_2 cdot (500text{[mm]})^2}{10text{[mm]}} = 2.5 cdot 10^7 epsilon_2text{[pF]}$$

    따라서 합성용량은 다음과 같다.

    $$C_{text{합성}} = frac{(2.5 cdot 10^7 epsilon_1)(2.5 cdot 10^7 epsilon_2)}{2.5 cdot 10^7 epsilon_1 + 2.5 cdot 10^7 epsilon_2} = frac{epsilon_1 epsilon_2}{epsilon_1 + epsilon_2} cdot (500text{[mm]})^2 cdot 10^{-12}text{[pF]}$$

    $$C_{text{합성}} = frac{4 cdot 9}{4 + 9} cdot (500text{[mm]})^2 cdot 10^{-12}text{[pF]} = 202text{[pF]}$$

  4. 2.2

    2023-04-17 15:43

    슬립(slip)은 실제 회전속도와 동기회전속도의 차이를 나타내는 값으로, 일반적으로 백분율(%)로 표시된다.

    이 문제에서는 3상 유도전동기의 출력과 저항손이 주어졌으므로, 슬립을 구하기 위해서는 동기회전속도를 알아야 한다.

    3상 유도전동기의 동기회전속도는 다음과 같이 구할 수 있다.

    동기회전속도 = 120 x 전원주파수 / 극수

    여기서 전원주파수는 60Hz로 가정하고, 극수는 2로 가정하면 다음과 같다.

    동기회전속도 = 120 x 60 / 2 = 3600 rpm

    따라서, 이 유도전동기의 동기회전속도는 3600 rpm이다.

    이제 슬립을 구하기 위해서는 실제 회전속도를 알아야 한다. 이 문제에서는 전부하 운전이므로, 실제 회전속도는 동기회전속도보다 낮을 것이다.

    슬립은 다음과 같이 구할 수 있다.

    슬립 = (동기회전속도 - 실제 회전속도) / 동기회전속도 x 100%

    출력 7.5[kW]의 3상 유도전동기는 저항손이 200[W]이므로, 유용출력은 다음과 같다.

    유용출력 = 출력 - 저항손 = 7.5[kW] - 0.2[kW] = 7.3[kW]

    유용출력 = 2π x 회전속도 x 토크 / 60

    슬립 = 1 - 7.3 / (2π x 3600 / 60) = 0.026 ≈ 2.6%

95. 길이 16[m], 설계하중 8.2[kN]의 철근콘크리트주를 지반이 튼튼한 곳에 시설하는 경우 지지물 기초의 안전율과 무관하려면 땅에 묻는 깊이를 몇 [m] 이상으로 하여야 하는가?

  2. 2.5
  3. 2.8
  4. 3.2
(정답률: 63%)
  • 30 CBT 기출문제AI

    2023-04-17 15:47

    지반의 안전율과 무관하게 설계하려면, 철근콘크리트주의 중심축과 지반의 접촉면 사이의 마력은 지지물 기초의 마력보다 작아야 합니다. 이를 수식으로 나타내면 다음과 같습니다.

    마력 = 설계하중 / (주의 길이 × 지반의 저항력)

    여기서 지반의 저항력은 땅에 묻는 깊이에 따라 달라집니다. 따라서, 마력이 지지물 기초의 마력보다 작아지도록 땅에 묻는 깊이를 조정해야 합니다.

    주어진 문제에서는 지반이 튼튼하다고 가정하므로, 지반의 저항력은 100[kN/m²]로 가정할 수 있습니다. 따라서, 마력은 다음과 같이 계산됩니다.

    마력 = 8.2[kN] / (16[m] × 100[kN/m²]) = 0.0⑤125[kN/m]

    이 값이 지지물 기초의 마력보다 작아지려면, 지지물 기초의 마력은 다음과 같이 계산됩니다.

    지지물 기초의 마력 = 0.0⑤125[kN/m] × 16[m] = 0.082[kN]

    따라서, 땅에 묻는 깊이는 다음과 같이 계산됩니다.

    땅에 묻는 깊이 = 지지물 기초의 마력 / (지반의 저항력 × 지반의 넓이) = 0.082[kN] / (100[kN/m²] × 1[m²]) = 0.00082[m] = 0.82[mm]
