    전하가 이동하는 동안 받는 힘은 전하와 전기장의 곱으로 나타낼 수 있다. 따라서 이 문제에서 전하가 받는 힘은 F=qE이다. 여기서 q는 전하의 크기, E는 전기장의 크기를 나타낸다.

    W = qΔV

    ΔV = -∫E·dr = -∫(2i+j+4k)·(4i+j/2+2k)·dr
    = -∫(8+1+8)·dr = -17∫dr = -17r

    W = qΔV = -(10^-5)·17·|4i+j/2+2k| = -1.7·10^-4 J

    따라서 정답은 "1.7×10-4"이다.

    P = 2πfBm2Vm2tanδ

    47.6[kcal] = 47.6 × 4184[J/kcal] = 199,024[J]

    fBm = √(P/2πVm2tanδ) = √(199,024[J]/(2π×(0.1[m]×0.01[m]×0.02[m])2×tanδ)) = 2.83[Wb/m2]

    Br/Bm = HL/μL

    μ = HL/Bm = 500[AT/m]/(2×10-6[T]) = 250,000[H/m]
