(정답률: 40%)

    OSI 7계층은 상위층부터 하위층까지 다음과 같이 나열됩니다.

    1. 응용 계층 (Application Layer)
    2. 표현 계층 (Presentation Layer)
    3. 세션 계층 (Session Layer)
    4. 전송 계층 (Transport Layer)
    5. 네트워크 계층 (Network Layer)
    6. 데이터 링크 계층 (Data Link Layer)

    D: 전송 계층은 데이터의 신뢰성과 효율성을 보장하는 계층입니다.
    G: 물리 계층은 데이터를 전기 신호로 변환하여 전송하는 계층입니다.
    F: 데이터 링크 계층은 물리 계층에서 전송된 데이터를 관리하고 오류를 검출하고 수정하는 등의 역할을 합니다.
    E: 네트워크 계층은 데이터를 목적지까지 전달하는 경로를 결정하고 라우팅하는 계층입니다.
