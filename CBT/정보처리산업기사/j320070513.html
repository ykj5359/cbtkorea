    - (D / E) -> (/ D E)
    - (C - (D / E)) -> (- C (/ D E))
    - (A * B) -> (* A B)
    - ((A * B) + (C - (D / E))) -> (+ (* A B) (- C (/ D E)))
    3. 최종적으로 전위 표기식으로 바꾼다.
    - (+ (* A B) (- C (/ D E))) -> (- + * A B C / D E)
