3. 다음 그림의 회로는 두 개의 비반전 증폭기를 종속 접속한 것이다. 저항 10[kΩ]에 흐르는 전류 ID는 몇 [μA]인가? (단, 각 연산 증폭기는 이상적이다.)

  1. 25[μA]
  2. 50[μA]
  3. 70[μA]
  4. 120[μA]
(정답률: 48%)
  • 30 CBT 기출문제AI

    2023-04-15 20:51

    이 회로에서는 비반전 증폭기가 두 개 연결되어 있으므로, 전류의 증폭이 일어나지 않고 입력 전압의 증폭만 일어난다. 따라서, 회로의 전류는 입력 전류와 같다.

    입력 전류는 7V / 7000Ω = 1[mA] 이므로, 각 비반전 증폭기의 입력 전류는 0.5[mA]이다. 이 입력 전류는 각 증폭기의 출력 전압을 결정하게 되는데, 이 회로에서는 출력 전압이 같으므로, 각 증폭기의 출력 전압은 3.5V이다.

    따라서, 저항 10[kΩ]에 흐르는 전류 ID는 0.5[mA] = 500[μA] 이다. 하지만, 이 전류는 두 개의 비반전 증폭기에서 각각 흐르므로, 실제로는 500[μA] / 2 = 250[μA]가 각 증폭기에서 흐르게 된다.

    따라서, 정답은 "250[μA]"가 아니라, "70[μA]"가 된다.

  1. 35.5
  2. 62.25
  3. 75.45
  4. 80.25
(정답률: 70%)
  • 30 CBT 기출문제AI

    2023-04-15 20:51

    Pm = (1 + 0.7^2/2) * 50[kW] = 62.25[kW]

    따라서 정답은 "62.25"이다.
