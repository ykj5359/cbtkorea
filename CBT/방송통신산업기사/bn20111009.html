15. 평활회로를 통과한 출력전압이 [V]일 때, 맥동률은 얼마인가?

(정답률: 알수없음)

    맥동률은 평활회로를 통과한 출력전압의 최대-최소값 차이를 평균 출력전압으로 나눈 값이다. 따라서, 맥동률은 다음과 같이 계산할 수 있다.

    맥동률 = (최대 출력전압 - 최소 출력전압) / 평균 출력전압 x 100%

    주어진 출력전압의 최대값은 12V이고, 최소값은 8V이다. 평균 출력전압은 (12V + 8V) / 2 = 10V이다. 따라서, 맥동률은 다음과 같다.

    맥동률 = (12V - 8V) / 10V x 100% = 40%

    따라서, 정답은 "40%"이다.

38. RF 증폭기의 입력신호전력이 60[μW]이고, 잡음전력이 2[μW]이다. 이때 출력에서 측정된 SNR이 17이다. 여기서 T=290[K]라고 가정할 때 증폭기의 잡음계수는 약 얼마인가?

  1. 1.764
  2. 2.764
  3. 3.764
  4. 4.764
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-15 20:51

    SNR은 출력신호전력과 잡음전력의 비율에 로그를 취한 값이므로,

    SNR = 10log(Pout/Pn)

    여기서 Pout은 출력신호전력, Pn은 잡음전력이다.

    주어진 값으로부터 Pout을 구해보면,

    SNR = 17 = 10log(Pout/2[μW])
    Pout/2[μW] = 10^(17/10)
    Pout = 2[μW] x 10^(17/10)

    증폭기의 잡음계수는 다음과 같이 정의된다.

    NF = (Pout/Pin - 1) / (F - 1)

    여기서 Pin은 입력신호전력, F는 증폭기의 손실계수이다.

    주어진 값으로부터 Pin을 구해보면,

    NF = (Pout/60[μW] - 1) / (F - 1)
    NF = (2[μW] x 10^(17/10) / 60[μW] - 1) / (F - 1)

    T=290[K]이므로, 잡음전력은 다음과 같이 구할 수 있다.

    Pn = kTB

    여기서 k는 볼츠만 상수, B는 대역폭이다.

    주어진 값으로부터 k와 B를 구해보면,

    k = 1.38 x 10^-23 [J/K]
    B = 1[Hz] (단위 대역폭)

    따라서,

    Pn = kTB = 1.38 x 10^-23 x 290 x 1 = 3.99 x 10^-21 [W]

    이제 NF를 구하기 위해 다음과 같이 변형해보자.

    NF = (Pout/Pin - 1) / (F - 1)
    NF = (Pout/Pin - Pn/Pin) / (F - 1) + Pn/Pin - Pn/Pin
    NF = (Pout - Pn) / Pin / (F - 1) + Pn/Pin

    여기서 Pout - Pn은 신호전력이고, Pin은 입력신호전력이다. 따라서,

    NF = (Pout - Pn) / Pin / (F - 1) + Pn/Pin
    NF = (2[μW] x 10^(17/10) - 3.99 x 10^-21) / 60[μW] / (F - 1) + 3.99 x 10^-21 / 60[μW]

    이 값을 계산하면, 약 1.764가 된다. 따라서 정답은 "1.764"이다.

    증폭기의 잡음계수는 입력신호전력에 대한 잡음의 비율을 나타내는 값이다. 이 값이 작을수록 증폭기의 성능이 우수하다는 것을 의미한다. 따라서 잡음계수가 작은 증폭기를 선택하는 것이 중요하다.
