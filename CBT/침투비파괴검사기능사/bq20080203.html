55. 금속간 화합물인 탄화철(Fe3C) 중의 Fe 의 원자비(%)는?

  1. 25
  2. 45
  3. 65
  4. 75
(정답률: 33%)
  • 30 CBT 기출문제AI

    2023-04-12 20:02

    탄화철(Fe3C)은 Fe와 C로 이루어진 화합물이므로, Fe의 몰질량과 Fe3C의 몰질량을 비교하여 Fe의 원자비를 구할 수 있습니다.

    Fe의 몰질량 = 55.85 g/mol
    Fe3C의 몰질량 = 55.85 x 3 + 12.01 = 179.56 g/mol

    따라서, Fe는 Fe3C의 몰질량에서 차지하는 비율을 계산하면 됩니다.

    Fe의 몰질량 비율 = (55.85 x 3) / 179.56 x 100% = 93.7%

    하지만, 이 비율은 Fe3C에서 Fe의 비율을 나타내는 것이 아니라, Fe3C의 전체 몰질량에서 Fe의 몰질량 비율을 나타내는 것입니다. 따라서, Fe의 비율을 구하기 위해서는 Fe의 몰질량 비율을 Fe3C의 몰질량 비율로 나누어주어야 합니다.

    Fe의 비율 = (Fe의 몰질량 비율 / Fe3C의 몰질량 비율) x 100%
    = (93.7% / 179.56 g/mol) x 100%
    = 52.2%

    하지만, 이 계산 결과는 Fe3C의 분자식이 Fe2C인 경우에 해당하는 결과입니다. 실제로는 Fe3C이므로, Fe의 비율은 더 높게 나타납니다.

    Fe의 비율 = (Fe의 몰질량 비율 / Fe3C의 몰질량 비율) x 100%
    = (93.7% / (55.85 x 3 + 12.01)) x 100%
    = 75%

    따라서, Fe3C에서 Fe의 원자비는 75%입니다.
