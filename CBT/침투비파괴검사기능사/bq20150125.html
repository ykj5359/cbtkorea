11. 관의 보수검사를 위해 와류탐상검사를 수행할 때 관의 외경을 d, 시험코일의 평균 직경을 D라고 하면 내십코일의 충전율을 구하는 식은?

(정답률: 63%)
  • 30 CBT 기출문제AI

    2023-04-12 20:08

    내십코일의 충전율은 다음과 같이 구할 수 있습니다.

    내십코일의 총 인덕턴스 = 시험코일의 인덕턴스 - 와류탐상코일의 인덕턴스
    내십코일의 충전율 = (내십코일의 총 인덕턴스 / 시험코일의 인덕턴스) x 100%

    와류탐상코일의 인덕턴스는 다음과 같이 구할 수 있습니다.

    와류탐상코일의 인덕턴스 = (μ0 x N^2 x A) / d

    여기서 μ0는 자유공기의 자기도(permeability)이고, N은 와류탐상코일의 코일수, A는 와류탐상코일의 단면적, d는 관의 외경입니다.

    시험코일의 인덕턴스는 다음과 같이 구할 수 있습니다.

    시험코일의 인덕턴스 = (μ0 x N^2 x A) / D

    여기서 N은 시험코일의 코일수, A는 시험코일의 단면적, D는 시험코일의 평균 직경입니다.

    따라서 내십코일의 충전율은 다음과 같이 구할 수 있습니다.

    내십코일의 충전율 = ((μ0 x N^2 x A) / d - (μ0 x N^2 x A) / D) / ((μ0 x N^2 x A) / D) x 100%
    내십코일의 충전율 = (D - d) / D x 100%

    따라서 정답은 "" 입니다. 이유는 내십코일의 충전율은 시험코일의 평균 직경과 관의 외경의 차이에 비례하기 때문입니다. 시험코일의 평균 직경이 클수록 내십코일의 충전율은 작아지고, 관의 외경이 클수록 내십코일의 충전율은 커집니다.
