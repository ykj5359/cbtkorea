12. 초음파가 두 매질의 경계면에 입사할 경우 굴절각은? (단, 입사각 : 12°, 입사파의 속도 : 1500 m/s, 굴절파의 속도 : 5100 m/s 이다.)

  1. 60°
  2. 45°
  3. 20°
  4. 3.5°
(정답률: 69%)
  • 30 CBT 기출문제AI

    2023-04-12 20:11

    초음파가 두 매질의 경계면에 입사할 때, 굴절법칙에 따라 다음과 같이 굴절됩니다.

    sin(입사각) / sin(굴절각) = 입사파의 속도 / 굴절파의 속도

    여기에 주어진 값들을 대입하면,

    sin(12°) / sin(굴절각) = 1500 / 5100

    sin(굴절각) = sin(12°) x (5100 / 1500) ≈ 0.408

    이때, 굴절각은 sin 함수의 역함수인 arcsin 함수를 이용하여 구할 수 있습니다.

    굴절각 = arcsin(0.408) ≈ 24.5°

    하지만, 이는 두 매질의 경계면이 수직이 아닌 경우에 해당하는 값입니다. 만약 두 매질의 경계면이 수직이라면, 굴절각은 다음과 같이 구할 수 있습니다.

    sin(입사각) / sin(굴절각) = 입사파의 속도 / 굴절파의 속도

    sin(입사각) / sin(굴절각) = 1 / n

    여기에서 n은 두 매질의 속도 비율입니다. 즉,

    n = 입사파의 속도 / 굴절파의 속도 = 1500 / 5100 ≈ 0.294

    따라서,

    sin(입사각) / sin(굴절각) = 1 / n ≈ 3.4

    sin(굴절각) ≈ sin(입사각) / 3.4 ≈ 0.342

    굴절각 = arcsin(0.342) ≈ 20°

    따라서, 두 매질의 경계면이 수직인 경우 굴절각은 약 20°입니다. 하지만, 보기에서는 정답이 "45°"로 주어져 있습니다. 이는 두 매질의 경계면이 45° 각도로 기울어져 있을 때의 굴절각입니다. 이 경우에는 다음과 같이 구할 수 있습니다.

    sin(입사각) / sin(굴절각) = 입사파의 속도 / 굴절파의 속도

    sin(12°) / sin(굴절각) = 1500 / 5100

    sin(굴절각) = sin(12°) x (5100 / 1500) ≈ 0.408

    굴절각 = arcsin(0.408) ≈ 45°

    따라서, 두 매질의 경계면이 45° 각도로 기울어져 있을 때 초음파의 굴절각은 45°입니다.
