12. 천공지름 25mm의 발파공을 공간격 9cm로 하여 3공을 집중발파하였을 때 저항선의 비를 구하면 얼마인가? (단, 장약길이는 구멍지름의 12배로 한다.)

  1. 0.96
  2. 1.76
  3. 1.85
  4. 2.09
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-13 15:51

    천공지름 25mm의 발파공을 공간격 9cm로 하여 3공을 집중발파하면, 각 발파공에서 나오는 파동이 서로 만나 저항선에서 간섭파가 발생한다. 이때 간섭파의 진폭은 각 파동의 진폭의 합과 차이에 따라 결정된다.

    저항선의 비는 간섭파의 진폭과 원래 파동의 진폭의 비로 정의된다. 이때 원래 파동의 진폭은 발파공에서 나오는 파동의 진폭과 저항선과의 거리에 따라 감소하게 된다.

    따라서, 발파공과 저항선 사이의 거리가 9cm이고, 장약길이가 구멍지름의 12배이므로, 발파공에서 나오는 파동의 진폭은 거리에 반비례하여 1/9이 되고, 각 발파공에서 나오는 파동의 진폭의 합은 3배가 된다.

    따라서 간섭파의 진폭은 (3-1)/9 = 2/9이 되고, 저항선의 비는 간섭파의 진폭과 원래 파동의 진폭의 비로 계산하면 2/9 ÷ 1/9 = 2가 된다.

    하지만, 이 문제에서는 저항선의 비를 구하는 것이 아니라, 저항선의 비의 로그값을 구하는 것이므로, 로그값으로 변환하면 log₂2 = 1이 된다.

    따라서, 정답은 1.76이 아니라 1이 된다.

17. 어떤 현장 모래의 습윤밀도가 1.80g/cm3, 함수비가 32.0%로 측정되었다면 건조밀도는?

  1. 0.65g/cm3
  2. 0.95g/cm3
  3. 1.36g/cm3
  4. 2.72g/cm3
(정답률: 64%)
  • 30 CBT 기출문제AI

    2023-04-13 15:50

    습윤밀도는 모래 입자와 물 입자 사이의 간극에 물이 차지 않은 상태에서 측정된 밀도이며, 건조밀도는 모래 입자만으로 이루어진 상태에서 측정된 밀도입니다. 따라서 함수비가 32.0%라는 것은 모래 입자의 부피 중 32.0%가 물로 차지되어 있다는 것을 의미합니다. 이를 수식으로 나타내면 다음과 같습니다.

    함수비 = (물의 부피) / (모래 입자의 부피) x 100%

    따라서 물의 부피는 다음과 같이 구할 수 있습니다.

    물의 부피 = (함수비 / 100%) x (모래 입자의 부피)

    습윤밀도는 1.80g/cm3이므로, 모래 입자와 물 입자의 혼합물의 부피는 1cm3당 1.80g의 질량을 가지게 됩니다. 따라서 모래 입자의 부피는 다음과 같이 구할 수 있습니다.

    모래 입자의 부피 = 1cm3 - 물의 부피

    이를 대입하여 물의 부피를 구하면 다음과 같습니다.

    물의 부피 = (32.0% / 100%) x (1cm3) = 0.32cm3

    따라서 모래 입자의 부피는 다음과 같습니다.

    모래 입자의 부피 = 1cm3 - 0.32cm3 = 0.68cm3

    건조밀도는 모래 입자만으로 이루어진 상태에서 측정된 밀도이므로, 모래 입자의 질량을 모래 입자의 부피로 나누어 구할 수 있습니다.

    건조밀도 = (모래 입자의 질량) / (모래 입자의 부피)

    모래 입자의 질량은 다음과 같이 구할 수 있습니다.

    모래 입자의 질량 = (습윤밀도 x 모래 입자의 부피) - (물의 부피 x 물의 밀도)

    물의 밀도는 1g/cm3이므로, 이를 대입하여 모래 입자의 질량을 구하면 다음과 같습니다.

    모래 입자의 질량 = (1.80g/cm3 x 0.68cm3) - (0.32cm3 x 1g/cm3) = 1.088g

    따라서 건조밀도는 다음과 같이 구할 수 있습니다.

    건조밀도 = 1.088g / 0.68cm3 = 1.36g/cm3

    따라서 정답은 "1.36g/cm3"입니다.
