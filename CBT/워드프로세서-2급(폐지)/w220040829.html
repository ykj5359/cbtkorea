20. 다음 중 저장 용량이 작은 것부터 큰 것 순으로 나열한 것은?

  2. KB → MB → TB → GB
  3. KB → GB → MB → TB
  4. KB → TB → MB → GB
(정답률: 77%)
  • 30 CBT 기출문제AI

    2023-04-13 21:07

    정답은 "KB → MB → GB → TB"이다.

    KB는 킬로바이트, MB는 메가바이트, GB는 기가바이트, TB는 테라바이트를 나타내는 단위이다. 이들 단위는 1024배씩 커지는 이진수 단위이기 때문에, 저장 용량이 작은 것부터 큰 것 순으로 나열하면 KB → MB → GB → TB 순서가 된다. 따라서, 이 단위들을 사용할 때는 이 순서를 지켜야 한다.

  2. 컴퓨터 각 부분의 동작을 제어·감독하는 역할을 한다.
  3. 데이터의 입출력을 직접 담당하는 역할을 한다.
  4. 주기억장치로부터 명령어를 읽어와 해석한다.

  4. MOV
(정답률: 63%)

    정답: JPG

    설명:

    - AVI, MPG, MOV: 동영상 파일 형식으로, 영상과 음성 정보를 함께 담고 있으며, 일반적으로 영상 재생 프로그램에서 재생 가능하다.
    - JPG: 정적인 이미지 파일 형식으로, 사진이나 그림 등의 이미지를 저장할 때 사용한다.
