41. 다음 중 네트워크를 규모가 작은 것에서 큰 순서대로 올바르게 나열한 것은?

  1. LAN < MAN < WAN
  2. MAN < WAN < LAN
  3. LAN < WAN < MAN
  4. MAN < LAN < WAN
(정답률: 84%)
  • 30 CBT 기출문제AI

    2023-04-13 20:47

    정답은 "LAN < MAN < WAN"이다.

    LAN은 Local Area Network의 약자로, 규모가 작은 지역 내에서 컴퓨터나 기기들이 연결되어 있는 네트워크를 말한다. 예를 들어 가정 내에서 가족들이 사용하는 인터넷이나 회사 내에서 직원들이 사용하는 내부 네트워크가 LAN에 해당한다.

    MAN은 Metropolitan Area Network의 약자로, 규모가 큰 지역 내에서 컴퓨터나 기기들이 연결되어 있는 네트워크를 말한다. 예를 들어 도시 내에서 여러 건물에 걸쳐 연결된 네트워크나 대학교 내부 네트워크가 MAN에 해당한다.

    WAN은 Wide Area Network의 약자로, 지리적으로 넓은 지역을 커버하는 네트워크를 말한다. 예를 들어 인터넷이나 글로벌 기업의 본사와 해외 지사 간의 연결된 네트워크가 WAN에 해당한다.

    따라서, LAN은 규모가 작은 지역 내에서, MAN은 규모가 큰 지역 내에서, WAN은 지리적으로 넓은 지역에서 사용되는 네트워크이므로 "LAN < MAN < WAN"이 올바른 순서이다.
