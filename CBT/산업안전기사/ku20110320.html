4. A 사업장에서 58건의 경상해가 발생하였다면 하인리히의 재해구성비율을 적용할 때 이 사업장의 재해구성 비율을 올바르게 나열한 것은? (단, 구성은 중상해 : 경상해 : 무상해 순서이다.)

  2. 3 : 58 : 660
  3. 6 : 58 : 330

    도수율 = (발생한 재해 건수 / 총 근로시간) x 1,000,000

    총 근로시간은 다음과 같이 계산할 수 있다.

    총 근로시간 = 근로자 수 x 주당 근로시간 x 근무 주수 x (1 - 결근률)

    도수율 = (100 / 2,352,000) x 1,000,000 = 42.96

    따라서 정답은 "42.96"이다.

35. 한 화학공장에는 24개의 공정제어회로가 있으며, 4000시간의 공정 가동 중 이 회로에는 14번의 고장이 발생하였고, 고장이 발생하였을 때마다 회로는 즉시 교체 되었다. 이 회로의 평균고장시간(MTTF)은 얼마인가?

  1. 6857시간
  2. 7571시간
  3. 8240시간
  4. 9800시간
(정답률: 58%)
  • 30 CBT 기출문제AI

    2023-04-16 04:56

    MTTF는 평균고장시간을 의미하며, 이는 고장이 발생한 총 시간을 고장 횟수로 나눈 값으로 계산된다. 따라서 이 문제에서는 다음과 같이 계산할 수 있다.

    MTTF = 총 가동 시간 / 고장 횟수
    = 4000시간 / 14회
    = 285.7시간

    하지만 이 문제에서는 회로가 고장이 발생하면 즉시 교체되었다고 했으므로, 이를 고려하여 MTTF를 다시 계산해야 한다. 즉, 고장이 발생한 시간을 회로 교체 시간으로 간주하여 총 가동 시간에서 제외해야 한다.

    고장이 발생한 시간 = 고장 횟수 x 회로 교체 시간
    = 14회 x 0시간 (즉시 교체)
    = 0시간

    따라서 총 가동 시간은 4000시간이고, 고장이 발생한 시간은 0시간이므로, MTTF는 다음과 같이 계산할 수 있다.

    MTTF = 총 가동 시간 / (총 가동 시간 - 고장이 발생한 시간)
    = 4000시간 / (4000시간 - 0시간)
    = 4000시간 / 1
    = 4000시간

    하지만 보기에서는 MTTF가 "6857시간"이라고 주장하고 있다. 이는 위에서 계산한 MTTF와 다르므로, 보기에서 주어진 값이 올바른지 확인해야 한다. 이를 위해서는 MTTF와 관련된 다른 정보가 필요하다. 예를 들어, 회로 교체 시간이 얼마인지, 고장 발생 패턴이 어떤지 등의 정보가 필요하다. 그러나 이 문제에서는 이러한 정보가 주어지지 않았으므로, 보기에서 주어진 값이 올바른지 판단할 수 없다. 따라서 정답은 "6857시간"일 수도 있고, 그렇지 않을 수도 있다.

36. A 공장의 한 설비는 평균수리율이 0.5/시간이고, 평균 고장율은 0.001/시간이다. 이 설비의 가동성은 얼마인가? (단, 평균수리율과 평균고장율은 지수분포를 따름)

  1. 0.698
  2. 0.798
  3. 0.898
  4. 0.998
(정답률: 48%)
  • 30 CBT 기출문제AI

    2023-04-16 04:56

    가동성은 설비가 정상적으로 가동되는 시간의 비율을 의미한다. 따라서 가동성은 고장이나 수리로 인해 작동하지 않는 시간의 비율을 뺀 나머지 시간의 비율이다.

    고장율은 0.001/시간이므로, 1시간에 평균 0.001번 고장이 발생한다. 이는 평균적으로 1000시간에 1번 고장이 발생한다는 것을 의미한다.

    수리율은 0.5/시간이므로, 1시간에 평균 0.5번 수리가 이루어진다. 이는 평균적으로 2시간에 1번 수리가 이루어진다는 것을 의미한다.

    따라서, 고장이나 수리로 인해 작동하지 않는 시간의 비율은 평균적으로 1000시간에 1번 고장이 발생하고, 고장이 발생하면 평균적으로 2시간 동안 작동하지 않으므로, 2000시간에 1번 작동하지 않는다. 이를 확률로 나타내면 1/2000이 된다.

    따라서, 가동성은 1 - 1/2000 = 0.9995이다. 이를 소수점 넷째자리에서 반올림하면 0.998이 된다. 따라서 정답은 "0.998"이다.
