9. 연평균 200명의 근로자가 작업하는 사업장에서 연간 3건의 재해가 발생하여 사망 1명. 나머지 1명은 20일간 요양하였다. 이 사업장의 강도율은? (단, 연간 근로일수는 300일, 1일 근로시간은 8시간이다.)

  1. 15.01
  2. 15.71
  3. 17.61
  4. 17.71
(정답률: 65%)
  • 30 CBT 기출문제AI

    2023-04-16 ⑤:02

    강도율은 다음과 같이 계산할 수 있다.

    강도율 = (사망자수 + 요양자수 x 0.1) / (총 근로자수 x 총 근로일수 x 8)

    여기서 사망자수는 1명, 요양자수는 20일간 요양한 1명이므로 0.1을 곱해준다. 총 근로자수는 200명, 총 근로일수는 300일, 1일 근로시간은 8시간이므로 이를 모두 곱해준다.

    강도율 = (1 + 1 x 0.1) / (200 x 300 x 8) = 0.0019625

    이 값을 100,000으로 곱해주면 강도율이 나온다.

    강도율 = 0.0019625 x 100,000 = 196.25

    따라서, 보기에서 정답이 "15.71" 인 이유는 소수점 둘째자리에서 반올림하여 나타낸 값이다.

46. 회전수가 200rpm으로 80마력을 전달하는 동력축의 지름은 얼마인가? (단, 재료의 인장 강도는 3,000kg/cm2로 하고, 비틀림 강도는 인장 강도의 60%이며, 안전율 S=8이다.)

  1. 6.83cm
  2. 7.49cm
  3. 8.66cm
  4. 9.45cm
(정답률: 37%)
  • 30 CBT 기출문제AI

    2023-04-16 ⑤:03

    동력축의 전달하는 동력은 다음과 같이 구할 수 있다.

    P = 2πNT/60

    여기서, P는 전달하는 동력, N은 회전수, T는 토크이다. 따라서,

    T = 9.55P/N

    여기서, P는 80마력이므로,

    P = 80 × 735.5 = 58,840W

    또한, 안전율 S=8이므로, 인장 강도는 다음과 같이 구할 수 있다.

    σ = 3,000 / 8 = 375kg/cm2

    비틀림 강도는 인장 강도의 60%이므로,

    τ = 0.6 × 375 = 225kg/cm2

    동력축의 지름은 다음과 같이 구할 수 있다.

    T/J = τ/R

    여기서, J는 극관성, R은 동력축의 반지름이다. 따라서,

    J = πR^4/2

    T/J = σ

    따라서,

    R = (2T/πσ)^(1/3)

    τ = σ/2

    여기에 값을 대입하면,

    R = (2 × 9.55 × 58,840 / π × 375)^(1/3) = 4.33cm

    따라서, 동력축의 지름은 2 × 4.33 = 8.66cm이다.
