    종합 재해지수 = 2.5 x (12 ÷ 1,200,000) x 1,000,000

    종합 재해지수 = 25

    종합 재해지수 = 0.5 x (12 ÷ 1,200,000) x 1,000,000
    종합 재해지수 = 0.5 x 0.00001 x 1,000,000
    종합 재해지수 = 5.0

    LPG의 비열은 2.4kJ/kg.℃이므로, 25℃에서의 LPG의 엔탈피는 다음과 같다.

    H = mCΔT = 10kg × 2.4kJ/kg.℃ × (25℃ - (-42.2℃)) = 10kg × 2.4kJ/kg.℃ × 67.2℃ = 1612.8kJ
