12. 강도 시험용 공시체를 이용하여 할렬인장강도 시험을 실시하였더니 95kN의 하중에서 파괴되었다. 인장강도는 얼마인가? (단, 공시체의 지름은 100mm, 높이는 200mm)

  1. 2.0 MPa
  2. 3.0 MPa
  3. 4.0 MPa
  4. 5.0 MPa
(정답률: 66%)
  • 30 CBT 기출문제AI

    2023-04-14 15:46

    할렬인장강도는 다음과 같이 계산할 수 있다.

    할렬인장강도 = 파괴하중 / 단면적

    공시체의 지름이 100mm 이므로 반지름은 50mm 이다. 따라서 단면적은 다음과 같이 계산할 수 있다.

    단면적 = π x 반지름^2 = 3.14 x 50^2 = 7,850 mm^2

    파괴하중은 95kN 이므로, 할렬인장강도는 다음과 같이 계산할 수 있다.

    할렬인장강도 = 95,000 N / 7,850 mm^2 = 12.1 MPa

    따라서, 인장강도는 12.1 MPa 이다. 하지만 문제에서 요구하는 것은 할렬인장강도가 아니라 인장강도이므로, 할렬인장강도를 4로 나누어 주어야 한다.

    인장강도 = 할렬인장강도 / 4 = 12.1 MPa / 4 = 3.0 MPa

    따라서, 정답은 "3.0 MPa" 이다.
