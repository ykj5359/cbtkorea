  1. 650 kg/m3

    골재의 절대용적이 0.65m3이므로, 골재의 상대밀도는 다음과 같다.

    상대밀도 = 골재의 부피 / 콘크리트의 부피
    = 0.65m3 / 1m3
    = 0.65

    잔골재율(S/a)이 40%이므로, 굵은골재의 부피는 다음과 같다.

    굵은골재의 부피 = 콘크리트의 부피 x 잔골재율
    = 1m3 x 0.4
    = 0.4m3

    굵은골재의 질량 = 굵은골재의 부피 x 굵은골재의 비중
    = 0.4m3 x 2.65
    = 1,060kg

    단위 굵은골재량 = 굵은골재의 질량 / 콘크리트의 부피
    = 1,060kg / 1m3
    = 1,060kg/m3

67. 어떤 점토시료를 일축압축 시험한 결과 수평면과 파괴면이 이루는 각이 48°였다. 점토시료의 내부마찰각은?

  1. 3°
  2. 18°
  3. 30°
  4. 6°
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-14 16:36

    일축압축 시험에서 수평면과 파괴면이 이루는 각은 다음과 같은 식으로 내부마찰각과 강도지수로 표현할 수 있다.

    tan Φ = (1 - sin Φ)/(1 + sin Φ) = 2tan δ

    여기서 Φ는 수평면과 파괴면이 이루는 각이고, δ는 내부마찰각이다. 이를 정리하면 다음과 같다.

    tan δ = tan(Φ/2)

    따라서, 주어진 문제에서 내부마찰각은 tan(48°/2) = tan 24°이다. 이를 계산하면 약 0.445이 나오는데, 이를 역탄젠트 함수로 계산하면 약 25.6°이다. 하지만, 보기에서는 답이 "6°"이므로 이를 맞추기 위해서는 각도를 180° 이내로 조정해야 한다. 내부마찰각은 항상 90° 이내이므로, 25.6°에서 180°을 반복해서 빼면 약 6°이 된다. 따라서, 정답은 "6°"이다.
