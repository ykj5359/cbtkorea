10. 콘크리트의 단위 잔골재량과 단위 굵은 골재량이 각각 700kg/m3과 1060kg/m3이며, 잔골재와 굵은 골재의 표건밀도가 각각 2.61g/cm3및 2.65g/cm3일 때 잔골재율(S/a)은?

  1. 35%
  2. 40%
  3. 45%
  4. 50%
(정답률: 56%)
  • 30 CBT 기출문제AI

    2023-04-14 15:10

    잔골재율(S/a)은 잔골재의 부피 비율을 나타내는 값으로, 다음과 같이 계산할 수 있다.

    S/a = (잔골재 부피) / (전체 콘크리트 부피)

    전체 콘크리트 부피는 잔골재와 굵은 골재의 부피 합이므로,

    전체 콘크리트 부피 = (잔골재 부피 + 굵은 골재 부피)

    잔골재와 굵은 골재의 단위 부피는 각각 700kg/m3과 1060kg/m3이므로,

    잔골재 부피 = 0.7m3/m3, 굵은 골재 부피 = 1.06m3/m3

    또한, 잔골재와 굵은 골재의 표건밀도는 각각 2.61g/cm3및 2.65g/cm3이므로,

    잔골재의 부피 당 질량 = 2.61g/cm3 × 1000kg/m3 = 2610kg/m3

    굵은 골재의 부피 당 질량 = 2.65g/cm3 × 1000kg/m3 = 2650kg/m3

    따라서, 전체 콘크리트의 단위 부피당 질량은 다음과 같이 계산할 수 있다.

    전체 콘크리트의 단위 부피당 질량 = (잔골재 부피 당 질량 × 잔골재 비율) + (굵은 골재 부피 당 질량 × 굵은 골재 비율)

    = (2610kg/m3 × 0.7) + (2650kg/m3 × 0.3)

    = 2597kg/m3

    따라서, 잔골재율(S/a)은 다음과 같이 계산할 수 있다.

    S/a = (잔골재 부피) / (전체 콘크리트 부피)

    = (0.7m3/m3) / [(0.7m3/m3) + (1.06m3/m3)]

    = 0.397

    즉, 잔골재율은 약 40%이다.

66. 어떤 포화점토의 일축압축강도(qu)가 3.0kg/cm2이었다. 이 흙의 점착력(c)은?

  1. 3.0kg/cm2
  2. 2.5kg/cm2
  3. 2.0kg/cm2
  4. 1.5kg/cm2
(정답률: 56%)
  • 30 CBT 기출문제AI

    2023-04-14 15:09

    일축압축강도(qu)와 점착력(c) 사이에는 다음과 같은 관계식이 성립한다.

    qu = 2c tan(φ)

    여기서 φ는 흙의 내부 마찰각을 나타낸다. 이 문제에서는 φ를 주지 않았으므로, 일반적으로 흙의 내부 마찰각은 30도에서 45도 사이라고 가정할 수 있다. 따라서, φ를 30도로 가정하고 위의 식에 대입하면 다음과 같다.

    3.0kg/cm2 = 2c tan(30°)

    c = 1.5kg/cm2

    따라서, 정답은 "1.5kg/cm2"이다.

  2. 2.14t/m2
  3. 3.12t/m2
  4. 4.27t/m2
(정답률: 41%)

    주어진 그림에서 X-X면에 수직인 면이 없으므로, 모래의 단면적은 X-Y면과 동일하다고 가정할 수 있다. 따라서, X-Y면에서의 전단강도를 구하면 된다.

    코하압력은 c=0 이므로, 전단강도는 탄젠트 공식을 이용하여 구할 수 있다.

    tan ø = (H/V) = (전단강도/유닛웨이트)

    전단강도 = tan ø * 유닛웨이트

    유닛웨이트 = (체적준위중량 - 물의중량) / 체적준위

    체적준위중량 = 20kN/m3 * 2m * 1m * 1m = 40kN

    체적준위 = 2m * 1m * 1m = 2m3

    유닛웨이트 = (40kN - 19.62kN) / 2m3 = 10.19kN/m3

    전단강도 = tan 30° * 10.19kN/m3 = 5.89kN/m2 = 0.589t/m2

    따라서, 정답은 0.589t/m2 * 2(면적비) * 2(면) = 2.356t/m2 이다.

    X-X면에서의 전단강도 = 2.356t/m2 / 2 = 1.178t/m2

  1. 2.12×107초
  2. 4.24×107초
  3. 6.36×107초

    압밀계수(D)와 시간계수(T)를 이용하여 압밀도(ε)를 구할 수 있다.

    ε = D × t / T

    여기서 ε = 0.9, D = 0.5×10-2cm2/s, T = 0.848, t를 구하면

    0.9 = 0.5×10-2 × t / 0.848

    t = 0.9 × 0.848 / 0.5×10-2 = 152.64초

    하지만 이 문제에서는 5m 두께의 점토층에서 압밀이 일어나는 시간을 구하는 것이므로, 이 시간에 5m를 나누어줘야 한다.

    t = 152.64 / 5 = 30.528초

    따라서 정답은 30.528초인데, 이를 지수표기법으로 나타내면 3.⑤28×101초이다. 하지만 보기에서는 단위를 초가 아닌 "초의 제곱"으로 표기하고 있으므로, 이를 다시 제곱하여 계산해야 한다.

    (3.⑤28×101)2 = 9.3184×102

    따라서 정답은 9.3184×102초2인데, 이를 지수표기법으로 나타내면 9.3184×107초2이다. 하지만 보기에서는 단위를 초가 아닌 "초의 제곱"으로 표기하고 있으므로, 다시 제곱근을 취해줘야 한다.

    √(9.3184×107) = 3.⑤6×104

79. 아래는 불교란 흙 시료를 채취하기 위한 샘플러 선단의 그림이다. 면적비(Ar)를 구하는 식으로 옳은 것은?
