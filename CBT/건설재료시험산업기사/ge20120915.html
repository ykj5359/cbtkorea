4. 콘크리트 1m3을 만드는 배합설계에서 필요한 골재의 절대용적이 720L 이었다. 잔골재율이 34%, 잔골재 밀도가 2.6g/cm3, 굵은골재 밀도가 2.65g/cm3일 때, 단위굵은골재량을 구하면?

  1. 1259 kg
  2. 1236 kg
  3. 649 kg
  4. 637 kg
(정답률: 35%)
  • 30 CBT 기출문제AI

    2023-04-14 15:44

    골재의 절대용적은 다음과 같이 구할 수 있다.

    절대용적 = 골재의 용적 + 잔골재의 용적

    720L = 골재의 용적 + 0.34골재의 용적

    골재의 용적 = 480L

    골재의 밀도는 문제에서 주어졌으므로, 부피를 무게로 환산하기 위해 다음과 같이 계산한다.

    골재의 무게 = 골재의 부피 x 골재의 밀도

    골재의 무게 = 480L x 2.6g/cm3 x 1m3/1000L

    골재의 무게 = 1248 kg

    잔골재의 무게는 다음과 같이 계산한다.

    잔골재의 무게 = 0.34골재의 용적 x 잔골재의 밀도

    잔골재의 무게 = 0.34 x 720L x 2.6g/cm3 x 1m3/1000L

    잔골재의 무게 = 630.72 kg

    따라서, 단위굵은골재량은 다음과 같이 계산한다.

    단위굵은골재량 = (1 - 잔골재율) x 총골재무게 / 총골재부피

    단위굵은골재량 = (1 - 0.34) x (1248 kg + 630.72 kg) / 1m3

    단위굵은골재량 = 1259 kg

    따라서, 정답은 "1259 kg"이다.
