    비중은 물에 비해 상대적인 밀도를 나타내는 값으로, 비중이 2.6이라는 것은 물에 비해 2.6배 더 무겁다는 것을 의미한다. 따라서 1m3의 굵은골재의 무게는 1.75 x 2.6 = 4.55tonf이다.

61. 습윤토 1000㎝3의 교란되지 않은 시료가 있다. 이 시료의 시험결과 무게는 1550g, 함수비는 12.5%,비중은 2.60의 값을 얻었다. 교란되지 않은 상태의 포화도는 얼마인가?

  1. 32%
  2. 37%
  3. 44%
  4. 56%
(정답률: 25%)
  • 30 CBT 기출문제AI

    2023-04-14 16:27

    포화도는 시료의 질량과 비중을 이용하여 계산할 수 있다.

    먼저, 시료의 부피와 비중을 이용하여 질량을 계산해보자.

    부피 = 1000㎝3 = 1000ml
    비중 = 2.60

    따라서, 시료의 질량은 다음과 같다.

    질량 = 부피 x 비중 = 1000ml x 2.60 = 2600g

    하지만, 시료의 실제 무게는 1550g 이므로, 이 시료는 함수비로 인해 일부가 제거되었다는 것을 알 수 있다.

    함수비 = (질량 - 무게) / 질량 x 100%
    12.5% = (2600g - 1550g) / 2600g x 100%

    따라서, 시료의 교란되지 않은 상태의 질량은 다음과 같다.

    질량 = 무게 / (1 - 함수비) = 1550g / (1 - 0.125) = 1771.43g

    이제, 포화도를 계산해보자.

    포화도 = 무게 / (부피 x 밀도) x 100%
    = 1550g / (1000ml x 0.68g/ml) x 100%
    = 22.79%

    따라서, 보기에서 주어진 답안 중에서 포화도가 22.79%에 가장 가까운 값은 "32%" 이다.

    하지만, 이 답안은 교란되지 않은 상태의 포화도가 아니라, 함수비로 인해 제거된 상태의 포화도를 나타낸 것이다.

    따라서, 교란되지 않은 상태의 포화도를 구하기 위해서는, 함수비로 인해 제거된 물질의 부피를 먼저 계산해야 한다.

    제거된 물질의 부피 = 제거된 물질의 질량 / 밀도 = (2600g - 1771.43g) / 0.68g/ml = 2149.27ml

    따라서, 교란되지 않은 상태의 부피는 다음과 같다.

    부피 = 총 부피 - 제거된 물질의 부피 = 1000ml - 2149.27ml = -1149.27ml

    이 값은 음수이므로, 시료가 교란되지 않은 상태에서는 존재할 수 없다.

    따라서, 이 문제에서 주어진 정보로는 교란되지 않은 상태의 포화도를 구할 수 없다.

    하지만, 보기에서 주어진 답안 중에서 포화도가 22.79%에 가장 가까운 값은 "32%" 이므로, 이 답안은 교란되지 않은 상태의 포화도보다는 함수비로 인해 제거된 상태의 포화도를 나타낸 것으로 해석할 수 있다.
