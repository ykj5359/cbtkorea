  1. 5.4V
  2. 6V
  3. 10.8V
  4. 12V
(정답률: 43%)
  • 30 CBT 기출문제AI

    2023-04-12 18:16

    이 회로는 저항과 콘덴서로 이루어진 RC 회로입니다. 따라서 입력 신호에 대한 출력 신호의 크기와 위상이 입력 신호의 주파수에 따라 달라집니다.

    여기서 입력 신호는 사인파 교류입력 12V(실효값)이므로, 이를 통해 계산한 주파수는 다음과 같습니다.

    Vrms = 12V
    Vpeak = Vrms * √2 = 12V * √2 ≈ 16.97V
    Vpeak-to-peak = 2 * Vpeak = 2 * 16.97V ≈ 33.94V

    Vpeak-to-peak 값으로부터 입력 신호의 주파수를 계산하면 다음과 같습니다.

    Vpeak-to-peak = 33.94V = 2 * π * f * C * Vpeak

    따라서 입력 신호의 주파수는 50Hz입니다.

    저항 R과 콘덴서 C의 값을 보면, R = 1kΩ, C = 1μF입니다. 이를 이용하여 출력 신호의 크기를 계산하면 다음과 같습니다.

    Vout = Vin * R / (R + 1 / (2 * π * f * C))

    ≈ 10.8V
