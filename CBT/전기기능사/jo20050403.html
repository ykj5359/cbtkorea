2. 10[V/m]의 전장에 어떤 전하를 놓으면 0.1[N]의 힘이 작용한다. 전하의 양[C]은?

  1. 10-5
  2. 10-4
  3. 10-3
  4. 10-2
(정답률: 56%)
  • 30 CBT 기출문제AI

    2023-04-12 18:30

    전하의 힘은 전장과 전하의 크기에 비례한다. 따라서 전하의 크기를 Q라고 하면 다음과 같은 식이 성립한다.

    0.1[N] = 10[V/m] * Q[C]

    이를 Q에 대해 정리하면 다음과 같다.

    Q[C] = 0.1[N] / 10[V/m] = 0.01[C]

    따라서 정답은 "10-2"이다.

3. 100[V], 500[W]의 전열선 2개를 같은 전압에서 직렬로 접속한 경우는 병렬로 접속한 경우의 전력의 몇 배인가?

  1. 1/2배
  2. 1/4배
  3. 2배
  4. 4배
(정답률: 40%)
  • 30 CBT 기출문제AI

    2023-04-12 18:30

    전열선의 저항은 전력과 전압의 관계식인 P=V^2/R 에서 R=V^2/P 으로 구할 수 있다. 따라서 100V, 500W의 전열선의 저항은 각각 200옴이다.

    직렬 접속한 경우, 전류는 같으므로 전압이 저항에 비례하여 분배된다. 따라서 각 전열선에 걸리는 전압은 50V이다. 이때 각 전열선의 전력은 P=V^2/R = 50^2/200 = 12.5W 이다. 따라서 전체 전력은 25W 이다.

    병렬 접속한 경우, 전압은 같으므로 각 전열선에 걸리는 전압은 100V이다. 이때 각 전열선의 전력은 P=V^2/R = 100^2/200 = 50W 이다. 따라서 전체 전력은 100W 이다.

    따라서 직렬 접속한 경우의 전력은 병렬 접속한 경우의 전력의 1/4배이다. 이는 각 전열선의 저항이 같은 경우에 한정된 결과이다.
