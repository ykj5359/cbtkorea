2. 인덕턴스 0.5H에 주파수가 60 Hz이고 전압이 220V인 교류 전압이 가해질 때 흐르는 전류는 약 몇 A 인가?

  1. 0.59
  2. 0.87
  3. 0.97
  4. 1.17
(정답률: 54%)
  • 30 CBT 기출문제AI

    2023-04-12 18:20

    인덕턴스 L, 주파수 f, 전압 V가 주어졌을 때, 인덕턴스에 흐르는 전류 I는 다음과 같이 계산할 수 있습니다.

    I = V / (2πfL)

    여기서, 2πfL은 인덕턴스의 임피던스(Z)를 나타냅니다.

    Z = 2πfL

    따라서, I = V / Z 입니다.

    주어진 문제에서, L = 0.5H, f = 60Hz, V = 220V 이므로,

    Z = 2πfL = 2π × 60 × 0.5 = 188.5Ω

    I = V / Z = 220 / 188.5 = 1.17A

    따라서, 정답은 "1.17"입니다.

9. 200 V의 교류전원에 선풍기를 접속하고 전력과 전류를 측정하였더니 600 W, 5 A 이였다. 이 선풍기의 역률은?

  1. 0.5
  2. 0.6
  3. 0.7
  4. 0.8
(정답률: 66%)
  • 30 CBT 기출문제AI

    2023-04-12 18:20

    역률은 유효전력과 피상전력의 비율로 정의됩니다. 유효전력은 실제로 선풍기가 사용하는 전력으로, 피상전력은 선풍기에 공급되는 전력입니다.

    유효전력은 P = VIcos(θ)로 계산할 수 있습니다. 여기서 V는 전압, I는 전류, cos(θ)는 역률입니다.

    피상전력은 S = VI로 계산할 수 있습니다.

    따라서 역률은 cos(θ) = P/S로 계산할 수 있습니다.

    주어진 값으로 계산하면,

    유효전력 P = 600 W
    피상전력 S = 200 V x 5 A = 1000 W

    cos(θ) = P/S = 600/1000 = 0.6

    따라서 정답은 "0.6"입니다. 이는 선풍기가 전체 공급 전력의 60%를 실제로 사용하고 있다는 것을 의미합니다.

10. 임의의 폐회로에서 키르히호프의 제2법칙을 가장 잘 나타낸 것은?

  1. 기전력의 합 = 합성 저항의 합
  2. 기전력의 합 = 전압 강하의 합
  3. 전압 강하의 합 = 합성 저항의 합
  4. 합성 저항의 합 = 회로 전류의 합
(정답률: 72%)
  • 30 CBT 기출문제AI

    2023-04-12 18:20

    정답: 전압 강하의 합 = 합성 저항의 합

    키르히호프의 제2법칙은 "회로의 닫힌 경로를 따라 합성 전압이 0이 되어야 한다"는 법칙입니다. 이 법칙은 전기 회로에서 전압과 전류의 관계를 설명하는 법칙 중 하나입니다.

    전압은 전기 회로에서 전하가 이동할 때 발생하는 전기적인 차이를 의미합니다. 전압은 전기 회로의 각 부분에서 발생하며, 이러한 전압은 회로의 전체 전압과 합쳐져야 합니다.

    전압 강하는 전기 회로에서 전압이 감소하는 것을 의미합니다. 전압 강하는 회로의 각 부분에서 발생하며, 이러한 전압 강하는 회로의 전체 전압과 합쳐져야 합니다.

    합성 저항은 전기 회로에서 여러 개의 저항이 직렬 또는 병렬로 연결되어 있는 경우, 이를 하나의 저항으로 대체한 것을 의미합니다. 합성 저항은 회로의 전체 저항과 같습니다.

    따라서, 키르히호프의 제2법칙에서는 전압 강하의 합이 합성 저항의 합과 같아야 합니다. 이는 전압과 전류의 관계를 설명하는 법칙 중 하나이며, 전기 회로에서 매우 중요한 개념입니다.

18. 2개의 저항 R1, R2를 병렬 접속하면 합성 저항은?

  1. 1/(R1+ R2)
  2. R1/(R1+ R2)
  3. (R1× R2)/(R1+ R2)
  4. R2/(R1+ R2)
(정답률: 83%)
  • 30 CBT 기출문제AI

    2023-04-12 18:20

    병렬 접속된 저항들은 전압은 같고 전류는 각각 다르게 흐르게 됩니다. 이때 전류의 총량은 각각의 전류의 합과 같으므로, 전압이 같은 저항들의 병렬 접속에서는 전류가 작은 저항이 더 큰 저항보다 더 많은 전류를 받게 됩니다.

    따라서 병렬 접속된 저항들의 합성 저항은 각각의 저항이 받는 전압이 같으므로, 각각의 저항에서의 전류 비율에 따라 가중 평균을 구해야 합니다. 이때 가중치는 각각의 저항의 저항값의 역수(1/R)입니다.

    따라서 병렬 접속된 저항들의 합성 저항은 (R1× R2)/(R1+ R2)입니다.

55. 전주의 길이가 16m 이고, 설계하중이 6.8kN 이하의 철근 콘크리트주를 시설할 때 땅에 묻히는 깊이는 몇 m 이상이어야 하는가?

  1. 1.2
  2. 1.4
  3. 2.0
  4. 2.5
(정답률: 54%)
  • 30 CBT 기출문제AI

    2023-04-12 18:20

    전주의 길이가 16m 이므로, 중앙에서 가장 큰 하중이 작용하게 됩니다. 따라서, 중앙에서의 최대 굽힘모멘트를 구해야 합니다.

    최대 굽힘모멘트 = (설계하중) x (전주의 길이)^2 / 8
    = 6.8 x 16^2 / 8
    = 217.6 kN·m

    이제, 이 최대 굽힘모멘트를 버틸 수 있는 단면적을 구해야 합니다. 이를 위해, 철근의 항복강도와 콘크리트의 압축강도를 알아야 합니다. 여기서는 철근의 항복강도를 420 MPa, 콘크리트의 압축강도를 21 MPa로 가정하겠습니다.

    최대 굽힘모멘트 = (단면적) x (철근의 항복강도) x (콘크리트의 압축강도) x (전주의 높이) / 2
    단면적 = 최대 굽힘모멘트 x 2 / (철근의 항복강도 x 콘크리트의 압축강도 x 전주의 높이)
    = 217.6 x 2 / (420 x 21 x 전주의 높이)
    = 0.0025 / 전주의 높이

    여기서, 단면적은 전주의 높이에 반비례하므로, 전주의 높이가 클수록 단면적은 작아집니다. 따라서, 전주의 높이가 가장 작은 지점에서의 단면적을 구해야 합니다. 이 지점에서의 전주의 높이를 h라고 하면,

    단면적 = 0.0025 / h
    = (π x (전주의 너비 / 2)^2) x (h + 0.⑤)
    = (π x (0.2 / 2)^2) x (h + 0.⑤)
    = 0.00785 x (h + 0.⑤)

    여기서, 전주의 너비는 0.2m, 철근의 지름은 16mm로 가정하였습니다. 이제, 이 단면적이 최소한으로 필요한 단면적보다 크거나 같아야 합니다. 이를 수식으로 나타내면,

    0.00785 x (h + 0.⑤) >= 0.0025 / h
    h^2 + 0.⑤h - 0.3185 <= 0

    위의 이차부등식을 풀면, h >= 2.5 를 얻을 수 있습니다. 따라서, 땅에 묻히는 깊이는 2.5m 이상이어야 합니다.

60. 150kW의 수전설비에서 역률을 80%에서 95%로 개선하려고 한다. 이때 전력용 콘덴서의 용량은 몇 kVA인가?

  1. 63.2
  2. 126.4
  3. 144.5
  4. 157.6
(정답률: 23%)
  • 30 CBT 기출문제AI

    2023-04-12 18:19

    전력용 콘덴서의 용량은 다음과 같이 계산할 수 있다.

    개선 전의 유효전력 = 150kW × 0.8 = 120kW
    개선 후의 유효전력 = 150kW
    개선 전의 무효전력 = sqrt(1 - 0.8^2) × 120kW = 96kVAR
    개선 후의 무효전력 = sqrt(1 - 0.95^2) × 150kW = 22.5kVAR

    따라서, 필요한 전력용 콘덴서의 용량은 다음과 같다.

    전력용 콘덴서의 용량 = (96 - 22.5) kVAR = 73.5 kVAR = 73.5 kVA

    하지만, 문제에서는 단위를 kVA로 요구하고 있으므로, 용량을 kVA로 변환해야 한다.

    전력용 콘덴서의 용량 = 73.5 kVA ≈ 63.2 kVA (소수점 이하 버림)

    따라서, 정답은 "63.2"이다.
