5. E=100+j20[V] 와 I=20-j30[A]일 때 유효전력 P는 몇[W]인가?

  4. 2600

    E와 I의 위상차이는 j로 표현된 부분에서 나타나는데, j는 90도를 나타내는 복소수입니다. 따라서 E와 I의 위상차이는 90도 + 90도 = 180도입니다.

    cos(180도)는 -1이므로, 유효전력 P는 다음과 같이 계산할 수 있습니다.

    P = Re(EI*) = Re((100+j20)(20+j30)*) = Re((100+j20)(20-j30)) = Re(1400-j400) = 1400

    따라서 정답은 "1400"입니다.
