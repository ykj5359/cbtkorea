8. 단면적 4cm2, 자기 통로의 평균 길이 50㎝, 코일 감은 횟수 1000회, 비투자율 2000 인 환상 솔레노이드가 있다. 이 솔레노이드의 자체 인덕턴스는?(단 진공 중의 투자율 μo는 4π × 10-7임)

  1. 약 2[H]
  2. 약 20[H]
  3. 약 200[H]
  4. 약 2000[H]
(정답률: 29%)
  • 30 CBT 기출문제AI

    2023-04-12 18:15

    환상 솔레노이드의 자체 인덕턴스는 다음과 같이 계산할 수 있습니다.

    L = μo * N^2 * A / l

    여기서,
    μo는 진공 중의 투자율으로 주어졌으므로 4π × 10^-7을 대입합니다.
    N은 코일 감은 횟수로 주어졌으므로 1000을 대입합니다.
    A는 단면적으로 주어졌으므로 4cm^2를 10^-4로 변환하여 대입합니다.
    l은 자기 통로의 평균 길이로 주어졌으므로 50cm를 0.5m로 변환하여 대입합니다.

    따라서, L = 4π × 10^-7 * 1000^2 * 4 × 10^-4 / 0.5 = 약 2[H]가 됩니다.

    따라서, 정답은 "약 2[H]"입니다.

9. 두개의 자체 인덕턴스를 직렬로 접속하여 합성 인덕턴스를 측정하였더니 95mH 이었다. 한쪽 인덕턴스를 반대 접속하여 측정하였더니 합성 인덕턴스가 15mH로 되었다. 두 코일의 상호 인덕턴스는?

  1. 20[mH]
  2. 40[mH]
  3. 80[mH]
  4. 160[mH]
(정답률: 91%)
  • 30 CBT 기출문제AI

    2023-04-12 18:15

    두 코일의 상호 인덕턴스는 다음과 같이 구할 수 있습니다.

    두 코일의 자체 인덕턴스를 각각 L1, L2라고 하면, 직렬 접속 시 합성 인덕턴스는 L1 + L2입니다.
    따라서, L1 + L2 = 95mH ... (식 1)

    한쪽 코일을 반대로 접속하면, 합성 인덕턴스는 L1 - L2가 됩니다.
    즉, L1 - L2 = 15mH ... (식 2)

    식 1과 식 2를 더하면, 2L1 = 110mH가 됩니다.
    따라서, L1 = 55mH입니다.

    식 1에 L1 = 55mH를 대입하면, L2 = 40mH가 됩니다.

    따라서, 두 코일의 상호 인덕턴스는 Lm = L1 + L2 = 55mH + 40mH = 95mH입니다.

    따라서, 정답은 "20[mH]"입니다.

37. 60Hz, 4극, 슬립 5%이 유도 전동기의 회전수는?

    = 900 x (1 - 0.⑤)
    = 855 rpm

    구부린 부분의 길이 = 2πr/4 = πr/2

    전체 길이 = 2π(R+r)

    여기서 R은 전선관의 반지름, 즉 (D+d)/2이다.

    따라서, 구부린 부분의 길이와 전체 길이를 이용하여 r을 구하면 다음과 같다.

    πr/2 = 2π(R+r)/4

    r = 2(R+r)/4

    r = (D+d)/2 + r/2

    r/2 = (D+d)/4 - d

    r = 2(D+d)/4 - 2d

    r = D/2 + d - 2d

    r = D/2 - d

    따라서, r = 6d + D/2가 된다.
