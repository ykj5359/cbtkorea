    Y결선 → △결선: R1 = (Rab x Rac) / (Rab + Rac + Rbc), R2 = (Rab x Rbc) / (Rab + Rac + Rbc), R3 = (Rac x Rbc) / (Rab + Rac + Rbc)

    △결선 → Y결선: Rab = (R1 x R2 + R2 x R3 + R3 x R1) / R1, Rac = (R1 x R2 + R2 x R3 + R3 x R1) / R3, Rbc = (R1 x R2 + R2 x R3 + R3 x R1) / R2
