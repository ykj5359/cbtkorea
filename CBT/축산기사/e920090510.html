    A의 부모는 A와 B이므로, A의 근교계수는 (0.5 + 0.25)/2 = 0.375입니다. A와 C의 자손은 교배하지 않았으므로, A와 C의 근교계수는 0입니다. 따라서 A의 총 근교계수는 (0.375 + 0)/2 = 0.1875입니다. 하지만 A와 D의 자손은 반형매간교배를 통해 생산되었으므로, A와 D의 근교계수는 0.375/2 = 0.1875입니다. 마지막으로 A와 E의 자손은 A와 D의 자손과 C와 교배를 했으므로, A와 E의 근교계수는 (0.1875 + 0)/2 = 0.09375입니다. 따라서 A의 근교계수는 A와 E의 근교계수인 0.09375/2 = 0.046875와 A와 D의 근교계수인 0.1875/2 = 0.09375의 합인 0.140625입니다. 이를 간단하게 표현하면 0.140625 = 0.125 + 0.015625이므로, A의 근교계수는 0.125입니다.

15. 돼지의 154 일령 체중에 대해 개체 선발을 한 결과 암퇘지와 수퇘지에 대한 선발차가 각각 3kg과 5kg이었다. 154일령 체중의 유전력이 0.2인 경우 기대되는 세대별 유전적 개량량은 얼마인가?

  1. 0.6kg
  2. 0.8kg
  3. 1.0kg
  4. 1.6kg
(정답률: 71%)
  • 30 CBT 기출문제AI

    2023-04-18 14:36

    유전적 개량량은 선택한 개체의 평균 체중과 전체 개체의 평균 체중 간의 차이를 의미한다. 따라서 암퇘지와 수퇘지의 선발차이를 더한 후 2로 나눈 값이 선택한 개체의 평균 체중이 된다.

    암퇘지와 수퇘지의 선발차이 = 3kg + 5kg = 8kg
    선택한 개체의 평균 체중 = 8kg / 2 = 4kg

    전체 개체의 평균 체중은 선택한 개체와 선택되지 않은 개체의 평균 체중의 가중평균으로 계산된다. 따라서 선택되지 않은 개체의 평균 체중은 선택한 개체의 평균 체중보다 작을 것이다. 이 경우 유전력이 0.2이므로 선택되지 않은 개체의 평균 체중은 선택한 개체의 평균 체중보다 0.2배 작을 것이다.

    선택되지 않은 개체의 평균 체중 = 4kg * 0.2 = 0.8kg
    전체 개체의 평균 체중 = (선택한 개체의 평균 체중 * 선택한 개체의 수 + 선택되지 않은 개체의 평균 체중 * 선택되지 않은 개체의 수) / 전체 개체의 수
    = (4kg * 1 + 0.8kg * 4) / 5
    = 1.6kg

    따라서 유전적 개량량은 전체 개체의 평균 체중과 선택한 개체의 평균 체중 간의 차이인 1.6kg - 4kg = -2.4kg 이다. 하지만 이 값은 선택한 개체의 평균 체중이 전체 개체의 평균 체중보다 크다는 가정에 기반하고 있으므로, 선택한 개체의 평균 체중이 전체 개체의 평균 체중보다 작은 경우에는 유전적 개량량이 양수가 될 수 있다. 따라서 보기에서 유전적 개량량이 0.8kg인 것이다.
