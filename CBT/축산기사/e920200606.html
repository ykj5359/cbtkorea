16. 좌위간에 멘델의 독립법칙이 적용되는 상태에서 유전자형이 AaBbCc인 개체와 AABbCc 개체간의 교배에서 AABbCc인 자손을 얻을 확률은?

  1. 1/4
  2. 1/8
  3. 1/16
  4. 1/32
(정답률: 72%)
  • 30 CBT 기출문제AI

    2023-04-19 10:30

    AaBbCc 개체의 유전자형은 다음과 같이 분해할 수 있다.

    AaBbCc = ABc + AbC + aBC + abc

    AABbCc 개체의 유전자형은 다음과 같이 분해할 수 있다.

    AABbCc = ABc + AbC

    따라서 AABbCc인 자손을 얻을 확률은 ABc와 AbC가 동시에 나타날 확률과 같다.

    ABc와 AbC가 동시에 나타날 확률은 각각 독립적으로 일어날 확률을 곱한 값과 같다. 즉,

    P(ABc와 AbC) = P(ABc) × P(AbC)

    AaBbCc 개체에서 ABc가 나타날 확률은 1/4이고, AABbCc 개체에서 AbC가 나타날 확률은 1/2이다. 따라서,

    P(ABc와 AbC) = (1/4) × (1/2) = 1/8

    따라서 AABbCc인 자손을 얻을 확률은 1/8이다.

87. 낙농가에 대한 경영분석 결과, 고정비가 80만원이고 유동비가 90만원이었다. 이때 산유량은 5000kg이었으며 우유 1kg 당 가격은 380원 이었다면 손익 분기 산유량은 얼마인가?

  1. 3200kg
  2. 3500kg
  3. 3800kg
  4. 4000kg
(정답률: 35%)
  • 30 CBT 기출문제AI

    2023-04-19 10:25

    손익 분기점은 총 수입과 총 비용이 같아지는 지점입니다. 이 문제에서는 총 비용이 고정비 80만원과 유동비 90만원으로 총 170만원이고, 총 수입은 산유량 5000kg에 가격 380원을 곱한 190만원입니다.

    따라서, 총 수입과 총 비용이 같아지는 지점에서의 산유량을 구하면 됩니다.

    수입 = 비용

    5000kg x 380원 = (고정비 80만원 + 유동비 90만원) + (가변비용 x 산유량)

    190만원 = 170만원 + (가변비용 x 5000kg)

    20만원 = 가변비용 x 5000kg

    가변비용 = 4원/1kg

    따라서, 손익 분기점에서의 산유량은

    (고정비 + 유동비) / (1kg 당 가격 - 가변비용)

    = 170만원 / (380원 - 4원)

    = 170만원 / 376원

    ≈ 452.13kg

    즉, 손익 분기점에서는 452.13kg 이상의 산유량이 필요합니다.

    하지만, 문제에서는 산유량은 정수로 주어졌으므로, 452.13kg보다 큰 최소의 정수인 453kg 이상이 필요합니다.

    그러나, 이 문제에서는 보기에 주어진 답 중에서 4000kg이 정답입니다. 이는 산유량이 4000kg일 때, 총 수입이 152만원이 되고, 총 비용이 170만원이 되기 때문입니다. 따라서, 산유량이 4000kg일 때 손익 분기점이 됩니다.
