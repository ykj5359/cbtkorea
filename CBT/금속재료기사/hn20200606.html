    NiO와 Ni가 평형으로 공존하는 상황에서, Gibbs 자유에너지 변화는 0이어야 합니다. 즉,

    ΔG = ΔH - TΔS = 0

    NiO(s): ΔH = -242.2 kJ/mol, ΔS = 43.6 J/(mol·K)

    Ni(g): ΔH = 431.3 kJ/mol, ΔS = 191.7 J/(mol·K)
    NiO(g): ΔH = -157.2 kJ/mol, ΔS = 197.9 J/(mol·K)

    ΔH = ΔH(products) - ΔH(reactants)
    = [ΔH(NiO(g)) + ΔH(Ni(s))] - [ΔH(NiO(s)) + ΔH(Ni(g))]
    = [(-157.2 kJ/mol) + (0 kJ/mol)] - [(-242.2 kJ/mol) + (431.3 kJ/mol)]

    = [ΔS(NiO(g)) + ΔS(Ni(s))] - [ΔS(NiO(s)) + ΔS(Ni(g))]
    = [(197.9 J/(mol·K)) + (29.8 J/(mol·K))] - [(43.6 J/(mol·K)) + (191.7 J/(mol·K))]
    = -6.6 J/(mol·K)

    0 = ΔH - TΔS

    = -4581.35 K
