8. 너비가 5mm이고 단면의 높이가 8mm, 길이가 40mm인 키에 작용하는 전단력은?(단. 키의 허용전단응력은 2MPa이다)

  1. 200N
  2. 400N
  3. 800N
  4. 4000N
(정답률: 42%)
  • 30 CBT 기출문제AI

    2023-04-13 00:17

    전단응력 = 전단력 / 단면적

    단면적 = 너비 x 높이 = 5mm x 8mm = 40mm²

    허용전단응력 = 2MPa = 2N/mm²

    전단응력 = 전단력 / 단면적 = 전단력 / 40mm²

    전단력 = 전단응력 x 단면적 = 2N/mm² x 40mm² = 80N

    하지만 문제에서는 단면의 길이가 40mm이므로, 전단력은 길이에 비례한다.

    전단력 = 전단응력 x 단면적 x 길이 = 2N/mm² x 40mm² x 40mm = 32000N

    하지만 문제에서는 허용전단응력이 2MPa로 제한되어 있으므로, 전단력은 다음과 같이 계산된다.

    전단력 = 허용전단응력 x 단면적 = 2MPa x 40mm² = 800N

    따라서, 키에 작용하는 전단력은 800N이며, 보기에서 정답은 "400N"이 아닌 "800N"이다.
1

15. 표전 평기어에서 피치원지름이 600mm, 모듈이 10인 경우 기어의 잇수는 몇 개인가?

  1. 50
  2. 60
  3. 100
  4. 120
(정답률: 90%)
  • 30 CBT 기출문제AI

    2023-04-13 10:57

    피치원지름이 600mm이므로 원주는 π × 600 ≈ 1885.44mm 입니다. 모듈이 10이므로 한 치의 높이는 10mm이 됩니다. 따라서 한 바퀴 돌 때마다 기어가 이동하는 거리는 1885.44mm 입니다. 이동 거리가 한 바퀴 돌 때마다 1885.44mm 이므로, 1000mm(1m)를 이동하기 위해서는 1000 ÷ 1885.44 ≈ 0.53바퀴를 돌아야 합니다. 이때 바퀴가 몇 번 도는지를 나타내는 것이 바로 기어의 잇수입니다. 따라서 기어의 잇수는 1 ÷ 0.53 ≈ 1.89개가 됩니다. 하지만 기어의 잇수는 정수이어야 하므로, 가장 가까운 정수인 2를 선택합니다. 따라서 정답은 2의 배수인 60이 됩니다.
