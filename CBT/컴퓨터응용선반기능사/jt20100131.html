5. 양끝을 고정한 단면적 2cm2인 사각봉의 온도 -10℃에서 가열되어 50℃가 되었을 때 재료에 발생하는 열응력은?(단, 사각봉의 세로탄성계수는 21000N/mm2, 선형평창계수는 0.000012/℃이다.)

  1. 25.20 N/mm2
  2. 15.12 N/mm2
  3. 35.80 N/mm2
  4. 39.90 N/mm2
(정답률: 44%)
  • 30 CBT 기출문제AI

    2023-04-13 11:02

    먼저, 열응력을 구하기 위해서는 선형팽창계수와 온도 변화량, 그리고 세로탄성계수와 단면적이 필요합니다.

    선형팽창계수는 0.000012/℃이므로, 온도가 -10℃에서 50℃로 변화하면 60℃의 변화가 발생합니다. 따라서, 사각봉의 길이는 2cm에 0.000012 × 60℃ × 2cm = 0.00144cm만큼 증가합니다.

    이제, 이 증가한 길이와 단면적 2cm2를 이용하여 변형률을 구할 수 있습니다. 변형률은 (증가한 길이) / (원래 길이) = 0.00144cm / 2cm = 0.00072입니다.

    마지막으로, 세로탄성계수와 변형률, 그리고 온도 변화량을 이용하여 열응력을 구할 수 있습니다. 열응력은 세로탄성계수 × 변형률 × 온도 변화량 = 21000N/mm2 × 0.00072 × 60℃ = 907.2N/mm2입니다.

    하지만, 이 문제에서는 단면적이 2cm2이므로, 위에서 구한 열응력을 단면적으로 나누어줘야 합니다. 따라서, 최종적으로 구한 열응력은 907.2N/mm2 / 2cm2 = 453.6N/cm2 = 15.12 N/mm2입니다.

    따라서, 정답은 "15.12 N/mm2"입니다.

10. 외경이 500mm 내경이 490mm인 얇은 원통의 내부에 3MPa의 압력이 작용할 때 원주 방향의 응력은 몇 N/mm2인가?

  1. 75
  2. 147
  3. 222
  4. 294
(정답률: 51%)
  • 30 CBT 기출문제AI

    2023-04-13 11:02

    원통의 내부에 작용하는 압력은 P = 3MPa = 3N/mm^2 이다.

    원통의 두께가 매우 얇기 때문에, 원주 방향의 응력은 내부 압력과 외부 압력의 차이로 결정된다. 외부 압력은 대기압으로 가정한다.

    따라서, 원주 방향의 응력은 σ = (P - 0)/(D/2) = P/(D/2) = 3/(500-490)/2 = 147 N/mm^2 이다.

    따라서, 정답은 "147" 이다.

55. ø44 드릴 가공에서 절삭 속도 150 m/min, 이송 0.08㎜/rev일 때, 회전수와 이송 속도는 (feed rate)는?

  1. 1085 rpm, 86.8 ㎜/min
  2. 320 rpm, 3.52 ㎜/min
  3. 200 rpm, 3.41 ㎜/min
  4. 170 rpm, 34.1 ㎜/min

    이송 거리 = 0.08 / (1,085 × 60) = 0.0000013 × 60 × 1,000 = 0.078 ≈ 86.8 ㎜/min

57. 그림과 같은 원호보간 지령을 I, J를 사용하여 표현하면?

  1. G03 X20.0 Y20.0 I-20.0 ;
  2. G03 X20.0 Y20.0 I-20.0 J-20.0 ;
  3. G03 X20.0 Y20.0 J-20.0 ;
  4. G03 X20.0 Y20.0 I20.0 ;
(정답률: 42%)

    2023-04-13 11:01

    I는 원호의 중심에서 시작점까지의 X축 거리를 의미하고, J는 원호의 중심에서 시작점까지의 Y축 거리를 의미합니다. 따라서 "G03 X20.0 Y20.0 I-20.0 ;"는 현재 위치에서 X축으로 20.0만큼, Y축으로 20.0만큼 이동한 후, 반시계 방향으로 중심에서 20.0만큼 떨어진 곳에서 원호를 그리는 지령입니다. J값이 없는 이유는 원호의 중심에서 시작점까지의 Y축 거리가 0이기 때문입니다.
