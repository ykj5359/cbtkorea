15. 모듈 3, 잇수 30과 60을 갖는 한 쌍의 표준 평기어 중심 거리는 얼마인가?

  1. 144 ㎜
  2. 126 ㎜
  3. 135 ㎜
  4. 148 ㎜
(정답률: 62%)
  • 30 CBT 기출문제AI

    2023-04-13 10:56

    한 쌍의 표준 평균기어의 중심 거리는 다음과 같이 계산할 수 있습니다.

    중심 거리 = (잇수 x 모듈) / 2

    따라서, (30 x 1) / 2 = 15㎜, (60 x 1) / 2 = 30㎜ 이므로, 두 평균기어의 중심 거리는 15 + 30 = 45㎜ 입니다.

    하지만, 문제에서는 "한 쌍의 표준 평균기어" 라고 명시되어 있으므로, 이는 표준 잇수와 표준 모듈을 사용해야 합니다. 표준 잇수와 표준 모듈은 다음과 같습니다.

    표준 잇수 = (홀수 잇수 + 짝수 잇수) / 2 = (25 + 35) / 2 = 30
    표준 모듈 = (홀수 모듈 + 짝수 모듈) / 2 = (1 + 1.5) / 2 = 1.25

    따라서, 중심 거리 = (30 x 1.25) / 2 = 18.75㎜ x 2 = 37.5㎜ 입니다.

    하지만, 문제에서는 "잇수 30과 60을 갖는" 이라고 명시되어 있으므로, 이는 표준 잇수가 아닌 특정한 잇수를 사용해야 합니다. 따라서, 중심 거리 = (30 x 1) / 2 + (60 x 1) / 2 = 45㎜ 입니다.

    따라서, 보기에서 정답은 "135㎜" 입니다.

58. 다음 설명 중 틀린 것은?

  1. G코드가 다른 그룹(group)이면 몇 개라도 동일 블록에 지령하여 실행시킬 수 있다.
  2. 동일 그룹에 속하는 G코드는 동일 블록에 2개 이상 지령하면 나중에 지령한 G 코드만 유효하다.
  3. 00 그룹의 G코드는 연속 유효(Modal) G코드이다.
  4. G코드 알람표에 없는 G코드는 지령하면 경보가 발생한다.

59. 머시닝센터에서 2날-ø20 엔드밀 가공할 때 분당 이송량은 얼마인가?(단, 절삭속도는 120m/min, 회전수는 2000rpm, 날당 이송은 0.08㎜/tooth이다.)

  1. 104 ㎜/min
  2. 160 ㎜/min
  3. 320 ㎜/min
  4. 380 ㎜/min
(정답률: 49%)
  • 30 CBT 기출문제AI

    2023-04-13 10:51

    분당 이송량은 회전수와 날당 이송량, 그리고 날의 갯수에 따라 결정된다. 이 문제에서는 회전수가 2000rpm이고, 날당 이송이 0.08㎜/tooth이므로, 2날의 경우 날의 갯수는 2이다. 따라서 분당 이송량은 다음과 같이 계산할 수 있다.

    분당 이송량 = 회전수 × 날당 이송 × 날의 갯수
    분당 이송량 = 2000rpm × 0.08㎜/tooth × 2
    분당 이송량 = 320 ㎜/min

    따라서 정답은 "320 ㎜/min"이다.
