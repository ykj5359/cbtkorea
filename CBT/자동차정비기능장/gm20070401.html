10. 4행정 사이클 기관에서 행정 체적 Vs =1600cm3, 제동마력 Ne = 70PS, 회전수 n = 4500rpm일 경우 제동평균 유효압력 Pme 은 몇kgf/cm2 인가?

  2. 8.75
  3. 9.75
  4. 10.75
(정답률: 23%)

    제동평균 유효압력 Pme은 다음과 같은 식으로 계산됩니다.

    Pme = (Ne × 75) / (n × Vs)

    Pme = (70 × 75) / (4500 × 1600) ≈ 0.00781 kgf/cm²

    이 값은 소수점 이하가 있으므로, 반올림하여 최종 답인 8.75 kgf/cm²가 됩니다.

13. 4행정 사이클 기관의 구조가 스퀘어 스트로크 엔진(square stroke engine) 이며, 실제 흡입 공기량이 1117.5cc일 때 체적효율은 몇% 인가? (단, 실린더 수는 4개이며, 행정은 78mm이다.)

  1. 80
  2. 75
  3. 70
  4. 65
(정답률: 52%)
  • 30 CBT 기출문제AI

    2023-04-12 10:50

    스퀘어 스트로크 엔진은 스트로크와 보어의 길이가 같은 엔진을 말합니다. 따라서 이 엔진의 실린더 부피는 보어의 제곱에 스트로크를 곱한 값과 같습니다.

    한 실린더의 부피는 다음과 같이 계산할 수 있습니다.

    V = π/4 x (보어)^2 x 스트로크

    여기서 보어는 78mm이므로,

    V = π/4 x (78)^2 x 78 = 236.9cc

    따라서 4개의 실린더가 모두 작동할 때의 총 부피는 947.6cc가 됩니다.

    하지만 문제에서는 실제 흡입 공기량이 1117.5cc라고 주어졌습니다. 이는 엔진 내에서 실제로 연소가 일어나는 공기의 양을 의미합니다.

    따라서 체적효율은 다음과 같이 계산할 수 있습니다.

    체적효율 = (실제 흡입 공기량) / (총 부피) x 100%

    체적효율 = 1117.5 / 947.6 x 100% ≈ 117.8%

    하지만 체적효율은 100%를 넘을 수 없으므로, 정답은 75%가 됩니다.

46. 4극 발전기를 1800rpm으로 운전할 경우 이 발전기의 주파수(f)는 몇 Hz인가?

  1. 120
  2. 450
  3. 60
  4. 50
(정답률: 38%)
  • 30 CBT 기출문제AI

    2023-04-12 10:50

    4극 발전기는 2회전수(p)가 4이므로, 동기회전수(n)는 다음과 같이 계산됩니다.

    n = (120 x f) / p

    여기서, n은 1800rpm이므로 1800/60 = 30Hz입니다. 따라서, 위 식을 이용하여 f를 구하면 다음과 같습니다.

    f = (n x p) / 120 = (30 x 4) / 120 = 1Hz

    즉, 4극 발전기를 1800rpm으로 운전할 경우 주파수는 1Hz가 됩니다. 따라서, 보기에서 정답은 "60"이 아닙니다.

  1. 12500 cd
  2. 15000 cd
  3. 20000 cd
  4. 22000 cd
(정답률: 80%)
  • 30 CBT 기출문제AI

    2023-04-12 10:50

    조도는 광원에서 발산된 광속의 밀도를 나타내는 값이므로, 광원에서의 광도를 구하기 위해서는 거리의 제곱에 조도를 곱한 후 4π를 곱해야 한다. 따라서, 광원의 광도는 다음과 같이 계산할 수 있다.

    광원의 광도 = (조도 × 거리² × 4π) / 광속

    여기서, 거리는 50m, 조도는 8 Lx로 주어졌으며, 광속은 299,792,458 m/s로 정의되어 있다. 따라서, 광원의 광도를 계산하면 다음과 같다.

    광원의 광도 = (8 Lx × 50² m² × 4π) / 299,792,458 m/s
    ≈ 21,022 cd

    따라서, 가장 가까운 값은 20000 cd이다.
