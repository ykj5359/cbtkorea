6. 총배기량 1,600cc 이고, 실린더수가 4개, 연소실 체적이 50cc 일때 이 기관의 압축비는?

  1. 7
  2. 8
  3. 9
  4. 10
(정답률: 58%)
  • 30 CBT 기출문제AI

    2023-04-12 10:50

    압축비는 압축 상태와 흡기 상태에서 실린더 내부 공기의 부피 비율로 정의됩니다. 따라서 압축비는 다음과 같이 계산됩니다.

    압축비 = (압축 상태에서 실린더 내부 공기의 부피) / (흡기 상태에서 실린더 내부 공기의 부피)

    압축 상태에서 실린더 내부 공기의 부피는 다음과 같이 계산됩니다.

    압축 상태에서 실린더 내부 공기의 부피 = 연소실 체적 + 실린더 내부 공기의 부피

    여기서 실린더 내부 공기의 부피는 다음과 같이 계산됩니다.

    실린더 내부 공기의 부피 = 실린더 직경의 제곱 x π / 4 x 실린더 스트로크

    따라서 이 문제에서는 다음과 같이 압축비를 계산할 수 있습니다.

    압축 상태에서 실린더 내부 공기의 부피 = 50cc + (40mm / 2)² x π / 4 x 80mm = 50cc + 502.65cc = 552.65cc

    흡기 상태에서 실린더 내부 공기의 부피는 다음과 같이 계산됩니다.

    흡기 상태에서 실린더 내부 공기의 부피 = (40mm / 2)² x π / 4 x 80mm = 502.65cc

    따라서 압축비는 다음과 같이 계산됩니다.

    압축비 = 552.65cc / 502.65cc = 1.098 ≈ 9

    따라서 정답은 "9"입니다.

  3. 50%
  4. 35%
(정답률: 75%)
  • 30 CBT 기출문제AI

    2023-04-12 11:02

    Duty(%)는 한 주기 내에서 신호가 활성화된 시간의 비율을 나타내는 값입니다. 주파수가 20Hz이므로 1초 동안 20번의 주기가 발생합니다. 따라서 15ms의 가동시간은 한 주기 내에서 0.015초 동안 활성화된 것입니다. Duty(%)는 이를 주기 전체인 0.⑤초 중에서 비율로 나타낸 값이므로, 0.015/0.⑤ = 0.3 = 30%가 됩니다. 따라서 정답은 "30%"입니다.

16. 어느 기관의 냉각수 규정량이 16ℓ였다. 사용 중 주입된 냉각수량이 12ℓ였다면 라디에이터의 코어막힘률은 몇 %인가?

45. 1AH의 방전시 전해액 속에 물이 0.67g 생성될 때 황산은 몇g 소비되는가?

  1. 1.66g
  2. 3.06g
  3. 3.60g
  4. 3.66g
(정답률: 29%)
  • 30 CBT 기출문제AI

    2023-04-12 10:49

    1AH의 방전시 전해액 속에 생성된 물의 양은 0.67g이다. 이는 전해질의 양과 같으므로, 전해질의 양을 구하면 된다.

    물의 분자량은 18g/mol이므로, 0.67g의 물은 0.67/18 = 0.0372 몰이다. 이는 황산과 반응하여 생성된 수소의 몰과 같다.

    반응식은 다음과 같다.

    H2SO4 + 2H2O → 2H2 + H2SO4

    따라서, 1 몰의 황산이 2 몰의 수소를 생성하므로, 0.0372 몰의 수소를 생성하기 위해서는 0.0372/2 = 0.0186 몰의 황산이 필요하다.

    황산의 분자량은 98g/mol이므로, 0.0186 몰의 황산은 0.0186 x 98 = 1.82g이다.

    하지만, 반응식에서 보면 황산이 1 몰당 2 몰 소비되므로, 실제로 필요한 황산의 양은 1.82 x 2 = 3.64g이다.

    따라서, 정답은 3.66g이다.
