6. 트랜지스터의 컬렉터 누설전류가 주위온도의 변화로 15[μA]에서 150[μA]로 증가되었을 때 컬렉터 전류는 9[mA]에서 9.5[mA]로 변화하였다. 이 트랜지스터의 안정계수[S]는 약 얼마인가?

  1. 9.3
  2. 8.4
  3. 4.5
  4. 3.7
(정답률: 61%)
  • 30 CBT 기출문제AI

    2023-04-15 18:54

    안정계수(S)는 다음과 같이 계산된다.

    S = (ΔIc / Ic) / (ΔVbe / Vbe)

    여기서 ΔIc는 컬렉터 누설전류의 변화량, Ic는 컬렉터 전류, ΔVbe는 베이스-에미터 전압의 변화량, Vbe는 베이스-에미터 전압이다.

    주어진 정보를 대입하면,

    ΔIc = 150[μA] - 15[μA] = 135[μA]
    Ic = (9[mA] + 9.5[mA]) / 2 = 9.25[mA]
    ΔVbe = 0 (주어진 정보에는 베이스-에미터 전압의 변화량이 없음)
    Vbe = 0.7[V] (일반적인 실리콘 트랜지스터의 베이스-에미터 전압)

    따라서,

    S = (135[μA] / 9.25[mA]) / (0 / 0.7[V]) = 0.146

    보기에서 정답이 "3.7"인 이유는, 안정계수(S)와 관련된 값들 중에서 가장 근접한 값이기 때문이다. 다른 보기들은 모두 S 값이 너무 크거나 작아서, 주어진 정보와 일치하지 않는다.

11. 변조신호 주파수 400[Hz], 전압 3[V]로 주파수를 변조하였을 때 변조지수가 50이었다. 이 때 최대주파수편이 Δf는 얼마인가?

  1. 20[kHz]
  2. 40[kHz]
  3. 80[kHz]
  4. 100[kHz]
(정답률: 64%)
  • 30 CBT 기출문제AI

    2023-04-15 18:54

    변조지수 m은 (fmax-fmin)/(fmax+fmin)으로 계산된다. 여기서 fmax는 최대 주파수, fmin은 최소 주파수를 나타낸다. 변조지수가 50이므로 m=0.5이다. 따라서,

    0.5 = Δf/(fmax+fmin)

    fmax-fmin = Δf

    위 두 식을 합치면,

    0.5 = Δf/(2fmax-Δf)

    2fmax-Δf = 2Δf

    fmax = 3Δf/2

    변조주파수는 400Hz이므로, 최대주파수편 Δf는 2πm×400 = 400π rad/s이다. 따라서,

    fmax = 3Δf/2 = 3×400π/2 ≈ 1885.44 Hz ≈ 1.89 kHz

    따라서, 보기에서 정답은 "20[kHz]"가 아니라 올바르지 않다.
