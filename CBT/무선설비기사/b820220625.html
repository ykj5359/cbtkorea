2. 다음 정전압회로에서 제너 다이오드의 내부저항(ra)는 2[Ω]이고, 입력 직렬 저항(RS)는 500[Ω]일 경우 전압 안정계수(S)는 약 얼마인가?

  1. 0.004
  2. 0.0⑤
  3. 0.006
  4. 0.007
(정답률: 83%)
  • 30 CBT 기출문제AI

    2023-04-19 09:53

    정전압회로에서 전압 안정계수(S)는 다음과 같이 계산된다.

    S = ΔVout / ΔVin

    여기서 ΔVout은 출력 전압의 변화량, ΔVin은 입력 전압의 변화량을 의미한다.

    이 문제에서는 입력 전압이 일정하게 유지되고 있으므로 ΔVin = 0 이다. 따라서 전압 안정계수는 출력 전압의 변화량에 비례한다.

    제너 다이오드의 내부저항(ra)는 2[Ω]이므로, 출력 전압의 변화량은 다음과 같이 계산된다.

    ΔVout = ra / (RS + ra) × ΔVref

    여기서 ΔVref는 기준 전압의 변화량을 의미한다. 이 문제에서는 ΔVref = 1[V]로 가정하자.

    따라서,

    ΔVout = 2[Ω] / (500[Ω] + 2[Ω]) × 1[V] = 0.003984[V]

    전압 안정계수는 ΔVout에 비례하므로,

    S = ΔVout / ΔVin = 0.003984[V] / 1[V] = 0.004

    따라서, 정답은 "0.004"이다.

49. 어떤 전리층의 임계 주파수가 6[MHz]로 측정되었다. 이 전리층의 최대 전자밀도는?

  • 30 CBT 기출문제AI

    2023-04-19 09:59

    임계 주파수는 전자밀도가 최대가 되는 주파수이다. 따라서 최대 전자밀도를 구하기 위해서는 임계 주파수에서의 전자밀도를 구하면 된다.

    임계 주파수에서의 전자밀도는 다음과 같이 구할 수 있다.

    $$n_{max} = frac{epsilon_0 epsilon_r k T}{e^2} left(frac{omega_{p}}{omega_{c}}right)^2$$

    여기서 $epsilon_0$는 자유공간의 유전율, $epsilon_r$은 상대유전율, $k$는 볼츠만 상수, $T$는 절대온도, $e$는 전자의 전하량, $omega_{p}$는 플라즈마 주파수, $omega_{c}$는 비행성 자기장에서의 전자의 진동주파수이다.

    임계 주파수가 6[MHz]이므로, 이를 라디안 단위로 바꾸면 $omega_{c} = 2pi f_{c} = 2pi times 6 times 10^6 = 37.7 times 10^6$이 된다.

    플라즈마 주파수는 다음과 같이 구할 수 있다.

    $$omega_{p} = sqrt{frac{n_e e^2}{epsilon_0 epsilon_r m_e}}$$

    $$n_{max} = frac{epsilon_0 epsilon_r m_e omega_{c}^2}{e^2}$$
