11. 다음의 자기 바이어스회로(self-bias)에서 Ic의 경우 Ico에 대한 안정계수 S의 이론적 최소치는 어느 경우인가? (단, 1+β≫RB/RE, RB=R1//R2이다. )

  1. RB/RE → 100 일 때
  2. RB/RE → 0 일 때
  3. RB/RE → ∞ 일 때
  4. RB/RE → 1+β 일 때
(정답률: 59%)
  • 30 CBT 기출문제AI

    2023-04-15 19:01

    이 회로에서 Ic는 다음과 같이 구할 수 있다.

    Ic = (Vcc - Vbe) / (Rb + (β+1)Re)

    안정계수 S는 Ic의 변화에 대한 Ib의 변화의 비율로 정의된다.

    S = ΔIb / ΔIc

    따라서 S는 다음과 같이 구할 수 있다.

    S = (β+1)Re / (Rb + (β+1)Re)
