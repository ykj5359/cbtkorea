    f0 = 1 / (2π√(L·C1·C2))

6. 진폭변조에서 80[%] 변조하였을 때, 상측파대의 전력은 반송파 전력의 몇 [%] 인가?

  1. 16[%]
  2. 32[%]
  3. 40[%]
  4. 48[%]
(정답률: 66%)
  • 30 CBT 기출문제AI

    2023-04-15 18:59

    진폭변조에서 80% 변조하였다는 것은, 원래의 반송파 진폭의 80% 만큼 변화시켰다는 것을 의미합니다. 따라서 변조된 상측파의 진폭은 원래의 반송파 진폭의 80% + 원래의 상측파 진폭이 됩니다.

    전력은 진폭의 제곱에 비례하므로, 변조된 상측파의 전력은 다음과 같이 계산할 수 있습니다.

    변조된 상측파 전력 = (0.8A + A)^2 = 1.64A^2

    반송파 전력은 원래의 반송파 진폭의 제곱에 비례하므로, 다음과 같이 계산할 수 있습니다.

    반송파 전력 = A^2

    따라서 변조된 상측파 전력이 반송파 전력의 몇 % 인지 계산하면 다음과 같습니다.

    (변조된 상측파 전력 / 반송파 전력) x 100% = (1.64A^2 / A^2) x 100% = 164%

    즉, 변조된 상측파 전력은 반송파 전력의 164% 이므로, 보기에서 정답은 "16%" 입니다.

    = 112.45 dB
