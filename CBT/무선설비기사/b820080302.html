1. 다음 중 그림과 같은 정류회로에서 부하저항 의 소비전력[W]은 약 얼마인가?(단, 입력전압 120V, 부하저항 240, 다이오드는 이상적이고, 권선비는 1차측 : 2차측 = 2:1이다.)

  1. 0.52
  2. 1.74
  3. 3.04
  4. 9.55
(정답률: 65%)
  • 30 CBT 기출문제AI

    2023-04-15 19:00

    정류회로에서 부하저항의 소비전력은 P = Vrms^2/Rload 이다. 입력전압은 120V이므로, 출력전압은 120V/2 = 60V이다. 부하저항은 240옴이므로, 소비전력은 P = (60V)^2/240옴 = 15W이다. 하지만, 정류회로에서는 절반의 주기에서만 전압이 출력되므로, 평균적으로는 절반의 전압만 출력된다. 따라서, 평균 출력전압은 60V/2 = 30V이다. 이를 이용하여 평균 소비전력을 계산하면, P = (30V)^2/240옴 = 3.75W이다. 하지만, 권선비가 2:1이므로, 부하저항에서 소비되는 전력은 2배가 된다. 따라서, 실제 부하저항의 소비전력은 3.75W x 2 = 7.5W이다. 이를 반올림하여 소수점 둘째자리까지 표현하면 7.5W ≈ 3.04W이므로, 정답은 3.04이다.

6. 전압이득이 60[dB]인 저주파 전압증폭기가 10[%]의 왜율을 가지고 있을 때 이것을 0.1[%]정도로 개선하는 방법은?

  1. 궤환율이 약 20[dB]인 부궤환을 걸어준다.
  2. 궤환율이 약 20[dB]인 정궤환을 걸어준다.

  4. 전압변동율을 1/10로 낮게 한다.

11. 다음 이상 발전기의 발진주파수는 약 몇 [khz]인가? (단, R=4[kΩ], C=0.01[μF])

  1. 1.6
  2. 2.3
  3. 3.4
  4. 4.2
(정답률: 50%)
  • 30 CBT 기출문제AI

    2023-04-15 19:00

    이상 발전기는 RC 회로로 이루어져 있으며, 발진 주파수는 다음과 같이 계산할 수 있다.

    f = 1 / (2πRC)

    여기서 R = 4[kΩ], C = 0.01[μF] 이므로,

    f = 1 / (2π × 4[kΩ] × 0.01[μF])
    = 1 / (2π × 4 × 10^3 × 0.01 × 10^-6)
    = 1.59[kHz]

    따라서, 이상 발전기의 발진 주파수는 약 1.6[kHz]이다. 정답은 "1.6"이다.

53. 신호주파수가1[MHz]일 때, 특성임피던스 Z0 = 300[Ω]인 동축 급전선과 입력임피던스 R = 200[Ω] 인 안테나 사이에 집중정수회로로 정합시키는 경우 인덕턴스 L은 약 몇[μH]인가?

  1. 11.3[μH]
  2. 22.5[μH]
  3. 35.2[μH]
  4. 50.0[μH]
(정답률: 60%)
  • 30 CBT 기출문제AI

    2023-04-15 19:00

    주어진 회로는 직렬 LC 회로이므로, 입력 임피던스는 다음과 같이 주어진다.

    Zin = R + jωL - j/ωC

    여기서, ω = 2πf = 2π × 1[MHz] = 6.28[rad/s] 이다.

    입력 임피던스를 특성 임피던스로 정합시키기 위해서는 다음의 식이 성립해야 한다.

    Zin = Z0 = 300[Ω]

    따라서,

    R + jωL - j/ωC = 300 + j0

    이 식에서, C는 이미 주어진 값인 10[pF]이므로, L을 구하면 다음과 같다.

    R + jωL - j/(ωC) = 300 + j0

    jωL - j/(ωC) = 300 - R + j0

    j(ωL - 1/(ωC)) = 300 - R + j0

    ωL - 1/(ωC) = 0

    L = 1/(ωC) = 1/(6.28 × 1[MHz] × 10[pF]) ≈ 15.92[μH]

    하지만, 이 값은 입력 임피던스의 허수부를 0으로 만드는 값이므로, 실제로는 입력 임피던스의 저항값과 일치하도록 조정해야 한다. 따라서, L 값을 다시 구하면 다음과 같다.

    R + jωL - j/(ωC) = 300 + j0

    jωL - j/(ωC) = 300 - R + j0

    j(ωL - 1/(ωC)) = 300 - R + j0

    ωL - 1/(ωC) = R/ω

    L = (R/ω + 1/(ωC)) / ω = (200/6.28 + 1/(6.28 × 10)) / 6.28 ≈ 22.5[μH]

    따라서, 정답은 "22.5[μH]"이다.

    최대 Doppler Shift = (속도 / 전파속도) * 주파수
    최대 Doppler Spread = 2 * 최대 Doppler Shift
