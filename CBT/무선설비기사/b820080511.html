14. 개루프 전압이득이 40[dB]인 저주파 증폭기에서 비직선 일그러짐이 10[%]일 때, 이것을 1[%]로 개선하기 위한 전압궤환율 β는?

  1. 1/40
  2. 9/100
  3. 9/1000
  4. 11/1000
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-15 19:01

    비직선 일그러짐이 10[%]이므로, 출력전압의 10[%]에 해당하는 왜곡전압이 존재한다. 따라서, 개선된 비율은 1[%]이므로, 출력전압의 1[%]에 해당하는 왜곡전압이 존재하도록 개선해야 한다.

    전압궤환율 β는 다음과 같이 정의된다.

    β = (ΔVout / Vout) / (ΔVin / Vin)

    여기서 ΔVout / Vout은 출력전압의 변화율, ΔVin / Vin은 입력전압의 변화율을 의미한다.

    개선된 비율이 1[%]이므로, 출력전압의 변화율은 0.01배가 된다. 따라서,

    0.01 = (ΔVout / Vout)

    개루프 전압이득이 40[dB]이므로, 출력전압과 입력전압의 비는 100배이다. 따라서,

    ΔVin / Vin = ΔVout / (100Vout)

    비직선 일그러짐이 10[%]이므로, 왜곡전압은 출력전압의 10[%]에 해당한다. 따라서,

    0.1 = (ΔVout / Vout)

    위의 식들을 종합하면,

    β = (0.1 / Vout) / (0.01 / (100Vout)) = 9/100

    따라서, 정답은 "9/100"이다.

    2023-04-15 19:01

    급전선과 안테나 간의 특성 임피던스 불일치로 인해 반사파가 발생한다. 이 때, 반사파와 정전파가 만나 상호 간섭하면서 전압 정재파비가 변화한다. 이를 방지하기 위해 급전선과 안테나 간의 임피던스 매칭이 필요하다.

    임피던스 차이는 복소 임피던스의 차이로 나타낸다. 따라서, 급전선과 안테나 간의 임피던스 차이는 다음과 같다.

    Z_diff = Z_antenna - Z_transmission_line
    = (1⑤ + j45) - 75
    = 30 + j45

    VSWR = (Z_antenna - Z_transmission_line) / (Z_antenna + Z_transmission_line)
    = (1⑤ + j45 - 75) / (1⑤ + j45 + 75)
    = (30 + j45) / (180 + j45)
    = 0.1667 + j0.25

    VSWR = (1 + Γ) / (1 - Γ)

    Γ = (VSWR - 1) / (VSWR + 1)
    = (0.1667 + j0.25 - 1) / (0.1667 + j0.25 + 1)
    = -0.6 + j0.4

    V_reflection = Γ * V_forward
    = (-0.6 + j0.4) * 1
    = -0.6 + j0.4

    |V| = |V_forward + V_reflection|
    = |1 - 0.6 + j(0.4)|
    = 1.8

    따라서, 정답은 "1.8" 이다.
