    2πfL = 1/(2πfC)
    L = 1/(4π^2f^2C)

    Z_L = √(R^2 + X_L^2)
    Z_C = 1/(2πfC)
    Z = Z_L - Z_C
    I = V/Z

    여기서 R은 코일의 저항으로, 주어지지 않았으므로 무시한다. f=1,200[kHz]일 때 Z_L과 Z_C를 구하면 다음과 같다.

    Z_C = 1/(2πfC) = 1/(2π×1,200×10^-12) = 132.7[Ω]

    Z = Z_L - Z_C = -89.2[Ω]
    I = V/Z = -11.2[μA]

    Z_L = 2πfL = 2π×1,020×88.4×10^-6 = 70.5[Ω]
    Z_C = 1/(2πfC) = 1/(2π×1,020×10^-12) = 124.9[Ω]

    I = V/Z = -18.4[μA]

    총 전력 = (송신기 출력) × (1 + 손실저항)
