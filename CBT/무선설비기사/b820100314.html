5. 다음 회로에서 RB값은 약 얼마인가? (단, VCC = 20[V], RC = 10[KΩ], RE = 0.47[KΩ], VCE = 5[V], β = 50, VBE = 0.7[V])

  1. 123[KΩ]
  2. 133[KΩ]
  3. 153[KΩ]
  4. 163[KΩ]
(정답률: 19%)
  • 30 CBT 기출문제AI

    2023-04-15 18:58



    위의 회로는 NPN 트랜지스터를 사용한 에미터 바이어스 구성이다. 이때, 베이스 전압 VB는 0.7[V]이다.

    VB = VCE + VE = 5[V] + 0.7[V] = 5.7[V]

    이때, 베이스 전류 IB는 다음과 같이 구할 수 있다.

    IB = (VB - VBE) / RB

    IC는 다음과 같이 구할 수 있다.

    IC = βIB

    그리고, 콜렉터 전류 IC는 다음과 같다.

    IC = (VC - VCE) / RC

    따라서, RB는 다음과 같이 구할 수 있다.

    RB = (VB - VBE) / IB = (5.7[V] - 0.7[V]) / (IC / β) = (5[V] / (IC / β))

    여기서, IC는 다음과 같다.

    IC = (VC - VCE) / RC = (20[V] - 5[V]) / 10[KΩ] = 1.5[mA]

    따라서, RB는 다음과 같다.

    RB = (5[V] / (1.5[mA] / 50)) = 133[KΩ]

    따라서, 정답은 "133[KΩ]"이다.
