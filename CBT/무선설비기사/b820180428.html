2. 다음 그림과 같은 회로의 입력에 120[Vrms], 60[Hz] 정현파 신호가 인가되었을 경우, 부하에 걸리는 직류전압은 약 얼마인가? (단, 다이오드에 걸리는 전압강하는 무시한다.)

  1. 169.9[V]
  2. 167.9[V]
  3. 164.9[V]
  4. 162.9[V]
(정답률: 46%)
  • 30 CBT 기출문제AI

    2023-04-15 18:44

    다이오드가 정방향으로 작동할 때, 입력 신호의 절반 주기 동안에는 다이오드가 전류를 통과시키고, 나머지 절반 주기 동안에는 전류가 차단된다. 따라서, 부하에 걸리는 직류전압은 입력 신호의 절반 주기 동안에만 발생한다.

    입력 전압의 효과적인 값은 120[Vrms]이므로, 최대 전압값은 120*√2 = 169.7[V]이다. 따라서, 부하에 걸리는 직류전압의 최대값은 169.7/π = 54[V]이다.

    하지만, 다이오드의 전압강하를 무시하면, 부하에 걸리는 직류전압은 입력 전압의 절반 값이 된다. 따라서, 부하에 걸리는 직류전압은 120/2 = 60[V]이다.

    하지만, 다이오드의 전압강하를 고려해야 하므로, 부하에 걸리는 직류전압은 169.7/π - 0.7 = 162.9[V]이다. 따라서, 정답은 "162.9[V]"이다.

5. 다음 회로에서 VGS가 -1.4[V], VDS가 4.5[V], IDS가 10[mA]일 때 RD와 RS의 값은?

  1. RD=410[Ω], RS=240[Ω]
  2. RD=410[Ω], RS=140[Ω]
  3. RD=310[Ω], RS=140[Ω]
  4. RD=310[Ω], RS=240[Ω]
(정답률: 68%)
  • 30 CBT 기출문제AI

    2023-04-15 18:44

    MOSFET의 작동 영역을 확인하기 위해 우선 VGS - Vth를 계산해야 한다. 여기서 Vth는 MOSFET의 문턱 전압(threshold voltage)으로, datasheet에서 확인할 수 있다. 이 MOSFET의 Vth는 -2[V]이므로, VGS - Vth = -1.4[V] - (-2[V]) = 0.6[V]이다. 이 값이 0보다 크므로 MOSFET은 적절한 작동 영역에 있다.

    다음으로, MOSFET의 ID-VDS 특성을 이용하여 RD와 RS의 값을 계산할 수 있다. MOSFET의 ID-VDS 특성은 다음과 같다.



    여기서 VDS = 4.5[V], ID = 10[mA]이므로, VDS = ID x RD + VDS,sat이 성립한다. 이를 RD에 대해 정리하면 RD = (VDS - VDS,sat) / ID = (4.5[V] - 0.1[V]) / 10[mA] = 410[Ω]이다.

    또한, MOSFET의 소자 내부에서 RS와 RD가 직렬로 연결되어 있으므로, RS는 다음과 같이 계산할 수 있다.

    RS = VGS / ID - RD = (-1.4[V]) / 10[mA] - 410[Ω] = 140[Ω]

    따라서 정답은 "RD=410[Ω], RS=140[Ω]"이다.
