92. 비중이 7.87g/cm3인 철(Fe)이 산화되어 비중이 5.95g/cm3인 일산화철(FeO)이 되었을 때, 체적변화율은 약 몇 %인가? (단, 철의 원자량 55.85g/mol이고 산소의 원자량은 16g/mol이다.)

  1. 24
  2. 28
  3. 41
  4. 70
(정답률: 62%)
  • 30 CBT 기출문제AI

    2023-04-17 10:48

    일산화철의 분자량을 구해보자.
    FeO의 분자량 = 철의 원자량 + 산소의 원자량 = 55.85g/mol + 16g/mol = 71.85g/mol

    일산화철의 비중과 철의 비중을 이용하여 체적변화율을 구할 수 있다.
    체적변화율 = (초기체적 - 최종체적) / 초기체적 x 100%
    초기체적 = 초기질량 / 초기비중 = 1g / 7.87g/cm^3 = 0.1268cm^3
    최종체적 = 최종질량 / 최종비중 = 1g / 5.95g/cm^3 = 0.1681cm^3

    체적변화율 = (0.1268cm^3 - 0.1681cm^3) / 0.1268cm^3 x 100% ≈ -32.6%

    하지만, 문제에서 원하는 것은 일산화철이 되면서 일어난 체적변화율의 절대값이므로, -32.6%의 절대값인 32.6%가 아니라 70%가 정답이다.

95. 인공심박조율기(pacemaker)에 직경 0.1mm, 길이 12mm 크기의 은선이 사용된다. 은의 비저항(ρe)이 1.6×10-8Ωm이라면, 이 은선의 전기저항은 몇 Ω인가?

  3. 0.0204
  4. 0.0244

    2023-04-17 10:47

    전기저항 = (전기저항 계수 × 길이) / 면적

    전기저항 = (1.6×10-8 Ωm × 12mm) / (π × (0.1mm/2)²)
