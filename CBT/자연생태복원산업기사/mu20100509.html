80. 다음 표에서 A, B, C 및 D의 Margalef의 종다양성지수는 각각 얼마인가?

  1. A=0.⑤, B=0.⑤, C=0.04, D=0.04
  2. A=2, B=2, C=1.5, D=1.5
  3. A=0.2000, B=0.9220, C=0.2800, D=0.9421
  4. A=0.8000, B=0.0780, C=0.7200, D=0.⑤79
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-17 14:07

    Margalef의 종다양성지수는 다음과 같이 계산됩니다.

    Margalef의 종다양성지수 = (종의 수 - 1) / ln(총 개체 수)

    따라서, 각각의 Margalef의 종다양성지수는 다음과 같습니다.

    A = (4 - 1) / ln(100) ≈ 2
    B = (4 - 1) / ln(100) ≈ 2
    C = (3 - 1) / ln(100) ≈ 1.5
    D = (3 - 1) / ln(100) ≈ 1.5

    따라서, 정답은 "A=2, B=2, C=1.5, D=1.5" 입니다.
