79. 다음 중 정보의 개념을 하위 개념에서 부터 상위 개념으로 나열한 것은?

  1. 필드(Field) → 레코드(Record) → 파일(File) → 문자(Character)
  2. 레코드(Record) → 파일(File) → 필드(Field) → 문자(Character)
  3. 문자(Character) → 필드(Field) → 레코드(Record) → 파일(File)
  4. 파일(File) → 문자(Character) → 필드(Field) → 레코드(Record)
(정답률: 50%)
  • 30 CBT 기출문제AI

    2023-04-18 20:22

    정답은 "문자(Character) → 필드(Field) → 레코드(Record) → 파일(File)" 이다.

    이유는 다음과 같다.

    - 문자(Character): 정보의 가장 작은 단위로, 알파벳, 숫자, 기호 등으로 이루어진 하나의 글자를 의미한다.
    - 필드(Field): 여러 개의 문자(Character)가 모여 하나의 의미를 가지는 데이터의 최소 단위로, 예를 들어 "이름", "나이", "성별" 등이 있다.
    - 레코드(Record): 여러 개의 필드(Field)가 모여 하나의 논리적인 단위를 이루는 데이터의 집합으로, 예를 들어 "고객 정보", "주문 정보" 등이 있다.
    - 파일(File): 여러 개의 레코드(Record)가 모여 하나의 물리적인 단위를 이루는 데이터의 집합으로, 예를 들어 "고객 정보 파일", "주문 정보 파일" 등이 있다.

    따라서, 정보의 개념을 하위 개념에서 부터 상위 개념으로 나열하면 문자(Character) → 필드(Field) → 레코드(Record) → 파일(File)이 된다.
