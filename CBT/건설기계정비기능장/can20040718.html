4. 제동 열효율 38%인 디젤기관에서 저위 발열량 10,100kcal/kg 인 경유를 사용할 때 연료소비율은 몇 g/(PS.h)인가?

  1. 155
  2. 165
  3. 176
  4. 186
(정답률: 42%)
  • 30 CBT 기출문제AI

    2023-04-12 10:00

    연료소비율은 다음과 같이 계산할 수 있습니다.

    연료소비율 = (연료유량 / 출력) * 3600

    여기서 출력은 PS 단위로 표시된 엔진의 출력을 의미합니다.

    따라서, 연료소비율을 계산하기 위해서는 먼저 출력을 계산해야 합니다.

    저위 발열량이 10,100kcal/kg 인 경유를 사용할 때, 연료의 열량은 다음과 같습니다.

    열량 = 10,100 kcal/kg

    따라서, 1 kg의 경유를 연소할 때 발생하는 열량은 10,100 kcal입니다.

    제동 열효율이 38%이므로, 1 kg의 경유를 연소할 때 엔진에서 사용할 수 있는 열량은 다음과 같습니다.

    사용할 수 있는 열량 = 10,100 kcal * 0.38 = 3,838 kcal

    연료소비율을 계산하기 위해서는 출력을 계산해야 합니다.

    제동 열효율이 38%이므로, 출력은 다음과 같습니다.

    출력 = 사용할 수 있는 열량 / 0.38 = 3,838 kcal / 0.38 = 10,100 PS

    따라서, 연료소비율은 다음과 같습니다.

    연료소비율 = (연료유량 / 출력) * 3600

    연료소비율 = (g / 10,100 PS) * 3600

    연료소비율 = 360,000 g / (10,100 PS * h)

    연료소비율 = 35.64 g / (PS.h)

    따라서, 연료소비율은 약 36 g/PS.h 입니다.

    하지만, 보기에서 주어진 답은 165 g/(PS.h) 입니다.

    이는 계산 과정에서 실수가 있었을 가능성이 있습니다.

50. 출력 토크 5.6[kgf.m], 회전수 30[rpm]인 피스톤 모터를 설계하려고 한다. 모터의 크기를 210[cm3/rev]로 할때 필요한 유압은 몇 [kgf/cm2]인가? (단, 모터의 토크효율 및 용적효율은 각각 90%로 한다.)

  1. 15.4[kgf/cm2]
  2. 16.8[kgf/cm2]
  3. 18.6[kgf/cm2]
  4. 20.3[kgf/cm2]
(정답률: 22%)
  • 30 CBT 기출문제AI

    2023-04-12 09:58

    유압 모터의 출력은 다음과 같이 구할 수 있다.

    출력 = 토크 × 회전수 / 9550

    여기서, 토크 효율과 용적 효율을 고려하여 유압 모터의 유량은 다음과 같이 구할 수 있다.

    유량 = 출력 / (토크 효율 × 용적 효율 × 210)

    따라서, 필요한 유압은 다음과 같이 구할 수 있다.

    유압 = 출력 / (유량 × 9.81)

    입력된 값에 대입하면,

    출력 = 5.6[kgf.m] × 30[rpm] / 9550 = 0.0176[kW]

    유량 = 0.0176[kW] / (0.9 × 0.9 × 210[cm3/rev]) = 0.00123[m3/s]

    유압 = 0.0176[kW] / (0.00123[m3/s] × 9.81) = 1.8 × 105[Pa]

    1[kgf/cm2] = 9.81[kPa] 이므로, 유압을 [kgf/cm2] 단위로 변환하면,

    유압 = 1.8 × 105[Pa] / 9.81[kgf/cm2] ≈ 18.4[kgf/cm2]

    따라서, 정답은 "18.6[kgf/cm2]" 이다.

57. 토출압력 5.4kgf/cm2의 펌프가 초당 0.2m3/sec의 토출량을 가진다. 펌프효율 η=0.85라고 하면 소요동력은 몇마력(PS)인가?
