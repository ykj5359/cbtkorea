10. 저위발열량 1⑤00kcal/kg인 경유를 사용하여 연료소비율 180g/ps·h로 운전하는 디젤기관의 열효율은 몇 %인가?

  1. 29.5
  2. 30.5
  3. 33.5
  4. 36.3
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-12 09:59

    열효율은 출력열 / 연료열로 계산됩니다. 따라서, 먼저 연료소비율을 kcal/h로 변환해야 합니다.

    연료소비율 = 180g/ps·h = 0.18kg/ps·h
    연료소비열 = 1⑤00kcal/kg x 0.18kg/ps·h = 1890kcal/ps·h

    이제 출력열을 계산해야 합니다. 디젤기관의 출력은 일반적으로 토크와 각속도에 의해 결정됩니다. 따라서, 이 문제에서는 출력을 직접 주어졌다고 가정하겠습니다.

    출력 = 100ps = 100kW
    출력열 = 100kW x 860kcal/kW = 86000kcal/h = 86000/3600kcal/s = 23.89kcal/ps

    따라서, 열효율은 다음과 같이 계산됩니다.

    열효율 = 출력열 / 연료소비열 x 100%
    = 23.89kcal/ps / 1890kcal/ps·h x 100%
    = 1.26% x 100%
    = 33.5%

    따라서, 정답은 "33.5"입니다.

55. 50℃, 압력 10kgf/cm2abs인 공기에서 밀도는 몇 kgf.sec2/m4 인가? (단, 공기를 이상기체로 가정하고 기체상수 R = 29.27 kgf.m/kg·K)이다.)

  1. 1.08
  2. 5.32
  3. 10.57
  4. 8.8
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-12 11:54

    이 문제에서는 밀도를 구하는 공식인 PV = mRT를 사용할 수 있습니다. 여기서 P는 압력, V는 체적, m은 질량, R은 기체상수, T는 절대온도를 나타냅니다.

    먼저, 절대온도인 50℃를 켈빈 온도로 변환해야 합니다. 50℃ + 273.15 = 323.15K입니다.

    다음으로, 압력을 kgf/m2 단위로 변환해야 합니다. 10kgf/cm2abs는 대기압을 기준으로 한 상대압력이므로, 절대압력으로 변환해야 합니다. 따라서 10 + 1.033 = 11.033kgf/cm2abs가 됩니다. 이를 kgf/m2 단위로 변환하면 1,083,300kgf/m2입니다.

    이제 PV = mRT를 사용하여 밀도를 구할 수 있습니다. 체적 V는 1m3으로 가정하겠습니다. 따라서 P = 1,083,300kgf/m2, R = 29.27kgf.m/kg·K, T = 323.15K입니다. 이를 대입하여 m을 구하면, m = P/RT = 1,083,300/(29.27 x 323.15) = 1.08kgf.sec2/m4가 됩니다.

    따라서 정답은 "1.08"입니다.
