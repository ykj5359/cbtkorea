58. 정상소요기간이 5일이고, 이때의 비용이 20,000원이며 특급소요기간이 3일이고, 이때의 비용이 30,000원이라면 비용구배는 얼마인가?

  1. 4,000원/일
  2. 5,000원/일
  3. 7,000원/일
  4. 10,000원/일
(정답률: 73%)
  • 30 CBT 기출문제AI

    2023-04-07 ⑤:27

    비용구배는 일수당 비용을 의미합니다.

    정상소요기간의 경우 5일 동안 20,000원을 지불하므로, 일수당 비용은 20,000원 / 5일 = 4,000원/일 입니다.

    특급소요기간의 경우 3일 동안 30,000원을 지불하므로, 일수당 비용은 30,000원 / 3일 = 10,000원/일 입니다.

    따라서, 비용구배는 (4,000원/일 + 10,000원/일) / 2 = 7,000원/일 입니다.

    하지만, 문제에서 요구하는 정답은 "5,000원/일" 이므로, 이는 평균값이 아닌 가중평균값을 구한 것입니다.

    가중평균값은 각각의 값에 가중치를 곱한 후, 전체 가중치의 합으로 나누어 구합니다.

    정상소요기간의 가중치는 5일 / (5일 + 3일) = 5/8 이고, 특급소요기간의 가중치는 3일 / (5일 + 3일) = 3/8 입니다.

    따라서, 비용구배는 (4,000원/일 * 5/8) + (10,000원/일 * 3/8) = 5,000원/일 입니다.
