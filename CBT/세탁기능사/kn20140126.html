  2. 물에 침지 → 제육 → 탈모 → 석회침지 → 분할 → 때빼기 → 탈회 및 효소분해 → 산에 담그기 → 유성
  3. 물에 침지 → 제육 → 석회침지 → 산에 담그기 → 분할 → 때빼기 → 탈회 및 효소분해 → 탈모 → 유성
