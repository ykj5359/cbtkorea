8. 다음은 전자기파에 대한 설명이다. ㉠∼㉢에 해당하는 전자기파로 가장 적절한 것은?(순서대로 ㉠, ㉡, ㉢)

  1. 적외선, X선, 감마(γ)선
  2. 가시광선, 감마(γ)선, X선
  3. 적외선, 자외선, X선
  4. 라디오파, 자외선, 감마(γ)선
(정답률: 알수없음)

    2023-04-14 00:19

    ㉠는 적외선, ㉡는 자외선, ㉢는 X선이다.

    적외선은 전자기파의 일종으로, 가시광선보다 짧은 파장을 가지며 열을 발생시키는데 사용된다. 따라서, "가시광선"은 적외선이 아니다.

    자외선은 가시광선보다 짧은 파장을 가지며, 피부를 태우거나 눈을 손상시키는데 사용된다. 따라서, "라디오파"는 자외선이 아니다.

    X선은 전자기파의 일종으로, 고에너지 전자를 이용하여 이미지를 촬영하거나 암 치료에 사용된다. 따라서, "라디오파"와 "자외선"은 X선이 아니다.

    따라서, "적외선, 자외선, X선"이 가장 적절한 답이다.

9. 다음 그림은 실린더에 들어 있는 일정량의 이상 기체의 상태를 A → B → C로 변화시키는 과정을 나타낸 것이다. A, B, C의 부피는 각각 2V, V, 2V이고, A → B는 단열 과정, B → C는 등압 과정이다. 이에 대한 설명으로 옳은 것만을 보기에서 있는 대로 고른 것은? (단, Q = 열량, W = 일, U = 내부에너지)

  1. ㉠
  2. ㉠㉢
  3. ㉡㉢
  4. ㉠㉡㉢
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-14 00:01

    - A → B : 단열 과정이므로 Q = 0, 따라서 ΔU = W
    - B → C : 등압 과정이므로 W = PΔV, Q = ΔU + W
    - A → C : A → B → C 이므로 ΔU = U_C - U_A = (U_B - U_A) + (U_C - U_B) = ΔU_1 + ΔU_2
    - ΔU_1 = W_1 = -W_2 = -PΔV_1 = -P(V - 2V) = PV
    - ΔU_2 = Q_2 - W_2 = PΔV_2 - PΔV_2 = 0
    - 따라서 ΔU = ΔU_1 + ΔU_2 = PV
    - Q = ΔU + W = PV + PΔV = P(2V)ln2
    - 따라서 옳은 보기는 "㉠㉢" 이다.
1
