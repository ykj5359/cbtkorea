    L = 1/2 x 공기밀도 x 날개면적 x 실속속도2 x 양력계수

    양력계수 = 2L / (공기밀도 x 날개면적 x 실속속도2)

57. 속도 720 ㎞/h로 비행하는 항공기에 장착된 터보제트 기관이 196㎏/s인 중량 유량의 공기를 흡입하여 300m/s의 속도로 배기 시킨다. 이때 진추력(㎏)은 얼마인가?

  1. 2000
  2. 3000
  3. 5000
  4. 6000
(정답률: 31%)
  • 30 CBT 기출문제AI

    2023-04-12 20:27

    진추력은 다음과 같이 계산할 수 있다.

    진추력 = 유량 × (입구속도 - 출구속도)

    여기서 유량은 196kg/s, 입구속도는 항공기의 비행속도인 720km/h를 3.6으로 나누어 m/s로 변환한 값인 200m/s, 출구속도는 터보제트 기관에서 배기된 공기의 속도인 300m/s이다.

    따라서, 진추력 = 196 × (200 - 300) = 196 × (-100) = -19600kg 이다.

    하지만 진추력은 항공기를 앞으로 밀어내는 힘이므로, 부호를 바꿔주어야 한다. 따라서, 진추력의 절댓값은 19600kg이다.

    하지만 이 문제에서는 진추력의 값을 kg으로 주었는데, 진추력은 단위가 N이다. 따라서, 진추력의 값을 kgf로 변환해주어야 한다. 1kgf는 9.8N이므로, 진추력의 값에 9.8을 곱해주면 된다.

    따라서, 진추력 = 19600 × 9.8 = 192080N 이다.

    이 값은 보기에서 주어진 값 중에서 2000에 가장 가깝다. 따라서, 정답은 "2000"이다.
