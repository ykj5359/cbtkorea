14. 날개의 길이가 11m, 평균시위의 길이가 1.44m 인 타원형날개에서 양력계수가 0.8일 때 가로세로비는 약 얼마인가?

  1. 4.9
  2. 6.1
  3. 7.6
  4. 8.8
(정답률: 68%)
  • 30 CBT 기출문제AI

    2023-04-12 20:31

    양력계수(C_L)는 다음과 같은 식으로 계산됩니다.

    C_L = Lift / (0.5 * rho * V^2 * S)

    여기서 Lift는 양력, rho는 공기밀도, V는 비행기의 속도, S는 날개의 면적입니다.

    양력계수가 0.8이므로, 다음과 같은 식이 성립합니다.

    0.8 = Lift / (0.5 * rho * V^2 * S)

    양변에 S를 곱하면,

    0.8 * S = Lift / (0.5 * rho * V^2)

    양변에 0.5 * rho * V^2를 곱하면,

    Lift = 0.4 * rho * V^2 * S

    여기서, rho는 대기압에서의 공기밀도인 1.225 kg/m^3이고, V는 평균시위의 길이인 1.44m에서의 비행속도입니다. 따라서,

    Lift = 0.4 * 1.225 * V^2 * S

    날개의 길이가 11m이므로, 가로축 반지름은 5.5m, 세로축 반지름은 0.72m입니다. 따라서, 날개의 면적 S는 다음과 같습니다.

    S = pi * a * b = pi * 5.5 * 0.72 = 11.88 m^2

    따라서,

    Lift = 0.4 * 1.225 * V^2 * 11.88 = 5.47 * V^2

    양력은 중력과 같아야 하므로, 다음과 같은 식이 성립합니다.

    Lift = Weight = m * g

    여기서, m은 비행기의 질량, g는 중력가속도입니다. 따라서,

    m * g = 5.47 * V^2

    비행기의 질량은 고려하지 않고, 중력가속도 g는 9.81 m/s^2입니다. 따라서,

    V^2 = (m * g) / 5.47 / 9.81

    가로축 반지름과 세로축 반지름의 비율은 다음과 같습니다.

    a / b = 11 / 1.44 = 7.64

    따라서, 가로세로비는 약 7.6입니다. 따라서, 정답은 "7.6"입니다.
