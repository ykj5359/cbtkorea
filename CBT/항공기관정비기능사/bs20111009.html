6. 날개의 양력계수 0.58, 날개면적(s) 10m2인 비행기가 밀도(ρ)0.1Kgㆍs/m인 공기 중을 50m/s로 비행하고 있다. 이때 날개에 발생하는 양력은 약 몇 Kgf인가?

  1. 425
  2. 527
  3. 625
  4. 725
(정답률: 45%)
  • 30 CBT 기출문제AI

    2023-04-12 20:29

    날개에 작용하는 양력은 다음과 같이 계산할 수 있습니다.

    L = 0.5 * ρ * v^2 * s * C

    여기서, L은 양력, ρ는 공기의 밀도, v는 비행기의 속도, s는 날개면적, C는 양력계수입니다.

    따라서, 주어진 값에 대입하면 다음과 같습니다.

    L = 0.5 * 0.1 * 50^2 * 10 * 0.58
    = 725 Kgf

    따라서, 정답은 "725"입니다.

7. 헬리콥터의 프로펠러와 같이 회전하는 물체의 각속도(Ω)와 회전반지름(R) 및 선속도(V)와의 관계로 옳은 것은?

  1. Ω=R/V
  2. Ω=V/R
  3. Ω=RV
  4. Ω=R2V
(정답률: 49%)
  • 30 CBT 기출문제AI

    2023-04-12 20:29

    정답은 "Ω=V/R"입니다.

    각속도(Ω)는 단위 시간당 회전하는 각도를 의미합니다. 회전반지름(R)은 회전 중심에서 회전하는 물체의 가장자리까지의 거리를 의미하며, 선속도(V)는 물체가 일정한 시간 동안 이동한 거리를 의미합니다.

    헬리콥터의 프로펠러와 같이 회전하는 물체에서는 각속도(Ω)와 선속도(V)는 회전반지름(R)과 밀접한 관련이 있습니다. 회전하는 물체의 한 점에서의 선속도(V)는 그 점에서의 각속도(Ω)와 회전반지름(R)의 곱으로 나타낼 수 있습니다. 이를 수식으로 나타내면 V = RΩ 입니다.

    이 식을 각속도(Ω)에 대해 정리하면 Ω = V/R이 됩니다. 따라서, 각속도(Ω)와 회전반지름(R) 및 선속도(V)의 관계는 "Ω=V/R"입니다.

55. 압축비가 7인 오토싸이클의 열효율은 약 얼마인가? (단, 작동유체의 비열비는 1.4로 한다. )

  1. 0.54
  2. 0.62
  3. 0.75
  4. 0.83
(정답률: 46%)
  • 30 CBT 기출문제AI

    2023-04-12 20:28

    열효율은 출력 열량 / 입력 열량으로 정의됩니다.

    입력 열량은 압축비와 작동유체의 비열비에 의해 결정됩니다. 압축비가 7이므로 입력 열량은 7배가 됩니다. 작동유체의 비열비가 1.4이므로 입력 열량은 1.4배가 됩니다. 따라서 입력 열량은 7 x 1.4 = 9.8배가 됩니다.

    출력 열량은 열효율에 따라 결정됩니다. 열효율이 0.54이므로 출력 열량은 입력 열량의 0.54배가 됩니다. 따라서 출력 열량은 9.8 x 0.54 = 5.292배가 됩니다.

    따라서, 압축비가 7인 오토싸이클의 열효율은 0.54입니다.
