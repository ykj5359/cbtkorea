16. 다수개 빼기 금형에서 런너의 길이를 20mm, 게이트의 랜드를 2mm, 런너 직경을 8.0mm로 주어졌을 때 게이트 밸런스 값은 약 얼마인가 ? (단, 게이트와 런너의 단면적 비 SG/SR=0.09로 한다)

  1. 0.4
  2. 0.5
  3. 0.6
  4. 0.7
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-12 10:12

    게이트 밸런스 값은 (게이트 단면적)/(게이트 단면적 + 런너 단면적) 으로 계산할 수 있다.

    게이트 단면적 = 게이트 랜드 x 게이트 두께 = 2mm x 8.0mm = 16mm²

    런너 단면적 = 런너 직경² x π / 4 = 8.0mm² x 3.14 / 4 = 50.24mm²

    따라서, 게이트 밸런스 값은 16 / (16 + 50.24) = 0.24 이다.

    하지만, 문제에서 주어진 SG/SR 값이 0.09 이므로,

    (게이트 단면적 / 런너 단면적) = 0.09

    게이트 단면적 = 0.09 x 런너 단면적
