46. 아래와 같은 머시닝센터 프로그램에서 현재 공구가 프로그램 원점에 위치해 있을 때 공구가 지령된 위치까지 도달하는 시간은? (단, 스핀들의 회전수는 120rpm 이다.)

  1. 3초
  2. 3분
  3. 1.5초
  4. 1.5분
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-12 10:11

    공구가 이동해야 할 거리는 X축 방향으로 100mm, Y축 방향으로 50mm 이므로, 피타고라스의 정리를 이용하여 이동 거리를 구할 수 있다.

    √(100² + 50²) = √(10000 + 2500) = √12500 ≈ 111.8mm

    공구가 이동하는 속도는 1000mm/min 이므로, 이동 시간은 다음과 같이 계산할 수 있다.

    이동 시간 = 이동 거리 ÷ 이동 속도 = 111.8 ÷ 1000 = 0.1118분

    스핀들의 회전수가 120rpm 이므로, 1분에 120회전을 한다. 따라서, 0.1118분 동안 스핀들은 다음과 같이 회전한다.

    회전수 = (1분 ÷ 120회전) × 0.1118분 = 0.000932회전

    즉, 공구가 지령된 위치까지 도달하는 시간은 이동 시간과 스핀들 회전 시간을 합한 값이다.

    공구가 지령된 위치까지 도달하는 시간 = 이동 시간 + 스핀들 회전 시간 ≈ 0.1118분 + 0.000932분 ≈ 3분

    따라서, 정답은 "3분" 이다.

58. nP관리도에서 시료군마다 n=100 이고, 시료군의 수가 k=20 이며, ΣnP = 77이다. 이때 nP관리도의 관리상한선 UCL을 구하면 얼마인가?

  1. UCL = 8.94
  2. UCL = 3.85
  3. UCL = 5.77
  4. UCL = 9.62
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-12 10:11

    UCL = μ + 3σ, 여기서 μ는 평균값, σ는 표준편차를 의미한다. nP관리도에서 μ는 ΣnP/k = 77/20 = 3.85 이다. nP관리도에서 σ는 sqrt(Σ(nP-μ)^2/k) 이다. 여기서 (nP-μ)는 각 시료군에서의 차이를 의미한다. 따라서, (n-1)P = nP - n 이므로, (nP-μ)^2 = (n-1)^2P^2 이다. 따라서, σ = sqrt(Σ(n-1)^2P^2/k) = sqrt(Σ99P^2/20) = sqrt(99/20)P = 2.22P 이다. 따라서, UCL = 3.85 + 3(2.22P) = 9.62 이다. 따라서, 정답은 "UCL = 9.62" 이다.
