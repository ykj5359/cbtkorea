4. 색료를 혼색한 결과 중 틀린 것은?

  3. Green + Magenta = Yellow
  4. Yellow + Magenta = Red
(정답률: 61%)
  • 30 CBT 기출문제AI

    2023-04-16 20:26

    정답은 "Yellow + Magenta = Red"입니다.

    색상 혼합에서, 빨강, 파랑, 녹색은 기본 색상으로 간주됩니다. 이러한 기본 색상을 혼합하여 다른 색상을 만들 수 있습니다.

    "Magenta + Cyan = Blue"는 파란색을 만드는 방법 중 하나입니다. 마젠타는 빨강과 파랑의 혼합으로 만들어지며, 시안은 파란색과 녹색의 혼합으로 만들어집니다. 따라서 마젠타와 시안을 혼합하면 파란색이 만들어집니다.

    "Red + Blue + Green = Black"은 모든 기본 색상을 혼합하여 검은색을 만드는 방법입니다. 이것은 빛의 혼합에서만 적용되며, 인쇄에서는 다른 색상 모델이 사용됩니다.

    "Green + Magenta = Yellow"는 녹색과 마젠타를 혼합하여 노란색을 만드는 방법입니다. 녹색은 녹색과 파랑의 혼합으로 만들어지며, 마젠타는 빨강과 파랑의 혼합으로 만들어집니다. 따라서 녹색과 마젠타를 혼합하면 노란색이 만들어집니다.

    "Yellow + Magenta = Red"는 노란색과 마젠타를 혼합하여 빨간색을 만드는 방법입니다. 그러나 이것은 올바른 방법이 아닙니다. 노란색은 빨강과 녹색의 혼합으로 만들어지며, 마젠타는 빨강과 파랑의 혼합으로 만들어집니다. 따라서 노란색과 마젠타를 혼합하면 보라색이 만들어집니다.
