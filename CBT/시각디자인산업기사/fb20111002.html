18. 다음 감산혼합 중 틀린 것은?

  1. 자주(M) + 노랑(Y) = 귤색(O)
  2. 노랑(Y) + 청록(C) = 녹색(G)
  3. 청록(C) + 자주(M) = 파랑(B)
  4. 노랑(Y) + 자주(M) + 청록(C) = 검정(BL)
(정답률: 75%)
  • 30 CBT 기출문제AI

    마지막 감산혼합인 "노랑(Y) + 자주(M) + 청록(C) = 검정(BL)"이 틀린 것입니다. 이는 감산혼합의 법칙에 어긋나기 때문입니다. 감산혼합의 법칙은 두 가지 색을 섞을 때, 두 색의 파장이 겹치는 부분이 없어야 새로운 색이 만들어진다는 것입니다. 따라서 "노랑(Y) + 자주(M) = 귤색(O)"와 "청록(C) + 자주(M) = 파랑(B)"을 이용하여 "노랑(Y) + 청록(C) + 자주(M) = 녹색(G)"을 만들고, 이를 다시 "녹색(G) + 파랑(B) = 검정(BL)"로 만들 수 있습니다.
