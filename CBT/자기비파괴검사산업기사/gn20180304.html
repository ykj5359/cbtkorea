17. 피복 아크 용접에서 무부하전압 80V, 아크전압 30V, 아크전류 200A라 하고, 이때의 내부손실을 4kW라 하면 용접기의 효율은 몇 %인가?

  1. 60
  2. 70
  3. 80
  4. 90
(정답률: 59%)
  • 30 CBT 기출문제AI

    2023-04-17 13:04

    용접기의 출력전력은 아크전압과 아크전류를 곱한 값이므로,

    출력전력 = 30V x 200A = 6000W

    내부손실은 4kW이므로,

    입력전력 = 출력전력 + 내부손실 = 6000W + 4kW = 10000W

    따라서, 용접기의 효율은

    효율 = (출력전력 / 입력전력) x 100% = (6000W / 10000W) x 100% = 60%

    따라서, 정답은 "60"입니다.

54. 자분탐상검사 시 코일을 사용하여 선형자화 할 때 길이 10 인치, 직경이 2인치의 환봉에 적용되는 Ampere-Turn 수는?

  2. 5000A.T
  3. 7000A.T
  4. 9000A.T
(정답률: 85%)
  • 30 CBT 기출문제AI

    2023-04-17 13:04

    자분탐상검사에서 코일을 사용하여 선형자화 할 때, Ampere-Turn 수는 코일에 흐르는 전류(Ampere)와 코일을 몇 번 감는지(Turn)에 따라 결정됩니다.

    이 문제에서는 길이 10인치, 직경이 2인치의 환봉에 적용되는 Ampere-Turn 수를 구해야 합니다. 환봉의 길이와 직경으로부터 환봉의 둘레를 구할 수 있습니다.

    둘레 = 2 x π x 반지름 = 2 x π x 1인치 = 2π 인치

    이제 코일을 몇 번 감는지를 구해야 합니다. 코일을 몇 번 감는지는 코일의 길이와 환봉의 둘레를 이용하여 구할 수 있습니다.

    코일을 한 번 감는 데 필요한 길이 = 둘레 = 2π 인치

    코일의 길이가 10인치이므로,

    코일을 몇 번 감는지 = 10인치 ÷ (2π 인치) ≈ 1.59회

    따라서, 코일을 한 번 감을 때 필요한 Ampere-Turn 수는 전류(Ampere) x 감수(Turn)입니다.

    코일을 한 번 감을 때 필요한 전류는 자분탐상검사에서 사용되는 전류 중 하나인 500A 이라고 가정하겠습니다.

    Ampere-Turn 수 = 전류(Ampere) x 감수(Turn) = 500A x 1.59회 ≈ 795A.T

    하지만 보기에서 주어진 답은 5000A.T 입니다. 이는 코일을 여러 번 감았을 때의 Ampere-Turn 수입니다. 코일을 여러 번 감았을 때의 Ampere-Turn 수는 감수(Turn)을 곱해주면 됩니다.

    만약 코일을 6번 감았다면,

    Ampere-Turn 수 = 전류(Ampere) x 감수(Turn) = 500A x 6회 = 3000A.T

    따라서, 코일을 10인치, 직경이 2인치의 환봉에 적용할 때 필요한 Ampere-Turn 수는 5000A.T가 됩니다.
