13. 비행기가 230km/h 로 수평비행 할 때 비행기의 상승률이 10m/s 라고 하면, 이 비행기 상승각은 약 몇 °인가?

  1. 4.8
  2. 7.2
  3. 9.0
  4. 12.0
(정답률: 54%)
  • 30 CBT 기출문제AI

    2023-04-18 02:30

    비행기의 상승각은 탄젠트 함수를 이용하여 구할 수 있다. 상승률은 초당 상승하는 높이를 의미하므로, 10m/s 는 1초에 10m 만큼 상승한다는 것을 의미한다. 이때 비행기의 속도는 230km/h 이므로, 1초에 비행기는 230/3600 km 만큼 이동한다. 이를 높이와 비교하여 탄젠트 함수를 이용하여 상승각을 구할 수 있다.

    tan(θ) = 상승률 / 수평속도
    tan(θ) = 10 / (230/3600)
    tan(θ) = 0.1565
    θ = arctan(0.1565)
    θ = 9.0°

    따라서, 정답은 "9.0" 이다.

70. 교류회로에서 피상전력이 1000VA 이고 유효전력이 600W, 무효전력은 800VAR 일 때 역률은 얼마인가?

  2. 0.5
  3. 0.6
  4. 0.7

    역률은 유효전력과 피상전력의 비율을 나타내는 값입니다. 따라서 역률은 유효전력을 피상전력으로 나눈 값으로 계산됩니다.

    역률 = 유효전력 / 피상전력

    주어진 문제에서 유효전력은 600W, 피상전력은 1000VA입니다.

71. 4극짜리 발전기가 1800rpm 으로 회전할 때 주파수는 몇 Hz 인가?

  1. 60
  2. 120
  3. 180
  4. 360
(정답률: 52%)
  • 30 CBT 기출문제AI

    2023-04-18 02:32

    4극짜리 발전기는 2회전수(pole pair)를 가지므로 1회전당 2사이클(cycle)의 전기 신호를 생성합니다. 따라서 1800rpm으로 회전할 때 발생하는 주파수는 다음과 같이 계산할 수 있습니다.

    1800rpm = 1800회전/분
    1분 = 60초
    1800회전/60초 = 30회전/초
    1회전당 2사이클 = 60Hz
    30회전/초 × 2사이클/회전 = 60Hz

    따라서 4극짜리 발전기가 1800rpm으로 회전할 때 발생하는 주파수는 "60"Hz입니다.
