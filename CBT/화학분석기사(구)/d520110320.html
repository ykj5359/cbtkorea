10. 포름산(HCOOH)의 이온화 상수는(Ka)는 1.80 x 10-4 이다. 0.001M의 포름산 용액에는 포름산 약 몇 % 가 이온화되어 있는가?

  1. 4.2
  2. 34
  3. 82
  4. 88
(정답률: 36%)
  • 30 CBT 기출문제AI

    2023-04-18 08:37

    포름산의 이온화 반응식은 다음과 같다.

    HCOOH ⇌ H+ + HCOO-

    이온화 상수(Ka)는 다음과 같이 정의된다.

    Ka = [H+][HCOO-]/[HCOOH]

    이 문제에서는 [HCOOH] = 0.001M 이다. 이를 이온화 반응식에 대입하면,

    Ka = [H+][HCOO-]/0.001

    [H+]와 [HCOO-]는 같은 양만큼 생성되므로, 둘의 농도는 같다. 따라서,

    [H+] = [HCOO-] = x (이온화된 양)

    Ka = x2/0.001

    x2 = 0.001 x Ka

    x = √(0.001 x Ka) = √(0.001 x 1.80 x 10-4) = 0.0134

    따라서, 포름산 용액에서 이온화된 양은 0.0134M 이다. 이를 백분율로 환산하면,

    이온화된 양 = 0.0134M = 1.34%

    따라서, 포름산 용액에서 약 1.34%가 이온화되어 있다. 이 값은 보기에서 "4.2", "82", "88"과 다르므로, 정답은 "34"이다.
