  1. 0.045
  2. 0.090
  3. 0.31
  4. 0.52
(정답률: 39%)

    2023-04-18 08:47

    먼저, 주어진 기체 혼합물의 화학식을 살펴보면,

    H2 + I2 ⇌ 2HI

    이므로, 이 화학식에 따라 평형 상수 Kc를 구할 수 있다.

    Kc = [HI]2 / ([H2] x [I2])

    주어진 농도를 대입하면,

    Kc = (2.1)2 / (0.13 x 0.70) = 23.14

    이제, 500.00mL의 용기에 0.20 mol의 HI를 주입하였으므로,

    [HI] = 0.20 mol / 0.500 L = 0.40 M

    이다.

    이제, 이 농도를 이용하여 평형 상수 Kc를 이용하여 [H2]와 [I2]를 구할 수 있다.

    Kc = [HI]2 / ([H2] x [I2])

    23.14 = (0.40)2 / ([H2] x [I2])

    [H2] x [I2] = (0.40)2 / 23.14 = 0.0069

    이제, [HI] = 2.1 M 일 때의 [H2]와 [I2]를 이용하여,

    2.1 = [H2] x [I2] / (0.13)

    2.1 = 0.0069 / [I2] x [I2] / (0.13)

    [I2] = 0.13 x 0.0069 / 2.1 = 0.00043 M

    [H2] = 0.0069 / 0.00043 = 16.⑤ M

    따라서, 평형 혼합물 속의 HI의 농도는

    [HI] = 2 x [H2] = 2 x 16.⑤ = 32.10 M

    하지만, 이는 불가능한 값이므로, 이는 [HI]가 0.40 M일 때의 초기 농도이다.

    따라서, 평형 혼합물 속의 HI의 농도는 0.40 M이다.

78. 액체막(liquid membrane) 칼슘 이온선택성 전극을 이용하여 용액의 Ca2+ 농도를 결정하고자 한다. 미지시료 25.0mL 에 칼슘이온 선택성 전극을 담가 전위를 측정하였더니 전위가 497.0mV 이었다. 미지시료에0.⑤00M 농도의 CaCl2 용액 2.00mL를 첨가하여 전위를 측정하였더니 전위가 512.0mV 이었다. 이온선택성전극이 Nernst 식을 따른다면 미지용액에서의 칼슘이온의 농도는?

  1. 0.00162M
  2. 0.00428M
  3. 0.0187M
  4. 1.124M

    Nernst 식은 다음과 같다.

    E = E° - (RT/nF)ln(Q)

    여기서 E는 전위, E°는 표준전위, R은 기체상수, T는 절대온도, n은 전자전달수, F는 Faraday 상수, Q는 반응곱이다.

    이 문제에서는 미지시료에 칼슘이온 선택성 전극을 담가 전위를 측정하였고, 그 전위는 497.0mV이다. 이때의 반응곱 Q는 다음과 같다.

    Q = [Ca2+]

    여기서 대괄호는 농도를 나타낸다. 따라서, 미지시료에서의 칼슘이온 농도는 다음과 같다.

    [Ca2+] = 10^((E - E°) x nF/RT)

    여기서 E는 497.0mV, E°는 칼슘 선택성 전극의 표준전위인 324.5mV이다. n은 2이고, F는 96485 C/mol, R은 8.314 J/mol·K, T는 298 K이다. 따라서,

    [Ca2+] = 10^((497.0 - 324.5) x 2 x 96485/(8.314 x 298)) = 0.00428M

    다음으로, 0.⑤00M 농도의 CaCl2 용액 2.00mL를 첨가하여 전위를 측정하였고, 그 전위는 512.0mV이다. 이때의 반응곱 Q는 다음과 같다.

    Q = [Ca2+] x [Cl-]2

    여기서 [Cl-]는 0.100M이다. 따라서,

    [Ca2+] = Q/[Cl-]2 = 10^((512.0 - 324.5) x 2 x 96485/(8.314 x 298)) / 0.1002 = 0.00162M

    따라서, 미지시료에서의 칼슘이온 농도는 0.00162M이다.
