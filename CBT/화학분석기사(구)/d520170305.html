3. 어느 실험과정에서 한 학생이 실수로 0.20M NaCI 용액 250mL를 만들었다. 그러나 실제 실험에 필요한 농도는 0.0⑤M 이었다. 0.20M NaCI 용액을 가지고 0.0⑤M NaCI 100mL를 만들려면, 100mL 부피 플라스크에 0.20M NaCI을 얼마나 넣어야 하는가?

  2. 2.5mL
  3. 4mL
  4. 5mL
(정답률: 79%)

    농도와 부피는 다음과 같은 관계식을 가진다.

    농도 × 부피 = 몰수

    따라서, 0.20M NaCI 용액 250mL의 몰수는 다음과 같다.

    0.20M × 250mL = 50 몰

    그리고 0.0⑤M NaCI 100mL의 몰수는 다음과 같다.

    0.0⑤M × 100mL = 0.5 몰

    따라서, 0.20M NaCI 용액에서 0.5 몰의 NaCI를 얻으려면 다음과 같은 관계식을 사용할 수 있다.

    농도 × 부피 = 몰수

    0.20M × x = 0.5 몰

    x = 0.5 몰 ÷ 0.20M

    x = 2.5mL

    따라서, 0.20M NaCI 용액에서 0.0⑤M NaCI 100mL를 만들기 위해서는 2.5mL의 용액을 사용해야 한다.

5. 황산칼슘(CaSO4)의 용해도곱(Ksp)이 2.4×10-5이다. 이 값을 이용하여 황산칼슘(CaSO4)의 용해도를 구하면? (단, 황산칼슘의 분자량은 136.2g이다)

  1. 1.414g/L
  2. 1.114g/L
  3. 0.667g/L
  4. 0.121g/L
(정답률: 67%)
  • 30 CBT 기출문제AI

    2023-04-18 08:44

    황산칼슘의 용해도곱 식은 다음과 같다.

    CaSO4 ⇌ Ca2+ + SO42-

    Ksp = [Ca2+][SO42-]

    Ksp 값이 주어졌으므로, 이를 이용하여 [Ca2+]와 [SO42-]의 값을 구할 수 있다.

    Ksp = [Ca2+][SO42-]

    2.4×10-5 = [Ca2+][SO42-]

    [Ca2+] = [SO42-] = x (가정)

    2.4×10-5 = x2

    x = 0.0049

    따라서, [Ca2+] = [SO42-] = 0.0049 M 이다.

    황산칼슘의 분자량이 136.2 g/mol 이므로, 1 L의 용액에는 0.0049 × 136.2 g = 0.667 g의 황산칼슘이 용해될 수 있다.

    따라서, 정답은 "0.667g/L" 이다.

10. Na2CO3용액에 HCl 용액을 첨가하면 다음과 같은 반응이 진행된다. 이 반응에 근거하여 Na2CO3용액의 몰농도와 노르말농도 사이의 관계를 옳게 나타낸 것은?

  1. 0.10M = 0.20N
  2. 0.10M = 0.10N
  3. 0.10M = 0.⑤N
  4. 0.10M = 0.01N
(정답률: 70%)
  • 30 CBT 기출문제AI

    2023-04-18 08:44

    Na2CO3와 HCl은 중화반응을 일으키며, 그 반응식은 다음과 같다.

    Na2CO3 + 2HCl → 2NaCl + CO2 + H2O

    이 반응에서 Na2CO3 1 몰이 HCl 2 몰과 반응하여 2 몰의 NaCl이 생성된다. 따라서 Na2CO3 용액의 노르말농도는 2N이 된다.

    노르말농도(N)는 용액의 몰농도(M)와 분자량(MW)의 곱으로 계산된다.

    N = M × MW

    Na2CO3의 분자량은 106 g/mol이므로, 0.10 M의 Na2CO3 용액의 노르말농도는 다음과 같다.

    N = 0.10 M × 106 g/mol = 10.6 N

    하지만, 위의 반응에서 HCl은 2배의 몰수로 반응하므로, Na2CO3 용액의 노르말농도는 2배로 줄어든다.

    따라서, 0.10 M의 Na2CO3 용액의 노르말농도는 10.6 N ÷ 2 = 5.3 N이 된다.

    그러므로, 옳은 정답은 "0.10M = 0.20N"이 아니라 "0.10M = 0.⑤N"이다.

62. 카드늄 전극이 0.0150M Cd+2용액에 담구어진 경우 반쪽전지의 전위를 Nernst식을 이용하여 구하면 약 몇 V인가?

  1. -0.257
  2. -0.311
  3. -0.457
  4. -0.511
(정답률: 71%)
  • 30 CBT 기출문제AI

    2023-04-18 08:50

    Nernst식은 다음과 같다.

    E = E° - (0.⑤92/n)logQ

    여기서 E는 반쪽전지의 전위, E°는 표준전위, n은 전자전달수, Q는 반응곱이다.

    이 문제에서는 Cd+2이 Cd(s)로 환원되는 반응이 일어나므로,

    Cd+2 + 2e- → Cd(s)

    n은 2이다.

    Q는 Cd+2의 활동도와 Cd(s)의 활동도의 비율인데, Cd(s)의 활동도는 항상 1이므로,

    Q = [Cd+2]/1 = 0.0150

    E°는 Cd+2 + 2e- → Cd(s) 반응의 표준전위인데, 표준상태에서 Cd+2의 농도는 1M이므로,

    E° = -0.403V

    따라서,

    E = -0.403 - (0.⑤92/2)log(0.0150) = -0.457V

    정답은 "-0.457"이다.

    이유는 Nernst식을 이용하여 계산한 결과이다.
