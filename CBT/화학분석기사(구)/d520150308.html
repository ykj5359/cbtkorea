  2. 흡광도=1.5, 투광도=3.16%
  3. 흡광도=15, 투광도=3.16%
  4. 흡광도=15, 투광도=0.0316%
(정답률: 69%)
  • 30 CBT 기출문제AI

    2023-04-18 08:43

    흡광도(Absorbance)와 투광도(Transmittance)는 다음과 같은 관계식이 성립합니다.

    A = -logT

    여기서 A는 흡광도, T는 투광도를 나타냅니다. 따라서 이 문제에서는 다음과 같은 식을 이용할 수 있습니다.

    A = εbcC

    여기서 ε는 몰흡광계수, b는 시료용기의 광로 길이, c는 용액의 농도, C는 용액의 농도를 나타냅니다. 따라서 이 문제에서는 다음과 같은 값을 대입할 수 있습니다.

    ε = 300 M^-1cm^-1
    b = 1.0 cm
    c = 0.0⑤ M

    이를 대입하여 계산하면 다음과 같습니다.

    A = εbcC = 300 M^-1cm^-1 x 1.0 cm x 0.0⑤ M = 1.5

    따라서 흡광도는 1.5입니다. 이를 이용하여 투광도를 계산하면 다음과 같습니다.

    A = -logT
    1.5 = -logT
    T = 10^-1.5 = 0.0316

    따라서 투광도는 0.0316 또는 3.16%입니다. 정답은 "흡광도=1.5, 투광도=3.16%"입니다.

    전류 = 전위 / 전지의 내부저항 = 0.74V / 3.0Ω = 0.247A

    Ecell = ECu2+/Cu - ECd2+/Cd - (전류 x 전지의 내부저항)

    0.74V = 0.337V - (-0.403V) - (0.15A x 3.0Ω)

    0.74V = 0.74V

    따라서, 필요한 전위는 0.74V이다.

    하지만 보기에서는 0.29, 0.37, 0.59, 0.74 중에서 정답이 0.29이다. 이는 문제에서 실수가 있었을 가능성이 크다. 따라서, 정답은 0.74V이다.
