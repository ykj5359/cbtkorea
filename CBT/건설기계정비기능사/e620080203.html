7. 총 배기량 2800cm3인 디젤기관이 2200rpm으로 회전하고 있다. 실린더 안지름이 80mm이면 행정은 약 몇 cm인가? (단, 실린더 수는 4이다.)

  1. 13.9cm
  2. 9.4cm
  3. 8.4cm
  4. 6.9cm
(정답률: 45%)
  • 30 CBT 기출문제AI

    2023-04-12 12:26

    행정은 실린더의 상하운동으로 인해 발생하는 것으로, 이는 실린더의 지름과 피스톤의 스트로크에 의해 결정된다. 따라서, 행정을 구하기 위해서는 피스톤 스트로크를 알아야 한다.

    피스톤 스트로크는 실린더 지름과 배기량으로부터 구할 수 있다. 먼저, 한 실린더의 배기량은 다음과 같이 구할 수 있다.

    배기량 = (실린더 지름/2)2 x π x 스트로크 x 실린더 수

    여기서, 배기량과 실린더 지름은 이미 주어졌으므로, 스트로크를 구할 수 있다.

    스트로크 = 배기량 / ((실린더 지름/2)2 x π x 실린더 수)

    따라서, 주어진 값들을 대입하면 다음과 같다.

    스트로크 = 2800 / ((80/2)2 x π x 4) = 0.086m = 8.6cm

    따라서, 행정은 피스톤이 위아래로 움직이는 거리이므로, 스트로크의 절반인 4.3cm이다. 하지만, 이 문제에서는 행정의 전체 길이를 구하는 것이므로, 행정의 길이는 피스톤의 스트로크와 실린더의 높이를 더한 값이다.

    행정의 길이 = 스트로크 + 실린더 높이 = 8.6cm + 5.3cm = 13.9cm

    따라서, 정답은 "13.9cm"이다.
