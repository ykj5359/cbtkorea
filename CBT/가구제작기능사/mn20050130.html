55. 수축율이 제일 많은 것부터 나열된 것은?

  1. A→ B→ C
  2. B →A→ C
  3. C →A→ B
  4. A→ C→ B
(정답률: 47%)
  • 30 CBT 기출문제AI

    2023-04-12 11:59

    수축율이란 초기 길이에 대한 변형률을 의미합니다. 따라서 수축율이 제일 많은 것은 초기 길이에 비해 가장 많이 줄어든 것입니다.

    그림을 보면, A, B, C 모두 초기 길이가 같습니다. 하지만 A는 가장 많이 줄어들어 초기 길이에 비해 가장 큰 수축율을 가지게 됩니다. 따라서 A→ B→ C 순서로 나열됩니다.

    B는 A보다는 적게 줄어들었지만, C보다는 많이 줄어들었습니다. 따라서 B →A→ C 순서로 나열됩니다.

    C는 가장 적게 줄어들었기 때문에 A, B보다는 수축율이 적습니다. 따라서 C →A→ B 순서로 나열됩니다.

    마지막으로 A→ C→ B 순서는 A와 C의 수축율이 비슷하기 때문에, B보다는 덜 줄어들었기 때문입니다.
