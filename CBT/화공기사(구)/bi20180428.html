12. 등온과정에서 300K일 때 기체의 압력이 10atm 에서 2atm 으로 변했다면 소요된 일의 크기는? (단, 기체는 이상기체라 가정하고, 기체상수 R은 1.987cal/mol·K이다.)

  1. 596.1cal
  2. 959.4cal
  3. 2494.2cal
  4. 4014.3cal
(정답률: 80%)
  • 30 CBT 기출문제AI

    2023-04-18 00:48

    등온과정에서 일의 크기는 다음과 같이 구할 수 있다.

    ΔU = 0 (등온과정에서 내부에너지 변화가 없음)
    W = -PΔV (기체가 일을 한 경우, 일의 크기는 음수)
    Q = ΔU + W = -PΔV

    여기서 ΔV는 첫 번째 압력과 두 번째 압력 사이의 부피 변화이다.

    P1V1 = nRT1
    P2V2 = nRT2

    V2/V1 = P1/P2 = 5 (압력이 1/5로 감소했으므로)

    따라서 ΔV = V2 - V1 = V1(5-1) = 4V1

    Q = -PΔV = -(10atm)(4V1) = -40V1atm

    여기서 V1은 기체의 몰 부피이다.

    V1 = RT1/P1 = (1.987cal/mol·K)(300K)/(10atm) = 59.61cal/mol

    따라서 Q = -40V1atm = -40(59.61cal/mol)(1atm) = -2384.4cal/mol

    하지만, 문제에서 일의 크기를 구하는 것이므로 부호를 바꿔준다.

    일의 크기 = 2384.4cal/mol ≈ 959.4cal (보기에서 "959.4cal"이 정답)

92. 회분식 반응기에서 0.5차 반응을 10min 동안 수행하니 75% 의 액체 반응물 A 가 생성물 R 로 전화되었다. 같은 조건에서 15min 간 반응을 시킨다면 전화율은 약 얼마인가?

  1. 0.75
  2. 0.85
  3. 0.90
  4. 0.94
(정답률: 36%)
  • 30 CBT 기출문제AI

    2023-04-18 00:47

    0.5차 반응에서 반응속도식은 다음과 같다.

    r = k[A]^0.5

    여기서 [A]는 시간에 따라 감소하므로, 반응속도식을 적분하여 다음과 같은 식을 얻을 수 있다.

    ln([A]0/[A]) = kt

    ln(1/0.75) = k x 10

    k = 0.0803/min

    ln(1/x) = 0.0803 x 15

    x = 0.94

    따라서, 정답은 "0.94"이다.
