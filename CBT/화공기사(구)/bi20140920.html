14. 1atm, 100℃에서 1mol 의 수증기와 물과의 내부에너지 차는 약 몇 cal 인가? (단, 수증기는 이상기체로 생각하고 주어진 압력과 온도에서 물의 증발 잠열은 539cal/g 이다.)

  1. 189070
  2. 87090
  3. 19110
  4. 8960
(정답률: 43%)
  • 30 CBT 기출문제AI

    2023-04-18 01:32

    먼저, 수증기와 물의 내부에너지 차이는 수증기의 증발 엔탈피와 물의 증발 엔탈피의 차이로 계산할 수 있다.

    물의 증발 엔탈피는 주어졌으므로, 수증기의 증발 엔탈피를 계산해야 한다. 이는 Clausius-Clapeyron 방정식을 사용하여 구할 수 있다.

    ln(P2/P1) = (ΔHvap/R) x (1/T1 - 1/T2)

    여기서 P1은 물의 증기압력 (1 atm), P2는 수증기의 증기압력, T1은 물의 온도 (100℃), T2는 수증기의 온도이다. ΔHvap은 수증기의 증발 엔탈피이다.

    수증기의 증기압력은 이상기체 상태 방정식을 사용하여 구할 수 있다.

    P2V = nRT

    여기서 V는 수증기의 부피, n은 몰수, R은 기체상수, T는 온도이다.

    수증기와 물의 몰수는 같으므로, 수증기의 부피는 물의 부피와 같다.

    따라서,

    P2 = nRT/V = (1 mol x 0.08206 L atm/mol K x 373 K) / 18.02 g/mol = 4.03 atm

    이제 Clausius-Clapeyron 방정식을 사용하여 ΔHvap을 계산할 수 있다.

    ln(4.03/1) = (ΔHvap/1.987) x (1/373 - 1/373)

    따라서, ΔHvap = 40.7 cal/g

    따라서, 1 mol의 수증기와 물의 내부에너지 차이는

    ΔU = n x (ΔHvap - ΔHvap,m) = 1 mol x (40.7 - 539) cal/mol = -498.3 cal

    여기서 ΔHvap,m은 물의 증발 엔탈피이다.

    하지만, 문제에서는 단위가 cal이 아니라 kJ로 주어졌으므로, -498.3 cal을 kJ로 변환해야 한다.

    -498.3 cal x (1 kJ/4.184 cal) = -119.1 kJ

    하지만, 문제에서는 정답이 양수로 주어졌으므로, 부호를 바꿔준다.

    따라서, 정답은 119.1 kJ 또는 8960 cal이다.

  2. -In(1-XA)=kt
  3. In[XA/(1-XA)]=kt
  4. In[1/(1-XA)]=kCAOt
(정답률: 57%)

    2023-04-18 01:31

    정답: "-In(1-XA)=kt"

    이유: 균일계 1차 액상반응에서는 반응물 농도의 감소율이 반응속도와 비례한다는 것이 알려져 있다. 이를 수식으로 나타내면 다음과 같다.

    d[XA]/dt = -k[XA]

    여기서 [XA]는 반응물 농도를 나타내며, k는 속도상수를 나타낸다. 이 식을 적분하면 다음과 같다.

    -In(1-XA) = kt + C

    -In(1-XA) = kt + In(1-[XA]0)

    In(1-XA) = -kt - In(1-[XA]0)

    따라서 "-In(1-XA)=kt"가 옳은 정답이다.
