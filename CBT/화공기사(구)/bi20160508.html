4. 다음과 같은 반응이 11⑤K에서 일어나며, 반응 평형 상수 K는 1.0이다. 초기에 1몰의 일산화탄소와 2몰의 물로 반응이 진행된다면 최종 반응좌표(몰)은얼마인가? (단, 혼합물은 이상기체로 본다.)

  2. 0.500
  3. 0.667
  4. 0.700
(정답률: 62%)

    일산화탄소와 물이 반응하여 수소와 이산화탄소가 생성되는 반응식은 다음과 같다.

    CO(g) + H2O(g) ⇌ H2(g) + CO2(g)

    반응 평형 상수 K가 1.0이므로, 반응물과 생성물의 몰수가 같을 때, 평형 상태에서 반응물과 생성물의 몰수는 같다. 따라서, 초기에 일산화탄소 1몰과 물 2몰이 혼합되어 있으므로, 반응이 진행하면서 일산화탄소와 물의 몰수가 감소하고, 수소와 이산화탄소의 몰수가 증가하게 된다.

    반응 진행에 따른 몰수 변화를 x로 놓으면, 반응좌표는 다음과 같다.

    CO(g) + H2O(g) ⇌ H2(g) + CO2(g)
    초기: 1mol 2mol 0mol 0mol
    변화: -x -x +x +x
    평형: 1-x 2-x x x

    반응 평형 상수 K는 다음과 같이 표현할 수 있다.

    K = [H2][CO2] / [CO][H2O]

    평형 상태에서 각 물질의 몰수를 대입하면,

    K = x^2 / [(1-x)(2-x)]

    K가 1.0이므로,

    1.0 = x^2 / [(1-x)(2-x)]

    x^2 = (1-x)(2-x)

    x^2 = 2 - 3x + x^2

    3x = 2

    x = 2/3

    따라서, 최종 반응좌표는 다음과 같다.

    CO: 1 - x = 1 - 2/3 = 1/3
    H2O: 2 - x = 2 - 2/3 = 4/3
    H2: x = 2/3
    CO2: x = 2/3

    따라서, CO의 몰수는 1/3mol, H2O의 몰수는 4/3mol, H2의 몰수는 2/3mol, CO2의 몰수는 2/3mol이다. 이들의 몰수를 모두 더하면,

    1/3 + 4/3 + 2/3 + 2/3 = 3mol

    따라서, 최종 반응좌표는 1mol의 일산화탄소와 2mol의 물이 혼합되어 3mol의 혼합물이 된다. 이상기체로 본다는 가정에 따라, 이들의 몰수는 모두 같으므로, 최종 반응좌표는 3mol의 이상기체 혼합물이 된다. 이 중에서 H2와 CO2의 몰수는 각각 2/3mol이므로, 이들의 몰 분율은 각각 2/3 ÷ 3 = 0.222이다. 따라서, CO2의 몰 분율은 1 - 0.222 = 0.778이고, 이는 0.667에 가장 가까운 값이다. 따라서, 정답은 "0.667"이다.

11. 압축비 4.5인 오토 사이클(Otto cycle)에 있어서 압축비가 7.5로 되었다고 하면 열효율은 몇 배가 되겠는가? (단, 작동유체는 이상기체이며, 열용량의 비 이다.)

  1. 1.22
  2. 1.96
  3. 2.86
  4. 3.31
(정답률: 55%)
  • 30 CBT 기출문제AI

    2023-04-18 01:12

    열효율은 다음과 같이 계산할 수 있다.

    열효율 = 1 - (냉각유체와 열교환한 열량 / 연소열)

    오토 사이클에서 연소열은 압축비와 작동유체의 열용량에 의해 결정된다. 따라서 압축비가 7.5일 때의 연소열을 연압비가 4.5일 때의 연소열로 나누면 열효율을 구할 수 있다.

    압축비가 7.5일 때의 연소열은 다음과 같다.

    연소열 = 열용량 × (온도비)

    압축비가 7.5이므로 압축과정에서 온도비는 7.5^(0.4) = 2.44이다. 따라서 연소열은 다음과 같다.

    연소열 = 0.5 × (2.44 - 1) × 1000 = 720 J/g

    연압비가 4.5일 때의 연소열은 다음과 같다.

    연소열 = 0.5 × (1.5) × 1000 = 750 J/g

    따라서 열효율은 다음과 같다.

    열효율 = 1 - (냉각유체와 열교환한 열량 / 연소열) = 1 - (Qc / 연소열)

    이상기체이므로 Qc = nCvΔT이다. 여기서 n은 작동유체의 몰수, Cv는 작동유체의 열용량, ΔT는 열교환으로 인한 온도강하이다. 이상기체의 경우 Cv/R = γ/(γ-1)이므로 Cv = R/(γ-1)이다. 따라서 Qc는 다음과 같다.

    Qc = nR/(γ-1) × ΔT

    압축비가 4.5일 때와 7.5일 때의 열효율을 비교하면 다음과 같다.

    열효율(압축비 4.5) = 1 - (Qc / 연소열) = 1 - (nR/(γ-1) × ΔT / 750) = 0.496

    열효율(압축비 7.5) = 1 - (Qc / 연소열) = 1 - (nR/(γ-1) × ΔT / 720) = 0.406

    따라서 압축비가 7.5일 때의 열효율은 압축비가 4.5일 때의 열효율보다 약 1.22배 낮다.

  3. 3차 반응
  4. 4차 반응

    2023-04-18 01:11

    반응속도식은 다음과 같이 나타낼 수 있다.

    r = k[A]^n

    여기서 r은 반응속도, k는 속도상수, [A]는 A기체의 농도, n은 반응차수이다.

    반감기는 반응물 농도가 초기 농도의 절반으로 감소하는 시간을 말한다. 따라서 반감기가 길어지면 반응물 농도가 더 느리게 감소한다는 것을 의미한다.

    첫 번째 실험에서 반감기가 80s이므로, t=80s일 때 [A]/[A]0 = 1/2 이다. 따라서,

    1/2 = e^(-kt)

    ln(1/2) = -kt

    k = ln2/80

    두 번째 실험에서 반감기가 120s이므로, t=120s일 때 [A]/[A]0 = 1/2 이다. 따라서,

    1/2 = e^(-kt)

    ln(1/2) = -kt

    k = ln2/120

    두 실험에서 k 값이 다르므로, 반응차수 n이 1차가 아니라고 추론할 수 있다.

    반응차수가 2차라고 가정하면,

    r = k[A]^2

    첫 번째 실험에서,

    r1 = k[A]1^2

    두 번째 실험에서,

    r2 = k[A]2^2

    두 식을 나누면,

    r2/r1 = [A]2^2/[A]1^2

    반감기가 길어지면 [A]2/[A]1 값이 작아지므로, r2/r1 값이 커진다. 따라서 반응차수가 2차라고 추론할 수 있다.

95. 체적이 일정한 회분식 반응기에서 다음과 같은 기체 반응이 일어난다. 초기의 전압과 분압을 각각 P0, PA0, 나중의 전압을 P라 할 때 분압 PA을 표시하는 식은? (단, 초기에 A, B는 양론비대로 존재하고 R은 없다.)

  1. PA=PA0-[a/(r+a+b)](P-P0)
  2. PA=PA0-[a/(r-a-b)](P-P0)
  3. PA=PA0+[a/(r-a-b)](P-P0)
  4. PA=PA0+[a/(r++)](P-P0)
(정답률: 46%)

    2023-04-18 01:11

    이 반응은 A와 B가 결합하여 C가 생성되는 반응이므로, A와 B의 몰수는 각각 a, b이고 C의 몰수는 r-a-b이다. 따라서, 초기에는 A와 B만 존재하므로 PA=PA0이다. 반응이 진행되면서 A와 B의 몰수가 감소하고 C의 몰수가 증가하므로 전체 몰수는 변하지 않는다. 따라서, PA와 P의 곱은 일정하다. 이를 이용하여 다음과 같은 식을 세울 수 있다.

    PA·(r-a-b) = PA0·(r-a-b) + a·(P-P0)

    PA = PA0 + [a/(r-a-b)]·(P-P0)

98. 부피가 일정한 회분식(batch) 반응기에서 다음의 기초반응(elementary reaction)이 일어난다. 반응속도 상수 k=1.0mol/m3/(sㆍmol), 반응 초기 A의 농도는1.0mol/m3이라면 A의 전화율이 75%일 때까지 걸리는 반응 시간은 얼마인가?

  1. 1.4s
  2. 3.0s
  3. 4.2s
  4. 6.0s
(정답률: 35%)
  • 30 CBT 기출문제AI

    2023-04-18 01:11

    주어진 반응식에서 A의 소비 속도는 k[A]2이다. 따라서 A의 농도가 75%로 감소하기 위해서는 초기 농도의 제곱의 1/4만큼 소비되어야 한다. 즉, 1.0mol/m3에서 0.25mol/m3으로 감소해야 한다. 이때 걸리는 시간은 다음과 같이 계산할 수 있다.
