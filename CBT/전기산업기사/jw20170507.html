3. 반지름 r=1[m]인 도체구의 표면 전하밀도가 이 되도록 하는 도체구의 전위는 몇 [V]인가?

  2. 20
  3. 40
  4. 80
(정답률: 54%)
  • 30 CBT 기출문제AI

    2023-04-17 15:54

    전하밀도가 주어졌으므로 전하량을 구할 수 있습니다. 도체구의 전하량은 전하밀도와 도체구의 표면적의 곱으로 구할 수 있습니다.

    전하량 = 전하밀도 × 표면적 = σ × 4πr²

    여기서 표면적은 도체구의 표면적인 4πr²이고, r은 반지름입니다.

    따라서 전하량은 다음과 같습니다.

    전하량 = (2 × 10⁻⁹ C/m²) × (4π × 1² m²) = 8π × 10⁻⁹ C

    전위는 전하량과 전위차의 비율로 구할 수 있습니다. 도체구의 중심에서 표면까지의 거리는 반지름인 1m이므로, 전위차는 다음과 같습니다.

    전위차 = k × Q / r = (9 × 10⁹ Nm²/C²) × (8π × 10⁻⁹ C) / 1m = 72π V

    따라서 전위는 다음과 같습니다.

    전위 = 전위차 / r = (72π V) / 1m = 72π [V] ≈ 226.2 [V]

    하지만 보기에서는 정답이 10, 20, 40, 80 중 하나입니다. 따라서 답은 40[V]입니다.

    이유는 전위차가 72π[V]이므로, 이를 2로 나누면 도체구의 중심에서 표면까지의 전위가 됩니다. 즉, 전위는 36π[V]이고, 이를 소수점 첫째 자리에서 반올림하여 40[V]이 됩니다.

    먼저, 회로망의 전체 회로를 그림으로 나타내면 다음과 같다.

    ```
    +---R1---+
    | |
    V1 R3
    | |
    A--R2--+--C--B
    | |
    GND R4
    | |
    +--------+
    ```

    VA = V1 - D * R3

    VA = V1 - (3+j2) * R3

    VAB = VA - (A-B) * R2

    VAB = VA - (8-j2) * R2

    IB = VAB / R4

    VC = B - IB * (B-GND)
