    자기인덕턴스(L)는 다음과 같은 공식을 사용하여 계산할 수 있다.

    L = ΔΦ / ΔI

    여기서 ΔΦ는 자기유도율 (NΦ)이며, N은 코일의 턴 수이고, Φ는 자기장의 플럭스이다. ΔI는 전류의 변화량이다.

    ε = -L (dI / dt)

    여기서 dI / dt는 시간에 대한 전류의 변화율이다.

    ε = -L (dI / dt)
    2.5 = -L (4 / 0.04)
    2.5 = -L (100)
    L = -0.025
    L = 25mH
