    Ar = 5r sin ø
    Aø = 0
    Az = 0

    ∇ × A = (1/r) [ (∂/∂ø)(Az) - (∂/∂z)(Aø) ] ar + (1/r) [ (∂/∂z)(Ar) - (∂/∂r)(rAz) ] aø + (1/r) [ (1/r)(∂/∂r)(rAø) - (∂/∂ø)(Ar) ] az

    (1/r) [ (∂/∂z)(Ar) - (∂/∂r)(rAz) ] aø
    = (1/r) [ (∂/∂z)(5r sin ø) - (∂/∂r)(r*0) ] aø
