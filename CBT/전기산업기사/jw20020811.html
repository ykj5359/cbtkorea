6. 길이 1[cm]마다 권수 50을 가진 무한장 솔레노이드에 500[mA]의 전류를 흘릴 때 내부자계는 몇[AT/m] 인가?

  2. 2500
  3. 12500
  4. 25000
(정답률: 73%)
  • 30 CBT 기출문제AI

    2023-04-17 17:20

    솔레노이드의 자기장은 다음과 같이 구할 수 있다.

    B = μ₀ * n * I

    여기서 B는 자기장의 세기, μ₀는 자유공간의 유전율, n은 권수 밀도(권수/길이), I는 전류이다.

    문제에서 권수 50을 가진 솔레노이드에 500[mA]의 전류를 흘린다고 했으므로, 권수 밀도는 50/1 = 50[권/m]이 된다.

    따라서, B = μ₀ * n * I = 4π × 10^-7 * 50 * 0.5 = 10^-5 [T] = 100 [G]

    1[T] = 10^4[G], 1[A/m] = 10^3[AT/m] 이므로,

    100[G] = 10^-2[T] = 10^-2 * 10^4[G] = 10^2[AT/m]

    따라서, 내부자계는 2500[AT/m]이 된다.
