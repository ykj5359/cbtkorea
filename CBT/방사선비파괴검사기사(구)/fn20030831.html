    log(노출량) = log(노출시간 x 노출량) = log(노출시간) + log(노출량) = log(노출시간) + (상대노출량 - 2)

    이를 이용하여 새로운 노출시간을 계산하면,
    log(노출시간 x 10mA-min) = 2.62
    log(노출시간) + (2.23 + 0.39) = 2.62
    log(노출시간) = 2.62 - 2.62
    log(노출시간) = 0
    노출시간 = 1
    따라서, 새로운 노출시간은 10mA-min을 1분 동안 노출하는 것이다.
    이를 MANTISSA표를 이용하여 계산하면 24.5 mA-min이 된다.
