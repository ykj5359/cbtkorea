14. X선 필름의 필름특성곡선에서 사진농도 2.10일 때 노출량 4mA × 52s, 사진농도 1.90일 때 노출량 4mA × 44s였다면 이 두 농도 사이의 평균 필름 콘트라스트는?

  1. 0.25
  2. 1.60
  3. 2.76
  4. 3.62
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-15 20:19

    평균 필름 콘트라스트는 (사진농도2.10 - 사진농도1.90) / 사진농도1.90 이다.

    따라서 (2.10 - 1.90) / 1.90 = 0.1⑤3 이다.

    노출량과 사진농도는 다음과 같은 관계가 있다.

    노출량1 / 노출량2 = (사진농도1 / 사진농도2)^(1/γ)

    여기서 γ는 필름의 감도를 나타내는데, 일반적으로 1.0 ~ 2.0 사이의 값을 가진다.

    위 식을 이용하여 노출량1 / 노출량2 = (1.10 / 0.90)^(1/γ) 로 변형할 수 있다.

    두 번째 노출량을 첫 번째 노출량으로 나누면,

    (4mA × 44s) / (4mA × 52s) = (1.10 / 0.90)^(1/γ)

    (11/13) = (1.10 / 0.90)^(1/γ)

    로그를 취하면,

    log(11/13) = (1/γ) * log(1.10 / 0.90)

    γ = log(11/13) / log(1.10 / 0.90)

    γ = 1.0

    따라서, 노출량과 사진농도의 관계식을 이용하여 사진농도가 2.10일 때의 노출량을 구하면,

    4mA × t = 2.10 / 1.90 * 4mA × 44s

    t = 52s

    노출량이 52s일 때의 사진농도는,

    2.10 / 1.90 = 1.1⑤3

    따라서, 필름특성곡선에서 사진농도가 1.90일 때와 2.10일 때의 노출량을 이용하여

    콘트라스트를 구하면,

    강의 노출량 = 노출시간 x 노출도 x 밀도
