    디지털 오디오의 데이터 크기는 샘플링 비율과 샘플 비트, 그리고 녹음 방식에 따라 결정된다. 따라서, 녹음 시간이 동일할 때 데이터 크기가 가장 큰 것은 "샘플링 비율 21kHz, 샘플 비트 16bit, 스테레오 녹음"이다. 이유는 다음과 같다.

    - 샘플링 비율: 샘플링 비율은 초당 샘플링 횟수를 의미한다. 따라서, 샘플링 비율이 높을수록 더 많은 샘플링 데이터가 생성되어 데이터 크기가 커진다. "샘플링 비율 21kHz"는 다른 보기들보다 높은 샘플링 비율을 가지고 있으므로 데이터 크기가 더 크다.

    - 샘플 비트: 샘플 비트는 하나의 샘플링 데이터가 차지하는 비트 수를 의미한다. 따라서, 샘플 비트가 높을수록 더 정밀한 데이터가 생성되어 데이터 크기가 커진다. "샘플 비트 16bit"는 다른 보기들보다 높은 샘플 비트를 가지고 있으므로 데이터 크기가 더 크다.

    - 녹음 방식: 스테레오 녹음은 모노 녹음보다 두 개의 채널에서 녹음되므로 데이터 크기가 두 배가 된다. 따라서, "샘플링 비율 21kHz, 샘플 비트 16bit, 스테레오 녹음"은 다른 보기들보다 스테레오 녹음을 하고 있으므로 데이터 크기가 더 크다.
