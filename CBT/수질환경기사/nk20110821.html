  3. 13.45m3
  4. 14.45m3
(정답률: 46%)

    메탄의 분자량은 16g/mol 이다. 따라서 15kg 의 메탄은 몰로 환산하면 15,000g / 16g/mol = 937.5 mol 이다.

    이상기체의 상태방정식은 PV = nRT 이다. 여기서 P는 압력, V는 부피, n은 몰수, R은 기체상수, T는 절대온도이다.

10. 벤젠, 톨루엔, 에틸벤젠, 자일렌이 같은 몰수로 혼합된 용액이 라울트 법칙을 따른다고 가정하면 이 혼합액의 총 증기압(25℃ 기준)은? (단, 벤젠, 톨루엔, 에틸벤젠, 자일렌의 25℃에서 순수 액체의 증기압은 각각 0.126, 0.038, 0.0126, 0.01177 atm 이며, 기타 조건은 고려하지 않음)

  1. 0.047 atm
  2. 0.⑤7 atm
  3. 0.067 atm
  4. 0.077 atm
(정답률: 61%)
  • 30 CBT 기출문제AI

    2023-04-16 15:03

    라울트 법칙에 따르면 혼합액의 총 증기압은 각 구성 성분의 증기압의 분압의 합과 같다. 따라서 각 구성 성분의 분압을 계산해야 한다.

    벤젠의 몰수를 x, 톨루엔의 몰수를 y, 에틸벤젠의 몰수를 z, 자일렌의 몰수를 w라고 하면, 각 구성 성분의 분압은 다음과 같다.

    벤젠의 분압 = x × 0.126 atm
    톨루엔의 분압 = y × 0.038 atm
    에틸벤젠의 분압 = z × 0.0126 atm
    자일렌의 분압 = w × 0.01177 atm

    따라서 혼합액의 총 증기압은 다음과 같다.

    총 증기압 = 벤젠의 분압 + 톨루엔의 분압 + 에틸벤젠의 분압 + 자일렌의 분압
    = x × 0.126 atm + y × 0.038 atm + z × 0.0126 atm + w × 0.01177 atm

    이제 주어진 몰수로 방정식을 세워 풀면 된다. 주어진 몰수의 합은 1이므로 다음과 같은 방정식이 성립한다.

    x + y + z + w = 1

    이 방정식과 각 구성 성분의 분압을 이용하여 총 증기압을 계산하면 다음과 같다.

    총 증기압 = x × 0.126 atm + y × 0.038 atm + z × 0.0126 atm + w × 0.01177 atm
    = (0.126 - 0.01177) x + 0.038 y + (0.0126 - 0.01177) z + 0.01177
    = 0.11423 x + 0.038 y + 0.00083 z + 0.01177

    이제 이 방정식을 x, y, z, w에 대해 최적화하여 총 증기압이 최대가 되는 값을 구할 수 있다. 하지만 이 문제에서는 최적화를 요구하지 않으므로, 각 구성 성분의 몰수가 모두 0.25일 때의 총 증기압을 계산하면 된다.

    x = y = z = w = 0.25 일 때,

    총 증기압 = 0.11423 × 0.25 + 0.038 × 0.25 + 0.00083 × 0.25 + 0.01177
    = 0.047 atm

    따라서 정답은 "0.047 atm"이다.

11. 다음은 Graham의 기체법칙에 관한 내용이다. ( )안에 알맞은 것은?

  1. ① 1/4, ② 1/8
  2. ① 1/6, ② 1/9
  3. ① 1/9, ② 1/12
  4. ① 1/12, ② 1/16
(정답률: 73%)
  • 30 CBT 기출문제AI

    2023-04-16 15:02

    Graham의 기체법칙은 P, V, T 세 가지 변수가 있을 때, PV/T가 일정하다는 법칙이다. 따라서, P1V1/T1 = P2V2/T2 이다.

    문제에서는 초기 상태와 최종 상태의 온도와 부피가 주어졌으므로, P1V1/T1 = P2V2/T2에서 P1/P2를 구하면 된다.

    ①에서는 초기 상태와 최종 상태의 부피가 2배 차이가 나므로, P1/P2 = 2가 된다.

    ②에서는 초기 상태와 최종 상태의 온도가 3배 차이가 나므로, T1/T2 = 3이 된다.

    따라서, P1/P2 = 2, T1/T2 = 3을 이용하여 P2/P1 = T2/T1 x V1/V2를 구할 수 있다.

    P2/P1 = 3 x 1/2 = 3/2 이므로, P1/P2 = 2/3이 된다.

    따라서, ①에서는 P1/P2 = 2/3이므로 1/4 x 2/3 = 1/6이 되고, ②에서는 P1/P2 = 2/3이므로 1/8 x 2/3 = 1/12가 된다.

    따라서, 정답은 "① 1/6, ② 1/9"이다.

(정답률: 51%)

    2023-04-16 15:02

    프로피온산의 이온화 반응식은 다음과 같습니다.

    C2H5COOH ⇌ C2H5COO- + H+

    이 때, 이온화 정수는 이온화된 양이 몰농도의 몇 분의 몇인지를 나타내는 값입니다. 이온화 정수를 x라고 하면, 이온화 반응식에 따라 다음과 같은 식이 성립합니다.

    x = [C2H5COO-][H+] / [C2H5COOH]

    여기서, [C2H5COOH] = 0.1M 이고, 이온화 정도가 4%이므로 [C2H5COO-] = [H+] = 0.04 × 0.1M = 0.004M 입니다. 이 값을 식에 대입하면,

    x = (0.004M)² / 0.1M = 0.00016 = 1.6 × 10^-4

    따라서, 이온화 정수는 1.7 × 10^-4 입니다.
