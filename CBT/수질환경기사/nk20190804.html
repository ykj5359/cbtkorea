6. 금속수산화물 M(OH)2의 용해도적(Kps)이 4.0×10-9이면 M(OH)2의 용해도(g/L)는? (단, M은 2가, M(OH)2의 분자량 = 80)

  1. 0.04
  2. 0.08
  3. 0.12
  4. 0.16
(정답률: 51%)
  • 30 CBT 기출문제AI

    2023-04-16 14:00

    Kps = [M^2+][OH^-]^2 = 4.0×10^-9
    M(OH)2의 분자량 = 80
    M(OH)2의 용해도(g/L)를 x라고 하면,
    [M^2+] = x/80
    [OH^-] = 2x/80 = x/40
    Kps = (x/80)^2(x/40)^2 = x^3/2.56×10^8
    x^3 = 2.56×10^-1
    x = 0.08

    따라서, M(OH)2의 용해도는 0.08g/L이다.

10. 생분뇨의 BOD는 19500ppm, 염소이온 농도는 4500ppm이다. 정화조 방류수의 염소이온 농도가 225ppm이고 BOD농도가 30ppm일 때, 정화조의 BOD 제거 효율은(%)? (단, 희석 적용, 염소는 분해되지 않음)

  1. 96
  2. 97
  3. 98
  4. 99
(정답률: 54%)
  • 30 CBT 기출문제AI

    2023-04-16 14:00

    BOD 제거 효율은 다음과 같이 계산할 수 있다.

    BOD 제거 효율(%) = ((입력 BOD - 출력 BOD) / 입력 BOD) x 100

    입력 BOD는 생분뇨의 BOD인 19500ppm을 희석하여 계산한다.

    입력 BOD = 19500ppm / 100 = 195ppm

    출력 BOD는 정화조 방류수의 BOD인 30ppm을 희석하여 계산한다.

    출력 BOD = 30ppm / 100 = 0.3ppm

    따라서, BOD 제거 효율은 ((195ppm - 0.3ppm) / 195ppm) x 100 = 99.85% 이다.

    하지만, 문제에서 염소는 분해되지 않는다고 했으므로, 정화조 방류수의 염소이온 농도는 생분뇨의 염소이온 농도와 같이 4500ppm이 된다.

    정화조 방류수의 염소이온 농도가 225ppm이므로, 생분뇨에서 제거된 염소이온 농도는 4275ppm이 된다.

    따라서, BOD 제거 효율은 ((195ppm - 0.3ppm) / 195ppm) x ((4500ppm - 4275ppm) / 4500ppm) x 100 = 97% 이다.

    즉, 염소이온 농도가 추가로 고려되어 BOD 제거 효율이 감소하게 된다.

12. 아세트산(CH3COOH) 1000mg/L 용액의 pH가 3.0이었다면, 이 용액의 해리상수(Ka)는?

  1. 2×10-5
  2. 3×10-5
  3. 4×10-5
  4. 6×10-5
(정답률: 55%)
  • 30 CBT 기출문제AI

    2023-04-16 14:00

    아세트산(CH3COOH)은 약산이므로 해리식은 다음과 같다.

    CH3COOH + H2O ⇌ CH3COO- + H3O+

    해리상수(Ka)는 다음과 같이 정의된다.

    Ka = [CH3COO-][H3O+]/[CH3COOH]

    pH가 3.0이므로 [H3O+] = 10-3.0 M = 1×10-3 M 이다. 또한, 초기 농도가 1000mg/L 이므로 [CH3COOH] = 1000/60 = 16.7 mM 이다. 초기에는 [CH3COO-] = 0 이므로, 균형상태에서 [CH3COO-] ≈ [H3O+] 이다.

    따라서, Ka ≈ [CH3COO-][H3O+]/[CH3COOH] ≈ [H3O+]2/[CH3COOH] = (1×10-3)2/16.7×10-3 = 6×10-5 이다.

    따라서, 정답은 "6×10-5" 이다.

18. 0.1N HCl 용액 100ml에 0.2N NaOH 용액 75ml를 섞었을 때 혼합용액의 pH는? (단, 전리도는 100% 기준)

  1. 약 10.1
  2. 약 10.4
  3. 약 11.3
  4. 약 12.5
(정답률: 42%)
  • 30 CBT 기출문제AI

    2023-04-16 14:00

    0.1N HCl 용액과 0.2N NaOH 용액을 섞으면 중화반응이 일어나고 NaCl과 H2O가 생성된다.

    NaOH + HCl → NaCl + H2O

    NaOH 용액의 몰농도가 0.2N 이므로 1L의 용액에 NaOH가 0.2mol 존재한다. 따라서 75ml의 NaOH 용액에는 0.015mol의 NaOH가 존재한다.
