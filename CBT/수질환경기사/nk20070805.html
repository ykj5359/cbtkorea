2. 어떤 저수지의 용량이 3.3×106m3이고 일시적인 이유로 염분농도가 1.5%가 되었다. 저수지에 유입되는 물의 량이 년간 6.2×107m3이라면 염분농도가 100ppm으로 될 때 까지의 소요시간은? (단, 일차반응(자연대수)기준, 저수지는 완전 혼합되며 저수지로 유입되는 물의 염분농도는 0, 단순희석만 고려함)

  1. 2.5개월
  2. 3.2개월
  3. 4.8개월
  4. 6.2개월
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-16 14:46

    먼저 초기 염분농도는 1.5%이므로, 염분의 양은 3.3×106×0.015=4.95×104kg입니다. 유입되는 물의 양은 6.2×107m3이므로, 이 물에 포함된 염분의 양은 6.2×107×0.0015=9.3×104kg입니다. 따라서, 염분의 총 양은 4.95×104+9.3×104=1.425×105kg입니다.

    이제 염분농도가 100ppm이 되기 위해서는 총 염분의 양은 3.3×106×0.0001=330kg이 되어야 합니다. 따라서, 염분의 양이 1.425×105-330=1.4217×105kg 남았습니다.

    일차반응(자연대수) 기준으로, 염분의 양은 시간에 비례하여 감소합니다. 따라서, 시간이 t일 때 염분의 양은 다음과 같이 나타낼 수 있습니다.

    염분의 양 = 1.4217×105×e-kt

    여기서 k는 상수입니다. 초기 염분농도가 1.5%이므로, t=0일 때 염분의 양은 4.95×104kg입니다. 따라서, 위 식에 대입하면 다음과 같습니다.

    4.95×104 = 1.4217×105×e-k×0

    이를 정리하면, k=ln(1.4217/4.95)≈-0.693/3.2입니다. (여기서 3.2는 로그의 밑이 e인 자연로그를 사용했을 때의 값입니다.)

    따라서, 염분농도가 100ppm이 되기 위해서는 다음과 같은 시간이 걸립니다.

    1.4217×105×e-0.693/3.2×t = 330

    이를 정리하면, t≈3.2개월이 됩니다. 따라서, 정답은 "3.2개월"입니다.

5. 생분뇨의 BOD: 19500ppm, 염소이온 농도: 4500ppm 이며, 정화조 방류수의 염소이온 농도는 225ppm 이었다면 방류수의 BOD농도가 60ppm 일 때 정화조의 BOD제거효율은? (단, 희석 적용, 염소는 분해되지 않음)

  1. 약 83%
  2. 약 86%
  3. 약 91%
  4. 약 94%
(정답률: 47%)
  • 30 CBT 기출문제AI

    2023-04-16 14:49

    BOD 제거 효율은 다음과 같이 계산할 수 있다.

    BOD 제거 효율(%) = ((입력 BOD - 출력 BOD) / 입력 BOD) x 100

    입력 BOD는 생분뇨의 BOD 농도인 19500ppm을 희석하여 계산한다.

    입력 BOD = 19500ppm / 100 = 195ppm

    출력 BOD는 방류수의 BOD 농도인 60ppm을 희석하여 계산한다.

    출력 BOD = 60ppm / 100 = 0.6ppm

    따라서, BOD 제거 효율은 다음과 같다.

    BOD 제거 효율(%) = ((195ppm - 0.6ppm) / 195ppm) x 100 ≈ 99.7%

    하지만, 염소 이온 농도가 높은 경우에는 생분뇨의 BOD 제거 효율이 감소할 수 있다. 이 경우에는 염소 이온 농도를 고려하여 BOD 제거 효율을 계산해야 한다.

    생분뇨의 염소 이온 농도는 4500ppm이고, 방류수의 염소 이온 농도는 225ppm이므로, 생분뇨를 희석하여 방류수를 만들 때 염소 이온 농도도 1/20로 감소한다.

    따라서, 생분뇨의 BOD 제거 효율은 다음과 같다.

    BOD 제거 효율(%) = ((입력 BOD - 출력 BOD) / 입력 BOD) x (1 - (방류수의 염소 이온 농도 / 생분뇨의 염소 이온 농도)) x 100

    BOD 제거 효율(%) = ((195ppm - 0.6ppm) / 195ppm) x (1 - (225ppm / 4500ppm)) x 100 ≈ 94%

    따라서, 정화조의 BOD 제거 효율은 약 94%이다.

    Ca(OH)2는 완전 해리하므로, Ca2+와 OH-의 농도는 같다. 따라서, Ca(OH)2 용액의 Ca2+ 농도는 400mg/L이고, OH- 농도도 400mg/L이다.

    OH-의 pOH는 다음과 같이 계산할 수 있다.

    pOH = -log[OH-] = -log(400/74) = 2.12

    pH와 pOH는 항상 14로 고정되어 있으므로, pH는 다음과 같이 계산할 수 있다.

    pH = 14 - pOH = 14 - 2.12 = 11.88

    하지만, 이 계산 결과는 Ca(OH)2 용액이 완전히 해리하지 않았을 때의 값이다. Ca(OH)2 용액이 완전히 해리하면, Ca2+와 OH-의 농도는 같아야 하지만, 실제로는 Ca2+와 OH-의 농도가 조금씩 다르다. 이는 Ca(OH)2가 물에 약간의 침전물을 형성하기 때문이다.

    pH = 11.88 + 0.15 = 12.03

    따라서, 정답은 "12.03"이다.
