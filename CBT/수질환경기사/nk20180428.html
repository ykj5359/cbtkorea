    BOD = BODu x (Qw/Qs) x (1 - k x t)

    BOD = 200 x (1/6) x (1 - 0.1 x t)

    DO = DOs + (k2/k1) x (BODs - BOD)

    여기서 DOs는 하천에서의 초기 DO 농도, k1과 k2는 각각 BOD 분해 상수와 DO 이동 상수, BODs는 하천에서의 BOD 농도이다.

    DO = 9.2 + (0.2/0.1) x (0 - BOD)

    여기서 BOD는 위에서 계산한 방류 후 하천에서의 BOD 농도이다.

    Q = (1/n) * A * R^(2/3) * S^(1/2)

    A = (π/4) * d^2

    R = (1/2) * d
