1. 150kL/day의 분뇨를 포기하여 BOD의 20%를 제거하였다. BOD 1kg을 제거하는데 필요한 공기공급량이 60m3 이라 했을 때 시간당 공기공급량(m3)은? (단, 연속포기, 분뇨의 BOD는 20000mg/L이다.)

  1. 100
  2. 500
  3. 1000
  4. 1500
(정답률: 71%)
  • 30 CBT 기출문제AI

    2023-04-16 14:21

    분뇨의 BOD는 20000mg/L이므로, 150kL(=150000L)의 분뇨의 BOD 양은 20000mg/L x 150000L = 3,000,000mg = 3000kg 이다. 이 중 20%를 제거하면 2400kg가 남는다.

    BOD 1kg을 제거하는데 필요한 공기공급량이 60m3 이므로, 2400kg를 제거하기 위해서는 2400 x 60 = 144000m3의 공기가 필요하다.

    시간당 공기공급량을 구하기 위해서는 이 값을 24시간으로 나누어야 한다. 따라서, 144000m3 ÷ 24시간 = 6000m3/시간이 된다.

    따라서, 시간당 공기공급량은 1500이 된다.

8. 유량 400000m3/day의 하천에 인구 20만명의 도시로부터 30000m3/day의 하수가 유입되고 있다. 하수 유입 전 하천의 BOD는 0.5mg/L이고, 유입 후 하천의 BOD를 2mg/L로 하기 위해서 하수처리장을 건설하려고 한다면 이 처리장의 BOD 제거효율(%)은? (단, 인구 1인당 BOD 배출량 20g/day)

  1. 약 84
  2. 약 87
  3. 약 90
  4. 약 93
(정답률: 44%)
  • 30 CBT 기출문제AI

    2023-04-16 14:21

    하수 유입 전 하천의 BOD 부하량은 다음과 같다.

    BOD 부하량 = 유량 x 농도 = 400000 x 0.5 x 10^-6 = 0.2 kg/day

    하수 유입 후 하천의 BOD 부하량은 다음과 같다.

    BOD 부하량 = (유량 + 하수 유입량) x 농도 = (400000 + 30000) x 2 x 10^-6 = 0.86 kg/day

    따라서, 하수 처리장에서 제거해야 할 BOD 부하량은 다음과 같다.

    BOD 제거 부하량 = 0.86 - 0.2 = 0.66 kg/day

    인구 1인당 BOD 배출량이 20g/day 이므로, 20만명의 인구가 배출하는 BOD 부하량은 다음과 같다.

    BOD 배출 부하량 = 20 x 10^-3 x 20만 = 4000 kg/day

    따라서, 처리장에서 제거해야 할 BOD 부하량은 전체 BOD 배출 부하량의 약 16.5%이다.

    BOD 제거 효율(%) = (처리해야 할 BOD 부하량 / 전체 BOD 배출 부하량) x 100 = (0.66 / 4) x 100 ≈ 16.5%

    하지만, 이 처리장에서 제거해야 할 BOD 부하량은 하수 유입량의 약 2.2배이므로, 처리장의 BOD 제거 효율은 약 84%이다. 따라서, 정답은 "약 84"이다.

    I2 + 2H2O + O2 → 2HIO3

    이 식에서, 1 mol의 아이오딘이 1 mol의 산소와 반응하여 2 mol의 HIO3을 생성한다. 따라서, 1 mol의 아이오딘은 0.5 mol의 산소에 해당한다.

    따라서, 0.18N의 산소량을 mg/L로 환산하면 다음과 같다.

    0.18 x 32 x 1000 / 1.429 = 4010.1 mg/L
