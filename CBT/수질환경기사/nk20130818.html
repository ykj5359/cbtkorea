  1. 약 33mg/L
  2. 약 45mg/L
  3. 약 52mg/L
  4. 약 57mg/L
(정답률: 67%)

    2023-04-16 14:33

    먼저, 유량과 유속을 이용하여 하천의 단면적을 구할 수 있다.

    단면적 = 유량 ÷ 유속 = 4.2 ÷ 0.4 = 10.5 m2

    공장폐수의 유입량을 분당 단위로 변환하면 다음과 같다.

    공장폐수 유입량 = 25.2 ÷ 60 = 0.42 m3/sec

    공장폐수의 BOD 양 = 공장폐수 유입량 × BOD 농도 = 0.42 × 500 = 210 mg/sec

    하천에서 유입되는 BOD 양 = 유량 × BOD 농도 = 4.2 × 7 = 29.4 mg/sec

    총 BOD 양 = 공장폐수의 BOD 양 + 하천에서 유입되는 BOD 양 = 210 + 29.4 = 239.4 mg/sec

    따라서, 합류지점에서의 BOD 농도는 다음과 같다.

    BOD 농도 = 총 BOD 양 ÷ 총 유입량 = 239.4 ÷ (4.2 + 0.42) = 52.2 mg/L

    따라서, 정답은 "약 52mg/L"이다.

    BOD 제거 효율 = (입구 BOD - 출구 BOD) / 입구 BOD x 100

    Ns = Nr (Qs/Qr)n

    따라서, 토출수두는 8m + 0.8m = 8.8m이다.

    비교 회전수를 계산하면 다음과 같다.

    Ns = 2000 (Qs/12)2 = 2000 (8.8/12)2 ≈ 1457
