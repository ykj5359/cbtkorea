  2. 12.7L
  3. 14.7L
  4. 23.7L
(정답률: 54%)

    V = nRT/P

    여기서, n은 몰수, R은 기체상수, T는 절대온도, P는 압력이다. 이 문제에서는 압력과 온도가 주어지지 않았으므로, 일반적으로 기체 상태를 나타내는 기준 상태인 0℃와 1 atm을 사용하여 계산할 수 있다. 따라서, R은 0.0821 L·atm/mol·K이고, T는 273 K이다.

    V = nRT/P = (1 mol) x (0.0821 L·atm/mol·K) x (273 K) / (1.32 atm) = 17.2 L

    하지만, 이는 전체 부피가 아니라, 1 mol의 기체가 차지하는 부피이므로, 실제 배관의 부피를 계산하기 위해서는 이 값을 배관의 길이와 단면적으로 곱해주어야 한다.

    A = πr2 = 3.14 x (12.5mm)2 = 490.6 mm2 = 0.00049 m2

    V = AL = (0.00049 m2) x (30 m) = 0.0147 m3 = 14.7 L

    따라서, 정답은 "14.7L"이다.

59. 이상기체의 정압비열(Cp)과 정적비열(Cv)에 대한 설명 중 틀린 것은? (단, k는 비열비이고, R 은 이상기체 상수이다.)

  1. 정적비열과 R의 합은 정압비열이다.
  2. 비열비(k)는 Cp/Cv로 표현된다.
  3. 정적비열은 R/(k - 1)로 표현된다.
  4. 정적비열은 (k - 1)/k 로 표현된다.
(정답률: 51%)
  • 30 CBT 기출문제AI

    2023-04-12 12:01

    "정적비열은 (k - 1)/k 로 표현된다."가 틀린 설명입니다.

    정압비열과 정적비열은 이상기체의 열역학적 성질을 나타내는 두 가지 개념입니다. 정압비열은 압력이 일정한 상태에서 단위 질량의 기체를 가열할 때 기체가 흡수하는 열의 양을 말하며, 정적비열은 부피가 일정한 상태에서 단위 질량의 기체를 가열할 때 기체가 흡수하는 열의 양을 말합니다.

    이상기체의 비열비(k)는 Cp/Cv로 표현됩니다. Cp는 압력이 일정한 상태에서 단위 질량의 기체를 가열할 때 기체가 흡수하는 열의 양을 단위 온도당 말하며, Cv는 부피가 일정한 상태에서 단위 질량의 기체를 가열할 때 기체가 흡수하는 열의 양을 단위 온도당 말합니다.

    정압비열과 정적비열은 다음과 같은 관계가 있습니다.

    Cp - Cv = R

    여기서 R은 이상기체 상수입니다. 따라서 정적비열은 R/(k - 1)로 표현됩니다. 이는 Cp과 Cv의 차이인 R을 비열비(k)로 나눈 값이기 때문입니다.
