20. 0℃, 1atm에서 4ℓ이던 기체는 273℃, 1atm일 때 몇 ℓ가 되는가?

  1. 2
  2. 4
  3. 8
  4. 12
(정답률: 65%)
  • 30 CBT 기출문제AI

    2023-04-12 12:10

    이 문제는 기체의 상태방정식을 이용하여 풀 수 있습니다.

    상태방정식: PV = nRT

    여기서 P는 압력, V는 부피, n은 몰수, R은 기체상수, T는 온도를 나타냅니다.

    먼저 초기 상태에서의 부피를 구해보겠습니다.

    P1V1/T1 = P2V2/T2 (상태방정식에서 파생된 식)

    여기서 P1 = P2 = 1 atm, T1 = 273 K, V1 = 4 L, T2 = 0 K (영점 절대온도) 입니다.

    1 x 4 / 273 = 1 x V2 / 0

    V2 = 0 L (영점에서는 모든 기체가 고체 상태이므로 부피가 0입니다.)

    따라서, 초기 상태에서의 부피는 4 L이었고, 이를 이용하여 최종 상태에서의 부피를 구해보겠습니다.

    P1V1/T1 = P2V2/T2

    여기서 P1 = P2 = 1 atm, T1 = 273 K, V1 = 4 L, T2 = 546 K (273 + 273) 입니다.

    1 x 4 / 273 = 1 x V2 / 546

    V2 = 8 L

    따라서, 최종 상태에서의 부피는 8 L이 됩니다. 따라서 정답은 "8"입니다.
