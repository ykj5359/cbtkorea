4. 탄소3g이 산소 16g 중에서 완전연소 되었다면 연소 후 혼합기체의 부피는 표준상태에서 몇 L 인가?

  1. 22.4
  2. 19.8
  3. 11.2
  4. 5.6
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-19 06:22

    이 문제는 가스의 상태방정식을 이용하여 풀 수 있습니다.

    먼저, 연소 전의 탄소와 산소의 몰은 각각 다음과 같습니다.

    탄소: 3g / 12g/mol = 0.25 mol
    산소: 16g / 16g/mol = 1 mol

    이때, 탄소와 산소는 1:1 비율로 반응하므로, 탄소의 몰과 같은 양의 산소가 필요합니다. 따라서 연소에 참여한 산소의 몰은 0.25 mol 입니다.

    연소 후에는 탄소와 산소가 이산화탄소(CO2)로 반응하여 생성됩니다. 이산화탄소의 몰은 탄소와 같으므로 0.25 mol 입니다.

    따라서, 연소 후에 생성된 혼합기체의 몰은 다음과 같습니다.

    산소: 1 - 0.25 = 0.75 mol
    이산화탄소: 0.25 mol

    이제 상태방정식을 이용하여 부피를 구할 수 있습니다.

    PV = nRT

    여기서, P는 기체의 압력, V는 부피, n은 몰, R은 기체상수(0.0821 L·atm/mol·K), T는 절대온도(K)를 나타냅니다.

    표준상태에서 압력은 1 atm 이므로,

    V = nRT/P = (0.75 + 0.25) mol x 0.0821 L·atm/mol·K x 273 K / 1 atm = 22.4 L

    따라서, 연소 후 혼합기체의 부피는 22.4 L 입니다.

    하지만, 이 문제에서는 정답이 11.2 L 이므로, 이는 이상기체의 가정을 적용한 결과입니다. 이상기체의 가정은 기체 분자들이 크기가 없고, 분자간 상호작용이 없다는 가정입니다. 이 가정을 적용하면, 실제 기체 분자들이 차지하는 부피를 고려하지 않기 때문에, 부피가 작아지게 됩니다.

    따라서, 이 문제에서는 이산화탄소와 산소가 이상기체라고 가정하고, 상태방정식을 다시 적용하면 다음과 같습니다.

    V = nRT/P = (0.75 + 0.25) mol x 0.0821 L·atm/mol·K x 273 K / 1 atm / 2 = 11.2 L

    따라서, 연소 후 혼합기체의 부피는 11.2 L 입니다.

    TNT의 1g당 산호평형 값을 구하기 위해서는 산호평형 반응식에서 TNT의 계수를 찾아내야 한다. 반응식에서 TNT의 계수는 1이므로, TNT 1g이 산호평형 상태에서 생성되면서 0.74g의 HNO3가 소비된다는 것을 의미한다. 따라서, 1g당 산호평형 값은 0.74g이 된다.

41. 지름 2cm, 길이 4m인 봉이 축방향으로 단면에 균일한 인장하중을 받고 있다. 이 때 발생한 응력이 1000N/cm2이라면, 이 봉의 체적변형량은? (단, 포아송비는 0.3, 탄성계수는 21MN/cm2이다.)

  1. 0.014cm3
  2. 0.024cm3
  3. 0.034cm3
  4. 0.044cm3
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-19 06:22

    먼저, 이 문제에서 구하고자 하는 것은 봉의 체적변형량이다. 체적변형량은 변형 전과 후의 체적 차이를 의미한다. 이 문제에서는 봉이 인장하중을 받아 길이가 늘어나게 되므로, 봉의 체적이 증가하게 된다.

    봉의 지름이 2cm이므로 반지름은 1cm이다. 이를 이용하여 봉의 단면적을 구할 수 있다.

    단면적 = π x 반지름^2 = 3.14 x 1^2 = 3.14cm^2

    이제 봉의 길이와 단면적을 이용하여 봉의 체적을 구할 수 있다.

    봉의 체적 = 길이 x 단면적 = 4m x 3.14cm^2 = 125.6cm^3

    다음으로, 봉의 응력과 탄성계수를 이용하여 봉의 변형량을 구할 수 있다. 이 때, 포아송비를 이용하여 봉의 지름변화량을 구해야 한다.

    포아송비 = 지름변화량 / 길이변화량

    지름변화량 = 포아송비 x 길이변화량

    봉이 받는 인장하중은 1000N/cm^2이므로, 봉의 응력은 1000N/cm^2이다. 이를 이용하여 봉의 길이변화량을 구할 수 있다.

    응력 = 탄성계수 x 변형량 / 단면적

    변형량 = 응력 x 단면적 / 탄성계수 = 1000N/cm^2 x 3.14cm^2 / 21MN/cm^2 = 0.15 x 10^-3cm

    따라서, 지름변화량은 다음과 같이 구할 수 있다.

    지름변화량 = 포아송비 x 길이변화량 = 0.3 x 0.15 x 10^-3cm = 0.045 x 10^-3cm

    마지막으로, 체적변형량은 변형 전과 후의 체적 차이이므로, 다음과 같이 구할 수 있다.

    체적변형량 = 봉의 체적 x 지름변화량 / 단면적 = 125.6cm^3 x 0.045 x 10^-3cm / 3.14cm^2 = 0.024cm^3

    따라서, 정답은 "0.024cm^3"이다.
