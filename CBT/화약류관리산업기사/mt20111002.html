19. 탄소 3g 이 산소 16g 중에서 완전연소 되었다면 연소 후 혼합기체의 부피는 표준상태에서 몇 L 인가?

  1. 22.4
  2. 19.8
  3. 11.2
  4. 5.6
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-19 06:19

    탄소 3g과 산소 16g이 완전연소되면 CO2와 H2O가 생성됩니다. 이때 생성된 기체의 몰은 다음과 같습니다.

    CO2: 3g / 44g/mol = 0.068 mol
    H2O: 16g / 18g/mol = 0.889 mol

    따라서 생성된 기체의 총 몰은 0.068 mol + 0.889 mol = 0.957 mol 입니다.

    이 기체의 부피는 아보가드로 수를 이용하여 다음과 같이 계산할 수 있습니다.

    V = nRT/P

    여기서, n은 몰, R은 기체상수, T는 온도, P는 압력입니다. 표준상태에서 온도는 273K이고 압력은 1 atm입니다. 따라서,

    V = 0.957 mol x 0.0821 L atm/mol K x 273K / 1 atm = 21.1 L

    하지만 이 기체는 CO2와 H2O로 이루어져 있으므로, 이들의 분압을 고려해야 합니다. 이들의 분압은 각각 다음과 같습니다.

    PCO2 = 0.068 mol / 0.957 mol x 1 atm = 0.071 atm
    PH2O = 0.889 mol / 0.957 mol x 1 atm = 0.929 atm

    따라서, 이 기체의 총 부피는 다음과 같습니다.

    VCO2 = PCO2 x V / P = 0.071 atm x 21.1 L / 1 atm = 1.5 L
    VH2O = PH2O x V / P = 0.929 atm x 21.1 L / 1 atm = 19.7 L

    따라서, CO2와 H2O의 부피를 합하면,

    V = VCO2 + VH2O = 1.5 L + 19.7 L = 21.2 L

    따라서, 정답은 21.2 L이 됩니다. 하지만 보기에서는 11.2 L이 정답으로 주어져 있습니다. 이는 CO2와 H2O의 분압을 고려하지 않고, 단순히 생성된 기체의 몰을 1 mol로 가정하여 계산한 값입니다. 따라서, 이 보기는 오답입니다.
