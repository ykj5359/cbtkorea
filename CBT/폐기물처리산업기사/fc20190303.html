11. 폐기물의 80%를 3cm 보다 작게 파쇄하려 할 때 Rosin-Rammler 입자크기 분포모델을 이용한 특성입자의 크기(cm)는? (단, n = 1)

  1. 1.36
  2. 1.86
  3. 2.36
  4. 2.86
(정답률: 62%)
  • 30 CBT 기출문제AI

    2023-04-18 19:43

    Rosin-Rammler 입자크기 분포모델은 다음과 같은 수식으로 나타낼 수 있습니다.

    F(x) = 1 - exp[-(x/xm)^n]

    여기서 F(x)는 입자크기가 x보다 작은 비율을 나타내며, xm은 중간값 입자크기를 나타내는 매개변수입니다. n은 분포의 형태를 결정하는 매개변수로, 일반적으로 1에서 3 사이의 값을 가집니다.

    문제에서는 입자크기가 3cm보다 작은 폐기물의 비율이 80%라고 하였으므로, F(x) = 0.8이 됩니다. 또한 n = 1이므로 수식을 다음과 같이 간단하게 나타낼 수 있습니다.

    F(x) = 1 - exp[-(x/xm)]

    따라서, 위 수식에 F(x) = 0.8을 대입하면 다음과 같은 식이 나옵니다.

    0.8 = 1 - exp[-(x/xm)]

    이를 정리하면 다음과 같습니다.

    exp[-(x/xm)] = 0.2

    양변에 로그를 취하면,

    -(x/xm) = ln(0.2)

    x/xm = -ln(0.2)

    x = xm * (-ln(0.2))

    따라서, xm은 특성입자의 크기(cm)가 1.86이 되도록 설정하면 됩니다.

32. 오염된 지하수의 Darcy 속도(유출속도)가 0.15m/day이고, 유효 공극률이 0.4일 때 오염원으로부터 1000m 떨어진 지점에 도달하는데 걸리는 기간(년)은? (단, 유출속도 : 단위시간에 흙의 전체 단면적을 통하여 흐르는 물의 속도)

  1. 약 6.5
  2. 약 7.3
  3. 약 7.9
  4. 약 8.5
(정답률: 58%)
  • 30 CBT 기출문제AI

    2023-04-18 19:43

    Darcy의 법칙에 따라 유출속도는 다음과 같이 표현할 수 있다.

    Q = KAΔh/L

    여기서 Q는 유출량, K는 토양의 투수도, A는 단면적, Δh는 유출면에서의 수위차, L은 유출면에서의 길이를 나타낸다.

    문제에서 주어진 유출속도는 0.15m/day이므로, 유출면에서의 수위차 Δh는 1m이 된다. 또한, 유효 공극률이 0.4이므로, 토양의 투수도 K는 다음과 같이 구할 수 있다.

    K = q/Δh = QL/(AΔh)

    여기서 q는 단위면적당 유출량을 나타내며, 문제에서 주어진 유출속도와 유효 공극률을 이용하여 다음과 같이 계산할 수 있다.

    q = Q/A = 0.15m/day / (1m x 1m) = 0.15m/day

    따라서,

    K = 0.15m/day x 1000m / (1m x 1m x 1m) = 150m/day

    이제, 오염원으로부터 1000m 떨어진 지점에 도달하는데 걸리는 기간을 구하기 위해 다음과 같은 식을 이용할 수 있다.

    t = L/Q = L/(KAΔh)

    여기서 L은 1000m이고, K와 A는 위에서 구한 값으로 대입하면,

    t = 1000m / (150m/day x 1m x 1m x 1m x 1m x 1m x 1m x 0.4) = 약 7.3년

    따라서, 정답은 "약 7.3"이다.
