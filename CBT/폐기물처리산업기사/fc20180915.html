3. 인구 1200만인 도시에서 년간 배출된 총 쓰레기량이 970만 톤이었다면 1인당 하루 배출량(kg/인ㆍ일)은? (단, 1년은 365일 임)

  1. 약 2.0
  2. 약 2.2
  3. 약 2.4
  4. 약 2.6
(정답률: 82%)

    년간 배출된 총 쓰레기량을 1200만으로 나누면 1인당 년간 배출량을 구할 수 있다.

    970만 ÷ 1200만 = 0.8083 톤/인

    년간 배출량을 일간 배출량으로 환산하기 위해 365일로 나눈다.

    0.8083 ÷ 365 = 0.0022 톤/인/일

    1톤 = 1000kg 이므로, 0.0022 톤을 kg으로 환산하면 2.2kg/인/일이 된다.

    따라서 정답은 "약 2.2"이다.

39. 유해폐기물 고화처리 시 흔히 사용하는 지표인 혼합율(MR)은 고화제 첨가량과 폐기물 양의 중량비로 정의된다. 고화처리 전 폐기물의 밀도가 1.0g/cm3, 고화처리된 폐기물의 밀도가 1.3g/cm이라면 혼합율(MR)이 0.755일 때 고화 처리된 폐기물의 부피변화율(VCF)은?

  1. 1.95
  2. 1.56
  3. 1.35
  4. 1.15
(정답률: 63%)
  • 30 CBT 기출문제AI

    2023-04-18 19:44

    혼합율(MR)은 고화제 첨가량과 폐기물 양의 중량비로 정의되므로, MR = 고화제 첨가량 / (고화제 첨가량 + 폐기물 양) 이다. 따라서, 고화제 첨가량은 MR * 폐기물 양 / (1 - MR) 이다.

    고화처리 전 폐기물의 부피는 폐기물 양과 같으므로, V1 = 폐기물 양.
    고화처리 후 폐기물의 부피는 밀도가 1.3g/cm³ 이므로, V2 = 폐기물 양 / 1.3 이다.

    고화제 첨가 후의 폐기물의 부피는 V1 + 고화제 첨가량 이므로, V3 = V1 + (MR * 폐기물 양 / (1 - MR)).

    따라서, 고화 처리된 폐기물의 부피변화율(VCF)은 (V3 - V1) / V1 이다.

    (V3 - V1) / V1 = ((V1 + (MR * 폐기물 양 / (1 - MR))) - V1) / V1
    = (MR * 폐기물 양 / (1 - MR)) / V1
    = MR / (1 - MR) * (1 / 밀도)

    여기에 MR = 0.755, 밀도 = 1.0g/cm³, 1.3g/cm³ 를 대입하면,
    VCF = 0.755 / (1 - 0.755) * (1 / 1.0 - 1 / 1.3)
    = 1.35

    따라서, 정답은 "1.35" 이다.
