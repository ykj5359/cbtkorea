6. A도시의 폐기물 수거량이 2,000,000ton/year 이며, 수거인부는 1일 4,000명이고 수거 대상인구는 5,000,000인이다. 그리고 수거인부의 일 평균작업시간은 5시간이라고 할 때, MHT는? (단, 1년은 365일 기준 )

  1. 1.83MHT
  2. 2.97MHT
  3. 3.65MHT
  4. 4.21MHT
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-18 19:27

    MHT는 Mean Hauling Time의 약자로, 한 번의 수거 작업에 걸리는 평균 시간을 의미한다.

    수거인부 1일 작업시간 = 4,000명 x 5시간 = 20,000시간

    1인당 평균 수거량 = 2,000,000 ton / 5,000,000인 = 0.4 ton/인

    1일 평균 수거량 = 0.4 ton/인 x 5,000,000인 = 2,000,000 ton/day

    1회 수거 작업에 걸리는 평균 시간 = 20,000시간 / (2,000,000 ton/day / 365일) = 1.825시간

    따라서 MHT는 1.83시간이 된다.

    하지만 보기에서는 MHT가 시간 단위가 아닌 분 단위로 표기되어 있으므로, 1.83시간 x 60분 = 109.8분 ≈ 1.83MHT

    따라서 정답은 "3.65MHT"가 된다.
