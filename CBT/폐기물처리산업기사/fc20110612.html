  1. 약 1020kW
  2. 약 1120kW
  3. 약 1220kW
  4. 약 1320kW
(정답률: 알수없음)

    2023-04-18 19:17

    파쇄 작업에서 필요한 동력은 다음과 같이 계산할 수 있다.

    파쇄 전 총 에너지 = 파쇄 후 총 에너지

    파쇄 전 총 에너지 = (평균 크기/2)^2 x 밀도 x 처리량 x 특정 열량
    = (30.5/2)^2 x 0.2 x 50 x 13.6
    = 1,303,780 kW·hr

    파쇄 후 총 에너지 = (최종 크기/2)^2 x 밀도 x 처리량 x 특정 열량
    = (5.1/2)^2 x 0.2 x 50 x 13.6
    = 54,864 kW·hr

    필요한 동력 = (파쇄 전 총 에너지 - 파쇄 후 총 에너지) / 처리 시간
    = (1,303,780 - 54,864) / (50 x 1000 / 3600)
    = 1220 kW

    따라서, 정답은 "약 1220kW"이다.

5. 트롬멜 스크린의 임계속도(nc)를 구하는 식으로 옳은 것은? (단, g : 중력가속도, r : 스크린 반경)

(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-18 19:17

    정답은 ""이다.

    트롬멜 스크린은 회전하는 원통형 스크린으로, 재료를 회전시켜 분리하는 장치이다. 이 때, 임계속도는 스크린에 붙어있는 입자가 중력과 원심력에 의해 분리되는 속도를 말한다. 이를 구하는 식은 다음과 같다.

    nc = (g / r)^(1/2)
