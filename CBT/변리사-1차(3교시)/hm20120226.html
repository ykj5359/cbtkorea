    따라서, 전자의 운동에너지는 전자의 총 에너지에서 우물의 포텐셜 에너지인 E = 0을 뺀 값이다. 전자의 총 에너지는 운동에너지와 포텐셜 에너지의 합인데, 이 때 운동에너지가 최소가 되려면 포텐셜 에너지가 최대가 되어야 한다.

    V(x) = {
    0 (0 ≤ x ≤ L)
    ∞ (x < 0 or x > L)
    }

    따라서, 전자의 운동에너지의 최소값은 포텐셜 에너지가 최대가 되는 x = L/2에서의 값이다. 이 때의 포텐셜 에너지는 V(L/2) = 0이므로, 전자의 운동에너지의 최소값은 전자의 총 에너지인 E = h^2/(8mL^2)이다.

3. 직선과 반원 모양이 연결된 관을 통해 진동수가 680 Hz인 소리굽쇠의 음파가 진행해 나가고 있다. 이 관의 반대편에서 수신자가 듣는 소리의 세기를 최대한 크게 하기 위한 반원 모양 관의 반지름 r의 최소값은? (단, π값은 3으로 하며, 관내의 모든 지점에서 음파의 속도는 340m/s로 균일하다. 수신자는 관을 통해서 전파된 소리만 들을 수 있고, 음파의 감쇠는 무시한다.)

  1. 30 cm
  2. 50 cm
  3. 60 cm
  4. 75 cm
  5. 80 cm
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-15 21:12

    반원 모양의 관 부분에서는 음파가 반사되어 일어나는 공명 현상으로 인해 세기가 증폭된다. 이 때, 공명 주파수는 반원의 둘레 길이와 반지름에 의해 결정된다. 따라서, 공명 주파수가 680 Hz가 되도록 하기 위해서는 반원의 둘레 길이와 반지름을 이용하여 다음과 같이 식을 세울 수 있다.

    반원의 둘레 길이 = 직선의 파장 / 2 = (340 / 680) / 2 = 0.25 m
    반원의 둘레 길이 = 2πr / 2 = πr

    따라서, πr = 0.25 m 이므로, r = 0.25 / π = 약 0.0798 m = 약 7.98 cm 이다. 하지만, 문제에서는 반지름의 최소값을 구하라고 했으므로, 반원의 둘레 길이가 최소가 되도록 반지름을 설정해야 한다. 이를 위해서는 반원의 둘레 길이가 직선의 파장의 절반인 0.25 m가 되도록 반지름을 설정하면 된다.

    반원의 둘레 길이 = 2πr / 2 = πr = 0.25 m
    r = 0.25 / π = 약 0.0798 m = 약 7.98 cm

    따라서, 반원 모양 관의 반지름 r의 최소값은 약 7.98 cm 이므로, 정답은 "50 cm"이 아닌 "30 cm"이다.

  2. A층 → B층 → C층 → 암맥 → 단층 → 부정합 → D층
  3. A층 → B층 → C층 → D층 → 부정합 → 단층 → 암맥
  4. A층 → B층 → C층 → 단층 → 부정합 → D층 → 암맥
  5. A층 → 단층 → B층 → C층 → 부정합 → 암맥 → D층
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-15 21:12

    정답은 "A층 → B층 → C층 → 단층 → 부정합 → 암맥 → D층"이다.

    지질단면을 보면 가장 아래에 있는 것은 A층으로, 이후 B층, C층이 차례로 쌓였다. 그리고 이후에는 단층이 생겨났고, 이 단층 위에는 부정합이 생겨났다. 부정합 위에는 암맥이 생겨났고, 마지막으로 D층이 쌓였다.

    따라서, 생성순서는 "A층 → B층 → C층 → 단층 → 부정합 → 암맥 → D층"이 된다.
