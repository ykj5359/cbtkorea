    줄이 감겨있는 도르래는 회전운동을 하게 된다. 이 때, 회전운동의 에너지 보존 법칙을 이용하면 회전운동의 운동에너지와 위치에너지의 합은 일정하다는 것을 알 수 있다. 따라서 물체가 자유낙하하여 도르래를 회전시키면, 물체의 위치에너지가 감소하면서 도르래의 회전운동 에너지가 증가하게 된다.

    물체가 도르래를 회전시키기 위해서는 중력이 도르래의 회전축 주위를 중심으로 회전운동을 하면서 도르래를 회전시켜야 한다. 이 때, 도르래의 관성모멘트 I와 각속도 ω, 물체의 질량 m, 중력가속도 g가 관련되어 있다. 따라서 물체가 도르래를 회전시키기 위해서는 다음과 같은 관계식을 만족해야 한다.

    mgh = 1/2Iω^2

    여기서 h는 물체의 높이이고, ω는 각속도이다. 이 식을 변형하면 다음과 같다.

    ω = √(2mgh/I)

    따라서 물체가 도르래를 회전시키기 위해서는 높이 h와 관성모멘트 I, 물체의 질량 m, 중력가속도 g가 주어져 있으면 각속도 ω를 구할 수 있다.

    한 바퀴를 도는 데 걸리는 시간은 주어진 각속도 ω에 대해 다음과 같다.

    T = 2π/ω

    따라서 도르래가 10회 회전하는 데 걸리는 시간은 다음과 같다.

    T = 20π/ω = 20π/√(2mgh/I)

    여기서 h = R(1-cosθ)이고, θ는 도르래의 회전각이다. 따라서 θ = 20π/10 = 2π이다. 따라서 h = R(1-cos2π) = 0이다. 따라서 물체가 도르래를 회전시키기 위해 필요한 높이는 0이므로, 위의 식에서 h = 0으로 대입하면 다음과 같다.

    T = 20π/√(2I/mg)

    여기서 I = 3kg⋅m^2, m = 5kg, g = 10 m/s^2이므로, 다음과 같다.

    T = 20π/√(2×3×5×10) = 2√π

    따라서 도르래가 10회 회전하는 데 걸리는 시간은 2√π초이다.

    금속막대가 미끄러지는 동안, 자기장이 막대를 향해 작용하며 막대에 일정한 힘을 가한다. 이 힘은 로렌츠 힘으로, F = q(v × B)로 표현된다. 여기서 q는 전하량, v는 속도, B는 자기장의 세기를 나타낸다. 이 문제에서는 전하량이나 전류가 주어지지 않았으므로, q는 무시할 수 있다. 따라서 F = vBsinθ로 표현할 수 있다. 여기서 θ는 막대와 자기장의 각도이다.

    막대가 처음에는 오른쪽으로 가속되므로, 로렌츠 힘은 왼쪽으로 작용한다. 따라서 막대는 왼쪽으로 힘을 받아서 감속하게 된다. 막대의 속도가 줄어들면서 로렌츠 힘의 크기도 줄어들게 되고, 어느 순간에는 로렌츠 힘이 없어지게 된다. 이때 막대의 속도는 최소값에 도달하게 된다. 그리고 다시 오른쪽으로 가속되면서 로렌츠 힘이 오른쪽으로 작용하게 된다.

    따라서 막대가 감속하다가 멈추는 순간에는 로렌츠 힘이 없어지므로, F = vBsinθ = 0이 된다. 이때 θ는 자기장과 막대의 속도 벡터 사이의 각도이다. 즉, 자기장이 수직으로 지나가므로 θ = 90도가 된다. 따라서 sinθ = 1이 되어, vB = 0이 된다. 이때의 속도는 1 m/s이므로, B = 0이 된다.

    따라서 정답은 ""이다.

8. 1몰 단원자 이상기체 상태가 압력-부피(P-V) 그림의 a에서 b까지 직선 경로를 따라 변할 때, 기체의 엔트로피(entropy) 변화량은? (단, 이상기체 상수는 R이다.)

  1. 3R⋅ln3
  2. 4R⋅ln2
  3. 4R⋅ln3
  4. 4R⋅ln4
  5. 4R⋅ln5
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-15 21:⑤

    기체의 엔트로피 변화량은 다음과 같이 구할 수 있다.

    ΔS = ∫(dq/T)

    여기서 dq는 열량, T는 절대온도이다. 이상기체 상태 방정식을 이용하여 dq를 다음과 같이 변형할 수 있다.

    dq = nCv dT = (Cp - Cv) n dT

    여기서 n은 몰수, Cv는 등체적 열용량, Cp는 등압적 열용량이다. 이를 위의 식에 대입하면 다음과 같다.

    ΔS = ∫[(Cp - Cv)/T] n dT

    이를 경로 a에서 b까지 적분하면 다음과 같다.

    ΔS = nR ln(Vb/Va) + nCp ln(Tb/Ta)

    여기서 V는 부피, T는 온도이다. 경로 a에서 b까지 직선 경로를 따라 변하므로, 부피와 온도는 다음과 같이 변한다.

    Vb/Va = 3/1
    Tb/Ta = 3/1

    따라서, ΔS는 다음과 같다.

    ΔS = nR ln(3) + nCp ln(3)

    이상기체 상태에서 Cp - Cv = R이므로, Cp = Cv + R이다. 이를 ΔS에 대입하면 다음과 같다.

    ΔS = nR ln(3) + n(Cv + R) ln(3)
    = nR ln(3) + nR ln(3) + nCv ln(3)
    = 2nR ln(3) + nCv ln(3)

    이상기체 상태에서 Cv = (3/2)R이므로, 이를 대입하면 다음과 같다.

    ΔS = 2nR ln(3) + (3/2)nR ln(3)
    = (4R/2) n ln(3) + (3/2) nR ln(3)
    = 4R ln(3)

    따라서, 정답은 "4R⋅ln3"이다.

    그림 (가)에서 별 A(베텔게우스)는 별 B(리겔)보다 더 큰 크기를 가지고 있으며, 그림 (나)에서 파장이 긴 빨간색 영역에서 별 A의 빛의 세기가 더 크다는 것을 알 수 있다. 이는 별 A가 별 B보다 더 높은 온도를 가지고 있기 때문이다.

    따라서, "ㄱ, ㄷ"가 정답이다.
