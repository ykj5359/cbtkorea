    L = L1 + x = L2 + 2x = 0.321L1 + 2x

4. 그림과 같이 공기 중에 전하량 +Q인 점전하와 한 변의 길이가 L인 가상의 정사각형이 있다. 점전하와 정사각형의 중심 사이의 거리가 L/2 일 때, 이 정사각형 내부를 통과하는 전기장 선속(또는 전기장 다발)의 크기는? (단, 공기의 유전율은 ε0이다.)

  2. Q / 6ε0

    정사각형의 중심과 점전하 사이의 거리가 L/2 이므로, 전기장의 크기는 Coulomb의 법칙에 따라 다음과 같이 계산할 수 있다.

    E = kQ / r^2

    여기서 k는 쿨롱 상수이고, r은 정사각형의 중심과 점전하 사이의 거리이다. 정사각형의 한 변의 길이가 L이므로, r은 다음과 같이 구할 수 있다.

    r = √(L^2 / 2)

    따라서 전기장의 크기는 다음과 같다.

    E = kQ / (L^2 / 2)

    E = 2kQ / L^2

    여기서 k는 ε0 / 4π이므로, 전기장의 크기는 다음과 같다.

    E = Q / (2πε0L^2)

    이제 정사각형 내부를 통과하는 전기장 선속(또는 전기장 다발)의 크기를 구해야 한다. 이는 전기장의 크기를 정사각형의 한 변의 길이 L로 나눈 값이다.

    전기장 선속 = E / L

    전기장 선속 = Q / (2πε0L^3)

    따라서 정답은 "Q / (2πε0L^3)"이다. 이를 간단화하면 "Q / 6ε0"이 된다.
