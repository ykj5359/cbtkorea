78. 나이퀴스트 채널용량 산출 공식(C)으로 옳은 것은? (단, 잡음이 없는 채널로 가정, S/N: 신호대잡음비, M : 진수, B : 대역폭)

  1. C＝Blog2(S/N)(bps)
  2. C＝Blog2(M＋1)(bps)
  3. C＝2Blog2(10＋S/N)(bps)
  4. C＝2Blog2M(bps)
(정답률: 44%)
  • 30 CBT 기출문제AI

    2023-04-15 21:23

    정답은 "C＝2Blog2M(bps)"이다.

    이유는 다음과 같다.

    나이퀴스트 채널용량 공식은 다음과 같다.

    C = B log2(1 + S/N)

    여기서 M = 2b이므로,

    C = B log2(1 + S/N) = 2B log2(√M + 1)

    = 2B log2(2b/2 + 1)

    = 2B log2(2b/2) + 2B log2(1 + 1/2b/2)

    = 2B(b/2) + 2B log2(1 + 1/2b/2)

    = Bb + 2B log2(1 + 1/2b/2)

    = 2Blog2M(bps)

    따라서, C＝2Blog2M(bps)이다.
