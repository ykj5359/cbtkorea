4. 프로세서의 처리 속도 단위가 느린 것부터 빠른 순으로 올바르게 나열된 것은?

  1. ps-㎲-ms-ns
  2. ms-ns- ㎲-ps
  3. ms-㎲- ns-ps
  4. ns-ps-㎲-ms
(정답률: 82%)
  • 30 CBT 기출문제AI

    2023-04-15 21:32

    정답은 "ms-㎲-ns-ps"이다.

    이유는 다음과 같다.

    - ms (밀리초) : 1/1000초, 즉 1초를 1000등분한 단위이다.
    - ㎲ (마이크로초) : 1/1000000초, 즉 1초를 1000000등분한 단위이다.
    - ns (나노초) : 1/1000000000초, 즉 1초를 1000000000등분한 단위이다.
    - ps (피코초) : 1/1000000000000초, 즉 1초를 1000000000000등분한 단위이다.

    따라서, 처리 속도가 느린 것부터 빠른 순으로 나열하면 ps → ㎲ → ms → ns → ps 순서가 된다.
