79. HDLC(High-level Data Link Control)의 링크 구성 방식에 따른 동작 모드로 틀린 것은?

  1. SRM
  2. ARM
  3. NRM
  4. ABM
(정답률: 44%)
  • 30 CBT 기출문제AI

    2023-04-15 21:37

    HDLC의 링크 구성 방식에 따른 동작 모드 중 틀린 것은 "SRM"입니다.

    - ARM (Asynchronous Response Mode): 비동기 응답 모드로, 주로 터미널과 호스트 간 통신에 사용됩니다. 터미널이 데이터를 보내면 호스트는 즉시 응답을 보내는 방식입니다.
    - NRM (Normal Response Mode): 일반 응답 모드로, 주로 컴퓨터 네트워크에서 사용됩니다. 송신 측이 데이터를 보내면 수신 측은 데이터를 받았다는 응답을 보내고, 이후에 데이터를 처리합니다.
    - ABM (Asynchronous Balanced Mode): 비동기 균형 모드로, 양방향 통신에 사용됩니다. 송신 측과 수신 측이 모두 데이터를 보낼 수 있으며, 각각의 데이터에 대해 응답을 보내는 방식입니다.

    SRM (Selective Reject Mode)은 HDLC의 링크 제어 프로토콜 중 하나이지만, HDLC의 동작 모드는 아닙니다. SRM은 오류가 발생한 프레임만 재전송하는 방식으로, NRM과 ABM에서 사용됩니다.
