  2. 73
  3. 99
  4. 126
(정답률: 30%)

    2023-04-18 04:13

    축과 키의 재료가 같다는 것은 최대전단응력이 같다는 것을 의미한다. 따라서, 키에서 발생하는 최대전단응력과 축에 발생하는 최대전단응력이 같다는 조건은 키와 축의 최대전단응력이 같다는 것을 의미한다.

    키의 최대전단응력은 다음과 같이 구할 수 있다.

    τ = T/(2A)
    여기서, T는 전단력, A는 키의 단면적이다.

    A = bL
    여기서, b는 키의 폭, L은 키의 길이이다.

    따라서, 키의 최대전단응력은 다음과 같다.

    τ = T/(2bL)

    τ = T/(2πr^2)
    여기서, r은 축의 지름의 절반(즉, 반지름)이다.

    따라서, 키와 축의 최대전단응력이 같다는 조건은 다음과 같이 표현할 수 있다.

    T/(2bL) = T/(2πr^2)

    이를 정리하면 다음과 같다.

    L = bπr^2

    여기서, b는 10mm, r은 25mm(지름이 50mm이므로 반지름은 25mm)이다. 따라서, 키의 길이 L은 다음과 같다.
