12. 소재의 직경 20mm, 소재의 두께 0.2mm, 전단저항 36kgf/mm2인 경우 블랭킹(blanking)에 필요한 힘을 구하면?

  1. 약 145kgf
  2. 약 452kgf
  3. 약 753kgf
  4. 약 2260kgf
(정답률: 40%)
  • 30 CBT 기출문제AI

    2023-04-18 03:56

    블랭킹은 재료를 원하는 모양으로 자르는 공정으로, 이때 필요한 힘은 다음과 같이 계산할 수 있다.

    필요한 힘 = 소재의 면적 x 소재의 전단저항

    소재의 면적 = π x (직경/2)2 - π x (직경/2 - 두께)2
    = π x (20/2)2 - π x (20/2 - 0.2)2
    = 314.16 - 301.59
    = 12.57mm2

    필요한 힘 = 12.57mm2 x 36kgf/mm2
    = 452.52kgf

    따라서, 블랭킹에 필요한 힘은 "약 452kgf"이다.
