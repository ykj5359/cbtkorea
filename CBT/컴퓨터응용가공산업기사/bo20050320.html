4. 밀링머신에서 스파이럴 밀링장치로 커팅할 때, 가공물의 원통직경을 120㎜, 스파이럴 각도를 30°로 할 경우의 리드(lead) 값은?

  1. 약 548㎜
  2. 약 653㎜
  3. 약 623㎜
  4. 약 638㎜
(정답률: 30%)
  • 30 CBT 기출문제AI

    2023-04-18 04:00

    리드(lead)란 나사나 나선형태의 가공물을 만들 때, 한 바퀴 회전할 때 나사나 나선이 나아가는 거리를 말합니다. 스파이럴 밀링장치로 가공할 때, 리드 값은 다음과 같이 계산됩니다.

    리드 = 원통직경 x π x 스파이럴 각도 / 360

    따라서, 주어진 조건에서 리드 값은 다음과 같이 계산됩니다.

    리드 = 120 x π x 30 / 360
    = 120 x 0.2618
    ≈ 31.416

    하지만, 이 값은 한 바퀴 회전할 때 나사나 나선이 나아가는 거리를 나타내는 것이므로, 가공물의 전체 길이를 구하기 위해서는 이 값을 원주에 곱해주어야 합니다.

    가공물의 원주 = 원통직경 x π
    = 120 x π
    ≈ 376.99

    따라서, 가공물의 전체 길이는 다음과 같이 계산됩니다.

    전체 길이 = 리드 x 원주
    ≈ 31.416 x 376.99
    ≈ 1184.67

    이 값은 소수점 이하가 있으므로, 반올림하여 정답은 "약 653㎜"이 됩니다.

5. 인발 작업에서 지름 10mm의 강선을 지름 5mm로 만들었을때 단면 감소율은?

  2. 50%
  3. 40%
  4. 25%
(정답률: 22%)

    2023-04-18 04:00

    단면 감소율은 (원래 단면 면적 - 새로운 단면 면적) / 원래 단면 면적 x 100 으로 계산됩니다.

    따라서, 지름이 10mm인 강선의 단면 면적은 (π/4) x (10mm)^2 = 78.54mm^2 이고, 지름이 5mm인 강선의 단면 면적은 (π/4) x (5mm)^2 = 19.63mm^2 입니다.

    그러므로, 단면 감소율은 (78.54 - 19.63) / 78.54 x 100 = 74.99 (약 75%) 가 됩니다. 따라서, 정답은 "75%" 입니다.
