7. 서울~부산간 영업거리가 441.7km, 무궁화호 임율이 56.10원일 경우, 어른 6명, 노인 1명, 어린이 2명의 운임으로 맞는것은?

  1. 180,000원
  2. 191,000원
  3. 200,000원
  4. 220,000원
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-18 07:24

    먼저 운임 계산식은 다음과 같다.
    운임 = 영업거리 x 임금률 x 인원수

    따라서, 우리는 다음과 같이 계산할 수 있다.

    어른 6명 = 441.7 x 56.10 x 6 = 148,766원
    어린이 2명 = 441.7 x 56.10 x 2 x 0.5 = 31,104원 (어린이는 운임에서 50% 할인)
    노인 1명 = 441.7 x 56.10 x 1 x 0.5 = 15,552원 (노인도 운임에서 50% 할인)

    따라서, 총 운임은 148,766원 + 31,104원 + 15,552원 = 195,422원 이다.

    하지만, 문제에서 우리는 "맞는 것"을 찾아야 한다. 따라서, 가장 가까운 운임을 선택해야 한다. 따라서, 정답은 "191,000원" 이다.
