13. 다음과 같은 브리지회로의 평형 조건은?

  1. R1×R2=R3×R4
  2. R1×R4=R2×R3
  3. R1+R2=R3+R4
  4. R1+R4=R2+R3
(정답률: 60%)
  • 30 CBT 기출문제AI

    2023-04-13 15:06

    브리지회로에서는 R1과 R2가 서로 평행하고, R3과 R4가 서로 평행합니다. 이때, 브리지회로의 양 끝에 전압을 걸어주면, 전압이 걸린 쪽의 R1과 R4에는 전류가 흐르고, R2와 R3에는 전류가 흐르지 않습니다. 이때, 전류가 흐르는 R1과 R4의 합과, 전류가 흐르지 않는 R2와 R3의 합이 서로 같아야 합니다. 이를 수식으로 나타내면 다음과 같습니다.

    전류가 흐르는 R1 + 전류가 흐르는 R4 = 전류가 흐르지 않는 R2 + 전류가 흐르지 않는 R3

    이 식을 정리하면 다음과 같습니다.

    전류가 흐르는 R1 - 전류가 흐르지 않는 R3 = 전류가 흐르지 않는 R2 - 전류가 흐르는 R4

    이때, R1과 R2가 서로 평행하고, R3과 R4가 서로 평행하기 때문에, 전류가 흐르는 R1과 전류가 흐르지 않는 R3의 비율은 전류가 흐르지 않는 R2와 전류가 흐르는 R4의 비율과 같습니다. 즉, 다음과 같은 식이 성립합니다.

    전류가 흐르는 R1 : 전류가 흐르지 않는 R3 = 전류가 흐르지 않는 R2 : 전류가 흐르는 R4

    이를 더 간단하게 나타내면 다음과 같습니다.

    R1×R4 = R2×R3

    따라서, 브리지회로의 평형 조건은 "R1×R4 = R2×R3"입니다.
