2. 총고정경비는 44,300,000원이고 참가자 1인당 변동비는 61,000원으로 분석되었다. 그리고 참가 예상자는 최소 1,700명으로 예측하고 있다. 컨벤션조직위원회에서는 컨벤션개최를 통하여 5,000,000원의 이익을 창출하고자 한다. 1,700명이 참가하는 것을 전제로 하는 경우 주최조직의 재정목표를 달성하기 위해서는 1인당 최소참가비는 얼마로 책정하여야 하는가?

  1. 80,000원
  2. 90,000원
  3. 100,000원
  4. 110,000원
(정답률: 알수없음)

    총 수입은 참가자 수에 참가비를 곱한 값이다. 따라서, 참가자 1인당 최소 참가비를 x라고 하면 다음과 같은 식이 성립한다.

    총 수입 = x × 참가자 수

    컨벤션조직위원회의 재정목표는 5,000,000원의 이익을 창출하는 것이므로, 총 수입은 다음과 같이 표현할 수 있다.

    총 수입 = 총 비용 + 5,000,000원

    총 비용은 고정비와 변동비의 합이다. 따라서, 다음과 같은 식이 성립한다.

    총 비용 = 44,300,000원 + 61,000원 × 참가자 수

    위의 두 식을 결합하면 다음과 같은 식이 성립한다.

    x × 참가자 수 = 44,300,000원 + 61,000원 × 참가자 수 + 5,000,000원

    이를 정리하면 다음과 같은 식이 성립한다.

    x × 참가자 수 - 61,000원 × 참가자 수 = 49,300,000원

    x = (49,300,000원) ÷ (참가자 수 - 61,000원)

    최소 참가자 수가 1,700명이므로, x는 다음과 같이 계산된다.

    x = (49,300,000원) ÷ (1,700명 - 61,000원)
    x = 90,000원

    따라서, 주최조직은 1인당 최소 90,000원의 참가비를 책정해야 재정목표를 달성할 수 있다.
