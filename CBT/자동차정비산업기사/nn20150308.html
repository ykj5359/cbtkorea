  2. 1/2 u1
  3. 2u1
  4. 4u1
(정답률: 53%)

    2023-04-17 13:39

    단위 체적 당 저장되는 탄성에너지는 다음과 같이 표현할 수 있다.

    W = (1/2)σε

    여기서 W는 탄성에너지, σ는 응력, ε는 변형률을 나타낸다. 이 문제에서는 탄성한도 내에서 작용하는 응력을 고려하므로, σ = Eε로 표현할 수 있다. 여기서 E는 탄성계수를 나타낸다.

    따라서,

    W = (1/2)Eε²

    이제 봉에 발생하는 인장응력이 2배가 되면, ε는 반으로 줄어들게 된다. 따라서,

    W' = (1/2)E(ε/2)² = (1/8)Eε²

    W'는 단위 체적 당 저장되는 탄성에너지이므로, 이를 비교하면 다음과 같다.

    W'/W = (1/8)Eε² / (1/2)Eε² = 1/4

    따라서, 단위 체적 당 저장되는 탄성에너지는 4u1이 된다.

73. 14V 배터리에 연결된 전구의 소비전력이 60W이다. 배터리의 전압이 떨어져 12V가 되었을 때 전구의 실제 전력은 약 몇 W 인가?

  1. 3.2
  2. 25.5
  3. 39.2
  4. 44.1
(정답률: 54%)
  • 30 CBT 기출문제AI

    2023-04-17 13:39

    전력은 전압과 전류의 곱으로 계산된다. 따라서, 전압이 12V로 떨어졌을 때 전류는 이전에 비해 증가해야 한다. 전류는 전압에 반비례하기 때문에, 14V에서 60W를 사용할 때의 전류(I1)는 다음과 같다.

    60W = 14V x I1
    I1 = 60W / 14V
    I1 = 4.29A

    12V에서의 전류(I2)는 다음과 같다.

    12V = 4.29A x R
    R = 12V / 4.29A
    R = 2.8Ω

    따라서, 12V에서의 전력(P2)은 다음과 같다.

    P2 = 12V x (4.29A)^2
    P2 = 12V x 18.4A
    P2 = 220.8W

    하지만, 이는 전구의 실제 전력이 아니라, 전류가 증가하면서 전선 등에서 발생하는 열로 인해 손실되는 전력까지 포함한 값이다. 따라서, 전구의 실제 전력은 이보다 작을 것이다. 이러한 손실을 고려하여, 전구의 실제 전력은 약 44.1W가 된다.
