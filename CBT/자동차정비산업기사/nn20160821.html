4. 허용 인장응력이 100N/mm2인 아이볼트에 축방향으로 1t의 화물을 들어 올리는 경우, 이 볼트의 골지름은 최소 몇 mm 이상이어야 하는가?

  1. 9.8
  2. 11.2
  3. 13.4
  4. 16.9
(정답률: 42%)
  • 30 CBT 기출문제AI

    2023-04-17 13:35

    화물의 무게는 1t = 1000kg 이므로, 이에 상응하는 힘은 F = mg = 1000kg x 9.8m/s2 = 9800N 이다. 이 힘이 작용하는 면적은 볼트의 단면적이므로, A = πr2 이다. 따라서 인장응력은 σ = F/A = F/(πr2) 이다.

    이제 주어진 조건에 따라 인장응력이 100N/mm2 이 되도록 볼트의 골지름을 구해보자.

    100N/mm2 = F/(πr2)

    r2 = F/(100N/mm2 x π)

    r2 = 9800N/(100N/mm2 x 3.14)

    r2 = 3121.66

    r = √3121.66

    r = 55.9mm

    따라서 볼트의 골지름은 최소 2r = 2 x 55.9mm = 11.2mm 이상이어야 한다.

79. 12V 50AH의 배터리에서 100A의 전류로 방전하여 비중 1.220으로 저하될 때까지의 소요시간은?

  1. 5분
  2. 10분
  3. 20분
  4. 30분
(정답률: 55%)
  • 30 CBT 기출문제AI

    2023-04-17 13:37

    전기용량(Q) = 전류(I) x 시간(t)

    50AH의 배터리에서 100A의 전류로 방전할 때, 소요시간(t)는 다음과 같이 계산할 수 있다.

    Q = 50AH = 50,000mAh
    I = 100A
    t = Q / I = 50,000mAh / 100A = 500시간

    하지만, 비중이 1.220으로 저하될 때까지의 시간을 구해야 하므로, 배터리의 상태를 모니터링하며 비중이 1.220이 될 때까지의 시간을 측정해야 한다.
