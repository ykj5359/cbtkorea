17. 바깥지름 80, 길이 120mm의 강재환봉을 초경바이트로 거친 절삭을 할때의 가공시간은? (단, 이송량 f=0.3 ㎜/rev, 절삭속도 v=70 m/min이다.)

  1. 약 1.44 min
  2. 약 3.45 min
  3. 약 5.54 min
  4. 약 7.54 min
(정답률: 30%)
  • 30 CBT 기출문제AI

    2023-04-16 07:18

    가공시간은 다음과 같이 계산할 수 있다.

    1. 초경바이트로 거친 절삭에서의 회전수 계산

    바깥지름 80mm이므로 반지름은 40mm이다. 이때 초경바이트의 직경은 20mm이므로 반지름은 10mm이다. 따라서 초경바이트로 거친 절삭에서의 회전수는 다음과 같다.

    회전수 = (바깥지름 - 초경바이트 직경) / (2 x 초경바이트 반지름)
    = (80 - 20) / (2 x 10)
    = 3

    2. 절삭에 필요한 이동거리 계산

    절삭에 필요한 이동거리는 강재환봉의 둘레길이와 절삭 깊이를 곱한 값이다. 강재환봉의 둘레길이는 다음과 같다.

    둘레길이 = π x 바깥지름
    = 3.14 x 80
    = 251.2mm

    절삭 깊이는 초경바이트의 반지름인 10mm이다. 따라서 절삭에 필요한 이동거리는 다음과 같다.

    이동거리 = 둘레길이 x 절삭 깊이
    = 251.2 x 10

    비틀림각과 비틀림모멘트 사이에는 다음과 같은 관계식이 성립한다.

    θ = L * G * M / (J * π)

    여기서,
    θ: 비틀림각
    L: 축의 길이
    G: 가로탄성계수
    M: 비틀림모멘트
    J: 평면적 관성모멘트
    π: 원주율

    θ = L * G * M / (J * π)
    J = L * G * M / (θ * π)
    J = 6 * 810000 * 400 / (3 * π)
    J ≈ 292238.8 ㎝4

    J = π * d^4 / 32

    d = (32 * J / π)^0.25
    d = (32 * 292238.8 / π)^0.25

    L{f(t)} = L{sinωt} = ω / (s^2 + ω^2)
