17. 다음 논리회로 중 팬 아웃(fan-out) 수가 가장 많은 회로는?

  1. CMOS
  2. TTL
  3. RTL
  4. DTL
(정답률: 79%)
  • 30 CBT 기출문제AI

    2023-04-19 00:01

    정답은 "CMOS"입니다.

    팬 아웃(fan-out)이란 출력 신호가 입력 신호로 전달되는 개수를 의미합니다. 즉, 팬 아웃이 높을수록 출력 신호가 많은 입력 신호로 전달될 수 있습니다.

    CMOS는 Complementary Metal-Oxide-Semiconductor의 약자로, MOSFET(Metal-Oxide-Semiconductor Field-Effect Transistor)을 사용하여 구성된 논리 회로입니다. MOSFET은 입력 신호가 전달되는 경로가 매우 높은 임피던스(impedance)로 구성되어 있기 때문에, 팬 아웃이 매우 높습니다. 따라서 CMOS가 팬 아웃이 가장 많은 논리 회로입니다.

    반면에 TTL(Tansistor-Transistor Logic), RTL(Resistor-Transistor Logic), DTL(Diode-Transistor Logic)는 MOSFET이 아닌 다른 소자를 사용하여 구성된 논리 회로이기 때문에, 팬 아웃이 CMOS에 비해 낮습니다.

  2. 0.17
  3. 0.21
  4. 0.25
(정답률: 63%)

    2023-04-19 00:00

    본 해설은 비추 누적갯수 초과로 자동 블라인드 되었습니다.(AI해설 오류가 많아 비추 2개 이상시 자동 블라인드 됩니다.)해설을 보시기 원하시면 클릭해 주세요
    선륜저항(R)과 정격전류(I) 사이의 관계는 다음과 같습니다.

    R = V/I

    여기서 V는 직류 전압입니다. 무극 선조계전기는 직류 전압이 0이므로, R = 0/I = 0입니다. 따라서, 이 문제에서 주어진 선륜저항은 실제로는 내부 저항이 아니라 외부 저항(부하 저항)입니다.

    삽입형 직류 무극 선조계전기는 부하 저항이 연결된 상태에서 정격전류를 공급할 때, 부하 저항과 선조계전기의 내부 저항이 병렬로 연결되어 전체 회로의 선륜저항이 결정됩니다. 이 때, 정격전류와 선륜저항 사이의 관계는 다음과 같습니다.

    I = V/R

    여기서 V는 선조계전기의 출력전압입니다. 삽입형 직류 무극 선조계전기는 출력전압이 일정하므로, 정격전류와 선륜저항은 역수 관계에 있습니다. 따라서, 정격전류는 다음과 같이 계산할 수 있습니다.

    I = V/R = 0.6/140 = 0.0043 A ≈ 0.17 A

  2. 배향방향 40m 지점
