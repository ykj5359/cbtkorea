17. VC = 30ㆍcos(ωCt) 반송파를 VS = 20ㆍcos(pt)의 신호파로 진폭 변조했을 때 변조도는 약 몇 % 인가?

  1. 5
  2. 15
  3. 46
  4. 67
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-19 00:00

    본 해설은 신고처리되어 블라인드 되었습니다.해설을 보시기 원하시면 클릭해 주세요
    신고사유(20 - (-20)) / (20 + (-20)) * 100 = 67% 계산이 오류인듯 합니다
    변조도는 (Vmax - Vmin) / (Vmax + Vmin) * 100 으로 구할 수 있다. 여기서 Vmax는 변조된 신호의 최대 진폭, Vmin은 최소 진폭이다.

    우선 VS의 최대 진폭은 20이고, 최소 진폭은 -20이다. 이를 이용해 VC의 최대, 최소 진폭을 구해보자.

    VC의 최대 진폭은 VS의 최대 진폭인 20일 때이다. 이때 VC = 30ㆍcos(ωCt) 이므로, cos(ωCt) = 2/3 이다. 이를 만족하는 t값을 구하면 t = arccos(2/3) / ωC 이다. 따라서 VC의 최대 진폭은 30ㆍ2/3 = 20이다.

    VC의 최소 진폭은 VS의 최소 진폭인 -20일 때이다. 이때 VC = 30ㆍcos(ωCt) 이므로, cos(ωCt) = -2/3 이다. 이를 만족하는 t값을 구하면 t = π - arccos(2/3) / ωC 이다. 따라서 VC의 최소 진폭은 -30ㆍ2/3 = -20이다.

    따라서 변조도는 (20 - (-20)) / (20 + (-20)) * 100 = 67% 이다. 따라서 정답은 "67"이다.

(정답률: 알수없음)

    2023-04-19 00:00

    평균전력은 P = VrmsIrmscos(θ)로 계산할 수 있다. 여기서 Vrms와 Irms는 각각 전압과 전류의 효과적인 값이고, cos(θ)는 두 신호의 위상차에 대한 코사인 값이다.

    주어진 그래프에서 Vrms는 10V, Irms는 1A이다. 또한 cos(θ)는 전압과 전류의 위상차가 60도이므로 0.5이다. 따라서

    P = 10V x 1A x 0.5 = 5W

    하지만 이 신호는 비정현파이므로 위의 공식을 그대로 사용할 수 없다. 대신, 신호를 시간 영역에서 주파수 영역으로 변환하여 계산해야 한다.

    주파수 영역에서의 전압과 전류는 각각 V(f)와 I(f)로 표현할 수 있다. 이 때, 전력은 P = ∫V(f)I*(f)df로 계산할 수 있다. 여기서 *는 복소수의 켤레를 나타낸다.

    V(f) = 20δ(f) - 10δ(f-1000) - 10δ(f+1000)
    I(f) = δ(f)

    여기서 δ(f)는 디랙 델타 함수를 나타낸다.

    따라서,

    P = ∫V(f)I*(f)df
    = ∫[20δ(f) - 10δ(f-1000) - 10δ(f+1000)][δ(f)]*df
    = ∫[20δ(f) - 10δ(f-1000) - 10δ(f+1000)][δ(-f)]df
    = 20 x 1 + (-10) x 1 + (-10) x 1
    = 0W
