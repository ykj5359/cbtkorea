27. 길이 10인치, 직경이 4인치인 시험체의 선형자화 전류를 구하면? (단, L/D가 2 이상이며 4 미만인 부품이며, 코일의 감은 횟수는 5회이다.)

  2. 900A
  3. 1800A
  4. 3600A

    선형자화 전류는 다음과 같이 계산할 수 있습니다.

    선형자화 전류 = (π/4) x (D/L) x (N x I)

    여기서, D는 직경, L은 길이, N은 코일의 감수, I는 전류입니다.

    주어진 시험체의 D/L 비율은 4/10 = 0.4입니다. 이는 L/D가 2 이상이며 4 미만인 조건을 만족합니다.

    또한, 코일의 감수는 5회이므로 N = 5입니다.

    따라서, 선형자화 전류를 계산하면 다음과 같습니다.

    선형자화 전류 = (π/4) x (4/10) x (5 x I) = 0.3927I

    보기에서 주어진 값들을 이 식에 대입해보면 다음과 같습니다.

    - 450A: 0.3927 x 450 = 176.715A
    - 900A: 0.3927 x 900 = 353.43A
    - 1800A: 0.3927 x 1800 = 706.86A
    - 3600A: 0.3927 x 3600 = 1413.72A

    따라서, 정답은 3600A입니다.

  3. 71
  4. 80

    허용 사용률은 정격 사용률에서 실제 사용률을 나눈 값이므로,

    허용 사용률 = (실제 사용률 ÷ 정격 사용률) × 100

    여기서 실제 사용률은 사용하는 용접전류를 정격 전류로 나눈 값이다.

    실제 사용률 = (사용하는 용접전류 ÷ 정격 전류) × 100

    따라서,

    실제 사용률 = (150A ÷ 200A) × 100 = 75%

    허용 사용률 = (75% ÷ 40%) × 100 = 187.5%

    하지만, 허용 사용률은 100%를 넘을 수 없으므로, 최대값인 100%로 제한된다.
