    선형자화법에서 소요 전류는 다음과 같이 계산할 수 있습니다.

    I = (π/4) x D^2 x n x μ x H

    여기서, D는 직경, n은 권선수, μ는 자기유도율, H는 자기장 세기를 나타냅니다.

    강봉의 직경이 4인치이므로, 반지름은 2인치가 됩니다. 이를 센티미터로 변환하면 5.08cm가 됩니다.

    따라서, D = 5.08cm 입니다.

    또한, 권선수는 4회이므로, n = 4 입니다.

    자기유도율과 자기장 세기는 선형자화법으로 검사하는 대상에 따라 다르게 결정됩니다. 이 문제에서는 이에 대한 정보가 주어지지 않았으므로, 일반적으로 사용되는 값인 μ = 4π x 10^-7 H/m을 사용하겠습니다.

    따라서, μ = 4π x 10^-7 H/m 입니다.

    마지막으로, 이 값을 식에 대입하여 소요 전류를 계산하면 다음과 같습니다.

    I = (π/4) x D^2 x n x μ x H
    = (π/4) x (5.08cm)^2 x 4 x (4π x 10^-7 H/m) x H
    = 1.26 x 10^-4 x H A

    여기서, H는 자기장 세기를 나타내는 값입니다. 이 값은 선형자화법으로 검사하는 대상에 따라 다르게 결정됩니다. 이 문제에서는 이에 대한 정보가 주어지지 않았으므로, 일반적으로 사용되는 값인 800 A/m을 사용하겠습니다.

    따라서, H = 800 A/m 입니다.

    I = 1.26 x 10^-4 x H A
    = 1.26 x 10^-4 x 800 A/m
    = 0.1 A
    = 100 mA
