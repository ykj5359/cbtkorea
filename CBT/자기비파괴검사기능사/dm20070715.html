11. 길이 25.4cm(10인치), 직경 5.08cm(2인치)인 부품의 선형 자화시 코일의 권선수가 5회 일 때 사용되는 전류는 몇 A인가?

  1. 300
  2. 1000
  3. 1800
  4. 2700
(정답률: 56%)
  • 30 CBT 기출문제AI

    2023-04-12 17:46

    선형 자화시 코일의 권선수가 5회이므로, 총 권선수는 5 x 2 = 10이 됩니다. 이 부품의 길이와 직경을 이용하여 부피를 구하면 다음과 같습니다.

    부피 = (π/4) x (직경)^2 x 길이
    = (π/4) x (5.08cm)^2 x 25.4cm
    = 1296.5 cm^3

    부피와 총 권선수를 이용하여 부픈의 자기적인도를 구하면 다음과 같습니다.

    자기적인도 = (4π x 10^-7) x (총 권선수)^2 x 부피
    = (4π x 10^-7) x (10)^2 x 1296.5 x 10^-6
    = 0.0⑤17 H

    자기적인도와 권선수를 이용하여 전류를 구하면 다음과 같습니다.

    전류 = 자기적인도 / 권선수
    = 0.0⑤17 H / 10
    = 0.00⑤17 A
    = 517 mA

    따라서, 정답은 1000이 아닌 517mA입니다.
