21. 그림과 같은 V형 맞대기 용접에서 굽힘 모멘트가(Mb)가 10000kgfㆍcm 작용하고 있을 때, 최대 굽힘 응력은? (다만, ℓ=150mm, t=20mm 이고 완전 용입일 때이다.)

  1. 10[kgf/cm2]
  2. 100[kgf/cm2]
  3. 1000[kgf/cm2]
  4. 10000[kgf/cm2]
(정답률: 58%)
  • 30 CBT 기출문제AI

    2023-04-17 08:37

    최대 굽힘 응력은 다음과 같이 구할 수 있다.

    σb = Mb / (Wp / 2) * (t / 2)

    여기서, Wp는 단면의 폭을 나타내며, V형 맞대기 용접에서는 Wp = ℓ + t로 계산할 수 있다.

    따라서,

    Wp = ℓ + t = 150 + 20 = 170mm

    σb = 10000 / (170 / 2) * (20 / 2) = 1000[kgf/cm2]
