  2. 전기에 부도체이며, 비중이 작다.
  3. 결정의 내부구조를 변경시킬 수 있다.
  4. 금속 고유의 광택을 갖고 있다.
(정답률: 83%)

    2023-04-17 08:26

    금속은 전기를 잘 전도하고, 비중이 크다는 특징이 있다. 따라서 전기에 부도체이며, 비중이 작다는 특징은 금속의 공통적인 성질과는 맞지 않는다.

    수은은 금속 중에서도 특이한 성질을 가지고 있어 상온에서 액체 상태를 유지한다. 결정체가 아니기 때문에 "결정의 내부구조를 변경시킬 수 있다."는 특징도 수은을 제외한 대부분의 금속에 해당한다. 또한 금속은 고유의 광택을 갖고 있기 때문에 "금속 고유의 광택을 갖고 있다."는 특징도 맞는다.

22. 무부하 전압이 80V, 아크전압 35V, 아크전류 400A라 하면 교류용접기의 역률과 효율은 각각 약 몇 % 인가? (단, 내부손실은 4kW 이다.)

  1. 역률 : 51, 효율 : 72
  2. 역률 : 56, 효율 : 78
  3. 역률 : 61, 효율 : 82
  4. 역률 : 66, 효율 : 88
(정답률: 57%)

    2023-04-17 08:27

    역률은 유효전력과 피상전력의 비율로 계산된다. 유효전력은 아크전압과 아크전류의 곱으로 계산되며, 피상전력은 무부하 전압과 전류의 곱으로 계산된다. 따라서, 유효전력은 35V x 400A = 14,000W 이고, 피상전력은 80V x 400A = 32,000W 이다. 따라서, 역률은 14,000W / 32,000W = 0.4375 = 43.75% 이다.

  2. 수소가스
  3. 산소와 질소의 혼합가스
  4. 질소가스

55. 정격전류가 500A 인 용접기를 실제로 400A 로 사용하는 경우의 허용사용률은 몇 % 인가? (단, 이 용접기의 정격사용률은 40% 이다.)

  1. 66.5
  2. 64.5
  3. 62.5
  4. 60.5
(정답률: 75%)
  • 30 CBT 기출문제AI

    2023-04-17 08:26

    용접기의 정격사용률이 40% 이므로, 이 용접기는 500A x 40% = 200A 까지만 사용이 가능하다. 따라서, 400A 로 사용하는 경우의 허용사용률은 400A / 200A x 100% = 200% 이다. 하지만, 용접기의 정격전류는 500A 이므로, 실제로는 400A 로 사용하는 경우의 허용사용률은 400A / 500A x 100% = 80% 이다. 따라서, 정답은 80% x 0.78125 = 62.5% 이다. (0.78125 는 400A / 500A 의 값이다.)

57. 돌기 용접(projection welding)의 특징 중 틀린 것은?

  1. 용접부의 거리가 짧은 점용접이 가능하다.
  2. 전극 수명이 길고 작업 능률이 높다.
  3. 작은 용접점이라도 높은 신뢰도를 얻을 수 있다.
  4. 한 번에 한 점씩만 용접할 수 있어서 속도가 느리다.
(정답률: 85%)
  • 30 CBT 기출문제AI

    2023-04-17 08:26

    돌기 용접은 용접부의 거리가 짧은 점용접이 가능하고, 전극 수명이 길며 작업 능률이 높으며, 작은 용접점이라도 높은 신뢰도를 얻을 수 있다는 특징이 있다. 하지만 한 번에 한 점씩만 용접할 수 있어서 속도가 느리다는 것은 틀린 설명이다. 돌기 용접은 한 번에 여러 개의 점을 용접할 수 있으며, 자동화된 용접 시스템을 사용하면 높은 생산성을 얻을 수 있다.

59. 전기저항용접과 가장 관계가 깊은 법칙은?

  1. 줄(Joule)의 법칙
  2. 플레밍의 법칙
  3. 암페어의 법칙
  4. 뉴턴(Newton)의 법칙
(정답률: 68%)
  • 30 CBT 기출문제AI

    2023-04-17 08:28

    전기저항용접에서는 전기 에너지가 열 에너지로 변환되어 용접재를 녹이고 결합시키는 과정이 일어납니다. 이때 전기 에너지와 열 에너지의 관계를 나타내는 법칙이 "줄(Joule)의 법칙"입니다. 이 법칙은 전기 저항체를 통과하는 전류의 크기와 전압의 크기에 비례하여 발생하는 열 에너지의 양을 나타내는데, 이는 전기저항용접에서 발생하는 열 에너지의 양을 예측하고 제어하는 데 매우 중요합니다. 따라서 전기저항용접과 가장 관계가 깊은 법칙은 "줄(Joule)의 법칙"입니다.
