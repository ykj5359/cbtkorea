14. Al-Cu계 합금의 석출 과정을 올바르게 나타낸 것은?

  1. G.P(I) → G.P(II) → 과포화 고용체 → θ′ → θ
  2. G.P(II) → G.P(I) → 과포화 고용체 → θ → θ′
  3. 과포화 고용체 → G.P(I) → G.P(II) → θ′ → θ
  4. 과포화 고용체 → G.P(II) → G.P(I) → θ → θ′
(정답률: 54%)
  • 30 CBT 기출문제AI

    2023-04-15 20:14

    정답은 "과포화 고용체 → G.P(I) → G.P(II) → θ′ → θ"이다.

    이유는 다음과 같다.

    1. 과포화 고용체: 초기 상태로, 용체 내부에는 과포화된 Cu 원자가 존재한다.

    2. G.P(I): Cu 원자가 Al 행렬 내부에서 군집을 이루어 구조를 형성한다. 이를 General Precipitate(I) 또는 GP(I)라고 한다.

    3. G.P(II): GP(I)가 더욱 성장하여 큰 군집을 이루게 되는데, 이를 General Precipitate(II) 또는 GP(II)라고 한다.

    4. θ′: GP(II)가 성장하면서 Al 행렬과 Cu 원자 사이의 결합이 강해지고, 이로 인해 새로운 상이 형성된다. 이를 θ′(theta prime) 상이라고 한다.

    5. θ: θ′ 상이 더욱 성장하여 큰 군집을 이루게 되면, 이를 θ(theta) 상이라고 한다. 이는 Al2Cu의 구조를 가지며, 최종적으로 형성되는 상이다.

80. 어떤 γ선에 대한 선형흡수계수가 8.6625 X 10-1(mm-1)인 물질로 선원을 차폐하여 처음의 선량율을 1/16로 줄이자면 이 차폐체의 최소 두께는?(오류 신고가 접수된 문제입니다. 반드시 정답과 해설을 확인하시기 바랍니다.)

  1. 8.0mm
  2. 11.5mm
  3. 23.0mm
  4. 32.0mm
(정답률: 34%)
  • 30 CBT 기출문제AI

    2023-04-15 20:13

    선형흡수계수는 물질이 얼마나 γ선을 흡수하는지를 나타내는 값입니다. 이 문제에서는 선형흡수계수가 8.6625 X 10-1(mm-1)인 물질로 선원을 차폐하여 처음의 선량율을 1/16로 줄인다고 했습니다. 이때 차폐체의 최소 두께를 구해야 합니다.

    선형흡수계수와 두께는 다음과 같은 관계식을 가집니다.

    I = I0 e-μx

    여기서 I는 차폐체 뒤에서 측정된 선량율, I0은 차폐체 앞에서 측정된 선량율, μ는 선형흡수계수, x는 차폐체의 두께입니다.

    문제에서는 처음의 선량율을 1/16로 줄인다고 했으므로 I/I0 = 1/16입니다. 이 값을 위의 식에 대입하면 다음과 같습니다.

    1/16 = e-μx

    양변에 자연로그를 취하면,

    ln(1/16) = -μx

    x = -ln(1/16)/μ

    여기서 μ는 8.6625 X 10-1(mm-1)이므로,

    x = -ln(1/16)/(8.6625 X 10-1) = 32.0mm

    따라서 차폐체의 최소 두께는 32.0mm입니다.
