15. 지리학적 광달거리를 구하는 계산식은? (단, D : 광달거리(마일), H : 수면 위의 등고(m), h : 수면 위의 관측자 눈의 높이(m) )

  1. D = 2.803(H⒟×h)
  2. D = 2.308(H⒟×h)
  3. D = 2.038(H⒟×h)
  4. D = 2.083(H⒟×h)
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-18 07:42

    지리학적 광달거리는 수평선과 지표면 사이의 거리이므로, 수평선과 지표면 사이의 거리를 나타내는 피타고라스의 정리를 이용하여 계산할 수 있다. 이때, 수평선과 지표면 사이의 거리는 수면 위의 등고(H)와 수면 위의 관측자 눈의 높이(h)를 이용하여 다음과 같이 표현할 수 있다.

    D = √(H⒟² + h²)

    하지만, 이 식에서 사용하는 단위는 미터(m)이므로, 마일(mile)로 변환해주어야 한다. 1마일은 약 1609.344m이므로, 위 식을 다음과 같이 변환할 수 있다.

    D = √(H⒟² + h²) / 1609.344

    D = √(H⒟² / 2.589988² + h² / 2.589988²) (단위 변환)

    D = √(0.621371²(H⒟²) + 0.621371²(h²)) (단위 제곱 분배)

    D = 0.621371√(H⒟² + h²) (단위 정리)

    D = 0.621371(H⒟² + h²)^(1/2)

    D = 2.083(H⒟×h)

    따라서, 정답은 "D = 2.083(H⒟×h)"이다.
