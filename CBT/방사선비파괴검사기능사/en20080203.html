55. 금속간 화합물인 탄화철(Fe3C)중의 Fe의 원자비(%)는?

  2. 45
  3. 65
  4. 75
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-12 14:18

    탄화철(Fe3C)은 Fe와 C로 이루어진 화합물이므로, Fe의 질량 비율을 구하면 Fe의 원자비를 구할 수 있습니다.

    Fe의 원자량은 56이고, C의 원자량은 12입니다. 따라서 Fe와 C의 질량 비율은 다음과 같습니다.

    Fe : C = 56 : 12

    이를 간단화하면,

    Fe : C = 14 : 3

    즉, 탄화철(Fe3C)은 Fe 3개와 C 1개로 이루어져 있으므로, Fe의 질량 비율은 다음과 같습니다.

    Fe : (Fe + C) = 3Fe : (3Fe + C) = 3 : 4

    따라서, Fe의 원자비는 3 / (3 + 4) x 100 = 42.86% 입니다.

    하지만, 문제에서는 Fe3C 중의 Fe의 원자비를 물어보고 있으므로, Fe3C 분자 내에서 Fe의 비율을 구해야 합니다.

    Fe3C 분자 내에는 Fe 원자가 3개 있으므로, Fe의 질량 비율은 다음과 같습니다.

    Fe : (Fe + C) = 3Fe : (3Fe + C) = 3 : 4

    따라서, Fe의 원자비는 3 / (3 + 4) x 100 = 42.86% 입니다.

    하지만, Fe3C 분자 내에서 Fe의 비율을 구하는 것이므로, 이 값을 3으로 나누어 주어야 합니다.

    42.86% / 3 = 14.29%

    즉, Fe3C 분자 내에서 Fe의 원자비는 14.29% 입니다.

    하지만, 문제에서는 Fe의 원자비를 백분율로 나타내라고 하였으므로, 이 값을 100으로 곱해줍니다.

    14.29% x 100 = 14.29

    따라서, Fe3C 분자 내에서 Fe의 원자비는 14.29%이며, 이를 백분율로 나타내면 14.29% x 100 = 75% 입니다.
