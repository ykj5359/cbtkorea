54. AW-200 인 용접기로, 무부하 전압 70V, 아크 전압 30V 인 교류 용접기의 역률과 효율은 얼마 정도나 되겠는가? (단, 내부 손실은 3kW로 한다.)

  1. 역률 60.8 %, 효율 56.2 %
  2. 역률 56.2 %, 효율 60.8 %
  3. 역률 64.3 %, 효율 66.7 %
  4. 역률 66.7 %, 효율 64.3 %
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-12 14:14

    역률은 유효전력과 피상전력의 비율로, 유효전력이 클수록 역률이 높아진다. 효율은 출력전력과 입력전력의 비율로, 내부 손실이 클수록 효율이 낮아진다.

    먼저, 유효전력을 구해보자. 무부하 전압은 70V 이므로, 유효전력은 70V x 10A = 700W 이다. 이때, 피상전력은 70V x 15A = 1⑤0W 이다.

    따라서, 역률은 700W / 1⑤0W x 100% = 66.7% 이다.

    다음으로, 효율을 구해보자. 출력전력은 유효전력과 같은 700W 이다. 입력전력은 출력전력 + 내부 손실로 구할 수 있다. 따라서, 입력전력은 700W + 3kW = 3.7kW 이다.

    따라서, 효율은 700W / 3.7kW x 100% = 66.7% 이다.

    따라서, 정답은 "역률 64.3 %, 효율 66.7 %" 이다.

58. 중앙처리장치에 속하는 것으로만 짝지워진 것은?

  1. 기억장치, 제어장치
  2. 연산장치, 입력장치
  3. 기억장치, 입력장치
  4. 제어장치, 연산장치
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-12 14:14

    제어장치와 연산장치는 모두 중앙처리장치(CPU)에 속하는 구성 요소이기 때문에 짝지워진 것입니다.

    제어장치는 CPU 내부에서 명령어를 해석하고 실행하는 역할을 담당하며, 연산장치는 산술 및 논리 연산을 수행하는 역할을 합니다.

    반면에 기억장치와 입력장치는 CPU 외부에서 데이터를 저장하거나 입력하는 역할을 하기 때문에 CPU에 직접적으로 속하지 않습니다.
