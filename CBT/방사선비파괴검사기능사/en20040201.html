7. 반가층이 1.2㎝인 납판으로 γ선을 차폐한 결과 강도가 1/8 로 감소되었을 때 이 납판의 두께는?

  1. 1.2㎝
  2. 2.4㎝
  3. 3.6㎝
  4. 4.8㎝
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-12 14:15

    강도가 1/8로 감소되었다는 것은 원래 강도의 1/8만큼만 남았다는 것을 의미합니다. 따라서, 반가층이 없을 때의 강도를 8로 나눈 값이 현재의 강도가 됩니다. 이를 수식으로 나타내면 다음과 같습니다.

    현재 강도 = 원래 강도 / 8

    반가층이 1.2㎝인 납판으로 γ선을 차폐할 때, 강도는 반가층이 없을 때의 강도의 1/8만큼만 남게 됩니다. 따라서, 납판의 두께를 x라고 하면 다음과 같은 식이 성립합니다.

    현재 강도 = 원래 강도 / 8 = 원래 강도 × (1/2)³ = 원래 강도 × 1/8

    즉, 원래 강도를 8로 나눈 값은 (1/2)³과 같습니다. 이를 이용하여 반가층이 있는 납판의 두께를 구할 수 있습니다.

    반가층이 없을 때의 강도를 I0, 반가층이 있는 납판의 두께를 x, 납의 밀도를 ρ, 반가층의 선량률을 μ라고 하면 다음과 같은 식이 성립합니다.

    I0 × e^(-μρx) = I0 / 8

    두 식을 나누면 다음과 같은 식이 성립합니다.

    e^(-μρx) = 1/8

    양변에 자연로그를 취하면 다음과 같은 식이 성립합니다.

    -μρx = ln(1/8) = -ln8

    따라서, x는 다음과 같이 구할 수 있습니다.

    x = ln8 / (μρ) ≈ 3.6㎝

    따라서, 정답은 3.6㎝입니다.

16. 20Ci의 Ir-192 선원을 가지고 SFD 60㎝, 노출시간 5분으로 필름농도 2.5의 좋은 사진을 얻었다. SFD 90㎝로 같은 결과를 얻기 위해 적용해야 할 시간은?

  1. 5분
  2. 7.5분
  3. 11.25분
  4. 12.5분
(정답률: 알수없음)

58. 내용적 50ℓ 산소용기의 고압력계가 150기압일 때 프랑스식 250번 팁으로 사용압력 1기압에서 혼합비 1:1을 사용하면 몇시간 작업할 수 있는가?

  1. 20 시간
  2. 30 시간
  3. 40 시간
  4. 50 시간
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-12 14:15

    산소용기의 용량이 50ℓ이므로, 산소의 양은 50ℓ이다. 고압력계가 150기압이므로, 산소의 압력은 150기압이다. 프랑스식 250번 팁으로 사용압력을 1기압으로 낮추면, 산소의 압력은 1기압이 되고, 이때의 산소의 양은 50ℓ이다. 따라서, 혼합비 1:1로 사용하면, 작업에 필요한 산소의 양은 100ℓ이 된다. 따라서, 50ℓ의 산소를 사용하여 100ℓ의 혼합기체를 만들 수 있으므로, 작업시간은 50/100 = 0.5시간이 된다. 이를 분으로 환산하면 30분이므로, 작업시간은 0.5시간 또는 30분이 된다. 따라서, 정답은 "30 시간"이다.

60. 다음 중 직류 정극성에 속하는 모재와 용접봉의 극성은?

  2. 모재(-), 용접봉(+)
  3. 모재(+), 용접봉(+)
  4. 모재(-), 용접봉(-)
(정답률: 알수없음)

    2023-04-12 14:15
