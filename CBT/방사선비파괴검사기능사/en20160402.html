7. 초음파가 두 매질의 경계면에 입사할 경우 굴절각은? (단, 12°, 입사파의 속도 : 1500m/s, 굴절파의 속도 : 5100m/s이다.)

  1. 60°
  2. 45°
  3. 20°
  4. 3.5°
(정답률: 63%)
  • 30 CBT 기출문제AI

    2023-04-12 14:10

    초음파가 두 매질의 경계면에 입사할 때, 굴절법칙에 따라 다음과 같이 굴절됩니다.

    sin(입사각) / sin(굴절각) = 입사파의 속도 / 굴절파의 속도

    여기서, 입사각은 12°이고 입사파의 속도는 1500m/s, 굴절파의 속도는 5100m/s이므로,

    sin(12°) / sin(굴절각) = 1500 / 5100

    sin(굴절각) = sin(12°) x (5100 / 1500) = 0.408

    굴절각은 sin의 역함수인 arcsin을 이용하여 구할 수 있습니다.

    굴절각 = arcsin(0.408) = 24.5°

    따라서, 초음파가 두 매질의 경계면에 입사할 때 굴절각은 24.5°가 됩니다.

    하지만, 문제에서 묻는 것은 두 매질의 경계면에 대한 굴절각이 아니라, 초음파의 입사각과 굴절각 사이의 각도인 "굴절각도"입니다. 따라서, 이 값을 구하기 위해서는 24.5°에 대한 보충각을 구해야 합니다.

    굴절각도 = 180° - 입사각 - 보충각

    보충각 = 90° - 굴절각 = 90° - 24.5° = 65.5°

    굴절각도 = 180° - 12° - 65.5° = 102.5°

    따라서, 초음파가 두 매질의 경계면에 입사할 때 굴절각도는 102.5°가 됩니다.

    하지만, 보기에서는 굴절각이 아니라 굴절각도를 묻고 있으므로, 이 값을 다시 180°에서 빼줘야 합니다.

    굴절각도 = 180° - 102.5° = 77.5°

    이 값은 보기에 없으므로, 가장 가까운 값인 45°를 선택해야 합니다.

60. 다음 그림과 같이 맞대기 용접에서 강판의 두께 20min, 인장하중 50000N, 용접부의 허용인장응력을 50N/mm2로 할 때 용접길이는 몇 mm인가?

  1. 50
  2. 100
  3. 500
  4. 1000
(정답률: 45%)
  • 30 CBT 기출문제AI

    2023-04-12 14:09

    용접부의 허용인장응력은 50N/mm2이므로, 인장하중 50000N을 버티기 위해 필요한 단면적은 1000mm2입니다. 따라서, 강판의 두께 20mm에 해당하는 단면적은 400mm2이므로, 용접부의 길이는 1000mm2 / 400mm2 = 2.5배가 되어야 합니다. 따라서, 용접길이는 20mm x 2.5 = 50mm가 됩니다. 따라서 정답은 "50"입니다.
