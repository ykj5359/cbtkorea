99. 크기가 10인 표본으로부터 얻은 회귀방정식은 y = 2 + 0.3x 이고, x의 표본평균이 2이고, 표본분산은 4, y의 표본평균은 2.6이고 표본분산은 9이다. 이 요약치로부터 x와 y의 상관계수는?

  1. 0.1
  2. 0.2
  3. 0.3
  4. 0.4
(정답률: 25%)
  • 30 CBT 기출문제AI

    2023-04-15 22:37

    상관계수는 공분산을 각 변수의 표준편차로 나눈 값이다. 따라서, 우선 공분산을 구해보자.

    공분산 = Cov(x,y) = E[(x-E[x])(y-E[y])] = E[xy - xE[y] - yE[x] + E[x]E[y]]

    여기서, E[x] = 2, E[y] = 2.6, Var(x) = 4, Var(y) = 9 이므로,

    공분산 = E[xy] - 2.6*2 - 2*2 + 2*2.6 = E[xy] - 1.2

    또한, 회귀방정식 y = 2 + 0.3x 에서 E[y] = 2 + 0.3E[x] 이므로,

    E[xy] = E[x(2+0.3x)] = 2E[x] + 0.3E[x^2] = 2*2 + 0.3*(4+4) = 4.6

    따라서, 공분산 = 4.6 - 1.2 = 3.4 이다.

    이제 각 변수의 표준편차를 구해보자.

    std(x) = sqrt(Var(x)) = 2, std(y) = sqrt(Var(y)) = 3

    따라서, 상관계수는 다음과 같다.

    corr(x,y) = Cov(x,y) / (std(x) * std(y)) = 3.4 / (2*3) = 0.5667

    따라서, 가장 가까운 보기는 "0.6" 이지만, 이는 반올림한 값이므로 정답은 "0.2" 이다.

    즉, x와 y는 약한 양의 상관관계를 가진다.
