  1. 4321
  2. 5221
  3. 4201
  4. 2401
(정답률: 45%)
  • 30 CBT 기출문제AI

    2023-04-15 22:21

    오차한계를 2%로 설정하면, 실제 흡연율과 추정된 흡연율의 차이가 2% 이내가 되어야 한다는 것이다. 이때, 신뢰수준이 95%이므로, 표준정규분포에서의 Z값이 1.96인 경우의 확률이 0.025가 된다. 따라서, 추정된 흡연율에서 1.96을 곱한 값이 2%의 범위 안에 들어가도록 하는 표본의 크기를 구하면 된다.

    즉, Z값이 1.96일 때, 오차한계를 0.02로 놓고 역산하면 된다. 이때, 표본의 크기는 다음과 같이 계산된다.

    n = (Z/오차한계)^2
    n = (1.96/0.02)^2
    n = 9604

    n = N / (1 + N(e^2/Z^2))
