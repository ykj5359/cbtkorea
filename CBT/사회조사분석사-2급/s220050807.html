    X, Y가 서로 독립인지 확인하기 위해선 결합분포함수와 주변분포함수를 비교해야 한다.

    X의 주변분포함수는 f_X(x) = ∑_y f(x, y) = f(x, 1) + f(x, 2) 이고, Y의 주변분포함수는 f_Y(y) = ∑_x f(x, y) = f(1, y) + f(2, y) 이다.

    따라서,

    f_X(1) = f(1, 1) + f(1, 2) = 0.2 + 0.3 = 0.5

    f_X(2) = f(2, 2) = 0.5

    f_Y(1) = f(1, 1) = 0.2

    f_Y(2) = f(1, 2) + f(2, 2) = 0.3 + 0.5 = 0.8

    이다.

    만약 X, Y가 서로 독립이라면, f_X(x) * f_Y(y) = f(x, y) 가 성립해야 한다.

    하지만,

    f_X(1) * f_Y(1) = 0.5 * 0.2 = 0.1

    f_X(1) * f_Y(2) = 0.5 * 0.8 = 0.4

    f_X(2) * f_Y(1) = 0.5 * 0.2 = 0.1

    f_X(2) * f_Y(2) = 0.5 * 0.8 = 0.4

    이므로, X, Y는 서로 독립이 아니다.

    U, V가 서로 독립인지 확인하기 위해서도 마찬가지로 결합분포함수와 주변분포함수를 비교해야 한다.

    g_U(2) = g(1, 3) + g(2, 2) = 0.1 + 0.5 = 0.6

    g_V(2) = g(1, 2) + g(2, 2) = 0.3 + 0.5 = 0.8

    이다.

    이므로, U, V는 서로 독립이 아니다.
