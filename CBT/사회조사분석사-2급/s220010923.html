    n = (Z^2 * p * (1-p)) / E^2

    n: 표본의 크기

    1,000 = 1.96 * (표본표준편차 / √n)

    여기서 표본표준편차는 모르기 때문에 대략적으로 모표준편차를 사용할 수 있다. 따라서, 표본크기는 다음과 같이 구할 수 있다.

    n = (1.96 / 1,000)² * 모표준편차²

    n = (1.96 / 1,000)² * 10,000² = 384.16
