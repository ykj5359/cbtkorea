    이 문제는 큰 수의 법칙(Law of Large Numbers)을 이용하여 풀 수 있다. 큰 수의 법칙은 샘플의 크기가 커질수록 표본평균이 모평균에 수렴한다는 것을 말한다. 따라서, 이 문제에서는 샘플의 크기가 충분히 크기 때문에 표본비율인 0.04이 모비율인 p에 대한 좋은 추정치가 된다.

    $hat{p} pm Z_{alpha/2} sqrt{frac{hat{p}(1-hat{p})}{n}}$

    $0.04 pm 1.96 sqrt{frac{0.04(1-0.04)}{1000}}$

    $= 0.04 pm 0.0121$

    $= (0.0279, 0.⑤21)$

98. 어느 대학교 학생들의 흡연율을 조사하고자 한다. 실제 흡연율과 추정치의 차이가 5% 이내라고 90% 정도의 확신을 갖기 위해서는 얼마만큼 크기의 표본이 필요한가?(단, Z0.1=1.282, Z0.⑤=1.645, Z0.025=1.960 )

  2. 192
  3. 271
  4. 385
(정답률: 42%)

    2023-04-15 22:38

    표본의 크기를 n이라고 하면, 실제 흡연율 p와 추정치 p̂의 차이는 다음과 같이 나타낼 수 있다.

    |p - p̂| ≤ 0.⑤

    이 식을 변형하면 다음과 같다.

    -0.⑤ ≤ p - p̂ ≤ 0.⑤

    p̂ = p ± 0.⑤

    여기서 p̂는 표본에서 구한 흡연율의 평균이다. 이때, 표본의 크기 n이 얼마만큼이어야 하는지 구하기 위해서는 다음과 같은 식을 사용한다.

    Zα/2 * √(p̂(1-p̂)/n) ≤ 0.⑤

    여기서 Zα/2는 표준정규분포에서 α/2에 해당하는 값이다. α는 1-0.9=0.1이므로, Zα/2는 Z0.⑤=1.645이다. 따라서 위 식은 다음과 같이 나타낼 수 있다.

    1.645 * √(p̂(1-p̂)/n) ≤ 0.⑤

    √(p̂(1-p̂)/n) ≤ 0.⑤ / 1.645

    p̂(1-p̂)/n ≤ (0.⑤ / 1.645)²

    n ≥ p̂(1-p̂) / (0.⑤ / 1.645)²

    이제 표본의 크기를 구하기 위해서는 p̂를 알아야 한다. 이를 위해서는 미리 예비조사를 통해 대략적인 흡연율을 추정해야 한다. 예를 들어, 예비조사에서 흡연율이 30%로 나왔다면, p̂=0.3이다. 따라서 n은 다음과 같이 계산할 수 있다.

    n ≥ 0.3(1-0.3) / (0.⑤ / 1.645)²

    n ≥ 271

    따라서, 이 문제에서는 표본의 크기가 271 이상이어야 실제 흡연율과 추정치의 차이가 5% 이내라는 조건을 90%의 확신으로 만족시킬 수 있다.
