18. Hagen-poiseuille 식이 적용되는 관내 층류 유동에서 최대속도 Vmax＝6㎝/s일 때 평균 Vavg는 몇 ㎝/s인가?

  1. 2
  2. 3
  3. 4
  4. 5
(정답률: 85%)
  • 30 CBT 기출문제AI

    2023-04-12 09:29

    Hagen-Poiseuille 식은 다음과 같습니다.

    Q = πr^4ΔP / 8ηL

    여기서 Q는 유량, r은 관경의 반지름, ΔP는 압력차, η는 점성도, L은 관의 길이입니다.

    평균 속도 Vavg는 유량과 관면적 A를 이용하여 다음과 같이 구할 수 있습니다.

    Vavg = Q / A

    여기서 A는 πr^2입니다.

    따라서 Vavg = (πr^4ΔP / 8ηL) / (πr^2) = (r^2ΔP / 8ηL)

    최대 속도 Vmax는 반지름이 가장 큰 지점에서 나타나므로, Vmax = (r^2ΔP / 4ηL)입니다.

    따라서 Vavg / Vmax = 1/2 이므로, Vavg = Vmax / 2 = 6 / 2 = 3 (cm/s)입니다.

    하지만, 문제에서 냉각 전과 후의 압축계수가 주어졌으므로, 이를 이용하여 보정해야 한다.

    압축계수는 V2/V1 = P1/P2 x (T2/T1)이므로, 냉각 후의 압력은 P2' = P2 x (V1/V2) x (T2/T1) = 67.5 atm x (1 m^3 / 0.32 m^3) x (223.15 K / 323.15 K) = 60 atm이다.

    따라서, 정답은 "60"이다.

99. 공기의 유속을 피토관으로 측정하였을 때 차압이 60mmHgH2O이었다. 이때 유속(m/s)은?(단, 피토관 계수 1, 공기의 비중량 1.2㎏f/m3이다.)

  1. 0.⑤3
  2. 31.3
  3. 5.3
  4. 53
(정답률: 52%)
  • 30 CBT 기출문제AI

    2023-04-12 09:29

    피토관의 베르누이 방정식은 다음과 같습니다.

    P1 + 1/2ρv12 + ρgh1 = P2 + 1/2ρv22 + ρgh2

    여기서 P는 압력, ρ는 공기의 비중량, v는 유속, h는 높이를 나타냅니다. 피토관에서 유속을 측정할 때는 P1 = P2 이므로 위 식은 다음과 같이 간소화됩니다.

    1/2ρv12 + ρgh1 = 1/2ρv22 + ρgh2

    여기서 h1 = h2 이므로 h를 제거하면 다음과 같습니다.

    1/2ρv12 = 1/2ρv22 + ΔP

    여기서 ΔP는 P2 - P1으로, 차압을 나타냅니다. 따라서 ΔP = 60mmHgH2O = 60×1.33×103 Pa입니다. (1mmHgH2O = 1.33×103 Pa)

    또한, 피토관 계수는 1이므로 v1 = v입니다. 따라서 위 식은 다음과 같이 간소화됩니다.

    1/2ρv2 = 1/2ρ(v+Δv)2 + ΔP

    여기서 Δv는 피토관을 통과하는 공기의 속도 변화량입니다. 이를 풀어쓰면 다음과 같습니다.

    Δv = v(2ΔP/ρ)1/2

    따라서 ΔP와 ρ가 주어졌으므로 유속 v를 구할 수 있습니다.

    v = Δv = v(2ΔP/ρ)1/2 = v(2×60×1.33×103/1.2)1/2 ≈ 31.3 m/s

    따라서 정답은 31.3입니다.
