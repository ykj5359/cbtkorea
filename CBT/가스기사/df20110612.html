1. 비중 0.8, 점도 5cP인 유체를 평균속도 10㎝/s로 내경 5㎝인 관을 사용하여 2㎞ 수송할 때 수반되는 손실수두는 약 몇 m인가?

  1. 0.163
  2. 0.816
  3. 1.63
  4. 8.16
(정답률: 26%)
  • 30 CBT 기출문제AI

    2023-04-12 09:40

    유체의 레이놀즈 수를 계산하여 손실수두를 구해야 한다.

    Reynolds number (Re) = (유체 밀도 × 평균속도 × 내경) / 점도

    = (0.8 × 10^-3 kg/cm^3 × 10 cm/s × 5 cm) / (5 cP × 10^-3 Pa·s)

    = 80

    Reynolds 수가 4000 이상이면 유동은 터빈트 유동으로 전환되어 손실수두가 증가한다. 따라서 이 문제에서는 터빈트 유동이 발생한다.

    터빈트 유동에서의 손실수두 계산식은 다음과 같다.

    손실수두 = (32 × 점도 × 길이 × 평균속도) / (내경^2 × 중력가속도 × 유체 밀도)

    = (32 × 5 cP × 2 km × 10 cm/s) / (5 cm^2 × 980 cm/s^2 × 0.8 × 10^-3 kg/cm^3)

    = 1.63 m

    따라서 정답은 1.63 이다.

  2. 2 : 3
  3. 3 : 2

8. 진공압력이 0.10㎏f/cm2이고, 온도가 20℃인 기체가 계기압력 7㎏f/cm2로 등온 압축되었다. 이때 압축 전 체적(V1)에 대한 압축 후의 체적(V2)비는 얼마인가? (단, 대기압은 720mmHg이다.)

  1. 0.11
  2. 0.14
  3. 0.98
  4. 1.41
(정답률: 30%)
  • 30 CBT 기출문제AI

    2023-04-12 09:40

    기체의 상태방정식인 PV=nRT를 이용하여 계산할 수 있다.

    압축 전 상태에서의 기체의 체적 V1은 다음과 같다.

    P1V1 = nRT1

    여기서, P1 = 720mmHg = 0.95kgf/cm^2, T1 = 20℃ = 293K 이므로,

    V1 = nRT1/P1 = (1mol x 0.08206 L·atm/mol·K x 293K) / (0.95kgf/cm^2 x 980.7cmHg/kgf) = 24.45L

    압축 후 상태에서의 기체의 체적 V2는 다음과 같다.

    P2V2 = nRT2

    여기서, P2 = 7kgf/cm^2, T2 = 20℃ = 293K 이므로,

    V2 = nRT2/P2 = (1mol x 0.08206 L·atm/mol·K x 293K) / (7kgf/cm^2 x 980.7cmHg/kgf) = 0.038L

    따라서, V1/V2 = 24.45L/0.038L = 644.74 ≈ 0.11 이다.

    즉, 압축 후의 체적은 압축 전의 체적의 약 0.11배이다.

16. 밀도가 892㎏/m3인 원유가 단면적이 2.165×10-3m2인 관을 통하여 1.388×10-3m3/s로 들어가서 단면적이 각각 1.314×10-3m2로 동일한 2개의 관으로 분할되어 나갈 때 분할되는 관내에서의 유속은 약 몇 m/s인가? (단, 분할되는 2개 관에서의 평균유속은 같다.)

  1. 1.036
  2. 0.841
  3. 0.619
  4. 0.528
(정답률: 49%)
  • 30 CBT 기출문제AI

    2023-04-12 09:40

    유체의 연속 방정식에 의해 유속은 유체의 질량 유지를 위해 단면적이 줄어들면 유속은 증가하게 된다. 따라서 원유가 분할되어 나가면서 단면적이 줄어들기 때문에 유속은 증가하게 된다.

    원유의 유량은 Q = Av로 표현할 수 있다. 여기서 A는 단면적, v는 유속이다. 따라서 분할되는 2개의 관에서의 유속은 원유의 유량이 분할되는 관의 단면적으로 나눈 값이다.

    분할 전 유량 = 분할 후 유량

    A1v1 + A2v2 = A3v3

    여기서 A1 = A2 = 2.165×10-3m2, A3 = 2 × 1.314×10-3m2 = 2.628×10-3m2, Q = 1.388×10-3m3/s로 대입하면,

    (2.165×10-3m2)v1 + (2.165×10-3m2)v2 = (2.628×10-3m2)v3

    v1 + v2 = (2.628/2.165)v3

    v1 = v2 = (2.628/2.165)v3/2

    v1 = v2 = 0.607v3

    따라서 분할되는 2개의 관에서의 평균유속은 0.607v3이다.

    원유의 밀도는 892kg/m3이므로, 유량과 유속은 다음과 같은 관계가 있다.

    Q = ρAv

    v = Q/(ρA)
