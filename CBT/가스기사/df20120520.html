3. 2차원 비압축성 유동의 연속방정식을 만족하지 않는 속도 벡터(V)는? (단, i와 j는 각각 직각좌표계에서 x, y 방향의 단위 벡터를 나타낸다.)

  1. V＝(16y-14x)i＋(14y-9x)j
  2. V＝6xi＋6yj
  3. V＝(4x2＋y2)i＋(-8xy)j
  4. V＝(6xy2＋y2 )i＋(4xy＋5x)j
(정답률: 53%)
  • 30 CBT 기출문제AI

    2023-04-12 09:37

    연속방정식은 유체의 질량이 변하지 않는다는 물리법칙을 수학적으로 표현한 것입니다. 따라서, 유체가 어떤 지점에서 들어오거나 나가는 양이 일치해야 합니다. 이를 수식으로 나타내면 다음과 같습니다.

    ∂ρ/∂t + ∇·(ρV) = 0

    여기서 ρ는 유체의 밀도, V는 속도 벡터입니다. ∂/∂t는 시간에 대한 편미분, ∇는 Nabla 연산자로, (x, y) 좌표계에서는 다음과 같이 나타납니다.

    ∇ = i(∂/∂x) + j(∂/∂y)

    따라서, 연속방정식은 다음과 같이 나타납니다.

    ∂ρ/∂t + (∂(ρVx)/∂x + ∂(ρVy)/∂y) = 0

    여기서 Vx와 Vy는 각각 x와 y 방향의 속도입니다. 이를 간단하게 표현하면 다음과 같습니다.

    ∂Vx/∂x + ∂Vy/∂y = 0

    이 식을 만족하지 않는 속도 벡터를 찾아야 합니다. 따라서, 주어진 보기 중에서 연속방정식을 만족하지 않는 속도 벡터를 찾아보면,

    V＝(6xy2＋y2 )i＋(4xy＋5x)j

    ∂Vx/∂x = 6y^2, ∂Vy/∂y = 4x + 5

    ∂Vx/∂x + ∂Vy/∂y = 6y^2 + 4x + 5 ≠ 0

    따라서, V＝(6xy2＋y2 )i＋(4xy＋5x)j는 연속방정식을 만족하지 않는 속도 벡터입니다.

  1. pV12 [(A1/A2)2-1]/2
  2. pV22 [(A1/A2)2-1]/2
  3. pV22 [(A2/A1)2-1]/2
  4. pV12 [(A2/A1)2-1]
(정답률: 55%)

    베르누이 방정식은 다음과 같다.

    P + 1/2ρV2 + ρgh = 상수

    여기서 P는 압력, ρ는 밀도, V는 속도, h는 높이를 나타낸다. 이 식은 유체의 운동에너지, 위치에너지, 압력 에너지의 합이 일정하다는 것을 나타낸다.

    이 문제에서는 마찰손실이 없다고 가정하므로, 압력차는 속도차에 의해 발생한다. 따라서, P1 + 1/2ρV12 = P2 + 1/2ρV22 이다.

    이 식을 정리하면, P1 - P2 = 1/2ρ(V22 - V12) 이다.

    여기서, A1V1 = A2V2 이므로, V2 = (A1/A2)V1 이다.

    따라서, P1 - P2 = 1/2ρV12((A1/A2)2 - 1) 이다.

    이를 정리하면, 정답은 "pV12 [(A1/A2)2-1]/2" 이다.
