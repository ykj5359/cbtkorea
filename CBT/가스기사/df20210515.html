  3. 2.⑤
  4. 2.25
(정답률: 56%)

    2023-04-12 09:19

    유체의 연속성 방정식에 의하면 유체의 질량유량은 일정합니다. 따라서 단면적이 변하는 관로에서 유체의 속도와 단면적은 반비례 관계에 있습니다.

    즉, 단면적이 작아지면 유체의 속도는 커지고, 단면적이 커지면 유체의 속도는 작아집니다.

    이 문제에서는 지름이 15cm인 단면에서의 평균속도가 4m/s 이므로, 지름이 20cm인 단면에서의 평균속도는 다음과 같이 구할 수 있습니다.

    단면적의 비율은 (지름이 20cm인 단면의 반지름)^2 / (지름이 15cm인 단면의 반지름)^2 = (20/2)^2 / (15/2)^2 = 16/9 입니다.

    따라서, 속도의 비율은 (지름이 15cm인 단면에서의 평균속도) / (지름이 20cm인 단면에서의 평균속도) = (16/9) : 1 이 됩니다.

    이를 이용하여 지름이 20cm인 단면에서의 평균속도를 구하면 다음과 같습니다.

    (지름이 15cm인 단면에서의 평균속도) / (지름이 20cm인 단면에서의 평균속도) = 16/9

    4 / (지름이 20cm인 단면에서의 평균속도) = 16/9

    (지름이 20cm인 단면에서의 평균속도) = 9/16 x 4 = 2.25

    따라서, 정답은 "2.25" 입니다.

20. 온도 20℃의 이상기체가 수평으로 놓인 관 내부를 흐르고 있다. 유동 중에 놓인 작은 물체의 코에서의 정체온도(stagnation temperature)가 Ts = 40℃ 이면 관에서의 기체의 속도(m/s)는? (단, 기체의 정압비열 cp = 1040 J/(kg·K)이고, 등엔트로피 유동이라고 가정한다.)

  1. 204
  2. 217
  3. 237
  4. 253
(정답률: 28%)
  • 30 CBT 기출문제AI

    2023-04-12 09:19

    등엔트로피 유동에서는 정체온도와 정압비열을 이용하여 Mach 수를 구할 수 있다. Mach 수는 다음과 같이 정의된다.

    Mach number = (2 / (γ - 1)) * ((T_s / T) - 1)

    여기서 γ는 기체의 비열비(heat capacity ratio)로, 대기 기체의 경우 약 1.4이다. T는 유동 중의 기체 온도이다.

    위 식에서 Mach 수를 1로 놓으면 초음속 유동이 된다. 따라서 이 문제에서는 Mach 수가 1보다 작은 서소음속 유동이라고 가정할 수 있다.

    Mach 수가 작을 때는 다음과 같은 관계식이 성립한다.

    Mach number = (V / a)

    여기서 V는 유동 중의 기체 속도이고, a는 기체의 속도음(속도음은 기체의 속도에 따라 변하는데, 대기 기체에서는 약 340 m/s이다).

    따라서 Mach 수를 이용하여 기체 속도를 구할 수 있다.

    Mach number = (2 / (γ - 1)) * ((T_s / T) - 1) = V / a

    여기서 T_s = 40℃ = 313K, T = 20℃ = 293K 이므로,

    Mach number = (2 / 0.4) * ((313 / 293) - 1) = 0.5

    따라서 V / a = 0.5 이므로,

    V = 0.5 * a = 0.5 * 340 = 170 m/s

    따라서 기체의 속도는 170 m/s이다. 이 값을 km/h로 변환하면 612 km/h이므로, 소수점 첫째 자리에서 반올림하여 "612"가 아니라 "610"이 되며, 이 값을 반올림하여 정답은 "610"이 된다.

    오리피스의 유량식은 다음과 같다.

    Q = Cd * A * sqrt(2gh)

    여기서 Q는 유량, Cd는 오리피스의 유량계수, A는 오리피스의 단면적, g는 중력가속도, h는 오리피스의 수위차이다.

    A = (π/4) * d^2

    0.01 = 0.6 * (π/4) * d^2 * sqrt(2 * 9.81 * 10)

    d^2 = 0.01 / (0.6 * (π/4) * sqrt(196.2))

    d^2 ≈ 0.0008

    d ≈ 0.03

    따라서 오리피스의 지름은 약 3.9cm이다.
