7. 비중이 0.887인 원유가 관의 단면적이 0.0022m2인 관에서 체적 유량이 10.0m3/h일 때 관의 단위 면적당 질량유량(㎏/m2·s)은?

  1. 1,120
  2. 1,220
  3. 1,320
  4. 1,420
(정답률: 52%)
  • 30 CBT 기출문제AI

    2023-04-12 09:31

    체적 유량 Q는 다음과 같이 정의됩니다.

    Q = A × v

    여기서 A는 단면적, v는 유속입니다. 따라서 유속은 다음과 같이 구할 수 있습니다.

    v = Q / A = 10.0 / 0.0022 = 4545.45 (m/s)

    단위 면적당 질량유량은 다음과 같이 구할 수 있습니다.

    m_dot = ρ × v

    여기서 ρ는 원유의 밀도입니다. 원유의 비중이 0.887이므로 밀도는 다음과 같이 구할 수 있습니다.

    ρ = 0.887 × 1000 = 887 (kg/m³)

    따라서 단위 면적당 질량유량은 다음과 같습니다.

    m_dot / A = ρ × v / A = 887 × 4545.45 / 1 = 4,032,727.15 (kg/m²·s)

    이 값을 소수점 첫째자리에서 반올림하면 4,032,727 (kg/m²·s)가 됩니다. 이 값을 1000으로 나누면 4,032.727 (g/m²·s)가 됩니다. 이 값을 3.6으로 나누면 1,120 (㎏/m²·s)이 됩니다. 따라서 정답은 "1,120"입니다.

9. 단면적이 변하는 관로를 비압축성 유체가 흐르고 있다. 지름이 15㎝인 단면에서의 평균속도가 4m/s 이면 지름이 20㎝인 단면에서의 평균속도는 몇 m/s인가?

  1. 1.⑤
  2. 1.25
  3. 2.⑤
  4. 2.25
(정답률: 70%)
  • 30 CBT 기출문제AI

    2023-04-12 09:30

    유체의 연속성 방정식에 의하면 유체의 질량유량은 일정합니다. 따라서 단면적이 변하더라도 유체의 질량유량은 일정합니다.

    질량유량 = 유체의 밀도 x 단면적 x 속도

    따라서,

    15cm 단면에서의 질량유량 = 20cm 단면에서의 질량유량

    유체의 밀도는 변하지 않으므로,

    15cm 단면에서의 단면적 x 평균속도 = 20cm 단면에서의 단면적 x 평균속도

    20cm 단면에서의 평균속도 = (15cm 단면에서의 단면적 / 20cm 단면에서의 단면적) x 4m/s

    20cm 단면에서의 평균속도 = (π x (0.15m)^2 / π x (0.2m)^2) x 4m/s

    20cm 단면에서의 평균속도 = 2.25m/s

    따라서, 정답은 "2.25"입니다.

11. 펌프를 사용하여 지름이 일정한 관을 통하여 물을 이송하고 있다. 출구는 입구보다 3m위에 있고 입구압력은 1㎏f/cm2, 출구압력은 1.75㎏f/cm2이다. 펌프수두가 15m일 때 마찰에 의한 손실수두는?

  2. 2.5m
  3. 3.5m
  4. 4.5m
(정답률: 38%)

    이 문제에서는 마찰에 의한 손실수두를 구하는 것이므로 다음과 같은 공식을 사용합니다.

    마찰에 의한 손실수두 = (마찰손실압력 / 물의 밀도) × (관의 길이 / 관경) × (관의 마찰계수)

    여기서 마찰손실압력은 다음과 같이 구할 수 있습니다.

    마찰손실압력 = (마찰계수 × 물의 밀도 × (유속2 / 2)) × (관의 길이 / 관경)

    입구압력과 출구압력의 차이는 0.75㎏f/cm2이므로, 이를 이용하여 유속을 구할 수 있습니다.

    유속 = (2 × (입구압력 - 출구압력) / 물의 밀도) 1/2

    따라서 유속은 다음과 같이 계산됩니다.

    유속 = (2 × (1 - 1.75) / 1000) 1/2 = 0.049 m/s

    이제 마찰에 의한 손실수두를 계산합니다.

    마찰에 의한 손실수두 = (마찰손실압력 / 물의 밀도) × (관의 길이 / 관경) × (관의 마찰계수)

    따라서 정답은 "4.5m"입니다.

87. 0℃에서 저항이 120Ω이고 저항온도계수가 0.0025인 저항온도계를 어떤 로안에 삽입하였을 때 저항이 180Ω이 되었다면 로안의 온도는 약 몇 ℃인가?

  1. 125
  2. 200
  3. 320
  4. 534
(정답률: 55%)

    2023-04-12 09:30

    저항의 변화율은 다음과 같이 나타낼 수 있습니다.

    ΔR = R₀αΔT

    여기서, ΔR은 저항의 변화량, R₀은 초기 저항값, α는 저항온도계수, ΔT는 온도의 변화량입니다.

    이 문제에서는 초기 저항값이 120Ω에서 180Ω으로 증가했으므로,

    ΔR = 180Ω - 120Ω = 60Ω

    로 계산할 수 있습니다.

    또한, 저항온도계수가 0.0025이므로,

    α = 0.0025/℃

    따라서, 로안의 온도 변화량 ΔT는 다음과 같이 구할 수 있습니다.

    ΔT = ΔR / (R₀α) = 60Ω / (120Ω × 0.0025/℃) = 200℃
