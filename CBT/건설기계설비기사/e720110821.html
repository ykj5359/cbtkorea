    단면 A와 B의 평균 반지름은 각각 (20+30)/2=25mm, (30+40)/2=35mm 이므로, TA/TB = √(35/25)² = 7/5의 제곱근 = √(49/25) = 7/5 × √1.96 = 7/5 × 1.4 ≈ 1.96/1.4 ≈ 1.4.

    따라서 정답은 "16/15"이다.

9. 폭 b = 60 mm, 길이 L = 500mm의 균일강도 외팔보의 자유단에 집중하중 P = 5kN이 작용한다. 허용 굽힘응력을 65MPa이라 하면 자유단에서 250mm되는 지점의 두께 h는? (단, 보의 단면은 두께는 변하지만 일정한 폭 b를 갖는 직사각형이다.)

  1. 14mm
  2. 28mm
  3. 44mm
  4. 62mm
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-14 10:16

    이 문제는 굽힘응력과 단면의 관계를 이용하여 두께를 구하는 문제이다.

    먼저, 외팔보의 자유단에서 작용하는 집중하중 P에 의해 발생하는 최대 굽힘모멘트 M은 다음과 같다.

    M = PL/4 = 5 × 500/4 = 1250 Nm

    다음으로, 단면의 중립면에서의 최대 굽힘응력 σmax는 다음과 같다.

    σmax = Mc/I

    I = bh^3/12

    σmax = 6Mhc/bh^3

    σmax ≤ 65

    따라서,

    6Mhc/bh^3 ≤ 65

    h^2 ≥ 6Mbc/65

    h ≥ √(6 × 1250 × 60/65) ≈ 43.8

10. 지름 3cm, 길이 1m인 환봉의 양단에 1000Nㆍm의 비틀림 모멘트가 작용할 때 비틀림 각은?(단, 선형 탄성 환봉의 전단탄성계수 G = 80GPa이다.)

  1. 0.16°
  2. 0.31°
  3. 9°
  4. 18°
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-14 10:16

    비틀림 모멘트 M과 비틀림 각 θ 사이의 관계식은 다음과 같다.

    M = G * J * θ / L

    여기서 J는 폴라르 모멘트이며, 원형 단면의 경우 J = πd^4 / 32이다. L은 환봉의 길이이다.

    따라서, J와 L은 주어졌으므로 비틀림 각 θ를 구하기 위해서는 G값이 필요하다. 문제에서 G값이 80GPa로 주어졌으므로, 다음과 같이 계산할 수 있다.

    θ = ML / GJ

    여기에 M = 1000Nㆍm, L = 1m, d = 3cm = 0.03m, J = πd^4 / 32, G = 80GPa = 80,000MPa를 대입하면,

    θ = (1000Nㆍm) * (1m) / (80,000MPa * (π(0.03m)^4 / 32)) = 0.157 라디안

    이다. 이 값을 도 단위로 변환하면,

    θ = 0.157 * 180 / π = 9.01°

    따라서, 비틀림 각은 약 9°이다.

16. 선형 탄성 재질의 정사각형 단면봉에 1000kN의 압축력이 작용할 때 100MPa의 압축응력이 생기도록 하려면 한 변의 길이를 몇 cm로 해야 하는가?

  3. 15
  4. 20
(정답률: 알수없음)

    2023-04-14 10:15

    압축응력은 압축력을 단면적으로 나눈 값으로 계산된다. 따라서, 압축응력이 100MPa가 되려면 압축력 1000kN을 단면적으로 나눈 값이 100MPa가 되어야 한다.

    압축응력 = 압축력 / 단면적
    100MPa = 1000kN / (x^2)

    x^2 = 1000kN / 100MPa
    x^2 = 10,000cm^2
    x = 100cm = 10m

    먼저, 다리순환법에서는 관의 시작점과 끝점을 잡고, 그 사이에서의 압력차를 구한다. 이 문제에서는 원관의 길이가 60m이므로, 시작점과 끝점을 잡을 때, 각각의 거리는 30m가 된다.
