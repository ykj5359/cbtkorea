6. 단위무게 1.59t/m3, 비중 2.60인 잔골재의 공극률은?

  1. 35.85%
  2. 38.85%
  3. 41.85%
  4. 44.85%
(정답률: 45%)
  • 30 CBT 기출문제AI

    2023-04-12 12:30

    공극률 = (1 - 단위부피중량/단위부피고체중량) x 100

    단위부피고체중량 = 단위무게 x 비중 = 1.59 x 2.60 = 4.134

    단위부피중량 = 1.59

    공극률 = (1 - 1.59/4.134) x 100 = 38.85%

    따라서 정답은 "38.85%"입니다.

7. A골재의 조립률이 1.75, B골재의 조립률이 3.5인 두 골재를 무게비 4:6의 비율로 혼합 할 때 혼합 골재의 조립률을 구하면?

  1. 2.8
  2. 3.8
  3. 4.8
  4. 5.8
(정답률: 35%)
  • 30 CBT 기출문제AI

    2023-04-12 12:30

    A골재와 B골재를 4:6의 비율로 혼합하면, 전체 무게 중 A골재의 무게 비율은 4/10, B골재의 무게 비율은 6/10이 됩니다.

    따라서 혼합 골재의 조립률은 (A골재의 조립률 x A골재의 무게 비율) + (B골재의 조립률 x B골재의 무게 비율)로 계산할 수 있습니다.

    이를 대입하면, (1.75 x 4/10) + (3.5 x 6/10) = 0.7 + 2.1 = 2.8이므로, 혼합 골재의 조립률은 2.8입니다.
