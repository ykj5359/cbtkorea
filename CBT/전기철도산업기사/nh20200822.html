55. 열차 견인력 30000kg, 속도 70km/h로 운전할 때 주 전동기의 출력(kW)은 얼마인가?

  2. 3644
  3. 5722

    먼저, 운동에너지는 다음과 같이 구할 수 있다.

    운동에너지 = (1/2) x 질량 x 속도^2

    여기서 질량은 견인하는 열차의 질량이 아니라, 열차와 함께 움직이는 모든 물체의 질량을 합한 것이다. 이를 효율 계수로 보정하여 계산하면 다음과 같다.

    시간 = 이동거리 / 속도
    = 1000m / (70km/h x 1000m/3600s)
    = 0.514s

    출력 = 운동에너지 / 시간
    = 1,102,500 J / 0.514s
    = 2,142,857 W
    ≈ 5722 kW

72. 지름 60mm, 길이 2m인 봉강에 축방향을 18000kgf의 인장력이 작용하여 6mm가 늘어났다면 이때의 인장응력은 약 몇 kgf/cm2 인가?

  1. 956
  2. 1217
  3. 1427
  4. 637
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-17 18:43

    인장응력은 인장력을 단면적으로 나눈 값으로 계산된다. 따라서 우선 봉강의 단면적을 구해야 한다.

    봉강의 지름이 60mm 이므로 반지름은 30mm 이다. 따라서 단면적은 원넓이 공식을 이용하여 구할 수 있다.

    원넓이 = π x 반지름의 제곱 = 3.14 x 30 x 30 = 2826mm^2

    이제 인장응력을 구할 수 있다.

    인장응력 = 인장력 / 단면적 = 18000kgf / 2826mm^2

    단위를 통일하기 위해 kgf를 N으로 변환하면,

    인장응력 = 18000kgf x 9.8m/s^2 / 2826mm^2 = 617.5 N/mm^2

    마지막으로 단위를 kgf/cm^2 로 변환하면,

    인장응력 = 617.5 N/mm^2 x 10.1972 mm^2/cm^2 / 1 kgf = 629.2 kgf/cm^2

    따라서, 보기에서 정답이 "637" 인 이유는 반올림한 값이기 때문이다.

  2. 인장응력

  • 30 CBT 기출문제AI

    정답은 "휨응력"입니다.

    부재 축방향에 수직인 단면에 생기는 응력은 수직응력, 인장응력, 압축응력이 있습니다.

    - 수직응력: 부재의 무게나 외부 하중에 의해 생기는 응력으로, 부재의 단면에 수직으로 작용합니다.

    반면, 휨응력은 부재가 굽히는 형태로 작용하는 응력입니다. 부재의 단면이 굽혀지면서 생기는 응력으로, 부재의 단면이 작아지는 것을 방지하기 위해 부재를 강화합니다. 따라서, 부재 축방향에 수직인 단면에 생기는 응력으로는 휨응력이 포함되지 않습니다.
