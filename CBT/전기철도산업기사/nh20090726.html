1. 100MHz의 전자파의 파장은?

  1. 0.3[m]
  2. 0.6[m]
  3. 3[m]
  4. 6[m]
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    전자파의 파장은 속도(v)와 주파수(f)의 곱으로 계산됩니다.

    파장 = v / f

    전자파는 빛과 같은 속도로 전파되는데, 이를 전자기파의 속도(c)라고 합니다.

    c = 3 x 10^8 [m/s]

    따라서,

    파장 = c / f

    주파수가 100MHz인 경우,

    파장 = 3 x 10^8 [m/s] / 100 x 10^6 [Hz]

    = 3 [m]

    따라서, 100MHz의 전자파의 파장은 3[m]입니다.

    평행판콘덴서의 정전용량은 다음과 같이 구할 수 있다.

    C = εA/d

    여기서 ε는 유전체의 비유전률, A는 콘덴서의 면적, d는 극판 간격이다.

76. 지지물의 굽힘에 따른 기울기에 대한 다음 설명 중 ( )안에 들어갈 적절한 숫자는?

  1. ㉠ 50 ㉡ 25 ㉢ 25
  2. ㉠ 100 ㉡ 50 ㉢ 50
  3. ㉠ 150 ㉡ 100 ㉢ 50
  4. ㉠ 237 ㉡ 110 ㉢ 127
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-17 18:46

    지지물의 굽힘에 따른 기울기는 다음과 같이 계산할 수 있습니다.

    기울기 = 굽힘 / 지지점 간 거리

    따라서, 위 그림에서 지지점 A와 B 사이의 거리는 2m이고, 지지점 B와 C 사이의 거리는 1m입니다. 또한, 지지물의 굽힘은 A에서는 100mm, B에서는 50mm, C에서는 50mm입니다.

    따라서, A에서의 기울기는 100mm / 2m = 0.⑤, B에서의 기울기는 50mm / 1m = 0.⑤, C에서의 기울기는 50mm / 1m = 0.⑤입니다.
