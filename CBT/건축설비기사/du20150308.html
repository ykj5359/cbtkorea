    2023-04-14 19:51

    압력강도는 Bernoulli의 방정식을 이용하여 구할 수 있다. Bernoulli의 방정식은 유체의 운동에너지와 위치에너지의 합이 일정하다는 것을 나타내는 식으로, 다음과 같다.

    P + 1/2ρv^2 + ρgh = 상수

    여기서 P는 압력, ρ는 유체의 밀도, v는 유체의 속도, g는 중력가속도, h는 유체의 위치를 나타낸다.

    이 문제에서는 배관 내부의 유체가 일정한 속도로 흐르고 있으므로, 유체의 운동에너지와 위치에너지는 일정하다. 따라서 Bernoulli의 방정식을 이용하여 압력강도를 구할 수 있다.

    먼저, 유체의 밀도는 물이므로 1000kg/m^3이다. 중력가속도는 보통 9.8m/s^2으로 가정한다.

    P1 + 1/2ρv1^2 + ρgh1 = P2 + 1/2ρv2^2 + ρgh2

    여기서 P1은 배관의 입구에서의 압력, P2는 배관의 출구에서의 압력, v1은 입구에서의 속도, v2는 출구에서의 속도, h1은 입구에서의 높이, h2는 출구에서의 높이를 나타낸다.

    입구에서의 높이와 출구에서의 높이는 같으므로, h1 = h2이다. 또한, 배관 내부의 지름이 일정하므로, 유체의 밀도와 중력가속도는 입구와 출구에서 동일하다. 따라서, ρgh1 = ρgh2이다.

    P1 + 1/2ρv1^2 = P2 + 1/2ρv2^2

    여기서, 배관 내부의 마찰력을 고려하기 위해 Darcy-Weisbach 방정식을 이용하여 손실압력을 계산해야 한다.

    Darcy-Weisbach 방정식은 다음과 같다.

    ΔP = f (L/D) (ρv^2/2)

    여기서, ΔP는 손실압력, f는 관마찰계수, L은 배관의 길이, D는 배관의 내경을 나타낸다.

    따라서, ΔP = 0.03 (50/0.025) (1000 x 2^2/2) = 24000 Pa = 24 kPa이다.

    따라서, P1 - P2 = 24 kPa이다.

    P1 - P2 = 1/2ρ(v2^2 - v1^2)

    여기서, v1 = 2m/s이고, v2는 구해야 하는 값이다.

    P1 - P2 = 1/2 x 1000 x (v2^2 - 2^2)

    P1 - P2 = 500 (v2^2 - 4)

    P1 - P2 = 500v2^2 - 2000

    P1 - P2 + 2000 = 500v2^2

    v2^2 = (P1 - P2 + 2000)/500

    v2^2 = (120000 - 24000 + 2000)/500

    v2^2 = 236

    v2 = 15.36 m/s

    따라서, 압력강도는 P1 - P2 = 1/2ρ(v2^2 - v1^2) = 120 kPa이다.
