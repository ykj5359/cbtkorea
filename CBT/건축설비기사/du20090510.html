58. 실용적 3000m3, 재실자 350인의 집회실이 있다. 다음과 같은 조건에서 실내온도 t1=19℃로 하기 위한 필요 환기량은?

  4. 21600 m3/h
(정답률: 39%)

    2023-04-14 20:09

    환기량은 다음과 같이 계산할 수 있다.

    환기량 = 실내부피 x 공기교환율 x (실외공기량/실내공기량)

    여기서 실내부피는 3000m3이고, 공기교환율은 1시간에 2회 환기하므로 2이다. 실외공기량은 0.5m/s의 바람속도에서 1시간 동안 지나가는 공기량으로, 표에서 2400 m3/h로 주어졌다.

    따라서, 환기량 = 3000 x 2 x (2400/3000) = 4800 m3/h 이다.

    하지만 이 문제에서는 온도를 19℃로 유지해야 하므로, 추가적인 환기량이 필요하다. 이를 계산하기 위해서는 열전달량을 고려해야 한다.

    열전달량 = 실내부피 x 공기바람속도 x 공기밀도 x 1.24 x (t2 - t1)

    여기서 t2는 실외온도로 주어진 10℃이다. 공기밀도는 1.2 kg/m3으로 가정하고, 공기바람속도는 0.5m/s로 주어졌으므로, 열전달량은 다음과 같다.

    열전달량 = 3000 x 0.5 x 1.2 x 1.24 x (10 - 19) = -11160 W

    음수인 이유는, 실내온도가 실외온도보다 높기 때문에 열이 실외로 방출된다는 것을 의미한다.

    따라서, 추가적인 환기량은 열전달량을 고려하여 다음과 같이 계산할 수 있다.

    추가 환기량 = 열전달량 / (1.2 x 10⑤ x (t2 - t1))

    여기서 1.2는 공기의 비열, 10⑤는 공기의 밀도, t1은 실내온도인 19℃이다. 따라서,

    추가 환기량 = -11160 / (1.2 x 10⑤ x (10 - 19)) = 930.8 m3/h
