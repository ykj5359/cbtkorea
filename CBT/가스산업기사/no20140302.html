7. 다음 반응식을 이용하여 메탄(CH4)의 생성열을 계산하면?

  1. ∆H = -17㎉/㏖
  2. ∆H = -18㎉/㏖
  3. ∆H = -19㎉/㏖
  4. ∆H = -20㎉/㏖
(정답률: 87%)
  • 30 CBT 기출문제AI

    2023-04-13 17:53

    반응식에서 메탄 1몰의 생성열을 구하는 것이므로, 반응식의 계수를 1로 맞추어 계산합니다.

    ∆H = (결합 에너지 합 - 해리 에너지 합) / 몰 수

    결합 에너지 합: C-H 결합 4개 = 4 × 413 = 1652 kJ/mol

    해리 에너지 합: C=O 결합 1개 = 799 kJ/mol, O-H 결합 2개 = 2 × 463 = 926 kJ/mol

    ∆H = (1652 - 799 - 926) / 1 = -73 kJ/mol

    단위를 kJ/mol에서 kJ/㎢으로 변환하면,

    ∆H = -73 kJ/mol × (1 mol / 16.04 g) × (1000 g / 1 kg) × (1 kmol / 1000 mol) = -4550 kJ/㎢

    따라서, 보기에서 ∆H = -18㎉/㏖이 정답인 이유는 단위를 다르게 표기한 것이며, 계산 결과는 동일합니다.

60. 어떤 온도에서 압력 6.0㎫, 부피 125L의 산소와 8.0 ㎫, 부피 200L의 질소가 있다. 두 기체를 부피 500L의 용기에 넣으면 용기 내 혼합기체의 압력은약 몇 ㎫이 되는가?

  2. 3.6
  3. 4.7
  4. 5.6

    2023-04-13 17:52

    기체의 상태방정식인 PV=nRT를 이용하여 문제를 풀 수 있다. 두 기체를 섞으면 전체 몰수는 산소와 질소의 몰수의 합이므로 다음과 같다.

    n = n(산소) + n(질소)

    n(산소) = PV/RT = (6.0 × 125)/(0.0821 × T) = 732/T
    n(질소) = PV/RT = (8.0 × 200)/(0.0821 × T) = 1953/T

    n = 732/T + 1953/T = 2685/T

    44.1/10 = 4.41 ≈ 4.7
