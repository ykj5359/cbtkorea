6. CH4(g) + 2O2(g) 偵 CO2(g) +2H2O(ℓ )의 반응열은 얼마인가?

  1. -144.5 kcal
  2. -180.3 kcal
  3. -212.9 kcal
  4. -248.7 kcal
(정답률: 62%)
  • 30 CBT 기출문제AI

    2023-04-14 08:28

    이 반응은 메탄과 산소가 반응하여 이산화탄소와 물이 생성되는 반응이다. 이 반응에서 발생하는 열은 반응열이다. 반응열은 생성된 생성물의 엔탈피와 원료의 엔탈피의 차이이다.

    따라서, 반응열은 생성물의 엔탈피 - 원료의 엔탈피로 계산할 수 있다.

    여기서, CO2와 H2O는 각각 -94.1 kcal/mol과 -68.3 kcal/mol의 엔탈피를 가지고 있고, CH4와 O2는 각각 -17.9 kcal/mol과 0 kcal/mol의 엔탈피를 가지고 있다.

    따라서, 반응열은 (-94.1 kcal/mol x 1) + (-68.3 kcal/mol x 2) - (-17.9 kcal/mol x 1) - (0 kcal/mol x 2) = -212.9 kcal/mol 이다.

    따라서, 정답은 "-212.9 kcal"이다.

10. 30℃, 1기압에서 수소 0.15g, 질소 0.90g, 암모니아 0.68g으로 된 혼합가스가 있다. 이 혼합가스의 부피는 약몇 L인가?(단, 원자량은 H : 1, N : 14)

  1. 3.66
  2. 2.97
  3. 1.73
  4. 0.011
(정답률: 48%)
  • 30 CBT 기출문제AI

    2023-04-14 08:27

    이 문제는 이상기체법칙을 이용하여 풀 수 있다.

    먼저, 각 기체의 몰 수를 구해보자.

    수소의 몰 수 = 0.15g / 1g/mol = 0.15 mol
    질소의 몰 수 = 0.90g / 14g/mol = 0.0643 mol
    암모니아의 몰 수 = 0.68g / 17g/mol = 0.04 mol

    따라서, 전체 혼합가스의 몰 수는 0.15 mol + 0.0643 mol + 0.04 mol = 0.2543 mol 이다.

    이제 이상기체법칙을 이용하여 부피를 구해보자.

    PV = nRT

    여기서, P = 1기압, T = 30℃ + 273.15 = 303.15K, n = 0.2543 mol, R = 0.08206 L·atm/mol·K 이다.

    V = nRT / P = (0.2543 mol) x (0.08206 L·atm/mol·K) x (303.15K) / (1기압) = 6.72 L

    따라서, 혼합가스의 부피는 약 6.72 L 이다.

    하지만, 문제에서는 소수점 둘째자리까지만 답을 구하도록 요구하고 있으므로, 6.72 L을 2.97로 반올림하여 정답은 "2.97"이다.

  2. cal/mol·K
  3. erg/kmol·K
  4. Joule/mol·K
(정답률: 76%)
  • 30 CBT 기출문제AI

    2023-04-14 08:29

    정답은 "cal/mol·K" 이다.

    기체상수 R은 PV=nRT에서 P는 압력, V는 부피, n은 몰수, T는 온도를 나타내는 변수이다. 따라서 R은 압력의 단위인 Pa, 부피의 단위인 m³, 몰수의 단위인 mol, 온도의 단위인 K를 사용하여 계산된다.

    각 보기의 단위를 살펴보면, "L·atm/mol.K"는 부피의 단위가 L이고 압력의 단위가 atm인 것으로 보아 올바른 단위가 아니다. "erg/kmol·K"는 에너지의 단위인 erg를 사용하고 있으며, "Joule/mol·K"는 역시 에너지의 단위인 Joule을 사용하고 있기 때문에 올바른 단위가 아니다.

    따라서, "cal/mol·K"가 올바른 단위이다. 이는 열의 단위인 cal을 사용하고 있으며, 몰수와 온도를 나타내는 단위인 mol과 K를 사용하고 있기 때문이다.

12. 압력 1 atm, 온도 20℃ 에서 공기 1 kg의 부피를 구하면 몇 m3인가? (단, 공기의 평균분자량은 29임.)

  1. 0.42 m3
  2. 0.62 m3
  3. 0.75 m3
  4. 0.83 m3
(정답률: 68%)
  • 30 CBT 기출문제AI

    2023-04-14 08:27

    이 문제는 이상기체 상태방정식을 이용하여 풀 수 있다.

    PV = nRT

    여기서 P는 압력, V는 부피, n은 몰수, R은 기체상수, T는 절대온도를 나타낸다.

    문제에서 압력과 온도가 주어졌으므로, 이를 이용하여 부피를 구할 수 있다.

    먼저, 주어진 온도를 절대온도로 변환해야 한다.

    20℃ = 293K

    이제 이 값을 이상기체 상태방정식에 대입하여 부피를 구할 수 있다.

    V = nRT/P

    n은 몰수이고, 공기 1kg의 몰수는 질량(m)을 몰질량(M)으로 나눈 값이므로 다음과 같이 구할 수 있다.

    n = m/M = 1kg/29kg/mol = 0.0345 mol

    R은 기체상수로, 대기압에서의 공기의 경우 R = 8.31 J/mol·K 이다.

    따라서,

    V = (0.0345 mol)(8.31 J/mol·K)(293K)/(1 atm) = 0.83 m^3

    따라서, 정답은 "0.83 m^3"이다.
