2. 0.085g의 어떤 화합물을 기화시킨 결과 730mmHg, 60℃에서 23.5mL가 되었다. 이 물질의 분자량은 약 얼마인가?

  1. 7g/mol
  2. 10g/mol
  3. 75g/mol
  4. 103g/mol
(정답률: 57%)
  • 30 CBT 기출문제AI

    2023-04-14 08:41

    이 문제는 가스의 상태방정식을 이용하여 분자량을 구하는 문제입니다.

    먼저, 기체의 상태방정식은 PV = nRT 입니다. 여기서 P는 압력, V는 부피, n은 몰수, R은 기체상수, T는 온도를 나타냅니다.

    이 문제에서는 압력(P), 부피(V), 온도(T)가 주어졌으므로, 몰수(n)를 구할 수 있습니다.

    n = (PV) / (RT)

    여기서 P는 730mmHg를 기준으로 하므로, 730mmHg를 대기압인 760mmHg으로 환산해줍니다.

    P = 730mmHg x (1 atm / 760mmHg) = 0.961 atm

    또한, 온도는 섭씨로 주어졌으므로 절대온도인 켈빈온도로 변환해줍니다.

    T = 60℃ + 273.15 = 333.15 K

    이제 몰수를 구할 수 있습니다.

    n = (0.961 atm x 0.0235 L) / (0.08206 L atm / mol K x 333.15 K) = 0.00102 mol

    마지막으로, 분자량을 구하기 위해 질량과 몰수의 관계인 M = m / n을 이용합니다.

    질량은 0.085g이므로,

    M = 0.085g / 0.00102 mol = 83.33 g/mol

    하지만, 보기에서는 103g/mol이 정답으로 주어졌습니다. 이는 반올림한 값입니다. 따라서, 정답은 "103g/mol"입니다.

6. 수소의 연소반응식이 다음과 같을 경우 1mol의 수소를 일정한 압력에서 이론산소 량으로 완전연소시켰을 때의 온도는 약 몇 K인가? (단, 정압비열은 10cal/mol·K, 수소와 산소의 공급온도는 25℃, 외부로의 열손실은 없다.)

  1. 5780
  2. 58⑤
  3. 6⑤3
  4. 6078
(정답률: 51%)
  • 30 CBT 기출문제AI

    2023-04-14 08:41

    수소의 연소반응식은 다음과 같습니다.

    2H2(g) + O2(g) → 2H2O(g)

    1mol의 수소를 이론상 산소량으로 완전연소시키면 2mol의 물이 생성됩니다. 따라서, 이 반응에서 발생하는 엔탈피 변화는 다음과 같습니다.

    ΔH = 2 × (-68.32 kcal/mol) = -136.64 kcal/mol

    여기서, ΔH는 반응열을 나타내며, 음수 값이므로 반응이 발열반응임을 알 수 있습니다.

    또한, 이 반응에서 발생하는 엔트로피 변화는 다음과 같습니다.

    ΔS = 2 × (51.0 cal/mol·K) + (1 × 2⑤.0 cal/mol·K) - (2 × 130.6 cal/mol·K) = 245.8 cal/mol·K

    여기서, ΔS는 반응 엔트로피를 나타내며, 양수 값이므로 반응이 엔트로피 증가반응임을 알 수 있습니다.

    따라서, 이 반응에서 Gibbs 자유 에너지 변화는 다음과 같습니다.

    ΔG = ΔH - TΔS

    여기서, T는 온도를 나타냅니다. 반응이 일어나는 온도에서 ΔG가 음수이면 반응이 일어날 가능성이 높아집니다.

    따라서, 이 문제에서 구하고자 하는 것은 ΔG가 0이 되는 온도입니다.

    0 = -136.64 kcal/mol - T × (245.8 cal/mol·K / 1000 cal/kcal)

    T = 6078 K

    따라서, 온도는 약 6078 K입니다.

9. 탄소(C) 1kg을 완전연소시키는 데 필요한 산소량은 약 몇 kg인가?

  1. 1.667
  2. 1.867
  3. 2.667
  4. 3.667
(정답률: 56%)
  • 30 CBT 기출문제AI

    2023-04-14 08:40

    탄소(C)와 산소(O₂)의 화학식은 각각 C와 O₂이다. 이 화학식을 이용하여 탄소 1kg과 산소를 반응시키면 CO₂가 생성된다.

    C + O₂ → CO₂

    이 반응식에서 탄소 1kg과 결합할 때 필요한 산소의 양은 1kg이다. 그러나 이 반응식에서는 산소가 분자량으로 주어졌기 때문에 몰 단위로 변환해야 한다.

    산소(O₂)의 분자량은 32g/mol이다. 따라서 1mol의 산소가 필요한 양은 32g이다. 그러나 이 반응식에서는 1kg의 탄소와 반응하므로 몰 단위로 변환하면 다음과 같다.

    1kg C × (1mol C / 12.01g C) × (1mol O₂ / 1mol C) × (32g O₂ / 1mol O₂) = 2.67kg O₂

    따라서 탄소 1kg을 완전연소시키는 데 필요한 산소량은 약 2.67kg이다.

61. 차압식 유량계에서 조리개 전·후의 압력 차가 처음보다 2배만큼 커졌다면 유량은 어떻게 변하는가? (단, Q1은 조리개 전의 유량, Q2는 조리개 후의 유량이다.)

  1. Q2=Q1
  2. Q2=2Q1
  3. Q2=√2·Q1
  4. Q2=4Q1
(정답률: 74%)
  • 30 CBT 기출문제AI

    2023-04-14 08:41

    차압식 유량계에서 유량은 다음과 같은 식으로 나타낼 수 있다.

    Q = K√ΔP

    여기서 Q는 유량, K는 상수, ΔP는 조리개 전·후의 압력 차이이다. 문제에서 ΔP가 2배가 되었으므로,

    2ΔP = 2(ΔP후 - ΔP전) = ΔP후 - ΔP전

    위 식을 이용하여 Q후와 Q전을 나타내면,

    Q후 = K√(ΔP후)
    = K√(ΔP전 + 2ΔP전)
    = K√ΔP전√(1+2)
    = √3K√ΔP전

    Q전 = K√(ΔP전)

    따라서,

    Q후/Q전 = (√3K√ΔP전)/(K√ΔP전) = √3

    즉, Q후 = √3Q전 = √3·√ΔP전·K

    여기서 ΔP전 = ΔP/2 이므로,

    Q후 = √3·√(ΔP/2)·K = √(3/2)·√ΔP·K

    따라서, Q2=√2·Q1이 아니라 Q후=√(3/2)·Q전이 된다.
