3. 2kg의 기체를 0.15MPa, 15℃에서 체적이 0.1m3가 될 때까지 등온압축할 때 압축 후 압력은 몇 MPa인가? (단, 비열은 각각 Cp=0.8kJ/kg·K, Cv=0.6kJ/kg·K이다.)

  1. 1.141
  2. 1.152
  3. 1.163
  4. 1.174
(정답률: 67%)
  • 30 CBT 기출문제AI

    2023-04-14 08:33

    등온압축에서는 온도가 일정하므로, 기체의 내부에너지는 변하지 않는다. 따라서, 압력과 체적은 반비례 관계에 있다.

    먼저, 초기 상태에서의 체적과 압력을 이용하여 초기 상태에서의 몰수를 구한다.

    PV = nRT

    n = PV/RT = (0.15MPa * 0.1m^3) / (8.31J/mol·K * 288.15K) = 0.0061mol

    등온압축이므로, 기체의 내부에너지는 변하지 않는다.

    U = nC_vT = 0.0061mol * 0.6kJ/kg·K * 288.15K = 1.⑤1kJ

    압축 후에도 내부에너지는 동일하므로,

    U = nC_vT = 0.0061mol * 0.6kJ/kg·K * T

    T = U / (nC_v) = 1.⑤1kJ / (0.0061mol * 0.6kJ/kg·K) = 292.5K

    압축 후의 몰수를 구하기 위해, 상태방정식을 이용한다.

    P = nRT/V

    n = PV/RT = (0.15MPa * V) / (8.31J/mol·K * 292.5K)

    등온압축이므로,

    V * P = 상수

    0.1m^3 * 0.15MPa = n * 8.31J/mol·K * 288.15K

    n = 0.0061mol

    따라서, 압축 후의 압력은

    P = nRT/V = (0.0061mol * 8.31J/mol·K * 292.5K) / 0.1m^3 = 1.152MPa

    따라서, 정답은 "1.152"이다.

75. 프로판의 밀도가 0.5 kg/ℓ일 때 표준상태에서 프로판 1ℓ가 기화하면 그 부피(ℓ)는?

  1. 254.5
  2. 264.5
  3. 274.5
  4. 284.5
(정답률: 35%)
  • 30 CBT 기출문제AI

    2023-04-14 08:32

    표준상태에서 기체 1몰의 부피는 22.4ℓ이다. 따라서 프로판 1몰의 부피는 22.4ℓ이다.

    프로판의 몰 질량은 44.1g/mol이므로, 1ℓ의 프로판 질량은 0.5kg이므로, 1ℓ의 프로판은 몇 몰인지 계산할 수 있다.

    1ℓ의 프로판 질량 = 0.5kg = 500g
    1ℓ의 프로판 몰 수 = 500g / 44.1g/mol = 11.32mol

    따라서, 1ℓ의 프로판은 11.32몰이며, 이는 11.32 x 22.4ℓ = 254.5ℓ이 된다. 따라서 정답은 "254.5"이다.
