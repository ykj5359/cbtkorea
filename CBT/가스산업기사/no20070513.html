2. 일산화탄소와 수소의 부피비가 3:7인 혼합가스의 온도 100℃, 50atm에서의 밀도는 약 몇 g/L인가?

  1. 16
  2. 18
  3. 21
  4. 23
(정답률: 51%)
  • 30 CBT 기출문제AI

    2023-04-14 08:40

    일단, 이 문제를 푸는데 필요한 것은 이상기체법칙입니다.

    PV = nRT

    여기서 P는 압력, V는 부피, n은 몰수, R은 기체상수, T는 절대온도입니다.

    먼저, 혼합가스의 부피비가 3:7이므로, 10L의 혼합가스 중 3L은 일산화탄소, 7L은 수소입니다.

    따라서, 일산화탄소의 몰수는 PV = nRT에서 n = PV/RT = (50atm x 3L) / (0.0821 L·atm/mol·K x 373K) = 0.57mol입니다.

    수소의 몰수는 PV = nRT에서 n = PV/RT = (50atm x 7L) / (0.0821 L·atm/mol·K x 373K) = 1.33mol입니다.

    따라서, 혼합가스의 총 몰수는 0.57mol + 1.33mol = 1.9mol입니다.

    이제, 혼합가스의 부피는 10L이므로, 혼합가스의 밀도는 1.9mol / 10L = 0.19mol/L입니다.

    마지막으로, 이 값을 구체적인 단위인 g/L로 변환해야 합니다. 이를 위해서는 혼합가스의 분자량을 구해야 합니다.

    일산화탄소의 분자량은 12.01 + 16.00 = 28.01g/mol입니다.

    수소의 분자량은 1.01g/mol입니다.

    따라서, 혼합가스의 분자량은 (0.57mol x 28.01g/mol) + (1.33mol x 1.01g/mol) = 32.54g입니다.

    이제, 혼합가스의 밀도는 0.19mol/L x 32.54g/mol = 6.19g/L입니다.

    하지만, 이 값은 소수점 이하까지 계산한 값이므로, 반올림하여 정답을 구해야 합니다.

    따라서, 정답은 6.19g/L을 반올림한 16입니다.
