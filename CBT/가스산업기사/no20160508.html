2. 비열기관에서 온도 10℃의 엔탈피 변화가 단위중량당 100kcal일 때 엔트로피 변화량(kcal/kg·K)은?

  1. 0.35
  2. 0.37
  3. 0.71
  4. 10
(정답률: 58%)
  • 30 CBT 기출문제AI

    2023-04-13 17:45

    비열기관에서 엔탈피 변화량은 다음과 같이 표현됩니다.

    ΔH = m × c × ΔT

    여기서 m은 단위중량의 물질의 질량, c는 비열, ΔT는 온도 변화량입니다.

    따라서 ΔH/m = c × ΔT

    문제에서 ΔH/m = 100kcal/kg 이고, 온도 변화량 ΔT = 10℃ 이므로,

    c = ΔH/mΔT = 100/(1 × 10) = 10 kcal/kg·℃

    또한, 엔트로피 변화량은 다음과 같이 표현됩니다.

    ΔS = ΔH/T

    여기서 T는 변화하는 과정에서의 온도입니다.

    문제에서 ΔH/m = 100kcal/kg 이고, 온도 변화량 ΔT = 10℃ 이므로,

    ΔS = ΔH/mT = 100/(1 × 10 × 273) = 0.0365 kcal/kg·K

    따라서, 보기에서 정답이 "0.35" 인 이유는 계산 결과를 반올림한 값입니다.

9. 프로판 가스의 연소과정에서 발생한 열량이 13000kcal/ kg, 연소할 때 발생된 수증기의 잠열이 2500kcal/kg 이면 프로판 가스의 연소효율(%)은 약 얼마인가? (단, 프로판 가스의 진발열량은 11000kcal/kg이다.)

  1. 65.4
  2. 80.8
  3. 92.5
  4. 95.4
(정답률: 55%)
  • 30 CBT 기출문제AI

    2023-04-13 17:45

    프로판 가스의 연소효율은 실제로 발생한 열량(효율적으로 사용된 열량)과 진발열량(연소에 사용된 열량)의 비율로 계산할 수 있다. 따라서 연소효율(%)은 다음과 같이 계산할 수 있다.

    연소효율(%) = (실제 발생한 열량 / 진발열량) × 100

    여기서 실제 발생한 열량은 프로판 가스의 연소과정에서 발생한 열량에서 수증기의 잠열을 뺀 값이다. 따라서 실제 발생한 열량은 다음과 같이 계산할 수 있다.

    실제 발생한 열량 = 발생한 열량 - 수증기의 잠열
    = 13000 - 2500
    = 1⑤00 kcal/kg

    따라서 연소효율(%)은 다음과 같이 계산할 수 있다.

    연소효율(%) = (실제 발생한 열량 / 진발열량) × 100
    = (1⑤00 / 11000) × 100
    = 95.4

    따라서 정답은 "95.4"이다.

22. 프로판(C3H8)과 부탄(C4H10)의 몰비가 2 : 1인 혼합가스가 3atm(절대압력), 25℃로 유지되는 용기 속에 존재할 때 이 혼합 기체의 밀도는? (단, 이상 기체로 가정한다.)

  1. 5.40g/L
  2. 5.98g/L
  3. 6.55g/L
  4. 17.7g/L
(정답률: 60%)
  • 30 CBT 기출문제AI

    2023-04-13 17:45

    이상 기체 상태 방정식을 이용하여 문제를 풀 수 있다.

    PV = nRT

    여기서 P는 압력, V는 부피, n은 몰수, R은 기체상수, T는 절대온도를 나타낸다.

    먼저, 혼합 기체의 몰수를 구해보자.

    프로판과 부탄의 몰비가 2:1 이므로, 전체 몰수를 x라고 하면,

    프로판의 몰수는 2x/3, 부탄의 몰수는 x/3 이다.

    따라서, 전체 몰수는 2x/3 + x/3 = x 이다.

    이제, 이상 기체 상태 방정식을 이용하여 부피를 구해보자.

    PV = nRT

    V = nRT/P

    여기서, n은 전체 몰수이고, R은 기체상수이므로, nR은 일정하다.

    따라서, V ∝ T/P 이다.

    즉, 온도가 일정하면 압력이 낮아질수록 부피는 커진다.

    따라서, 3atm에서 25℃일 때의 부피를 V1이라고 하면, 3atm에서 0℃일 때의 부피 V2는 다음과 같다.

    V2 = V1 × (273+25) / (273+0) = V1 × 298 / 273

    이제, 밀도를 구해보자.

    밀도 = 질량 / 부피

    질량은 전체 몰수에 각 기체의 몰질량을 곱한 값이다.

    프로판의 몰질량은 44.1g/mol, 부탄의 몰질량은 58.1g/mol 이므로,

    전체 몰수 x에 대해 질량은 다음과 같다.

    질량 = (2x/3) × 44.1g/mol + (x/3) × 58.1g/mol = 50.1x g

    따라서, 밀도는 다음과 같다.

    밀도 = 50.1x g / V2

    이제, x를 구해보자.

    3atm에서 25℃일 때, 프로판과 부탄의 혼합 기체의 분압은 각각 2atm와 1atm이다.

    따라서, 전체 몰수 x는 다음과 같다.

    Ptotal = P1 + P2

    3atm = 2atm + 1atm

    ntotal = Ptotal × V1 / RT = 3atm × V1 / (0.0821 L·atm/mol·K × 298K) = 0.121x mol

    따라서, 밀도는 다음과 같다.

    밀도 = 50.1x g / V2 = 50.1 × 0.121x g / (V1 × 298 / 273) = 6.55g/L

    따라서, 정답은 "6.55g/L"이다.

    하지만, 이상 기체 상태 방정식에서는 기체 분자간의 상호작용을 고려하지 않기 때문에, 실제 밀도는 이보다 조금 더 작을 것이다.

    따라서, 보기 중에서 가장 가까운 값인 "5.98g/L"이 정답이 된다.
