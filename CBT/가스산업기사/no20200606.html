11. 메탄올 96g과 아세톤 116g을 함께 진공상태의 용기에 넣고 기화시켜 25℃의 혼합기체를 만들었다. 이 때 전압력은 약 몇 mmHg인가? (단, 25℃에서 순수한 메탄올과 아세톤의 증기압 및 분자량은 각각 96.5mmHg, 56mmHg, 및 32, 58이다.)

  1. 76.3
  2. 80.3
  3. 152.5
  4. 170.5
(정답률: 59%)
  • 30 CBT 기출문제AI

    2023-04-13 17:25

    먼저, 혼합기체의 분자량을 구해야 한다.

    메탄올의 몰질량 = 32g/mol
    아세톤의 몰질량 = 58g/mol

    96g의 메탄올은 몇 몰인가?
    96g / 32g/mol = 3 mol

    116g의 아세톤은 몇 몰인가?
    116g / 58g/mol = 2 mol

    따라서, 혼합기체의 총 몰수는 3mol + 2mol = 5mol 이다.

    이제 혼합기체의 분자량을 구할 수 있다.

    (3mol x 32g/mol) + (2mol x 58g/mol) = 166g

    따라서, 혼합기체의 분자량은 166g/mol 이다.

    이제 혼합기체의 증기압을 구할 수 있다.

    메탄올의 증기압 = 96.5mmHg
    아세톤의 증기압 = 56mmHg

    각각의 몰분율을 구하면 다음과 같다.

    메탄올의 몰분율 = 3mol / 5mol = 0.6
    아세톤의 몰분율 = 2mol / 5mol = 0.4

    따라서, 혼합기체의 증기압은 다음과 같다.

    (0.6 x 96.5mmHg) + (0.4 x 56mmHg) = 80.3mmHg

    따라서, 정답은 "80.3"이다.

    프로판(C3H8) 1몰이 완전연소될 때 생성되는 이산화탄소(CO2)와 수증기(H2O)의 몰 비는 각각 3:4 이다. 따라서 1Sm3의 프로판이 완전연소될 때 생성되는 이산화탄소와 수증기의 몰은 각각 3/7Sm3, 4/7Sm3 이다. 이들의 몰 비는 3:4 이므로, 이산화탄소와 수증기 중 몰이 더 많은 수증기의 몰이 4/7Sm3 이다. 이론공기는 수증기를 포함한 공기이므로, 이론공기량은 4/7Sm3 이다. 이를 소수점 첫째자리까지 반올림하면 0.6Sm3 이다. 따라서, 프로판 1Sm3를 완전연소시키는데 필요한 이론공기량은 1+0.6=1.6Sm3 이다. 이를 23.8로 환산하면, 1Sm3의 이론공기량은 23.8/1.6=14.875 이므로, 프로판 1Sm3를 완전연소시키는데 필요한 이론공기량은 14.875 x 1.6 = 23.8Sm3 이다.

  3. 98mm

    유량(Q)과 평균유속(V) 사이에는 다음과 같은 관계식이 성립합니다.

    Q = πr^2V

    여기서 r은 파이프의 반지름입니다. 이 관계식을 파이프 지름(d)와 평균유속(V) 사이의 관계식으로 변형하면 다음과 같습니다.

    d = 2r
    Q = πr^2V = π(d/2)^2V = (π/4)d^2V
    V = Q / ((π/4)d^2)

    이제 문제에서 주어진 유량(Q)과 평균유속(V) 값을 대입하여 파이프 지름(d)을 구하면 됩니다.

    V = Q / ((π/4)d^2) = 25 / ((π/4) × (406.3)^2) = 3
    d = √(25 / (3 × π/4)) ≈ 103mm (근사값)

    따라서, 파이프의 지름을 약 103mm로 해야 합니다.

80. 헴펠(Hempel)법에 의한 분석순서가 바른 것은?

  1. CO2→CmHn→O2→CO
  2. CO→CmHn→O2→CO2
  3. CO2→O2→CmHn→CO
  4. CO→O2→CmHn→CO2

    2023-04-12 09:57

    정답은 "CO2→CmHn→O2→CO"입니다.

    헴펠법은 불완전 연소 시 생성된 가스의 성분을 분석하는 방법입니다. 이 방법은 먼저 산소(O2)를 가스 샘플에 흡입하여 가스를 완전 연소시키고, 이어서 이산화탄소(CO2)를 가스 샘플에 흡입하여 생성된 CO2의 양을 측정합니다. 이후, 이산화탄소(CO2)를 제거하고 남은 가스 샘플에서 수소(H2)와 일차탄화수소(CmHn)를 측정합니다. 마지막으로, 이산화탄소(CO2)를 다시 가스 샘플에 흡입하여 생성된 CO2의 양을 측정합니다.

    따라서, CO2를 먼저 분석하는 것이 가장 바람직합니다. 이후 CmHn과 O2를 분석하고, 마지막으로 CO2를 다시 분석합니다. 이 방법은 분석 과정에서 CO2의 영향을 최소화할 수 있기 때문에 정확한 분석 결과를 얻을 수 있습니다.
