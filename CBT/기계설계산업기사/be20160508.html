7. 그림과 같이 더브테일 홈 가공을 하려고 할 때 X의 값은 약 얼마인가? (단, tan60°=1.7321, tan30°=0.5774이다.)

  1. 60.26
  2. 68.39
  3. 82.04
  4. 84.86
(정답률: 73%)
  • 30 CBT 기출문제AI

    2023-04-15 06:16

    먼저, 삼각형 ABC에서 각 B의 크기는 60도이므로, 각 A의 크기는 180-60=120도입니다. 또한, 삼각형 ABD에서 각 D의 크기는 90도이므로, 각 ABD의 크기는 180-90=90도입니다.

    따라서, 삼각형 ABD에서 tan(ABD) = BD/AD입니다. tan(ABD)는 tan(60) = 1.7321이므로, BD/AD = 1.7321입니다.

    또한, 삼각형 ACD에서 tan(ACD) = CD/AD입니다. tan(ACD)는 tan(30) = 0.5774이므로, CD/AD = 0.5774입니다.

    마지막으로, 삼각형 BCD에서 tan(BCD) = BD/CD입니다. 이를 이용하여 BD를 구할 수 있습니다. tan(BCD)는 tan(120) = -1.7321이므로, BD/CD = -1.7321입니다. 따라서, BD = -1.7321CD입니다.

    이제, BD와 CD의 비율을 이용하여 X를 구할 수 있습니다. X는 BD+CD입니다. BD = -1.7321CD이므로, X = -0.7321CD입니다. CD/AD = 0.5774이므로, CD = 0.5774AD입니다. 따라서, X = -0.7321(0.5774AD) + AD = 0.399AD입니다.

    따라서, X의 값은 AD의 약 0.399배입니다. 삼각형 ACD에서 AD의 길이는 100이므로, X의 값은 약 39.9입니다. 하지만, 이는 원래 그림에서의 길이이므로, 1.7배를 해주어야 합니다. 따라서, 최종적으로 X의 값은 약 68.39가 됩니다.

    T = P x r / (2 x pi x N)

    τ = T x r / J
