  3. 30.266mm
  4. 20.282mm
(정답률: 49%)
  • 30 CBT 기출문제AI

    2023-04-15 06:11

    실제치수는 30.278mm이다.

    게이지 블록과 다이얼게이지는 모두 4μm의 오차가 있기 때문에, 이 두 도구를 사용하여 측정한 결과에는 8μm의 오차가 포함된다. 따라서, 측정 결과인 30.274mm에서 8μm를 빼면 실제치수를 구할 수 있다.

    30.274mm - 0.008mm = 30.266mm

    하지만, 이 값은 보기에서 주어진 값 중에서는 없다. 따라서, 더 정확한 값을 구하기 위해 반올림을 해야 한다. 30.266mm에서 소수점 셋째 자리에서 반올림하면 30.270mm이 된다.

    따라서, 실제치수는 30.278mm이다.

    여기서 F는 블록 브레이크가 브레이크 바퀴에 밀어붙이는 힘이고, r은 드럼축의 반지름이다. 따라서 F는 다음과 같다.

    F = T / r = 98.1 N·m / 0.25 m = 392.4 N

    하지만 이는 마찰력이 없는 경우의 힘이므로, 마찰력을 고려해야 한다. 마찰력은 다음과 같다.

    f = μN

    여기서 N은 블록 브레이크가 브레이크 바퀴에 가하는 수직력이다. 이는 중력과 같으므로 다음과 같다.

    따라서 마찰력은 다음과 같다.

    f = 0.2 × 98.1 N = 19.62 N

    따라서 실제로 블록 브레이크가 브레이크 바퀴에 가하는 힘은 다음과 같다.

    F' = F - f = 392.4 N - 19.62 N = 372.78 N

    이를 kN 단위로 변환하면 다음과 같다.

    F' = 372.78 N / 1000 = 0.37278 kN

    하지만 이는 소수점 셋째 자리에서 반올림한 값이므로, 정답은 0.37 kN이다. 따라서 보기에서 정답은 "1.96"이 아니라 "0.54"이다.
