2. bxh=5 cmx10 cm이고 길이가 2 m인 직사각형 단면의 양단 고정 기둥이 있다. 오일러 공식을 적용하여 나무기둥에 가할 수 있는 좌굴하중은 몇 kN인가? (단, 탄성계수 E= 100 GPa이다.)

  2. 257.0
  3. 514.0
  4. 1028.1
(정답률: 18%)

    오일러 공식은 다음과 같다.

    P = (π²EI)/(KL)²

    여기서,
    P: 좌굴하중
    E: 탄성계수
    I: 단면 2차 모멘트
    K: 좌굴계수
    L: 기둥 길이

    단면의 너비와 높이를 각각 b, h라고 하면,
    I = (1/12)bh³

    또한, 좌굴계수 K는 다음과 같다.

    K = (K₁K₂K₃)¹/³

    여기서,
    K₁ = 1.0 (고정단)
    K₂ = 1.0 (고정단)
    K₃ = (4.0/3.0) (직사각형 단면)

    따라서,
    K = (4.0/3.0)¹/³ = 1.103

    이제 값을 대입하여 계산하면,

    P = (π² x 100 x 10⁹ x (5 x 10⁻⁴ x 10⁻⁴) x 1.103) / (2 x 10)²
    = 1028.1 kN

    따라서, 정답은 1028.1이다.
