79. 3차원 직교좌표계 상의 세 점 A(1, 1, 1), B(2, 1, 4), C(5, 1, 3)가 이루는 삼각형의 면적은 얼마인가?

  1. 4
  2. 5
  3. 8
  4. 10
(정답률: 48%)
  • 30 CBT 기출문제AI

    2023-04-15 06:12

    먼저 세 점 A, B, C를 이용하여 삼각형의 한 변의 길이를 구합니다.

    AB = √[(2-1)^2 + (1-1)^2 + (4-1)^2] = √10

    BC = √[(5-2)^2 + (1-1)^2 + (3-4)^2] = √10

    CA = √[(1-5)^2 + (1-1)^2 + (1-3)^2] = 2√5

    이제 헤론의 공식을 이용하여 삼각형의 넓이를 구합니다.

    s = (AB + BC + CA) / 2 = (2√10 + 2√5) / 2 = √10 + √5

    넓이 = √s(s-AB)(s-BC)(s-CA) = √(√10 + √5)(√10 - √5)(√5)(√5 - √10)

    = √(10 - 5)(5)(√5 - √10) = √25(√5 - √10) = 5(√5 - √10)

    따라서 정답은 "5"입니다.
