16. 천해파(Shallow sea wave)의 파속(phase speed)과 수심과의 관계를 가장 올바르게 설명한 것은?

  1. 파속은 수심에 반비례한다.
  2. 파속은 수심의 제곱근에 비례한다.
  3. 파속은 수심에 정비례한다.
  4. 파속은 수심과 무관하다.
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-18 08:00

    정답은 "파속은 수심의 제곱근에 비례한다."이다.

    천해파의 파속은 수심과 밀접한 관련이 있다. 파속은 파장 길이와 주기의 곱으로 정의되는데, 천해파의 파장 길이는 수심에 따라 변하지 않고, 주기는 수심에 비례한다. 따라서 파속은 주기와 관련이 있다.

    수식적으로는 파속(celerity)은 다음과 같이 나타낼 수 있다.

    c = L / T

    여기서 L은 파장 길이, T는 주기이다. 천해파의 주기는 다음과 같이 나타낼 수 있다.

    T = 2π / ω

    여기서 ω는 각진동수이다. 천해파의 각진동수는 다음과 같이 나타낼 수 있다.

    ω = 2π / T = gk

    여기서 g는 중력가속도, k는 파수이다. 파수는 파장 길이와 수심에 따라 결정된다.

    k = 2π / L * h^(1/2)

    따라서 파속은 다음과 같이 나타낼 수 있다.

    c = L / T = gk / ω = g / k * h^(1/2)

    여기서 h는 수심이다. 따라서 파속은 수심의 제곱근에 비례한다.

    V = √( (K + 4/3μ) / ρ )

    여기서, K는 암석의 척도모듈러스, μ는 암석의 전단모듈러스이다.

    먼저, K를 구하기 위해 다음의 공식을 이용한다.

    K = ρV2 (1 - 2μ) / (3 - 2μ)

    여기서, V는 P파의 속도이다.

    K를 구하기 위해, 먼저 μ를 구한다.

    μ = (3K - 2G) / (2(3G + K))

    G = K / (2(1 + μ))

    μ = (3K - 2G) / (2(3G + K))
    0.11 = (3K - 2G) / (2(3G + K))

    0.66G + 0.33K = 2G
    0.33K = 1.34G
    K = 4.06G

    G = K / (2(1 + μ))
    μ = (3K - 2G) / (2(3G + K))
    G = 1.54×1010 N/m2
    μ = 0.25

    K = 4.06G = 6.25×1010 N/m2

    V = √( (K + 4/3μ) / ρ )
