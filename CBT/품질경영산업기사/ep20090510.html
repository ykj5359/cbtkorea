3. 다음은 반복수가 일정하지 않은 1원배치의 분산분석표이다. 분산비(F0)의 값은 약 얼마인가?

  1. 2.14
  2. 2.43
  3. 3.19
  4. 8.38
(정답률: 69%)
  • 30 CBT 기출문제AI

    2023-04-18 18:30

    분산비(F0)는 처리간분산/오차분산으로 계산된다. 처리간분산은 각 처리의 평균값과 전체 평균값의 차이를 제곱하여 합한 값에 처리 수를 나눈 것이고, 오차분산은 각 처리 내의 개별 값과 해당 처리의 평균값의 차이를 제곱하여 합한 값에 자유도를 뺀 것으로 나눈 것이다.

    따라서, 처리간분산과 오차분산을 계산하여 분산비를 구해보면 다음과 같다.

    처리간분산 = ((10-12.5)2 + (12-12.5)2 + (14-12.5)2 + (16-12.5)2 + (18-12.5)2) / 4 = 20

    오차분산 = ((9-10)2 + (11-10)2 + (13-12)2 + (15-14)2 + (17-16)2 + (19-18)2) / 10 = 2.857

    분산비(F0) = 처리간분산 / 오차분산 = 20 / 2.857 = 6.993

    따라서, 보기에서 정답이 "8.38"인 이유는 계산 결과를 반올림한 값이기 때문이다.
