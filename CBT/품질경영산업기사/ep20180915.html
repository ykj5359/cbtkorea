    ( x̄1 - x̄2 ) ± tα/2 * √( s2 / n1 + s2 / n2 )

    x̄1 - x̄2 = 0.825 - 0.375 = 0.45
    s2 = ((n1-1)s12 + (n2-1)s22) / (n1 + n2 - 2)

    0.45 ± tα/2 * 0.173
    = 0.45 ± 2.145 * 0.173 (자유도 8, α=0.⑤)
    = 0.45 ± 0.372
