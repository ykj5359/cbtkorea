    3×3 라틴방격 실험에서 인자 A의 변동은 다음과 같이 계산할 수 있다.

    총 변동 = TSS = Σ(x-μ)²
    인자간 변동 = SSTR = (T₁∙∙² + T₂∙∙² + T₃∙∙²)/n - (Σx)²/N
    인자내 변동 = SSE = TSS - SSTR

    여기서, n은 각 인자의 수준 수, N은 전체 자료의 수, x는 각 자료 값, μ는 전체 자료의 평균을 나타낸다.

    따라서, 인자 A의 변동은 다음과 같이 계산할 수 있다.

    총 변동 = TSS = (16² + 40² + 47²) - ((16+40+47)²/9) = 1026.22
    인자간 변동 = SSTR = ((16²/3 + 40²/3 + 47²/3) - ((16+40+47)²/9))/2 = 850.00
    인자내 변동 = SSE = 1026.22 - 850.00 = 176.22

    따라서, 인자 A의 변동은 약 176.22이다.
