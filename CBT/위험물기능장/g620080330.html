29. 27℃, 2atm 에서 20g의 CO2 기체가 차지하는 부피는 약 몇 L 인가?

  2. 2.80
  3. 1.40
  4. 0.50
(정답률: 75%)

    2023-04-12 10:59

    이 문제는 이상기체 법칙을 이용하여 풀 수 있습니다.

    PV = nRT

    여기서 P는 압력, V는 부피, n은 몰수, R은 기체상수, T는 절대온도를 나타냅니다.

    먼저, CO2의 몰량을 구해야 합니다.

    CO2의 분자량은 12.01 + 2(16.00) = 44.01 g/mol 입니다.

    따라서, 20g의 CO2는 20g / 44.01 g/mol = 0.454 mol 입니다.

    27℃ = 300K

    V = nRT/P = (0.454 mol)(0.0821 L·atm/mol·K)(300K)/(2atm) = 5.59 L

    c 관리도에서 k = 20 인 군의 총부적합(결점)수 합계는 58 이므로, 평균 결점수는 58/20 = 2.9 이다. 이를 이용하여 UCL과 LCL을 구할 수 있다.

    UCL = 평균 결점수 + 3 x 표준편차
    LCL = 평균 결점수 - 3 x 표준편차

    표준편차는 평균 결점수의 제곱근으로 구할 수 있다.

    평균 결점수 = 2.9
    표준편차 = sqrt(2.9) = 1.70

    따라서,

    UCL = 2.9 + 3 x 1.70 = 8.01
    LCL = 2.9 - 3 x 1.70 = 고려하지 않음

    보기 중에서 정답은 "UCL = 8.01, LCL = 고려하지 않음" 이다. 이유는 LCL이 음수가 되기 때문에 적용할 수 없다. 따라서 LCL은 고려하지 않는다.
