    LMTD = (ΔT1 - ΔT2) / ln(ΔT1 / ΔT2)

    여기서 ΔT1은 열교환기의 입구와 방열 유체의 입구 온도차이, ΔT2는 열교환기의 출구와 방열 유체의 출구 온도차이입니다.

    NTU와 전열효율이 주어졌으므로, 다음과 같은 식을 이용하여 ΔT2 / ΔT1을 구할 수 있습니다.

    NTU = (1 - e^(-NTU)) / (1 - e^(-NTU * (ΔT2 / ΔT1)))

    ΔT2 / ΔT1 = (-ln(1 - NTU) + NTU) / NTU

    LMTD = (1⑤ - (-1⑤)) / ln((1⑤ / (-1⑤)) / ((-ln(1 - 3.5) + 3.5) / 3.5)) ≈ 30
