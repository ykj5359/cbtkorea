    열전달 방정식 Q = mcΔT를 이용하여 문제를 풀 수 있다. 여기서 Q는 열량, m은 강재의 질량, c는 강재의 비열, ΔT는 강재의 온도 변화량이다.

    먼저 연료의 발열량을 구해보자. 연료 1 Nm3를 연소시켰을 때 발생하는 열량은 2,000㎉이다.

    다음으로, 가열로를 통과하는 연료와 공기의 혼합기체의 열용량을 구해보자. 연료와 공기의 질량 비율은 1:9 이므로, 1 Nm3의 혼합기체의 질량은 연료 0.1 Nm3과 공기 0.9 Nm3의 질량을 합한 것이다.

    연료 0.1 Nm3의 질량은 밀도 x 부피 = 0.8 x 0.1 = 0.08 kg 이다.
    공기 0.9 Nm3의 질량은 밀도 x 부피 = 1.2 x 0.9 = 1.08 kg 이다.
    따라서 혼합기체 1 Nm3의 질량은 0.08 + 1.08 = 1.16 kg 이다.

    혼합기체의 비열은 공기와 연료의 비열을 가중평균한 값이다.
    공기의 비열은 1.0⑤ kJ/kg·K, 연료의 비열은 1.2 kJ/kg·K 이므로,
    혼합기체의 비열은 (0.9 x 1.0⑤ + 0.1 x 1.2) = 1.011 kJ/kg·K 이다.

    가열로를 통과하는 혼합기체의 온도 변화량을 구해보자.
    가열로의 입구 온도는 25℃, 출구 온도는 1,000℃ 이므로, 온도 변화량은 1,000 - 25 = 975℃ 이다.

    따라서, 강재가 함유하는 열량은 다음과 같이 계산할 수 있다.

    Q = mcΔT = 1.16 x 1.011 x 975 = 1,126.57 kJ/Nm3

    이를 1 Nm3 당으로 환산하면,

    1,126.57 / 1 = 1,126.57 kJ/Nm3

    1 kJ = 0.239 kcal 이므로,

    1,126.57 x 0.239 = 269.14 kcal/Nm3

    269.14 kcal/Nm3은 925.57 ㎉/Nm3에 해당한다. 따라서 정답은 "925.57"이다.

    발열량 = 337C + 1442(H - O/8) + 93S - 11A - M

    C = 100 - 수분 - 휘발분 - 회분 = 100 - 4.2 - 16.2 - 28.9 = 50.7
