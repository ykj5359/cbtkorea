6. 프로판(C3H8) 및 부탄(C4H10)이 혼합된 LPG를 건조 공기로 연소시킨 가스를 분석하였더니 CO2 11.32%, O2 3.76%, N2 84.92% 의 조성을 얻었다. LPG 중의 프로판과 부탄의 부피비는?

  1. 100.00 : 0.00
  2. 91.65 : 8.35
  3. 86.28 : 13.72
  4. 73.15 : 26.85
(정답률: 64%)
  • 30 CBT 기출문제AI

    2023-04-07 08:46

    LPG를 연소시키면 다음과 같은 반응식이 일어납니다.

    C3H8 + 5O2 → 3CO2 + 4H2O
    C4H10 + 6.5O2 → 4CO2 + 5H2O

    이 반응식에서 CO2의 양은 프로판과 부탄이 생성하는 CO2의 양의 합과 같습니다. 따라서 CO2의 양으로부터 프로판과 부탄의 부피비를 구할 수 있습니다.

    CO2의 부피는 11.32% 이므로, 프로판과 부탄이 생성하는 CO2의 부피는 11.32%를 2로 나눈 값인 5.66%입니다. 따라서 프로판과 부탄이 생성하는 CO2의 부피비는 5.66% : 5.66% = 1 : 1입니다.

    O2의 부피는 3.76% 이므로, 연소에 필요한 총 공기의 부피는 100% / (100% - 3.76%) = 104.17%입니다. 이 중에서 프로판과 부탄이 차지하는 부피는 100% - 11.32% - 3.76% = 84.92%입니다. 이 부피 중에서 프로판과 부탄이 차지하는 부피비는 1 : 1이므로, 프로판의 부피비는 0.5 : 0.5 = 1 : 1, 부탄의 부피비도 1 : 1입니다.

    따라서 LPG의 프로판과 부탄의 부피비는 1 : 1이며, 이는 "91.65 : 8.35"가 아닌 "100.00 : 0.00"입니다. 따라서 정답은 없습니다.

12. 다음과 같은 조성을 가진 석탄의 완전연소에 필요 한 이론공기량(kg/kg)은 약 얼마인가?

  3. 9.7
  4. 10.4
(정답률: 56%)

    CₓHₓ + (x + 0.25y)O₂ → xCO₂ + 0.5yH₂O

    이론공기량 = (8 + 0.25×18) / 8 = 8.875

13. 프로판(Propane) 가스 1kg을 완전연소시킬 때 필요한 이론공기량(Sm3/kg)은?

  1. 6
  2. 8
  3. 10
  4. 12
(정답률: 71%)
  • 30 CBT 기출문제AI

    2023-04-07 08:47

    프로판의 화학식은 C3H8이며, 완전연소시 CO2와 H2O로 분해됩니다. 이 때, 반응식은 다음과 같습니다.

    C3H8 + 5O2 → 3CO2 + 4H2O

    이 반응식에서 몰 비율을 보면, 1 몰의 프로판에 5 몰의 산소가 필요합니다. 이를 이용하여 1kg의 프로판에 필요한 이론공기량을 계산해보면 다음과 같습니다.

    1kg 프로판 = 1000g / 44.1 g/mol = 22.68 mol 프로판
    필요한 산소 = 22.68 mol 프로판 × 5 mol O2/mol 프로판 = 113.4 mol O2

    따라서, 이론공기량은 산소 113.4 mol에 대한 공기의 양으로 계산됩니다. 이 때, 공기는 대기 중 78%가 질소(N2)이고 21%가 산소(O2)이며, 나머지는 기타 기체로 이루어져 있습니다. 따라서, 이론공기량은 다음과 같이 계산됩니다.

    이론공기량 = 113.4 mol O2 / 0.21 = 540 mol 공기
    = 540 × 22.4 L/mol (0℃, 1 atm 기준) / 1000 g
    = 12.1 Sm3/kg

    따라서, 프로판 1kg을 완전연소시킬 때 필요한 이론공기량은 약 12.1 Sm3/kg이며, 보기 중에서 가장 가까운 값은 "12"입니다.

99. 내화벽돌이 두께 140mm 적벽돌 및 100mm 단열 벽돌로 되어있는 노벽이 있다. 이것의 열전도율은 각각 1.2, 0.06kcal/m ㆍ h ㆍ ℃ 이다. 이 때 손실열량은 약 몇 kcal/m2ㆍ h 인가? (단, 노내 벽면의 온도는 1000℃ 이고, 외벽면의 온도는 100℃ 이다.)

  1. 289
  2. 442
  3. 5⑤
  4. 635
(정답률: 45%)
  • 30 CBT 기출문제AI

    2023-04-07 09:02

    손실열량은 다음과 같이 계산할 수 있다.

    Q = (Tin - Tout) / (R내 + R단열 + R외)

    여기서, Tin은 노내 벽면의 온도인 1000℃, Tout은 외벽면의 온도인 100℃이다. R내, R단열, R외는 각각 내화벽돌, 단열 벽돌, 적벽돌의 열저항이다.

    R내 = 두께 / 열전도율 = 0.14 / 1.2 = 0.1167 m2ㆍ ℃ / kcal
    R단열 = 두께 / 열전도율 = 0.1 / 0.06 = 1.6667 m2ㆍ ℃ / kcal
    R외 = 두께 / 열전도율 = 0.14 / 1.2 = 0.1167 m2ㆍ ℃ / kcal

    따라서,

    Q = (1000 - 100) / (0.1167 + 1.6667 + 0.1167) = 5⑤ kcal/m2ㆍ h

    따라서 정답은 "5⑤"이다.

100. 내압 60kgf/cm2 이 작용하는 외경 150mm, 두께 5mm 의 파이프에 작용하는 축방향의 인장력은 약 몇 kgf 인가?

  1. 2450
  2. 7625
  3. 9566
  4. 19133
(정답률: 38%)

    2023-04-07 09:02

    인장력은 내압과 파이프의 면적, 그리고 안전율에 따라 결정됩니다. 이 문제에서는 파이프의 외경과 두께를 이용하여 면적을 구할 수 있습니다.

    파이프의 내경은 외경에서 두께의 두 배를 뺀 값이므로, 내경은 140mm 입니다. 이를 이용하여 파이프의 면적을 구하면 다음과 같습니다.

    면적 = (외경의 제곱 - 내경의 제곱) × π / 4
    = (150^2 - 140^2) × 3.14 / 4
    = 1767.5 mm^2

    따라서, 인장력은 내압에 면적을 곱한 값이 됩니다.

    인장력 = 내압 × 면적
    = 60 × 1767.5
    = 106⑤0 kgf

    하지만, 이 값은 안전율을 고려하지 않은 값입니다. 일반적으로 안전율은 3~4 정도로 설정되는데, 이 문제에서는 안전율이 명시되어 있지 않으므로, 보기에서 제시된 값 중에서 가장 근접한 값인 9566 kgf 가 정답이 됩니다.
