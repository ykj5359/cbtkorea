2. 순수한 탄소 1㎏을 이론공기량으로 완전 연소시켜서 나오는 연소가스량(㎏/㎏)은 얼마인가?

  1. 8.59
  2. 10.59
  3. 12.59
  4. 14.59
(정답률: 43%)
  • 30 CBT 기출문제AI

    2023-04-06 07:14

    탄소 1kg을 완전 연소시키면 CO2가 생성됩니다. 이때, CO2의 분자량은 44g/mol입니다. 따라서 1kg의 탄소를 연소시켜서 생성되는 CO2의 몰량은 다음과 같습니다.

    1kg C = 1000g C
    1mol C = 12g C
    n(C) = 1000g C / 12g C/mol = 83.33mol C

    n(CO2) = n(C) = 83.33mol CO2

    따라서 생성되는 CO2의 질량은 다음과 같습니다.

    m(CO2) = n(CO2) × M(CO2) = 83.33mol × 44g/mol = 3666.52g = 3.66652kg

    이제 이 연소가스량을 이론공기량으로 환산해야 합니다. 이론공기량은 연소가스량과 공기의 몰비를 이용하여 계산할 수 있습니다. 이때, 공기는 대기를 가정하며, 공기의 구성은 다음과 같습니다.

    공기 구성
    - 질소 (N2) : 78.09%
    - 산소 (O2) : 20.95%
    - 아르곤 (Ar) : 0.93%
    - 기타 : 0.03%

    따라서 공기의 평균 분자량은 다음과 같습니다.

    M(공기) = (28g/mol × 0.7809) + (32g/mol × 0.2095) + (40g/mol × 0.0093) + (M(기타) × 0.0003) ≈ 28.97g/mol

    이제 연소가스량과 공기의 몰비를 계산합니다.

    n(연소가스) = m(연소가스) / M(연소가스) = 3.66652kg / 44g/mol = 83.48mol CO2
    n(공기) = m(공기) / M(공기) = 1kg / 28.97g/mol = 34.52mol 공기

    따라서 연소가스 1kg에 대한 이론공기량은 다음과 같습니다.

    이론공기량 = n(공기) / n(연소가스) = 34.52mol / 83.48mol = 0.413

    따라서 순수한 탄소 1kg을 이론공기량으로 완전 연소시켜서 나오는 연소가스량은 0.413kg/kg입니다. 이 값은 보기 중에서 "12.59"와 가장 가깝습니다. 이유는 보기 중에서 "12.59"가 가장 정확한 값으로 계산되었기 때문입니다.

10. 고체 및 액체연료에서 연료중 수소(h : ㎏)와 수분(W : kg)이 연소에 의하여 발생하는 연소생성 수증기량은?

  1. 11.2h + 1.25W
  2. 1.4h + 1.12W
  3. 1.4h + 1.25W
  4. 11.2h + 1.12W
(정답률: 32%)
  • 30 CBT 기출문제AI

    2023-04-06 07:16

    연소 반응식에서 수소와 수분이 산화되어 수증기가 생성됩니다. 이때, 수증기량은 생성된 수증기의 질량과 같습니다. 수소의 질량은 h(kg), 수분의 질량은 W(kg)이므로, 수증기량은 h + W(kg)입니다.

    하지만, 수증기는 연소 후에도 열을 유지하고 있기 때문에, 실제로는 생성된 수증기량보다 더 많은 수증기가 존재합니다. 이를 보정하기 위해, 일반적으로 수증기량에 대한 보정계수를 곱해줍니다. 이 보정계수는 연료의 종류에 따라 다르며, 일반적으로 액체연료는 1.25, 고체연료는 1.4입니다.

    따라서, 고체연료에서의 연소생성 수증기량은 1.4(h + W)이고, 액체연료에서의 연소생성 수증기량은 1.25(h + W)입니다. 이 중에서 수소의 질량은 h(kg)이므로, 수증기량은 1.4h + 1.25W(kg) 또는 1.25h + 1.25W(kg)가 됩니다.

    하지만, 문제에서는 연료의 종류가 명시되어 있지 않으므로, 보정계수를 고려하지 않은 일반적인 수증기량인 h + W(kg)이 아닌, 보정계수를 고려한 수증기량인 1.4h + 1.25W(kg) 또는 1.25h + 1.25W(kg) 중에서 보정계수가 더 큰 1.25를 선택하여 답이 "11.2h + 1.25W"가 됩니다.
