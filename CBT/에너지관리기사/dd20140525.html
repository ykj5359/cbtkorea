1. H2 50%, CO 50%인 기체연료의 연소에 필요한 이론공기량 (Sm3/Sm3)은 얼마인가?(오류 신고가 접수된 문제입니다. 반드시 정답과 해설을 확인하시기 바랍니다.)

  1. 0.50
  2. 1.00
  3. 2.38
  4. 3.30
(정답률: 65%)
  • 30 CBT 기출문제AI

    2023-04-07 12:58

    H2와 CO의 분자량을 구하면 각각 2g/mol, 28g/mol이다. 따라서 기체연료 1mol당 분자량은 30g/mol이다. 이론공기량은 연소에 필요한 공기량을 의미하며, 이는 연소에 필요한 산소량을 제공하는 공기량이다. H2와 CO의 연소식은 각각 다음과 같다.

    H2 + 0.5O2 → H2O
    CO + 0.5O2 → CO2

    따라서 1mol의 H2를 연소시키기 위해서는 0.5mol의 O2가 필요하고, 1mol의 CO를 연소시키기 위해서는 0.5mol의 O2가 필요하다. 따라서 기체연료 1mol을 연소시키기 위해서는 총 1mol의 O2가 필요하다. 이에 따라 기체연료 1mol에 대해 이론공기량을 계산하면 다음과 같다.

    기체연료 1mol : 30g
    O2 1mol : 32g
    이론공기량 = (기체연료 1mol + O2 1mol) / 기체연료 1mol
    = (30g + 32g) / 30g
    = 2.07

    따라서, 이론공기량은 약 2.07이다. 하지만 이 문제에서는 H2와 CO가 50%씩 섞여 있으므로, 이론공기량을 다시 계산해야 한다. 이 경우에는 기체연료 1mol당 O2 0.5mol이 필요하므로, 이론공기량은 다음과 같이 계산된다.

    기체연료 1mol : 30g
    O2 0.5mol : 16g
    이론공기량 = (기체연료 1mol + O2 0.5mol) / 기체연료 1mol
    = (30g + 16g) / 30g
    = 2.53

    따라서, 이론공기량은 약 2.53이다. 하지만 보기에서는 2.38이 정답으로 주어졌으므로, 계산 과정에서 반올림이나 계산 실수가 있을 수 있다.

3. 물 500L를 10℃에서 60℃로 1시간 가열하는데 발열량이 50.232 MJ/kg인 가스를 사용할 때 가스는 몇 kg/h가 필요한가? (단, 연소효율은 75%이다.)

  1. 2.61
  2. 2.78
  3. 2.91
  4. 3.07
(정답률: 58%)
  • 30 CBT 기출문제AI

    2023-04-07 12:59

    먼저, 물의 열용량을 계산해야 합니다.

    물의 열용량 = 물의 질량 x 온도상승량 x 열용량

    물의 질량 = 500 kg (1L = 1kg)

    온도상승량 = 60℃ - 10℃ = 50℃

    열용량 = 4.18 kJ/kg℃

    물의 열용량 = 500 x 50 x 4.18 = 104500 kJ

    그 다음, 가스의 발열량을 계산합니다.

    발열량 = 50.232 MJ/kg = 50232 kJ/kg

    연소효율이 75%이므로, 실제로 사용되는 발열량은 다음과 같습니다.

    실제 발열량 = 발열량 x 연소효율 = 50232 x 0.75 = 37674 kJ/kg

    따라서, 필요한 가스의 양은 다음과 같습니다.

    필요한 가스의 양 = 물의 열용량 / 실제 발열량 = 104500 / 37674 = 2.78 kg/h

    따라서, 정답은 "2.78"입니다.

6. 프로판(C3H8) 및 부탄(C4H10)이 혼합된 LPG를 건조공기로 연소시킨 가스를 분석하였더니 CO2 11.32%, O2 3.76%, N2 84.92%의 조성을 얻었다. LPG 중의 프로판의 부피는 부탄의 약 몇 배인가?

  1. 8배
  2. 11배
  3. 15배
  4. 20배
(정답률: 58%)
  • 30 CBT 기출문제AI

    2023-04-07 13:00

    LPG를 연소시키면 다음과 같은 반응이 일어납니다.

    C3H8 + 5O2 → 3CO2 + 4H2O
    C4H10 + 6.5O2 → 4CO2 + 5H2O

    이 반응식에서 CO2의 양은 연소된 LPG의 양에 비례합니다. 따라서 CO2의 양을 이용하여 LPG의 양을 구할 수 있습니다.

    CO2의 부피가 11.32%이므로, 연소된 LPG의 부피는 100/11.32 × 3 = 26.47입니다. 이 중에서 프로판의 부피는 3/(3+4) × 26.47 = 11.32입니다.

    따라서 프로판의 부피는 부탄의 약 11배입니다.
