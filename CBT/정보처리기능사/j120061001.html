13. 불(Boolean) 대수의 기본 법칙으로 옳지 않은 것은?

  1. A + A = A
  2. A · A' = 0
  3. A + A' = 1
  4. A + 0 = 0
(정답률: 73%)
  • 30 CBT 기출문제AI

    2023-04-12 23:01

    정답: A + 0 = 0이 옳지 않음

    A + 0 = A인 것이 맞는 법칙이며, 이는 OR 연산에서 0은 아무것도 선택하지 않는 것이므로 A와 0을 OR 연산하면 A가 선택되는 것과 같다. 따라서 A + 0 = A가 성립한다.

    A + A = A는 OR 연산에서 같은 항목을 두 번 선택하는 것과 같으므로 A를 한 번 선택하든 두 번 선택하든 결과는 A가 선택된 것과 같다. 따라서 A + A = A가 성립한다.

    A · A' = 0은 AND 연산에서 A와 A'가 동시에 선택되는 경우가 없으므로 결과는 0이 된다. 따라서 A · A' = 0이 성립한다.

    A + A' = 1은 OR 연산에서 A와 A' 중 적어도 하나가 선택되는 경우가 있으므로 결과는 1이 된다. 따라서 A + A' = 1이 성립한다.
1
