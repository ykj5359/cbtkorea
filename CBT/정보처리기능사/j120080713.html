7. 2진수 10110을 1의 보수(1'complement)로 표현한 것은?

  3. 00110
  4. 01001
(정답률: 86%)

    1의 보수란, 모든 비트를 반전시킨 것입니다. 따라서 2진수 10110의 1의 보수는 다음과 같이 계산할 수 있습니다.

    1. 2진수 10110의 각 비트를 반전시킵니다.

  1. fetch cycle → instruction decoding cycle → write-back 작업 → 명령어 실행단계

  3. fetch cycle → write-back 작업 → 명령어 실행단계 → instruction decoding cycle

    2023-04-12 22:59
