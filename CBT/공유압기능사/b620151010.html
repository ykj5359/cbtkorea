(정답률: 79%)

4. 그림의 실린더는 피스톤 단면적(A)이 20[cm2], 행정거리(s) 는 10[cm]이다. 이 실린더가 전진행정을 1분 동안에 마치려면 필요한 공급유량은 약 몇 [cm3/sec] 인가?

  1. 1.1
  2. 2.2
  3. 3.3
  4. 4.4
(정답률: 60%)
  • 30 CBT 기출문제AI

    2023-04-12 12:35

14. 동력에 관한 설명으로 옳은 것은?

  1. 작용한 힘의 크기와 움직인 거리의 곱이다.
  2. 작용한 힘의 크기와 움직이는 속도의 곱이다.
  3. 작용한 압력의 크기와 움직인 거리의 곱이다.
  4. 작용한 압력의 크기와 움직이는 속도의 곱이다.
(정답률: 58%)
  • 30 CBT 기출문제AI

    2023-04-12 12:35

    동력은 물체를 움직이는 힘의 크기와 방향을 나타내는 물리량입니다. 따라서 작용한 힘의 크기와 움직이는 속도의 곱이 동력이 되는 것입니다. 이는 뉴턴의 제2법칙인 F=ma에서 유도됩니다. F는 힘, m은 물체의 질량, a는 가속도를 나타내는데, 가속도는 속도의 변화율이므로 F=m(v/t)입니다. 이를 정리하면 Fv=mv^2/t가 되는데, mv^2/t는 물체의 운동에너지를 나타내므로, Fv는 물체의 동력이 됩니다.

36. RL 병렬 회로에 100∠0°[V]의 전압이 가해질 경우에 흐르는 전체 전류(I)은 몇 [A]인가? (단, R=100[Ω], ωL=100[Ω] 이다.)

  1. 1
  2. 2
  3. √2
  4. 100
(정답률: 53%)
  • 30 CBT 기출문제AI

    2023-04-12 12:35

    전압과 저항의 관계식인 V=IR을 이용하여 전류를 구할 수 있습니다.
    전압 V는 병렬 회로이므로 각각의 저항에 동일하게 가해지며, 전류 I는 각각의 저항을 통해 흐르게 됩니다.
    따라서, 전압 V를 각각의 저항 R과 ωL에 대해 계산해보면 다음과 같습니다.

    V_R = 100∠0°[V]
    V_L = 100∠90°[V]

    여기서, ωL은 인덕턴스를 나타내는 값으로, 전압과의 위상차가 90도입니다.

    각각의 전압에 대해 전류를 구해보면 다음과 같습니다.

    I_R = V_R / R = 100∠0°[V] / 100[Ω] = 1∠0°[A]
    I_L = V_L / ωL = 100∠90°[V] / 100[Ω] = 1∠90°[A]

    여기서, I_L은 전압과의 위상차가 90도이므로, 전류가 전압보다 90도 뒤쳐지는 것을 나타냅니다.

    전체 전류 I는 각각의 전류가 벡터합되어 구해지므로, 다음과 같습니다.

    I = √(I_R^2 + I_L^2) = √(1^2 + 1^2) = √2 [A]

    따라서, 정답은 "√2"입니다.

55. 양끝을 고정한 단면적 2[cm2]인 사각봉이 온도 -10[℃]에서 가열되어 50[℃]가 되었을 때, 재료에 발생하는 열응력은? (단, 사각봉의 탄성계수는 21[GPa], 선팽창계수는 12×10-6[/℃] 이다.)

  1. 15.1[MPa]
  2. 25.2[MPa]
  3. 29.9[MPa]
  4. 35.8[MPa]
(정답률: 27%)
  • 30 CBT 기출문제AI

    2023-04-12 12:35

    먼저, 열응력을 구하기 위해서는 먼저 재료의 선형팽창계수를 이용하여 길이 변화량을 구해야 합니다. 이 경우, 선형팽창계수는 12×10-6[/℃] 이므로, 온도가 40[℃] 상승하였으므로, 길이 변화량은 다음과 같이 구할 수 있습니다.

    ΔL = LαΔT = (1m)(12×10-6[/℃])(40[℃]) = 0.0048[m]

    다음으로, 길이 변화량을 이용하여 변형률을 구할 수 있습니다. 이 경우, 사각봉의 단면적은 2[cm2] 이므로, 부피 변화량은 다음과 같이 구할 수 있습니다.

    ΔV = ΔL×A = (0.0048[m])(2×10-4[m2]) = 9.6×10-8[m3]

    변형률은 부피 변화량을 원래 부피로 나눈 값으로 구할 수 있습니다. 이 경우, 사각봉의 길이는 1[m] 이므로, 원래 부피는 다음과 같이 구할 수 있습니다.

    V = AL = (2×10-4[m2])(1[m]) = 2×10-4[m3]

    따라서, 변형률은 다음과 같이 구할 수 있습니다.

    ε = ΔV/V = (9.6×10-8[m3])/(2×10-4[m3]) = 0.00048

    마지막으로, 열응력을 구하기 위해서는 재료의 탄성계수를 이용하여 응력을 구해야 합니다. 이 경우, 탄성계수는 21[GPa] 이므로, 열응력은 다음과 같이 구할 수 있습니다.

    σ = Eε = (21×109[Pa])(0.00048) = 10,080[Pa] = 10.08[MPa]

    따라서, 온도가 40[℃] 상승하였을 때, 재료에 발생하는 열응력은 10.08[MPa] 입니다.
