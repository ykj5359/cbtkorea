    Huff 모델에서 각 점포의 선택확률은 다음과 같이 계산된다.

    선택확률 = (점포 크기)^α / Σ(모든 점포의 크기^α)

    여기서 α는 소비자가 부여하는 점포 크기에 대한 가중치이다. 이 문제에서는 α=1로 가정한다.

    따라서 각 점포의 선택확률은 다음과 같다.

    A의 선택확률 = 1 / (1^1 + 2^1 + 3^1) = 0.1667
    B의 선택확률 = 2 / (1^1 + 2^1 + 3^1) = 0.3333
    C의 선택확률 = 3 / (1^1 + 2^1 + 3^1) = 0.5000

    이제 각 점포까지의 거리에 대한 가중치를 고려하여 각 점포의 선택확률을 조정한다. 이 문제에서는 거리에 대한 가중치가 -2이므로 거리가 멀수록 선택확률이 작아진다.

    A의 최종 선택확률 = 0.1667 * exp(-2*1) = 0.0498
    B의 최종 선택확률 = 0.3333 * exp(-2*2) = 0.0452
    C의 최종 선택확률 = 0.5000 * exp(-2*3) = 0.0677

90. 정보의 유용성을 판별하기 위한 판단기준에 대한 설명으로 가장 옳지 않은 것은?

  1. 적시성 : 정보가 의사결정자에게 의미를 갖도록 적시에 제공될 수 있어야 한다.
  2. 적합성 : 의사결정에 적합하지 않은 데이터가 데이터베이스에 있어서는 안 된다.
  3. 신뢰성 : 데이터의 기밀성을 확인해야 한다.
  4. 비용효율성 : 데이터의 획득에 소요되는 비용과 그 가치에 대해 평가가 필요하다.
  5. 비교가능성 : 적합성이 확보된 다른 정보와 비교할 수 있어야 한다.
