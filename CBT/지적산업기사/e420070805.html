    보정식은 다음과 같다.

    보정된 지상거리 = 측정된 지상거리 + (폐합오차 / 변의 길이)

    보정된 지상거리 = 측정된 지상거리 + (폐합오차 / 변의 길이)
    = 측정된 지상거리 + (1 / 5)
    = 6 + 0.2
    = 6.2m

9. 앨리데이드를 이용하여 두 점간의 경사거리와 경사분획을 측정한 결과 경사거리 80m, 경사분획 + 15.5인 경우 두 점간의 수평거리는 얼마인가?

  1. 79.1m
  2. 79.5m
  3. 78.5m
  4. 78.1m
(정답률: 65%)
  • 30 CBT 기출문제AI

    2023-04-18 13:38

    앨리데이드를 이용하여 측정한 경사거리와 경사분획은 다음과 같은 관계식을 가진다.

    경사분획 = 경사각 tan(θ) × 100

    따라서, 경사각은 다음과 같이 구할 수 있다.

    경사각 tan(θ) = 경사분획 / 100

    또한, 경사거리와 수평거리, 그리고 경사각은 다음과 같은 관계식을 가진다.

    경사거리 = 수평거리 × tan(θ)

    따라서, 수평거리는 다음과 같이 구할 수 있다.

    수평거리 = 경사거리 / tan(θ)

    문제에서 주어진 경사거리는 80m이고, 경사분획은 +15.5이다. 따라서, 경사각은 다음과 같이 구할 수 있다.

    경사각 tan(θ) = 15.5 / 100 = 0.155

    수평거리는 다음과 같이 구할 수 있다.

    수평거리 = 80 / tan(0.155) ≈ 79.1m

    따라서, 정답은 "79.1m"이다.

32. 단곡선에서 교각 I = 36°20′반경 R = 500m 노선의 기점에서 교점 (IP) 까지의 거리는 6500m 이다. 20m 간격으로 중심말뚝을 설치 할때 종단현의 길이 (ℓ2)는?

  1. 11m
  2. 12m
  3. 13m
  4. 15m
(정답률: 알수없음)

    단곡선에서 교각의 중심각은 36°20′ 이므로, 이를 호의 길이로 변환하면 다음과 같다.

    36°20′ = 36.3333°
    = 36.3333 × π / 180 (라디안으로 변환)
    = 0.6349 rad

    따라서 교각의 호의 길이는 다음과 같다.

    l = Rθ
    = 500 × 0.6349
    = 317.45m

    d = 6500 - l
    = 6500 - 317.45
    = 6182.55m

    ℓ2 = (n - 1) × 20 + 2d

    = 20n + 12345.1

    20n + 12345.1 = 13
