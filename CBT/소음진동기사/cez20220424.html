3. 80dB(A)의 소음도에 7시간, 70dB(A)의 소음도에 3시간 노출된 지점의 등가 소음도는 약 몇 dB(A)인가?

  2. 79
  3. 81
  4. 82
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-16 08:41

    등가 소음도는 소음의 지속 시간과 강도에 따라 계산됩니다. 따라서, 80dB(A)의 소음도에 7시간 노출된 경우 등가 소음도는 80dB(A)이고, 70dB(A)의 소음도에 3시간 노출된 경우 등가 소음도는 73dB(A)입니다.

    등가 소음도는 다음과 같이 계산됩니다.

    L_eq = 10log10[(T1/10)^(L1/10) + (T2/10)^(L2/10) + ... + (Tn/10)^(Ln/10)]

    여기서,
    L_eq = 등가 소음도 (dB(A))
    T = 소음이 지속된 시간 (시간)
    L = 소음의 강도 (dB(A))
    n = 소음이 발생한 횟수

    따라서,

    L_eq = 10log10[(7/10)^(80/10) + (3/10)^(70/10)]
    = 10log10[(0.1995) + (0.5012)]
    = 10log10[0.7007]
    = 79 dB(A)

    따라서, 정답은 "79"입니다.

    금속스프링의 질량을 고려한 시스템의 고유진동수(fn)는 다음과 같이 계산할 수 있다.

    fn = (1/2π) x √(k/M_eff)

    여기서 M_eff는 시스템의 등가질량(equivalent mass)으로, 다음과 같이 계산할 수 있다.

    M_eff = M + m/3

    fn = (1/2π) x √(k/(M + m/3))
