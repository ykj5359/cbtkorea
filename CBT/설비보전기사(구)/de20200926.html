2. 다음 안정도 판별법에 관한 설명에서 ( ) 안에 들어갈 알맞은 값은?

  1. 180°
  2. 360°
  3. -180°
  4. -360°
(정답률: 65%)
  • 30 CBT 기출문제AI

    2023-04-16 07:24

    주어진 안정도 판별식에서 분모의 값이 0이 되는 경우 안정도 판별이 불가능하다. 따라서, 분모의 값이 0이 되는 각도를 구하면 된다. 이를 계산하면 -180°이므로 정답은 "-180°"이다.

    이유는 분모의 값이 0이 되는 경우는 다음과 같다.

    - Kp*Kd - Ki*Kp*G(s) = 0
    - Kp*Kd - Ki*Kp*(s^2 + 2ζωns + ωn^2) = 0

    위 식에서 ωn과 ζ는 각각 감쇠진동수와 감쇠비를 나타내며, 이 값들은 시스템의 특성을 결정하는 중요한 요소이다. 이 값들을 구하고, 위 식에 대입하여 분모의 값을 계산하면 -180°이 나오게 된다. 이는 시스템이 고차항 시스템일 때, 안정도 판별식이 복잡해지는 것을 보여준다.

16. 질량과 스프링으로 이루어진 1자유도계 진동시스템에서 스프링의 정적 처짐이 3mm인 경우, 이 시스템의 고유 진동 주파수[Hz]는? (단, g = 9.81 m/sec2 이다.)

  2. 3.27
  3. 9.10
  4. 57.18
(정답률: 57%)
  • 30 CBT 기출문제AI

    2023-04-16 07:24

    고유 진동 주파수는 다음과 같이 계산할 수 있다.

    ω = √(k/m)

    여기서 k는 스프링 상수이고, m은 질량이다. 정적 처짐이 3mm인 경우, 스프링의 변위에 의한 힘은 다음과 같다.

    F = kx = k(0.003)

    이 힘은 중력과 평형을 이루므로, 다음과 같은 식이 성립한다.

    mg = k(0.003)

    여기서 g는 중력가속도이다. 따라서 스프링 상수는 다음과 같다.

    k = mg/0.003 = 9.81 × 0.1 / 0.003 = 327 N/m

    질량은 문제에서 주어지지 않았으므로, 일반적인 기호로 m으로 나타내자. 이제 고유 진동 주파수는 다음과 같다.

    ω = √(k/m) = √(327/m)

    단위를 맞추기 위해 m을 kg으로 바꾸면,

    ω = √(327/m) = √(327/0.001m) = √(327000/m) rad/s

    주파수로 바꾸기 위해 2π를 곱하고, Hz로 나타내기 위해 1/2π를 곱하면,

    f = ω/2π = √(327000/m) / 2π ≈ 9.10 Hz

    따라서 정답은 "9.10"이다.
