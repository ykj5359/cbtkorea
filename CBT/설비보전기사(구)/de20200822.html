14. 액면이 높이가 h[m], 배관의 면적이 A[m2], 액체의 비중량이 γ[N/m3] 일 때 배관을 빠져나오는 유량 Q[m3/s]는? (단, g는 중력가속도[m/s2]이다.)

(정답률: 61%)
  • 30 CBT 기출문제AI

    2023-04-16 07:24

    이 문제는 베르누이 방정식을 이용하여 풀 수 있다. 베르누이 방정식은 유체의 운동에 대한 기본적인 방정식으로, 유체의 속도, 압력, 밀도 등을 고려하여 유체의 운동을 설명한다.

    베르누이 방정식은 다음과 같다.

    P1 + 1/2ρv12 + ρgh1 = P2 + 1/2ρv22 + ρgh2

    여기서 P는 압력, ρ는 밀도, v는 속도, h는 높이를 나타낸다. 1번 지점은 배관의 입구, 2번 지점은 배관의 출구를 나타낸다.

    이 문제에서는 유량을 구하는 것이 목적이므로, 베르누이 방정식을 다음과 같이 변형하여 사용한다.

    Q = Av

    여기서 Q는 유량, A는 배관의 면적, v는 유체의 속도를 나타낸다.

    따라서, 유량을 구하기 위해서는 먼저 유체의 속도를 구해야 한다. 이를 위해 베르누이 방정식을 사용하여 다음과 같이 유체의 속도를 구한다.

    P1 + 1/2ρv12 + ρgh1 = P2 + 1/2ρv22 + ρgh2

    여기서 P1은 대기압이므로 0으로 생략할 수 있다. 또한, 배관의 입구와 출구가 연결되어 있으므로 h1 = h2이다. 따라서 위 식은 다음과 같이 간소화된다.

    1/2ρv12 = P2 - P1

    여기서 P2는 액체의 압력이고, P1은 대기압이므로 P2 = γh이다. 따라서 위 식은 다음과 같이 변형된다.

    1/2ρv12 = γh

    여기서 v1은 유체의 입구에서의 속도이므로, 다음과 같이 구할 수 있다.

    v1 = √(2γh/ρ)

    이제 유량을 구하기 위해 Q = Av를 사용하면 된다. 따라서 유량은 다음과 같이 구할 수 있다.

    Q = A√(2γh/ρ)

    이때, 보기에서 정답이 "" 인 이유는, 유량은 배관의 면적에 비례하므로 A가 커질수록 유량도 커진다. 따라서 A가 2배가 되면 유량도 2배가 된다.
