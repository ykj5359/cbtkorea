  1. Pm = (LVS) / (6120η)
  2. Pm = (ηVS) / (6120L)

  4. Pm = (LVSη) / 6120
(정답률: 68%)

2. 엘리베이터 정격속도가 90[m/min]의 피트 깊이는 최소 몇 [m]인가?(오류 신고가 접수된 문제입니다. 반드시 정답과 해설을 확인하시기 바랍니다.)

  1. 1.2[m]
  2. 1.8[m]
  3. 2.1[m]
  4. 2.4[m]
(정답률: 69%)
  • 30 CBT 기출문제AI

    2023-04-12 15:28

    엘리베이터의 정격속도가 90[m/min]이므로 1분에 90미터를 이동할 수 있습니다. 이를 초속으로 환산하면 1.5[m/s]입니다.

    엘리베이터가 움직이는 동안 중력가속도로 인해 속도가 감소하게 되는데, 이 감속도는 9.8[m/s^2]입니다. 따라서 최대한 빠르게 정지하려면 감속거리가 충분해야 합니다.

    감속거리는 다음과 같이 계산할 수 있습니다.

    감속거리 = (감속시간)^2 x (감속도) / 2

    여기서 감속시간은 엘리베이터가 정지하기 위해 걸리는 시간입니다. 이 시간은 엘리베이터의 길이에 비례하므로, 엘리베이터의 길이를 L이라고 하면 감속시간은 2L/1.5입니다.

    따라서 감속거리를 구하면 다음과 같습니다.

    감속거리 = (2L/1.5)^2 x 9.8 / 2

    이 값을 최소화하기 위해 감속거리를 미분하면 다음과 같습니다.

    d(감속거리)/dL = 8L/1.5 x 9.8 / 2 = 26.13L

    이 값이 0이 되도록 하는 L이 최소 감속거리를 가지는 L입니다. 따라서 L = 0이거나 L = 무한대일 때 감속거리는 최소가 됩니다.

    L = 0은 엘리베이터가 없다는 뜻이므로, L = 무한대일 때 감속거리가 최소가 됩니다. 이 경우 감속거리는 무한대가 되므로, 엘리베이터의 길이는 무한대가 되어야 합니다.

    하지만 현실적으로는 엘리베이터의 길이는 유한하기 때문에, 감속거리를 충분히 확보하기 위해 엘리베이터의 길이를 적절히 늘려야 합니다.

    실제로는 엘리베이터의 길이가 1.8[m] 정도면 충분히 감속거리를 확보할 수 있습니다. 따라서 정답은 1.8[m]입니다.
