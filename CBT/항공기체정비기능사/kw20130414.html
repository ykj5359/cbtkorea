7. 날개 면적이 80m2, 무게가 7500kgf 인 비행기가 밀도 1/8kgfㆍs2/m4 인 해면고도를 수평 비행할 때, 비행 속도는 몇 m/s 인가? (단, 양력계수는 0.15 이다.)

  1. 80
  2. 100
  3. 120
  4. 150
(정답률: 48%)
  • 30 CBT 기출문제AI

    2023-04-13 13:28

    비행기의 양력은 다음과 같이 계산할 수 있다.

    양력 = 1/2 x 밀도 x 비행기의 면적 x 비행 속도의 제곱 x 양력계수

    양력과 중력이 평형을 이루기 때문에, 양력과 중력이 같아지는 비행 속도를 구하면 된다.

    중력 = 비행기의 무게 = 7500kgf

    중력 = 양력

    양력 = 1/2 x 밀도 x 비행기의 면적 x 비행 속도의 제곱 x 양력계수

    7500 = 1/2 x 1/8 x 80 x 비행 속도의 제곱 x 0.15

    비행 속도의 제곱 = 7500 / (1/2 x 1/8 x 80 x 0.15) = 100000

    비행 속도 = √100000 = 316.23 ≈ 316 (단위: m/s)

    따라서, 정답은 316이지만, 보기에서 가장 가까운 값은 100이므로 정답은 100이다.
1

8. 공기 중에서 50kgf 항력을 받으며 면적이 8m2 인 물체가 일정한 속도 10 m/s 로 떨어지고 있을 때 물체가 갖는 항력계수는 얼마인가? (단, 공기의 밀도는 0.1kgfㆍs2/m4 이다.)

  1. 1.0
  2. 1.15
  3. 1.25
  4. 1.75
(정답률: 70%)
  • 30 CBT 기출문제AI

    2023-04-13 13:28

    항력력은 다음과 같이 계산할 수 있습니다.

    항력력 = 1/2 x 공기밀도 x 면적 x 속도의 제곱 x 항력계수

    문제에서 주어진 값들을 대입하면 다음과 같습니다.

    50kgf = 1/2 x 0.1kgfㆍs^2/m^4 x 8m^2 x 10m/s^2 x 항력계수

60. 항공기 구조부재 중 지름이 20cm, 길이가 320cm 인 원형기둥의 세장비는?

  1. 64
  2. 75
  3. 100
  4. 125
(정답률: 39%)
  • 30 CBT 기출문제AI

    2023-04-13 13:28

    원형기둥의 부피는 πr²h 이므로, 반지름(r) = 10cm, 높이(h) = 320cm 일 때 부피를 구하면 다음과 같습니다.

    부피 = πr²h = 3.14 x 10² x 320 ≈ 100,480 (cm³)

    세장비는 부피를 1/3로 줄이는 작업을 3번 반복하는 것이므로, 부피에 1/3을 곱하는 것을 3번 반복한 값이 세장비의 부피가 됩니다.

    세장비의 부피 = 부피 x (1/3)³ = 100,480 x (1/27) ≈ 64

    따라서, 정답은 "64" 입니다.
