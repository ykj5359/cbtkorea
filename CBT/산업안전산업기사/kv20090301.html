    재해발생 구성비율은 전체 재해발생 건수를 기준으로 각각의 구성요소가 차지하는 비율을 나타낸다. 따라서 중상해가 5건 발생했다는 것은 전체 재해발생 건수에서 중상해가 차지하는 비율을 구할 수 있다.

    전체 재해발생 건수가 몇 건인지는 문제에서 주어지지 않았으므로 정확한 답을 구할 수는 없다. 하지만 보기에서 "1500건"이 정답으로 주어졌으므로, 이는 전체 재해발생 건수가 100건일 때 중상해가 5건이 발생한 경우를 15배로 확대한 것이다. 따라서 무상해사고는 95%에 해당하는 1500건이 된다.

13. 강도율이 5.5라 함은 연근로시간 몇 시간 중 재해로 인한 근로손실이 110일 발생하였음을 의미하는가?

  2. 20000
  3. 50000
  4. 100000
(정답률: 59%)
  • 30 CBT 기출문제AI

    2023-04-16 ⑤:17

    강도율은 근로자 1명당 발생한 근로손실일수를 나타내는 지표이다. 따라서 강도율이 5.5라 함은 근로자 1명당 평균 5.5일의 근로손실이 발생했다는 것을 의미한다. 이를 토대로 연근로시간을 계산하면 다음과 같다.

    1인당 근로손실일수 = 5.5일
    총 근로자 수 = x명
    총 근로일수 = 110일

    따라서, x = 110일 / 5.5일 = 20명

    연근로시간 = 근로자 수 x 근로일수 x 8시간 = 20명 x 110일 x 8시간 = 17,600시간

    하지만, 문제에서는 연근로시간이 몇 시간 중이라고 했으므로, 17,600시간을 24시간으로 나누어 계산해야 한다.

    연근로시간 = 17,600시간 / 24시간 = 733.33시간

    따라서, 연근로시간이 733.33시간이므로, 가장 가까운 보기인 "20000"이 정답이 된다.

    n(H2) = P × V(H2) / (R × T) × 0.3

    n(N2) = P × V(N2) / (R × T) × 0.5

    n = n(H2) + n(O2) + n(N2)

    V = V(H2) + V(O2) + V(N2)
