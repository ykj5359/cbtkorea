6. 어떤 작업에 대한 평균에너지 값이 4.7kcal/분 일 경우 1시간의 총 작업시간 내에 포함시켜야만 하는 휴식 시간은 약 얼마인가? (단, 작업에 대한 평균 에너지가의 상한은 4kcal/분이다.)

  1. 3.86분
  2. 7.23분
  3. 10.11분
  4. 13.13분
(정답률: 35%)
  • 30 CBT 기출문제AI

    2023-04-16 ⑤:21

    작업에 대한 평균 에너지 값이 4.7kcal/분이고, 상한이 4kcal/분이므로 작업 중에는 4kcal/분으로 가정한다. 1시간은 60분이므로, 작업에 소요되는 총 에너지는 4kcal/분 x 60분 = 240kcal 이다. 이 작업을 수행하는 동안 휴식을 취하지 않으면, 작업 중에도 계속해서 에너지를 소비하게 되므로 작업 중간에 휴식을 취해야 한다. 이때, 휴식 시간 동안에도 일정한 에너지가 소비되므로, 휴식 시간이 길어질수록 총 에너지 소비량이 증가하게 된다. 따라서, 휴식 시간이 적당한 길이여야 한다.

    휴식 시간을 x 분이라고 가정하면, 작업 시간은 (60 - x) 분이 된다. 작업 시간 동안 소비되는 총 에너지는 4kcal/분 x (60 - x)분 = 240 - 4x kcal 이다. 이때, 휴식 시간 동안 소비되는 에너지는 4.7kcal/분 x x분 = 4.7x kcal 이다. 따라서, 총 에너지 소비량은 240 - 4x + 4.7x = 240 + 0.7x kcal 이 된다.

    휴식 시간이 적당한 길이여야 하므로, 총 에너지 소비량이 최소가 되는 x 값을 찾으면 된다. 이를 위해, 총 에너지 소비량을 x에 대한 함수로 나타내면 다음과 같다.

    f(x) = 240 + 0.7x

    이 함수의 최솟값을 구하기 위해, 미분을 하여 f'(x) = 0 인 x 값을 찾으면 된다.

    f'(x) = 0.7

    f(8) = 245.6 kcal
    f(9) = 246.3 kcal
