26. 건강한 남성이 8시간 동안 특정 작업을 실시하고, 분당 산소 소비량이 1.1L/분으로 나타났다면 8시간 총 작업시간에 포함될 휴식시간은 약 몇 분인가? (단, Murrell의 방법을 적용하며, 휴식 중 에너지소비율은 1.5kcal/min이다.)

  1. 30분
  2. 54분
  3. 60분
  4. 75분
(정답률: 59%)
  • 30 CBT 기출문제AI

    2023-04-16 ⑤:06

    Murrell의 방법에 따르면, 총 작업시간에서 휴식시간을 뺀 시간 동안의 에너지 소비량은 일정하다고 가정한다. 따라서, 총 작업시간 동안 소비한 에너지와 휴식 중 소비한 에너지의 합이 전체 에너지 소비량과 같아진다.

    8시간 동안 분당 산소 소비량이 1.1L/분이므로, 총 산소 소비량은 8시간 x 60분/시간 x 1.1L/분 = 528L이다.

    휴식 중 에너지 소비율이 1.5kcal/min이므로, 휴식시간 x 1.5kcal/min = 전체 에너지 소비량 - 작업 중 에너지 소비량이다.

    따라서, 휴식시간 = (전체 에너지 소비량 - 작업 중 에너지 소비량) / 1.5kcal/min = (528L x 5kcal/L - 8시간 x 60분/시간 x 1.1L/분) / 1.5kcal/min = 60분이다.

    따라서, 정답은 "60분"이다.
