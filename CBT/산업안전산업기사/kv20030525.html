42. 크레인 작업시 2ton의 중량을 걸어 20m/s2 가속도로 감아올릴 때 로프에 걸리는 총 하중은?

  1. 5,998kg
  2. 6,000kg
  3. 6,082kg
  4. 6,112kg
(정답률: 50%)
  • 30 CBT 기출문제AI

    2023-04-16 ⑤:25

    크레인 작업시 로프에 걸리는 총 하중은 물체의 중량과 중력가속도, 그리고 로프에 걸린 힘의 합이다. 따라서 이 문제에서는 다음과 같이 계산할 수 있다.

    물체의 중량 = 2ton = 2000kg
    중력가속도 = 9.8m/s2
    감속도 = 20m/s2

    로프에 걸리는 총 하중 = 물체의 중량 + 물체의 운동에너지를 제공하기 위해 필요한 힘
    물체의 운동에너지 = 1/2 x 물체의 질량 x 속도의 제곱
    물체의 최종 속도 = 감속도 x 시간
    시간 = 물체의 최종 속도 / 감속도

    물체의 운동에너지 = 1/2 x 2000kg x (20m/s)2 = 400,000J
    물체의 최종 속도 = 20m/s2 x (20m/s / 20m/s2) = 20m/s
    시간 = 20m/s / 20m/s2 = 1s

    따라서 로프에 걸리는 총 하중은 다음과 같다.

    로프에 걸리는 총 하중 = 2000kg x 9.8m/s2 + 400,000J / 1s
    = 19,600N + 400,000N
    = 419,600N
    = 42,750kgf

    하지만 이 문제에서는 단위가 kgf가 아닌 kg으로 주어졌기 때문에, kgf를 kg으로 변환해줘야 한다.

    1kgf = 9.8N
    42,750kgf = 42,750kgf x 9.8N/kgf = 419,550N = 42,750kg

    따라서 로프에 걸리는 총 하중은 6,082kg이 된다.

    아브가드로의 법칙은 "같은 온도와 압력에서 같은 부피의 기체는 같은 분자수를 가진다"는 것이다. 따라서, SO2의 분자수는 변하지 않고, 부피만 변하므로, 다음과 같은 식을 사용할 수 있다.

    (V1/V2) = (n1/n2)

    V2 = (V1 x T2) / T1

    = 1,000kg/m3 × 9.8m/s2 × 2m
