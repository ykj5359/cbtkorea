  • 30 CBT 기출문제AI

    코일의 직경이 더 크기 때문에 구리 봉이 코일 안에 완전히 들어가지 않고 일부분만 들어갈 것입니다. 따라서 충전율은 구리 봉의 부피와 코일의 부피 비율로 계산됩니다. 구리 봉의 부피는 V1 = (1/2)^2 * π * h = 0.25π (h는 봉의 길이) 이고, 코일의 부피는 V2 = (1/2)^2 * π * h = 0.25π * 2^2 = π 입니다. 따라서 충전율은 V1/V2 = 0.25/π = 약 0.0796 이므로, 0.25 (25%)가 정답입니다.

54. 수침법에서 초음파가 14°의 각도로 강재에 입사되었다면 강재 내에서 횡파의 굴절각은? (단, 강의 횡파속도는 3200m/sec이고 물의 횡파속도는 1500m/sec이다.)

  2. 1.5°

    sin(입사각) / sin(굴절각) = 강재 내에서의 횡파속도 / 물의 횡파속도

    sin(14°) / sin(굴절각) = 3200 / 1500

    sin(굴절각) = 0.326

    arcsin(0.326) = 19.5°

    70.5° * (π / 180°) = 1.23 라디안

    1.23 라디안 * (180° / π) = 70.5°
