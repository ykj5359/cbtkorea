15. 인장시험에서 10mm의 강봉을 초점거리 50mm로 표시한 후, 시험편을 시험 후 측정하였더니 표점이 60mm가 되었다. 이때의 강도와 연신율은? (단, 최대하중은 10톤으로 측정되었다,)

  1. 127.3 kgf/mm2, 20%
  2. 133 kgf/mm2, 15%
  3. 127.3 kgf/mm2, 10%
  4. 31.8 kgf/mm2, 20%
(정답률: 55%)
  • 30 CBT 기출문제AI

    2023-04-18 18:07

    인장강도 = 최대하중 / 단면적

    단면적을 구하기 위해서는 강봉의 지름이 필요하다. 지름은 10mm 이므로 반지름은 5mm이다.

    단면적 = π x 반지름^2 = 3.14 x 5^2 = 78.5 mm^2

    따라서, 인장강도 = 10톤 / 78.5mm^2 = 127.3 kgf/mm^2

    연신율은 (시험편의 길이 - 원래 길이) / 원래 길이 x 100 으로 구할 수 있다.

    연신율 = (60mm - 50mm) / 50mm x 100 = 20%

    따라서, 정답은 "127.3 kgf/mm^2, 20%" 이다.

18. 용접전류가 400A, 아크 전압은 35V, 용접속도가 20cm/min 일 때 단위 길이당 용접 입열은 몇 J/cm인가?

  2. 12500
  3. 44000
  4. 45500

    2023-04-18 18:07

    용접 입열은 다음과 같이 계산할 수 있다.

    용접 입열 = 용접전류 x 아크 전압 x 용접속도 / 1000

    여기에 주어진 값들을 대입하면,

    용접 입열 = 400 x 35 x 20 / 1000 = 280 J/cm

    Q=V*I*60/S
    Q=35*400*60/20
    42000J/cm
