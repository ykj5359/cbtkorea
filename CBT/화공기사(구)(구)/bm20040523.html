8. 50kg의 강철주물(비열 0.12kcal/kg℃)이 600℃로 가열되었다. 이것을 25℃의 기름(비열 0.6kcal/kg℃) 200kg중에집어넣었다. 주위와 온도는 단열되었으며, 주물의 최종온도는 52.4℃였다. 전체 엔트로피 변화는 얼마인가?

  1. 4.63kcal/K
  2. 5.92kcal/K
  3. 10.56kcal/K
  4. 16.48kcal/K
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-18 03:44

    전체 엔트로피 변화는 다음과 같이 계산할 수 있다.

    ΔS = ΔS1 + ΔS2

    여기서 ΔS1은 강철주물의 엔트로피 변화이고, ΔS2는 기름의 엔트로피 변화이다.

    ΔS1 = (50kg) × (0.12kcal/kg℃) × ln[(52.4℃ + 273K)/(600℃ + 273K)] = -2.98kcal/K

    기름의 엔트로피 변화는 다음과 같이 계산할 수 있다.

    ΔS2 = (200kg) × (0.6kcal/kg℃) × ln[(52.4℃ + 273K)/(25℃ + 273K)] = 7.61kcal/K

    따라서 전체 엔트로피 변화는 다음과 같다.

    ΔS = ΔS1 + ΔS2 = -2.98kcal/K + 7.61kcal/K = 4.63kcal/K

    따라서 정답은 "4.63kcal/K"이다.

  2. 166.6ℓ
  3. 146.6ℓ
  4. 122.5ℓ
(정답률: 알수없음)

    2023-04-18 03:44

    이 문제는 혼합 반응기의 용적을 구하는 문제이다. 용적을 구하기 위해서는 먼저 반응식과 반응속도식을 구해야 한다.

    반응식은 A가 R과 S로 분해되는 과정으로 다음과 같다.

    A → R + S

    분해 반응은 1차 반응으로 가정하면, 반응속도식은 다음과 같다.

    r = k[A]

    여기서 k는 속도상수이다. 이제 이 반응속도식을 이용하여 용적을 구해보자.

    F_A = C_A*V = 0.1*1000 = 100 mol/hr

    반응속도식에서 A의 소모율은 -r이므로, R의 생성율은 r이다. 따라서 R의 유량은 다음과 같다.

    F_R = r*V = k[C_A]*V

    여기서 k[C_A]는 A의 소모율이므로, A의 유량과 같다. 따라서 F_R = F_A = 100 mol/hr이다.

    C_R = F_R/V = F_A/V = 100/V mol/L

    k[C_A]V = F_A = 0.2*1000 = 200 mol/hr

    따라서 V는 다음과 같다.

    V = F_A/(k[C_A]) = 100/(0.2) = 500ℓ

    따라서 혼합 반응기의 용적은 500ℓ이다.

119. 물 72kg에 HCl 가스 36.5kg을 용해 시켰을 때 이 HCl의 농도는?

  1. 43.64%
  2. 33.64%
  3. 23.64%
  4. 13.64%
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-18 03:42

    HCl의 몰 질량은 36.5g/mol입니다. 따라서 36.5kg의 HCl은 몇 몰인지 계산해보면:

    36.5kg / 36.5g/mol = 1000 mol

    물의 질량은 72kg이므로, 이 용액의 총 질량은 72kg + 36.5kg = 108.5kg입니다.

    따라서 HCl의 농도는:

    1000 mol / 108.5kg = 9.217 mol/kg

    이 됩니다. 이 값을 백분율로 환산하면:

    9.217 mol/kg × 36.5 g/mol × 100% = 33.64%

    따라서 정답은 "33.64%"입니다.
