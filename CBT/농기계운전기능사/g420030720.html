2. 4실린더 기관의 안지름이 100㎜, 행정이 100㎜, 회전수가 2000rpm일 때 분당 총 배기량은? (단, 4행정식 기관임)

  1. 1256000cm3/min
  2. 2512000cm3/min
  3. 3140000cm3/min
  4. 4230000cm3/min
(정답률: 56%)
  • 30 CBT 기출문제AI

    2023-04-12 13:51

    한 실린더의 배기량은 다음과 같이 계산할 수 있습니다.

    한 실린더의 배기량 = (안지름/2)^2 x 행정 x 3.14

    = (50)^2 x 100 x 3.14

    = 785,000mm^3

    따라서 4실린더 기관의 한 회전당 총 배기량은 다음과 같습니다.

    한 회전당 총 배기량 = 한 실린더의 배기량 x 실린더 수

    = 785,000mm^3 x 4

    = 3,140,000mm^3

    분당 총 배기량은 회전수에 따라 달라지므로, 2000rpm일 때 분당 총 배기량은 다음과 같습니다.

    분당 총 배기량 = 한 회전당 총 배기량 x 회전수

    = 3,140,000mm^3 x 2000

    = 6,280,000,000mm^3/min

    이를 cm^3/min으로 변환하면 다음과 같습니다.

    6,280,000,000mm^3/min = 6,280,000cm^3/min

    따라서 정답은 "3140000cm^3/min"입니다.

15. 농업기계 구입가격이 200만원, 폐기 가격이 20만원, 내구년한이 8년이라고 할 때 연간 감가상각비를 직선법으로 구하면?

  1. 100,000원
  2. 225,000원
  3. 250,000원
  4. 275,000원
(정답률: 75%)
  • 30 CBT 기출문제AI

    2023-04-12 13:51

    직선법으로 연간 감가상각비를 구할 때는 다음과 같은 공식을 사용합니다.

    연간 감가상각비 = (구입가격 - 폐기 가격) / 내구년한

    따라서 이 문제에서는 다음과 같이 계산할 수 있습니다.

    연간 감가상각비 = (200만원 - 20만원) / 8년
    = 180만원 / 8년
    = 22.5만원

    하지만 문제에서는 감가상각비를 월 단위로 계산하라고 하지 않았으므로, 연간 감가상각비를 12로 나누어 월간 감가상각비를 구해야 합니다.

    월간 감가상각비 = 연간 감가상각비 / 12
    = 22.5만원 / 12
    = 1.875만원

    이 값을 천 단위로 반올림하여 정답을 구하면 다음과 같습니다.

    정답 = 1.875만원
    = 187,500원 (반올림)
    = 225,000원

    따라서 정답은 "225,000원"입니다.
