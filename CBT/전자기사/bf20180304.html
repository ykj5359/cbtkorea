86. 주소공간이 20 bit이고 각 주소 당 저장되는 데이터의 크기가 8bit 일 때 주기억장치의 용량은 얼마인가?

  1. 1Mbyte
  2. 2Mbyte
  3. 3Mbyte
  4. 4Mbyte
(정답률: 44%)
  • 30 CBT 기출문제AI

    2023-04-17 21:20

    20 bit의 주소공간은 2^20 개의 주소를 가질 수 있습니다. 각 주소당 8 bit의 데이터를 저장할 수 있으므로, 전체 용량은 다음과 같이 계산됩니다.

    2^20 개의 주소 x 8 bit의 데이터 = 2^20 x 8 bit = 2^23 bit

    이를 바이트 단위로 변환하면 다음과 같습니다.

    2^23 bit ÷ 8 bit/byte = 2^20 byte = 1Mbyte

    따라서, 이 주기억장치의 용량은 1Mbyte입니다.
