    E1 = Q / (2πε0a)

    여기서 ε0는 진공의 유전율이다.

    C = Q / V = Q / Ed = (2πε0a(a+d)) / d

    따라서, 점 A에 작용하는 힘을 구하기 위해서는 점 A와 점 B, 점 C 간의 거리를 구해야 한다. 정삼각형의 한 변의 길이가 0.1m 이므로, 점 A와 점 B, 점 C 간의 거리는 모두 0.1m 이다.

    F = k * q^2 / r^2

  4. 1

    볼대수식을 최소화하기 위해서는 가능한 많은 변수를 제거해야 합니다. 이를 위해서는 먼저 변수들 간의 관계를 파악해야 합니다.

    볼대수식에서 "A"와 "B"는 "BC"에 의존합니다. 즉, "BC"가 0이면 "A"와 "B"도 0이 되고, "BC"가 1이면 "A"와 "B"는 어떤 값이든 될 수 있습니다. 따라서 "A"와 "B"는 "BC"에 의존하는 변수입니다.

    따라서 "BC"를 최대한 먼저 제거해야 합니다. "BC"를 제거하기 위해서는 "BC"와 관련된 항을 모두 더해야 합니다. "BC"와 관련된 항은 "BC", "ABC", "AB'C", "A'BC", "A'B'C"입니다.

    이 중에서 "BC"와 "A'B'C"는 이미 주어진 값이므로 더 이상 제거할 수 없습니다. 따라서 "ABC"와 "AB'C", "A'BC" 중에서 하나를 선택하여 제거해야 합니다.

    여기서 "AB'C"를 선택하여 제거하면 다음과 같은 식이 됩니다.

    A'BC + ABC + BC + A'B'C
    = BC(A + A') + A'B'C
    = BC + A'B'C

    따라서 최종적으로는 "BC"와 "A'B'C"만 남게 되므로, "1"이 정답입니다.
