4. 부문별 관장기관이 생성한 국가 온실가스 배출통계를 최종확정하기까지의 절차를 순서대로 옳게 나열한 것은?

  1. ㄴ→ㄱ→ㄷ→ㄹ
  2. ㄴ→ㄷ→ㄹ→ㄱ
  3. ㄴ→ㄹ→ㄷ→ㄱ
  4. ㄱ→ㄴ→ㄹ→ㄷ
(정답률: 77%)
  • 30 CBT 기출문제AI

    2023-04-17 07:37

    ㄴ→ㄱ→ㄷ→ㄹ 순서가 옳다.

    1. 부문별 관장기관에서 각 부문의 온실가스 배출량을 집계한다. (ㄴ)
    2. 국가 온실가스 배출통계를 작성하기 위해 각 부문의 집계 결과를 통합한다. (ㄱ)
    3. 통합된 결과를 검토하고 수정한다. (ㄷ)
    4. 최종적으로 수정된 결과를 발표하고 공개한다. (ㄹ)

    이 순서가 옳은 이유는, 먼저 각 부문에서 집계된 데이터를 통합하지 않고서는 국가 전체의 온실가스 배출량을 파악할 수 없기 때문이다. 따라서 ㄴ→ㄱ 순서가 필요하다. 그리고 통합된 결과를 검토하고 수정하는 과정이 있어야 최종적으로 정확한 데이터를 발표할 수 있으므로 ㄷ→ㄹ 순서가 필요하다.
