15. 트랜지스터의 베이스접지 전류증폭률을 α 라 하면 이미터 접지의 전류증폭률 β 는 어떻게 표시되는가?

  1. β =α/α +1
  2. β =α/1-α
  3. β =α -1/α
  4. β =α +1/α
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-18 08:23

    베이스접지 전류증폭률 α는 베이스 전류의 변화에 따른 콜렉터 전류의 변화를 나타내는 값이다. 이에 비해 이미터 접지의 전류증폭률 β는 베이스 전류의 변화에 따른 에미터 전류의 변화를 나타내는 값이다.

    트랜지스터의 전류증폭은 베이스-콜렉터 접합과 베이스-에미터 접합의 이온화로 이루어진다. 이 때 베이스-콜렉터 접합의 이온화가 베이스-에미터 접합의 이온화보다 더 많이 일어나기 때문에, 베이스-콜렉터 접합의 전류증폭률 α는 베이스-에미터 접합의 전류증폭률 β보다 크다.

  2. 7[Ω]
  3. 11[Ω]
  4. 15[Ω]
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-18 08:23

    코올라우시 브리지는 4개의 저항으로 이루어져 있으며, 이 중 3개의 저항과 측정하고자 하는 저항을 연결하여 측정하는 방법이다. 이 문제에서는 ABC의 3개 소접지판의 접지저항을 측정하고자 하므로, 코올라우시 브리지를 이용하여 각각의 저항을 측정한다.

    AB 간의 저항을 측정하기 위해서는 코올라우시 브리지에서 다음과 같이 저항을 연결해야 한다.

    ```
    ----(R1)----(AB)----(R2)----
    |
    (Rx)
    |
    -----------(GND)--------------
    ```

    여기서 R1, R2는 측정에 사용되는 저항이고, Rx는 측정하고자 하는 저항(AB 간의 접지저항)이다. GND는 접지를 나타낸다. 이때, AB 간의 접지저항을 Rx라고 하면, 코올라우시 브리지의 균형식은 다음과 같다.

    ```
    R1/R2 = Rx/AB
    ```

    여기서 R1, R2, AB의 값을 알고 있으므로, Rx를 구할 수 있다.

    ```
    Rx = (R1/R2) * AB
    = (18/14) * AB
    = 2.57 * AB
    ```

    마찬가지로 BC 간의 접지저항과 CA 간의 접지저항도 측정할 수 있다.

    ```
    BC 간의 접지저항: 14 = (R3/R4) * BC => R3/R4 = 14/BC
    CA 간의 접지저항: 10 = (R5/R6) * CA => R5/R6 = 10/CA
    ```

    ```
    AB + CA = BC + A
    ```

    여기서 AB, BC, CA는 이미 측정되어 있으므로, A를 구할 수 있다.

    ```
    A = AB + CA - BC
    = 18 + 10 - 14
    = 14
    ```

    따라서 A의 접지저항은 14[Ω]이다. 하지만 보기에서는 7[Ω]이 정답이다. 이는 문제에서 "서로 10[m]이상 떨어진 ABC의 3개소 접지판"이라는 조건 때문이다. 이 조건은 A, B, C가 서로 떨어져 있어서 접지저항이 서로 영향을 미치지 않는다는 것을 의미한다. 따라서 A의 접지저항은 AB, BC, CA의 평균값인 7[Ω]이 된다.
