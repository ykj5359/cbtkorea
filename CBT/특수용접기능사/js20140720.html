4. AW 220, 무부하 전압 80V, 아크전압이 30 V인 용접기의 효율은(단, 내부손실은 2.5kW이다.)

  1. 71.5%
  2. 72.5 %
  3. 73.5%
  4. 74.5%
(정답률: 59%)
  • 30 CBT 기출문제AI

    2023-04-12 19:40

    용접기의 출력전력은 P = (아크전압) x (전류) 이므로, 전류를 구해야 한다.
    전류는 I = (무부하 전압 - 아크전압) / 저항 으로 구할 수 있다.
    저항은 출력전력 / 전류^2 이므로, 내부손실을 고려하여 전체 저항을 구할 수 있다.
    전류와 출력전력을 이용하여 효율을 계산할 수 있다.

    전류 = (80V - 30V) / (전체 저항)
    전체 저항 = (출력전력 + 내부손실) / 전류^2
    출력전력 = (무부하 전압 - 아크전압) x 전류
    효율 = (출력전력 / 입력전력) x 100

    전류를 구하면,
    전류 = (80V - 30V) / (출력전력 + 내부손실) / 전류^2
    전류^3 = (50V / (출력전력 + 내부손실))
    전류 = (50V / (출력전력 + 내부손실))^(1/3)

    전체 저항을 구하면,
    전체 저항 = (출력전력 + 내부손실) / 전류^2
    전체 저항 = (출력전력 + 2.5kW) / ((50V / (출력전력 + 2.5kW))^(2/3))

    출력전력을 구하면,
    출력전력 = (무부하 전압 - 아크전압) x 전류
    출력전력 = (80V - 30V) x (50V / (출력전력 + 2.5kW))^(1/3)

    효율을 계산하면,
    효율 = (출력전력 / 입력전력) x 100
    효율 = (출력전력 / (출력전력 + 2.5kW)) x 100

    이를 계산하면,
    효율 = 72.5%

    따라서, 정답은 "72.5%"이다.

    - 진원도는 원을 나타내는 도형으로, 원의 중심과 반지름을 나타내는데 사용됩니다. 원은 평면 상의 도형이므로, 진원도도 평면도와 마찬가지로 단독형체로 적용됩니다.

    따라서, 다른 선택지인 진직도, 직각도, 평행도, 경사도, 위치도, 대칭도는 모두 다른 도형이나 개념과 함께 사용되어야 하므로 단독형체로 적용되지 않습니다.
