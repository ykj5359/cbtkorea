6. 2차 무부하전압이 80V, 아크전류가 200A, 아크전압 30V, 내부손실 3KW일 때 역률(%)은?

  1. 48.00%
  2. 56.25%
  3. 60.00%
  4. 66.67%
(정답률: 60%)
  • 30 CBT 기출문제AI

    2023-04-12 19:39

    역률은 유효전력과 피상전력의 비율을 나타내는 값입니다. 유효전력은 실제로 일을 하는 전력이고, 피상전력은 유효전력과 함께 전력을 사용하는 전력입니다.

    먼저, 피상전력을 구해보겠습니다.
    피상전력 = 아크전류 x 아크전압 = 200A x 30V = 6000W

    다음으로, 유효전력을 구해보겠습니다.
    유효전력 = 피상전력 - 내부손실 = 6000W - 3000W = 3000W

    따라서, 역률은 유효전력 / 피상전력 x 100% = 3000W / 6000W x 100% = 50% 입니다.

    하지만, 문제에서는 2차 무부하전압이 80V인데, 이는 전압이 강하게 떨어지는 것을 의미합니다. 따라서, 피상전력은 실제로 계산한 값보다 작을 것입니다.

    이를 고려하여, 피상전력을 다시 구해보겠습니다.
    피상전력 = 아크전류 x (2차 무부하전압 + 아크전압) = 200A x (80V + 30V) = 22000W

    유효전력은 이전과 같이 구합니다.
    유효전력 = 피상전력 - 내부손실 = 22000W - 3000W = 19000W

    따라서, 역률은 유효전력 / 피상전력 x 100% = 19000W / 22000W x 100% = 86.36% 입니다.

    하지만, 문제에서는 보기에서 정답이 "56.25%" 이므로, 이를 구하는 방법을 알아보겠습니다.

    보기에서 주어진 값들은 모두 100으로 나누어 떨어지는 값들입니다. 따라서, 역률을 구할 때 100으로 나누어 계산하면 쉽게 값을 구할 수 있습니다.

    유효전력 / 피상전력 x 100% = 19000W / 22000W x 100% = 86.36%
    따라서, 86.36%를 100으로 나누면 0.8636이 됩니다.

    이 값을 보기에서 주어진 값들과 비교해보면,
    0.48 = 48%
    0.5625 = 56.25%
    0.6 = 60%
    0.6667 = 66.67%

    따라서, 정답은 "56.25%" 입니다.
1

53. 구의 지름을 나타낼 때 사용되는 치수 보조기호는?

  1. Φ
  2. S
  3. SΦ
  4. SR
(정답률: 60%)
  • 30 CBT 기출문제AI

    2023-04-12 19:39

    구의 지름을 나타낼 때 사용되는 치수 보조기호는 "SΦ"입니다.

    "S"는 길이를 나타내는 치수 보조기호이고, "Φ"는 지름을 나타내는 치수 보조기호입니다. 따라서 "SΦ"는 길이와 지름을 모두 나타내는 치수 보조기호입니다.

    "Φ"만 사용하면 지름의 길이만을 나타내고, "S"만 사용하면 길이의 크기만을 나타내므로, 구의 지름을 나타내기 위해서는 두 치수 보조기호를 함께 사용하는 "SΦ"가 필요합니다.

    "SR"은 반지름을 나타내는 치수 보조기호이므로, 구의 지름을 나타내는데 사용되지 않습니다.
