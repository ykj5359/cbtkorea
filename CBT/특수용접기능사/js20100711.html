9. AW-300 무부하 전압 80V, 아크전압 30V인 교류 용접기를 사용할 때 역률과 효율은 약 얼마인가? 단, 내부손실은 4kw이다.

  1. 역률 : 54%, 효율 : 69%
  2. 역률 : 89%, 효율 : 72%
  3. 역률 : 80%, 효율 : 72%
  4. 역률 : 54%, 효율 : 80%
(정답률: 64%)
  • 30 CBT 기출문제AI

    2023-04-12 19:51

    역률은 유효전력과 피상전력의 비율로 계산됩니다. 유효전력은 실제로 용접에 사용되는 전력이며, 피상전력은 용접기에서 소비되는 전력입니다. 따라서, 역률은 유효전력을 피상전력으로 나눈 값입니다.

    무부하 전압이 80V이므로, 피상전력은 80V x 100A = 8kW입니다. 내부손실이 4kW이므로, 실제로 사용되는 전력은 8kW - 4kW = 4kW입니다. 따라서, 유효전력은 4kW입니다.

    아크전압이 30V이므로, 아크전류는 100A입니다. 따라서, 피상전력은 80V x 100A = 8kW이고, 유효전력은 30V x 100A = 3kW입니다.

    따라서, 역률은 3kW / 8kW x 100% = 37.5%입니다. 하지만, 내부손실이 4kW이므로, 실제 역률은 3kW / (8kW - 4kW) x 100% = 54%입니다.

    효율은 유효전력을 피상전력으로 나눈 값입니다. 따라서, 효율은 4kW / 8kW x 100% = 50%입니다. 하지만, 내부손실이 4kW이므로, 실제 효율은 4kW / (8kW - 4kW) x 100% = 69%입니다.

    따라서, 정답은 "역률 : 54%, 효율 : 69%"입니다.

13. 내용적 40리터, 충전압력이 150kgf/㎠ 인 산소용기의 압력이 100kgf/㎠ 까지 내려갔다면 소비한 산소의 량은 몇 ℓ인가?

  1. 2000
  2. 3000
  3. 4000
  4. 5000
(정답률: 54%)
  • 30 CBT 기출문제AI

    2023-04-12 19:51

    산소용기의 압력이 100kgf/㎠ 까지 내려갔다는 것은, 초기 압력이 150kgf/㎠ 였을 때와 비교하여 50kgf/㎠ 만큼 압력이 감소했다는 것을 의미합니다.

    산소용기의 용량이 40리터 이므로, 초기에는 150kgf/㎠의 압력으로 40리터의 산소가 들어있었습니다.

    압력이 50kgf/㎠ 만큼 감소했으므로, 산소의 부피는 이에 비례하여 증가합니다. 이때, 산소의 부피와 압력은 역비례 관계에 있으므로, 압력이 감소한 만큼 산소의 부피는 증가합니다.

    따라서, 압력이 100kgf/㎠ 일 때의 산소 부피는 다음과 같습니다.

    (150kgf/㎠ ÷ 100kgf/㎠) × 40리터 = 60리터

    따라서, 소비한 산소의 양은 초기에 들어있던 40리터에서 60리터를 뺀 20리터가 됩니다.

    20리터는 2000ℓ과 같으므로, 정답은 "2000" 입니다.

57. 그림과 같이 원통을 경사지게 절단한 제품을 제작할 때 다음 중 어떤 전개법이 가장 적합한가?

  1. 사각형법
  2. 평행선법

  4. 방사선법
