32. 정격 2차 전류가 200A, 아크출력 60kW인 교류 용접기를 사용할 때 소비전력은 얼마인가? (단, 내부 손실이 4kW이다.)

  1. 64kW
  2. 104kW
  3. 264kW
  4. 804kW
(정답률: 54%)
  • 30 CBT 기출문제AI

    2023-04-12 19:41

    용접기의 소비전력은 입력전력과 내부 손실의 합이다. 입력전력은 아크출력과 효율에 따라 결정된다. 이 문제에서는 아크출력이 60kW이므로 입력전력은 60kW/효율이다. 효율은 입력전력/출력전력으로 구할 수 있다. 출력전력은 정격 2차 전류와 전압의 곱이다. 따라서 입력전력 = 60kW/효율, 출력전력 = 200A x 전압, 내부 손실 = 4kW 이므로, 입력전력 = 출력전력/효율 + 내부 손실이다. 이를 정리하면, 60kW/효율 = 200A x 전압 + 4kW 이다. 이 식에서 전압을 구하면, 전압 = (60kW/효율 - 4kW)/200A 이다. 따라서 입력전력 = 60kW/효율 = (200A x 전압 + 4kW) x 효율 이다. 이를 정리하면, 입력전력 = 200A x 전압 x 효율 + 4kW x 효율 이다. 따라서 입력전력과 내부 손실의 합은 200A x 전압 x 효율 + 4kW x 효율 + 4kW 이다. 이를 계산하면, 입력전력과 내부 손실의 합은 64kW 이므로, 정답은 "64kW" 이다.

44. 탄소 함량 3.4%,규소 함량 2.4% 및 인 함량 0.6%인주철의 탄소당량(CE)은?

  1. 4.0
  2. 4.2
  3. 4.4
  4. 4.6
(정답률: 44%)
  • 30 CBT 기출문제AI

    2023-04-12 19:41

    주어진 주철의 탄소 함량, 규소 함량, 인 함량을 이용하여 탄소당량(CE)을 계산할 수 있습니다. CE는 주철의 용융성과 주조성을 결정하는 중요한 요소 중 하나입니다.

    CE = %C + (%Si / 3) + (%P / 3)

    여기서 %C는 탄소 함량, %Si는 규소 함량, %P는 인 함량을 나타냅니다.

    따라서, 주어진 주철의 CE를 계산하면:

    CE = 3.4 + (2.4 / 3) + (0.6 / 3) = 4.4

    따라서, 정답은 "4.4"입니다.
