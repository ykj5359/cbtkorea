4. 입력 저항이 20[kΩ]인 증폭기에 직렬 전류 궤환회로를 적용할 경우 입력 저항값은 얼마가 되는가? (단, βA=9이다.)

  1. 0.1[MΩ]
  2. 0.2[MΩ]
  3. 0.3[MΩ]
  4. 0.4[MΩ]
(정답률: 64%)
  • 30 CBT 기출문제AI

    2023-04-17 22:22

    직렬 전류 궤환회로를 적용하면 입력 저항은 다음과 같이 계산된다.

    Rin = βA * Re

    여기서 Re는 궤환회로의 임피던스이다. 일반적으로 궤환회로에서는 Re = RC로 설정한다. 따라서 입력 저항은 다음과 같이 계산된다.

    Rin = βA * RC

    입력 저항이 20[kΩ]이므로 RC는 다음과 같이 계산된다.

    RC = Rin / βA = 20[kΩ] / 9 = 2.22[kΩ]

    따라서 RC는 2.22[kΩ]이고, 이를 메가옴 단위로 변환하면 0.00222[MΩ]이 된다. 이 값은 보기에서 주어진 값 중에서 "0.2[MΩ]"에 가장 가깝다. 따라서 정답은 "0.2[MΩ]"이다.

7. 정궤환(Positive Feedback)을 사용하는 발진회로에서 발진을 위한 궤환루프(Feedback Loop)의 조건은?

  2. 궤환루프의 이득은 1보다 작고, 위상천이가 90°이다.
  3. 궤환루프의 이득은 1이고, 위상천이가 0°이다.

(정답률: 69%)

    정궤환(Positive Feedback)을 사용하는 발진회로에서 발진을 위한 궤환루프(Feedback Loop)의 조건은 "궤환루프의 이득은 1보다 크고, 위상천이가 180°이다." 이다.

    이유는 발진회로에서는 양의 피드백을 사용하기 때문에, 출력 신호가 입력 신호를 증폭시키는 방향으로 피드백이 작용해야 한다. 이를 위해서는 궤환루프의 이득이 1보다 커야 하며, 위상천이가 180°이어야 한다. 이는 출력 신호와 입력 신호가 서로 반대 방향으로 흐르기 때문이다. 반면에 궤환루프의 이득이 작거나(1보다 작거나) 위상천이가 90°이면, 피드백이 양의 방향이 아닌 음의 방향으로 작용하게 되어 발진이 일어나지 않는다. 또한, 궤환루프의 이득이 1이고 위상천이가 0°이면, 피드백이 작용하지 않아 발진이 일어나지 않는다.
