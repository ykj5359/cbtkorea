    부궤환 증폭회로의 궤환 증폭도는 다음과 같이 계산할 수 있다.

    Af = -R2/R1

    여기서 R1은 입력 임피던스, R2는 출력 임피던스이다. 이 회로에서 입력 임피던스는 R1과 C1로 결정되며, 출력 임피던스는 R2와 C2로 결정된다. 따라서 궤환 증폭도는 R1, R2, C1, C2에 의해 결정된다.

    보기에서 ""은 R1과 R2의 값이 적절하게 조정되어 궤환 증폭도가 최대가 되는 경우이다. 이를 위해서는 R1과 R2의 값이 서로 비슷해야 하며, C1과 C2의 값도 적절하게 조정되어야 한다. 이러한 조건을 만족하면 입력 신호가 궤환을 돌면서 증폭되어 출력되므로, 궤환 증폭도가 최대가 된다.

    2023-04-17 22:08

    ⓐ→ⓒ→ⓓ→ⓑ→ⓔ 순서는 기술의 발전 순서에 따라서 올바르게 나열한 것이다.

    - ⓐ: 직렬 다중화 (Multiplexing)
    - ⓒ: 분기 다중화 (Multiplexing)
    - ⓓ: 주파수 다중화 (Frequency Division Multiplexing)
    - ⓑ: 시분할 다중화 (Time Division Multiplexing)
    - ⓔ: 코드 다중화 (Code Division Multiplexing)

    먼저, 직렬 다중화는 여러 개의 데이터를 하나의 통신 회선을 통해 전송하는 방법으로, 초기에는 이 방법이 사용되었다. 그러나 이 방법은 전송 속도가 느리고, 오류 발생 시 전체 데이터가 손실될 가능성이 있어서 한계가 있었다.

    그래서 분기 다중화가 등장하게 되었다. 이 방법은 하나의 통신 회선을 여러 개의 채널로 분할하여 각각의 채널에서 데이터를 전송하는 방법이다. 이 방법은 전송 속도가 빠르고, 오류 발생 시 해당 채널에서만 손실이 발생하므로 전체 데이터 손실 가능성이 적다는 장점이 있다.

    그러나 분기 다중화도 채널 수가 한정되어 있어서 한계가 있었다. 이에 따라 주파수 다중화가 등장하게 되었다. 이 방법은 하나의 통신 회선을 여러 개의 주파수 대역으로 분할하여 각각의 대역에서 데이터를 전송하는 방법이다. 이 방법은 채널 수가 많아지면서 분기 다중화보다 더 많은 데이터를 전송할 수 있게 되었다.

    하지만 주파수 다중화도 여전히 채널 수가 한정되어 있어서, 시분할 다중화가 등장하게 되었다. 이 방법은 하나의 통신 회선을 시간 단위로 분할하여 각각의 시간 단위에서 데이터를 전송하는 방법이다. 이 방법은 채널 수가 매우 많아져서 대용량 데이터 전송에 적합하다는 장점이 있다.

    마지막으로, 코드 다중화는 주파수나 시간 대신에 데이터를 구분하는 코드를 사용하여 다중화하는 방법이다. 이 방법은 주파수나 시간에 제약을 받지 않아서 대역폭을 효율적으로 사용할 수 있고, 보안성이 높다는 장점이 있다.

    따라서, 이러한 기술의 발전 순서에 따라서 다중화 방법이 ⓐ→ⓒ→ⓓ→ⓑ→ⓔ 순서로 발전해왔다.
