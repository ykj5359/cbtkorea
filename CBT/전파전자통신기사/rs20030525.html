20. 아래의 그림과 같은 전압분할 바이어스의 CE 증폭기에서 동작점에서의 전류 ICQ와 C-E간 전압 VCEQ의 값을 구하면? (단, 트랜지스터의 VBE(ON) = 0.7 [V], IC = IE로 간주한다.)

  1. ICQ = 1.0 [mA], VCEQ = 4.5 [V]
  2. ICQ = 1.5 [mA], VCEQ = 4.8 [V]
  3. ICQ = 1.8 [mA], VCEQ = 4.2 [V]
  4. ICQ = 2.0 [mA], VCEQ= 5.0 [V]
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-17 22:17

    전압분할 바이어스에서는 R1과 R2의 저항값이 다르기 때문에 전압이 분할되어 트랜지스터의 베이스와 에미터에 각각 다른 전압이 걸리게 된다. 이 때, 베이스와 에미터 사이의 전압은 VBE(ON)인 0.7[V]이므로, R1과 R2에 걸리는 전압의 차이는 12[V] - 0.7[V] = 11.3[V]이다.

    이를 이용하여 R1과 R2에 걸리는 전압을 구하면,

    R1에 걸리는 전압 : 11.3[V] x (R1 / (R1 + R2))
    R2에 걸리는 전압 : 11.3[V] x (R2 / (R1 + R2))

    또한, 전류의 분기점 법칙에 따라 IC = IE이므로, IC와 IE는 같은 값이다.

    이를 이용하여 다음과 같은 방정식을 세울 수 있다.
