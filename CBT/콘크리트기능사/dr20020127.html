    잔골재는 건축물의 구조물을 지탱하는 중요한 역할을 합니다. 따라서 잔골재의 강도는 매우 중요합니다. 점토덩어리는 잔골재의 강도를 약화시키는 유해물질 중 하나입니다. 따라서 점토덩어리 함유량이 적을수록 좋습니다.

    전 시료에 대한 최대무게비는 시료 중 유해물질의 함유량을 나타내는 지표입니다. 예를 들어, 전 시료에 대한 최대무게비가 1%라면, 시료 중 유해물질의 함유량은 1% 이하여야 합니다. 따라서 점토덩어리 함유량도 1% 이하여야 합니다.

    즉, 잔골재의 강도를 유지하기 위해서는 점토덩어리 함유량이 최대 1% 이하여야 합니다.

2. 조립율이 3.0인 잔골재 0.2m3와 조립율이 7.0인 0.3m3의 굵은 골재를 혼합한 경우의 조립율은 얼마인가?

  1. 4.2
  2. 4.6
  3. 5.0
  4. 5.4
(정답률: 48%)

    조립율이란 재료의 부피 중 실제로 사용 가능한 부피의 비율을 말합니다. 따라서 두 재료를 혼합한 경우, 전체 부피 대비 사용 가능한 부피의 비율을 구하면 됩니다.

    먼저 잔골재의 사용 가능한 부피는 0.2m3 × 3.0 = 0.6m3 입니다. 마찬가지로 굵은 골재의 사용 가능한 부피는 0.3m3 × 7.0 = 2.1m3 입니다.

    이제 두 재료의 사용 가능한 부피를 합쳐 전체 부피 대비 사용 가능한 부피의 비율을 구합니다.

    전체 사용 가능한 부피 = 0.6m3 + 2.1m3 = 2.7m3
    전체 부피 = 0.2m3 + 0.3m3 = 0.5m3

    따라서 조립율은 2.7m3 ÷ 0.5m3 = 5.4 입니다.

59. 그림과 같이 3등분 하중법으로 콘크리트 휨강도 시험을 하여 중앙 3등분 바깥쪽에서 파괴되었다. b가 a의 몇 % 이상일 때 이 시험체의 시험을 무효로 하는가?

  1. 1%
  2. 3%
  3. 5%
  4. 10%
(정답률: 37%)
  • 30 CBT 기출문제AI

    2023-04-12 22:⑤

    3등분 하중법으로 시험을 진행할 때, 중앙 1/3 부분에는 하중이 거의 작용하지 않기 때문에 파괴되지 않을 것이라고 가정할 수 있습니다. 따라서, 시험체가 무효가 되기 위해서는 바깥쪽 1/3 부분이 모두 파괴되어야 합니다.

    그림에서 b는 a의 1.5배이므로, 바깥쪽 1/3 부분의 너비는 중앙 1/3 부분의 너비의 0.5배가 됩니다. 이때, 콘크리트 휨강도 시험에서는 하중과 굽힘모멘트가 비례하기 때문에, 바깥쪽 1/3 부분에서는 중앙 1/3 부분보다 2배 더 큰 하중이 작용하게 됩니다.

    따라서, 바깥쪽 1/3 부분이 모두 파괴되기 위해서는 중앙 1/3 부분에서 파괴되는 하중의 2배 이상의 하중이 작용해야 합니다. 이를 수식으로 나타내면 다음과 같습니다.

    (중앙 1/3 부분에서 파괴되는 하중) x 2 ≤ (바깥쪽 1/3 부분에서 파괴되는 하중)

    여기서, 중앙 1/3 부분에서 파괴되는 하중은 전체 하중의 1/3이므로,

    (전체 하중) x (1/3) x 2 ≤ (전체 하중) x (1/3) x (b-a)

    식을 정리하면,

    b ≥ a + 1/3

    따라서, b가 a의 1/3보다 크거나 같을 때, 바깥쪽 1/3 부분이 모두 파괴되므로 시험체의 시험을 무효로 할 수 있습니다.

    이때, a=60mm, b=90mm 이므로, b는 a의 1.5배입니다. 따라서, b가 a의 1/3보다 크거나 같을 때, 즉 60 + 1/3 x 60 = 80mm 이상일 때, 시험체의 시험을 무효로 할 수 있습니다.

    따라서, 정답은 "5%"입니다.
