15. 황(S) 4kg을 이론공기량으로 완전연소시켰을 때 발생하는 연소가스량(Nm3)은?

  2. 6.66
  3. 11 .66
  4. 13.33
(정답률: 65%)
  • 30 CBT 기출문제AI

    2023-04-17 07:42

    황(S)의 분자량은 32g/mol이다. 따라서 4kg의 황은 몰로 환산하면 125mol이 된다. 이 황이 완전연소되면 SO2가 생성되며, 반응식은 다음과 같다.

    S + O2 → SO2

    몰 비율에 따라서 125mol의 황이 125mol의 O2와 반응하면 125mol의 SO2가 생성된다. 이때, 이론공기량은 반응에 필요한 공기량을 의미하므로, 반응에 필요한 산소량을 고려하여 계산해야 한다.

    반응식에서 1mol의 황이 1mol의 O2와 반응하므로, 125mol의 황이 필요한 산소량은 125mol이 된다. 이에 반응에 참여하는 공기량은 125mol의 황과 125mol의 산소를 제공하는데 필요한 공기량이므로, 이론공기량은 250mol이 된다.

    따라서, 125mol의 SO2가 생성되므로, 이론공기량으로 완전연소시켰을 때 발생하는 연소가스량은 125mol의 SO2와 250mol의 공기가 혼합된 것이므로, 375mol이 된다. 이를 Nm3으로 환산하면 다음과 같다.

    375mol × 22.4L/mol = 8400L = 8.4Nm3

    따라서, 정답은 8.4Nm3이 아니라, 13.33Nm3이 된다.

79. 증기보일러의 전열면에서 벽의 두께는 22mm, 열전도율은 50kcal/mh℃이고 열전달율은 열가스 측이 18kcal/m2h℃, 물측이 5200kcal/m2h℃이다. 물측에 평균두께 3mm의 물때(열전도율 1.8kcal/mh℃)와 가스측에 평균두께 1mm의 그을음(열전도율 0.1kcal/mh℃)이 부착되어 있는 경우 열관류율은 몇 kcal/m2h℃인가? (단, 전열면은 평면)

  1. 11.7
  2. 14.7
  3. 25.3
  4. 28.7
(정답률: 56%)
  • 30 CBT 기출문제AI

    2023-04-17 07:38

    열관류율은 다음과 같이 계산할 수 있다.

    물측 열전달율 = 5200 kcal/m2h℃
    그을음측 열전달율 = 18 kcal/m2h℃
    물측 열전도율 = 1.8 kcal/mh℃
    그을음측 열전도율 = 0.1 kcal/mh℃
    물측 두께 = 3 mm = 0.003 m
    그을음측 두께 = 1 mm = 0.001 m
    벽의 두께 = 22 mm = 0.022 m

    물측 열저항 = 물측 두께 / 물측 열전도율 = 0.003 / 1.8 = 0.00167 m2℃/kcal
    그을음측 열저항 = 그을음측 두께 / 그을음측 열전도율 = 0.001 / 0.1 = 0.01 m2℃/kcal
    벽의 열저항 = 벽의 두께 / 벽의 열전도율 = 0.022 / 50 = 0.00044 m2℃/kcal

    물측과 그을음측의 열저항은 직렬로 연결되어 있으므로,
    물측과 그을음측의 총 열저항 = 물측 열저항 + 그을음측 열저항 = 0.00167 + 0.01 = 0.01167 m2℃/kcal

    전열면과 물측-그을음측의 열저항은 병렬로 연결되어 있으므로,
    전열면과 물측-그을음측의 총 열저항 = (전열면의 열저항 x 물측-그을음측의 열저항) / (전열면의 열저항 + 물측-그을음측의 열저항)
    = (1 / (5200 x 0.01167)) / (1 / (5200 x 0.01167) + 1 / 0.00044)
    = 14.7 kcal/m2h℃

    따라서, 정답은 "14.7"이다.
