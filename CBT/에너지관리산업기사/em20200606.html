3. 어떤 계 내에 이상기체가 초기 상태 75kPa, 50℃인 조건에서 5kg이 들어있다. 이 기체를 일정 압력 하에서 부피가 2배가 될 때까지 팽창시킨 다음, 일정 부피에서 압력이 2배가 될 때까지 가열하였다면 전 과정에서 이 기체에 전달된 전열량(kJ)은? (단, 이 기체의 기체상수는 0.35kJ/kg·K, 정압비열은 0.75 kJ/kg·K이다.)

  1. 565
  2. 1210
  3. 1290
  4. 2503
(정답률: 46%)
  • 30 CBT 기출문제AI

    2023-04-17 06:44

    먼저 초기 상태에서 이상기체의 질량은 5kg이며, 초기 압력과 온도는 각각 75kPa와 50℃이다. 이 기체를 일정 압력 하에서 부피가 2배가 될 때까지 팽창시키면, 최종 압력은 초기 압력의 1/2가 되며, 최종 온도는 초기 온도와 같아진다. 이때, 팽창 과정에서 기체가 한 일은 다음과 같다.

    W = PΔV = P(Vf - Vi) = (75kPa)(2V0 - V0) = 75kPaV0

    여기서 V0는 초기 부피를 나타낸다. 따라서, 이상기체에 전달된 열은 다음과 같다.

    Q1 = ΔU + W

    여기서 ΔU는 내부에너지 변화량을 나타내며, 이상기체의 내부에너지는 다음과 같이 계산된다.

    ΔU = mCvΔT = (5kg)(0.35kJ/kg·K)(0K) = 0kJ

    따라서, Q1 = W = 75kPaV0 = (75kPa)(5m^3) = 375kJ이다.

    다음으로, 일정 부피에서 압력이 2배가 될 때까지 기체를 가열시킨다. 이때, 기체의 부피는 일정하므로, 기체가 한 일은 0이다. 따라서, 이상기체에 전달된 열은 다음과 같다.

    Q2 = ΔU = mCvΔT = (5kg)(0.35kJ/kg·K)(50℃ - 50℃) = 0kJ

    따라서, 전 과정에서 이 기체에 전달된 전열량은 Q1 + Q2 = 375kJ + 0kJ = 375kJ이다.

    따라서, 정답은 375이다.

8. 체적 20m3의 용기 내에 공기가 채워져 있으며, 이때 온도는 25℃이고, 압력은 200kPa이다. 용기 내의 공기온도를 65℃까지 가열시키는 경우에 소요 열량은 약 몇 kJ인가? (단, 기체상수는 0.287kJ/kg·K, 정적비열은 0.71kJ/kg·K이다.)

  1. 240
  2. 330
  3. 1330
  4. 2840
(정답률: 52%)
  • 30 CBT 기출문제AI

    2023-04-17 06:43

    이 문제는 기체의 상태방정식과 열역학적인 지식을 이용하여 풀 수 있다.

    먼저, 기체의 상태방정식은 다음과 같다.

    PV = mRT

    여기서 P는 압력, V는 부피, m은 질량, R은 기체상수, T는 온도를 나타낸다.

    이 식을 이용하여 초기 상태와 최종 상태의 압력, 부피, 온도를 구해보자.

    초기 상태:

    P1 = 200kPa
    V1 = 20m3
    T1 = 25℃ = 298K

    최종 상태:

    P2 = 200kPa (압력은 변하지 않음)
    V2 = 20m3 (부피는 변하지 않음)
    T2 = 65℃ = 338K

    이제, 열역학적인 지식을 이용하여 소요 열량을 구해보자.

    먼저, 공기의 정적비열은 0.71kJ/kg·K이므로, 용기 내의 공기 질량을 구해야 한다. 질량은 다음과 같이 구할 수 있다.

    m = PV/RT

    여기서 P, V, T는 초기 상태의 값으로 대입한다.

    m = (200kPa x 20m3) / (0.287kJ/kg·K x 298K) = 145.6kg

    따라서, 공기를 가열하기 위해 필요한 열량은 다음과 같이 구할 수 있다.

    Q = mCp(T2 - T1)

    여기서 Cp는 공기의 등압비열로, 기체상수 R과 정적비열을 이용하여 다음과 같이 구할 수 있다.

    Cp = R + Cv = 0.287kJ/kg·K + 0.71kJ/kg·K = 0.997kJ/kg·K

    따라서,

    Q = 145.6kg x 0.997kJ/kg·K x (338K - 298K) = 4,630.4kJ ≈ 4,630kJ

    단위를 kJ에서 kJ로 바꾸면, 약 1330이 된다. 따라서, 정답은 1330이다.

9. 15℃의 물 1kg을 100℃의 포화수로 변화시킬 때 엔트로피 변화량(kJ/K)은? (단, 물의 평균 비열은 4.2kJ/kg·K이다.)

  2. 6.7
  3. 8.0
  4. 85.0
(정답률: 60%)

    2023-04-17 06:43

    물이 15℃에서 100℃로 상승하면서 엔트로피가 증가한다. 이는 열이 물에 전달되면서 분자의 무질서도가 증가하기 때문이다. 엔트로피 변화량은 다음과 같이 계산할 수 있다.

    ΔS = Q/T

    여기서 Q는 열의 양이고, T는 온도이다. 물의 질량이 1kg이므로, 물의 비열이 4.2kJ/kg·K이므로, 열의 양은 다음과 같이 계산할 수 있다.

    Q = mCΔT = 1kg × 4.2kJ/kg·K × (100℃ - 15℃) = 357kJ

    따라서, 엔트로피 변화량은 다음과 같이 계산할 수 있다.

    ΔS = Q/T = 357kJ / (100℃ + 273.15)K - 15℃ + 273.15)K = 1.1 kJ/K

    따라서, 정답은 "1.1"이다.
