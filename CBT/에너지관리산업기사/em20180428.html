3. 냉동기에서의 성능계수 COPR 과 열펌프에서의 성능계수 COPH 와의 관계식으로 옳은 것은?

  1. COPR ＝COPH
  2. COPR ＝COPH ＋1
  3. COPR ＝COPH －1
  4. COPR ＝1－COPH
(정답률: 64%)
  • 30 CBT 기출문제AI

    2023-04-17 07:03

    정답은 "COPR ＝COPH －1" 입니다.

    냉동기와 열펌프는 역사적으로는 같은 원리를 사용하며, 냉동기는 실내를 냉방하기 위해 열을 제거하는 반면, 열펌프는 실내를 냉방 및 난방하기 위해 열을 이동시킵니다.

    COPR은 냉동기의 성능계수를 나타내며, COPH은 열펌프의 성능계수를 나타냅니다. 이 둘의 관계식은 다음과 같습니다.

    COPR = 1 / (1 - Qevap / Qcond)

    COPH = Qcond / (Qcond - Qevap)

    여기서 Qevap은 냉동기나 열펌프의 증발열, Qcond은 응축열을 나타냅니다.

    냉동기와 열펌프의 차이는 열펌프가 실내를 냉방 및 난방하기 위해 열을 이동시키는 반면, 냉동기는 열을 제거하기만 합니다. 따라서 열펌프의 COPH는 냉동기의 COPR보다 항상 높습니다. 이를 수식으로 나타내면 다음과 같습니다.

    COPH > COPR

    COPH - COPR > 0

    COPR = COPH - (COPH - COPR)

    따라서 COPR = COPH - 1이 됩니다.

6. 산소를 일정 체적하에서 온도를 27℃로부터 －3℃로 강하시켰을 경우 산소의 엔트로피(kJ/kgㆍK)의 변화는 얼마인가? (단, 산소의 정적비열은 0.654kJ/kgㆍK이다.)

  1. －0.0689
  2. 0.0689
  3. －0.⑤82
  4. 0.⑤82
(정답률: 59%)

    산소의 엔트로피 변화는 ΔS = Cp ln(T2/T1) - R ln(P2/P1) 이다. 여기서 Cp는 정압비열, R은 기체상수, P는 압력이다. 이 문제에서는 압력이 일정하므로 두 번째 항은 제외할 수 있다. 따라서 ΔS = Cp ln(T2/T1)이다.

    산소의 정압비열인 Cp는 0.654kJ/kgㆍK이므로, ΔS = 0.654 ln(270/267) = -0.0689(kJ/kgㆍK)이다. 따라서 정답은 "－0.0689"이다.

57. 증발량 2000kg/h인 보일러의 상당증발량(kg/h)은? (단, 증기의 엔탈피는 600kcal/kg, 급수의 엔탈피는 30kcal/kg이다.)

  1. 1560kg/h
  2. 2115kg/h
  3. 2565kg/h
  4. 2890kg/h
(정답률: 59%)
  • 30 CBT 기출문제AI

    2023-04-17 07:06

    상당증발량은 보일러에서 생산된 증기 중 실제로 사용되는 양을 말한다. 상당증발량은 증발량에서 보일러 내부에서 소비되는 양을 빼면 된다.

    즉, 상당증발량 = 증발량 - 소비량 이다.

    보일러에서 소비되는 양은 급수량과 상수량의 차이이다. 상수량은 보일러 내부에서 증발되지 않고 배출되는 양을 말한다.

    상수량 = 증발량 - 상당증발량 이므로,

    상당증발량 = 증발량 - 상수량 이다.

    주어진 문제에서는 상수량이 주어지지 않았으므로, 상수량을 구해야 한다.

    상수량은 보일러 내부에서 증발되지 않고 배출되는 양이므로, 급수량과 증발량의 차이이다.

    급수량 = 증발량 - 상수량 이므로,

    상수량 = 증발량 - 급수량 이다.

    급수량은 보일러 내부에서 증발된 증기를 대체하기 위해 공급되는 물의 양이다.

    급수량 = 증발량 x (증기의 엔탈피 / 급수의 엔탈피) 이므로,

    급수량 = 2000 x (600 / 30) = 40000 kg/h 이다.

    따라서,

    상수량 = 증발량 - 급수량 = 2000 - 40000 = -38000 kg/h 이다.

    상수량이 음수이므로, 보일러 내부에서 증발되지 않고 배출되는 양이 없다는 것을 의미한다. 따라서, 상당증발량은 증발량과 같다.

    상당증발량 = 증발량 = 2000 kg/h 이다.

    따라서, 정답은 "1560kg/h", "2115kg/h", "2565kg/h", "2890kg/h" 중에서 "2115kg/h" 이다.
