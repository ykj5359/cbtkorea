14. 이상기체 5kg이 350℃에서 150℃까지 “PV1.3 = 상수” 에 따라 변화하였다. 엔트로피의 변화는? (단, 가스의 정적비열은 0.653kJ/kgㆍK이고, 비열비(k)는 1.4 이다.)

  1. 1.69kJ/K
  2. 1.52kJ/K
  3. 0.85kJ/K
  4. 0.42kJ/K
(정답률: 32%)
  • 30 CBT 기출문제AI

    2023-04-17 07:16

    먼저, 이상기체의 상태방정식인 “PV^1.3 = 상수”를 로그를 취해 선형화하면 “logP + 1.3logV = log상수”가 된다. 이때, 엔트로피 변화는 다음과 같이 구할 수 있다.

    ΔS = ∫(Cp/T)dT - Rln(P2/P1)

    여기서, Cp는 가역과정에서의 열용량이고, R은 기체상수이다. Cp는 이상기체의 경우 Cp = kR/(k-1)로 구할 수 있다. 따라서, Cp = (1.4)(8.314)/(1.4-1) = 29.1 J/mol·K이다.

    먼저, 초기 상태에서의 압력과 체적을 구해보자. 초기 상태에서의 압력은 P1 = (350+273)K에서의 압력으로 구할 수 있다. 이상기체의 경우, PV = nRT이므로 V1 = nRT1/P1이다. 여기서, n은 몰수이고, R은 기체상수, T1은 초기온도이다. 따라서, V1 = (5/28.97)(8.314)(350+273)/P1 = 0.⑤2 m^3이다.

    마찬가지로, 최종 상태에서의 압력과 체적을 구해보자. 최종 상태에서의 압력은 P2 = (150+273)K에서의 압력으로 구할 수 있다. 최종 상태에서의 체적은 PV^1.3 = 상수이므로, V2 = (P1V1^1.3)/P2^1.3 = 0.089 m^3이다.

    따라서, ΔS = ∫(Cp/T)dT - Rln(P2/P1) = ∫(29.1/T)dT - (8.314)(ln(P2/P1)) = 29.1ln(T2/T1) - 8.314ln(P2/P1) = 29.1ln(150+273)/(350+273) - 8.314ln(P2/P1) = -0.42 J/K이다.

    따라서, 정답은 "0.42kJ/K"이다.

    이 연료의 화학식은 CH1.87S0.03이다. 이 연료를 연소시키면 다음과 같은 반응이 일어난다.

    CH1.87S0.03 + 2.935(O2 + 3.76N2) → 1CO2 + 0.935H2O + 0.03SO2 + 8.84N2

    환산증발량 = 발생증기량 / (1 - (급수 엔탈피 / 발생증기 엔탈피))

    환산증발량 = 2000 / (1 - (10 / 549)) = 2000kg/h

    따라서, 정답은 "2000kg/h"입니다.
