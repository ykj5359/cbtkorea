    여기서 저온체는 열을 받아들이는 열기체이고, 고온체는 열을 방출하는 열기체입니다.

    방출열량 = 100kJ x 효율

    따라서, 효율이 28%인 경우 방출열량은 다음과 같이 계산됩니다.

    방출열량 = 100kJ x 0.28 = 28kJ

    따라서, 정답은 28이 아니라 28의 2배인 72입니다.

7. 어떤 가역 열기관이 400℃에서 1000kJ을 흡수하여 일을 생산하고 100℃에서 열을 방출한다. 이 과정에서 전체 엔트로피 변화는 약 몇 kJ/K인가?

  1. 0
  2. 2.5
  3. 3.3
  4. 4
(정답률: 62%)
  • 30 CBT 기출문제AI

    2023-04-17 07:48

    가열 열기관이 가역 과정을 거치므로, 엔트로피 변화는 다음과 같이 계산할 수 있다.

    ΔS = Q/T

    여기서 Q는 열이고, T는 절대온도이다. 따라서, 열을 흡수하는 과정에서 엔트로피 변화는 다음과 같다.

    ΔS1 = 1000 kJ / (400 + 273) K = 2.08 kJ/K

    열을 방출하는 과정에서 엔트로피 변화는 다음과 같다.

    ΔS2 = -1000 kJ / (100 + 273) K = -3.33 kJ/K

    전체 엔트로피 변화는 ΔS1 + ΔS2 = -1.25 kJ/K 이므로, 보기에서 정답은 "0"이다. 이는 엔트로피 변화가 0에 가까운 가역 과정에서만 일어날 수 있다는 열역학 제2법칙에 따른 것이다.

10. 1Sm3의 메탄(CH4)가스를 공기와 같이 연소시킬 경우 이론 공기량(Sm3)은?

  4. 9.52
(정답률: 60%)
  • 30 CBT 기출문제AI

    2023-04-17 07:21

    메탄(CH4)가 연소할 때 생성되는 산소(O2)의 양은 다음과 같이 계산할 수 있습니다.

    1 mol의 CH4가 연소할 때 필요한 O2의 양 = 2 mol

    따라서 1Sm3의 CH4가 연소할 때 필요한 O2의 양은 다음과 같이 계산할 수 있습니다.

    1Sm3의 CH4 = 1000 L의 CH4 = (1000/22.4) mol의 CH4

    필요한 O2의 양 = 2 × (1000/22.4) mol = 89.3 mol

    이제 이론 공기량을 계산해보겠습니다. 이론 공기량은 연소에 필요한 산소(O2)의 양을 공기 중의 산소(O2)의 분압으로 나눈 값입니다. 공기 중의 산소(O2)의 분압은 대략 0.21 atm입니다.

    이론 공기량 = (필요한 O2의 양) / (공기 중의 산소(O2)의 분압) = 89.3 mol / (0.21 atm × 1 Sm3 / 22.4 L) = 9.52 Sm3

    따라서 정답은 "9.52"입니다.

    물이 100℃, 1기압에서 증발할 때, 물의 기화열은 2257kJ/kg 이므로, 1kg의 물이 증발할 때 방출되는 엔트로피 변화는 2257kJ/kg이다. 따라서, 18kg의 물이 증발할 때 방출되는 엔트로피 변화는 2257kJ/kg x 18kg = 40626kJ 이다.

    또한, 엔트로피 변화는 열과 온도의 관계에 의해 결정된다. 따라서, 엔트로피 변화는 다음과 같이 계산할 수 있다.

    ΔS = Q/T

    이를 kJ/K로 환산하면, ΔS = 0.109 kJ/K x 1000mol = 109 kJ/K 이다.

    포밍은 수면계 내부에서 액체의 운동이나 흐름이 급격하게 변화할 때 발생하는 현상이다. 이 때 액체의 표면이 불안정해져서 파도가 일어나는 것처럼 보이며, 이러한 파도가 선박에 영향을 미칠 수 있다.
