1. 가로, 세로, 높이가 각각 3m, 4m, 5m인 직육면체 상자에 들어있는 이상기체의 질량이 80kg일 때, 상자 안의 기체의 압력이 100kPa이면 온도는? (단, 기체상수는 250J/kgㆍK이다.)

  1. 27℃
  2. 31℃
  3. 34℃
  4. 44℃
(정답률: 51%)
  • 30 CBT 기출문제AI

    2023-04-17 07:49

    상자 안의 기체의 부피는 가로, 세로, 높이를 곱한 값인 60m³이다. 이를 이용하여 기체의 밀도를 구할 수 있다.

    기체의 질량 = 기체의 부피 x 기체의 밀도
    80kg = 60m³ x 기체의 밀도
    기체의 밀도 = 80kg / 60m³ = 1.33kg/m³

    이제 이 기체의 압력, 부피, 기체상수를 이용하여 온도를 구할 수 있다.

    PV = nRT
    n = m / M (n: 몰의 수, m: 질량, M: 분자량)
    M = 28.97g/mol (공기의 분자량)

    V = 60m³ = 60000L
    P = 100kPa
    R = 250J/kgㆍK
    m = 80kg
    n = m / M = 80kg / 28.97g/mol = 2764.5mol
    T = (P x V) / (n x R) = (100kPa x 60000L) / (2764.5mol x 250J/kgㆍK) = 31.2K

    위 식에서 구한 온도는 절대온도(K)이므로, 섭씨온도로 변환하여 최종 답인 "27℃"을 구할 수 있다.

    T(℃) = T(K) - 273.15 = 31.2K - 273.15 = -241.95℃
    -241.95℃에 절대온도와 섭씨온도 간의 변환식을 적용하면 최종 답인 "27℃"을 얻을 수 있다.

3. 프로판(C3HS) 20 vol%, 부탄(C4H10) 80 vol%의 혼합가스 1L를 완전 연소하는 데 50%의 과잉 공기를 사용하였다면 실제 공급된 공기량은? (단, 공기 중 산소는 21vol%로 가정한다.)

  1. 27L
  2. 34L
  3. 44L
  4. 51L
(정답률: 49%)
  • 30 CBT 기출문제AI

    2023-04-17 07:15

    프로판과 부탄이 연소할 때, 산소와 반응하여 이산화탄소와 물이 생성된다.

    C3H8 + 5O2 → 3CO2 + 4H2O

    C4H10 + 13/2O2 → 4CO2 + 5H2O

    따라서, 1L의 혼합가스를 연소시키면 3L의 CO2와 4L의 H2O가 생성된다.

    과잉 공기를 50% 사용하였으므로, 연소에 필요한 산소의 양은 1.5배가 된다. 따라서, 연소에 필요한 산소의 양은 1L당 5.25L이 된다.

    공기 중 산소의 비율은 21 vol%이므로, 1L의 공기 중에는 0.21L의 산소가 포함되어 있다.

    따라서, 1L의 혼합가스를 연소시키기 위해서는 5.25L의 산소가 필요하고, 이는 5.25/0.21 = 25L의 공기가 필요하다.

    하지만, 이 연소 반응에서 생성된 CO2와 H2O도 함께 배출되므로, 이들이 차지하는 부피를 고려해야 한다.

    1L의 혼합가스를 연소시키면 3L의 CO2와 4L의 H2O가 생성되므로, 이들이 차지하는 부피는 7L이 된다.

    따라서, 1L의 혼합가스를 연소시키기 위해서는 25L의 공기와 7L의 CO2와 H2O가 필요하다.

    따라서, 총 공급된 공기량은 25 + 7 = 32L이 된다.

    하지만, 이 문제에서는 혼합가스의 부피 비율을 주어졌으므로, 이를 이용하여 정답을 구할 수 있다.

    혼합가스의 부피 비율은 프로판 20 vol%, 부탄 80 vol%이므로, 1L의 혼합가스 중에는 0.2L의 프로판과 0.8L의 부탄이 포함되어 있다.

    따라서, 1L의 혼합가스를 연소시키기 위해서는 0.2L의 프로판과 0.8L의 부탄이 연소되어야 하므로, 이들이 차지하는 부피는 각각 0.2L과 0.8L이 된다.

    따라서, 1L의 혼합가스를 연소시키기 위해서는 0.2L의 프로판과 0.8L의 부탄, 25L의 공기, 7L의 CO2와 H2O가 필요하므로, 총 공급된 공기량은 0.2 + 0.8 + 25 = 25L + 0.2L + 0.8L = 26L이 된다.

    따라서, 정답은 "26L"이다.

4. 압력이 300kPa인 공기가 가역단열 변화를 거쳐 체적이 처음 체적의 5배로 증가하는 경우의 최종 압력은? (단, 공기의 비열비는 1.4이다.)

  1. 23kPa
  2. 32kPa
  3. 143kPa
  4. 276kPa
(정답률: 43%)
  • 30 CBT 기출문제AI

    2023-04-17 07:14

    가역단열 변화에서는 엔트로피가 일정하게 유지되므로 다음과 같은 식이 성립한다.

    P1^(1-γ) / T1^γ = P2^(1-γ) / T2^γ

    여기서 P1은 초기 압력, T1은 초기 온도, P2는 최종 압력, T2는 최종 온도를 나타낸다. γ는 공기의 비열비로 주어졌으므로 1.4로 대입한다.

    먼저 초기 상태에서의 체적 V1을 구해보자. 이때 초기 압력은 300kPa이므로 다음과 같이 계산할 수 있다.

    V1 = mRT1 / P1 = (1kg) x (287J/kgK) x (300K) / (300kPa) = 0.957m^3

    여기서 m은 공기의 질량, R은 기체상수를 나타낸다.

    다음으로 최종 상태에서의 체적 V2를 구해보자. 이때 체적이 처음의 5배로 증가했으므로 다음과 같이 계산할 수 있다.

    V2 = 5V1 = 4.785m^3

    이제 위의 식을 이용하여 최종 압력 P2를 구해보자. 이때 초기 온도 T1과 최종 온도 T2는 같으므로 식에서 상쇄된다.

    P1^(1-γ) / V1^(γ) = P2^(1-γ) / V2^(γ)

    (300kPa)^(0.4) / (0.957m^3)^(1.4) = P2^(0.4) / (4.785m^3)^(0.4)

    P2 = (300kPa)^(0.4) x (4.785m^3)^(0.4) / (0.957m^3)^(0.4) = 32kPa

    따라서 최종 압력은 32kPa이다.

13. 100℃ 건포화증기 2kg이 온도 30℃인 주위로 열을 방출하여 100℃ 포화액으로 변했다. 증기의 엔트로피 변화는? (단, 100℃에서의 증발잠열은 2257kJ/kg이다.)

  1. -14.9kJ/K
  2. -12.1kJ/K
  3. -11.3kJ/K
  4. -10.2kJ/K
(정답률: 61%)
  • 30 CBT 기출문제AI

    2023-04-17 07:49

    이 문제는 열역학 제2법칙에 따라 증기의 엔트로피 변화를 구하는 문제입니다.

    먼저, 증기가 100℃에서 30℃로 냉각되면서 열을 방출하므로, 증기의 엔트로피는 감소합니다. 이때, 엔트로피 변화는 다음과 같이 계산할 수 있습니다.

    ΔS = Q/T

    여기서 Q는 열량, T는 절대온도입니다.

    증기가 방출한 열량 Q는 다음과 같이 계산할 수 있습니다.

    Q = mcΔT

    여기서 m은 증기의 질량, c는 증기의 비열, ΔT는 온도 변화입니다.

    m = 2kg (문제에서 주어짐)
    c = 2,257kJ/kg (문제에서 주어짐)
    ΔT = 100℃ - 30℃ = 70℃

    따라서, Q = 2kg × 2,257kJ/kg × 70℃ = 317,780kJ입니다.

    증발량 = (보일러에서 생성된 증기량) / (증기의 상당증발열)

    증기의 상당증발열은 증기가 생성될 때 필요한 열량을 말한다. 따라서 증기의 상당증발열은 급수의 엔탈피와 보일러에서 생성된 증기의 엔탈피를 빼면 구할 수 있다.

    증기의 상당증발열 = (640 - 20) kcal/kg = 620 kcal/kg

    증발량 = (3500 kg/h) / (620 kcal/kg) ≈ 5.645 kg/kcal

  1. 수면계를 보수 교체했을 때
  2. 2개 수면계의 수위가 서로 다를 때
  3. 수면계 수위의 움직임이 민첩할 때
  4. 포밍이나 프라이밍 현상이 발생할 때
