  1. FTP
  2. mail
  3. WWW
  4. Archie
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-18 06:34

    정답은 "WWW"입니다. HTTP 프로토콜은 웹 브라우저와 웹 서버 간의 통신에 사용되며, 이를 통해 인터넷 사용자는 웹 사이트를 방문하고 정보를 검색할 수 있습니다. 따라서 HTTP 프로토콜을 이용한 인터넷의 대표적인 서비스는 WWW입니다. FTP는 파일 전송 프로토콜, mail은 이메일, Archie는 파일 검색 서비스를 의미합니다.

  3. ＜SCRIPT TYPE="css"＞~＜/SCRIPT＞
  4. ＜CLASS type="css"＞~＜CLASS＞
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-18 06:34

    정답은 "＜STYLE TYPE="text/css"~＜/STYLE＞"이다. 이는 CSS를 작성하기 위한 태그로, HTML 문서 내에서 스타일을 지정할 수 있도록 해준다. "＜CSS＞~＜/CSS＞"는 존재하지 않는 태그이며, "＜SCRIPT TYPE="css"＞~＜/SCRIPT＞"는 스크립트를 작성하기 위한 태그이다. "＜CLASS type="css"＞~＜CLASS＞"는 클래스를 지정하기 위한 태그이며, CSS를 작성하기 위한 태그가 아니다.

  1. title {bgcolor:black;fgcolor:white}
  2. title {background-color:black;color:white}
  3. .title {bgcolor:black;fgcolor:white}
  4. .title {background-color:black;color:white}
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-18 06:34

    정답은 ".title {background-color:black;color:white}" 입니다.

    이유는 CSS에서 클래스를 지정할 때는 "."을 사용하고, 배경색은 "background-color", 글자색은 "color"로 지정합니다. 또한 색상 코드는 "#000000"과 같이 16진수로 표현할 수도 있지만, 간단하게 "black"과 "white"와 같은 영어 단어로도 지정할 수 있습니다. 따라서 ".title {background-color:black;color:white}"가 바르게 작성된 것입니다.

8. MEMBER 라는 테이블에 있는 모든 데이터를 name필드를 기준으로 오름차순 순서대로 가져 오고자 한다. 바르게 작성한 SQL 문장은?

  1. SELECT * FROM member ORDER BY name DESC
  2. SELECT * FROM member ORDER BY name ASC
  3. SELECT * FROM member SORT BY name DESC
  4. SELECT * FROM member SORT BY name ASC
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-18 06:34

    정답은 "SELECT * FROM member ORDER BY name ASC" 이다.

    ORDER BY 절은 SELECT 문에서 결과를 정렬하는 데 사용된다. ASC는 오름차순을 의미하며, name 필드를 기준으로 오름차순으로 정렬하도록 지정한다. 따라서 이 SQL 문장은 MEMBER 테이블에서 모든 데이터를 가져와서 name 필드를 기준으로 오름차순으로 정렬하여 반환한다.

    다른 보기들은 SORT BY 절을 사용하거나, 오름차순과 내림차순을 혼동하거나, 문법적으로 잘못된 구문을 사용하고 있어 정답이 아니다.
