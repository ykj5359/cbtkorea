(정답률: 47%)
  • 30 CBT 기출문제AI

    2023-04-18 06:32

    정답: "ftp:ftp.korham.net"

    설명: URL은 인터넷에서 특정 자원의 위치를 나타내는 문자열이다. 이 중에서 "ftp:ftp.korham.net"는 적절하지 않은 사용 예이다. 이유는 "ftp:"는 프로토콜을 나타내는데, 이 URL에서는 프로토콜 뒤에 주소가 없기 때문이다. 즉, 어떤 FTP 서버의 어떤 자원을 나타내는지 명시되어 있지 않다.

    - "http://www.korcham.net:8080": HTTP 프로토콜을 사용하여 korcham.net의 8080번 포트에 접속하는 URL이다.
    - "http://104.195.110.101/~korcham": HTTP 프로토콜을 사용하여 IP 주소 104.195.110.101의 korcham 사용자의 홈 디렉토리에 접속하는 URL이다.
    - "mailto:master@korcham.net": 이메일 주소 master@korcham.net으로 메일을 보내는 URL이다.
