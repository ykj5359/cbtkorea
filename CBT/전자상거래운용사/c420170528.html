15. 다음 중 CSS로 디자인하여 표현하는데 있어 사용되는 속성과 그 쓰임새가 가장 올바르지 않은 것은?

  2. table, th, td {border:1px solid red;} : 표를 붉은 색으로 1px 굵기로 지정
  3. #text {font-family : 20pt;} : 문자는 모두 20pt 크기로 표현
  4. #text1, #text2 { ..중략.. } : 여러 줄에 걸쳐 속성을 정의할 때는 id를 연달아서 지정

    2023-04-18 06:36
