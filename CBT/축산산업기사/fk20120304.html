7. 젖소에 있어 산유량이 7000kg이상인 암소들을 선발한 결과 평균 산유량은 8000kg이고 이 암소들이 속한 집단의 평균 산유량은 5000kg이었다고 하며 수소에서 선발이 이루어지지 않았다고 하면 선발차는?

  1. 3000kg
  2. 2000kg
  3. 1500kg
  4. 1000kg
(정답률: 51%)
  • 30 CBT 기출문제AI

    2023-04-18 20:34

    선발된 암소들의 평균 산유량은 8000kg이므로, 이 암소들의 전체 산유량은 (암소 수) x 8000kg이다. 이 암소들이 속한 집단의 평균 산유량은 5000kg이므로, 이 집단의 전체 산유량은 (암소 수 + 수소 수) x 5000kg이다. 따라서, 선발된 암소들의 수는 (암소 수) = (전체 산유량 차이) / (8000kg - 5000kg)이다. 여기서 전체 산유량 차이는 (암소 수 + 수소 수) x (8000kg - 5000kg) - (암소 수 + 수소 수) x 5000kg = (암소 수 + 수소 수) x 3000kg이다. 따라서, (암소 수) = (전체 산유량 차이) / 3000kg이다. 이를 이용하여 선발차를 계산하면 다음과 같다.

    선발차 = (암소 수) x (8000kg - 5000kg) = [(전체 산유량 차이) / 3000kg] x 3000kg = 전체 산유량 차이

    따라서, 선발차는 전체 산유량 차이와 같다. 이 문제에서는 수소에서 선발이 이루어지지 않았으므로, 전체 산유량 차이는 선발된 암소들의 전체 산유량과 같다. 즉, 전체 산유량 차이 = (암소 수) x 8000kg - (암소 수 + 수소 수) x 5000kg = (암소 수) x 3000kg이다. 따라서, 선발차는 (암소 수) x 3000kg = 전체 산유량 차이 = (7000kg 이상인 암소들의 전체 산유량) - (선발된 암소들의 전체 산유량) = (7000kg 이상인 암소들의 전체 산유량) - [(암소 수) x 8000kg] = (7000kg 이상인 암소들의 전체 산유량) - [(전체 산유량 차이) / 3000kg x 8000kg] = (7000kg 이상인 암소들의 전체 산유량) - [(7000kg 이상인 암소들의 전체 산유량) / 3] = (2/3) x (7000kg 이상인 암소들의 전체 산유량)이다. 따라서, 선발차는 (2/3) x (7000kg 이상인 암소들의 전체 산유량) = 1500kg이다.
