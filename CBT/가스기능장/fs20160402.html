2. 1[kg]의 공기가 일정 온도 200[℃]에서 팽창하여 처음 체적의 6배가 되었다. 이 때 소비된 열량은 약 몇 [kJ] 인가?

  2. 143
  3. 187
  4. 243
(정답률: 46%)
  • 30 CBT 기출문제AI

    2023-04-08 13:15

    이 문제는 가열 공기의 팽창 문제로, 이상 기체 상태 방정식을 이용하여 풀 수 있습니다.

    먼저, 이상 기체 상태 방정식은 다음과 같습니다.

    PV = nRT

    여기서 P는 압력, V는 체적, n은 몰 수, R은 기체 상수, T는 절대온도를 나타냅니다.

    이 문제에서는 첫 번째 상태에서의 체적 V1과 두 번째 상태에서의 체적 V2가 주어졌으므로, 이를 이용하여 압력의 변화를 구할 수 있습니다.

    V2 = 6V1

    P1V1 = nRT1

    P2V2 = nRT2

    P1V1 = P2V2

    nR(T2 - T1) = P1V1(6V1 - V1)

    nR(T2 - T1) = 5P1V1^2

    여기서 nR(T2 - T1)은 소비된 열량을 나타내므로, 이를 구하면 됩니다.

    nR(T2 - T1) = 5P1V1^2

    nR(T2 - T1) = 5P1(V2/6)^2

    nR(T2 - T1) = 5P1(V1^2/36)

    nR(T2 - T1) = (5/36)P1V1^2

    따라서, 소비된 열량은 (5/36)P1V1^2입니다.

    이제 압력 P1을 구해야 합니다. 이 문제에서는 일정 온도에서의 팽창이므로, 압력과 체적은 역의 관계에 있습니다.

    P1V1 = P2V2

    P1 = P2(V2/V1)

    P1 = 1/6P2

    따라서, 소비된 열량은 (5/36)(1/6P2)V1^2 = (5/1296)P2V1^2입니다.

    이제 P2를 구해야 합니다. 이 문제에서는 일정 온도에서의 팽창이므로, 압력과 체적은 역의 관계에 있습니다.

    P1V1 = P2V2

    P2 = P1(V1/V2)

    P2 = 6P1

    따라서, 소비된 열량은 (5/1296)(6P1)V1^2 = (5/216)P1V1^2입니다.

    마지막으로, P1을 구해야 합니다. 이 문제에서는 공기가 이상 기체로 가정되었으므로, 기체 상수 R은 다음과 같습니다.

    R = (m/M)R0

    여기서 m은 공기의 질량, M은 공기의 몰 질량, R0은 일반 기체 상수입니다.

    공기의 몰 질량은 다음과 같습니다.

    M = (28.97[g/mol])(1[kg]/1000[g]) = 0.02897[kg/mol]

    따라서, 기체 상수 R은 다음과 같습니다.

    R = (1[kg]/0.02897[kg/mol])R0 = 287.1[J/(kg·K)]

    이제 P1을 구할 수 있습니다.

    P1V1 = nRT1

    P1 = nRT1/V1

    n = m/M = 1[kg]/0.02897[kg/mol] = 34.53[mol]

    T1 = 200[℃] + 273.15 = 473.15[K]

    P1 = (34.53[mol])(287.1[J/(kg·K)])(473.15[K])/1[kg] = 46163.5[Pa]

    따라서, 소비된 열량은 (5/216)(46163.5[Pa])(1[kg])V1^2 = 243[kJ]입니다. 따라서, 정답은 "243"입니다.

    이 문제는 이상기체 상태방정식을 이용하여 풀 수 있습니다.

    PV = nRT

    여기서 P는 압력, V는 부피, n은 몰수, R은 기체상수, T는 온도를 나타냅니다.

    먼저, 온도가 35[℃]일 때의 부피를 구해야 합니다. 이때, 산소는 이상기체로 가정할 수 있으므로 이상기체 상태방정식을 이용하여 부피를 구할 수 있습니다.

    V1 / T1 = V2 / T2

    여기서 V1은 충전 전 부피, T1은 충전 전 온도, V2는 충전 후 부피, T2는 충전 후 온도를 나타냅니다.

    이를 이용하여 충전 전 부피를 구하면 다음과 같습니다.

    V1 / (273 + 0) = V2 / (273 + 35)

    V1 = V2 * (273 + 0) / (273 + 35)

    여기서 V2는 충전 후 부피이므로, 산소용기의 부피를 알아야 합니다. 하지만 문제에서는 부피에 대한 정보가 주어지지 않았으므로, 이를 가정해야 합니다. 일반적으로 산소용기의 부피는 40리터 정도이므로, 이를 가정하여 계산하면 다음과 같습니다.

    V1 = 40 * (273 + 0) / (273 + 35) = 37.2 [L]

    P1V1 / T1 = P2V2 / T2

    여기서 P1은 충전 전 압력, P2는 충전 후 압력을 나타냅니다.

    이를 이용하여 충전 전 압력을 구하면 다음과 같습니다.

    P1 = P2 * V2 * T1 / (V1 * T2)

    여기서 P2는 20[MPa], V2는 산소용기의 부피인 40리터, T1은 273 + 35 = 308[K], V1은 위에서 구한 37.2[L], T2는 273[K]입니다.

    따라서, 정답은 "17.7"입니다.

50. 내경이 10[cm]인 관에 비중이 0.9, 점도가 1.5[cP]인 액체가 흐르고 있다. 임계속도는 약 몇 [m/s] 인가?(단, 임계 레이놀즈수는 2100 이다.)

  1. 0.025
  2. 0.035
  3. 0.045
  4. 0.⑤5
(정답률: 55%)
  • 30 CBT 기출문제AI

    2023-04-08 13:16

    임계 레이놀즈수는 다음과 같이 정의됩니다.

    Re = (밀도 × 속도 × 내경) / 점도

    여기서, Re는 레이놀즈수, 밀도는 액체의 밀도, 속도는 액체의 속도, 내경은 관의 내경, 점도는 액체의 점도를 나타냅니다.

    임계 레이놀즈수가 2100이므로, 액체의 속도를 구하기 위해서는 다음과 같은 식을 사용할 수 있습니다.

    속도 = (Re × 점도) / (밀도 × 내경)

    여기서, 액체의 밀도는 비중과 물의 밀도를 비교하여 구할 수 있습니다.

    액체의 밀도 = 비중 × 물의 밀도 = 0.9 × 1000[kg/m^3] = 900[kg/m^3]

    따라서, 액체의 속도는 다음과 같습니다.

    속도 = (2100 × 1.5[cP]) / (900[kg/m^3] × 0.1[m]) = 0.35[m/s]

    하지만, 문제에서 속도를 묻는 것이 아니라 임계속도를 묻고 있습니다. 임계속도는 임계 레이놀즈수에서의 속도를 의미합니다. 따라서, 임계속도는 다음과 같습니다.

    임계속도 = (2100 × 1.5[cP]) / (900[kg/m^3] × 0.1[m]) × 0.⑤ = 0.035[m/s]

    여기서 0.⑤는 임계속도에서의 레이놀즈수와 속도의 비율을 나타내는 상수입니다.

    따라서, 정답은 "0.035"입니다.
