    최종 엔탈피 = 46.25kJ/kg
    엔탈피 변화량 = 초기 엔탈피 - 최종 엔탈피 = 84.82kJ/kg - 46.25kJ/kg = 38.57kJ/kg

    3. 상대습도 변화량 계산하기
    냉각 과정에서 상대습도는 증가하게 된다. 이 때, 상대습도 변화량은 초기 상대습도에서 최종 상대습도를 뺀 값으로 계산할 수 있다.
    초기 상대습도 = 27℃에서의 상대습도 = 50%
    최종 상대습도 = 17℃에서의 상대습도 = 95%
    상대습도 변화량 = 최종 상대습도 - 초기 상대습도 = 95% - 50% = 45%

    4. 냉각열량 계산하기
    냉각열량은 공기의 질량, 엔탈피 변화량, 상대습도 변화량을 곱한 값으로 계산할 수 있다.
    냉각열량 = 공기의 질량 x 엔탈피 변화량 x 상대습도 변화량
    = 1,200kg/h x 38.57kJ/kg x 45%
    = 20,947.2W = 20.95kW
