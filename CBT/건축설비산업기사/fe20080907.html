    건조공기의 엔탈피는 다음과 같이 구할 수 있습니다.

    h_dry = c_p * T

    여기서 c_p는 건조공기의 정압비열, T는 건구온도입니다. 따라서,

    h_dry = 1.01 * 20 = 20.2 kJ/kg′

    수증기의 엔탈피는 다음과 같이 구할 수 있습니다.

    h_moist = h_fg + c_p,v * (T - T_sat)

    여기서 h_fg는 0℃에서 포화수의 증발잠열, c_p,v는 수증기의 정압비열, T는 건구온도, T_sat는 해당 절대습도에서의 포화수증기의 포화온도입니다.

    먼저, 절대습도가 0.0072 kg/kg′일 때, 해당 공기의 상대습도를 구합니다.

    phi = 0.622 * e / (p - e)

    여기서 e는 수증기의 증기압력, p는 대기압입니다.

    e = phi * p / (0.622 + phi) = 0.0072 * 101.3 / (0.622 + 0.0072) = 1.16 kPa

    포화압식: e = 0.611 * exp(17.27 * T / (T + 237.3))

    이를 이용하여, 포화압력이 1.16 kPa일 때의 포화온도를 구하면,

    1.16 = 0.611 * exp(17.27 * T_sat / (T_sat + 237.3))

    T_sat = 10.6℃

    따라서, 해당 절대습도에서의 포화수증기의 포화온도는 10.6℃입니다.

    이제, 수증기의 엔탈피를 구할 수 있습니다.

    h_moist = 2501 + 1.85 * (20 - 10.6) = 38.47 kJ/kg′

    h = h_dry + h_moist = 20.2 + 38.47 = 58.67 kJ/kg′
