2. 공기 중 10[Wb]의 자극에서 나오는 자기력선의 총 수는?

  1. 약 6.885×106개
  2. 약 7.985×106개
  3. 약 8.885×106개
  4. 약 90.92×106개
(정답률: 63%)
  • 30 CBT 기출문제AI

    2023-04-12 11:07

    자기력선의 총 수는 자기장의 세기와 관련이 있습니다. 공기 중 10[Wb]의 자극에서 나오는 자기장의 세기는 약 4π×10-7×10/1 = 4π×10-6 [T] 입니다. 여기서 T는 테슬라를 나타내는 단위입니다.

    자기장의 세기가 4π×10-6 [T] 일 때, 자기력선의 총 수는 다음과 같이 계산할 수 있습니다.

    - 자기장의 세기가 1 [T] 일 때, 자기력선의 총 수는 4π×107 개입니다. (자기장의 세기가 높을수록 자기력선의 밀도가 높아지기 때문입니다.)
    - 따라서, 자기장의 세기가 4π×10-6 [T] 일 때, 자기력선의 총 수는 4π×107 × 4π×10-6 = 1.591×102 개입니다.
    - 하지만, 이 자기장은 10[Wb]의 자극에서 나오는 것이므로, 실제 자기장의 크기는 10[Wb]를 기준으로 계산해야 합니다.
    - 10[Wb]의 자기장은 1 [T]의 자기장을 만들기 위해 10/1 = 101 배의 자기장 세기가 필요합니다.
    - 따라서, 10[Wb]의 자기장에서 나오는 자기력선의 총 수는 1.591×102 × 101 = 1.591×103 개입니다.
    - 하지만, 이는 자기장의 크기를 기준으로 계산한 것이므로, 실제 자기장의 크기와는 다를 수 있습니다.
    - 따라서, 이 값을 보기 중에서 가장 가까운 값으로 선택해야 합니다. 약 7.985×106개가 가장 가까운 값입니다.

6. 공급점 30[m]인 지점에 70[A], 45[m]인 지점에 50[A], 60[m]인 지점에 30[A]의 부하가 걸려있을 때, 부하 중심까지의 거리를 산출하여 전압강하를 고려한 전선의 굵기를 결정하고자 한다. 부하중심까지의 거리는 몇 [m]인가?

  2. 50[m]
  3. 41[m]
  4. 36[m]
(정답률: 72%)
  • 30 CBT 기출문제AI

    2023-04-12 11:07

    전압강하를 고려한 전선의 굵기를 결정하려면 먼저 부하의 총 전력을 계산해야 한다.

    30[m] 지점의 부하 전력: 70[A] x 220[V] = 15,400[W]
    45[m] 지점의 부하 전력: 50[A] x 220[V] = 11,000[W]
    60[m] 지점의 부하 전력: 30[A] x 220[V] = 6,600[W]

    총 부하 전력: 15,400[W] + 11,000[W] + 6,600[W] = 33,000[W]

    다음으로, 전압강하를 고려하여 전선의 굵기를 결정해야 한다. 전압강하는 전선의 길이, 전류, 저항 등에 영향을 받는데, 이 문제에서는 전선의 길이와 전류만 고려하면 된다. 전압강하는 다음과 같은 공식으로 계산할 수 있다.

    전압강하 = 전류 x 전선의 길이 x 전선의 저항 x 2

    전압강하를 최소화하기 위해서는 전선의 굵기를 늘리면 된다. 따라서, 전선의 굵기를 결정하기 위해 전압강하를 최대 5%로 제한하고, 전류와 전선의 길이를 이용하여 전선의 굵기를 계산한다.

    전압강하 = 0.⑤ x 220[V] = 11[V]
    전류 = 총 부하 전력 / 전압 = 33,000[W] / 220[V] = 150[A]

    30[m] 지점에서의 전압강하: 150[A] x 30[m] x 0.0175[Ω/m] x 2 = 157.5[V]
    45[m] 지점에서의 전압강하: 150[A] x 15[m] x 0.0175[Ω/m] x 2 = 131.25[V]
    60[m] 지점에서의 전압강하: 150[A] x 15[m] x 0.0175[Ω/m] x 2 = 131.25[V]

    전압강하가 11[V] 이하여야 하므로, 전선의 굵기는 41[m] 지점에서 결정된다. 따라서, 부하 중심까지의 거리는 41[m]이다.
