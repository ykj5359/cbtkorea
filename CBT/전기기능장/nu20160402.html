22. 그림과 같은 직렬형 인버터에 대해서 L=1mH, C=8㎌일 때 출력 주파수를 1kHz로 할 경우 거의 정현파의 출력전압 파형이 얻어진다. 이 때 부하 저항 R은 몇 Ω인가?

  1. 13.5
  2. 18.5
  3. 23.0
  4. 27.5
(정답률: 50%)
  • 30 CBT 기출문제AI

    2023-04-12 11:08

    직렬형 인버터에서 출력 주파수는 다음과 같이 계산할 수 있습니다.

    f = 1 / (2π√(LC))

    여기서 f를 1kHz로 설정하고, L=1mH, C=8㎌을 대입하면,

    1kHz = 1 / (2π√(1mH×8㎌))

    로부터, √(1mH×8㎌) = 1 / (2π×1kHz) = 159.2Ω

    따라서, 부하 저항 R은 다음과 같이 계산할 수 있습니다.

    R = (Vdc / √3) / Iload

    여기서 Vdc는 DC 입력 전압, Iload는 부하 전류입니다. 이 문제에서는 Vdc=200V로 주어졌으므로,

    Iload = (Vdc / √3) / R

    를 이용하여 R을 구할 수 있습니다. 이 때, 출력 전압의 효율은 90%로 가정합니다.

    90% = (Vload / Vdc) × 100%

    Vload = 0.9 × Vdc / √3 = 109.1V

    따라서,

    Iload = Vload / √(R² + (2πfL - 1/(2πfC))²)

    여기서 f, L, C은 위에서 구한 값입니다. 이 식을 R에 대해 정리하면,

    R = Vload / Iload - √(2πfL - 1/(2πfC))²

    = 109.1V / (200V / √3) - √(2π×1kHz×1mH - 1/(2π×1kHz×8㎌))²

    ≈ 18.5Ω

    따라서, 정답은 "18.5"입니다.

    = 0.0068

    이 값을 대입하면,

    효율 = 역률 / (1 + 0.0068 x 역률)

    이 식의 최대값을 구하면 최대 효율을 구할 수 있다. 최대값은 미분을 통해 구할 수 있으며, 구한 결과 역률이 약 1.22일 때 최대값을 가진다. 따라서,

    최대 효율 = 1 / (1 + 0.0068 x 1.22) x 100

    = 97.8%

    따라서 정답은 "97.8"이다.
