7. 10kVA, 2000/100V 변압기에서 1차로 환산한 등가 임피던스가 6.2+j7Ω 이다. 이 변압기의 % 리액턴스 강하는?

  1. 0.18
  2. 0.35
  3. 1.75
  4. 3.5
(정답률: 62%)
  • 30 CBT 기출문제AI

    2023-04-12 11:03

    등가 임피던스의 크기는 다음과 같이 구할 수 있다.

    |Z| = √(6.2² + 7²) = 9.04Ω

    변압기의 % 리액턴스 강화는 다음과 같이 구할 수 있다.

    % 리액턴스 강화 = (100 × X) / R

    여기서 X는 등가 임피던스의 허수부분, R은 등가 임피던스의 실수부분이다.

    % 리액턴스 강화 = (100 × 7) / 6.2 ≈ 112.9

8. 전부하에서 2차 전압이 120V이고 전압 변동률이 2%인 단상변압기가 있다. 1차 전압은 몇 V인가? (단, 1차 권선과 2차 권선의 권수비는 20:1 이다.)

  1. 1224
  2. 2448
  3. 2888
  4. 3142
(정답률: 78%)
  • 30 CBT 기출문제AI

    2023-04-12 11:08

16. 저항 20Ω인 전열기로 21.6kcal의 열량을 발생시키려면 5A의 전류를 약 몇 분간 흘려주면 되는가?

  1. 3분
  2. 5.7분
  3. 7.2분
  4. 18분
(정답률: 78%)
  • 30 CBT 기출문제AI

    2023-04-12 11:08

    전열기의 발생하는 열량은 전류, 저항, 시간의 곱으로 나타낼 수 있습니다. 따라서, 전류와 저항이 주어졌을 때 발생하는 열량을 계산하여 시간을 구할 수 있습니다.

    전류 = 5A
    저항 = 20Ω
    열량 = 21.6kcal

    열량 = 전류^2 x 저항 x 시간
    21.6kcal = 5^2 x 20 x 시간
    21.6kcal = 500 x 시간
    시간 = 21.6kcal / 500
    시간 = 0.0432시간

    위의 계산 결과를 분으로 환산하면 약 2.6분이 나오지만, 이는 발생하는 열량이 21.6kcal가 아닌 21.6kJ로 계산한 결과입니다. 따라서, 정확한 답은 3분이 됩니다.

37. 변압기의 전부하 동손이 240W, 철손이 160W 일 때, 이 변압기를 최고 효율로 운전하는 출력은 격출력의 몇 %가 되는가?

    변압기의 효율은 출력/입력으로 계산할 수 있습니다. 입력은 동손과 철손의 소비 전력의 합인 240W+160W=400W입니다. 따라서 출력이 최대가 되려면 입력과 출력이 같아야 합니다. 즉, 출력이 400W일 때 효율이 최대가 됩니다.

    하지만 문제에서는 최대 효율로 운전하는 출력을 구하라고 했으므로, 이를 구하기 위해 변압기의 효율 공식을 이용합니다.

    효율 = 출력 / 입력

    출력 = 입력 x 효율

    이때, 효율은 출력/입력 = 2x/5x = 0.4입니다. 따라서, 최대 효율로 운전하는 출력은 400W x 0.4 = 160W입니다.

    마지막으로, 격출력의 비율을 구하기 위해 160W를 400W로 나누어 0.4를 곱한 후 100을 곱해줍니다.

    160W / 400W x 0.4 x 100 = 81.65

    따라서, 정답은 81.65입니다.

56. 자전거를 셀 방식으로 생산하는 공장에서, 자전거 1대당 소요공수가 14.5H 이며, 1일 8H, 월 25일 작업을 한다면 작업자 1명 당 월 생산 가능 대수는 몇 대인가? (단, 작업자의 생산종합효율은 80% 이다.)

  1. 10대
  2. 11대
  3. 13대
  4. 14대
(정답률: 80%)
  • 30 CBT 기출문제AI

    2023-04-12 11:08

    1일 소요공수는 8H 이므로, 1달 소요공수는 8H x 25일 = 200H 입니다.
    작업자 1명이 1달에 생산할 수 있는 자전거 대수는 200H ÷ 14.5H/대 = 13.79대 입니다.
    하지만 작업자의 생산종합효율이 80% 이므로, 실제 생산 가능 대수는 13.79대 x 0.8 = 11.03대 입니다.
    소수점 이하를 버리면 생산 가능 대수는 11대가 됩니다. 따라서 정답은 "11대" 입니다.
