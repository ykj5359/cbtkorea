1. 100khz에서 20Ω의 저항을 갖는 100μH 코일의 임피던스는 얼마인가?

  1. 0.5Ω
  2. 20Ω
  3. 51Ω
  4. 66Ω
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-17 07:57

    임피던스는 저항과 리액턴스의 합으로 구성되며, 리액턴스는 주파수와 인덕턴스에 따라 결정된다. 따라서, 이 문제에서는 다음과 같은 공식을 사용할 수 있다.

    임피던스 = √(저항² + 리액턴스²)

    여기서, 리액턴스는 다음과 같이 구할 수 있다.

    리액턴스 = 2πfL

    여기서 f는 주파수, L은 인덕턴스이다. 따라서, 주어진 문제에서는 다음과 같이 계산할 수 있다.

    리액턴스 = 2π(100kHz)(100μH) = 62.8Ω

    따라서, 임피던스는 다음과 같이 계산할 수 있다.

    임피던스 = √(20² + 62.8²) = 66Ω

    따라서, 정답은 "66Ω"이다.

    B = μ₀ * n * I

    B = 4π × 10⁻⁷ * 200 * 7 / 0.4

    B = 3500 A/m

  1. 42
  2. 52
  3. 64
  4. 73
(정답률: 알수없음)

    2023-04-17 07:55

    정답은 "52"이다.

    CC' 조성의 합금을 냉각시키면서 고용체가 정출되는 과정은 단순한 단일 상태에서의 상변화가 아니므로, 상변화 열은 다음과 같이 계산된다.

    Q = ΔH1 + ΔH2 + ΔH3

    여기서 ΔH1은 고용체가 형성될 때 방출되는 열, ΔH2는 고용체와 고체 용체 사이의 경계면이 형성될 때 방출되는 열, ΔH3는 용체가 고체로 변환될 때 방출되는 열이다.

    냉각 과정에서는 용체가 먼저 형성되고, 이후에 고용체가 정출된다. 따라서, ΔH1은 무시할 수 있다.

    또한, 고용체와 고체 용체 사이의 경계면이 형성될 때 방출되는 열은 ΔH2 = -TΔS2로 나타낼 수 있다. 여기서 ΔS2는 고용체와 고체 용체 사이의 경계면이 형성될 때 방출되는 엔트로피 변화이다.

    마지막으로, 용체가 고체로 변환될 때 방출되는 열은 ΔH3 = -ΔHf로 나타낼 수 있다. 여기서 ΔHf는 고체 상태에서의 결정화 열이다.

    따라서, 상변화 열은 다음과 같이 계산할 수 있다.

    Q = ΔH2 + ΔH3 = -TΔS2 - ΔHf

    이제, 고용체의 양을 계산하기 위해 Gibbs-Thomson 방정식을 사용할 수 있다.

    ΔT = K / r

    여기서 ΔT는 용체와 고체 용체 사이의 온도 차이, K는 상수이고, r은 결정의 반지름이다.

    고용체의 양은 다음과 같이 계산할 수 있다.

    f = (1 - exp(-Q / RT)) / (1 - exp(-ΔHf / RT))

    여기서 f는 고용체의 분율이고, R은 기체 상수이다.

    따라서, 고용체의 양은 다음과 같이 계산할 수 있다.

    f = (1 - exp(TΔS2 / RT) * exp(ΔHf / RT)) / (1 - exp(-ΔHf / RT))

    여기서, T = t2 - t1이고, t1은 용체 상태에서의 온도이다.

    이 값을 계산하면, f = 0.52가 나오므로, 고용체의 양은 약 52%이다.
