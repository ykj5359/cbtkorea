4. 어느 재료에 주파수가 10kHz일 때 와전류 침투깊이가 3mm이었다. 다른 조건은 변화시키지 않고 단지 주파수만 5kHz로 변경하였다면 침투깊이는 약 얼마가 되겠는가?

  1. 1.8mm
  2. 3.0mm
  3. 4.2mm
  4. 5.4mm
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-17 07:53

    와전류 침투깊이는 다음과 같은 공식으로 계산된다.

    δ = 5030 / √(σf)

    여기서 δ는 침투깊이, σ는 재료의 전기전도도, f는 주파수이다.

    주어진 문제에서는 재료와 조건이 동일하고 주파수만 5kHz로 변경되었으므로, 위의 공식에서 f값만 변경하여 계산하면 된다.

    원래 주파수가 10kHz일 때,

    δ = 5030 / √(σ x 10,000)

    주파수가 5kHz로 변경되었을 때,

    δ' = 5030 / √(σ x 5,000)

    두 식을 나누면,

    δ' / δ = √(5,000 / 10,000) = 0.707

    따라서, 주파수가 5kHz일 때의 침투깊이는 원래 침투깊이의 0.707배인 약 4.2mm가 된다.
