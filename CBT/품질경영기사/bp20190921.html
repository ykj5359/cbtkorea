  2. 8
  3. 9
  4. 11

    2요인 모수모형에서 오차항의 자유도는 다음과 같이 계산된다.

    νe = N - ab

    여기서 N은 전체 데이터 수, a는 요인 A의 수준 수, b는 요인 B의 수준 수이다.

    따라서 이 문제에서는 N = 15 (4 x 4 - 1), a = 4, b = 4 이므로,

    νe = 15 - 4 x 4 = 15 - 16 = -1

    νe = N - ab + 1 = 15 - 4 x 4 + 1 = 8

    따라서 정답은 "8"이다.

    SA = (n × Σi=1a (Yi / n)²) - (Σj=1n Yj² / N)

    여기서, n은 각 수준에서의 반복 횟수, a는 요인 A의 수준 수, Yi는 i번째 수준에서의 평균값, N은 전체 반복 횟수이다.

    A3: (16.5 + 17.5 + 18.5) / 3 = 17.17

    SA = (3 × ((11.17 - 14)² + (14.17 - 14)² + (17.17 - 14)²)) - ((10.5² + 11.5² + 12.5² + 13.5² + 14.5² + 15.5² + 16.5² + 17.5² + 18.5²) / 27)

  1. 1/2[abc-a+b-c]

  4. 1/2[abc+a-b-c]
(정답률: 75%)

    주효과 = (조합1 평균값 + 조합2 평균값 + ... + 조합n 평균값) / n

    여기서 n은 조합의 개수이다. 이를 간단하게 표현하면 다음과 같다.

    주효과 = (Σ조합 평균값) / n

    따라서, 주어진 보기 중에서 주효과를 구하는 식을 계산해보면 다음과 같다.

    1/2[abc-a+b-c] = (abc 평균값 + a 평균값 - b 평균값 - c 평균값) / 4

    1/2[abc+a-b+c] = (abc 평균값 + a 평균값 + b 평균값 - c 평균값) / 4

    1/2[abc-a-b+c] = (abc 평균값 - a 평균값 - b 평균값 + c 평균값) / 4

    1/2[abc+a-b-c] = (abc 평균값 + a 평균값 - b 평균값 - c 평균값) / 4

    위의 식들 중에서 주어진 실험 조건에 맞는 것은 1/2[abc+a-b-c]이다. 이유는 다음과 같다.

    - abc, a, b, c 4개의 조합에 의한 일부실시법으로 실험한다는 것은, 각 요인의 레벨을 2개씩만 조합하여 실험한다는 것이다. 따라서, abc 조합은 a=+, b=+, c=+와 a=-, b=-, c=- 두 가지 경우의 평균값을 구하면 된다. 이와 같이 각 조합에 대해 평균값을 구하면, 다음과 같은 결과를 얻을 수 있다.

    abc 평균값 = (abc++, abc+-, abc-+, abc--)의 평균값

    a 평균값 = (a++, a+-, a-+, a--)의 평균값

    b 평균값 = (b++, b+-, b-+, b--)의 평균값

    c 평균값 = (c++, c+-, c-+, c--)의 평균값

    - 이제 각 식에 대해 계산을 해보면, 1/2[abc+a-b-c]의 경우는 다음과 같다.

    1/2[abc+a-b-c] = [(abc++ + abc+- + abc-+ + abc--)/4 + (a++ + a+- + a-+ + a--)/4 - (b++ + b+- + b-+ + b--)/4 - (c++ + c+- + c-+ + c--)/4] / 4

    = [(abc++ + abc+- + abc-+ + abc-- + a++ + a+- + a-+ + a-- - b++ - b+- - b-+ - b-- - c++ - c+- - c-+ - c--)/4] / 4

    = (abc++ + abc+- + abc-+ + abc-- + a++ + a+- + a-+ + a-- - b++ - b+- - b-+ - b-- - c++ - c+- - c-+ - c--) / 16

    - 따라서, 1/2[abc+a-b-c]는 각 조합의 평균값을 이용하여 주효과를 구하는 식으로 맞는 것이다.

  2. 0.0027
  3. 0.0228
  4. 0.1587
(정답률: 58%)
  • 30 CBT 기출문제AI

    2023-04-18 04:53

    먼저 UCL과 LCL은 다음과 같이 계산된다.

    UCL = μ + 3σ = 30 + 3(10) = 60

    LCL = μ - 3σ = 30 - 3(10) = 0

    따라서, 그림참조 관리도의 관리상한은 60이다.

    이제, UCL과 LCL을 이용하여 공정의 평균과 표준편차를 추정할 수 있다.

    UCL = μ + kσ → 43.4 = 30 + k(10) → k = 1.44

    LCL = μ - kσ → 16.6 = 30 - k(10) → k = 1.84

    따라서, 평균과 표준편차는 다음과 같이 추정된다.

    μ = (UCL + LCL) / 2 = (43.4 + 16.6) / 2 = 30

    σ = (UCL - LCL) / 6 = (43.4 - 16.6) / 6 = 4.4

    이제, 그림참조 관리도가 관리상한을 벗어날 확률을 계산할 수 있다.
