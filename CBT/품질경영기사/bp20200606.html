    λ = (고장수 / 시험제품수) / 시간

    고장수는 30개, 시험제품수는 40개이므로,

    λ = (30/40) / 시간

    시간은 문제에서 주어지지 않았으므로, 일반적으로 1시간으로 가정한다.

    따라서,

    λ = 0.75

    이제 R(t)를 구할 수 있다.

    R(t) = e^(-λt) = e^(-0.75t)

    평균순위법에서 평균수명은 다음과 같이 구할 수 있다.

    MTTF = 1 / λ

    따라서,

    MTTF = 1 / 0.75 = 1.3333

    이제 t=MTTF 일 때의 R(t)를 구해보자.

    R(MTTF) = e^(-λMTTF) = e^(-0.75*1.3333) = 0.2683

    따라서, 정답은 "0.2683"이다.

    즉, 이 제품의 MTTF는 1.3333시간이며, 1시간 동안 고장이 발생할 확률은 0.75이다. 또한, MTTF에 도달했을 때의 신뢰도는 0.2683이다.

100. Y 제품의 치수가공을 관리하기 위해서 관리도를 이용하고자 한다. 관리도의 작성을 위해 n=5인 부분군 25개를 추출하여 결과를 정리하니 이었다. 주어진 치수의 규격은 26.0±1.0mm 라고 하면, 공정능력지수 Cp는 약 얼마인가? (단, n=5일 때, A2=0.58, D4=2.11, d2=2.326 이다.)

  1. 0.73
  2. 0.99
  3. 1.33
  4. 1.47
(정답률: 33%)
  • 30 CBT 기출문제AI

    2023-04-18 04:49

    공정능력지수 Cp는 다음과 같이 계산된다.

    Cp = (규격 상한값 - 규격 하한값) / (6 x 표준편차)

    여기서 표준편차는 부분군 평균치의 표준편차를 의미한다. 따라서 먼저 부분군 평균치와 표준편차를 계산해보자.

    부분군 평균치: (25.1 + 25.2 + 25.0 + 25.3 + 25.1) / 5 = 25.14

    표준편차: √[((25.1-25.14)² + (25.2-25.14)² + (25.0-25.14)² + (25.3-25.14)² + (25.1-25.14)²) / 4] = 0.115

    따라서 표준편차는 0.115이다. 이제 Cp를 계산해보자.

    Cp = (27.0 - 25.0) / (6 x 0.115) = 1.47

    따라서 정답은 "1.47"이다. 이유는 공정능력지수 Cp는 규격 상한값과 하한값의 차이를 표준편차의 6배로 나눈 값이기 때문이다. 이 값이 클수록 공정의 능력이 높다는 것을 의미한다.
