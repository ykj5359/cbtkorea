4. 반복이 없는 모수모형의 3원배치법 분산분석 결과 A, B, C 주효과만 유의한 경우 3인자의 수준조합에서 신뢰구간 추정시 유효반복수를 구하는 식은? (단, 인자 A, B, C의 수준수 는 각각 ℓ, m, n이다.)

(정답률: 90%)
  • 30 CBT 기출문제AI

    2023-04-18 04:23

    유효반복수는 다음과 같은 식으로 구할 수 있다.

    유효반복수 = (총 변동 / 오차 변동) - (n - 1)

    여기서 총 변동은 전체 데이터의 변동량을 나타내고, 오차 변동은 각 수준 내에서의 변동량을 나타낸다. 반복이 없는 모수모형에서는 오차 변동이 추정에 사용되는 모든 변동이므로, 유효반복수는 오차 변동에만 의존한다.

    3원배치법 분산분석 결과 A, B, C 주효과만 유의한 경우, 총 변동은 A, B, C, AB, AC, BC, ABC의 7개 요인으로 나누어진 변동으로 나타낼 수 있다. 오차 변동은 각 수준 내에서의 변동으로 나타낼 수 있다.

    따라서 유효반복수는 (7-1) / (n-1) 이 된다. 이를 정리하면 가 된다.

12. 인자 A가 변량인자일 때 수준수가 4, 반복수가 6인 1원배치 실험을 하였더니 ST=2.148, SA=1.979이었다. 이때 σ2A의 값은 약 얼마인가?

  1. 0.109
  2. 0.126
  3. 0.163
  4. 0.241
(정답률: 60%)
  • 30 CBT 기출문제AI

    2023-04-18 04:43

    1원배치 실험에서 변량인자 A의 수준수가 4이므로, 자유도는 3이다. 반복수가 6이므로, 총 자료수는 24이다.

    ST는 총 변동량, SA는 인자 A에 의한 변동량을 나타낸다.

    따라서, 인자 A에 의한 변동의 평균제곱합인 MSA는 다음과 같다.

    MSA = SA / (자유도) = 1.979 / 3 = 0.660

    또한, 오차에 의한 변동의 평균제곱합인 MSE는 다음과 같다.

    MSE = (ST - SA) / (자유도) = (2.148 - 1.979) / 20 = 0.00845

    따라서, 전체 변동의 평균제곱합인 MST는 다음과 같다.

    MST = ST / (총 자료수 - 1) = 2.148 / 23 = 0.09339

    이제, σ2A를 구하기 위해 F값을 계산한다.

    F = MSA / MSE = 0.660 / 0.00845 = 78.⑤

    이 F값은 자유도 3, 20인 F분포에서 검정하면 p-value는 매우 작을 것이다. 따라서, σ2A는 유의수준 0.⑤에서 유의하다.

    마지막으로, σ2A를 구하기 위해 다음과 같은 식을 사용한다.

    σ2A = MSA - (σ2E / 반복수) = 0.660 - (0.00845 / 6) = 0.660 - 0.00141 = 0.65859

    따라서, σ2A의 값은 약 0.109이다.

    즉, 인자 A에 의한 변동은 전체 변동 중 약 10.9%를 차지한다는 것을 의미한다.
