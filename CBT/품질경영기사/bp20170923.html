    σ2e = Se / (n - k) = 2508.8 / (16 - 4) = 179.2

    t = (x̄1 - x̄4) / (sp * √(2/n))

    -2.131 = (x̄1 - x̄4) / (2.12 * √(2/4))

    이 문제는 검정력 분석을 통해 해결할 수 있다.

    먼저, 귀무가설(H0)과 대립가설(H1)을 설정해보자.

    H0: μ ≤ 500 (합격)
    H1: μ > 540 (불합격)

    여기서 μ는 모평균을 의미한다.

    이제 검정력 분석을 위해 필요한 정보들을 계산해보자.

    1. 유의수준 α에 해당하는 임계값 Kα는 1.645이다.

    n = (Kα+Kβ)²(σ²)/(μ1-μ0)²

    CPK = min[(USL-평균)/3표준편차, (평균-LSL)/3표준편차]

    CPK = min[(14.0-11.5)/3×0.5, (11.5-10.0)/3×0.5] = min[1.67, 1.0] = 1.0
