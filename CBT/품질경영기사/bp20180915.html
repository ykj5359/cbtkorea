99. 4개의 PCB 제품에서 각 제품마다 10개를 측정했을 때, 부적합수가 각각 2개, 1개, 3개, 2개가 나왔다. 이 때 6시그마 척도인 DPMO(Defects per Million Opportunities)는?

  1. 0.2
  2. 2.0
  3. 200000
  4. 800000
(정답률: 46%)
  • 30 CBT 기출문제AI

    2023-04-18 04:53

    DPMO는 다음과 같이 계산된다.

    DPMO = (부적합수 / 측정 기회 수) x 1,000,000

    각 제품마다 10개를 측정했으므로, 측정 기회 수는 10이다. 따라서 각 제품의 DPMO는 다음과 같다.

    제품 1: (2 / 10) x 1,000,000 = 200,000
    제품 2: (1 / 10) x 1,000,000 = 100,000
    제품 3: (3 / 10) x 1,000,000 = 300,000
    제품 4: (2 / 10) x 1,000,000 = 200,000

    따라서, 전체 제품의 DPMO는 각 제품의 DPMO를 평균한 값인 200,000이 된다. 따라서 정답은 "200000"이다.
