    - 작업자 1: (130+20)/150 = 0.867

76. 어떤 시스템의 고장률(λ)과 수리율(μ)이 각각 0.025와 0.34일 때 가용도는 약 얼마인가?

  1. 0.0685
  2. 0.0735
  3. 0.932
  4. 0.954
(정답률: 85%)

    A = (시스템이 정상적으로 동작하는 시간) / (전체 시간)

    시스템이 정상적으로 동작하는 시간은 다음과 같이 계산할 수 있다.

    시스템이 정상적으로 동작하는 시간 = (1 / (μ - λ))

    여기서 λ는 고장률, μ는 수리율이다. 따라서 위의 문제에서 시스템이 정상적으로 동작하는 시간은 다음과 같다.

    시스템이 정상적으로 동작하는 시간 = (1 / (0.34 - 0.025)) = 3.125

    전체 시간은 시스템이 정상적으로 동작하는 시간과 시스템이 고장하는 시간의 합이다. 따라서 전체 시간은 다음과 같다.

    전체 시간 = (시스템이 정상적으로 동작하는 시간) + (시스템이 고장하는 시간)

    시스템이 고장하는 시간은 다음과 같이 계산할 수 있다.

    시스템이 고장하는 시간 = (1 / λ)

    따라서 위의 문제에서 전체 시간은 다음과 같다.

    전체 시간 = (시스템이 정상적으로 동작하는 시간) + (시스템이 고장하는 시간) = 3.125 + (1 / 0.025) = 40.125
