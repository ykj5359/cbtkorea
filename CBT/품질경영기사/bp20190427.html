  1. vA=3, ve=396
  2. vA=4, ve=396
  3. vA=3, ve=796
  4. vA=4, ve=796
(정답률: 73%)

    각 기계에서 만들어진 제품의 부적합 여부는 독립적으로 결정되므로, 이는 베르누이 시행이다. 따라서, 모든 기계에서 만들어진 제품의 부적합 여부를 합한 총합은 이항 분포를 따른다.

    이항 분포의 평균은 n*p이고, 분산은 n*p*(1-p)이다. 여기서 n은 시행 횟수, p는 성공 확률이다. 이 문제에서는 모든 기계에서 200개씩 제품을 만들었으므로, n=800이다. 부적합품의 비율은 모르기 때문에 p를 구해야 한다.

    부적합품의 비율을 p라고 하면, 적합품의 비율은 1-p이다. 따라서, 적합품의 개수는 800*(1-p)이고, 부적합품의 개수는 800*p이다. 이 중에서 적합품으로 분류되어야 하는 부적합품의 개수는 vA*800이고, 부적합품으로 분류되어야 하는 적합품의 개수는 ve*800이다.

  2. 3σ
  3. 4σ
  4. 6σ
(정답률: 41%)

    2023-04-18 04:58

    규격한계까지의 거리는 일반적으로 허용오차로 정의되며, 이는 공정에서 생산되는 제품이 규격한계 내에 들어가는 것을 보장하기 위한 범위이다.

    평균에서 규격한계까지의 거리를 계산하기 위해서는 먼저 표준편차를 알아야 한다. Cp=1.33이므로, 공정의 변이성이 상당히 낮다는 것을 의미한다. 일반적으로 Cp가 1.33 이상이면 공정의 변이성이 낮다고 판단할 수 있다.

    표준편차를 구하기 위해서는 다음과 같은 식을 사용한다.

    Cp = (규격한계 상한 - 규격한계 하한) / (6σ)

    여기서, 규격한계 상한과 하한은 각각 U와 L이다.

    따라서,

    6σ = (U - L) / Cp = (U - L) / 1.33

    평균에서 규격한계까지의 거리는 U 또는 L에서 평균을 뺀 값이므로,

    평균에서 규격한계까지의 거리 = (U - μ) 또는 (μ - L)

    이다.

    이제, 평균에서 규격한계까지의 거리를 표준편차로 나누어 계산하면 된다.

    평균에서 규격한계까지의 거리 / σ = (U - μ) / σ 또는 (μ - L) / σ

    = (U - L) / (2σ)

    = (U - L) / (2 × (U - L) / (1.33))

    = 1.33 / 2

    = 0.665

    따라서, 평균에서 규격한계까지의 거리는 약 0.665σ이다.

    보기에서 정답이 "4σ"인 이유는, 표준편차가 작을수록 평균에서 규격한계까지의 거리가 작아지기 때문이다. Cp=1.33이면 공정의 변이성이 낮으므로, 표준편차가 작아서 평균에서 규격한계까지의 거리가 작아진다. 따라서, 보기에서 정답이 "4σ"인 것이다.
