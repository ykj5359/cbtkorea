61. 고장율 λ = 0.07/시간, 수리율 μ = 0.5/시간 일 때, 가용도(Availability)는 약 몇 % 인가?

  1. 12.33
  2. 14.02
  3. 87.72
  4. 88.10
(정답률: 50%)
  • 30 CBT 기출문제AI

    2023-04-18 04:53

    가용도(Availability)는 시스템이 정상적으로 동작하는 시간의 비율을 의미한다. 따라서 가용도는 다음과 같이 계산할 수 있다.

    가용도 = (시스템이 정상적으로 동작하는 시간) / (전체 시간)

    시스템이 정상적으로 동작하지 않는 시간은 고장이나 수리 시간이다. 따라서 시스템이 정상적으로 동작하는 시간은 다음과 같이 계산할 수 있다.

    시스템이 정상적으로 동작하는 시간 = 전체 시간 - (고장 시간 + 수리 시간)

    고장 시간과 수리 시간은 모두 지수분포를 따른다고 가정할 수 있다. 따라서 고장율과 수리율을 이용하여 각각의 기대값을 계산할 수 있다.

    고장율 λ = 0.07/시간 이므로, 고장이 발생하는 평균 시간은 다음과 같다.

    1/λ = 1/(0.07/시간) = 14.29 시간

    수리율 μ = 0.5/시간 이므로, 수리가 완료되는 평균 시간은 다음과 같다.

    1/μ = 1/(0.5/시간) = 2 시간

    따라서 시스템이 정상적으로 동작하는 시간은 다음과 같다.

    시스템이 정상적으로 동작하는 시간 = 전체 시간 - (고장 시간 + 수리 시간)
    = 전체 시간 - (λ/(λ+μ)) - (μ/(λ+μ))
    = 전체 시간 - (0.07/(0.57)) - (0.5/(0.57))
    = 전체 시간 - 0.1228 시간

    따라서 가용도는 다음과 같다.

    가용도 = (시스템이 정상적으로 동작하는 시간) / (전체 시간)
    = (전체 시간 - 0.1228 시간) / (전체 시간)
    = 1 - 0.1228 / 전체 시간

    전체 시간은 임의로 정해주어야 하지만, 예를 들어 100 시간이라고 가정하면 다음과 같다.

    가용도 = 1 - 0.1228 / 100
    = 0.8772

    따라서 정답은 "87.72"이다.
