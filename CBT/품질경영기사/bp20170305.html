2. 요인의 수준 ℓ=4, 반복수 m=3으로 동일한 1요인실험에서 총제곱합 (ST)은 2.383, 요인 A의 제곱합 (SA)은 2.011이었다. μ(Ai)와 μ(A'i) 의 평균치 차를 α=0.⑤로 검정하고 싶다. 평균치 차의 절대값이 약 얼마보다 클 때 유의하다고 할 수 있는가? (단, t0.975(8)=2.306, t0.95(8)=1.860이다.)

  3. 0.327

    μ(Ai)와 μ(A'i)의 평균치 차를 검정하기 위해, 두 평균치의 차이를 나타내는 t-통계량을 계산해야 한다.

    t = (x̄i - x̄'i) / (sε * √(2/m))

    여기서, x̄i와 x̄'i는 각각 요인 A의 i번째 레벨에서의 평균과 요인 A의 i번째 레벨을 제외한 나머지 레벨들의 평균이다. sε는 오차항의 표준편차이며, m은 반복 수이다.

    먼저, sε를 계산해보자.

    Sε = ST - SA = 2.383 - 2.011 = 0.372

    sε = √(Sε / dfε) = √(0.372 / 60) = 0.086

    다음으로, 각 레벨의 평균을 계산해보자.

    x̄1 = (1.042 + 1.032 + 1.038) / 3 = 1.037

    x̄2 = (1.026 + 1.016 + 1.022) / 3 = 1.021

    x̄3 = (1.018 + 1.008 + 1.014) / 3 = 1.013

    x̄4 = (1.014 + 1.004 + 1.010) / 3 = 1.009

    마찬가지로, 나머지 레벨들의 평균을 계산해보자.

    x̄'1 = (1.021 + 1.013 + 1.009) / 3 = 1.014

    x̄'2 = (1.037 + 1.013 + 1.009) / 3 = 1.020

    x̄'3 = (1.037 + 1.021 + 1.009) / 3 = 1.022

    x̄'4 = (1.037 + 1.021 + 1.013) / 3 = 1.024

    t = (1.037 - 1.014) / (0.086 * √(2/3)) = 2.47
