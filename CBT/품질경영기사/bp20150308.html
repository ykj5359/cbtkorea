    따라서, 10월의 예측값은 이전달인 9월의 예측값을 이용하여 계산된다. 초기값은 주로 첫번째 데이터를 사용하므로, 9월의 예측값은 초기값으로 설정된다.

    10월의 예측값 = (1-α) x 9월의 예측값 + α x 9월의 실제값
    = (1-0.2) x 500 + 0.2 x 540
    = 480 + 108
    = 588

    따라서, 11월의 예측값은 다음과 같이 계산된다.

    11월의 예측값 = (1-α) x 10월의 예측값 + α x 10월의 실제값

    = 578.4

51. 설비의 종합효율을 계산하는 식은?

  3. 시간가동률 × 성능가동률 × 양품률

(정답률: 66%)
  • 30 CBT 기출문제AI

    2023-04-18 04:25

    설비의 종합효율은 시간가동률, 성능가동률, 양품률의 곱으로 계산됩니다.

    - 시간가동률: 설비가 계획된 가동시간 대비 실제 가동한 시간의 비율을 나타냅니다. 즉, 설비를 얼마나 오랫동안 가동했는지를 나타내는 지표입니다.

    따라서, 이 세 가지 지표를 모두 고려하여 설비의 종합효율을 계산하는 것입니다. 이 중에서 "시간가동률 × 성능가동률 × 양품률"이 정답인 이유는, 이 세 가지 지표가 모두 중요한 역할을 하기 때문입니다. 시간가동률은 설비를 얼마나 오랫동안 가동했는지를 나타내고, 성능가동률은 설비가 얼마나 효율적으로 작동했는지를 나타내며, 양품률은 설비에서 생산된 제품의 품질을 나타냅니다. 이 세 가지 지표를 모두 고려하여 종합적으로 설비의 효율성을 평가할 수 있기 때문에, 이와 같은 식이 사용되는 것입니다.

    불신뢰도 F(t)는 다음과 같이 계산할 수 있습니다.

    F(t) = (고장개수 / 시험대상 수) x (1 - 누적확률함수)
