  2. 3
  3. 4
  4. 6
(정답률: 68%)

    MTBF는 Mean Time Between Failures의 약자로, 장애가 발생하지 않는 평균 시간을 의미한다. 부품의 수명이 지수분포를 따른다는 것은 장애가 발생하는 확률이 일정하다는 것을 의미한다.

    여러 개의 부품을 병렬로 연결하면 전체 시스템의 장애 확률이 감소한다. 이때, 병렬 연결된 부품 중 하나라도 고장나면 전체 시스템은 고장나게 된다.

    n개의 부품을 병렬로 연결한 경우, 전체 시스템의 장애 확률은 각 부품의 장애 확률을 p라고 할 때, 다음과 같이 계산할 수 있다.

    전체 시스템의 장애 확률 = 1 - (1-p)^n

    시스템의 MTBF를 두 배로 늘리기 위해서는 전체 시스템의 장애 확률을 절반으로 줄여야 한다. 따라서, 다음과 같은 식이 성립한다.

    1 - (1-p)^n = 1/2

    양변에 로그를 취하면,

    n*log(1-p) = log(1/2)

    n = log(1/2) / log(1-p)

    부품의 수명이 지수분포를 따르므로, 장애 확률 p는 다음과 같이 표현할 수 있다.

    p = e^(-λt)

    여기서 λ는 부품의 실패율을 나타내는 상수이다. t는 시간이다.

    따라서, n은 다음과 같이 표현할 수 있다.

    n = log(1/2) / log(e^(-λt))

    n = log(1/2) / (-λt)

    이때, t가 일정하다면, n은 실패율 λ에 반비례한다. 즉, 실패율이 작을수록 더 많은 부품을 병렬로 연결해야 한다.
