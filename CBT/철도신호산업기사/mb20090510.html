4. 5[kHz]의 신호주파수로 80[MHz]의 반송파를 FM 변조했을 때 최대 주파수 편이가 415[kHz]이면 점유 주파수 대역폭은 몇 [kHz] 인가?

  1. 15[kHz]
  2. 180[kHz]
  3. 320[kHz]
  4. 490[kHz]
(정답률: 57%)
  • 30 CBT 기출문제AI

    2023-04-17 22:54

    FM 변조에서 최대 주파수 편이는 Δf = kf × Amax 이다. 여기서 kf는 변조 계수, Amax는 최대 진폭이다. 주파수 편이가 415[kHz]이므로 Δf = 415[kHz]이다. 또한, kf = Δf / Amax 이므로 kf = 415[kHz] / Amax 이다.

    점유 주파수 대역폭은 B = 2 × Δf + 2 × fm 이다. 여기서 fm은 모드레이션 주파수로, 일반적으로 최대 진폭의 5% 정도로 가정한다. 따라서 fm = 0.⑤ × Amax = 0.⑤ × (415[kHz] / kf) = 5[kHz] / kf 이다.

    따라서 B = 2 × 415[kHz] + 2 × 5[kHz] / kf 이다. kf = 415[kHz] / Amax 이므로 Amax = 415[kHz] / kf = 415[kHz] / (415[kHz] / Amax) = Amax 이다. 따라서 Amax = 1 이다.

    따라서 B = 2 × 415[kHz] + 2 × 5[kHz] / 415[kHz] = 830[kHz] + 0.024[kHz] = 830.024[kHz]이다. 이를 kHz 단위로 변환하면 B = 830.024[kHz] ≈ 830[kHz]이다. 따라서 점유 주파수 대역폭은 약 830[kHz]이다.

    하지만 보기에서는 180[kHz]가 정답으로 주어졌다. 이는 B = 2 × Δf + 2 × fm = 2 × 415[kHz] + 2 × 5[kHz] / 180[kHz] ≈ 830[kHz]에서 반올림한 값이다. 따라서 180[kHz]가 정답이다.

80. 다음과 같은 전기회로의 입력을 e1, 출력을 e2라고 할 때 전달함수는? (단, T=L/R 이다.)

  1. TS+1
  2. TS2+1
  3. 1/TS+1
  4. TS/TS+1
(정답률: 47%)
  • 30 CBT 기출문제AI

    2023-04-17 22:53

    전달함수는 출력 전압(e2)을 입력 전압(e1)으로 나눈 것이다. 이 회로에서 출력 전압은 R과 L에 의해 결정되며, 입력 전압은 전압원에서 주어진다. 따라서 전달함수는 R과 L에 의해 결정된다.

    전달함수를 구하기 위해 먼저 회로의 전압-전류 관계식을 구하자. 오른쪽 끝의 전압은 출력 전압(e2)이고, 왼쪽 끝의 전압은 입력 전압(e1)이다. 따라서 전압-전류 관계식은 다음과 같다.

    e1 - IR - L(dI/dt) = 0

    이를 정리하면 다음과 같다.

    dI/dt + R/L I = e1/L

    이는 일차 선형 상미분 방정식이다. 이를 해결하면 다음과 같은 전달함수를 얻을 수 있다.

    I(s) = e1/(sL + R)

    e2 = RI(s)

    따라서 전달함수는 다음과 같다.

    H(s) = e2/e1 = R/(sL + R) = TS/TS+1

    여기서 T=L/R 이므로, 전달함수는 TS/TS+1이 된다.
