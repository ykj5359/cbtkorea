1. 2000kHz에 공진하는 공진회로 코일의 Q가 100 이라 하면, 회로를 통과하는 -3dB의 주파수 대역폭은 몇 kHz 인가?

  1. 1900∼2100
  2. 2010∼2015
  3. 1980∼2000
  4. 1990∼2010
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-17 22:59

    Q = 2000 / Δf 이므로 Δf = 20kHz
    따라서 -3dB 대역폭은 20kHz/Q = 0.2kHz = 200Hz 이다.
    하지만 이 문제에서는 단위를 kHz로 주어졌으므로 0.2kHz = 200kHz 로 변환해야 한다.
    따라서 주파수 대역폭은 2000kHz ± 100kHz = 1900kHz ~ 2100kHz 이다.
    따라서 정답은 "1900∼2100" 이다.

    여기서 Z1은 1단자와 C 단자 사이의 임피던스, Z2는 2단자와 C 단자 사이의 임피던스이다. 이를 정리하면 다음과 같은 식을 얻을 수 있다.

    Vc = V1 / (1 + jωCZ1) = V1 / (1 + jωC / (jωL + 1/ jωC))

    이때, C 단자에 인가되는 전압 Vc와 전류 Ic의 비율을 취하면 C 단자의 임피던스 Zc를 구할 수 있다.

    Zc = Vc / Ic = Z2 / (1 + jωCZ1)

    따라서, C 단자의 임피던스 Zc는 다음과 같다.

    Zc = Z2 / (1 + jωC / (jωL + 1/ jωC)) = jωC / (1 - ω^2LC + jωR)

    여기서 R은 1단자와 2단자 사이의 저항이다. 이때, C 단자의 임피던스 Zc의 실수부분이 0이 되도록 하기 위해서는 R = 0이 되어야 한다. 따라서, 보기에서 C 단자의 임피던스가 "jωC"인 것은 R = 0일 때이며, 이때 C 단자의 정수는 C이다.
