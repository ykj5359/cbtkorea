    2023-04-17 23:02

    CE 등가회로에서 베이스와 에미터 사이의 전압 Vbe는 입력 전압 Vin과 베이스 전류 Ib에 따라 결정됩니다.

    h 파라미터는 다음과 같은 관계식을 가집니다.

    Ib = hfe * Ic + hie * Ib + hre * Vce

    Ib = hie * Ib + hre * Vce

    Vbe = hie * Ib + hre * Vce

    따라서 정답은 "hieIb + hreVce"입니다.

24. 변압기의 % 저항강하 2%, % 리액턴스강하 3%, 부하역률 80%(늦음)일 때 전압변동률은 몇 %인가?

  1. 4.6
  2. 3.4
  3. 2.0
  4. 1.6
(정답률: 30%)
  • 30 CBT 기출문제AI

    2023-04-17 23:02

    전압변동률은 변압기의 전압강하율과 부하역률에 따라 결정된다. 이 문제에서는 변압기의 % 저항강하와 % 리액턴스강하가 주어졌으므로, 전압강하율을 계산할 수 있다.

    전압강하율 = √(1 + (% 저항강하/100)^2 + (% 리액턴스강하/100)^2) = √(1 + 0.02^2 + 0.03^2) = 1.036

    부하역률이 80%이므로, 전압변동률은 전압강하율에 부하역률의 역수를 곱한 값이다.

    전압변동률 = 전압강하율 x (1/부하역률) = 1.036 x (1/0.8) = 1.295

    따라서, 전압변동률은 약 3.4%이다.

    L(di/dt) + Ri = V

    i = (V/R)(1 - e^(-Rt/L))
