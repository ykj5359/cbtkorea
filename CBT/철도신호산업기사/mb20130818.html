2. 듀티사이클(duty cycle)이 0.1이고 주기가 40μs 인 경우 펄스폭은 몇 μs인가?

  2. 4
  3. 3
  4. 1
(정답률: 82%)
  • 30 CBT 기출문제AI

    2023-04-17 22:55

    듀티사이클(duty cycle)은 펄스폭(pulse width)과 주기(period)의 비율을 나타내는 값입니다. 따라서 주어진 문제에서는 펄스폭을 구하기 위해 다음과 같은 식을 사용할 수 있습니다.

    0.1 = 펄스폭 / 40μs

    펄스폭 = 4μs

    따라서 정답은 "4"입니다.

6. 다음 중 진폭변조에서 변조도를 m이라 할 때, 상측파대의 반송파와의 전력비는?

  1. m
  2. m2
  3. 1/2m2
  4. 1/4m2
(정답률: 69%)
  • 30 CBT 기출문제AI

    2023-04-17 22:55

    진폭변조에서 변조도를 m이라고 하면, 변조된 신호의 최대 진폭은 원래 신호의 진폭보다 m배 커진다는 것을 의미합니다.

    반송파는 원래 신호와 같은 주파수를 가지고 있으며, 진폭은 변조되지 않은 원래 신호의 진폭과 같습니다.

    따라서, 상측파대의 전력은 변조된 신호의 최대 진폭의 제곱인 m^2배가 되고, 반송파의 전력은 원래 신호의 진폭의 제곱과 같습니다.

    전력비는 상측파대의 전력을 반송파의 전력으로 나눈 값이므로, (m^2)/(원래 신호의 진폭의 제곱)이 됩니다.

    원래 신호의 진폭은 변조되지 않았으므로, 이 값은 1이 됩니다.

    따라서, 전력비는 (m^2)/1 = m^2이 됩니다.

    하지만 문제에서는 전력비를 1/4m^2로 표기하라고 했으므로, 이는 (m^2)/(4*1) = 1/4m^2가 됩니다.

    즉, 상측파대의 반송파와의 전력비는 1/4m^2입니다.

13. 잡음지수가 3dB이고 증폭도가 20dB인 전치 증폭기를 잡음지수가 5dB인 종속증폭기에 연결하면 종합잡음지수는?

  1. 2 dB
  2. 3.2 dB
  3. 4 dB
  4. 5.2 dB
(정답률: 13%)
  • 30 CBT 기출문제AI

    2023-04-17 22:55

    잡음지수와 증폭도는 다음과 같은 관계식이 성립합니다.

    종합잡음지수 = 10log(입력잡음전력 + (증폭된 신호의 출력전력 / 증폭도)) - 10log(증폭된 신호의 출력전력)

    먼저 전치 증폭기의 증폭도가 20dB이므로, 증폭된 신호의 출력전력은 입력신호의 100배가 됩니다. 따라서 증폭된 신호의 출력전력은 입력신호의 10log(100) = 20dBm 입니다.

    전치 증폭기의 잡음지수가 3dB이므로, 입력잡음전력은 출력전력의 2배가 됩니다. 따라서 입력잡음전력은 증폭된 신호의 출력전력의 1/100배인 -40dBm 입니다.

    이제 종속증폭기에 연결합니다. 종속증폭기의 증폭도는 입력신호의 출력전력 대비 20배이므로, 증폭된 신호의 출력전력은 -20dBm 입니다.

    종속증폭기의 잡음지수가 5dB이므로, 입력잡음전력은 출력전력의 3.16배가 됩니다. 따라서 입력잡음전력은 증폭된 신호의 출력전력의 1/3.16배인 -23.8dBm 입니다.

    이제 위에서 구한 값들을 종합잡음지수 공식에 대입합니다.

    종합잡음지수 = 10log(-40 + (-20 / 20)) - 10log(-20) - 10log(-23.8 + (-20 / 20)) + 10log(-20)
    종합잡음지수 = 3.2 dB

    따라서 정답은 "3.2 dB" 입니다.
