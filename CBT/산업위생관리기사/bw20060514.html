4. 근로자로부터 35cm로 떨어진 물체(10kg)를 바닥으로부터 120cm 들어올리는 작업을 1분에 6회씩 1일 8시간 실시할 때 MPL은? (단, 박스의 손잡이는 양호하며 계산공식은 다음과 같다. AL=40(15/H)(1-0.004 IV-751), (0.7+(7.5+D))(1-(F/Fmax)), Fmax는 122회/min이다.)

  1. 13.7kg
  2. 15.7kg
  3. 17.7kg
  4. 19.7kg
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-16 06:47

    MPL은 최대 허용 무게를 의미하며, 작업자가 안전하게 일할 수 있는 최대 무게를 나타낸다. MPL은 작업자의 신체적 능력, 작업 환경 등에 따라 다르게 결정된다.

    이 문제에서는 AL 공식을 사용하여 MPL을 계산한다. AL 공식은 작업자의 신체적 능력을 고려하여 작업 부하를 계산하는 공식이다.

    AL=40(15/H)(1-0.004 IV-751), (0.7+(7.5+D))(1-(F/Fmax))

    여기서 H는 작업자의 신장(cm), IV는 작업자의 나이, D는 작업자의 거리(cm), F는 작업자의 심박수이다.

    문제에서는 작업자로부터 35cm 떨어진 물체(10kg)를 120cm 들어올리는 작업을 1분에 6회씩 1일 8시간 실시한다고 하였다. 이를 공식에 대입하면 다음과 같다.

    H = 작업자의 신장 = ?
    IV = 작업자의 나이 = ?
    D = 35cm
    F = 6회/min
    Fmax = 122회/min
    물체의 무게 = 10kg
    작업 시간 = 8시간

    AL=40(15/H)(1-0.004 IV-751), (0.7+(7.5+D))(1-(F/Fmax))
    AL=40(15/H)(1-0.004 IV-751), (0.7+(7.5+35))(1-(6/122))
    AL=40(15/H)(1-0.004 IV-751), 1.39

    AL 값이 1.39로 나왔다. 이 값은 작업자가 안전하게 일할 수 있는 최대 부하를 의미한다. 이 값으로부터 MPL을 계산하면 다음과 같다.

    MPL = AL x 작업자의 체중
    MPL = 1.39 x 작업자의 체중

    문제에서 MPL이 13.7kg이 되도록 작업자의 체중을 구해야 한다. 따라서 다음과 같이 계산한다.

    13.7 = 1.39 x 작업자의 체중
    작업자의 체중 = 13.7 / 1.39
    작업자의 체중 = 9.85kg

    따라서, 작업자의 체중은 9.85kg 이상이어야 안전하게 작업을 수행할 수 있다. 그러나 보기에서는 13.7kg이 정답으로 주어졌다. 이는 작업자의 체중이 9.85kg 이상이라는 조건을 만족하면서도 작업 부하를 더 안전하게 제한하기 위해 설정된 값이다.

12. 어느 근로자의 1시간 작업에 소요되는 열량이 500kcal이었다면, 작업 대사 율은 약 얼마인가? (단. 기초대사량: 60kcal/hr, 안정 시 열량은 기초대사량의 1.2배임.)

  1. 4.7
  2. 5.4
  3. 6.4
  4. 7.1
(정답률: 39%)
  • 30 CBT 기출문제AI

    2023-04-16 06:46

    작업 대사율은 작업에 소요된 열량을 시간으로 나눈 값이다. 따라서 이 문제에서는 다음과 같이 계산할 수 있다.

    작업 대사율 = 작업에 소요된 열량 / 작업 시간

    여기서 작업 시간은 1시간이므로, 작업 대사율은 다음과 같다.

    작업 대사율 = 500kcal / 1시간 = 500kcal/hr

    하지만 이 값은 기초대사량을 고려하지 않은 값이므로, 안정 시 열량을 고려해 보정해야 한다. 안정 시 열량은 기초대사량의 1.2배이므로, 이 값을 곱해주면 된다.

    작업 대사율 = 500kcal / 1시간 x 1.2 = 600kcal/hr

    따라서 이 근로자의 작업 대사율은 600kcal/hr이다. 이 값을 기초대사량인 60kcal/hr로 나누면 다음과 같이 계산할 수 있다.

    작업 대사율 / 기초대사량 = 600kcal/hr / 60kcal/hr = 10

    즉, 이 근로자의 작업 대사율은 기초대사량 대비 10배 높다는 것을 의미한다. 이 값을 소수점 첫째 자리까지 반올림하면 7.1이 된다. 따라서 정답은 "7.1"이다.

44. 덕트에서 공기 흐름의 평균 속도압이 25mmH2O 였다면 덕트에서의 반송속도(m/sec)는? (단, 공기 밀도 1.21kg/m3)

  1. 10
  2. 15
  3. 20
  4. 25
(정답률: 73%)
  • 30 CBT 기출문제AI

    2023-04-16 06:46

    공기 흐름의 평균 속도압이 25mmH2O 이므로, Bernoulli의 방정식을 사용하여 다음과 같이 표현할 수 있다.

    P1 + 1/2ρv12 + ρgh1 = P2 + 1/2ρv22 + ρgh2

    여기서, P는 압력, ρ는 공기 밀도, v는 속도, h는 높이를 나타낸다. 덕트에서의 반송속도는 덕트 내부의 압력 차이로 인해 발생하는 것이므로, P1 = P2 로 가정할 수 있다. 또한, 덕트가 수평이므로 h1 = h2 이다. 따라서, 위의 식은 다음과 같이 단순화된다.

    1/2ρv12 = 1/2ρv22

    이를 정리하면,

    v2 = v1√(P2/P1)

    여기서, P2/P1 = 1 - ΔP/P1 이다. ΔP는 덕트 내부의 압력 차이를 나타내며, 이는 25mmH2O 에 해당한다. 따라서,

    ΔP/P1 = 25/101325 ≈ 0.000246

    v2 = v1√(1 - ΔP/P1) ≈ v1(1 - ΔP/2P1) ≈ v1
