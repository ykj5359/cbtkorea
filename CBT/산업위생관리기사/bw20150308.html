2. 어떤 사업장에서 1000명의 근로자가 1년동안 작업하던 중 재해가 40건 발생하였다면 도수율은 얼마인가?(단, 근로자는 1일 8시간 씩 연간 300일을 근무하였다.)

  1. 12.3
  2. 16.7
  3. 24.4
  4. 33.4
(정답률: 86%)
  • 30 CBT 기출문제AI

    2023-04-16 06:35

    도수율은 일정 기간 동안 발생한 사고 건수를 일정 기간 동안 근무한 근로자 수로 나눈 후 100을 곱한 값입니다. 따라서 이 문제에서는 다음과 같이 계산할 수 있습니다.

    - 일정 기간 동안 발생한 사고 건수: 40건
    - 일정 기간 동안 근무한 근로자 수: 1000명 x 1일 x 300일 = 300,000인일

5. 근로자로부터 40cm 떨어진 물체(9kg)를 바닥으로부터 150cm 들어 올리는 작업을 1분에 5회씩 1일 8시간 실시하였을 때 감시기준(AL, action limit)은 얼마인가? (단, H는 수평거리, V는 수직거리,D 는 이동거리. F는 작업빈도계수이다.)

  1. 2.6kg
  2. 3.6kg
  3. 4.6kg
  4. 5.6kg
(정답률: 45%)
  • 30 CBT 기출문제AI

    2023-04-16 06:35

    AL은 다음과 같이 계산할 수 있다.

    AL = (작업빈도계수 × 물체중 × 이동거리 × 수직거리) ÷ (수평거리 × 작업시간)

    여기서 작업빈도계수는 5회/분, 물체중은 9kg, 이동거리는 150cm, 수직거리는 40cm, 수평거리는 0cm(근로자와 물체가 같은 평면상에 있으므로)이다. 작업시간은 1일 8시간 = 480분이다.

    따라서,

    AL = (5회/분 × 9kg × 150cm × 40cm) ÷ (0cm × 480분)
    = 무한대

    AL이 무한대이므로, 이 작업은 안전하지 않다는 것을 의미한다. 따라서, 이 작업을 수행하기 위해서는 보호조치를 취해야 한다.

    정답은 "4.6kg"이 아닌데, 이유는 AL이 무한대이므로 어떤 무게를 초과해도 안전하지 않다는 것이다. 따라서, 보기에서 제시된 모든 무게는 모두 틀린 것이다.

30. 어떤 음의 발생원의 Sound Power가 0.006W이면 이때 음향 파워레벨은?

  3. 96dB
  4. 98dB
(정답률: 69%)

    음향 파워레벨은 다음과 같은 공식으로 계산됩니다.

    음향 파워레벨 = 10 log10 (음의 발생원의 Sound Power / 기준 Sound Power)

  2. 59 dB
  3. 69 dB
  4. 79 dB

    음향 파워레벨(PWL)과 음압레벨(SPL)은 다음과 같은 관계가 있습니다.

    PWL = SPL + 10log(distance^2)

    여기서 distance는 점음원과 측정 지점 사이의 거리입니다.

    따라서, 이 문제에서는 distance가 100m이므로,

    110 dB = SPL + 10log(100^2)

    110 dB = SPL + 200

    SPL = 110 dB - 200

    SPL = -90 dB

    하지만, 음압레벨은 보통 0 dB를 기준으로 합니다. 따라서, 이 값을 0 dB로 이동시키기 위해 90 dB를 더해줍니다.

    SPL = -90 dB + 90 dB

    SPL = 0 dB
