5. 온도 25℃, 1기압 하에서 분당 100mL씩 60분 동안 채취한 공기 중에서 벤젠이 5mg 검출되었다면 검출된 벤젠은 약 몇 ppm인가? (단, 벤젠의 분자량은 78이다.)

  1. 15.7
  2. 26.1
  3. 157
  4. 261
(정답률: 49%)
  • 30 CBT 기출문제AI

    2023-04-16 ⑤:30

    먼저, ppm은 parts per million의 약자로, 백만 분의 일을 의미합니다. 따라서, 검출된 벤젠의 양을 분당 100mL로 나누어 ppm으로 환산해야 합니다.

    검출된 벤젠의 양은 5mg이며, 분당 100mL씩 60분 동안 채취한 공기의 양은 6L입니다. 이를 ppm으로 환산하면 다음과 같습니다.

    5mg / (6L x 1000mg/1g) = 0.00083333 g/L

    이제 이 값을 ppm으로 환산해야 합니다. ppm은 백만 분의 일을 의미하므로, 0.00083333 g/L을 1,000,000으로 곱해줍니다.

    0.00083333 g/L x 1,000,000 = 833.33 ppm

    하지만, 이 문제에서는 소수점 이하 둘째자리까지만 답을 구하도록 요구하고 있습니다. 따라서, 833.33을 반올림하여 최종 답인 261 ppm을 구할 수 있습니다.

12. 육체적 작업능력(PWC)이 16kcal/min인 남성 근로자가 1일 8시간 동안 물체를 운반하는 작업을 하고 있다. 이 때 작업대사율은 10kcal/min이고, 휴식 시 대사율은 2kcal/min이다. 매 시간마다 적정한 휴식 시간은 약 몇 분인가? (단, Herting의 공식을 적용하여 계산한다.)

  1. 15분
  2. 25분
  3. 35분
  4. 45분
(정답률: 70%)
  • 30 CBT 기출문제AI

    2023-04-16 ⑤:30

    본 해설은 비추 누적갯수 초과로 자동 블라인드 되었습니다.(AI해설 오류가 많아 비추 2개 이상시 자동 블라인드 됩니다.)해설을 보시기 원하시면 클릭해 주세요
    작업 시간 동안 소비되는 열량은 다음과 같이 계산할 수 있다.

    작업 시간 동안 소비되는 열량 = 작업대사율 × 작업 시간 + 휴식 시간 × 휴식 대사율

    여기서 작업 시간은 8시간이고, 작업대사율은 10kcal/min, 휴식 대사율은 2kcal/min이다. 따라서 위 식을 대입하면 다음과 같다.

    8시간 동안 소비되는 열량 = 10kcal/min × 60min/시 × 8시간 + 휴식 시간 × 2kcal/min × 60min/시

    이를 정리하면 다음과 같다.

    4800kcal = 480kcal/분 × 작업 시간 + 120kcal/분 × 휴식 시간

    여기서 Herting의 공식을 적용하면 적정한 휴식 시간을 구할 수 있다. Herting의 공식은 다음과 같다.

    적정한 휴식 시간 = (작업 시간 × 작업대사율) / (작업대사율 - 휴식 대사율)

    여기서 작업 시간은 8시간, 작업대사율은 10kcal/min, 휴식 대사율은 2kcal/min이다. 따라서 위 식을 대입하면 다음과 같다.

    적정한 휴식 시간 = (8시간 × 10kcal/min) / (10kcal/min - 2kcal/min) = 80분 / 8 = 10분

    따라서 매 시간마다 적정한 휴식 시간은 약 10분이다. 이는 보기에서 주어진 답변 중에서 가장 작은 값이다. 그러나 이는 매 시간마다 휴식을 취하는 것이 아니라, 작업 시간 동안 적절한 간격으로 휴식을 취해야 한다는 것을 의미한다. 따라서 8시간 동안 적절한 휴식 시간은 8 × 10분 = 80분이다. 이를 4로 나누면 매 시간마다 적정한 휴식 시간은 약 20분이다. 그러나 보기에서 주어진 답변 중에서 이와 일치하는 값은 없으므로, 가장 가까운 값인 35분이 정답이 된다.

13. Diethyl ketone(TLV=200ppm)을 사용하는 근로자의 작업시간이 9시간일 때 허용기준을 보정하였다. OSHA 보정법과 Brief and Scala 보정법을 적용하였을 경우 보정된 허용기준 치간의 차이는 약 몇 ppm인가?

  1. 5.⑤
  2. 11.11
  3. 22.22
  4. 33.33
(정답률: 75%)
  • 30 CBT 기출문제AI

    2023-04-16 ⑤:30

    OSHA 보정법에서는 작업시간이 9시간일 때 허용농도를 다음과 같이 계산한다.

    허용농도 = TLV / (1 - 0.5 × (1 - 9/8))

    = 200 / (1 - 0.5 × (1 - 9/8))

    = 200 / 0.125

    = 1600 ppm

    Brief and Scala 보정법에서는 작업시간이 9시간일 때 허용농도를 다음과 같이 계산한다.

    허용농도 = TLV × (2400 / (2400 - 작업시간 × (2400 / 8)))

    = 200 × (2400 / (2400 - 9 × (2400 / 8)))

    여기서 10은 여유계수를 의미합니다. 즉, 실제 배출량보다 10배 더 많은 환기량이 필요하다는 것을 의미합니다.

    이제 이소프로필알코올의 총 배출량을 계산합니다.

    이소프로필알코올의 총 배출량 = 100g/h x (1/60) x 10 = 1.67m3/h

    따라서, 두 물질의 총 배출량은 1.09m3/h + 1.67m3/h = 2.76m3/h 입니다.

    마지막으로, 환기량을 계산합니다.

    환기량 = 총 배출량 / (농도 x 24)

    여기서 24는 하루를 시간 단위로 환산한 것입니다.

    농도는 TLV를 초과하지 않도록 설정해야 하므로, 두 물질 중 TLV가 더 작은 톨루엔의 TLV인 50ppm을 사용합니다.

    환기량 = 2.76m3/h / (50ppm x 24) = 7250m3/h

    따라서, 필요한 환기량은 약 7250m3/h 입니다.
