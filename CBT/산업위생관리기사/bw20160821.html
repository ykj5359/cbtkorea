5. 600명의 근로자가 근무하는 공장에서 1년에 30건의 재해가 발생하였다. 이 가운데 근로자들이 질병, 기타의 사유로 인하여 총근로시간 중 3%를 결근하였다면 이 공장의 도수율은 얼마인가? (단, 근무는 1주일에 40시간, 연간 50주를 근무한다.)

  1. 25.77
  2. 48.50
  3. 49.55
  4. 50.00
(정답률: 78%)
  • 30 CBT 기출문제AI

    2023-04-16 ⑤:34

    도수율은 다음과 같이 계산할 수 있다.

    도수율 = (발생한 재해 건수 / 총 근로시간) x 1,000,000

    총 근로시간은 다음과 같이 계산할 수 있다.

    총 근로시간 = 근로자 수 x 주당 근무시간 x 근무 주수 x (1 - 결근률)

    여기서 결근률은 3%이므로 0.97로 대체할 수 있다.

    총 근로시간 = 600 x 40 x 50 x 0.97 = 1,176,000

    따라서 도수율은 다음과 같이 계산할 수 있다.

    도수율 = (30 / 1,176,000) x 1,000,000 = 25.77

    따라서 정답은 "25.77"이다.

48. 유해성 유기용매 A가 7m×14m×4m의 체적을 가진 방에 저장되어 있다. 공기를 공급하기 전에 측정한 농도는 400ppm이었다. 이 방으로 60m3/min의 공기를 공급한 후 노출기준인 100ppm으로 달성되는 데 걸리는 시간은? (단, 유해성 유기용매 증발 중단, 공급공기의 유해성 유기용매 농도는 0, 희석만 고려)

  1. 약 3분
  2. 약 5분
  3. 약 7분
  4. 약 9분

    농도가 100ppm이 되기 위해서는 초기 농도의 1/4이 되어야 한다. 이를 수식으로 나타내면 다음과 같다.

    (1/4) = (400ppm) x e^(-kt)

    t = (1/k) x ln(4)

    공급된 공기의 부피는 60m3/min이므로, 1분당 공급되는 공기의 부피는 1m3/s이다. 따라서, 1초당 공급되는 공기의 부피는 1m3/s이다.

    (400ppm) x (392m^3) = 156,800mg

    C = 156,800mg / (392m^3)

    C' = 156,800mg / (392m^3 + 60m^3 x t)

    여기서 C는 초기 농도이고, C'는 시간 t 후의 농도이다.

    따라서, 위의 식에서 C'가 100ppm이 되는 시간 t를 구하면 된다.

    (156,800mg) / (392m^3 + 60m^3 x t) = 100ppm

    t = 8.9분
