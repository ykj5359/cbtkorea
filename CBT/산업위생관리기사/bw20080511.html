3. 육체적 작업능력(PWC)이 15kcal/min인 근로자가 1일 8시간동안 물체를 운반하고 있다. 이 때의 작업대사량은 8kcal/min 이고, 휴식시 대사량은 3kcal/min 이라면, 매시간당 휴식시간과 작업시간으로 가장 적절한 것은? (단, Hertig식을 적용한다.)

  1. 휴식시간은 28분, 작업시간은 32분이다.
  2. 휴식시간은 30분, 작업시간은 30분이다.
  3. 휴식시간은 32분, 작업시간은 28분이다.
  4. 휴식시간은 36분, 작업시간은 24분이다.
(정답률: 80%)
  • 30 CBT 기출문제AI

    2023-04-16 06:42

    Hertig식은 작업시간과 휴식시간을 균등하게 나누는 방법이다. 따라서, 8시간 중 작업시간과 휴식시간을 각각 4시간씩 나누면 된다.

    작업시간에는 PWC가 15kcal/min이므로, 15kcal/min x 60min x 4시간 = 3600kcal이 소비된다.

    휴식시간에는 대사량이 3kcal/min이므로, 3kcal/min x 60min x 4시간 = 720kcal이 소비된다.

    따라서, 작업시간과 휴식시간의 비율은 3600:720 = 5:1이 된다.

    작업시간 5분에 대해 휴식시간 1분을 적용하면, 작업시간은 5/6 x 240분 = 200분, 휴식시간은 1/6 x 240분 = 40분이 된다.

    이를 4시간씩 나누면, 휴식시간은 40분 x 4 = 160분, 작업시간은 200분 x 4 = 800분이 된다.

    따라서, 매시간당 휴식시간은 160분/8시간 = 20분, 작업시간은 800분/8시간 = 100분이 된다.

    이를 60분 단위로 변환하면, 휴식시간은 20분 x 3 = 60분(36분), 작업시간은 100분 x 3 = 300분(24분)이 된다.

    따라서, 정답은 "휴식시간은 36분, 작업시간은 24분이다."이다.

9. 어떤 작업장에서 TCE의 농도를 측정하여 다음과 같은 [데이터]를 얻었다. 이들이 대수정규분포를 한다고 할 때 기하평균(GM)은 약 몇 ppm 인가? [데이터] 30, 33, 40, 80, 150 (단위 : ppm)

  1. 50.7
  2. 54.4
  3. 60.3
  4. 66.6
(정답률: 74%)
  • 30 CBT 기출문제AI

    2023-04-16 06:42

    TCE의 농도를 대수정규분포로 가정하면, 각 측정값의 로그를 취한 후 평균을 구하면 기하평균이 된다. 따라서, 각 측정값의 로그를 취한 후 평균을 구해보면:

    log(30) = 1.477
    log(33) = 1.518
    log(40) = 1.602
    log(80) = 1.903
    log(150) = 2.176

    이들의 평균은 (1.477 + 1.518 + 1.602 + 1.903 + 2.176) / 5 = 1.735 이다. 이 값의 지수를 취하면 기하평균이 된다.

    exp(1.735) = 5.68

    따라서, 기하평균은 약 5.68 ppm 이다. 주어진 보기에서 가장 가까운 값은 "54.4" 이므로 정답은 "54.4" 이다.

93. 어떤 물질의 독성에 관한 인체실험 결과 안전 흡수량이 체중 kg 당 0.1mg 이었다. 체중이 50kg 인 근로자가 1일 8시간 작업할 경우 이 물질의 체내 흡수를 안전 흡수량이하로 유지하려면 공기 중 농도를 몇mg/m3 이하로 하여야 하는가? (단, 작업시 폐환기율은 1.25m3/h, 체내 잔류율은 1.0으로 한다.)

  1. 0.5
  2. 1.0
  3. 1.5
  4. 2.0
(정답률: 61%)
  • 30 CBT 기출문제AI

    2023-04-16 06:44

    안전 흡수량이 체중 kg 당 0.1mg 이므로, 50kg의 근로자는 하루에 안전 흡수량이 5mg를 넘지 않도록 물질을 흡수해야 합니다. 체내 잔류율이 1.0이므로, 흡입한 물질 중 100%가 체내에 흡수됩니다. 따라서, 하루에 흡입할 수 있는 물질의 양은 5mg입니다.

    따라서, 공기 중 농도를 계산하기 위해서는 다음과 같은 식을 사용할 수 있습니다.

    공기 중 농도 (mg/m3) = 하루에 흡입할 수 있는 물질의 양 (mg) ÷ 하루에 흡입하는 공기의 양 (m3)

    공기 중 농도 (mg/m3) = 5mg ÷ 10m3 = 0.5mg/m3
