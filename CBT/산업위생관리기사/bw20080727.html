5. 기초대사량이 80kcal/h, 작업대사량이 240kcal/h인 육제적인 작업을 할 때 이 작업의 실동률(%)은 약 얼마인가? (단, 사이또 오시마식을 적용한다.)

  1. 60%
  2. 70%
  3. 80%
  4. 90%
(정답률: 50%)
  • 30 CBT 기출문제AI

    2023-04-16 06:42

    사이또 오시마식에 따르면, 작업의 실동률은 다음과 같이 계산된다.

    실동률(%) = 작업대사량 / (기초대사량 + 작업대사량) × 100

    따라서, 육제적인 작업의 실동률은 다음과 같이 계산된다.

    실동률(%) = 240 / (80 + 240) × 100 ≈ 70%

    즉, 이 작업의 실동률은 약 70%이다.

44. 관경이 200MM인 직관 속을 공기가 흐르고 있다. 공기의 동점성계수가 1.5*10^(-5)m2/s이고, 레이놀즈수가 40000이하면 직관의 풍량(m3/hr)은?

  2. 약 420
  3. 약 530
  4. 약 650

    Q = (π/4) × D2 × V

    Re = (ρ × V × D) / μ

    V = (40000 × 1.5×10^(-5)) / (1.2 × 0.2) = 25 m/s

    열부하량은 작업장내에서 발생하는 열의 양을 의미하며, 이는 작업장내의 공기를 더욱 더 뜨겁게 만든다. 따라서 작업장내의 공기를 신선한 외기로 대체하여 열을 제거하고 실내온도를 유지하기 위해 전체환기가 필요하다.

    전체환기량은 다음과 같이 계산할 수 있다.

    전체환기량 = 작업장 부피 x 전환율 x 밀도 x 열용량 x (작업장내 온도 - 외기온도)

    작업장 부피는 작업장의 크기에 따라 다르며, 전환율은 작업장내 공기의 교환 빈도를 의미한다. 일반적으로 전환율은 6~8회/시간이 권장된다. 밀도는 공기의 밀도를 의미하며, 열용량은 공기의 단위 부피당 열의 에너지를 의미한다.

    여기서는 전환율을 6회/시간으로 가정하고, 밀도는 1.2 kg/m3로 가정한다. 열용량은 정압비열을 이용하여 계산할 수 있다.

    열용량 = 0.3 kcal/m3*C x 1.2 kg/m3 = 0.36 kcal/kg*C

    따라서 전체환기량은 다음과 같이 계산할 수 있다.

    전체환기량 = 작업장 부피 x 6 x 1.2 x 0.36 x (35-20) / 60

    전체환기량 = 작업장 부피 x 0.18

    작업장 부피를 구하기 위해서는 작업장의 크기와 높이를 곱한 값을 사용한다. 예를 들어, 작업장의 크기가 10m x 10m이고 높이가 3m이라면 작업장 부피는 다음과 같다.

    작업장 부피 = 10m x 10m x 3m = 300 m3

    따라서 전체환기량은 다음과 같다.

    전체환기량 = 300 x 0.18 = 54 m3/min

    하지만 이는 열부하량만 고려한 값이므로, 작업장내의 인원수, 기계 등 다른 열원들도 고려하여 보정해야 한다. 이를 고려하면 전체환기량은 약 74 m3/min이 된다.

79. 지상에서 음력이 10W 인 소음원으로부터 10m 떨어진 곳의 음압수준은 약 얼마인가? (단, 음속은 344.4m/s, 공기의 밀도는 1.18kg/m3 이다.)(오류 신고가 접수된 문제입니다. 반드시 정답과 해설을 확인하시기 바랍니다.)

  1. 96dB
  2. 99dB
  3. 102dB
  4. 1⑤dB
(정답률: 50%)
  • 30 CBT 기출문제AI

    2023-04-16 06:42

    음압수준은 다음과 같이 계산할 수 있다.

    음압수준(dB) = 20log10(압력/기준압력)

    여기서 압력은 다음과 같이 계산할 수 있다.

    압력 = 소음원에서 발생한 음파의 진폭 / 거리

    음파의 진폭은 음력과 밀도에 의해 결정된다.

    음파의 진폭 = 음력 / (음속 x 밀도)

    따라서, 압력은 다음과 같이 계산할 수 있다.

    압력 = 음력 / (음속 x 밀도 x 거리)

    이를 이용하여 문제를 풀면 다음과 같다.

    압력 = 10W / (344.4m/s x 1.18kg/m3 x 10m) = 0.0021Pa

    기준압력은 보통 20μPa(마이크로파스칼)로 정의된다. 따라서,

    음압수준 = 20log10(0.0021Pa/20μPa) = 99dB

    따라서, 정답은 "99dB"이다.
