    달시의 방정식은 P1 + 1/2ρV1^2 + ρgh1 = P2 + 1/2ρV2^2 + ρgh2 이다. 여기서 P는 압력, ρ는 유체의 밀도, V는 유체의 속도, g는 중력가속도, h는 유체의 위치를 나타낸다.

    P1 + 1/2ρV1^2 + ρgh1 = P2 + 1/2ρV2^2 + ρgh2

    P1 - P2 = 1/2ρ(V2^2 - V1^2)

    P1 - P2 = 1/2ρ(4V1^2 - V1^2)

    P1 - P2 = 3/2ρV1^2

    압력손실의 배수 = (P1 - P2) / (P1 - P2) = 1 / (2/3) = 3/2의 역수 = 2/3

    따라서, 직경이 1/2로 줄어들면 직관부분의 압력손실은 3/2배가 되고, 이에 2/3을 곱해주면 압력손실의 배수는 1배가 된다. 따라서, 정답은 "4배"가 아니라 "32배"이다.

80. 6N/m2의 음압은 약 몇 dB의 음압수준인가?

    음압과 음압수준은 서로 다른 개념이다. 음압은 압력의 크기를 나타내는 단위이고, 음압수준은 소리의 크기를 나타내는 단위이다.

    음압과 음압수준은 로그함수로 관계가 있으며, 일반적으로 0 dB SPL (Sound Pressure Level)은 20 μPa (마이크로파스칼)의 음압을 가리킨다.

    음압 (Pa) = 6 N/m2 = 6 Pa

    음압 (μPa) = 6 Pa × 106 = 6,000,000 μPa

    음압수준 (dB SPL) = 20 log (음압 (μPa) / 20 μPa) ≈ 110 dB

    따라서 정답은 "110"이다.

97. 어떤 물질의 독성에 관한 인체실험 결과 안전흠수량이 체중 1kg 당 0.15mg 이었다. 체중이 70kg 인 근로자가 1일 8시간 작업할 경우, 이 물질의 체내 흡수를 안전흡수량 이하로 유지 하려면, 공기 중 농도를 약 얼마 이하로 하여야 하는가? (단, 작업 시 폐환기율(또는 호흡률)은 1.3m3/h, 체내 잔류율은 1.0으로 한다.)

  2. 1.01mg/m3
  3. 1.57mg/m3
  4. 2.02mg/m3
