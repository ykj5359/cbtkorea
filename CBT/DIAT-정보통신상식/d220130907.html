1. 다음 컴퓨터의 분류 방법 중 처리 능력에 따른 분류에 해당하지 않는 것은?

  1. 미니 컴퓨터
  2. 워크스테이션
  3. 개인용 컴퓨터
  4. 디지털 컴퓨터
(정답률: 44%)

  • 2023-04-14 12:21

    디지털 컴퓨터는 처리 능력에 따른 분류에 해당하지 않는다. 이는 모든 컴퓨터가 디지털 신호를 처리하기 때문이다. 따라서, 디지털 컴퓨터는 다른 분류 방법에 따라 분류되어야 한다.

2. 다음 중 컴퓨터의 특징으로 옳지 않은 것은?

  1. 신속성
  2. 정확성
  3. 이동성
  4. 범용성
(정답률: 44%)

  • 2023-04-14 12:21

    컴퓨터의 특징으로 옳지 않은 것은 "이동성"입니다. 이유는 컴퓨터는 대개 크고 무거워서 이동하기 어렵기 때문입니다. 이동성이 필요한 경우에는 노트북 컴퓨터나 태블릿 컴퓨터 등을 사용할 수 있지만, 이들도 모두 제한된 이동성을 가지고 있습니다. 따라서 이동성은 컴퓨터의 특징 중 하나가 아닙니다.

3. 다음 중 주기억장치에 대한 설명으로 옳은 것은?

  1. CPU가 직접 접근하여 처리할 수 있다.
  2. 대량의 자료를 반영구적으로 저장할 수 있는 기억장치이다.
  3. 보조기억장치에 비해 저장 용량이 크고 가격이 저렴하지만 속도가 느리다.
  4. 광디스크, USB 메모리 등이 해당된다.
(정답률: 44%)

  • 2023-04-14 12:21

    주기억장치는 CPU가 직접 접근하여 처리할 수 있는 기억장치이다. 이는 CPU가 주기억장치에 저장된 데이터를 빠르게 읽고 쓸 수 있기 때문이다. 따라서 주기억장치는 CPU의 작업 속도에 직접적인 영향을 미치게 된다.

4. 다음 중 중앙처리장치(CPU)가 수행하는 기능으로 옳지 않은 것은?

  1. 작업 감독
  2. 영상 판독
  3. 산술 연산
  4. 논리 연산
(정답률: 44%)

  • 2023-04-14 12:21

    CPU는 작업 감독, 산술 연산, 논리 연산을 수행하지만, 영상 판독은 CPU가 수행하는 기능이 아닙니다. 영상 판독은 주로 그래픽 카드나 이미지 프로세싱 유닛 등 다른 하드웨어에서 수행됩니다. CPU는 주로 데이터 처리와 제어를 담당합니다.
1

5. 다음 입출력 장치 중 그 역할이 다른 하나는?

  1. 레이저 프린터
  2. 디지타이저
  3. 모니터
  4. X-Y 플로터
(정답률: 44%)

    디지타이저는 입력 장치로서, 펜이나 손가락으로 그림이나 글씨를 쓰면 그것을 디지털 데이터로 변환하여 컴퓨터에 입력하는 역할을 합니다. 반면, 레이저 프린터는 출력 장치로서, 컴퓨터에서 받은 디지털 데이터를 용지에 출력하는 역할을 합니다. 모니터는 출력 장치로서, 컴퓨터에서 받은 디지털 데이터를 화면에 출력하는 역할을 합니다. X-Y 플로터는 출력 장치로서, 컴퓨터에서 받은 디지털 데이터를 용지에 그리는 역할을 합니다. 따라서, 디지타이저는 입력 장치로서 그 역할이 다른 입출력 장치와 구분됩니다.

7. 다음 시스템 소프트웨어 분류 중에서 제어 프로그램에 해당하는 것은?

  1. 감시 프로그램
  2. 서비스 프로그램
  3. 문제 프로그램
  4. 언어 번역 프로그램
(정답률: 44%)

  • 2023-04-14 12:21

    제어 프로그램은 컴퓨터 시스템의 하드웨어나 소프트웨어를 제어하고 관리하는 역할을 합니다. 따라서 감시 프로그램이 제어 프로그램에 해당합니다. 감시 프로그램은 시스템의 상태를 지속적으로 모니터링하고, 문제가 발생하면 이를 감지하고 대처하는 역할을 합니다. 이를 통해 시스템의 안정성과 신뢰성을 유지할 수 있습니다.

11. 다음 중 하나의 중앙처리장치(CPU)가 주기억 장치에 적재된 여러 프로그램을 동시에 처리하는 운영체제 운영 방식은?

  2. 다중 처리 시스템

  4. 일괄 처리 시스템
(정답률: 44%)

1

  1. OLE
  2. GUI
  3. Plug & Play
  4. Open system
(정답률: 44%)

  • 2023-04-14 12:21

    정답은 "Open system"입니다.Windows는 OLE(객체 링크 및 임베딩), GUI(그래픽 사용자 인터페이스), Plug & Play(자동 하드웨어 인식 및 설치)를 지원합니다. 그러나 "Open system"은 Windows에서 지원하지 않는 용어입니다. "Open system"은 일반적으로 시스템이 다른 시스템과 상호 운용성을 가지며, 개방적인 표준과 프로토콜을 사용하여 다른 시스템과 통신할 수 있는 시스템을 의미합니다. Windows는 Microsoft의 소프트웨어 제품군으로, 다른 운영 체제와의 상호 운용성이 제한적입니다.
