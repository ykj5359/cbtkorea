6. 데이터의 기억 용량 단위를 크기순으로 올바르게 나열한 것은?

  1. KB < MB < GB < PB < TB
  2. KB < MB < GB < TB < PB
  3. KB < GB < MB < TB < PB
  4. KB < GB < MB < PB < TB
(정답률: 44%)

  • 2023-04-14 12:21

    데이터의 기억 용량은 바이트(Byte) 단위로 표시되며, 이를 더 큰 단위로 표현하기 위해 일반적으로 1024배씩 증가하는 이진 단위를 사용합니다. 따라서, KB(Kilobyte)는 1024바이트, MB(Megabyte)는 1024KB, GB(Gigabyte)는 1024MB, TB(Terabyte)는 1024GB, PB(Petabyte)는 1024TB를 의미합니다. 이에 따라, 크기순으로 나열하면 KB < MB < GB < TB < PB가 됩니다.
