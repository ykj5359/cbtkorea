  4. RAM은 전원이 차단되면 기억된 내용이 지워지는 휘발성 기억장치이다.

  2. 의사코드
  3. 고급언어
  4. 순서도
(정답률: 44%)

  • 2023-04-14 12:21

    정답은 "고급언어"입니다.자연어는 일반적인 언어로서 사람들이 일상적으로 사용하는 언어를 말합니다. 이러한 자연어를 사용하여 알고리즘을 표현하는 것은 이해하기 어렵고 모호하기 때문에 사용하지 않습니다.의사코드는 자연어와 프로그래밍 언어의 중간 형태로, 알고리즘을 자연어와 유사한 형태로 표현하는 것입니다. 이는 프로그래밍 언어로 바로 옮기기 쉽고, 이해하기 쉽기 때문에 많이 사용됩니다.순서도는 그림으로 표현된 알고리즘으로, 각각의 도형과 화살표를 사용하여 알고리즘의 흐름을 나타냅니다. 이는 시각적으로 이해하기 쉽고, 프로그래밍 언어로 바로 옮기기 어렵지만, 알고리즘을 설계하는 데 많이 사용됩니다.고급언어는 프로그래밍 언어를 말합니다. 이는 컴퓨터가 이해할 수 있는 형태로 작성된 코드로, 알고리즘을 구현하는 데 사용됩니다. 하지만 알고리즘을 설계하는 데 사용되는 것은 아니며, 알고리즘을 표현하는 데는 적합하지 않습니다.
