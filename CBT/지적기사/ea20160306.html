  1. E=(Y2-Y1) sinα-(X2-X1) cosa
  2. E=(Y2-Y1) sinα-(X2-X1) sina
  3. E=(Y2-Y1) cosα-(X2-X1) cosa
  4. E=(Y2-Y1) cosα -(X2-X1) sina
(정답률: 59%)
  • 30 CBT 기출문제AI

    2023-04-18 15:29

    직선의 방정식을 구하면 y-y1 = tanα(x-x1)이다. 이때 점 B(X2, Y2)가 이 직선 위에 있으므로 y2-y1 = tanα(x2-x1)이다. 이를 정리하면 x2-x1 = (y2-y1)/tanα이다.

    이제 점 A에서 직선에 내린 수선의 길이 E를 구해보자. E는 수선의 길이이므로 직선의 방향과 수직인 방향을 가진다. 따라서 직선의 방향벡터와 수직인 벡터를 구해내면 E를 구할 수 있다.

5. 그림과 같이 원필지 □ABCD를 분할선 PQ로 분할 할 때 협각이 각각 α, β, γ, δ이면 성립하는 등식은?

  2. α+γ=β+δ
  3. α+δ=β+γ
  4. α+β+γ+δ=360°
(정답률: 65%)

    2023-04-18 15:31

    분할선 PQ가 원의 중심 O와 만나는 점을 E라고 하면, 각 AOE, BOE, COE, DOE는 모두 90도이므로 삼각형 AOE, BOE, COE, DOE는 직각삼각형이다. 따라서 각각의 대변에 대한 사인값은 다음과 같다.

    sinα = AE/OE
    sinβ = BE/OE
    sinγ = CE/OE
    sinδ = DE/OE

    또한, 삼각형 AOE, BOE, COE, DOE는 모두 삼각형 ABCD의 내부에 있으므로, 각각의 대변에 대한 사인값은 모두 같다. 즉,

    AE/OE = BF/OF = CG/OG = DH/OH

    따라서,

    sinα = sinβ = sinγ = sinδ

    이 되고, 이를 이용하여 다음과 같은 등식이 성립한다.

    sinα + sinβ = sinγ + sinδ

    이를 사인의 합공식에 따라 변형하면,

    2sin((α+β)/2)cos((α-β)/2) = 2sin((γ+δ)/2)cos((γ-δ)/2)

    cos((α-β)/2) = cos((γ-δ)/2)

    여기에 cos의 합공식을 적용하면,

    cos(α/2)cos(β/2) - sin(α/2)sin(β/2) = cos(γ/2)cos(δ/2) - sin(γ/2)sin(δ/2)

    cos(α/2)cos(β/2) + cos(γ/2)cos(δ/2) = sin(α/2)sin(β/2) + sin(γ/2)sin(δ/2)

    이를 다시 사인의 합공식에 적용하면,

    2sin((α+β)/2)sin((γ+δ)/2) = 2cos((α-β)/2)cos((γ-δ)/2)

    sin(α+β) = sin(γ+δ)

    따라서,

    α+β = γ+δ

    이 된다.

37. 카메라의 초점거리 153mm,촬영경사 7°로 평지를 촬영한 사진이 있다. 이 사진의 등각점은 주점으로부터 최대경사선 상의 몇 mm인 곳에 위치하는가?

  2. 10.63mm
  3. 12.36mm
  4. 13.63mm
(정답률: 34%)
  • 30 CBT 기출문제AI

    2023-04-18 15:13

    등각점은 카메라와 지면 사이의 수직거리와 관련이 있다. 이 거리는 다음과 같이 계산할 수 있다.

    카메라와 지면 사이의 거리 = 초점거리 / cos(촬영경사)

    여기서 cos(7°)는 약 0.9925이므로,

    카메라와 지면 사이의 거리 = 153 / 0.9925 ≈ 154.23mm

    따라서 등각점은 최대경사선 상에서 154.23mm 떨어진 곳에 위치한다.

    이제 최대경사선의 길이를 계산해보자. 이는 다음과 같이 계산할 수 있다.

    최대경사선의 길이 = 등각점까지의 거리 / sin(촬영경사)

    여기서 sin(7°)는 약 0.1222이므로,

    최대경사선의 길이 = 154.23 / 0.1222 ≈ 1261.5mm

    따라서 등각점은 최대경사선 상에서 1261.5mm 떨어진 곳에 위치한다.

    마지막으로 등각점과 주점 사이의 거리를 계산해보자. 이는 다음과 같이 계산할 수 있다.

    등각점과 주점 사이의 거리 = 최대경사선의 길이 * tan(촬영경사)

    여기서 tan(7°)는 약 0.1222이므로,

    등각점과 주점 사이의 거리 = 1261.5 * 0.1222 ≈ 154.23mm

    따라서 등각점은 주점으로부터 154.23mm 떨어진 곳에 위치한다.

40. 지표에서 거리 1000m 떨어진 A, B 두개의 수직터널에 의하여 터널 내외의 연결측량을 하는 경우 수직터널의깊이가 1500m라 할 때, 두 수직터널 간 거리의 지표와 지하에서의 차이는? (단, 지구반지름 R=6370km)

  1. 15cm
  2. 24cm
  3. 48cm
  4. 52cm
(정답률: 53%)
  • 30 CBT 기출문제AI

    2023-04-18 15:22

    지표에서의 거리가 1000m이므로 A, B 두 지점 간의 지표 거리는 2000m이다. 수직터널의 깊이가 1500m이므로 지하에서의 거리는 2000m - 1500m = 500m이다. 이제 두 지점 간의 지표와 지하에서의 거리 차이를 구해보자.

    지표에서의 거리와 지하에서의 거리 차이는 지구의 곡률 때문에 발생한다. 지구의 곡률은 지구 반지름 R에 비례하므로, 두 지점 간의 곡률 거리 차이는 다음과 같다.

    곡률 거리 차이 = R(1 - cosθ)

    여기서 θ는 두 지점 간의 중심각이다. 중심각은 두 지점 간의 지표 거리와 지구 반지름 R을 이용하여 구할 수 있다.

    cosθ = (지구 반지름 R)^2 + (지점 간 지표 거리)^2 - (지점 간 지하 거리)^2 / (2 * 지구 반지름 R * 지점 간 지표 거리)

    cosθ = (6370km)^2 + (2000m)^2 - (500m)^2 / (2 * 6370km * 2000m)

    cosθ = 0.999969

    θ = 0.000031 radians

    따라서 곡률 거리 차이는 다음과 같다.

    곡률 거리 차이 = 6370km(1 - cos0.000031)

    곡률 거리 차이 = 24cm

    따라서 두 수직터널 간 거리의 지표와 지하에서의 차이는 24cm이다.
