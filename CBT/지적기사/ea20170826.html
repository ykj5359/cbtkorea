6. 지상 1km2의 면적을 도상 4cm2로 표시한 도면의 축척은?

  1. 1/2500
  2. 1/5000
  3. 1/25000
  4. 1/50000
(정답률: 64%)
  • 30 CBT 기출문제AI

    2023-04-18 15:41

    면적의 축척과 길이의 축척은 다르다는 것을 기억해야 한다. 면적의 축척은 실제 면적 대비 도면상 면적의 비율을 나타내는 것이다.

    지상 1km2의 면적을 도상 4cm2로 표시하고 있다면, 면적의 축척은 다음과 같이 계산할 수 있다.

    면적의 축척 = (도면상 면적) / (실제 면적)

    도면상 면적은 4cm2이고, 실제 면적은 1km2이다.

    1km2 = 1000m x 1000m = 1000000m2

    따라서, 면적의 축척은

    면적의 축척 = 4cm2 / 1000000m2

    = 4 / (1000000 x 10000)

    = 1 / 250000

    하지만, 보기에서는 길이의 축척을 나타내는 것이므로, 이 값을 길이의 축척으로 변환해야 한다.

    길이의 축척 = (실제 길이) / (도면상 길이)

    실제 길이는 1km이고, 도면상 길이는 얼마인지 알아야 한다.

    1km = 1000m = 100000cm

    따라서, 도면상 길이는

    도면상 길이 = (실제 길이) x (면적의 축척)

    = 1km x (1 / 250000)

    = 4cm

    즉, 지상 1km2의 면적을 도상 4cm2로 표시한 도면의 축척은 1/50000이다.
