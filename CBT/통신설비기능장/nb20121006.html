  3. 약 44.4

10. PCM-24 방식에서 1프레임시간(Tf)과 1통화로에 할당된 시간(Tc)은 얼마인가?

  2. Tf=125[μs], Tc=5.2[μs]

    PCM-24 방식에서 1프레임은 24개의 time slot으로 구성되며, 각 time slot은 1비트를 전송하는 시간을 가진다. 따라서 1프레임의 전송 시간은 24 x 1비트 = 24[비트]가 된다. 이를 전송 속도로 환산하면 24[비트] / 125[μs] = 192[kbps]가 된다.

    한편, 1통화로에 할당된 시간은 1초당 8000샘플링, 24비트 샘플링으로 이루어지므로 1샘플당 24비트 / 8000샘플링 = 3/1000[ms] = 3[μs]가 소요된다. 따라서 1통화로에 할당된 시간은 8000샘플링 x 24비트 x 3[μs] = 460.8[ms]가 된다. 이를 전송 속도로 환산하면 460.8[ms] / 1[통화] / 125[μs] = 2944[프레임/통화]가 된다.

    따라서, 1프레임시간(Tf)은 125[μs], 1통화로에 할당된 시간(Tc)은 5.2[μs]가 된다.

12. 10[MHz]의 반송파를 진폭이 20[V]이고 주파수가 15[kHz]인 변조신호로 주파수변조하는 경우 피변조파의 대역폭은 얼마인가? (단, 주파수감도계수 kf는 60[Hz/V]이다.)

  4. 33.8[kHz]
(정답률: 53%)

    주파수 변조에서 피크 대역폭은 kf와 변조 신호의 최대 진폭에 비례합니다. 따라서, 변조 신호의 최대 진폭이 20[V]이므로, 피크 대역폭은 kf x 20[V] = 60[Hz/V] x 20[V] = 1200[Hz]입니다.
