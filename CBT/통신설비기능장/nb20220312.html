2. 전화선의 채널대역폭이 6,000[Hz]이고 채널의 출력 S/N=10,000인 경우 통신용량은? (단, log210=3.322로 하고 근사치로 계산.)

  2. 19,063 [bit/sec]
  3. 79,728 [bit/sec]
  4. 79,968 [bit/sec]

    통신용량(C)은 다음과 같이 계산할 수 있습니다.

    C = 채널대역폭 x log2(1 + S/N)

    여기서 채널대역폭은 6,000[Hz], S/N은 10,000으로 주어졌으므로,

    C = 6,000 x log2(1 + 10,000/1)

    ≈ 6,000 x 13.287

    ≈ 79,722.6 [bit/sec]

    따라서, 가장 가까운 근사치인 "79,728 [bit/sec]"가 정답입니다.

3. 100[W] 전력의 반송파를 사용하여 신호를 변조도 80[%]로 진폭 변조하여 전송하고자 할 때 소요되는 총 전력은 몇 [W] 인가?

  1. 80
  2. 100
  3. 132
  4. 140
(정답률: 70%)

    진폭 변조된 신호의 총 전력은 다음과 같은 공식을 사용하여 계산할 수 있습니다:

    P_total = P_c (1 + (m^2) / 2)

    여기서 P_c는 반송파 전력이고, m은 변조 지수입니다. 변조 지수는 변조 신호의 최대 진폭을 반송파의 최대 진폭으로 나눈 값입니다. 변조도는 변조 지수를 백분율로 표현한 것입니다. 따라서 변조도가 80%일 경우, 변조 지수 m은 0.8이 됩니다.

    본 문제에서 반송파 전력 P_c는 100W이고, 변조 지수 m은 0.8입니다. 따라서 위의 공식에 대입하여 계산하면 다음과 같습니다:

    P_total = 100 (1 + (0.8^2) / 2) = 132 [W]

    따라서, 본 문제의 답은 132W입니다.

13. UHF 주파수 대역의 파장 범위는?

  3. 0.1 ~ 1[m]
  4. 100 ~ 1000[cm]
(정답률: 80%)

    UHF는 Ultra High Frequency의 약자로, 주파수 범위는 대체로 300MHz에서 3GHz 사이입니다. 전파의 속도는 빛의 속도와 같으므로 약 300,000 km/s 입니다. 따라서 파장 λ는 속도 c를 주파수 f로 나눈 것이며, 이를 식으로 나타내면 λ = c / f 입니다.

    UHF의 최저 주파수에서의 파장은 λ = 300,000 km/s / 300 MHz = 1 m입니다.
    UHF의 최고 주파수에서의 파장은 λ = 300,000 km/s / 3 GHz = 0.1 m입니다.
    따라서 UHF 주파수 대역의 파장 범위는 0.1 ~ 1[m]입니다.

    F_total = F1 + (F2-1)/G1 + (F3-1)/(G1G2) + ... + (Fn-1)/(G1G2*...*Gn-1)

    여기서 F는 잡음 지수, G는 이득을 나타냅니다. 본 문제에서는 두 개의 증폭기만 주어져 있으므로, 이들에 대해서만 고려하면 됩니다.

    F1은 초단 증폭기의 잡음 지수 2, G1은 초단 증폭기의 이득 10입니다.

    따라서 위의 공식에 대입하여 계산하면 다음과 같습니다:

    F_total = 2 + (4-1)/10 = 2.3

    따라서, 본 문제의 답은 2.3입니다.

    OSI(Open Systems Interconnection) 7계층 모델은 네트워킹에서 데이터 통신을 이해하기 위해 국제 표준화 기구(ISO)에 의해 개발된 모델입니다. 이 모델은 다음과 같이 7개의 계층으로 구성되어 있습니다:

    1. **물리 계층(Physical Layer):** 이 계층은 전기적, 기계적, 기능적인 특성을 이용해 데이터를 전송합니다. 케이블, 카드, 허브 등 물리적 매체를 관리합니다.

    2. **데이터 링크 계층(Data Link Layer):** 이 계층은 네트워크 기기 간의 데이터 전송과 오류 검출 및 재전송을 담당합니다. 이더넷과 MAC 주소가 이 계층에서 작동합니다.

    3. **네트워크 계층(Network Layer):** 이 계층에서는 다양한 네트워크 간의 통신 경로를 결정하고, IP 주소를 관리합니다. 라우팅과 같은 작업이 이루어집니다.

    4. **전송 계층(Transport Layer):** 이 계층은 데이터의 전송을 관리하며, TCP와 UDP 프로토콜이 이곳에서 작동합니다. 데이터의 분할 및 재조립, 오류 검출 및 복구 등을 수행합니다.

    5. **세션 계층(Session Layer):** 이 계층은 네트워크 상의 두 컴퓨터 사이의 통신 세션을 만들고, 유지하며, 종료합니다.

    6. **표현 계층(Presentation Layer):** 이 계층은 데이터의 암호화, 복호화, 압축, 해제 등을 담당합니다. 즉, 데이터를 안전하게 전송하기 위한 변환 작업을 수행합니다.

    7. **응용 계층(Application Layer):** 이 계층은 사용자와 가장 가까운 계층으로, 사용자 인터페이스나 메일, 웹 브라우저 등의 응용 프로그램이 이곳에서 작동합니다.

    이 7계층 모델은 네트워크에서 데이터가 어떻게 패키징되고, 전송되며, 수신되는지를 이해하는 데 도움을 줍니다. 각 계층은 서로 독립적으로 작동하며, 한 계층에서 발생하는 일이 다른 계층에 직접적인 영향을 주지 않습니다. 이를 통해 효율적인 네트워킹 및 문제 해결이 가능해집니다.
