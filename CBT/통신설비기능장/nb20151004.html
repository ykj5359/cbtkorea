16. 마이크로파 통신에서 송신출력이 2[W], 송ㆍ수신 안테나 이득이 각각 35[dBi], 수신 입력 레벨이 -30[dBm]일 때 자유공간 손실은?

  1. 110[dB]
  2. 125[dB]
  3. 133[dB]
  4. 142[dB]
(정답률: 67%)
  • 30 CBT 기출문제AI

    2023-04-12 11:42

    자유공간 손실은 다음과 같이 계산됩니다.

    자유공간 손실 = 20log(d) + 20log(f) - 147.55

    여기서 d는 거리(m), f는 주파수(MHz)입니다.

    주어진 문제에서는 거리와 주파수가 주어지지 않았으므로, 자유공간 손실을 계산하기 위해서는 다른 방법을 사용해야 합니다.

    송신출력이 2[W]이므로, 수신측에 도달하는 파워는 다음과 같습니다.

    수신 파워 = 송신출력 + 송신안테나 이득 - 자유공간 손실 - 수신안테나 이득

    여기서 송신안테나 이득과 수신안테나 이득은 각각 35[dBi]이므로, 다음과 같이 계산할 수 있습니다.

    수신 파워 = 2[W] + 35[dBi] - 자유공간 손실 - 35[dBi]

    수신 입력 레벨이 -30[dBm]이므로, 다음과 같은 식이 성립합니다.

    -30[dBm] = 10log(수신 파워)

    따라서, 수신 파워는 다음과 같습니다.

    수신 파워 = 10^(-30/10) = 1 nW

    이를 이용하여, 자유공간 손실을 계산할 수 있습니다.

    2[W] + 35[dBi] - 자유공간 손실 - 35[dBi] = 1 nW

    자유공간 손실 = 20log(2) + 20log(10^9) - 20log(1 nW) = 133[dB]

    따라서, 정답은 "133[dB]"입니다.

  2. 표준시간
