9. 다음 중 데이터 전송 방식에서 동기식의 특성이 아닌 것은?

    '동기는 글자 단위로 이루어진다.'는 동기식 데이터 전송의 특성이 아닙니다.

    동기식 전송 방식은 데이터를 블록(또는 프레임) 단위로 전송하는 특성을 가집니다. 이 방식에서 각 블록은 동기 문자로 시작되며, 이는 데이터 블록의 시작을 표시합니다. 또한 블록 내부의 데이터 사이에는 휴지 간격이 없습니다. 이는 동기식 전송 방식이 전송 효율성을 높이기 위해 휴지 시간을 최소화하는 특성 때문입니다. 마지막으로 동기식 전송 방식은 주로 중고속 데이터 전송에 사용되며, 전송 속도는 보통 2,400 bps 이상입니다.

    - 데이터 전송 방식: 데이터를 한 장치에서 다른 장치로 이동시키는 방법을 말합니다. 이는 통신 네트워크에서 중요한 역할을 합니다.
    - 동기식: 동기식 전송 방식에서는 데이터를 블록 단위로 전송하며, 각 블록은 동기 문자로 시작합니다.
    - 동기문자: 동기식 전송 방식에서 데이터 블록의 시작을 표시하는 문자를 말합니다.
    - 휴지 간격: 데이터 전송에서 데이터 단위 사이에 발생하는 휴지 시간을 말합니다. 동기식 전송 방식에서는 이 휴지 시간을 최소화합니다.
    - 전송 속도: 데이터가 전송되는 속도를 말합니다. 동기식 전송 방식에서는 보통 2,400 bps 이상의 속도를 사용합니다.
