    따라서 정답은 "159"입니다.

    IC = βIB = 100 × 0.2mA = 20mA

    (V1 - V2) / R1 = (V3 - V4) / R2

    (V2 - VG) / R2 = (V3 - VG) / R2

    (V1 - VG) / R1 = (V3 - VG) / R2

    (V2 - VG) / (V3 - VG) = R1 / R2
