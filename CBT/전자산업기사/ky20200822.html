3. 회로에서 Vi = 1V일 때 전류 IL은 몇 mA 인가?

  1. -0.4
  2. -0.1
  3. 0.1
  4. 0.4
(정답률: 50%)
  • 30 CBT 기출문제AI

    2023-04-19 ⑤:34

    Vi = 1V 일 때, R1과 R2은 병렬 연결이므로 등가저항 Req은 다음과 같다.

    1/Req = 1/R1 + 1/R2 = 1/2kΩ + 1/1kΩ = 1/1.5kΩ

    Req = 1.5kΩ

    따라서, IL은 다음과 같이 계산할 수 있다.

    IL = (Vi - Vo) / Req = (1V - (-0.4V)) / 1.5kΩ = 0.4mA

    따라서, 정답은 "0.4"이다.

(정답률: 44%)

    2023-04-19 ⑤:37

    콜라우시 브리지는 전류가 흐르지 않는다는 가정 하에 만들어진 회로이므로, E2와 E3 사이의 전압과 E3와 E1 사이의 전압이 같다는 것을 이용할 수 있다. 따라서, E2와 E3 사이의 전압을 V2(V), E3와 E1 사이의 전압을 V3(V)이라고 하면, V2 = V3 이다. 이를 이용하여 각 저항에 대한 전압과 전류를 구하면 다음과 같다.

    - R1에 흐르는 전류: I1 = (E1 - V2) / R1
    - R2에 흐르는 전류: I2 = V2 / R2
    - R3에 흐르는 전류: I3 = V3 / R3

    여기서, 전류의 보존 법칙에 따라 I1 = I2 + I3 이므로, 다음과 같은 식이 성립한다.

    (E1 - V2) / R1 = V2 / R2 + V3 / R3

    이를 정리하면 다음과 같다.

    E1 = V2 * R1 * R3 / (R1 * R3 + R2 * R3 + R1 * R2)

    따라서, 정답은 "" 이다.
