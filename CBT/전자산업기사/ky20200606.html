7. 다음 그림과 같은 회로에서 RL에 50mA의 전류가 흐를 때 RL(Ω)은? (단, Vin = 5V, R1 = 10kΩ, R2 = 470kΩ 이다.)

  1. 47
  2. 470
  3. 4700
  4. 47000
(정답률: 71%)
  • 30 CBT 기출문제AI

    2023-04-19 ⑤:34

    전류의 크기는 전압과 저항에 비례한다는 오므로, RL에 흐르는 전류를 구하기 위해 먼저 회로 전체의 저항을 구해야 한다. R1과 R2는 병렬 연결이므로 다음과 같이 계산할 수 있다.

    1/R전체 = 1/R1 + 1/R2 = 1/10k + 1/470k = 0.00002128

    R전체 = 46934.7Ω

    따라서, RL에 흐르는 전류는 다음과 같다.

    I = Vin / R전체 = 5 / 46934.7 = 0.0001063A = 106.3μA

    하지만 문제에서는 RL에 50mA의 전류가 흐른다고 했으므로, RL의 저항은 다음과 같이 구할 수 있다.

    RL = VL / I = 5 / 0.⑤ = 100Ω

    따라서, 보기에서 정답이 "4700" 인 이유는 아마도 R2의 값이 470kΩ이기 때문에 "470"과 "47000"이라는 값도 가능하지만, RL의 값이 100Ω이므로 "4700"이 가장 적절한 값이라고 할 수 있다.
