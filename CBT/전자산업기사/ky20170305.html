6. 부하저항 RL=16Ω에 20Vpeak의 신호를 공급한 B급 증폭기의 입력전력 Pi와 출력전력 Po는? (단, 전원전압 VCC=30V이다.)

  1. Pi = 24W, Po = 13W
  2. Pi = 34W, Po = 23W
  3. Pi = 24W, Po = 28W
  4. Pi = 54W, Po = 43W
(정답률: 67%)
  • 30 CBT 기출문제AI

    2023-04-19 ⑤:31

    B급 증폭기는 입력 신호의 절반 주기에 대해서만 증폭을 수행하므로, 입력전력은 전체 주기에 대한 평균값으로 계산해야 한다. 입력전력은 다음과 같이 계산할 수 있다.

    Pi = (VCC/π)²RL = (30/π)²×16 ≈ 24W

    출력전력은 부하저항에 걸린 전압과 전류를 이용하여 계산할 수 있다. 부하저항에 걸린 전압은 Vpeak/2 = 10V이고, 이에 대한 전류는 Vpeak/2RL = 0.625A이다. 따라서 출력전력은 다음과 같이 계산할 수 있다.

    Po = (Vpeak/2)²/RL = 10²/16 ≈ 6.25W

    하지만 B급 증폭기는 출력 신호의 절반 주기에 대해서만 증폭을 수행하므로, 출력전력은 전체 주기에 대한 평균값으로 계산해야 한다. 출력전력은 다음과 같이 계산할 수 있다.

    Po = Pavg = Pmax/2 = 6.25/2 ≈ 3.125W

    따라서 정답은 "Pi = 24W, Po = 13W"이다.

12. 트랜지스터의 컬렉터 누설전류가 주위 온도변화로 40μA에서 200μA로 증가할 때 컬렉터 전류가 1mA에서 1.8mA로 되었다면 안정도(S)는 약 얼마인가?

  1. 3
  2. 5
  3. 12
  4. 18
(정답률: 74%)
  • 30 CBT 기출문제AI

    2023-04-19 ⑤:31

    안정도(S)는 다음과 같이 계산할 수 있다.

    S = (ΔIc / Ic) / (ΔVbe / Vbe)

    여기서 ΔIc는 컬렉터 누설전류의 증가량, Ic는 최종 컬렉터 전류, ΔVbe는 베이스-에미터 전압의 변화량, Vbe는 최종 베이스-에미터 전압을 나타낸다.

    주어진 문제에서 ΔIc는 200μA - 40μA = 160μA이고, Ic는 1.8mA이다. 또한, 베이스-에미터 전압의 변화량은 무시할 수 있으므로 ΔVbe = 0이다. 따라서,

    S = (160μA / 1.8mA) / 0 = 0

    안정도(S)는 0이므로, 이 트랜지스터는 안정하지 않은 상태이다. 따라서, 이 문제의 정답은 "5"가 아닌 "0"이다.

    전류계의 최대 측정 가능한 전류는 100 mA 이므로, 0.6 A까지 측정하려면 분류기를 사용해야 한다. 분류기는 내부저항과 외부저항으로 이루어져 있으며, 외부저항을 조절하여 측정하고자 하는 전류 범위에 맞게 확대 측정할 수 있다.

78. 다음은 진폭변조 회로의 출력을 오실로스코프로 측정한 결과이다. a=3b이면 변조율은 몇 % 인가?

  1. 25
  2. 50
  3. 75
  4. 100

  • 30 CBT 기출문제AI
