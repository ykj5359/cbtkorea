  1. 1L [H]
  2. 2L [H]
  3. 4L [H]
  4. 8L [H]
(정답률: 71%)
  • 30 CBT 기출문제AI

    2023-04-12 11:29

    같은 철심 위에 감긴 코일은 서로 결합되어 인덕턴스가 더해진다. 따라서 각 코일의 인덕턴스를 합산하면 된다. 코일이 2개이므로 각각의 인덕턴스를 더해주면 된다.

    L1 + L2 = L + L = 2L

    따라서 합성 인덕턴스는 2L이다. 하지만 직렬로 접속했으므로 전류가 흐르는 방향이 같아 자기장이 서로 방해하게 되어 인덕턴스가 감소한다. 이 때, 결합계수가 1이므로 감소하는 정도는 최소화된다. 따라서 합성 인덕턴스는 2L에서 감소하지 않고 그대로 2L이다.

18. 이득이 12[dB], 잡음지수 8[dB]인 증폭기 뒤에 잡음지수 10[dB]인 증폭기를 연결할 때 종합잡음지수는?

  1. 1.5 [dB]
  2. 1.25 [dB]
  3. 9.6 [dB]
  4. 8.75 [dB]
(정답률: 59%)
  • 30 CBT 기출문제AI

    2023-04-12 11:29

    두 증폭기를 연결할 때 종합잡음지수는 다음과 같이 계산됩니다.

    종합잡음지수 = 10log(10^(잡음지수1/10) + 10^(잡음지수2/10) - 1)

    여기서, 잡음지수1은 이득이 12[dB]인 증폭기의 잡음지수인 8[dB]이고, 잡음지수2는 잡음지수가 10[dB]인 증폭기의 잡음지수입니다.

    따라서, 종합잡음지수 = 10log(10^(8/10) + 10^(10/10) - 1) = 8.75[dB]가 됩니다.

    정답은 "8.75 [dB]"입니다.

    2023-04-12 11:38

    입력 신호와 출력 신호의 전압 비율을 나타내는 전압이득(Av)은 출력 전압(Vout)을 입력 전압(Vin)으로 나눈 값입니다.

    이 증폭기 회로에서는 입력 신호가 베이스-에미터 전압에 의해 증폭되어 출력 신호가 콜렉터-에미터 전압으로 나타납니다.

    따라서 전압이득(Av)은 출력 전압(Vout)을 입력 전압(Vin)으로 나눈 값인데, 이 회로에서는 R1과 R2가 베이스-에미터 회로를 형성하고, R3과 RL이 콜렉터-에미터 회로를 형성합니다.

    따라서 전압이득(Av)은 R3과 RL의 병렬 저항(R3||RL)을 R1과 R2의 직렬 저항(R1+R2)으로 나눈 값입니다.

    R1 = 1kΩ, R2 = 4.7kΩ, R3 = 1kΩ, RL = 4.7kΩ 일 때,

    R3||RL = (1kΩ x 4.7kΩ) / (1kΩ + 4.7kΩ) = 800Ω

    R1+R2 = 1kΩ + 4.7kΩ = 5.7kΩ

    전압이득(Av) = (R3||RL) / (R1+R2) = 800Ω / 5.7kΩ ≈ 0.14

    하지만 문제에서는 전압이득(Av)을 dB 단위로 표시하라고 하였으므로,

    전압이득(Av) = 20log(Av) ≈ 20log(0.14) ≈ -9.5dB

    따라서 보기에서 정답이 "11"인 것은 아니며, 올바른 정답은 "5"입니다.

    3-4 = -1
    4-4 = 0
    5-4 = 1
    6-4 = 2

    이를 제곱하여 합산합니다.

    (-2)^2 + (-1)^2 + 0^2 + 1^2 + 2^2 = 4 + 1 + 1 + 4 = 10

    따라서 편차 제곱합(S)은 10이 됩니다.

    하지만 소숫점 3자리까지 구하라는 조건이 있으므로, 10을 소수점 3자리까지 반올림하여 1.029가 됩니다.

    즉, 정답이 "1.029"인 이유는 편차 제곱합(S)이 10이지만, 소숫점 3자리까지 반올림하여 구하라는 조건이 있기 때문입니다.
