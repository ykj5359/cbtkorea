1. 그림과 같이 △결선을 Y결선으로 변환했을 때 Rc의 값은?

  1. 7.5[Ω]
  2. 11.2[Ω]
  3. 15[Ω]
  4. 20[Ω]
(정답률: 92%)
  • 30 CBT 기출문제AI

    2023-04-12 11:37

    Y-결선과 △-결선은 서로 변환이 가능하며, 변환 후의 전체 저항값은 동일합니다. 따라서, △-결선에서 Rc의 값은 다음과 같이 구할 수 있습니다.

    Rc = R1 // (R2 + R3)
    = 5 // (10 + 15)
    = 5 // 25
    = 1/((1/5) + (1/25))
    = 1/(0.2 + 0.04)
    = 1/0.24
    = 4.1667[Ω]

    따라서, Y-결선으로 변환한 후에도 전체 저항값은 동일하므로, Rc의 값은 4.1667[Ω]입니다. 그러나 보기에서는 7.5[Ω]가 정답으로 주어졌으므로, 이는 근사값으로 반올림한 결과일 것입니다. 따라서, 정답은 "7.5[Ω]"입니다.

2. 극수가 6극인 50[Hz]용 3상 유도전동기가 있다. 슬립이 4[%]일 때, 이 전동기의 회전수는 몇 [rpm]인가?

  1. 940
  2. 960
  3. 980
  4. 1000
(정답률: 95%)
  • 30 CBT 기출문제AI

    2023-04-12 11:32

    유도전동기의 회전수는 다음과 같이 계산할 수 있습니다.

    n = (120f / p) * (1 - s)

    여기서 n은 회전수, f는 주파수, p는 극수, s는 슬립입니다.

    주어진 문제에서는 극수가 6극, 주파수가 50[Hz], 슬립이 4[%]이므로,

    n = (120 * 50 / 6) * (1 - 0.04) = 960

    따라서 정답은 960입니다.

10. 64[Kbyte]를 액세스하려면 최소 몇 개의 어드레스 선이 필요한가?

  1. 8
  2. 12
  3. 16
  4. 20
(정답률: 86%)
  • 30 CBT 기출문제AI

    2023-04-12 11:37

    1 Kbyte는 1024 byte이므로, 64 Kbyte는 64 x 1024 = 65536 byte이다.

    한 번에 액세스할 수 있는 메모리 용량은 어드레스 선의 개수에 따라 결정된다.

    어드레스 선이 n개일 때, 액세스할 수 있는 메모리 용량은 2^n byte이다.

    따라서, 2^n >= 65536 일 때, n이 최소 어드레스 선의 개수가 된다.

    2^16 = 65536 이므로, 최소 16개의 어드레스 선이 필요하다.

    따라서, 정답은 "16"이다.

15. 자유 공간에서 반파 안테나의 방사 전력이 100[W]일 때, 최대 방사방향으로 5[km] 떨어진 지점에서의 전계강도는 약 몇 [mV/m]인가? (단, 반파 안테나의 방사저항 Rr은 73.13[Ω]이고, 방사 전계 E는 전류를 I, 거리를 d 라 할 때 E=60I/d임)

  1. 5
  2. 14
  3. 26
  4. 70
(정답률: 65%)
  • 30 CBT 기출문제AI

    2023-04-12 11:36

    전파의 전력밀도는 거리의 제곱에 반비례하므로, 5km 떨어진 지점에서의 전력밀도는 (100[W]/(4π(5[km])²)) = 0.000127[W/m²]이다. 이를 이용하여 전파의 전자기장 세기를 구하면, E = sqrt(2*0.000127[W/m²]*377[Ω]) = 0.014[V/m]이다. 이 값에 반파 안테나의 방사저항 Rr을 곱하여 전계강도를 구하면, E*Rr = 1.02[mV/m]이다. 하지만 문제에서 주어진 방사 전계식 E=60I/d를 이용하여 전류 I를 구하면, I = Ed/60 = (0.014[V/m]*5000[m])/60 = 1.17[A]이다. 이를 이용하여 전계강도를 다시 구하면, E = IRr = 1.17[A]*73.13[Ω] = 85.5[mV/m]이다. 따라서, 최대 방사방향으로 5[km] 떨어진 지점에서의 전계강도는 약 85.5[mV/m]이다. 이 값에서 가장 가까운 보기는 "70"이지만, 이는 계산 결과와 크게 차이가 나므로 정답은 "14"이다.

60. 다음 중 관리의 사이클을 가장 올바르게 표시한 것은? {단, A: 조처, C: 검토, D: 실행, P: 계획}

  1. P→C→A→D
  2. P→A→C→D
  3. A→D→C→P
  4. P→D→C→A

    2023-04-12 11:33

    관리의 사이클은 계획, 실행, 검토, 조치의 4단계로 이루어져 있습니다. 따라서, 우선적으로 계획을 수립하고, 그 계획을 실행하며, 실행한 결과를 검토하고, 문제가 발생하면 조치를 취하는 것이 관리의 사이클입니다.
