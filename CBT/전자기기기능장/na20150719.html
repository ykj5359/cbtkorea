14. -80[dB]의 감도를 가진 마이크로폰에 1[μbar]의 음압을 가했을 때 출력전압은?

  1. 0.01[mV]
  2. 0.1[mV]
  3. 1[mV]
  4. 10[mV]
(정답률: 54%)
  • 30 CBT 기출문제AI

    2023-04-12 11:32

    dB와 음압, 출력전압 사이의 관계는 다음과 같습니다.

    dB = 20log(출력전압/음압)

    이를 변형하면,

    출력전압/음압 = 10^(dB/20)

    주어진 문제에서는 음압이 1[μbar], 감도가 -80[dB]이므로,

    출력전압/1[μbar] = 10^(-80/20) = 10^(-4) = 0.0001

    따라서 출력전압은 1[μbar]에 0.0001을 곱한 값이 됩니다.

    1[μbar] × 0.0001 = 0.0001[μV]

    하지만 보기에서는 단위가 [mV]로 주어졌으므로, 0.0001[μV]을 [mV]로 변환해줍니다.

    0.0001[μV] = 0.0000001[V] = 0.0001[mV]

    따라서 정답은 "0.1[mV]"가 됩니다.

60. 자전거를 셀 방식으로 생산하는 공장에서, 자전거 1대당 소요공수가 14.5H이며, 1일 8H, 월 25일 작업을 한다면 작업자 1명당 월 생산 가능 대수는 몇 대인가? (단, 작업자의 생산종합효율은 80%이다.)

  1. 10대
  2. 11대
  3. 13대
  4. 14대
(정답률: 70%)
  • 30 CBT 기출문제AI

    2023-04-12 11:40

    1일 소요공수는 8H이므로, 1달 소요공수는 8H x 25일 = 200H이다.
    작업자 1명이 1달에 생산할 수 있는 자전거 대수는 200H / 14.5H = 13.79대이다.
    하지만 작업자의 생산종합효율이 80%이므로, 실제 생산 가능 대수는 13.79대 x 0.8 = 11.03대이다.
    소수점 이하를 버리면 생산 가능 대수는 11대이다.
