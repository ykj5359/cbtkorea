    섭씨 30도를 랭킨 온도로 바꾸기 위해서는 다음과 같은 공식을 사용한다.

    랭킨 온도 = (섭씨 온도 + 273.15) x 1.8

    랭킨 온도 = (30 + 273.15) x 1.8
    = 546.67

    따라서, 섭씨 30도는 랭킨 온도로 546도이다.

8. 1기압, 100℃에서의 물 1g의 기화잠열은 약 몇 cal 인가?

  1. 425
  2. 539
  3. 647
  4. 734
(정답률: 91%)
  • 30 CBT 기출문제AI

    2023-04-16 07:47

    1g의 물이 기화될 때 필요한 열량을 기화잠열이라고 한다. 이 문제에서는 1기압, 100℃에서의 물 1g의 기화잠열을 구하는 것이다. 이는 물이 상변화를 일으키는 열량이므로, 물의 비열과 상변화 열을 더한 값이 된다.

    물의 비열은 1g당 1cal/℃이고, 상변화 열은 540cal/g이다. 따라서 1g의 물이 기화될 때 필요한 열량은 1 x 540 = 540cal이 된다.

    하지만 이 문제에서는 cal이 아닌 kcal을 답으로 제시하고 있으므로, 540cal을 1000으로 나누어 주면 된다. 따라서 정답은 540/1000 = 0.54kcal이다.

    하지만 보기에서는 단위를 cal로 제시하고 있으므로, 0.54kcal을 1000으로 곱하여 cal로 변환해준다. 따라서 정답은 0.54 x 1000 = 540cal이다.

    하지만 이 문제에서는 보기에서 제시된 답안 중에서 정답을 고르는 것이므로, 540cal을 가장 가까운 값으로 반올림하여 계산해야 한다. 따라서 540cal은 539cal로 반올림하여 정답은 "539"가 된다.

13. 할론 가스 45kg과 함께 기동가스로 질소2kg을 충전하였다. 이 때 질소가스의 몰분율은? (단, 할론 가스의 분자량은 149이다.)

  1. 0.19
  2. 0.24
  3. 0.31
  4. 0.39
(정답률: 51%)
  • 30 CBT 기출문제AI

    2023-04-16 07:47

    할론 가스와 질소 가스는 서로 다른 기체이므로 몰분율을 구할 때는 각각의 몰을 구해야 한다.

    할론 가스 45kg의 몰 수 = 45kg / 149g/mol = 302.01 mol
    질소 가스 2kg의 몰 수 = 2kg / 28g/mol = 71.43 mol

    따라서, 전체 몰 수는 302.01 mol + 71.43 mol = 373.44 mol 이다.

    질소 가스의 몰분율 = 질소 가스의 몰 수 / 전체 몰 수 = 71.43 mol / 373.44 mol = 0.19

    따라서, 정답은 "0.19" 이다.
