18. 다음은 피부표면에 부착된 전극의 전기적 등가회로에서 전극-피부의 경계면의 등가회로이다. 양단의 등가 임피던스는?

(정답률: 67%)
  • 30 CBT 기출문제AI

    2023-04-17 10:37

    전극-피부 경계면에서의 등가회로는 병렬 회로이다. 따라서 등가 임피던스는 병렬 임피던스의 역수의 합인데, 이를 계산하면 다음과 같다.

    1/Z = 1/Z1 + 1/Z2 + 1/Z3

    여기서 Z1, Z2, Z3은 각각 전극, 피부, 전해질의 임피던스이다. 전해질의 임피던스는 주어져 있으므로, 전극과 피부의 임피던스를 구하면 된다.

    전극의 임피던스는 전극-전해질 경계면에서의 등가회로이므로, 다음과 같다.

    Z1 = R1 + jX1

100. 어떤 베어링의 요구되는 수명이 5000 시간이고 400rpm 으로 회전할 때 요구되는 수명에 따른 회전수(106 회전)는?

  1. 240
  2. 180
  3. 120
  4. 60
(정답률: 66%)
  • 30 CBT 기출문제AI

    2023-04-17 10:36

    베어링의 수명은 다음과 같은 공식으로 계산됩니다.

    L10 = (C/P)^3 x 10^6

    여기서 L10은 90%의 베어링이 수명을 다한 시간, C는 베어링의 기본 동적 하중, P는 베어링에 작용하는 등속 회전하중입니다.

    문제에서는 베어링의 요구되는 수명이 5000시간이고 회전속도가 400rpm이므로, 등속 회전하중은 다음과 같이 계산할 수 있습니다.

    P = (π/30) x 400 x Fr

    여기서 Fr은 베어링에 작용하는 방사하중입니다. 문제에서는 Fr이 주어지지 않았으므로 가정을 해야 합니다. 예를 들어, Fr이 1000N이라고 가정하면, C는 다음과 같이 계산할 수 있습니다.

    C = 1.66 x 10^7 x (1000/1000.0)^0.67 = 1.66 x 10^7 N

    따라서, L10은 다음과 같이 계산할 수 있습니다.

    L10 = (1.66 x 10^7 / 1000)^3 x 10^6 = 4.39 x 10^9 회전

    이제, 요구되는 수명인 5000시간에 해당하는 회전수를 계산하면 다음과 같습니다.

    5000시간 = 5000 x 3600초 = 1.8 x 10^7 초

    회전수 = (1.8 x 10^7 / 60) x 400 = 1.2 x 10^6 회전

    따라서, 정답은 "120"입니다.
