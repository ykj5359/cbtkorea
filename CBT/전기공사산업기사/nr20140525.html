16. 단면적 S[m2]의 파이프를 θ로 경사시켜서 비중 ρ인 액체를 Q[m3/s]의 유량으로 양정 H[m]까지 끌어올린다고 할 때 액체 펌프에 요하는 소요동력 P[kW]는?

  1. P＝ρHQs
  2. P＝9.8ρHQs
  3. P＝ρHQ
  4. P＝9.8ρHQ
(정답률: 68%)
  • 30 CBT 기출문제AI

    2023-04-17 14:58

    액체를 끌어올리는 데 필요한 일은 액체의 무게를 이겨내는 것입니다. 따라서, 액체의 무게는 다음과 같이 계산할 수 있습니다.

    액체의 부피 = Q [m^3/s]
    액체의 밀도 = ρ [kg/m^3]
    액체의 무게 = 액체의 부피 x 액체의 밀도 x 중력가속도(g) [N]

    여기서 중력가속도(g)는 9.8 m/s^2 입니다.

    액체를 끌어올리는 데 필요한 일은 액체의 무게를 이겨내는 것이므로, 액체를 끌어올리는 데 필요한 힘은 다음과 같이 계산할 수 있습니다.

    액체를 끌어올리는 데 필요한 힘 = 액체의 무게 [N]

    액체를 끌어올리는 데 필요한 일은 액체를 일정한 높이(H)까지 끌어올리는 것이므로, 액체를 끌어올리는 데 필요한 일은 다음과 같이 계산할 수 있습니다.

    액체를 끌어올리는 데 필요한 일 = 액체를 끌어올리는 데 필요한 힘 x 끌어올리는 높이(H) [J]

    여기서 1 J/s = 1 W 이므로, 액체를 끌어올리는 데 필요한 소요동력은 다음과 같이 계산할 수 있습니다.

    액체를 끌어올리는 데 필요한 소요동력 = 액체를 끌어올리는 데 필요한 일 / 시간 [W]

    따라서, 액체를 끌어올리는 데 필요한 소요동력은 다음과 같이 계산할 수 있습니다.

    액체를 끌어올리는 데 필요한 소요동력 = 액체를 끌어올리는 데 필요한 일 x 유량 [W]
    액체를 끌어올리는 데 필요한 소요동력 = 액체의 무게 x 끌어올리는 높이(H) x 유량(Q) [W]

    여기서 액체의 무게는 액체의 부피 x 액체의 밀도 x 중력가속도(g) 이므로, 다음과 같이 표현할 수 있습니다.

    액체를 끌어올리는 데 필요한 소요동력 = Q x ρ x g x H x Q [W]

    따라서, 액체를 끌어올리는 데 필요한 소요동력은 P = ρQHgQ 이며, 중력가속도(g)를 9.8 m/s^2 로 대입하면 P = 9.8ρQH 가 됩니다.
