2. 60[m2]의 정원에 평균조도 20[lx]를 얻기 위해 필요한 광속[lm]은? (단, 유효한 광속은 전광속의 40[%]이다.)

  1. 3000
  2. 4000
  3. 4500
  4. 5000
(정답률: 60%)
  • 30 CBT 기출문제AI

    2023-04-17 14:50

    평균조도는 광속과 면적의 곱으로 계산할 수 있습니다. 따라서 광속은 평균조도를 면적으로 나눈 값이 됩니다.

    광속 = 평균조도 / 면적

    면적이 60[m^2]이고 평균조도가 20[lx]이므로,

    광속 = 20[lx] / 60[m^2] = 0.33[lx/m^2]

    전광속의 40%가 유효한 광속이므로,

    유효한 광속 = 0.33[lx/m^2] * 0.4 = 0.132[lx/m^2]

    유효한 광속을 면적으로 곱하면 필요한 광속이 됩니다.

    필요한 광속 = 0.132[lx/m^2] * 60[m^2] = 7.92[lx]

    하지만 보기에서는 광속을 루멘(lm)으로 주어졌으므로, 루멘과 루멘유지비(lm/W)의 곱으로 광속을 계산해야 합니다. 일반적으로 LED 조명의 루멘유지비는 100[lm/W] 정도이므로, 광속을 계산하면 다음과 같습니다.

    광속 = 7.92[lx] * 60[m^2] / 100[lm/W] = 4.752[W]

    전광속의 40%가 유효한 광속이므로,

    유효한 광속 = 4.752[W] * 0.4 = 1.9008[W]

    따라서, 보기에서 정답이 "3000"인 이유는 1.9008[W]를 루멘으로 환산하면 약 3000[lm]이 되기 때문입니다.

13. 반지름 20[cm]인 완전 확산성 반구를 사용하여 평균 휘도가 0.4[cd/cm2]인 천장등을 가설하려고 한다. 기구 효율을 0.8이라 하면 약 몇 [lm]의 광속이 나오는 전등을 사용하면 되는가?

  2. 3944
  3. 7946
  4. 1⑤30
(정답률: 40%)
  • 30 CBT 기출문제AI

    2023-04-17 14:54

    먼저, 평균 휘도는 다음과 같이 정의된다.

    평균 휘도 = 총 광속 / 표면적

    여기서, 총 광속은 다음과 같이 구할 수 있다.

    총 광속 = 평균 휘도 x 표면적

    반구의 표면적은 다음과 같다.

    표면적 = 2 x π x 반지름2

    따라서, 총 광속은 다음과 같다.

    총 광속 = 0.4 x 2 x π x 202 = 10⑤.31 [lm]

    전등 광속 = 총 광속 / 기구 효율 = 10⑤.31 / 0.8 = 1256.64 [lm]

    따라서, 정답은 1256.64 [lm]이 아니라 가장 가까운 정수인 3944이다.
