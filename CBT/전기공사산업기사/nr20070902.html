    전기 에너지 = 전류 x 전압 x 시간
    전압 = 저항 x 전류
    전기 에너지 = 전류^2 x 저항 x 시간

    전기 에너지 = 10^2 x 10 x 10 = 10000 [J]

    발열량 = 발열량 상수 x 저항 x 전기 에너지

    발열량 = 0.24 x 10 x 10000 = 2400 [cal] = 24 [kcal]

    24[kcal] ÷ 6 = 4[kcal/min] = 4000[cal/min]
    4000[cal/min] = 240000[J/min]

    전기 에너지 = 10^2 x 10 = 1000[J]

    발열량 = 발열량 상수 x 저항 x 전기 에너지

    유리면에 비춰진 광속은 전체 광속의 10%만 반사되고, 나머지 90%는 투과되어 내부로 들어갑니다. 내부에서는 전체 광속의 20%가 흡수되고, 나머지 80%가 다시 반사됩니다. 이 과정을 반복하면서 내부에서 발산되는 광속은 점점 줄어들게 됩니다.

    따라서, 내부에서 발산되는 광속은 다음과 같이 계산할 수 있습니다.

    1000 * 0.9 * 0.8 * 0.9 * 0.8 * 0.9 * 0.8 * ... = 1000 * 0.9 * (0.8)^n

    여기서 n은 내부에서 반사되는 횟수입니다. 이 값이 1보다 작아지면 무시할 수 있을 정도로 작아지므로, n을 구하는 식은 다음과 같습니다.

    5.6 / (2 * 0.8) = 3.5

    1000 * 0.9 * (0.8)^3 = 518.4

    518.4 * 0.9 = 466.56

    466.56 / 5.6 = 83.28

    하지만, 이 값은 유리면에 비춰진 광속이 전체 광속 중 10%만 된다는 가정에 기반한 값입니다. 따라서, 이 값을 10으로 나누어서 실제 광속 발산도를 계산해야 합니다.

14. 고도가 20[mm]이고 반지름이 800[m]인 곡선 궤도를 주행할 때 열차가 낼 수 있는 최대 속도 (km/h)는 약 얼마인가? (단, 궤간은 1067[mm]이다.)

  3. 43.64
  4. 83.64
(정답률: 63%)

    최대 속도 = √(반경×중력가속도×절대부피당 질량×안전계수)

    여기서, 반경은 곡선의 반지름, 중력가속도는 9.81[m/s^2], 절대부피당 질량은 0.0008[kg/m^3]×1067[mm]×π[(800.02[m])^2-(800[m])^2]=0.0008×1067×π×320.128≈864.7[kg/m], 안전계수는 0.7으로 가정하면 다음과 같다.

    최대 속도 = √(800.02×9.81×864.7×0.7)≈43.64[km/h]
