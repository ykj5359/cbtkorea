    V1/V2 = N1/N2
    I1/I2 = N2/N1

    여기서 N1과 N2는 각각 1차 측과 2차 측의 코일 감수이다.

    4단자 회로에서 A와 C는 각각 1차 측과 2차 측의 코일에 연결된 접점이다. 이상적인 변압기에서는 전압과 전류의 비율이 일정하므로, A와 C 사이의 전압은 V1과 동일하고, A와 C 사이의 전류는 I1과 동일하다.

    R = V1/I1

    P1 = V1I1 = P2 = V2I2

    따라서 다음과 같은 관계가 성립한다.

    V1I1 = V2I2
    V1/N1 = V2/N2
    I1N2 = I2N1

    A = V1/I1 = (V2/N2)/(I2N1/N2) = V2/I2N1 = n (n은 정수)
    C = V2/I2 = (V1/N1)/(I1N2/N1) = V1/I1N2 = 0

    따라서 정답은 "A＝n, C＝0"이다.
