17. 권상하중 10t, 매분 24m/min의 속도로 물체를 올리는 권상용 전동기의 용량(kW)은 약 얼마인가? (단, 전동기를 포함한 기중기의 효율은 65%이다.)

  1. 41
  2. 73
  3. 60
  4. 97
(정답률: 49%)
  • 30 CBT 기출문제AI

    2023-04-17 14:44

    전동기의 용량은 권상하중과 속도, 그리고 효율에 따라 결정된다.

    먼저, 권상하중 10t을 들어올리는 데 필요한 일은 다음과 같다.

    일 = 힘 × 거리

    여기서 힘은 무게에 비례하므로 10t에 해당하는 무게를 뉴턴(N)으로 환산해야 한다.

    10t = 10,000kg = 10,000 × 9.8 N ≈ 98,000 N

    따라서 일 = 98,000 N × 24 m = 2,352,000 J/min 이다.

    하지만, 이 일을 하는 데에는 기계적인 손실이 발생하므로, 전동기의 용량은 다음과 같이 계산된다.

    용량 = 일 ÷ (시간 × 효율)

    여기서 시간은 1분이므로,

    최대 자기유도계수 Lmax = (4π²fN₁²μA)/R
    여기서, f는 주파수, N₁은 1차 권선수, μ는 상대투자율, A는 단면적, R은 전기저항입니다.

    Lmax = (4π² x 60 x 3000² x 2000 x A) / R

    1차 권선의 단면적 = (6900 / 2) x (60000 / 1000) = 2070 mm²

    마지막으로, 전기저항 R을 구해야 합니다. 변압기의 전력은 일정하므로, 전류는 1차와 2차에서 동일합니다. 따라서, 2차 전류를 구하여 전기저항을 계산할 수 있습니다.

    R = 2차 전류² x 3 / 전력

    R = (1 / 20)² x 3 / (6900 x 20) x 3 = 0.00000076
