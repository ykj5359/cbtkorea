13. 외경 30mm, 두께 2.5mm인 튜브를 직경 20mm인 코일이 감겨있는 내삽형 탐촉자로 와전류탐상시험 할 때, 충전율(fill factor)은 얼마인가?

  1. 0.44
  2. 0.64
  3. 0.67
  4. 0.80
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-17 22:45

    충전율은 코일 내부에 전류가 흐르는 부피의 비율을 나타내는 값이다. 즉, 코일 내부에 전류가 흐르는 부피가 클수록 충전율이 높아진다.

    내삽형 탐촉자는 튜브 안쪽에 코일이 감겨있기 때문에, 코일 내부에 전류가 흐르는 부피는 튜브의 단면적과 코일의 감긴 수에 비례한다.

    따라서, 내삽형 탐촉자의 충전율은 (코일 내부에 전류가 흐르는 부피) / (코일 전체 부피) 로 계산할 수 있다.

    코일 전체 부피는 파이 x (직경/2)^2 x 코일의 길이로 계산할 수 있다. 여기서 직경은 20mm이므로 반지름은 10mm이다. 따라서, 코일 전체 부피는 파이 x 10^2 x (외경 - 두께) = 7068.58mm^3 이다.

    코일 내부에 전류가 흐르는 부피는 튜브의 단면적 x 코일의 감긴 수로 계산할 수 있다. 튜브의 단면적은 파이 x (외경/2)^2 - 파이 x (내경/2)^2 = 471.24mm^2 이다. 코일의 감긴 수는 계산되지 않았으므로, 여기서는 감긴 수를 10회로 가정하겠다. 따라서, 코일 내부에 전류가 흐르는 부피는 471.24mm^2 x 10회 = 4712.4mm^3 이다.

    따라서, 내삽형 탐촉자의 충전율은 4712.4mm^3 / 7068.58mm^3 = 0.67 이다.

    하지만, 여기서는 코일의 감긴 수를 10회로 가정했기 때문에, 실제 충전율은 더 낮을 것이다. 따라서, 보기에서 가장 근접한 값인 0.64가 정답이다.

  2. 3600L
  3. 4525L
  4. 7000L
(정답률: 알수없음)

    2023-04-17 22:44

    용기 전체 무게에서 공병의 무게를 빼면, 아세틸렌 가스의 무게를 구할 수 있다.

    아세틸렌 가스의 밀도는 0.9kg/L 이므로, 아세틸렌 가스의 부피는 다음과 같다.

    (45kgf - 40kgf) / 0.9kg/L = 5kgf / 0.9kg/L = 5.56L

    하지만, 이는 1기압, 0℃에서의 부피이므로, 1kgf/cm2, 15℃에서의 부피로 변환해야 한다.

    아세틸렌 가스의 온도와 압력이 변할 때의 부피 변화는 아래의 식으로 계산할 수 있다.

    V2 = V1 × (P2 / P1) × (T1 / T2)

    여기서, V1은 0℃, 1기압에서의 부피이므로 5.56L이고, P1은 1기압, T1은 0℃이다. P2는 1kgf/cm2, T2는 15℃이다.

    따라서, 아세틸렌 가스의 부피는 다음과 같다.

    5.56L × (1kgf/cm2 / 1기압) × (273+0℃ / 273+15℃) = 4525L

    따라서, 정답은 "4525L"이다.
