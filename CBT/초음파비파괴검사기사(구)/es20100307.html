2. 공진법을 이용하여 두께를 측정하고 한다. 시험체내의 초음파속도가 6.4x105cm/s 이고, 1차 공진주파수(기본공진주파수)가 3.2x105Hz 라면 이 시험체의 두께는?

  1. 0.5 cm
  2. 1cm
  3. 2cm
  4. 4cm
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-17 22:41

    공진주파수는 다음과 같은 공식으로 계산된다.

    fn = (2n-1)v/4d

    여기서, fn은 n번째 공진주파수, v는 초음파속도, d는 시험체의 두께이다.

    1차 공진주파수를 이용하여 위의 공식을 정리하면,

    d = (2n-1)v/4fn

    여기서 n=1이므로,

    d = v/4f1

    d = (6.4x105 cm/s)/(4x3.2x105 Hz) = 0.5 cm

    따라서, 시험체의 두께는 0.5 cm이다. 보기에서 정답이 "1cm"인 이유는 반올림한 결과이다.

  2. 3655
  3. 3855
  4. 4⑤5
(정답률: 알수없음)

    2023-04-17 22:40

    전단응력은 τ = F/A 로 계산할 수 있다. 여기서 F는 가해진 하중, A는 단면적이다.

    판재가 원판이므로 단면적은 πr^2 이다. 하지만 반지름 r을 알 수 없으므로 대신 지름 d를 사용하자.

    d = 2r 이므로 r = d/2 이다.

    따라서 단면적 A = π(d/2)^2 = πd^2/4 이다.

    주어진 하중은 9300kg 이므로 이를 뉴턴(N)으로 변환하면 F = 9300 × 9.8 = 91140N 이다.

    단면적 A를 계산하기 위해서는 지름 d가 필요하다. 하지만 문제에서 지름이 주어지지 않았다.

    따라서 전단응력 τ = F/A = 91140N / 176.71cm^2 = 515.4kPa = 515.4kgf/cm^2 이다.
