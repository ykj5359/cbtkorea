2. 종파를 이용하여 펄스반사법으로 알루미늄을 탐상시험할 때 탐상면으로부터 10mm 깊이에 불연속이 존재함을 알았다. 이때 탐상면으로 입사한 초음파가 표시기(CRT)에 불연속 에코를 나타낼 때까지 걸리는 시간은? ( 단, 알루미늄에서 종파속도는 6.0×106mm/s 이다. )

  1. 33초
  2. 3.3×10-6초
  3. 64초
  4. 6.6×10-6초
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-17 23:⑤

    알루미늄에서 종파속도는 6.0×106mm/s 이므로, 10mm 깊이에 도달하는데 걸리는 시간은 10mm / 6.0×106mm/s = 1.67×10-6초 이다.

    하지만 불연속이 존재하기 때문에, 초음파는 불연속에서 반사되어 다시 탐상면으로 돌아오게 된다. 이때 불연속에서 반사되어 돌아오는 시간은 불연속의 두께를 종파속도로 나눈 값과 같다.

    따라서, 불연속의 두께가 10mm이므로, 불연속에서 반사되어 돌아오는 시간은 10mm / 6.0×106mm/s = 1.67×10-6초 이다.

    따라서, 초음파가 불연속에서 반사되어 다시 탐상면으로 돌아오는데 걸리는 시간은 1.67×10-6초 x 2 = 3.3×10-6초 이다.

    따라서, 정답은 "3.3×10-6초" 이다.

  4. 80°
(정답률: 알수없음)

(정답률: 알수없음)

    화씨온도(℉)를 섭씨온도(℃)로 변환하는 식은 다음과 같다.

    이 식에서 32는 화씨온도에서 섭씨온도로 변환할 때 빼주는 상수이고, 5/9는 화씨온도를 섭씨온도로 변환할 때 곱해주는 상수이다. 따라서, 화씨온도에서 섭씨온도로 변환할 때는 32를 빼주고, 그 결과에 5/9를 곱해주면 된다.
