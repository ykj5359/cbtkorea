8. 직경 20㎜, 주파수 5MHZ인 수직탐촉자로 철강재를 탐상할 때 초음파의 지향각은 몇 도인가? (단, 철강재의 종파속도는 5900m/s 이다.)

  1. 약 10도
  2. 약 6.6도
  3. 약 5.2도
  4. 약 4.1도
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-17 23:19

    초음파의 지향각은 다음과 같이 계산할 수 있다.

    sinθ = λ / (d × n)

    여기서, θ는 지향각, λ는 파장, d는 탐촉자 직경, n은 주파수에 대한 진행파수이다.

    주어진 조건에서 파장 λ는 다음과 같이 계산할 수 있다.

    λ = v / f

    여기서, v는 철강재의 종파속도, f는 주파수이다.

    따라서, λ = 5900 / 5000000 = 0.00118m

    진행파수 n은 다음과 같이 계산할 수 있다.

    n = 1 / cosθ

    여기서, θ는 지향각이다.

    따라서, cosθ = 1 / n

    n = d / λ × cosθ

    여기서, d는 0.02m, λ은 0.00118m이다.

    따라서, n = 0.02 / 0.00118 × cosθ = 16.95 × cosθ

    cosθ = 16.95 / n

    따라서, θ = arccos(16.95 / n)

    따라서, θ = arccos(16.95 / 1.17) = 약 4.1도

    따라서, 정답은 "약 4.1도"이다.
