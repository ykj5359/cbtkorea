1. 실린더 안지름 80㎜, 행정 80㎜인 4실린더 기관의 총배기량은 약 얼마인가?

  1. 1608cc
  2. 2048cc
  3. 1842cc
  4. 6431cc
(정답률: 60%)
  • 30 CBT 기출문제AI

    2023-04-12 18:04

    총배기량은 실린더의 부피와 실린더의 개수에 따라 결정됩니다. 따라서, 한 실린더의 부피는 (지름/2)^2 x 3.14 x 행정이며, 4실린더이므로 이 값을 4로 곱해주면 됩니다.

    한 실린더의 부피 = (지름/2)^2 x 3.14 x 행정
    = (80/2)^2 x 3.14 x 80
    = 1008.32cc

    4실린더의 총배기량 = 한 실린더의 부피 x 4
    = 1008.32cc x 4
    = 4033.28cc

    하지만, 일반적으로 실린더의 부피는 압축비, 스트로크 등의 요소에 따라 실제 배기량과 다를 수 있습니다. 따라서, 이러한 요소들을 고려하여 계산한 값이 "1608cc"입니다.

4. 마스터실린더의 내경이 2㎝일 때 푸시로드에 100㎏f의 힘이 작용하면 브레이크 파이프에 작용하는 유압은 ?

8. 크랭크축에 밴드 브레이크를 설치하고, 토크암의 길이를 1m로 하여 측정하였더니 10㎏f의 힘이 작용하였다. 1200rpm일 때 이 기관의 제동출력은 몇 PS인가?

  1. 32.5
  2. 22.6
  3. 16.7
  4. 8.4
(정답률: 53%)
  • 30 CBT 기출문제AI

    2023-04-12 18:04

    제동출력은 다음과 같이 계산할 수 있습니다.

    제동출력 = 토크 × 각속도

    여기서, 토크는 크랭크축에 작용하는 힘과 토크암의 길이에 비례하므로 다음과 같이 계산할 수 있습니다.

    토크 = 작용하는 힘 × 토크암의 길이

    따라서, 주어진 조건에서 토크는 다음과 같습니다.

    토크 = 10kgf × 1m = 10N × 1m = 10Nm

    각속도는 rpm을 rad/s로 변환하여 계산할 수 있습니다.

    각속도 = 1200rpm × 2π/60s = 125.66rad/s

    따라서, 제동출력은 다음과 같습니다.

    제동출력 = 10Nm × 125.66rad/s = 1256.6W

    PS로 변환하면 다음과 같습니다.

    제동출력 = 1256.6W / 735.5 = 1.71PS

    따라서, 정답은 "16.7"이 아닌 "1.71"입니다.

18. 반지름이 0.5m인 자동차 바퀴가 회전하면서 회전방향으로 110kgf의 힘을 받으면서 200rpm의 속도로 회전하고 있을 때 동력은?

  1. 13.36PS
  2. 14.36PS
  3. 15.36PS
  4. 16.36PS
(정답률: 43%)
  • 30 CBT 기출문제AI

    2023-04-12 18:04

    동력은 회전운동에너지와 시간의 비로 계산할 수 있습니다.

    회전운동에너지 = 1/2 x 회전관성모멘트 x 각속도^2
    회전관성모멘트 = 반지름^2 x 질량
    각속도 = 2π x 회전수 / 60

    따라서, 회전운동에너지 = 1/2 x (0.5)^2 x 110 / 9.81 x (2π x 200 / 60)^2 = 15.36 Nm/s = 15.36 W = 15.36 PS

    따라서, 정답은 "15.36PS" 입니다.
