2. 행정 길이 200mm인 가솔린 기관에서 피스톤의 평균 속도가 5m/s 이면, 크랭크축의 1분간 회전수는?

  1. 75rpm
  2. 150rpm
  3. 750rpm
  4. 1500rpm
(정답률: 54%)
  • 30 CBT 기출문제AI

    2023-04-12 17:51

    피스톤의 평균 속도는 다음과 같이 구할 수 있습니다.

    평균 속도 = 이동 거리 ÷ 이동 시간

    여기서 이동 거리는 행정 길이인 200mm이고, 이동 시간은 1분(60초) ÷ 2(행정이 왕복하기 때문에) = 30초입니다.

    따라서 평균 속도 = 200mm ÷ 30초 = 6.67mm/s 입니다.

    크랭크축의 1분간 회전수는 다음과 같이 구할 수 있습니다.

    1분간 회전수 = (피스톤의 평균 속도 × 2 × 60) ÷ (연소횟수 × 스트로크)

    여기서 연소횟수는 가솔린 기관의 경우 4회이고, 스트로크는 행정 길이인 200mm이므로 0.2m입니다.

    따라서 1분간 회전수 = (6.67mm/s × 2 × 60) ÷ (4 × 0.2m) = 750rpm 입니다.

10. 실린더 안지름 80mm, 행정이 70mm 인 4실린더 4행정 기관에서 회전수가 2000rpm 이라면, 분당 총 배기량은 약 몇 ℓ인가?

  1. 약 1600
  2. 약 1942
  3. 약 1500
  4. 약 1407
(정답률: 48%)
  • 30 CBT 기출문제AI

    2023-04-12 17:51

    한 실린더의 배기량은 실린더 내부의 부피와 같습니다. 따라서 한 실린더의 배기량은 다음과 같이 계산할 수 있습니다.

    한 실린더의 부피 = (지름/2)^2 x π x 행정

    = (80/2)^2 x π x 70

    ≈ 246,400 mm^3

    4실린더이므로, 분당 총 배기량은 다음과 같이 계산할 수 있습니다.

    분당 총 배기량 = 한 실린더의 배기량 x 실린더 수 x 회전수 / 2

    = 246,400 x 4 x 2000 / 2

    ≈ 1,567,200 mm^3/min

    이를 ℓ/min으로 환산하면 다음과 같습니다.

    1,567,200 mm^3/min ÷ 1,000^3 = 0.0015672 ℓ/min

    따라서, 약 1407이 정답입니다.

26. 20km/h로 주행하는 자동차가 10초후에 가속하여 56km/h 속도가 되었다. 이때의 가속도는?

  1. 1m/s2
  2. 20m/s2
  3. 30m/s2
  4. 36m/s2
(정답률: 46%)
  • 30 CBT 기출문제AI

    2023-04-12 17:51

    가속도는 변화하는 속도를 시간으로 나눈 값입니다. 따라서, 가속도는 다음과 같이 구할 수 있습니다.

    가속도 = (최종속도 - 초기속도) / 시간

    여기서 초기속도는 20km/h, 최종속도는 56km/h, 시간은 10초입니다. 하지만, 단위가 km/h이므로, m/s로 변환해주어야 합니다.

    초기속도 = 20km/h = 20 × 1000m / 3600s = 5.56m/s
    최종속도 = 56km/h = 56 × 1000m / 3600s = 15.56m/s

    따라서, 가속도는 다음과 같이 계산됩니다.

    가속도 = (15.56m/s - 5.56m/s) / 10s = 1m/s^2

    따라서, 정답은 "1m/s^2"입니다.
