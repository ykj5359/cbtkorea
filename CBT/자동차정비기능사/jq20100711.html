2. 4행정 기관에서 흡기밸브의 열림각은 242˚, 배기밸브의 열림 각은 274˚, 흡기 밸브의 열림 시작점은 BTDC13˚,배기밸브의 닫힘 점은 ATDC16˚ 이었을 때 흡기밸브의 닫힘 시점은?

  1. ABDC 20˚
  2. ABDC 37˚
  3. ABDC 42˚
  4. ABDC 49˚
(정답률: 51%)
  • 30 CBT 기출문제AI

    2023-04-12 17:52

    흡기밸브의 열림각과 배기밸브의 열림각을 더하면 242˚ + 274˚ = 516˚이다. 이 값에서 360˚을 빼면 156˚이 남는다. 이 값은 720˚(2바퀴)에서 흡기밸브의 열림 시작점인 BTDC13˚와 배기밸브의 닫힘 점인 ATDC16˚을 더한 값인 697˚을 빼면 된다. 720˚ - 697˚ = 23˚이므로, 흡기밸브의 닫힘 시점은 열림각의 합에서 BTDC와 ATDC를 더한 값에서 23˚을 빼면 된다. 516˚ - 29˚ - 16˚ - 23˚ = 448˚이므로, 흡기밸브의 닫힘 시점은 ABDC 49˚이다.

5. 가솔린 200cc를 연소시키기 위해 몇 kgf의 공기가 필요한가?(단,혼합비는 15:1이고,가솔린의 비중은0.73이다.)

  1. 2.19kgf
  2. 3.42kgf
  3. 4.14kgf
  4. 5.63kgf
(정답률: 38%)
  • 30 CBT 기출문제AI

    2023-04-12 17:52

    연소에 필요한 공기의 양은 연료의 양과 연료의 화학식에 따라 결정된다. 가솔린의 화학식은 C8H18이므로, 1mol의 가솔린을 연소시키기 위해서는 25mol의 공기가 필요하다. 따라서, 200cc(0.2L)의 가솔린을 연소시키기 위해서는 다음과 같이 계산할 수 있다.

    - 가솔린의 몰 수 = 0.73(g/mL) x 0.2(L) / 114.23(g/mol) = 0.00127mol
    - 공기의 몰 수 = 15 x 0.00127mol = 0.019mol
    - 공기의 질량 = 0.019mol x 28.96(g/mol) = 0.55g
    - 공기의 중력가속도 = 9.81m/s^2
    - 공기의 무게 = 0.55g / 1000(g/kg) x 9.81m/s^2 = 0.0⑤4kgf

    따라서, 가솔린 200cc를 연소시키기 위해서는 약 2.19kgf의 공기가 필요하다.
