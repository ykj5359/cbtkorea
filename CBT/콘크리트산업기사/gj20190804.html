6. 시방배합결과가 아래와 같을 때, 잔골재의 표면수율이 3%, 굵은 골재의 표면수율이 1%라면 이를 보정하여 현장배합으로 바꾼 단위 수량은? (단, 입도에 의한 보정은 무시한다.)

    현장배합 = 시방배합 × (100 + 잔골재 표면수율 + 굵은 골재 표면수율) / (100 + 잔골재 표면수율 + 굵은 골재 표면수율 + 모래 표면수율)

    현장배합 = 2,400 × (100 + 3 + 1) / (100 + 3 + 1 + 25) = 147.7kg/m³

    따라서, 정답은 "147.7kg/m³" 이다.

    잔골재와 굵은 골재를 1:1.5의 비율로 혼합한다는 것은 1 부분의 잔골재와 1.5 부분의 굵은 골재를 혼합한다는 것을 의미합니다. 따라서 혼합골재의 총 부피는 1 + 1.5 = 2.5 부분이 됩니다.

    그리고 혼합된 골재의 총 중량은 잔골재와 굵은 골재의 중량을 합한 것과 같습니다. 따라서 잔골재와 굵은 골재의 비중을 각각 w1, w2라고 할 때, 혼합골재의 조립률은 다음과 같이 계산할 수 있습니다.

    (2.4w1 + 7.4w2) / (w1 + w2)

    비율을 1:1.5로 주었으므로, w1:w2 = 1:1.5 입니다. 이를 대입하면,

    (2.4 + 7.4 x 1.5) / (1 + 1.5) = 5.4

    따라서 혼합골재의 조립률은 5.4가 됩니다.

    2023-04-18 00:23

    표준편차는 다음과 같은 공식으로 계산할 수 있다.

    표준편차 = √(∑(각 데이터 - 평균)^2 / 데이터 개수)

    먼저, 주어진 데이터의 평균을 구해보자.

    평균 = (32.1 + 33.2 + 34.1 + 35.2 + 36.1) / 5 = 34.14

    이제 각 데이터와 평균의 차이를 구하고, 제곱한 값을 모두 더해보자.

    (32.1 - 34.14)^2 = 4.14^2 = 17.1396
    (33.2 - 34.14)^2 = 0.94^2 = 0.8836
    (34.1 - 34.14)^2 = 0.04^2 = 0.0016
    (35.2 - 34.14)^2 = 1.06^2 = 1.1236
    (36.1 - 34.14)^2 = 1.96^2 = 3.8416

    ∑(각 데이터 - 평균)^2 = 23.990

75. 경간 10m인 단순보에 계수하중 36kN/m가 등분포하중으로 작용할 때 계수휨모멘트는?

  1. 350kNㆍm
  2. 400kNㆍm
  3. 450kNㆍm
  4. 500kNㆍm
(정답률: 49%)
  • 30 CBT 기출문제AI

    2023-04-18 00:22

    단순보의 계수휨모멘트는 등분포하중의 크기와 보의 길이에 따라 결정된다. 따라서 계수휨모멘트는 다음과 같이 계산된다.

    M = (wL^2)/8

    여기서 w는 등분포하중의 크기, L은 보의 길이이다. 따라서 이 문제에서는 다음과 같이 계산할 수 있다.

    M = (36 × 10 × 10^3 × 10^2)/8
    = 450 × 10^3 Nㆍm
    = 450 kNㆍm

    따라서 정답은 "450kNㆍm"이다.
