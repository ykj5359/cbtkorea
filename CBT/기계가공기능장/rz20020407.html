51. 표점거리 50mm, 직경 ø14mm인 인장시편을 시험한 후 시편을 측정한 결과 길이는 늘어나고 직경은 ø12mm였다. 이 재료의 단면수축율은 몇 %인가?

  1. 13.5
  2. 20.5
  3. 26.5
  4. 36.1
(정답률: 58%)
  • 30 CBT 기출문제AI

    2023-04-12 10:34

    단면수축율은 (원래 직경 - 변형된 직경) / 원래 직경 x 100 으로 계산할 수 있습니다.

    따라서, 단면수축율 = (14 - 12) / 14 x 100 = 14.3%

    하지만, 이 문제에서는 길이가 늘어났다는 정보가 주어졌으므로, 표점거리 50mm에서 변형된 길이를 빼서 실제 길이 변화를 계산해야 합니다.

    길이 변화 = (실제 길이 - 표점거리) / 표점거리 x 100

    실제 길이 = 50mm + 길이 변화

    시편을 측정한 결과 길이는 늘어났다고 했으므로, 길이 변화는 양수입니다.

    예를 들어, 실제 길이가 55mm라면, 길이 변화 = (55 - 50) / 50 x 100 = 10%

    따라서, 단면수축율 = (14 - 12) / 14 x 100 - 10% = 26.5%

    정답은 "26.5"입니다.

60. 준비작업시간이 5분, 정미작업시간이 20분, lot수 5, 주작업에 대한 여유율이 0.2라면 가공시간은?

  1. 150분
  2. 145분
  3. 125분
  4. 1⑤분
(정답률: 43%)
