2. 항력 계수가 3.5라 가정하고 직경 3cm인 알루미늄 임자를 선별하기 위하여 부유시키는데 필요한 속도는? (단, 공기선별, ρs=2.70, ρ=0.0012이며 속도식 : V= 적용)

  1. 1.24×103cm/s
  2. 1.59×103cm/s
  3. 1.78×103cm/s
  4. 1.92×103cm/s
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-18 10:45

    부유력은 물체의 첨력과 같아지는 순간에 최대가 된다. 따라서 부유력은 다음과 같이 구할 수 있다.

    FB = ρW * V * g

    여기서 ρW는 물의 밀도, V는 물체의 체적, g는 중력가속도이다.

    알루미늄 임자의 체적은 다음과 같다.

    V = (π/6) * d3 = (π/6) * (3cm)3 = 7.07cm3

    따라서 부유력은 다음과 같다.

    FB = 2.70 * 7.07 * 9.81 = 187.5N

    알루미늄 임자의 중력은 다음과 같다.

    FG = ρ * V * g = 0.0012 * 7.07 * 9.81 = 0.083N

    따라서 알루미늄 임자가 부유하기 위해서는 부유력이 중력과 같아져야 한다.

    V = (FB / ρW) * (1/g) = (187.5N / 1,000kg/m3) * (1/9.81m/s2) * 100cm/m = 1.91×103cm/s

    하지만 이것은 알루미늄 임자가 완전히 부유하는 속도이므로, 항력을 고려해야 한다. 항력 계수가 3.5이므로, 다음과 같이 항력을 구할 수 있다.

    FD = 0.5 * ρ * A * CD * v2

    여기서 A는 단면적, v는 속도, CD는 항력 계수이다.

    알루미늄 임자의 단면적은 다음과 같다.

    A = (π/4) * d2 = (π/4) * (3cm)2 = 7.07cm2

    따라서 항력은 다음과 같다.

    FD = 0.5 * 0.0012 * 7.07cm2 * 3.5 * v2 = 0.013v2

    부유력과 항력이 같아지는 속도에서 알루미늄 임자는 부유하게 된다. 따라서 다음과 같은 방정식이 성립한다.

    FB - FD = FG

    187.5 - 0.013v2 = 0.083

    0.013v2 = 187.417

    v2 = 14,393.6

    v = 1.59×103cm/s

    따라서 정답은 "1.59×103cm/s"이다.

4. 쓰레기를 파쇄할 때 90% 이상을 3.8cm보다 작게 파쇄하려고 하는 경우, Rosin-Rammler Model에 의한 특성입자의 크기는? (단, n=1)

  1. 약 1.2cm
  2. 약 1.7cm
  3. 약 2.3cm
  4. 약 2.6cm
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-18 10:45

    Rosin-Rammler Model은 입자 크기 분포를 나타내는 모델 중 하나이다. 이 모델에서 특성입자의 크기는 다음과 같이 계산된다.

    x = x_m * exp(-ln(2) * (d/d_m)^n)

    여기서 x_m은 중간값, d_m은 중간값에서 입자 크기가 절반인 지름, d는 입자 지름이다. n은 모양 인자로, 일반적으로 1로 가정한다.

    문제에서는 90% 이상을 3.8cm보다 작게 파쇄하려고 한다고 했으므로, d_m은 3.8cm가 된다. 또한, 중간값 x_m은 특성입자의 크기이므로, 이를 구하면 다음과 같다.

    0.1 = x_m * exp(-ln(2) * (3.8cm/x_m)^1)

    양변에 ln을 취하면,

    ln(0.1) = -ln(2) * (3.8cm/x_m)^1

    x_m = 1.7cm

    따라서, 정답은 "약 1.7cm"이 된다.

7. 자연상태의 쓰레기 밀도가 200kg/m3이었던 것을 정환장에 설치된 압축기에 넣어 압축시킨 결과 800kg/m3으로 증가 하였다. 이 때 부피의 감소율은?

  2. 80%
  3. 85%
  4. 90%
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-18 10:35

    부피의 감소율은 (최종 부피 - 초기 부피) / 초기 부피 x 100 으로 계산할 수 있다. 따라서, 압축 전 부피를 V1, 압축 후 부피를 V2라고 하면, 감소율은 (V1 - V2) / V1 x 100 이 된다.

    주어진 문제에서, 초기 부피의 밀도는 200kg/m3이므로, 초기 부피는 1m3당 200kg이다. 따라서, 초기 부피 V1은 1 / 200 = 0.0⑤m3이다.

    따라서, 부피의 감소율은 (0.0⑤ - 0.00125) / 0.0⑤ x 100 = 75% 이다.
