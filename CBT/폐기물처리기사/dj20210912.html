6. 밀도가 400kg/m3인 쓰레기 10ton을 압축시켰더니 처음 부피 보다 50%가 줄었다. 이 경우 Compaction ratio는?

  2. 2.0

  4. 3.0
(정답률: 70%)

    쓰레기의 초기 부피는 다음과 같습니다.

    10,000 kg / 400 kg/m^3 = 25 m^3

    압축 후의 부피는 초기 부피의 50%가 줄어들었으므로 다음과 같습니다.

    25 m^3 * 0.5 = 12.5 m^3

    10,000 kg / 12.5 m^3 = 800 kg/m^3

9. X90=4.6cm로 도시폐기물을 파쇄하고자 할 때 Rosin-Rammler 모델에 의한 특성입자크기(Xo, cm)는? (단, n=1로 가정)

  1. 1.2
  2. 1.6
  3. 2.0
  4. 2.3
(정답률: 64%)
  • 30 CBT 기출문제AI

    2023-04-18 11:07

    Rosin-Rammler 모델은 입자크기 분포를 나타내는 모델로, 다음과 같은 수식으로 표현된다.

    F(X) = 1 - exp[-(X/Xo)^n]

    여기서 X는 입자크기, Xo는 특성입자크기, n은 분포계수를 나타낸다.

    문제에서 X90=4.6cm로 주어졌으므로, F(X90)=0.9이다. 따라서 위의 수식을 이용하여 Xo를 구할 수 있다.

    0.9 = 1 - exp[-(4.6/Xo)^1]

    exp[-(4.6/Xo)^1] = 0.1

    -(4.6/Xo)^1 = ln(0.1)

    4.6/Xo = -ln(0.1)

    Xo = 4.6/ln(10) ≈ 2.0

    따라서 정답은 "2.0"이다.

    C8H18 + 12.5(O2 + 3.76N2) → 8CO2 + 9H2O + 47N2

    여기서, 연소공기는 공기(산소(O2) + 질소(N2))와 연료(옥탄)의 몰비를 나타내는 AFR(Air-Fuel Ratio)로 표현됩니다.

    AFR = (kg molair)/(kg molfuel)

    따라서, 연소공기의 몰은 다음과 같이 계산할 수 있습니다.

    연소공기의 몰 = 12.5(O2 + 3.76N2)/114.24

    여기서, 12.5는 옥탄 1몰당 필요한 산소의 몰수입니다. 또한, 공기는 약 21%의 산소와 79%의 질소로 이루어져 있으므로, 3.76은 공기 1몰당 질소의 몰수입니다.

    따라서, AFR은 다음과 같이 계산할 수 있습니다.

    AFR = (12.5(O2 + 3.76N2)/114.24) / 1

    AFR = 12.5(O2 + 3.76N2)/114.24

    AFR = 12.5(0.21 + 3.76x0.79)/114.24

    AFR = 12.5x1.492/114.24

    AFR = 0.163

    따라서, 옥탄의 완전 연소시 AFR은 0.163입니다. 이 값을 kg molair/kg molfuel로 변환하면 다음과 같습니다.

    AFR = (kg molair)/(kg molfuel)

    0.163 = (kg molair)/(1 kg molfuel)

    kg molair/kg molfuel = 6.13

    하지만, 이 문제에서는 AFR을 반올림하여 정수로 표현하도록 요구하고 있습니다. 따라서, AFR 6.13을 가장 가까운 정수로 반올림하여 6으로 만들면, 정답은 59.5가 됩니다.
