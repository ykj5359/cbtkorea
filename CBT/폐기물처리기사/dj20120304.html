1. 함수율 50%인 쓰레기를 함수율 20%로 감소시킨다면 전체중량은? (단, 쓰레기 비중은 1.0으로 가정함)

  1. 처음의 약 52%로 된다.
  2. 처음의 약 57%로 된다.
  3. 처음의 약 63%로 된다.
  4. 처음의 약 68%로 된다.
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-18 10:34

    함수율이 50%인 쓰레기는 쓰레기 중 50%가 실제 쓰레기이고, 나머지 50%는 공기 등의 빈 공간이다. 따라서 전체 중량 중 쓰레기의 비중은 1.0 * 0.5 = 0.5이다.

    함수율을 20%로 감소시키면, 쓰레기 중 20%만 실제 쓰레기이고, 나머지 80%는 빈 공간이다. 따라서 전체 중량 중 쓰레기의 비중은 1.0 * 0.2 = 0.2이다.

    따라서 처음의 쓰레기 비중 0.5에서 0.2로 감소하면, 전체 중량 중 쓰레기의 비중은 0.2 / 0.5 = 0.4이다. 이를 백분율로 나타내면 약 80%이다.

    하지만 문제에서는 쓰레기 비중이 1.0으로 가정되어 있으므로, 전체 중량 중 쓰레기의 비중이 0.2가 되면 전체 중량은 처음의 0.2 / 0.5 = 0.4배가 된다. 이를 백분율로 나타내면 약 63%이다. 따라서 정답은 "처음의 약 63%로 된다."이다.

4. 함수율 80%(중량비)인 슬러지 내 고형물은 비중이 2.5인 FS 1/3과 비중이 1.0인 VS 2/3로 되어 있다. 이 슬러지의 비중은? (단, 물의 비중은 1.0 이다.)

  1. 1.04
  2. 1.08
  3. 1.12
  4. 1.16
(정답률: 알수없음)

    2023-04-18 10:34

    슬러지 내 고형물의 비중은 FS 1/3이 2.5이므로, FS 1kg당 고형물 0.33kg이며, VS 2/3이 1.0이므로, VS 1kg당 고형물 0.67kg이다. 따라서, 1kg의 슬러지 내 고형물은 FS 0.33kg + VS 0.67kg = 1kg이다.

    함수율이 80%이므로, 1kg의 슬러지 중 물은 0.2kg이다. 따라서, 전체 슬러지의 무게는 1kg + 0.2kg = 1.2kg이다.

    전체 슬러지의 부피는 물의 부피와 같으므로, 1.2L이다.

    슬러지의 비중은 무게 대 부피로 계산할 수 있으므로, 1.2kg/1.2L = 1.0이다.

    FS 1/3의 비중이 2.5이므로, 1kg의 FS 내 고형물은 0.33kg x 2.5 = 0.825kg이다.

    VS 2/3의 비중이 1.0이므로, 1kg의 VS 내 고형물은 0.67kg x 1.0 = 0.67kg이다.

    따라서, 1kg의 슬러지 내 고형물은 0.825kg + 0.67kg = 1.495kg이다.

    전체 슬러지의 부피는 1.2L이므로, 슬러지 내 고형물의 부피는 1.2L x 0.8 = 0.96L이다.

    슬러지 내 고형물의 비중은 무게 대 부피로 계산할 수 있으므로, 1.495kg/0.96L = 1.56이다.

    하지만, 이 문제에서는 물의 비중이 1.0이므로, 슬러지 내 고형물의 비중에서 물의 비중을 빼줘야 한다.

    따라서, 슬러지의 비중은 1.56 - 1.0 = 0.56이다.

    하지만, 문제에서는 슬러지의 비중이 아니라 슬러지 내 고형물의 비중을 구하는 것이므로, FS와 VS의 비중을 고려해야 한다.

    FS 1/3의 비중이 2.5이므로, FS 내 고형물의 비중은 2.5이다.

    VS 2/3의 비중이 1.0이므로, VS 내 고형물의 비중은 1.0이다.

    따라서, 슬러지 내 고형물의 비중은 (FS 내 고형물의 비중 x FS의 비중) + (VS 내 고형물의 비중 x VS의 비중) = (2.5 x 0.33) + (1.0 x 0.67) = 1.04이다.

    따라서, 정답은 "1.04"이다.

11. 투입량이 1ton/h이고, 회수량이 600kg/h(그중 회수 대상물질은 540kg/h)이며 제거량은 400kg/h (그중 회수 대상물질은 50kg/h)일 때 Rietema식에 의한 선별 효율은?

  1. 76.9%
  2. 79.2%
  3. 81.3%
  4. 83.2%
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-18 10:49

    Rietema식에 의한 선별 효율은 다음과 같이 계산할 수 있다.

    선별 효율 = (회수 대상물질 회수량 / 제거 대상물질 제거량) × (1 - exp(-Δh / H))

    여기서 Δh는 입구와 출구의 높이 차이이고, H는 회전식 스크린의 유효 높이이다.

    문제에서 회수 대상물질 회수량은 540kg/h, 제거 대상물질 제거량은 50kg/h이다. 따라서,

    선별 효율 = (540 / 50) × (1 - exp(-Δh / H))

    선별 효율을 구하기 위해서는 Δh / H 값을 알아야 한다. 이 값은 회전식 스크린의 설계에 따라 다르므로, 문제에서는 주어지지 않았다. 따라서 정확한 답을 구할 수는 없지만, 보기에서 가장 가까운 값인 "76.9%"를 선택할 수 있다.
