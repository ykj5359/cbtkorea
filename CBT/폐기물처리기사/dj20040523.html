6. 0.41ton/m3 의 밀도를 갖는 쓰레기 시료를 압축하여 밀도를 0.75ton/m3 으로 증가시켰다. 이때의 부피 감소율은?

  1. 38%
  2. 45%
  3. 66%
  4. 72%
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-18 10:23

    쓰레기 시료의 초기 부피를 1m3이라고 가정하면 초기 질량은 0.41ton이 됩니다. 압축 후의 질량은 부피가 0.75ton/m3이므로 0.75ton이 됩니다.

    부피 감소율은 다음과 같이 계산할 수 있습니다.

    부피 감소율 = (초기 부피 - 압축 후 부피) / 초기 부피 x 100%

    압축 후 부피는 압축 전 밀도와 압축 후 질량을 이용하여 계산할 수 있습니다.

    압축 후 부피 = 압축 후 질량 / 압축 전 밀도

    따라서, 압축 후 부피는 다음과 같이 계산할 수 있습니다.

    압축 후 부피 = 0.75ton / 0.41ton/m3 = 1.829m3

    따라서, 부피 감소율은 다음과 같이 계산할 수 있습니다.

    부피 감소율 = (1m3 - 1.829m3) / 1m3 x 100% = -45%

    따라서, 부피 감소율은 45%입니다. 부호가 음수인 이유는 부피가 감소했기 때문입니다.

  2. 2.4
  3. 3.6
  4. 4.8
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-18 10:23

    MHT는 "1인당 1일 폐기물 수거량"을 계산하여 구할 수 있다.

    1인당 1일 폐기물 수거량 = 총 폐기물 수거량 / (인부 수 x 1일 작업 시간 x 1년 작업일수)

    = 3000000 / (4500 x 8 x 300)

    = 3000000 / 10800000

    = 0.2778

    따라서, 1인당 1일 폐기물 수거량은 0.2778톤이다.

    MHT는 이 값을 1시간 당 평균 수거량으로 환산하여 계산할 수 있다.

    1시간 당 평균 수거량 = 0.2778 / 8

    = 0.0347

    따라서, MHT는 1시간에 약 0.0347톤의 폐기물을 수거할 수 있다.

    1년에는 1시간에 0.0347톤의 폐기물을 수거하는 일수는 300 x 8 = 2400시간이다.

    따라서, MHT는 1년에 약 83.28(=0.0347 x 2400)만 톤의 폐기물을 수거할 수 있다.

    이를 100만으로 나누면, MHT는 약 3.328의 인력이 필요하다는 것을 알 수 있다.

    하지만 문제에서는 인부 수가 4500명으로 주어졌으므로,

    MHT는 4500 / 3.328 = 1351.44(≈ 1351)명의 인력으로 충분하다.

    따라서, MHT는 3.6이 아닌 1351이 된다.
