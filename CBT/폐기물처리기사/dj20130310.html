1. 도시폐기물을 파쇄할 경우 X90=2.5cm로 하여 구한 X0(특성입자)는? (단, Rosin Rammler 모델 적용, n=1)

  1. 약 1.1cm
  2. 약 1.3cm
  3. 약 2.5cm
  4. 약 1.7cm
(정답률: 67%)
  • 30 CBT 기출문제AI

    2023-04-18 10:58

    Rosin Rammler 모델은 입자 크기 분포를 나타내는 모델로, 다음과 같은 식으로 표현된다.

    $$F(X)=1-e^{-(X/X_{0})^{n}}$$

    여기서 F(X)는 X보다 작은 입자의 비율을 나타내며, X0은 특성입자의 크기를 나타내는 매개변수이다. n은 입자 크기 분포의 형태를 나타내는 매개변수로, n이 작을수록 분포가 좁아지고, n이 클수록 분포가 완만해진다.

    문제에서 X90=2.5cm로 주어졌으므로, F(X90)=0.9이다. 따라서 위의 식을 이용하여 X0을 구할 수 있다.

    $$0.9=1-e^{-(2.5/X_{0})^{1}}$$

    $$e^{-(2.5/X_{0})^{1}}=0.1$$

    $$-(2.5/X_{0})^{1}=ln(0.1)$$

    $$X_{0}=2.5/ln(10)approx1.1$$

    따라서 정답은 "약 1.1cm"이다.

5. 투입량이 1ton/h이고, 회수량이 750kg/h(그중, 회수 대상물질은 600kg/h)이며 제거량 중 회수대상물질은 70kg/h일 때 선별효율은? (단, Worrell식 적용)

  1. 약 45%
  2. 약 49%
  3. 약 54%
  4. 약 59%
(정답률: 63%)
  • 30 CBT 기출문제AI

    2023-04-18 10:58

    선별효율은 Worrell식을 이용하여 계산할 수 있다.

    선별효율 = (회수 대상물질 회수량 / 투입량) × 100

    회수 대상물질 회수량 = 70kg/h

    투입량 = 1ton/h = 1000kg/h

    선별효율 = (70kg/h / 1000kg/h) × 100 = 7%

    하지만, 문제에서 회수량이 750kg/h이고 그중 회수 대상물질은 600kg/h이므로, 실제 회수 대상물질의 회수량은 600kg/h이다.

    따라서, 선별효율 = (600kg/h / 1000kg/h) × 100 = 60%

    하지만, 제거량 중 회수대상물질은 70kg/h이므로, 실제 선별효율은 60% - (70kg/h / 1000kg/h) × 100 = 49%이다.

    따라서, 정답은 "약 49%"이다.

8. 어느 도시의 폐기물 수거량이 2,500,000톤/년, 수거인부 3,000명, 1일 작업시간 8시간, 연간 작업일 수 340일 일 때 MHT는?

  1. 약 2.38
  2. 약 2.83
  3. 약 3.26
  4. 약 3.62
(정답률: 67%)
  • 30 CBT 기출문제AI

    2023-04-18 10:58

    MHT는 다음과 같이 계산할 수 있습니다.

    MHT = (총 작업시간) / (총 작업인력 x 작업일수)

    총 작업시간 = 1일 작업시간 x 작업일수 = 8시간 x 340일 = 2,720시간
    총 작업인력 = 수거인부 = 3,000명
    작업일수 = 연간 작업일 수 = 340일

    따라서,

    MHT = 2,720시간 / (3,000명 x 340일) = 2,720시간 / 1,020,000명 = 0.00267시간/명

    이 값을 분으로 환산하면,

    MHT = 0.00267시간/명 x 60분/1시간 = 0.16분/명

    마지막으로, 분을 초로 환산하면,

    MHT = 0.16분/명 x 60초/1분 = 9.6초/명

    따라서, 폐기물 수거의 MHT는 약 3.26초/명이 됩니다.
