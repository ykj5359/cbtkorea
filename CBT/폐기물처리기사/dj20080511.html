7. X90=3.8㎝로 도시폐기물을 파쇄하고자 할 때(즉, 90% 이상을 3.8㎝보다 작게 파쇄하고자 할 때) Rosin-Rammler 모델에 의한 특성입자크기 X0는?

  1. 약 1.1㎝
  2. 약 1.3㎝
  3. 약 1.7㎝
  4. 약 1.9㎝
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-18 10:43

    Rosin-Rammler 모델은 입자크기 분포를 나타내는 모델로, 다음과 같은 식으로 표현된다.

    $$F(X)=1-e^{-(X/X_0)^n}$$

    여기서 $F(X)$는 특정 크기 이하의 입자가 차지하는 비율을 나타내며, $X$는 입자의 크기, $X_0$는 특성입자크기, $n$은 분포의 형태를 결정하는 지수이다.

    문제에서는 $X_{90}=3.8$㎝로 주어졌으므로, $F(X_{90})=0.9$이다. 따라서 다음 식을 만족해야 한다.

    $$0.9=1-e^{-(3.8/X_0)^n}$$

    양변에 $e^{-(3.8/X_0)^n}$을 곱하고 양변에 로그를 취하면,

    $$ln(1-0.9)=-(3.8/X_0)^n$$

    $$ln 0.1=-(3.8/X_0)^n$$

    양변에 $-ln 0.1$을 취하면,

    $$(3.8/X_0)^n=ln 10$$

    $n$이 일반적으로 1.5~3.0 사이의 값을 가지므로, $n=2$로 가정하면,

    $$(3.8/X_0)^2=ln 10$$

    $$X_0=3.8/sqrt{ln 10}approx 1.7text{㎝}$$

    따라서 정답은 "약 1.7㎝"이다.

25. 밀도가 2.0g/cm3인 폐기물 20㎏에다 고형화재료를 10㎏첨가하여 고형화시킨 결과 밀도가 2.8g/cm3으로 증가하였다면 부피변화율(VCF)은?

  1. 0.94
  2. 1.07
  3. 1.17
  4. 1.24
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-18 10:42

    먼저, 초기 밀도와 최종 밀도를 이용하여 첨가된 고형화재료의 질량을 구해야 한다.

    초기 밀도 = 2.0g/cm3
    최종 밀도 = 2.8g/cm3
    첨가된 고형화재료의 질량 = (최종 밀도 - 초기 밀도) × 폐기물의 부피 = (2.8 - 2.0) × 20 = 16kg

    따라서, 최종적으로는 20kg의 폐기물과 10kg의 고형화재료가 혼합되어 36kg의 물질이 만들어진다.

    부피변화율(VCF)은 다음과 같이 계산된다.

    VCF = (최종 부피 - 초기 부피) / 초기 부피

    초기 부피는 폐기물의 질량을 초기 밀도로 나눈 값이다.

    초기 부피 = 20kg / 2.0g/cm3 = 10000cm3

    최종 부피는 혼합물의 질량을 최종 밀도로 나눈 값이다.

    최종 부피 = 36kg / 2.8g/cm3 = 12857.14cm3

    따라서, VCF는 다음과 같이 계산된다.

    VCF = (12857.14 - 10000) / 10000 = 0.2857
