8. 그림과 같은 RC결합 CC증폭기 회로에서 전압이득은 약 얼마인가? (단, 입력저항 Ri = 2⑤[㏀]hie = 1.1[㏀])

  1. 51
  2. 1.3
  3. 0.995
  4. 0.699
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-15 20:50

    RC결합 CC증폭기 회로에서 전압이득은 다음과 같이 계산할 수 있다.

    전압이득 = -gm x (Rc || RL)

    여기서 gm은 hfe / (hie + re)로 계산할 수 있다. (hfe는 BJT의 진폭증폭도, hie는 입력임피던스, re는 에미터 저항)

    gm = hfe / (hie + re)

    따라서 gm을 계산하기 위해서는 hfe와 re를 알아야 한다. 이 문제에서는 이 값들이 주어지지 않았으므로, 대략적인 값을 사용하여 계산해보자.

    hfe는 일반적으로 100 ~ 300 정도의 값을 가진다. 따라서 hfe = 200으로 가정하자.

    re는 VT / Ie로 계산할 수 있다. (VT는 열적 전압, Ie는 콜렉터 전류)

    VT는 대략 26mV 정도의 값을 가지며, Ie는 Ib = Ic / hfe로 계산할 수 있다. (Ib는 베이스 전류)

    이 문제에서는 Ic가 주어지지 않았으므로, 대략적인 값을 사용하여 계산해보자. 일반적으로 Ic는 mA 단위로 주어지며, 대략 1mA 정도의 값을 가정하자.

    따라서 Ib = 1mA / 200 = 5uA이다. 이를 이용하여 Ie = (hfe + 1) x Ib = 1.0⑤mA로 계산할 수 있다.

    따라서 re = VT / Ie = 25.87[Ω]이다.

    이제 gm을 계산할 수 있다.

    gm = hfe / (hie + re) = 200 / (1.1kΩ + 25.87Ω) = 0.181[mS]

    마지막으로 전압이득을 계산하자.

    전압이득 = -gm x (Rc || RL) = -0.181[mS] x (2.2kΩ || 1kΩ) = -0.995

    따라서 전압이득은 0.995이다.
