3. 다음 정전압회로에서 제너 다이오드의 내부저항(rd)는 2[Ω]이고, 입력 직렬저항 (Rs)는 500[Ω]일 경우 전압 안정계수(S)는 약 얼마인가?

  1. 0.004
  2. 0.0⑤
  3. 0.006
  4. 0.007
(정답률: 53%)
  • 30 CBT 기출문제AI

    2023-04-15 20:43

    정전압회로에서 전압 안정계수(S)는 다음과 같이 계산된다.

    S = ΔVout / ΔVin

    여기서 ΔVout은 출력전압의 변화량, ΔVin은 입력전압의 변화량을 의미한다.

    제너 다이오드의 내부저항(rd)는 2[Ω]이므로, 입력 직렬저항 (Rs)와 함께 병렬저항으로 계산하면 다음과 같다.

    R = (rd * Rs) / (rd + Rs) = (2 * 500) / (2 + 500) ≈ 1.99[Ω]

    따라서, 전압 안정계수(S)는 다음과 같이 계산된다.

    S = ΔVout / ΔVin = 1 / (1 + R/Rs) ≈ 0.004

    따라서, 정답은 "0.004"이다.
