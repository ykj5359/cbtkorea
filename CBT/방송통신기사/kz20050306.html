7. 다음 논리식을 간략화 하면?

  2. A B + B C + C A
  3. A B + C A
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-15 20:56

    논리식을 간략화하기 위해서는 논리식을 최소항 형태로 변환해야 한다.

    논리식을 최소항 형태로 변환하기 위해서는 참인 경우를 모두 나열하고, 거짓인 경우를 최소한으로 줄여야 한다.

    따라서, 논리식 "A B + B C + C A" 에서 참인 경우를 나열하면 "A=1, B=1, C=0" 과 "A=0, B=1, C=1" 이다.

    이를 최소항으로 표현하면 "A B + C A" 이므로, 정답은 "A B + C A" 이다.

    이유는 논리식 "A B + B C + C A" 에서 "A B" 와 "C A" 가 중복되므로, 이를 하나로 합쳐서 "A B + C A" 로 간략화할 수 있다.
