2. 다음 정전압 회로에서 22[V]에서 30[V]까지 변화하는 입력전압 VS를 가지고 있다. 조정된 제너 다이오드의 양단의 출력전압이 12[V]이고 부하저항이 140[Ω]에서 100[kΩ]까지 변한다면, 최대허용 직렬저항 RS는 약 얼마인가?

  1. 117[Ω]
  2. 120[Ω]
  3. 123[Ω]
  4. 126[Ω]
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-19 09:56

    정전압 회로에서 출력전압이 일정하게 유지되기 위해서는 제너 다이오드의 동작점이 일정하게 유지되어야 한다. 따라서 입력전압의 변화에도 제너 다이오드의 동작점은 일정하게 유지되어야 하므로, 입력전압의 변화에 따라 직렬저항 RS를 조절해야 한다.

    제너 다이오드의 출력전압은 VO = VZ + VB 이다. 여기서 VZ는 제너 다이오드의 절단전압이고, VB는 베이스-에미터 절단전압이다. 이 값은 일반적으로 0.7[V] 정도이다.

    따라서 출력전압이 12[V]이므로, VZ + VB = 12[V] 이다. 이를 이용하여 VZ = 11.3[V] 이다.

    부하저항이 140[Ω]에서 100[kΩ]까지 변화하므로, 최대허용 직렬저항 RS는 100[kΩ]일 때이다. 이 때, 제너 다이오드의 출력전압은 VO = VS - VZ 이다. 따라서 VS = VO + VZ = 12[V] + 11.3[V] = 23.3[V] 이다.

    입력전압이 22[V]에서 30[V]까지 변화하므로, 최대허용 직렬저항 RS는 입력전압이 30[V]일 때이다. 이 때, 제너 다이오드의 출력전압은 VO = VS - VZ 이다. 따라서 VO = 30[V] - 11.3[V] = 18.7[V] 이다.

    부하저항이 100[kΩ]일 때, 출력전압이 12[V]이므로, RL = VO / IL = 18.7[V] / (12[V] / 100[kΩ]) = 156[kΩ] 이다.

    따라서 최대허용 직렬저항 RS는 RS = (VS - VO) / IL - RL = (23.3[V] - 18.7[V]) / (12[V] / 100[kΩ]) - 156[kΩ] = 117[Ω] 이다. 따라서 정답은 "117[Ω]"이다.

  4. 6,006

    카슨 법칙에 따르면, FM 변조된 신호의 대역폭은 최대 주파수와 최소 주파수의 합에 변조 지수를 곱한 값의 2배이다. 변조 지수는 변조 신호의 최대 주파수 변위를 원래 신호의 최대 주파수로 나눈 값이다.
