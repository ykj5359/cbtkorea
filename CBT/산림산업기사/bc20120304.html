66. 산림면적이 2,000ha이고, 임도 시설거리가 40km일 때, 임도밀도를 계산하면?

  2. 40m/ha
  3. 30m/ha
  4. 20m/ha
(정답률: 41%)

    2023-04-16 04:35

    임도밀도는 단위 면적당 임도 시설의 개수를 의미한다. 따라서, 임도밀도를 계산하기 위해서는 임도 시설의 총 개수를 구해야 한다.

    임도 시설거리가 40km이므로, 이를 미터 단위로 변환하면 40,000m이 된다. 이때, 임도 시설의 개수는 다음과 같이 계산할 수 있다.

    임도 시설의 개수 = (산림면적 / 단위 면적당 임도 시설 면적) x (임도 시설거리 / 1)

    임도 시설 면적은 일반적으로 1ha(10,000m²)로 설정되며, 문제에서는 임도 시설 면적이 명시되어 있지 않으므로, 이 값을 사용한다. 따라서, 임도 시설의 개수는 다음과 같이 계산할 수 있다.

    임도 시설의 개수 = (2,000ha / 1) x (40,000m / 1) / (10,000m² / 1ha) = 8,000개

    따라서, 단위 면적당 임도 시설 개수는 8,000개 / 2,000ha = 4개/ha가 된다. 이 값을 1/4로 역수를 취하면, 단위 면적당 임도 시설 면적을 구할 수 있다.

    단위 면적당 임도 시설 면적 = 1 / 4개/ha = 0.25ha/개

    이 값을 10,000m²/ha로 곱하면, 단위 면적당 임도 시설 면적을 m² 단위로 구할 수 있다.

    단위 면적당 임도 시설 면적 = 0.25ha/개 x 10,000m²/ha = 2,500m²/개

    따라서, 임도밀도는 1개당 2,500m²이므로, 이를 m/ha 단위로 변환하면 다음과 같다.

    임도밀도 = 1개/2,500m² x 1,000m/1km x 1km²/1,000,000m² x 2,000ha = 0.8개/ha
