    유역면적과 최대시우량으로 유출계수를 구할 수 있습니다.

    유출계수(c) = 최대시유량(Q) / 유역면적(A) x 3600

    c = 100 / 40 x 3600 = 9

    합리식법으로 최대홍수 유량(Qp)을 구할 수 있습니다.

    Qp = c x C x A^(1/2)

    Qp = 9 x 0.7 x 40^(1/2) = 21.07

    하지만, 이 문제에서는 최대시우량이 100m/h이므로, 시간 단위로 변환해줘야 합니다.

    100m/h = 100 / 3600 m/s = 0.0278 m/s

    따라서, 최대홍수 유량(Qp)을 시간 단위로 변환해줘야 합니다.

    Qp = 21.07 / 0.0278 = 757.2 m^3/s

    따라서, 최대홍수 유량은 757.2 m^3/s 입니다.

    단면면적(S) = Qp / V

    여기서는 D를 1.5 m로 선택하겠습니다.

    S = L x D = L x 1.5

    L = S / 1.5 = 504.8 / 1.5 = 336.5 m

    따라서, 최대홍수 유량을 고려한 단면의 가로길이는 336.5 m 입니다.

    단면면적(S) = 가로길이(L) x 수심(D)

    S = 336.5 x D

    D = S / 336.5

    D = 504.8 / 336.5 = 1.5

    따라서, 최대홍수 유량을 고려한 단면의 수심은 1.5 m 입니다.
