    FoS = 강도 / 작용력
    SoR = 파괴저항 / 파괴작용

    파괴작용은 토박력과 지반중력의 합으로 구할 수 있다.

    강도 = EΔL/LA = 30000 × 0.15 / (2 × 5) = 2250 kN/m2

    파괴저항 = c + σtanφ = 1.5 + 2250 × tan30° = 1506 kN/m2
    파괴작용 = q + γHcosα = 1.8 × 5 × cos15° + 1.8 × 5 = 11.3 kN/m2

    따라서,

    FoS = 강도 / 작용력 = 2250 / 0.47 = 4787
    SoR = 파괴저항 / 파괴작용 = 1506 / 11.3 = 133.4

77. 직경 30cm 콘크리트 말뚝을 단동식 증기해머로 타입하였을 때 엔지니어링 뉴스 공식을 적용한 말뚝의 허용지지력은?(단, 타격에너지=3.6tㆍm, 해머효율=0.8, 손실상수=0.25cm, 마지막 25mm관입에 필요한 타격횟수=5)

    허용탄성변형량 = (말뚝의 길이) / 500
    허용하중 = (허용탄성변형량) * (단면적) * (콘크리트의 인장강도)

    3.6tㆍm = (말뚝의 길이) * (단면적) * (콘크리트의 밀도) * (0.8) * (0.25cm) * (5)
