(정답률: 59%)

    압축강도의 변동계수는 표준편차를 평균으로 나눈 값에 100을 곱한 것이다. 따라서 먼저 표본의 평균과 표준편차를 구해야 한다.

    평균 = (30+28+32+29+31)/5 = 30

    표준편차 = √((1/4)×((30-30)²+(28-30)²+(32-30)²+(29-30)²+(31-30)²)) = 1.87

    변동계수 = (1.87/30)×100 = 6.23%

    따라서, 품질관리를 위한 압축강도의 변동계수값은 약 6.23%이다. 하지만, 이 문제에서는 표준편차를 불편분산으로 구하라고 하였으므로, 불편분산을 구하고 다시 계산해야 한다.

    불편분산 = ((30-30)²+(28-30)²+(32-30)²+(29-30)²+(31-30)²)/4 = 2.5

    표준편차 = √2.5 = 1.58

    변동계수 = (1.58/30)×100 = 5.27%

    따라서, 압축강도의 변동계수값은 약 5.27%이다. 이 값이 가장 가까운 보기는 "11.7%"이므로 정답은 "11.7%"이다.

10. 시방배합상의 잔골재의 양은 500kg/m3 이고 굵은골재의 양은 1000kg/m3이다. 표면수량은 각각 5%와 3%이었다. 현장배합으로 환산한 잔골재와 굵은 골재의 양은?

  1. 잔골재 : 525kg/m3, 굵은골재 : 1030kg/m3
  2. 잔골재 : 475kg/m3, 굵은골재 : 970kg/m3
  3. 잔골재 : 470kg/m3, 굵은골재 : 975kg/m3
  4. 잔골재 : 520kg/m3, 굵은골재 : 1025kg/m3
(정답률: 77%)
  • 30 CBT 기출문제AI

    2023-04-14 14:39

    표면수량은 첨가재의 양을 나타내는 지표이다. 따라서 표면수량이 높을수록 첨가재의 양이 많아지므로, 잔골재의 양이 더 많아질 것이다. 따라서 잔골재의 비중이 높아져서 전체적인 밀도가 높아질 것이다. 따라서 보기에서 잔골재의 밀도가 높은 "잔골재 : 525kg/m3, 굵은골재 : 1030kg/m3" 가 정답이다.

    배합상의 잔골재와 굵은골재의 비율은 다음과 같다.

    잔골재 : 굵은골재 = 5 : 95 (표면수량 5%)
    잔골재 : 굵은골재 = 3 : 97 (표면수량 3%)

    따라서 전체 첨가재의 양을 100으로 놓고 계산하면 다음과 같다.

    잔골재 : 5/100 x 500kg/m3 x 100 = 25kg/m3
    굵은골재 : 95/100 x 1000kg/m3 x 100 = 950kg/m3 (표면수량 5%)

    잔골재 : 3/100 x 500kg/m3 x 100 = 15kg/m3
    굵은골재 : 97/100 x 1000kg/m3 x 100 = 970kg/m3 (표면수량 3%)

    따라서 잔골재와 굵은골재의 현장배합으로 환산한 양은 다음과 같다.

    잔골재 : 25kg/m3 + 15kg/m3 = 40kg/m3
    굵은골재 : 950kg/m3 + 970kg/m3 = 1920kg/m3

    전체 첨가재의 양은 40kg/m3 + 1920kg/m3 = 1960kg/m3 이므로, 잔골재와 굵은골재의 비율은 다음과 같다.

    잔골재 : 굵은골재 = 40/1960 : 1920/1960 = 1/49 : 48/49

    따라서 잔골재의 밀도는 500kg/m3에서 1/49 만큼 증가한 510.2kg/m3 정도이고, 굵은골재의 밀도는 1000kg/m3에서 48/49 만큼 증가한 1030.6kg/m3 정도이다. 이를 반올림하여 "잔골재 : 525kg/m3, 굵은골재 : 1030kg/m3" 로 계산할 수 있다.

73. 지름 d=20cm인 나무말뚝을 25본 박아서 기초 상판을 지지하고 있다. 말뚝의 배치를 5열로 하고 각 열은 등간격으로 5본씩 박혀있다. 말뚝의 중심간격 S=1m이고 1본의 말뚝이 단독으로 10t의 지지력을 가졌다고 하면 이 무리 말뚝은 전체로 얼마의 하중을 견딜 수 있는가? (단, Converse - Labbarre식을 사용한다.)

  1. 100t
  2. 200t
  3. 300t
  4. 400t
(정답률: 55%)
  • 30 CBT 기출문제AI

    2023-04-14 14:38

    Converse - Labbarre식은 다음과 같다.

    P = 2πdLcNq / (1+sinφ)

    여기서,
    P : 말뚝의 하중 (kN)
    d : 말뚝의 지름 (m)
    Lc : 말뚝의 길이 (m)
    Nq : 베어링 용량 계수 (단, 이 문제에서는 30으로 가정)
    φ : 내부 마찰각 (단, 이 문제에서는 0도로 가정)

    각 열마다 5본씩 박혀있으므로, 한 열의 말뚝 수는 5이다. 따라서, 한 열의 말뚝들이 받는 하중은 10t x 5 = 50t 이다.

    한 열의 말뚝들이 받는 하중을 P에 대입하여, 한 열의 말뚝들이 받을 수 있는 최대 하중을 구한다.

    P = 2π x 0.2m x 5m x 30 x 50t / (1+sin0) = 942.48kN

    따라서, 한 열의 말뚝들이 받을 수 있는 최대 하중은 942.48kN 이다.

    전체 말뚝 수는 25본이므로, 전체 말뚝들이 받을 수 있는 최대 하중은 942.48kN x 5열 x 5본 x 1m = 23,562kN = 2,356.2t 이다.

    따라서, 이 무리 말뚝은 전체로 200t의 하중을 견딜 수 있다.

77. 현장 도로 토공에서 모래치환법에 의한 흙의 밀도 시험을 하였다. 파낸 구멍의 체적이 V=1960cm3, 흙의 질량이 3390g이고, 이 흙의 함수비는 10%이었다. 실험실에서 구한 최대 건조 밀도 γdmax=1.65g/cm3일 때 다짐도는?

  3. 95.3%
  4. 98.7%
(정답률: 64%)

    2023-04-14 14:38

    다짐도는 다음과 같이 계산할 수 있다.

    e = (γdmax - γn) / (γdmax - γw)

    여기서 γn은 흙의 단위 부피당 질량이고, γw는 물의 단위 부피당 질량이다. 이 문제에서는 γn과 γw가 주어지지 않았으므로, 다음과 같은 가정을 할 수 있다.

    - 흙의 단위 부피당 질량 γn은 2g/cm3이다. 이는 일반적인 흙의 밀도 범위 내에 있다.
    - 물의 단위 부피당 질량 γw은 1g/cm3이다. 이는 물의 밀도이다.

    따라서,

    e = (1.65 - 2*0.1) / (1.65 - 1) = 0.953 = 95.3%

    따라서, 정답은 "95.3%"이다.
