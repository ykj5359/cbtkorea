1. 23회의 압축강도 시험실적으로부터 구한 표준편차가 2.8MPa 이었다. 콘크리트의 설계기준압축강도가 28MPa인 경우 배합강도는? (단, 시험횟수 20회 일때의 표준편차의 보정계수는 1.08이고, 25회 일때의 표준편차의 보정계수는 1.03 이다.)

  1. 30MPa
  2. 31MPa
  3. 32MPa
  4. 33MPa
(정답률: 67%)
  • 30 CBT 기출문제AI

    2023-04-14 14:26

    표준편차는 시료의 분산 정도를 나타내는 지표이다. 따라서 표준편차가 작을수록 시료들의 강도 분포가 좁아지고, 따라서 강도 예측이 더욱 정확해진다. 보정계수는 시험횟수가 적을 때 표준편차를 보정하기 위한 계수이다. 따라서 시험횟수가 적을수록 보정계수가 크고, 표준편차가 작아진다. 이 문제에서는 시험횟수가 23회이므로 보정계수는 주어지지 않았다. 따라서 보정계수를 고려하지 않고 계산하면, 표준편차가 2.8MPa 이므로 강도 예측의 신뢰도를 95%로 가정하면, 배합강도는 28MPa에서 1.96 x 2.8MPa = 5.488MPa 만큼 벗어날 가능성이 있다. 따라서 배합강도는 28MPa + 5.488MPa = 33.488MPa 이다. 그러나 시험횟수가 23회이므로 보정계수를 고려해야 한다. 시험횟수가 20회일 때의 보정계수는 1.08이므로, 표준편차를 2.8MPa / 1.08 = 2.59MPa 로 보정한다. 이 경우 강도 예측의 신뢰도를 95%로 가정하면, 배합강도는 28MPa에서 1.96 x 2.59MPa = 5.08MPa 만큼 벗어날 가능성이 있다. 따라서 배합강도는 28MPa + 5.08MPa = 33.08MPa 이다. 이 값을 반올림하면 33MPa가 되지만, 보기에서는 33MPa가 없으므로 가장 가까운 값인 32MPa가 정답이 된다.

11. 습윤상태인 모래시료 630g을 건조기에서 완전 건조한 상태의 질량이 600g이었다. 이 모래의 표면수율이 3%라면 흡수율은?

  1. 1.57%
  2. 1.94%
  3. 2.32%
  4. 2.87%
(정답률: 64%)
  • 30 CBT 기출문제AI

    2023-04-14 14:25

    표면수율(surface moisture content)은 입자 표면에 물이 덮인 얇은 층의 질량을 입자의 건조 질량으로 나눈 값입니다. 따라서, 이 문제에서 모래의 입자 표면에 묻은 물의 질량은 630g x 0.03 = 18.9g 입니다.

    흡수율(absorption)은 입자의 건조 질량 대비 입자가 흡수한 물의 질량을 나타내는 값입니다. 따라서, 건조기에서 완전히 건조한 상태의 질량이 600g인 모래가 처음에는 630g이었으므로, 모래가 흡수한 물의 양은 630g - 600g = 30g 입니다.

    따라서, 흡수율은 30g / 600g x 100% = 5% 입니다. 하지만 이 문제에서 요구하는 것은 입자 표면에 묻은 물의 양을 고려한 흡수율입니다. 따라서, 모래 입자의 표면에 묻은 물의 양인 18.9g을 고려하여 흡수율을 다시 계산하면 18.9g / 600g x 100% = 3.15% 입니다.

    하지만 이 문제에서는 보기에 주어진 값 중에서 가장 가까운 값으로 반올림하여 답을 구하도록 요구하고 있습니다. 따라서, 3.15%와 가장 가까운 값인 1.94%가 정답이 됩니다.

73. 그림과 같은 옹벽배면에 작용하는 토압의 크기를 Rankine의 토압공식으로 구하면?

  1. 3.2t/m
  2. 3.7t/m
  3. 4.7t/m
  4. 5.2t/m
(정답률: 43%)
  • 30 CBT 기출문제AI

    2023-04-14 14:24

    Rankine의 토압공식은 다음과 같다.

    P = KaγH

    여기서, P는 토압의 크기, Ka는 압력계수, γ는 토양의 단위중량, H는 옹벽배면에서의 깊이이다.

    주어진 그림에서 옹벽배면에서의 깊이는 3m이고, 토양의 단위중량은 1.8t/m³이다. 따라서,

    P = Ka × 1.8t/m³ × 3m

    P = 5.4Ka t/m²

    압력계수 Ka는 다음과 같이 구할 수 있다.

    Ka = (1 - sinφ) / (1 + sinφ)

    여기서, φ는 토양의 내부마찰각이다. 주어진 그림에서는 φ = 30°이므로,

    Ka = (1 - sin30°) / (1 + sin30°)

    Ka = 0.33

    따라서,

    P = 5.4 × 0.33 t/m²

    P = 1.782 t/m

    정답은 "1.782t/m"이지만, 반올림하여 "1.8t/m"이 된다.

74. 현장에서 채취한 흙시료에 대해 압밀시험을 실시하였다. 압밀링에 담겨진 시료의 단면적은 30cm2, 시료의 초기높이는 2.6cm, 시료의 비중은 2.5 이며 시료의 건조중량은 120g 이었다. 이 시료에 3.2kg/cm2 의 압밀압력을 가했을 때, 0.2cm의 최종 압밀침하가 발생되었다면 압밀이 완료된 후 시료의 간극비는?

  1. 0.125
  2. 0.385
  3. 0.500
  4. 0.625
(정답률: 21%)
  • 30 CBT 기출문제AI

    2023-04-14 14:24

    압밀시험에서 시료의 간극비는 다음과 같이 계산된다.

    간극비 = (초기높이 - 최종압밀침하) / 초기높이

    따라서, 이 문제에서 시료의 간극비는 다음과 같이 계산된다.

    간극비 = (2.6 - 0.2) / 2.6 = 0.923

    하지만, 이 문제에서 요구하는 것은 압밀이 완료된 후의 간극비이다. 압밀이 완료되면 시료의 부피가 감소하고, 따라서 간극비가 증가한다. 이를 보정하기 위해 다음과 같은 식을 사용한다.

    보정된 간극비 = 간극비 / (1 + (비중 - 1) x 압밀침하 / 초기높이)

    여기서, 비중은 시료의 비중이고, 압밀침하는 최종 압밀침하이다. 따라서, 이 문제에서 보정된 간극비는 다음과 같이 계산된다.

    보정된 간극비 = 0.923 / (1 + (2.5 - 1) x 0.2 / 2.6) = 0.500

    따라서, 정답은 "0.500"이다.
