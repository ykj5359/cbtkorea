    시간당 작업량 = 불도저의 속력 × 불도저의 폭 × 불도저의 깊이

    불도저의 속력은 2km/h 이므로, 1시간에 2km를 이동한다.

    불도저의 폭은 3.5m 이므로, 1시간에 3.5m를 토공한다.

    불도저의 깊이는 0.3m 이므로, 1시간에 0.3m를 토공한다.

    시간당 작업량 = 2km/h × 3.5m × 0.3m = 2,100m3/h

    본바닥 토량 = 작업면적 × 작업깊이

    작업면적은 불도저의 폭과 작업면의 길이를 곱한 값이다.

    작업면적 = 불도저의 폭 × 작업면의 길이 = 3.5m × 20m = 70m2

    따라서, 본바닥 토량은 다음과 같이 계산할 수 있다.

    본바닥 토량 = 70m2 × 0.3m = 21m3

    따라서, 불도저의 시간당 작업량은 다음과 같이 계산할 수 있다.

    시간당 작업량 = 2,100m3/h ÷ 21m3 = 100m/h

  2. 95.2%
  3. 97.1%
  4. 98.1%
(정답률: 36%)
  • 30 CBT 기출문제AI

    2023-04-14 14:34

    상대다짐도 = (실제 단위중량 / 최대건조 단위중량) x 100

    먼저, 최대건조 단위중량은 주어졌으므로 계산할 필요가 없다.

    실제 단위중량을 구하기 위해서는 들밀도와 함수비를 이용해야 한다.

    들밀도 = 파낸 흙의 무게 / 파낸 부분의 체적 = 3.95kg / 1,800cm^3 = 0.0021944kg/cm^3

    함수비 = (파낸 부분의 체적 - 들어간 부분의 체적) / 들어간 부분의 체적 = (1,800cm^3 - 1,600cm^3) / 1,600cm^3 = 0.125

    들어간 부분의 체적은 파낸 부분의 체적 x (1 - 함수비) = 1,800cm^3 x 0.875 = 1,575cm^3

    따라서, 들어간 부분의 무게는 전체 무게에서 파낸 부분의 무게를 빼면 된다.

    들어간 부분의 무게 = 전체 무게 - 파낸 부분의 무게 = (1,800cm^3 + 1,575cm^3) x 2.65g/cm^3 - 3.95kg = 6.0075kg

  2. 5.5t/m
  3. 6.5t/m
  4. 9.13t/m

    주어진 문제는 연직옹벽의 주동토압을 구하는 것이다. 이를 구하기 위해서는 다음과 같은 공식을 사용한다.

    P = Ka * γ * H

    여기서 P는 주동토압, Ka는 활동계수, γ는 토의 단위중량, H는 옹벽의 높이이다.

    우선 활동계수를 구해야 한다. 내부마찰각이 25˚이고 점착력이 없으므로, 활동계수는 다음과 같이 구할 수 있다.

    Ka = tan²(45 + φ/2) = tan²(45 + 25/2) ≈ 1.63

    P = 1.63 * 1.8 * 5 ≈ 14.67t/m

    하지만, 이 값은 수평 지표에서의 주동토압이므로, 연직옹벽에서의 주동토압을 구하기 위해서는 수직방향으로의 힘을 구해야 한다. 이를 위해서는 수평방향으로의 힘을 구하고, 이를 연직방향으로 변환해야 한다.

    수평방향으로의 힘은 다음과 같다.

    Fh = P * H = 14.67 * 5 ≈ 73.35t/m

    연직방향으로의 힘은 다음과 같다.

    Fv = Fh * tan(45 + φ/2) = 73.35 * tan(45 + 25/2) ≈ 45.22t/m

    따라서, 연직옹벽에서의 주동토압은 다음과 같다.

    P = Fv / H = 45.22 / 5 ≈ 9.13t/m

    따라서, 정답은 "9.13t/m"이다.
