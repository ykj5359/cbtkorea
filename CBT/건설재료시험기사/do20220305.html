9. 현장의 골재에 대한 체분석 결과 잔골재 속에서 5mm 체를 남는 것이 6%, 굵은 골재 속에서 5mm체를 통과하는 것이 11% 이었다. 시방배합표상의 단위 잔골재량이 632kg/m3, 단위 굵은 골재량이 1176kg/m3일 때 현장배합을 위한 단위 잔골재량은? (단, 표면수에 대한 보정은 무시한다.)

    잔골재 속에서 5mm체를 남기는 비율이 6%이므로, 94%는 5mm보다 작은 입도의 골재이다. 따라서 잔골재의 유효입도는 5mm보다 작은 입도의 골재의 비중으로 계산할 수 있다. 이를 통해 잔골재의 유효입도는 632kg/m3 x 94% = 594.08kg/m3 이다.

    굵은 골재 속에서 5mm체를 통과하는 비율이 11%이므로, 89%는 5mm보다 큰 입도의 골재이다. 따라서 굵은 골재의 유효입도는 5mm보다 큰 입도의 골재의 비중으로 계산할 수 있다. 이를 통해 굵은 골재의 유효입도는 1176kg/m3 x 89% = 1044.64kg/m3 이다.

    따라서 현장배합을 위한 단위 잔골재량은 다음과 같이 계산할 수 있다.

    단위 잔골재량 = (전체체적 - 굵은 골재체적) x 잔골재 유효입도 / (잔골재 유효입도 + 굵은 골재 유효입도)

    여기서 전체체적은 잔골재와 굵은 골재를 합친 체적이다.

    전체체적 = 1m3 = 1000L

    굵은 골재체적은 다음과 같이 계산할 수 있다.

    굵은 골재체적 = 전체체적 x 굵은 골재 비중 = 1000L x 1176kg/m3 / 1000 = 1176L

    따라서 단위 잔골재량은 다음과 같이 계산할 수 있다.

    단위 잔골재량 = (1000L - 1176L) x 594.08kg/m3 / (594.08kg/m3 + 1044.64kg/m3) = 522kg/m3

    따라서 정답은 "522 kg/m3" 이다.

    따라서 E = 1 - (20-1)/190 = 0.8958 이다.

70. 토립자가 둥글고 입도분포가 나쁜 모래 지반에서 표준관입시험을 한 결과 N값을 10이었다. 이 모래의 내부 마찰각(ø)을 Dunham의 공식으로 구하면?

  1. 21°
  2. 26°
  3. 31°
  4. 36°
(정답률: 43%)

    2023-04-14 14:58

    Dunham의 공식은 다음과 같다.

    N = (2Cn/π) * tan[(45+ø/2)°] * tan[(45-ø/2)°]

    여기서 N은 표준관입시험에서 측정된 N값이고, Cn은 토립자의 보정상수이다.

    이 문제에서는 N값이 10이므로, Cn을 구해야 한다. Cn은 다음과 같이 구할 수 있다.

    Cn = (π/2) * [(D^2 - d^2)/D^2]

    여기서 D는 토립자의 직경이고, d는 토립자의 중심구멍의 직경이다. 이 문제에서는 토립자가 둥글기 때문에 D와 d는 같다고 가정할 수 있다. 따라서 Cn은 다음과 같이 계산할 수 있다.

    Cn = (π/2) * [(D^2 - d^2)/D^2] = (π/2) * [(D^2 - D^2)/D^2] = 0

    따라서 Cn은 0이다.

    이제 Dunham의 공식에 N값과 Cn값을 대입하여 ø를 구할 수 있다.

    N = (2Cn/π) * tan[(45+ø/2)°] * tan[(45-ø/2)°]
    10 = (2*0/π) * tan[(45+ø/2)°] * tan[(45-ø/2)°]
    tan[(45+ø/2)°] * tan[(45-ø/2)°] = 0

    여기서 tan[(45+ø/2)°]과 tan[(45-ø/2)°]는 서로 역수 관계이므로, 둘 중 하나가 0이면 다른 하나는 무한대가 된다. 따라서 tan[(45+ø/2)°]과 tan[(45-ø/2)°] 중 하나는 0이 되어야 한다.

    tan[(45+ø/2)°] = 0일 때,

    (45+ø/2)° = 180°n (n은 정수)

    ø = 360°n - 90°

    하지만 이 경우 ø는 0보다 작아지므로 가능하지 않다.

    따라서 tan[(45-ø/2)°] = 0일 때,

    (45-ø/2)° = 180°n (n은 정수)

    ø = 360°n - 90°

    여기서 ø는 0보다 크고 90°보다 작아야 하므로, n은 0 또는 1이어야 한다.

    n = 0일 때, ø = -90°로 가능하지 않다.

    n = 1일 때, ø = 270°이다.

    하지만 ø는 0보다 크고 90°보다 작아야 하므로, ø = 270°은 가능하지 않다.

    따라서 정답은 ø = 360°n - 90° 중에서 0보다 크고 90°보다 작은 값이어야 한다.

    이 중에서 26°이 정답인 이유는, ø가 26°일 때 Dunham의 공식이 N = 10을 만족하기 때문이다.

    - 수동토압(Pp)은 인력이나 기계적인 힘에 의해 발생하는 토압으로, 주로 건설 현장에서 발생한다. 주동토압보다는 작용하는 토압의 크기가 작을 수 있다.
    - 정지토압(Po)은 벽체와 토양 사이의 마찰력에 의해 발생하는 토압으로, 벽체가 움직이지 않을 때 발생한다. 따라서 주동토압과 수동토압보다는 작용하는 토압의 크기가 더 작을 수 있다.

    따라서 Pp ＞ Po ＞ Pa의 순서가 옳다.

75. 포화된 점토에 대하여 비압밀비배수(UU) 시험을 하였을 때 결과에 대한 설명으로 옳은 것은? (단, ø : 내부마찰각, c : 점착력)

  1. ø와 c가 나타나지 않는다.
  2. ø와 c가 모두 “0”이 아니다.
  3. ø는 “0”이 아니지만 c는 “0”이다.
  4. ø는 “0”이고 c는 “0”이 아니다.
(정답률: 49%)
  • 30 CBT 기출문제AI

    2023-04-14 14:58

    정답은 "ø는 “0”이 아니지만 c는 “0”이다."이다.

    비압밀비배수(UU) 시험은 포화된 점토의 내부마찰각(ø)과 점착력(c)을 측정하는 시험이다. 따라서 ø와 c가 나타나지 않는다는 보기는 틀린 설명이다.

    ø는 점토 입자 간의 마찰에 의한 내부저항을 나타내는 값으로, 점토 입자의 크기, 모양, 표면 상태 등에 영향을 받는다. 따라서 ø가 “0”이 되는 경우는 거의 없다.

    반면에 c는 점토 입자와 시험기의 벽면 사이의 접착력을 나타내는 값으로, 점토 입자의 표면 상태, 시험기 벽면의 특성 등에 영향을 받는다. 따라서 c가 “0”이 되는 경우도 있지만, 대부분의 경우 c는 “0”이 아니다.

77. 점토지반으로부터 불교란 시료를 채취하였다. 이 시료의 지름이 50mm, 길이가 100mm, 습윤 질량이 350g, 함수비가 40% 일 때 이 시료의 건조밀도는?

  1. 1.78 g/cm3
  2. 1.43 g/cm3
  3. 1.27 g/cm3
  4. 1.14 g/cm3
(정답률: 62%)

    2023-04-14 14:58

    건조밀도 = (습윤질량 / 건조체적) = (습윤질량 / (지름/2)^2 * 길이)

    건조체적 = (지름/2)^2 * 길이 = (50/2)^2 * 100 = 196,000 mm^3

    습윤질량 = 건조질량 / (1 + 함수비) = 350g / (1 + 0.4) = 250g

    따라서, 건조밀도 = 250g / 196,000 mm^3 = 1.27 g/cm^3
