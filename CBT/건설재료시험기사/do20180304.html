    안전율 = 강도 / 하중

    여기서 강도는 내부마찰각과 코펠각을 이용하여 계산할 수 있다. 코펠각은 경사각과 지반의 마찰각을 이용하여 계산할 수 있다.

    코펠각 = arctan(경사각)

    강도 = (지반의 마찰각) / (코펠각 + tan(지반의 마찰각))

    하중 = (지하수위까지의 압력) x (지반의 단면적)

    여기서 지하수위까지의 압력은 다음과 같이 계산된다.

    지하수위까지의 압력 = (지하수위까지의 수직 깊이) x (지하수의 밀도) x (중력가속도)

    따라서 안전율은 다음과 같이 계산된다.

    안전율 = ((지반의 마찰각) / (arctan(경사각) + tan(지반의 마찰각))) / ((지하수위까지의 수직 깊이) x (지하수의 밀도) x (중력가속도) x (지반의 단면적))

    이 문제에서는 안전율이 1 이상이 되기 위한 최소한의 내부마찰각을 구하는 것이 목적이므로, 위의 식에서 안전율을 1로 놓고 내부마찰각을 구하면 된다.

    1 = ((지반의 마찰각) / (arctan(경사각) + tan(지반의 마찰각))) / ((지하수위까지의 수직 깊이) x (지하수의 밀도) x (중력가속도) x (지반의 단면적))
