64. 아래 그림에서 투수계수 K=4.8×103cm/sec 일 때 Darcy 유출속도(v)와 실제 물의 속도(침투속도, vs)는?

  1. v=3.4×10-4cm/sec, vs=5.6×10-4cm/sec
  2. v=3.4×10-4cm/sec, vs=9.4×10-4cm/sec
  3. v=5.8×10-4cm/sec, vs=10.8×10-4cm/sec
  4. v=5.8×10-4cm/sec, vs=13.2×10-4cm/sec
(정답률: 45%)
  • 30 CBT 기출문제AI

    2023-04-19 09:26

    Darcy의 법칙에 따르면 유체의 유출속도(v)는 다음과 같다.

    v = KΔh/L

    여기서 Δh는 유체가 흐르는 높이차이, L은 유체가 흐르는 거리이다. 따라서 이 문제에서는 Δh와 L을 구해야 한다.

    먼저 Δh를 구하기 위해, 그림에서 A지점과 B지점 사이의 높이차이를 계산한다.

    Δh = 20cm - 10cm = 10cm

    다음으로 L을 구하기 위해, 그림에서 A지점과 B지점 사이의 거리를 계산한다.

    L = 40cm

    이제 이 값을 Darcy의 법칙에 대입하여 유출속도(v)를 계산할 수 있다.

    v = KΔh/L = (4.8×10^3 cm/sec) × (10cm) / (40cm) = 1.2×10^3 cm^2/sec

    마지막으로, 실제 물의 속도(침투속도, v_s)는 porosity(n)를 고려하여 다음과 같이 계산된다.

    v_s = v/n

    porosity(n)은 그림에서 빈 공간의 비율로 주어졌다. 따라서 이 값을 이용하여 porosity(n)을 계산할 수 있다.

    n = (빈 공간의 부피) / (전체 부피) = (πr^2h - πr^2h') / (πr^2h) = (h - h')/h

    여기서 r은 원통의 반지름, h은 원통의 높이, h'은 물이 차지하는 높이이다. 따라서 이 문제에서는 다음과 같다.

    n = (20cm - 10cm) / 20cm = 0.5

    이제 이 값을 이용하여 실제 물의 속도(침투속도, v_s)를 계산할 수 있다.

    v_s = v/n = (1.2×10^3 cm^2/sec) / 0.5 = 2.4×10^3 cm/sec

    하지만 이 값은 cm/sec이 아니라 cm/min으로 주어져 있으므로, 다시 단위를 변환해준다.

    v_s = 2.4×10^3 cm/min = 2.4×10^-2 cm/sec

    따라서 정답은 "v=5.8×10^-4cm/sec, v_s=13.2×10^-4cm/sec"이다.
