9. 시방배합결과 물 180㎏/m3, 잔골재 650㎏/m3, 굵은 골재 1000㎏/m3을 얻었다. 잔골재의 흡수율이 2%, 표면수율이 3%라고 하면 현장배합상의 단위 잔골재량은?

  1. 637.0 kg/m3
  2. 656.5 kg/m3
  3. 663.0kg/m3
  4. 669.5kg/m3
(정답률: 42%)
  • 30 CBT 기출문제AI

    2023-04-14 14:44

    단위 부피당 잔골재의 무게는 다음과 같다.

    잔골재 무게 = (물의 부피 × 물의 밀도) + (잔골재의 부피 × 잔골재의 밀도) + (굵은 골재의 부피 × 굵은 골재의 밀도)

    여기서 물의 부피는 1m3이므로 180kg이다. 굵은 골재의 부피는 표면수율을 곱한 후 잔골재의 부피를 뺀 값이다.

    굵은 골재의 부피 = 1 - (잔골재의 부피 × (1 + 흡수율))

    따라서 굵은 골재의 부피는 0.97m3이다. 이를 대입하여 계산하면 다음과 같다.

    잔골재 무게 = (1 × 180) + (잔골재의 부피 × 650 × (1 + 흡수율)) + (0.97 × 1000)

    잔골재 무게 = 180 + (잔골재의 부피 × 663) + 970

    잔골재 무게 = 1150 + (잔골재의 부피 × 663)

    잔골재 무게 = 1150 + (잔골재의 부피 × 0.663 × 1000)

    잔골재 무게 = 1150 + (잔골재의 부피 × 663)

    잔골재 무게 = 1150 + (잔골재의 부피 × 663)

    잔골재 무게 - 1150 = 잔골재의 부피 × 663

    (잔골재 무게 - 1150) / 663 = 잔골재의 부피

    잔골재의 부피 = 0.637m3

    따라서 단위 잔골재량은 다음과 같다.

    단위 잔골재량 = 잔골재의 무게 / 1m3

    단위 잔골재량 = (잔골재의 부피 × 650 × (1 + 흡수율)) / 1m3

    단위 잔골재량 = (0.637 × 650 × 1.02) / 1m3

    단위 잔골재량 = 669.5kg/m3

    따라서 정답은 "669.5kg/m3"이다.

  3. 0.30
  4. 0.35

    2023-04-14 14:41

    압축지수(Cc)는 다음과 같은 식으로 구할 수 있다.

    Cc = (emax - emin) / log(Pmax / Pmin)

    여기서 emax는 최대압축률, emin은 최소압축률, Pmax는 최대응력, Pmin은 최소응력이다.

    최대압축률 emax = 40%

    최소압축률 emin = 22.3%

    최대응력 Pmax는 정규압밀 상태에서의 최대응력으로, 이는 다음과 같이 구할 수 있다.

    Pmax = (σ1 + σ3) / 2 + (σ1 - σ3) / 2 * emax

    여기서 σ1은 최대주축응력, σ3은 최소주축응력이다. 정규압밀 상태에서는 σ1 = σ3 이므로,

    Pmax = σ1 * (1 + emax)

    Pmin = σ3 * (1 + emin)

    따라서,

    Pmax / Pmin = (σ1 / σ3) * (1 + emax) / (1 + emin)

    정규압밀 상태에서는 σ1 / σ3 = 1, 따라서

    Pmax / Pmin = (1 + emax) / (1 + emin)

    Cc = (emax - emin) / log((1 + emax) / (1 + emin))

    Cc = (0.4 - 0.223) / log((1 + 0.4) / (1 + 0.223)) = 0.27

    P = nL/2 * σ * A
