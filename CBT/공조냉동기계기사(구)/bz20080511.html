1. 다음 그림과 같은 랭킨 사이클에서 각 점의 엔탈피(kJ/kg)가 각각 i1 = 800, i2 = 350, i3 = 50, i4 = 200이다. 이 사이클의 효율은 얼마인가?

  1. 20%
  2. 30%
  3. 40%
  4. 50%
(정답률: 50%)
  • 30 CBT 기출문제AI

    2023-04-15 04:02

    랭킨 사이클에서의 열효율은 1 - (T4/T1)이다. 엔탈피는 온도와 관련이 있으므로, 열효율을 구하기 위해서는 각 점의 온도를 알아야 한다. 랭킨 사이클에서는 1-2, 3-4 구간이 등압과정이므로, 이 구간에서의 엔탈피 변화량은 온도 변화량과 같다. 따라서, i1 - i2 = cp(T1 - T2)와 i4 - i3 = cp(T4 - T3)이 성립한다. 여기서 cp는 열용량을 나타내는 상수이다. 이를 이용하여 T1 - T2 = (i1 - i2)/cp와 T4 - T3 = (i4 - i3)/cp를 구할 수 있다. 또한, 2-3, 4-1 구간에서는 등엔트로피과정이므로, 이 구간에서의 엔탈피 변화량은 0이다. 따라서, i3 = i2와 i4 = i1이 성립한다. 이를 이용하여 T2 = (i1 - i2)/cp + T1, T3 = T4 - (i1 - i2)/cp이 된다. 따라서, 열효율은 1 - (T4/T1) = 1 - (T3/T2) = 1 - [(T4 - (i1 - i2)/cp)/((i1 - i2)/cp + T1)]이 된다. 이를 계산하면 약 50%가 된다. 따라서, 정답은 "50%"이다.

3. 이상기체의 압력(P), 체적(V)의 관계식 "PVn = 일정"에서 가역단열과정을 표시하는 n 의 값은? (단, Cp는 정압비열, Cv는 정적비열이다.)

  1. 0
  2. 1
  3. 정압비역과 정적비열의 비(Cp/Cv)
  4. 무한대
(정답률: 65%)

    2023-04-15 04:02

    가역단열과정에서 열의 전달이 없으므로, 열용량은 일정하다. 따라서, PV^n = 일정에서 n은 다음과 같이 유도된다.

    P^(1-n)T^(n-1)CvT = 일정
    P^(1-n)T^nCv^(1-n) = 일정

    따라서, n = Cp/Cv 이다.

6. 환산 온도(Tr)와 환산 압력(Pr)을 이용하여 나타낸 다음과 같은 상태방정식이 있다. 어떤 물질의 기체상수가 0.189 kJ/kgK, 임계온도가 3⑤K 임계압력이 7380 kPa이다. 이 물질의 비체적을 위의 방정식을 이용하여 20℃, 1000kPa 상태에서 구하면?

  1. 0.0111 m3/kg
  2. 0.0303 m3/kg
  3. 0.0492 m3/kg
  4. 0.⑤54 m3/kg
(정답률: 41%)
  • 30 CBT 기출문제AI

    2023-04-15 04:02

    먼저, 상태방정식에서 Pr과 Tr은 다음과 같이 정의된다.

    Pr = P/Pc (P: 실제 압력, Pc: 임계압력)

    Tr = T/Tc (T: 실제 온도, Tc: 임계온도)

    따라서, 이 문제에서는 다음과 같은 값을 구해야 한다.

    Pr = P/Pc = 1000/7380 ≈ 0.1356

    Tr = T/Tc = (20+273.15)/3⑤ ≈ 0.9754

    그리고 상태방정식에서 비체적 vr은 다음과 같이 정의된다.

    vr = v/vc (v: 실제 비체적, vc: 임계비체적)

    따라서, 상태방정식을 이용하여 vr을 구하면 다음과 같다.

    Z = 1 + B1 / Tr + B2 / Tr² + B3 / Tr³ + B4 / Tr⁴ + B5 / Tr⁵

    B1 = -0.0689, B2 = 0.0842, B3 = -0.0375, B4 = 0.0065, B5 = 0.00⑤

    vr = ZRT/P = ZRTrPr/Pc

    여기서 R은 기체상수이고, 이 문제에서는 0.189 kJ/kgK로 주어졌다.

    따라서, vr을 계산하면 다음과 같다.

    Z = 1 -0.0689/0.9754 + 0.0842/0.9754² - 0.0375/0.9754³ + 0.0065/0.9754⁴ + 0.00⑤/0.9754⁵ ≈ 0.8625

    vr = ZRTrPr/Pc = 0.8625 × 0.189 × (20+273.15) × 1000/7380 ≈ 0.0492 m³/kg

    따라서, 이 물질의 비체적은 0.0492 m³/kg이다.

14. 정상과정으로 100kPa, 22℃의 공기를 1 MPa로 압축하는 압축기가 있다. 압축공기 질량 1 kg에 대해 냉각수는 16 kJ의 열을 제거하고 180 kJ의 일이 요구될 때, 압축기 출구 온도는 약 몇 ℃인가? (단, 공기의 비열은 1.04 kJ/kg∙K이다.)

  1. 210
  2. 195
  3. 180
  4. 170
(정답률: 27%)
  • 30 CBT 기출문제AI

    2023-04-15 04:02

    압축기에서 압축된 공기는 열을 발생시키므로, 출구 온도는 압축기 내부 온도보다 높아진다. 따라서, 출구 온도를 구하기 위해서는 압축기 내부 온도를 알아야 한다. 이를 위해, 압축기 내부에서 발생한 열과 냉각수가 제거한 열의 합이 압축된 공기의 일과 같아진다는 것을 이용한다.

    압축된 공기의 일은 다음과 같이 구할 수 있다.

    일 = (1 MPa - 100 kPa) × 0.001 m³/kg = 0.9 kJ/kg

    따라서, 압축기 내부에서 발생한 열은 0.9 kJ/kg 이다.

    냉각수가 제거한 열은 16 kJ/kg 이므로, 압축기 내부에서 발생한 열과 냉각수가 제거한 열의 합은 16.9 kJ/kg 이다.

    압축된 공기의 비열은 1.04 kJ/kg∙K 이므로, 출구 온도 변화량은 다음과 같이 구할 수 있다.

    16.9 kJ/kg = 1 kg × 1.04 kJ/kg∙K × (T₂ - 22℃)

    T₂ - 22℃ = 16.25

    T₂ ≈ 38.25℃

    따라서, 압축기 출구 온도는 약 38℃이다.

    정답이 "180" 인 이유는 문제에서 요구하는 것이 압축기에서 요구되는 일이므로, 압축된 공기의 일인 0.9 kJ/kg를 더해준 값인 180 kJ를 선택한 것이다.
