5. 87℃의 물 1kg과 27℃의 물 1kg이 열의 손실 없이 직접 혼합될 때 생기는 엔트로피의 차로서 가장 적절한 것은? (단, 물의 비열은 4.18kJ/kg·K로 한다)

  1. 0.035 kJ/K
  2. 1.36 kJ/K
  3. 4.22 kJ/K
  4. 5.02 kJ/K
(정답률: 38%)
  • 30 CBT 기출문제AI

    2023-04-15 03:49

    물의 엔트로피 변화는 다음과 같이 계산할 수 있다.

    ΔS = Q/T

    여기서 ΔS는 엔트로피 변화량, Q는 열량, T는 절대온도이다. 열의 손실이 없으므로, 열량은 보존된다.

    먼저 87℃의 물 1kg의 엔트로피 변화량을 계산해보자. 이 물의 초기 엔트로피는 87℃에 해당하는 엔트로피이다. 엔트로피는 온도가 높을수록 높아지므로, 87℃에 해당하는 엔트로피는 다음과 같이 구할 수 있다.

    S1 = S0 + Cp ln(T1/T0)

    여기서 S0는 0℃에서의 엔트로피, Cp는 물의 비열, T0는 0℃에 해당하는 절대온도(273.15K)이다. 따라서,

    S1 = 0 + 4.18 ln(360.15/273.15) = 22.76 J/K

    물의 질량이 1kg이므로, 이 물의 초기 엔트로피는 22.76 J/K이다.

    다음으로 27℃의 물 1kg의 엔트로피 변화량을 계산해보자. 이 물의 초기 엔트로피는 27℃에 해당하는 엔트로피이다. 따라서,

    S2 = 0 + 4.18 ln(300.15/273.15) = 9.45 J/K

    물의 질량이 1kg이므로, 이 물의 초기 엔트로피는 9.45 J/K이다.

    두 물이 혼합되면 최종 엔트로피는 다음과 같이 계산할 수 있다.

    ΔS = S최종 - (S1 + S2)

    여기서 S최종은 혼합된 물의 엔트로피이다. 엔트로피는 혼합 후에는 초기 엔트로피의 가중평균으로 계산할 수 있다.

    S최종 = (m1S1 + m2S2)/(m1 + m2)

    여기서 m1과 m2는 각각 초기 물의 질량이다. 따라서,

    S최종 = (1*22.76 + 1*9.45)/(1+1) = 16.11 J/K

    따라서, 두 물이 혼합될 때 생기는 엔트로피의 변화량은 다음과 같다.

    ΔS = 16.11 - (22.76 + 9.45) = -16.1 J/K

    음수인 이유는 엔트로피가 감소했기 때문이다. 이 값을 kJ/K로 변환하면,

    ΔS = -0.0161 kJ/K

    따라서, 가장 적절한 정답은 "0.035 kJ/K"이 아니라, "0.0161 kJ/K"이다.
