(정답률: 58%)

    이상기체의 압력과 온도는 다음과 같은 식으로 연관되어 있다.

    P1/T1 = P2/T2

    여기서 P1은 초기 압력, T1은 초기 온도, P2는 최종 압력, T2는 최종 온도이다.

    문제에서 초기 압력은 300kPa, 초기 온도는 0℃이고, 최종 온도는 100℃이다. 따라서 최종 압력을 구하기 위해 다음과 같이 계산할 수 있다.

    P2 = P1 × T2/T1
    = 300 × (100 + 273)/(0 + 273)
    = 408.7kPa

    증가한 압력 = 408.7 - 300
    = 108.7 ≈ 110(kPa)

    따라서 정답은 "110"이다.

4. 공기 1kg이 50kPa, 3m3인 상태로부터 900kPa, 0.5m3인 상태로 변화할 때 내부에너지 증가가 160kJ이었다. 이 경우 엔탈피 증가는 몇 kJ 인가?

  1. 30
  2. 185
  3. 235
  4. 460
(정답률: 48%)
  • 30 CBT 기출문제AI

    2023-04-15 04:02

    내부에너지 증가는 다음과 같이 표현할 수 있다.

    ΔU = Q - W

    여기서 Q는 열이고, W는 일이다. 이 문제에서는 상태 변화가 등압 변화이므로 W = PΔV = 0이 된다. 따라서,

    ΔU = Q

    이다. 엔탈피는 다음과 같이 정의된다.

    H = U + PV

    따라서,

    ΔH = ΔU + PΔV

    이다. 이 문제에서는 P1 = 50kPa, V1 = 3m3, P2 = 900kPa, V2 = 0.5m3, ΔU = 160kJ 이므로,

    ΔH = ΔU + P2ΔV = 160kJ + 900kPa × (0.5m3 - 3m3) = -460kJ

    따라서 정답은 460이다.

7. 엔탈피 125kJ/kg인 물을 보일러에서 가열하여 엔탈피 2940kJ/kg인 증기를 시간당 10톤을 만든다. 이 증기를 증기터빈에 송압한 후 증기터빈의 출구에서 엔탈피가 2570kJ/kg이 되었다. 이 경우 보일러에서의 가열량은? (단, 보일러에서는 정압가열이며 터빈에서는 단열팽창이다.)

  1. 3.715×105 kJ/h
  2. 3.225×106 kJ/h

14. 공기 1kg이 압력 101.3kPa, 체적 0.85m3인 상태에서 온도가 300℃인 상태로 변화하였다. 이 과정에서 상승한 온도는? (단, 공기의 기체상수는 0.287kJ/kgㆍk 이다.)

  1. 273K
  2. 300K
  3. 546K
  4. 573K
(정답률: 58%)
  • 30 CBT 기출문제AI

    2023-04-15 04:02

    가스 상태 방정식을 이용하여 문제를 풀 수 있다.

    PV = nRT

    여기서 P는 압력, V는 체적, n은 몰수, R은 기체상수, T는 온도를 나타낸다.

    먼저 초기 상태에서의 온도를 구해보자.

    n = m/M (m은 질량, M은 분자량)

    공기의 분자량은 대략 29g/mol 이므로, 1kg의 공기는 대략 34.5몰이 된다.

    따라서 초기 상태에서의 온도는 다음과 같이 구할 수 있다.

    PV = nRT

    T = PV/nR = (101.3kPa)(0.85m^3)/(34.5mol)(0.287kJ/kgㆍk) = 300K

    따라서 초기 상태에서의 온도는 300K이다.

    이제 최종 상태에서의 온도를 구해보자.

    PV = nRT

    T = PV/nR = (101.3kPa)(0.85m^3)/(34.5mol)(0.287kJ/kgㆍk) + (273K) = 573K

    따라서 최종 상태에서의 온도는 573K이다.

    따라서 상승한 온도는 573K - 300K = 273K이다.

    따라서 정답은 "273K"이다.

    이유는 초기 상태에서의 온도가 300K이므로, 최종 상태에서의 온도에서 초기 상태의 온도를 빼면 상승한 온도가 나오게 된다.
