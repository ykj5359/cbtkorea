4. 지름이 D인 원형축의 중심에 높이 h, 폭 6인 직사각형 단면인 구멍이 축의 도심에 뚫린 경우, 단면 도심축에 대한 단면 2차 모멘트를 구하는 식은?

(정답률: 39%)
  • 30 CBT 기출문제AI

    2023-04-17 13:14

    단면 도심축에 대한 단면 2차 모멘트는 다음과 같이 구할 수 있습니다.

    $I_{xx} = I_{xx,원형축} + I_{xx,직사각형축} + A_{직사각형}d^2$

    여기서 $I_{xx,원형축}$은 원형축에 대한 단면 2차 모멘트, $I_{xx,직사각형축}$은 직사각형축에 대한 단면 2차 모멘트, $A_{직사각형}$은 직사각형 단면의 면적, $d$는 직사각형 단면의 중심축과 원형축 사이의 거리입니다.

    이 문제에서는 직사각형 단면의 중심축이 원형축과 일치하므로 $d=0$이 됩니다. 따라서 식은 다음과 같이 간단해집니다.

    $I_{xx} = I_{xx,원형축} + I_{xx,직사각형축} + A_{직사각형} cdot 0^2 = I_{xx,원형축} + I_{xx,직사각형축} + 0$

    그리고 원형축과 직사각형축은 수직이므로 $I_{xx,원형축} = frac{pi D^4}{64}$, $I_{xx,직사각형축} = frac{bh^3}{12}$입니다. 따라서 최종적으로 단면 도심축에 대한 단면 2차 모멘트는 다음과 같습니다.

    $I_{xx} = frac{pi D^4}{64} + frac{bh^3}{12}$

    따라서 정답은 ""입니다.

89. 12V의 기전력이 인가된 회로에서 저항이 10Q인 경우 10초 동안의 전력량이 모두 열로 소비되었을 때의 열량(cal)은 약 얼마인가?

  1. 17.28
  2. 26.28
  3. 34.56
  4. 46.46
(정답률: 22%)
  • 30 CBT 기출문제AI

    2023-04-17 13:13

    전력(P) = 전압(V) x 전류(I)
    전류(I) = 전압(V) / 저항(R)

    따라서, 전력(P) = 전압(V)² / 저항(R)

    12V의 기전력이 인가되었으므로, 전압(V) = 12V
    저항(R) = 10Q

    전력(P) = 12² / 10 = 14.4W

    10초 동안의 전력량은 14.4W x 10s = 144J

    열량(cal) = 전력량(J) / 4.18

    따라서, 열량(cal) = 144 / 4.18 = 34.45 ≈ 34.56

    정답은 "34.56" 이다.
