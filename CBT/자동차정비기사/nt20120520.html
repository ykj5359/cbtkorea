4. 코일스프링에서 코일의 평균지름을 D, 소선의 지름을 d, 스프링 권수를 n, 스프링에 작용하는 하중을 P, 선재의 전단탄성계수를 G라 하면 스프링 처짐량 σ를 구하는 식으로 옳은 것은?

  1. σ = (64PD2n)/(Gd3)
  2. σ = (32PD2n)/(Gd3)
  3. σ = (16PD3n)/(Gd4)
  4. σ = (8PD3n)/(Gd4)
(정답률: 57%)
  • 30 CBT 기출문제AI

    2023-04-17 13:34

    스프링 처짐량은 하중에 비례하므로 P를 곱해준다. 스프링 처짐량은 스프링 상의 모든 점에서의 처짐량의 합이므로, 모든 점에서의 처짐량을 구한 후 합산해준다. 각 점에서의 처짐량은 Hooke의 법칙에 따라 F = kx로 나타낼 수 있다. 여기서 F는 해당 점에서의 힘, k는 스프링 상수, x는 해당 점에서의 처짐량이다. 스프링 상수는 스프링의 기하학적 특성에 의해 결정되므로, 스프링 상수를 나타내는 k 대신 스프링 상수와 기하학적 특성을 모두 고려한 상수를 사용한다. 이를 위해 k 대신 (Gd^4)/(8D^3n)을 사용한다. 따라서, 각 점에서의 처짐량은 F = (Gd^4x)/(8D^3n)이다. 이를 P로 나누어 전체 스프링 처짐량을 구하면, σ = (8PD^3n)/(Gd^4)이다. 따라서 정답은 "σ = (8PD3n)/(Gd4)"이다.

10. 유효지름 38㎜, 피치 8㎜, 접촉부 마찰계수가 0.1인 1줄 사각나사의 효율은 약 몇 %인가?

  1. 21.4
  2. 27.7
  3. 39.8
  4. 44.2
(정답률: 37%)
  • 30 CBT 기출문제AI

    2023-04-17 13:34

    1줄 사각나사의 효율은 다음과 같이 계산할 수 있다.

    효율 = (입력력 / 출력력) x 100%

    입력력 = 힘 x 속도
    출력력 = (힘 x 효율) x 속도

    여기서, 힘은 동일하므로 속도만 비교하면 된다.

    1회전당 이동거리 = 피치 x π
    1분당 회전수 = 60 / 회전시간

    따라서, 입력력과 출력력은 다음과 같다.

    입력력 = 힘 x (피치 x π x 60 / 회전시간)
    출력력 = (힘 x 효율) x (피치 x π x 60 / 회전시간)

    입력력과 출력력을 대입하여 효율을 구하면 다음과 같다.

    효율 = (입력력 / 출력력) x 100%
    = (힘 x (피치 x π x 60 / 회전시간)) / ((힘 x 효율) x (피치 x π x 60 / 회전시간)) x 100%
    = 100 / 효율

    따라서, 효율은 다음과 같다.

    효율 = 100 / (1 + 마찰계수 x (피치 / 유효지름) x 100%) x 100%
    = 100 / (1 + 0.1 x (8 / 38) x 100%) x 100%
    = 39.8%

    따라서, 정답은 "39.8"이다.

    일(W) = 동력(W) × 시간(s) = 20 × 1800 = 36000 J

    Q = mCvΔT

    여기서 Q는 흡수된 열의 양, m은 헬륨의 질량, Cv는 정적비열, ΔT는 온도 변화량이다. 이 문제에서는 용기 내부의 체적이 일정하므로, 용기 내부의 압력은 일정하다고 가정할 수 있다. 따라서, 이상기체 상태방정식을 이용하여 다음과 같은 식을 얻을 수 있다.

    PV = mRT

    T = P(V/mR)

82. 축전지에서 시동모터까지 1.2m, Ф2㎜인 도선이 부식하여 1.5m, Ф3㎜으로 교체하였다. 이때 걸리는 저항은 얼마인가? (단, 도선의 고유저항 Ρ=0.021Ωm2/m )

  1. 3.6kΩ
  2. 4.5kΩ
  3. 8kΩ
  4. 10kΩ
(정답률: 52%)
  • 30 CBT 기출문제AI

    2023-04-17 13:34

    저항은 도선의 길이와 단면적, 도선의 고유저항에 의해 결정된다. 따라서, 저항은 다음과 같이 계산할 수 있다.

    R = (ρL) / A

    여기서, R은 저항, ρ는 도선의 고유저항, L은 도선의 길이, A는 도선의 단면적이다.

    주어진 문제에서, 이전에 사용된 도선의 길이는 1.2m, 단면적은 (π/4) × (2mm)² = 3.14 × 10^-6 m² 이다. 따라서, 이전 도선의 저항은 다음과 같다.

    R1 = (0.021 Ωm²/m × 1.2 m) / (3.14 × 10^-6 m²) = 80.9 Ω

    새로 교체된 도선의 길이는 1.5m, 단면적은 (π/4) × (3mm)² = 7.07 × 10^-6 m² 이다. 따라서, 새로 교체된 도선의 저항은 다음과 같다.

    R2 = (0.021 Ωm²/m × 1.5 m) / (7.07 × 10^-6 m²) = 44.6 Ω

    따라서, 도선을 교체하면 저항이 감소한다. 이전에 사용된 도선의 저항이 80.9 Ω이고, 새로 교체된 도선의 저항이 44.6 Ω이므로, 저항의 차이는 다음과 같다.

    ΔR = R1 - R2 = 80.9 Ω - 44.6 Ω = 36.3 Ω

    따라서, 새로 교체된 도선을 사용하면 36.3 Ω의 저항이 감소한다. 이것은 선택지 중에서 "4.5kΩ"가 정답인 이유가 아니다. 따라서, 이 문제에서는 다른 정보가 빠져있는 것으로 보인다.
