1. 그림과 같이 2개의 연강봉에 같은 인장하중을 받을 때, 각 봉의 탄성변형에너지비 V1 : V2는? (단, 그림에서 길이 단위는 ㎜이고, 왼쪽봉의 탄성변형에너지가 V1, 오른쪽 봉의 탄성변형에너지가 V2이다.)

  2. 5 : 8
  3. 8 : 3
  4. 8 : 5
(정답률: 40%)
  • 30 CBT 기출문제AI

    2023-04-17 13:21

    두 연강봉이 같은 인장하중을 받을 때, 변형된 길이는 봉의 길이에 비례한다는 훅의 법칙에 따라 변형된 길이를 구하면 다음과 같다.

    왼쪽 봉의 변형된 길이 = (인장하중 × 봉의 길이) ÷ (단면적 × 탄성계수) = (100 × 200) ÷ (π × 10² × 2 × 10¹¹) ≈ 0.318㎜

    오른쪽 봉의 변형된 길이 = (인장하중 × 봉의 길이) ÷ (단면적 × 탄성계수) = (100 × 300) ÷ (π × 10² × 2 × 10¹¹) ≈ 0.477㎜

    따라서, 각 봉의 탄성변형에너지는 다음과 같이 구할 수 있다.

    왼쪽 봉의 탄성변형에너지 = (1/2) × (인장하중 × 변형된 길이) ≈ 5.03 × 10⁻⁴ J

    오른쪽 봉의 탄성변형에너지 = (1/2) × (인장하중 × 변형된 길이) ≈ 8.57 × 10⁻⁴ J

    따라서, V1 : V2 = 5.03 × 10⁻⁴ : 8.57 × 10⁻⁴ ≈ 5 : 8 이다.

4. 유효지름 38㎜, 피치 8㎜, 접촉부 마찰계수가 0.1인 1줄 사각나사의 효율은 약 몇 %인가?

  1. 21.4
  2. 27.7
  3. 39.8
  4. 44.2
(정답률: 37%)
  • 30 CBT 기출문제AI

    2023-04-17 13:21

    1줄 사각나사의 효율은 다음과 같이 계산할 수 있다.

    효율 = (입력력 / 출력력) x 100%

    입력력 = 힘 x 속도
    출력력 = (힘 x 효율) x 속도

    여기서 힘은 회전력으로 변환할 수 있으므로 다음과 같이 표현할 수 있다.

    입력력 = 회전력 x 회전속도
    출력력 = (회전력 x 회전속도 x 효율)

    따라서 효율은 다음과 같이 계산할 수 있다.

    효율 = (회전력 x 회전속도) / (회전력 x 회전속도 x 효율) x 100%
    = 1 / 효율 x 100%

    1줄 사각나사의 회전력은 다음과 같이 계산할 수 있다.

    회전력 = (힘 x 효과적인 반지름) / 2
    = (힘 x 피치 / (2 x tan(30°))) / 2
    = (힘 x 피치 / 2.31) / 2

    여기서 힘은 접촉부 마찰력으로 계산할 수 있다.

    힘 = 접촉부 마찰력 x π x 효율지름
    = 접촉부 마찰력 x π x (효율지름 + 2 x 피치 x cos(45°) / π)

    따라서 효율은 다음과 같이 계산할 수 있다.

    효율 = 1 / (1 + 마찰계수 x 피치 / (2 x 2.31 x (효율지름 + 2 x 피치 x cos(45°) / π)))
    = 1 / (1 + 0.1 x 8 / (2 x 2.31 x (38 + 2 x 8 x cos(45°) / π)))
    = 39.8%

    따라서 정답은 "39.8"이다.

  1. Tmax = 32T/(πd3)

(정답률: 41%)

    중심축에 가해지는 토크 T는 전단응력과 관련이 있다. 전단응력 τ는 T를 축 지름 d와 교차면적 A로 나눈 값으로 계산된다. 여기서 교차면적 A는 축의 단면적 πd^2/4이다. 따라서 τ = T/(πd^2/4) = 4T/(πd^2)이다. 최대 전단응력은 원통형 구조물에서 중심축에 수직인 평면에서 발생하므로, 최대 전단응력 Tmax는 τ의 최댓값인 τmax = 2τ = 8T/(πd^2)이다. 이때 τmax는 최대 전단응력이므로, 이 값을 최대로 만드는 T값을 찾아야 한다. τmax를 T로 표현하면 T = τmax(πd^2/8) = 2τmax(πd^2/4)이다. 이를 Tmax에 대입하면 Tmax = τmax(πd/2) = 16T/(πd^3)이 된다. 따라서 정답은 "Tmax = 16T/(πd^3)"이다.
