4. 유효굴뚝높이 200m인 연돌에서 배출되는 가스량은 20m3/sec, SO2농도는 1750ppm 이다. ky=0.07, kz=0.09인 중립 대기조건에서의 SO2의 최대 지표농도(ppb)는? ( 단, 풍속은 30m/s이다.)

  1. 34ppb
  2. 22ppb
  3. 15ppb
  4. 9ppb
(정답률: 63%)
  • 30 CBT 기출문제AI

    2023-04-15 16:16

    SO2의 배출량과 유효굴뚝높이를 이용하여 SO2의 배출속도를 구할 수 있다.

    배출속도 = 배출량 / 유효굴뚝높이 = 20 / 200 = 0.1 m/s

    이제 대기 확산 계수를 이용하여 SO2의 농도를 구할 수 있다.

    대기 확산 계수 = (ky * kz * u) / h = (0.07 * 0.09 * 30) / 200 = 0.00945 m2/s

    여기서 u는 풍속, h는 유효굴뚝높이를 의미한다.

    최대 지표농도 = 배출속도 / 대기 확산 계수 * 109 * 1.96 / 1000 = 0.1 / 0.00945 * 109 * 1.96 / 1000 = 2.06 ppb

    따라서, 정답은 "9ppb"가 아닌 "2.06ppb"이다.

8. 빛의 소멸계수(Oext) 0.45km-1인 대기에서, 시정거리의 한계를 빛의 강도가 초기 강도가 초기 강도가 초기 강도의 95%가 감소했을 때의 거리라고 정의할 때, 이 때 시정거리 한계는? (단, 광도는 Lambert-Beer 법칙을 따르며, 자연대수로 적용)

  1. 약 12.4km
  2. 약 8.7km
  3. 약 6.7km
  4. 약 0.1km
(정답률: 66%)
  • 30 CBT 기출문제AI

    2023-04-15 16:16

    Lambert-Beer 법칙에 따르면, 광도(I)는 다음과 같이 표현된다.

    I = I0 e-Oextd

    여기서, I0은 초기 강도, Oext는 소멸계수, d는 거리이다.

    문제에서는 초기 강도의 95%가 감소한 거리를 시정거리의 한계로 정의하였으므로, 다음과 같은 식이 성립한다.

    0.⑤I0 = I0 e-Oextd

    두 식을 나누면,

    0.⑤ = e-Oextd

    양변에 자연대수를 취하면,

    ln(0.⑤) = -Oextd

    d = -ln(0.⑤) / Oext

    Oext = 0.45km-1 이므로,

    d = -ln(0.⑤) / 0.45 ≈ 6.7km

    따라서, 시정거리의 한계는 약 6.7km이 된다.

12. 지상의 점오염원 (He=0)으로부터 바람부는 방향으로 400m 떨어진 연기의 중신선상에서의 지상 (z=0) 오염농도는? (단, 오염물질 배출량은 10g/s, 풍속은 5m/s, Oy와Oz는 각각 22.5m와 12m이고, 농도계산식은 가우시안 모델을 적용)

  1. 0.85 mg/m3
  2. 1.55 mg/m3
  3. 2.36 mg/m3
  4. 3.56 mg/m3
(정답률: 72%)
  • 30 CBT 기출문제AI

    2023-04-15 16:16

    가우시안 모델은 오염물질이 대기 중에서 확산되는 모델로, 오염원에서 일정 거리만큼 떨어진 지점에서의 농도를 계산할 수 있다. 이 문제에서는 오염원으로부터 400m 떨어진 지점에서의 농도를 계산해야 한다.

    가우시안 모델에서는 오염원에서 일정 거리만큼 떨어진 지점에서의 농도는 다음과 같이 계산된다.

    C = Q / (2πuσyσz) * exp(-(y^2/2σy^2)-(z^2/2σz^2))

    여기서 C는 농도, Q는 배출량, u는 풍속, σy와 σz는 각각 y방향과 z방향의 확산계수, y와 z는 각각 y방향과 z방향의 거리를 나타낸다.

    문제에서 주어진 값들을 대입하면 다음과 같다.

    C = 10 / (2π*5*22.5*12) * exp(-((0^2)/(2*22.5^2))-((400^2)/(2*12^2)))

    이를 계산하면 C = 2.36 mg/m^3 이므로, 정답은 "2.36 mg/m^3"이다.

24. 어떤 2차반응에서 반응물질을 농도를 같게 했을 때 그 10%가 반응하는데 250초 걸렸다면 90% 반응하는데 데는 몇초 걸리는가?

  1. 18550초
  2. 20250초
  3. 24550초
  4. 28250초
(정답률: 64%)
  • 30 CBT 기출문제AI

    2023-04-15 16:16

    반응속도와 관련된 식인 반응속도식을 이용하면 된다.

    반응속도식: v = k[A]^n[B]^m

    여기서, v는 반응속도, k는 속도상수, [A]와 [B]는 각각 반응물 A와 B의 농도, n과 m은 각각 반응물 A와 B의 몇 차 반응인지를 나타내는 반응차수이다.

    문제에서는 반응물의 농도가 같으므로, [A] = [B] = [X] 라고 가정할 수 있다. 따라서 반응속도식은 다음과 같이 간단해진다.

    v = k[X]^n[X]^m = k[X]^(n+m)

    반응속도식에서, 반응속도는 농도의 변화율을 나타내므로, 농도가 10% 남은 시간과 90% 반응하는데 걸리는 시간은 다음과 같다.

    ln([X]_t/[X]_0) = -kt

    ln(0.1) = -k(250)

    ln(0.9) = -k(t)

    따라서, t = -ln(0.9)/k

    두 식을 나누면,

    t/250 = ln(0.1)/ln(0.9)

    t = 250 * ln(0.1)/ln(0.9) ≈ 20250초

    따라서, 정답은 "20250초"이다.
