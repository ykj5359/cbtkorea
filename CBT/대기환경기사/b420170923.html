6. 직경4m인 굴뚝에서 연기가 10m/s의 속도로 풍속 5m/s인 대기로 방출된다. 대기는 27℃, 중립상태(⊿θ/⊿z=0)이고, 연기의 온도가 167℃일 때 TVA모델에 의한 연기의 상승고(m)는?

  1. 약 196m
  2. 약 165m
  3. 약 145m
  4. 약 124m
(정답률: 58%)
  • 30 CBT 기출문제AI

    2023-04-15 15:53

    TVA 모델에 따르면, 연기의 상승고는 다음과 같이 계산된다.

    H = (Q/A) x (1/2πV) x (ΔT/Δθ)^(1/3)

    여기서,
    Q/A는 단위면적당 연기유량
    V는 풍속
    ΔT/Δθ는 연기와 대기의 온도차

    따라서, 계산을 위해 다음과 같은 값을 구해야 한다.

    - 연기유량(Q/A)
    - ΔT/Δθ
    - 풍속(V)

    연기유량(Q/A)은 굴뚝의 직경과 연기의 속도를 이용하여 다음과 같이 구할 수 있다.

    Q/A = (π/4) x D^2 x V

    여기서, D는 굴뚝의 직경이다. 따라서,

    Q/A = (π/4) x 4^2 x 10 = 125π

    ΔT/Δθ는 연기와 대기의 온도차이다. 연기의 온도는 167℃이고 대기의 온도는 27℃이므로,

    ΔT/Δθ = (167-27)/1000 = 0.14

    풍속(V)는 5m/s이다.

    따라서, 상승고를 계산하면 다음과 같다.

    H = (125π/2πx5) x 0.14^(1/3) = 196.2m

    따라서, 정답은 "약 196m"이다.

    유속 = (2gh)^0.5

    여기서 h는 피토관의 높이, g는 중력가속도, 유속은 m/s 단위로 나타낸다.

    유속 = (2 x 9.8 x 0.5)^0.5 = 3.13m/s

    P1 + 1/2ρv1^2 + ρgh1 = P2 + 1/2ρv2^2 + ρgh2

    1/2ρv1^2 + ρgh1 = 1/2ρv2^2 + ρgh2

    여기서 h1과 h2는 각각 피토관의 입구와 출구에서의 높이를 나타낸다. 문제에서는 두 높이가 같다고 가정할 수 있다. 따라서 이 식은 다음과 같이 간소화된다.

    1/2ρv1^2 = 1/2ρv2^2

    v1^2 = v2^2

    v2 = v1

    즉, 피토관에서 측정한 유속과 배출가스 유속은 같다는 것을 알 수 있다. 따라서 유속은 50.7m/s이다.
