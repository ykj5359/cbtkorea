3. 최대혼합고도를 300m로 예상하여 오염물질 농도를 5ppm으로 예측하였다. 그러나, 실제 관측된 최대혼합고도는 500m이었다. 이 때 실제 나타날 오염농도는?

  1. 1.08ppm
  2. 1.80ppm
  3. 2.31ppm
  4. 8.23ppm
(정답률: 57%)
  • 30 CBT 기출문제AI

    2023-04-15 16:23

    최대혼합고도가 500m이므로, 오염물질이 희석되어 농도가 예측보다 낮아질 것이다. 이를 계산하기 위해 먼저 농도와 혼합비를 이용하여 혼합물의 농도를 구한다.

    농도 = (오염물질의 양 / 혼합물의 양) * 1,000,000

    혼합비 = (오염물질의 양 / 첨가물의 양)

    혼합물의 양 = 오염물질의 양 + 첨가물의 양

    따라서, 혼합물의 농도는 다음과 같다.

    농도 = (오염물질의 양 / (오염물질의 양 + 첨가물의 양)) * 1,000,000

    혼합비 = (오염물질의 양 / 첨가물의 양)

    혼합물의 양 = 오염물질의 양 + 첨가물의 양

    따라서, 혼합물의 농도는 다음과 같다.

    농도 = (5 / (5 + 첨가물의 양)) * 1,000,000

    혼합비 = (5 / 첨가물의 양)

    최대혼합고도가 500m이므로, 혼합비는 다음과 같다.

    500 / 300 = (5 / 첨가물의 양)

    첨가물의 양 = 3

    따라서, 혼합물의 농도는 다음과 같다.

    농도 = (5 / (5 + 3)) * 1,000,000 = 625,000ppm = 625ppm

    이는 보기 중에서 "1.08ppm"이다.

    NH3의 분자량은 17g/mol 이므로 4kg은 235.3 몰이다.
