1. 유효굴뚝높이 100m 인 연돌에서 배출되는 가스량은 10m3/sec, SO2의 농도가 1500ppm 일 때 Sutton식에 의한 최대지표농도는? (단, Ky = Kz = 0.⑤, 평균풍속은 10m/sec 이다.)

  1. 약 0.008 ppm
  2. 약 0.035 ppm
  3. 약 0.078 ppm
  4. 약 0.116 ppm
(정답률: 74%)
  • 30 CBT 기출문제AI

    2023-04-15 16:13

    Sutton식은 다음과 같다.

    Cx = (Q / (2πKyuH)) * exp(-Kzz / H)

    여기서, Cx는 최대지표농도, Q는 배출량, Ky와 Kz는 각각 수직방향과 수평방향의 확산계수, u는 평균풍속, H는 유효굴뚝높이, z는 측정지점과 유효굴뚝높이 사이의 거리를 나타낸다.

    따라서, 주어진 값들을 대입하면 다음과 같다.

    Cx = (10 / (2π * 0.⑤ * 10 * 100)) * exp(-0.⑤ * 0 / 100)

    Cx = 0.000318 * 1

    Cx = 0.000318 ppm

    하지만, 이 값은 SO2의 농도가 0 ppm 일 때의 최대지표농도이다. 따라서, SO2의 농도가 1500ppm 일 때의 최대지표농도는 다음과 같이 계산된다.

    최대지표농도 = Cx * (SO2의 농도 / 106)

    최대지표농도 = 0.000318 * (1500 / 106)

    최대지표농도 = 0.000477 ppm

    따라서, 정답은 "약 0.035 ppm"이다.

4. 유효고 50m인 굴뚝에서 NO가 200g/s의 속도로 배출되고있다. 굴뚝 유효고에서의 풍속은 10m/sec 일 때, 500m 풍하방향 중심선상 지표면에서의 NO농도는? (단, σy=30m,, σz=15m)

  1. 약 3㎍/m3
  2. 약 5㎍/m3
  3. 약 27㎍/m3
  4. 약 55㎍/m3
(정답률: 57%)
  • 30 CBT 기출문제AI

    2023-04-15 16:18

    먼저, 배출된 NO의 농도는 다음과 같이 계산할 수 있다.

    C = Q / (u * A)

    여기서, C는 농도 (g/m^3), Q는 배출량 (g/s), u는 풍속 (m/s), A는 굴뚝 단면적 (m^2)이다.

    따라서, 굴뚝에서의 NO 농도는 다음과 같다.

    C1 = 200 / (10 * π * (0.5)^2) ≈ 127.32 (g/m^3)

    다음으로, NO의 대기 중 이동과 확산을 고려하여 지표면에서의 농도를 계산할 수 있다. 이를 위해 Gaussian 모델을 사용한다.

    C2 = C1 * exp(-y^2 / (2 * σy^2)) * exp(-z^2 / (2 * σz^2))

    여기서, C2는 지표면에서의 농도 (g/m^3), y는 수평 거리 (m), z는 수직 거리 (m), σy와 σz는 Gaussian 모델의 파라미터이다.

    따라서, 500m 풍하방향 중심선상 지표면에서의 NO 농도는 다음과 같다.

    C2 = 127.32 * exp(-500^2 / (2 * 30^2)) * exp(0) ≈ 55 (g/m^3)

    따라서, 정답은 "약 55㎍/m^3"이다.

  2. 332초
  3. 498초
  4. 615초

    2023-04-15 16:18

    반응속도는 일반적으로 1차 반응으로 가정됩니다. 1차 반응에서는 반응물의 농도에 비례하여 반응속도가 결정됩니다. 따라서, 100초 동안 반응물의 1/2 이 분해되었다는 것은, 100초 동안 반응물의 농도가 1/2 로 줄어들었다는 것을 의미합니다. 이를 수식으로 나타내면 다음과 같습니다.

    ln([A]t/[A]0) = -kt

    k = ln2/t1/2 = ln2/100

    ln([A]/[A]0) = -kt

    ln(1/10) = -k*t

    t = ln(1/10)/k = ln(10)/k

    과잉산소량은 실제 공기량에서 이론 공기량을 뺀 값입니다. 이론 공기량은 부피, 온도, 압력 등의 조건이 모두 표준 상태일 때의 공기량을 말합니다. 따라서 이론 공기량은 다음과 같이 계산됩니다.

    Ao = V × (Pstd / (R × Tstd))

    A = m × Ao

    O2 = A - V

    O2 = m × Ao - V
