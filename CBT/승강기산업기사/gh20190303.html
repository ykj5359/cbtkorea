1. 정격하중 1000kg, 정격속도 60m/min, 오버밸런스율 40%, 총합효율 60%일 때 권상전동기의 용량은 약 몇 kW인가?

  2. 6.5
  3. 8.2
  4. 9.8
(정답률: 74%)
  • 30 CBT 기출문제AI

    2023-04-16 18:49

    권상전동기의 용량은 다음과 같이 계산할 수 있다.

    - 정격하중: 1000kg
    - 오버밸런스율: 40%
    - 오버밸런스율은 정격하중의 일부를 추가로 지탱할 수 있는 비율을 의미한다. 따라서 실제로 권상전동기가 지탱해야 할 하중은 1000kg * (1 + 40%) = 1400kg 이다.
    - 총합효율: 60%
    - 총합효율은 권상전동기가 소비하는 전력과 실제로 지탱하는 하중의 비율을 의미한다. 따라서 권상전동기가 소비해야 할 전력은 1400kg * 60m/min / 60 / 1000 * 1 / 0.6 = 14kW 이다.
    - 따라서 권상전동기의 용량은 약 9.8kW 이다.

    따라서 정답은 "9.8" 이다.

77. 다음 분류기의 배율은? (단, Rs : 분류기의 저항, Rn:전류계의 내부저항)

  1. Rs/Rn
  2. 1+Rs/Rn
  3. 1+Rn/Rs
  4. Rn/Rs
(정답률: 41%)
  • 30 CBT 기출문제AI

    2023-04-16 18:48

    전류계는 분류기와 병렬로 연결되어 있으므로, 전류계의 전압과 분류기의 전압은 같다. 이를 이용하여 전류계의 전압을 구하면 다음과 같다.

    전류계의 전압 = 전압분배법칙에 의해 (전압전체) × (Rn / (Rs + Rn))

    전류계의 전압 = 분류기의 전압 = (전압전체) × (Rs / (Rs + Rn))

    따라서, (전압전체) × (Rn / (Rs + Rn)) = (전압전체) × (Rs / (Rs + Rn))

    이를 정리하면, Rn / Rs = (전압전체 - 분류기의 전압) / 분류기의 전압

    전압전체는 일정하므로, 분류기의 전압이 작아질수록 Rn / Rs 값은 커진다. 따라서, 분류기의 저항이 작아질수록 Rn / Rs 값은 작아진다. 이를 역수로 취하면, 분류기의 저항이 작아질수록 1 + Rn / Rs 값은 커진다. 따라서, 정답은 "1+Rn/Rs" 이다.
