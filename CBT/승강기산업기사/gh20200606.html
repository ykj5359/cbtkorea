16. 엘리베이터 과속조절기(조속기) 로프의 최소 파단 하중은 권상 형식 과속조절기의 마찰계수 µmax0.2를 고려하여 과속조절기가 작동될 때 로프에 발생하는 인장력에 몇 이상의 안전율을 가져야 하는가?

  1. 2
  2. 4
  3. 6
  4. 8
(정답률: 70%)
  • 30 CBT 기출문제AI

    2023-04-16 18:35

    엘리베이터 과속조절기의 작동 시 로프에 발생하는 인장력은 다음과 같이 계산된다.

    T = (m1 + m2)g + Ff

    여기서, T는 로프에 발생하는 인장력, m1은 엘리베이터의 질량, m2는 탑승객 등 추가적인 하중의 질량, g는 중력가속도, Ff는 과속조절기의 마찰력이다.

    로프의 최소 파단 하중은 다음과 같이 계산된다.

    Wmin = T / SF

    여기서, Wmin은 로프의 최소 파단 하중, SF는 안전율이다.

    따라서, 안전율 SF는 다음과 같이 계산된다.

    SF = T / Wmin

    과속조절기의 마찰계수 µmax는 0.2이므로, Ff는 다음과 같이 계산된다.

    Ff = µmax(m1 + m2)g

    따라서, T는 다음과 같이 계산된다.

    T = (m1 + m2)g + µmax(m1 + m2)g = (1 + µmax)(m1 + m2)g

    안전율 SF가 8 이상이 되려면, 다음의 조건을 만족해야 한다.

    Wmin ≤ T / 8

    Wmin = T / SF = T / 8

    따라서, T / 8 ≤ T / Wmin = SF = (1 + µmax)(m1 + m2)g / 8

69. 어떤 회로에 220V의 교류 전압을 인가했더니 4.4A의 전류가 흐르고, 전압과 전류와의 위상차는 60°가 되었다. 이 회로의 저항성분(Ω)은?

    2023-04-16 18:45

    이 문제는 전기회로의 기본 법칙인 오옴의 법칙과 코사인 법칙을 이용하여 풀 수 있습니다.

    오옴의 법칙에 의하면 전압(V)은 전류(I)와 저항(R)의 곱으로 나타낼 수 있습니다.

    V = IR

    코사인 법칙에 의하면 전압과 전류와의 위상차(cosθ)는 저항(R)과 인덕턴스(L) 또는 캐패시턴스(C)의 곱으로 나눈 값과 같습니다.

    cosθ = R / √(R² + (XL - XC)²)

    여기서 XL은 인덕턴스의 반응성, XC는 캐패시턴스의 반응성입니다.

    이 문제에서는 캐패시턴스나 인덕턴스가 주어지지 않았으므로, 위상각 60°는 전압과 전류 사이에 저항성분만 있는 경우의 값입니다.

    cos60° = R / R
