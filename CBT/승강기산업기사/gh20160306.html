78. R, L, C 직렬회로에서 인가전압을 입력으로, 흐르는 전류를 출력으로 할 때 전담함수를 구하면?

  2. 1/R+LS+CS
  3. E+LS+1/CS
  4. 1/R+LS+1/CS
(정답률: 49%)
  • 30 CBT 기출문제AI

    2023-04-16 18:54

    R, L, C 직렬회로에서 전담함수는 다음과 같이 구할 수 있습니다.

    전담함수 = 전압 출력 / 전압 입력

    전압 출력은 R, L, C에 걸리는 전압의 합이므로 다음과 같이 표현할 수 있습니다.

    전압 출력 = IR + L(dI/dt) + 1/C ∫Idt

    여기서 I는 전류, R은 저항, L은 인덕턴스, C는 캐패시턴스입니다. 이를 전압 입력으로 나누면 다음과 같습니다.

    전담함수 = (IR + L(dI/dt) + 1/C ∫Idt) / E

    전담함수 = 1/R + Ls + 1/Cs

    여기서 s는 라플라스 변환에서의 변수입니다. 따라서 정답은 "1/R+LS+1/CS"입니다.
