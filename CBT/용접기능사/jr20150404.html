28. 35℃에서 150kgf/㎠으로 압축하여 내부용적 40.7리터의 산소 용기에 충전하였을 때, 용기속의 산소량은 몇 리터인가?

  1. 4470
  2. 5291
  3. 61⑤
  4. 7000
(정답률: 75%)
  • 30 CBT 기출문제AI

    2023-04-12 16:31

    이 문제는 이상기체 상태방정식을 이용하여 풀 수 있습니다.

    PV = nRT

    여기서 P는 압력, V는 부피, n은 몰수, R은 기체상수, T는 온도를 나타냅니다.

    먼저, 이 문제에서는 압력과 부피가 주어졌으므로, 이를 이용하여 몰수를 구할 수 있습니다.

    PV = nRT

    n = PV/RT

    여기서 R은 기체상수이므로, T가 변하지 않는다면 n은 PV에 비례합니다.

    따라서, 용기속의 산소량은 다음과 같이 구할 수 있습니다.

    n = PV/RT = (150kgf/㎠) x (40.7L) / (0.0821 L atm/mol K x 308K) = 61⑤ mol

    여기서 308K는 35℃를 절대온도로 변환한 값입니다.

    마지막으로, 몰수와 분자량을 이용하여 용기속의 산소량을 리터로 변환할 수 있습니다.

    V = n x M / ρ

    여기서 M은 분자량, ρ는 밀도를 나타냅니다.

    산소의 분자량은 32g/mol이고, 밀도는 1.43g/L입니다.

    따라서, 용기속의 산소량은 다음과 같이 구할 수 있습니다.

    V = n x M / ρ = (61⑤ mol) x (32g/mol) / (1.43g/L) = 136,125 L = 61⑤ 리터

    따라서, 정답은 "61⑤"입니다.
