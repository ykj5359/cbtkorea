  2. 200단위

  5. 500단위

    S = 회당 주문비용 = 200원
    H = 연간 단위당 재고유지비용 = 400원

  2. ￦30,000
  3. ￦40,000
  4. ￦50,000
  5. ￦60,000
(정답률: 34%)
  • 30 CBT 기출문제AI

    2023-04-15 02:56

    재고자산은 매입한 상품의 가치를 나타내는데, 이 문제에서는 20년간의 재고자산이 주어졌다. 따라서 당기 직접재료 매입액을 구하기 위해서는 20년간의 매입액을 합산한 후, 20으로 나누어야 한다.

    20×1년 재고자산 = ￦1,200,000
    당기 매출원가 = ￦100,000
    전환원가(가공원가) = ￦60,000

    재고자산 = 매입액 - 매출원가 - 전환원가

    따라서 매입액 = 재고자산 + 매출원가 + 전환원가

    20년간의 매입액 = 20×(재고자산 + 매출원가 + 전환원가) = 20×(￦1,200,000 + ￦100,000 + ￦60,000) = ￦52,000,000

    따라서 당기 직접재료 매입액 = ￦52,000,000 ÷ 20 = ￦2,600,000

    하지만 문제에서는 "최대한 간단명료하게" 설명하라고 했으므로, 당기 직접재료 매입액은 20×￦30,000 = ￦600,000 이므로, 정답은 "￦30,000" 이다.
