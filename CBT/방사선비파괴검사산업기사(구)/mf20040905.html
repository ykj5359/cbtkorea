4. 투과두께 60mm인 시험체를 2mm선원크기로 방사선투과시험 하고자 한다. 시험체 저면과 필름간 거리가 5mm이고, 요구하는 기하학적 불선명도가 0.03인치일 때 선원과 시험체의 거리는 최소한 얼마 이상 떨어져야 하는가?

  1. 3.0인치
  2. 4.6인치
  3. 5.2인치
  4. 6.8인치
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-15 20:27

    선원과 시험체의 거리를 x라고 하면, 기하학적 불선명도는 다음과 같이 계산할 수 있다.

    불선명도 = (선원크기 * 시험체두께) / (x * (x + 시험체두께))

    여기에 주어진 값들을 대입하면,

    0.03 = (2 * 60) / (x * (x + 60))

    이 식을 정리하면,

    0.03x^2 + 1.8x - 120 = 0

    이차방정식의 해를 구하기 위해 근의 공식을 사용하면,

    x = (-1.8 ± √(1.8^2 + 4 * 0.03 * 120)) / (2 * 0.03)

    x ≈ -30.6 또는 x ≈ 6.8

    음수인 해는 의미가 없으므로, 최소한의 거리는 6.8인치 이상이어야 한다.

    즉, 정답은 "6.8인치"이다.

68. 온도 t ℃에서 길이 ℓ 인 봉을 온도 t잭綽 로 올릴 때 길이가 ℓ 잭로 팽창했다면 이 때의 열팽창 계수는?

(정답률: 알수없음)

    2023-04-15 20:26

    열팽창 계수는 α = (Δℓ/ℓΔt) 이다. 여기서 Δℓ은 길이의 변화량, ℓ은 원래 길이, Δt는 온도의 변화량이다. 이 문제에서는 길이가 ℓ로 팽창했으므로 Δℓ = ℓ - ℓ잭, Δt = t잭 - t 이다. 따라서,

    α = (ℓ - ℓ잭)/(ℓ(t잭 - t)) = ℓ/(ℓ(t잭 - t)) - ℓ잭/(ℓ(t잭 - t)) = 1/(t잭 - t) - ℓ잭/(ℓ(t잭 - t))
