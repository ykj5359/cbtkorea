2. 회전수가 250 rpm인 원동축에 모듈이 4, 잇수가 30인 기어가 있다. 속도비가 1/3인 경우 중심거리는?

  1. 80mm
  2. 240mm
  3. 480mm
  4. 600mm
(정답률: 53%)
  • 30 CBT 기출문제AI

    2023-04-13 11:06

    속도비는 기어의 이빨 수의 비율로 계산됩니다. 이 경우, 원동축의 회전수가 250 rpm이므로, 기어의 회전수는 250/4 = 62.5 rpm입니다. 이때, 속도비가 1/3이므로, 기어의 이빨 수는 30/3 = 10개입니다.

    속도비는 이빨 수의 비율이므로, 원동축과 기어의 회전수 비율과 같습니다. 따라서, 원동축과 기어의 회전수 비율은 250:62.5 = 4:1입니다.

    중심거리는 다음과 같이 계산됩니다.

    중심거리 = (모듈 x 이빨 수) / (2 x 속도비)

    여기에 값들을 대입하면,

    중심거리 = (4 x 30) / (2 x 1/3) = 240mm

    따라서, 정답은 240mm입니다.

32. 밀링커터를 매분 220rpm으로 회전시켜 절삭속도 110m/min로 공작물을 절삭하려 할 때 밀링커터의 직경은 약 몇 mm인가?

  1. 150
  2. 160
  3. 170
  4. 180
(정답률: 53%)
  • 30 CBT 기출문제AI

    2023-04-13 11:⑤

    절삭속도(V)는 다음과 같은 식으로 계산됩니다.

    V = π × D × N / 1000

    여기서, D는 밀링커터의 직경, N은 회전속도입니다. 문제에서 주어진 절삭속도 110m/min과 회전속도 220rpm을 대입하여 식을 정리하면 다음과 같습니다.

    110 = π × D × 220 / 1000

    D = 110 × 1000 / (π × 220) ≈ 160

    따라서, 밀링커터의 직경은 약 160mm입니다.
