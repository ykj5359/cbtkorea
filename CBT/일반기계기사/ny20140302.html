    1자유도계의 감쇠 고유진동수는 다음과 같이 계산할 수 있습니다.

    감쇠 고유진동수 = (고유진동수) x √(1 - (감쇠비)^2)

    고유진동수는 그림에서 주어졌으므로 2π x 1.5 = 9.42 rad/s 입니다.

    감쇠비는 다음과 같이 계산할 수 있습니다.

    감쇠비 = (2π x 0.1) / 9.42 = 0.0669

    따라서 감쇠 고유진동수 = 9.42 x √(1 - 0.0669^2) = 9.42 x 0.9978 = 9.38 rad/s 입니다.

    이를 Hz로 변환하면 9.38 / 2π = 1.49 Hz 입니다.

    하지만 보기에서는 1.14, 2.14, 3.14, 4.14 Hz 중에서 선택해야 합니다.

    감쇠비를 계산할 때 0.0669 대신 0.07을 사용하면 감쇠 고유진동수는 1.49 x √(1 - 0.07^2) = 1.47 Hz 가 됩니다.
