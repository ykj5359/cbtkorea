    이 문제는 정적 평형을 이용하여 풀 수 있습니다. 먼저, 보의 왼쪽 끝점 A에 작용하는 수평방향의 힘을 FA, 보의 오른쪽 끝점 B에 작용하는 수평방향의 힘을 FB라고 합시다. 그리고 보의 길이를 L, 보의 중심에서 A까지의 거리를 x, 보의 중심에서 B까지의 거리를 L-x라고 합시다. 이 때, 보의 중심에서의 모멘트 균형식을 세울 수 있습니다.

    FA x (L/2-x) + FB x (L/2-(L-x)) = 0

    이 식을 정리하면,

    FA = FB x (L-x)/x

    여기서, 보의 하중 중심에서의 모멘트는 0이므로, 보의 왼쪽 반에 작용하는 하중의 합과 오른쪽 반에 작용하는 하중의 합이 같습니다. 이를 이용하여 수직방향의 힘의 균형식을 세울 수 있습니다.

    RA + RB = 800

    여기서, RA은 FA와 같고, RB는 FB와 같으므로,

    FA + FB = 800

    FA = 800 - FB

    위의 두 식을 결합하면,

    800 - FB = FB x (L-x)/x

    800x - FB x x = FB x (L-x)

    800x = FB x L

    FB = 800x/L

    FA = 800 - 800x/L

    이제, FA와 FB를 이용하여 RA과 RB를 구할 수 있습니다.

    RA = FA + FB x (L-x)/L = 800 - 800x/L + 800x/L = 800

    RB = FB + FA x (L-x)/L = 800x/L + (800 - 800x/L) x (L-x)/L = 800

    따라서, 정답은 "RA=411.1KN,RB=288.9KN"입니다.
