80. 다음과 같은 회로에서 i2가 0 이 되기 위한 C의 값은? (단, L은 합성인덕턴스, M은 상호인덕턴스이다.)

  1. 1/wL
  2. 1/w2L
  3. 1/wM
  4. 1/w2M
(정답률: 32%)
  • 30 CBT 기출문제AI

    2023-04-16 17:56

    i2가 0이 되기 위해서는 L과 M에 흐르는 전류가 0이 되어야 한다. 따라서, L과 M에 인가되는 전압은 다음과 같다.

    VL = i1 * wL
    VM = i1 * wM

    여기서, VL과 VM은 서로 반대 방향으로 작용하므로, 전압의 합은 다음과 같다.

    Vsum = VL - VM = i1 * (wL - wM)

    이때, C에 인가되는 전압은 Vsum과 같으므로, C에 흐르는 전류는 다음과 같다.

    iC = C * dVsum/dt = C * (wL - wM) * di1/dt

    i2가 0이 되기 위해서는 iC가 0이 되어야 하므로, wL - wM = 0이 되어야 한다. 따라서, C의 값은 1/w2M이다.
