    K = -V/V0 * ΔP/ΔV

    먼저, 운동에너지와 위치에너지의 보존 법칙은 다음과 같다.

    운동에너지 + 위치에너지 = 상수

    즉, 시스템 내에서 운동에너지와 위치에너지의 합은 변하지 않는다는 것이다.

    이 때, 운동에너지는 다음과 같이 계산할 수 있다.

    운동에너지 = 1/2 x 물의 질량 x 물의 속도^2

    물의 질량 = Q/h x 1000

    운동에너지 = 1/2 x Q/h x 1000 x (15 m/s)^2

    위치에너지 = Q/h x 1000 x 9.8 x h
