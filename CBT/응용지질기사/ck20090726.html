9. 고온으로부터 저온으로 변화하는 Bowen의 반응 계열이 맞게 나열된 것은?

  1. 마그네슘 감람석 → 마그네슘 휘석 → 칼슘-마그네슘 휘석 → 각섬석 → 흑운모
  2. 마그네슘 감람석 → 마그네슘 휘석 → 칼슘-마그네슘 휘석 → 흑운모 → 각섬석

69. 국제암반역학회(ISRM)는 개략적인 체적절리계수와 RQD의 관계를 제시하였다. 체적절리계수가 20개/m3 일 때 RQD는 얼마인가?

  2. 62 %
  3. 49 %
  4. 33 %

    ISRM에서 제시한 체적절리계수와 RQD의 관계식은 다음과 같다.

    RQD = (Nc / N) x (Jn / Ja) x (100 - F)

    여기서 N은 총 드릴링 길이, Nc는 코어(암반 조각)의 길이, Jn은 비암석 부분의 길이, Ja는 암석 부분의 길이, F는 균열, 절리, 기타 결함 등의 비율을 나타낸다.

    체적절리계수는 단위 체적당 암반 내부의 공간 개수를 나타내는 값으로, 단위는 개/m3이다. 따라서 체적절리계수가 20개/m3이면, 1m3의 암반 내부에 20개의 공간이 있다는 것을 의미한다.

    이를 이용하여 RQD를 구하기 위해선, 다음과 같은 정보가 필요하다.

    - 총 드릴링 길이 (N)
    - 코어(암반 조각)의 길이 (Nc)
    - 비암석 부분의 길이 (Jn)
    - 암석 부분의 길이 (Ja)
