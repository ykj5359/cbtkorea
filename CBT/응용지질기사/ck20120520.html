79. 국제암반역학회(ISRM)는 개략적인 체적절리계수와 RQD의 관계를 제시하였다. 체적절리계수가 15개/m3 일 때 RQD는 얼마인가?

  1. 74%
  2. 66%
  3. 49%
  4. 33%
(정답률: 56%)
  • 30 CBT 기출문제AI

    2023-04-17 10:22

    ISRM에서 제시한 관계식은 다음과 같다.

    RQD = (V무결성 / V시료) x 100

    여기서 V무결성은 시료 중 무결성이 보존된 부분의 체적이고, V시료는 시료의 총 체적이다.

    체적절리계수는 다음과 같이 정의된다.

    체적절리계수 = (체적중량 - 입도중량) / 체적중량

    여기서 체적중량은 시료의 총 체적이고, 입도중량은 시료 내 입도가 있는 부분의 체적이다.

    따라서 체적절리계수가 15개/m3일 때, 시료의 입도가 없다고 가정하면 체적중량과 입도중량이 같아지므로 체적절리계수는 0이 된다. 이를 이용하여 V무결성을 구할 수 있다.

    체적절리계수 = (체적중량 - 입도중량) / 체적중량 = 0
    → 체적중량 = 입도중량

    V무결성 = 시료의 총 체적 - 입도중량

    따라서 V무결성 / V시료 = (시료의 총 체적 - 입도중량) / 시료의 총 체적 = 1 - (입도중량 / 시료의 총 체적)

    여기서 입도중량 / 시료의 총 체적은 체적절리계수이므로 1 - 체적절리계수가 된다. 따라서 RQD는 다음과 같이 계산할 수 있다.

    RQD = (V무결성 / V시료) x 100 = (1 - 체적절리계수) x 100

    체적절리계수가 15개/m3일 때, RQD = (1 - 15/100) x 100 = 85%

    따라서 정답은 "74%"가 아닌 "66%"이다.
