12. Gibbs의 상률(phase rule)을 올바르게 표시한 것은? (단, P : 상(相)의 수, F : 자유도, C : 성분의 수)

  1. P + C = F + 2
  2. P + 2 = C = F
  3. P + F = C + 2
  4. P = C + F + 2
(정답률: 86%)
  • 30 CBT 기출문제AI

    2023-04-17 10:33

    정답: "P + F = C + 2"

    이유: Gibbs의 상률은 다음과 같이 표현됩니다.

    F = C - P + 2

    여기서 F는 자유도, C는 성분의 수, P는 상(相)의 수를 나타냅니다. 이 식을 변형하면 다음과 같이 표현할 수 있습니다.

    P + F = C + 2

    즉, 상의 수와 자유도의 합은 성분의 수에 2를 더한 값과 같습니다. 이는 상, 자유도, 성분 간의 관계를 나타내는 중요한 식으로, 화학, 물리학 등 다양한 분야에서 활용됩니다.

  1. 모암은 묘봉층 일부와 풍촌석회암층이다.
  2. 관계 화성암은 화강섬록암이다.
  3. 주요 광석광물은 섬아연석, 방연석, 황동석이다.
  4. 수반 광물은 자류철석, 황철석, 백철석 등이다.
(정답률: 30%)
  • 30 CBT 기출문제AI

    2023-04-17 10:33

    "관계 화성암은 화강섬록암이다."가 옳지 않은 것이다. 관계 화성암은 화강섬록암이 아니라, 혼합암(마암)으로 분류된다.

    관계 화성암은 화강섬록암과 칼륨성 화강암, 그리고 암감석 등이 혼합되어 있는 암이다. 이러한 혼합암은 지질학적으로 다양한 과정을 거쳐 형성되기 때문에 광물 조성이나 미세 구조 등이 다양하다. 따라서, 광물 조성이나 미세 구조에 따라서 다양한 종류의 광물이 함유될 수 있다.
