  2. CaO ＞ 10%이면 반려암

(정답률: 알수없음)

    Fo ＞ 50이면 섬록암인 이유는, 철 마그네시움 실리케이트의 함량이 높은 암석은 대부분 섬록암으로 분류되기 때문입니다.

    반사계수 = (하부층의 밀도 - 상부층의 밀도) / (하부층의 밀도 + 상부층의 밀도)

  1. 1.⑤g/cm3
  2. 1.36g/cm3
  3. 2.65g/cm3
  4. 2.80g/cm3
(정답률: 20%)
  • 30 CBT 기출문제AI

    2023-04-17 10:26

    습윤밀도는 모래 입자와 물이 차지하는 부피의 비율을 나타내는 값이므로, 건조 상태에서는 물이 없으므로 입자 부피와 실제 부피가 같아진다. 따라서 건조밀도는 입자의 질량과 입자 부피의 비율을 나타내는 값이다.

    건조밀도 = 질량 / 입자 부피

    입자 부피 = 입자 직경^3 * π / 6

    입자 직경은 주어지지 않았으므로, 대신 입자의 비중을 이용하여 입자 부피를 구할 수 있다.

    입자 비중 = 입자의 밀도 / 물의 밀도

    입자의 밀도 = 건조밀도 * 물의 밀도

    따라서 입자 부피 = 입자 비중 * 질량 / (입자 비중 * 밀도) = 질량 / 밀도

    건조밀도 = 질량 / 입자 부피 = 질량 / (질량 / 밀도) = 밀도

    따라서 건조밀도는 1.80g/cm3 / 2.56 = 0.703g/cm3 이다.

    하지만 보기에서는 단위가 g/cm3로 주어졌으므로, 이 값을 cm3으로 변환하여 계산해야 한다.

    1g = 1cm3 이므로,

    건조밀도 = 0.703g/cm3 * (1cm3 / 1g) = 0.703cm3/g

    따라서 보기에서 정답이 "1.36g/cm3" 인 이유는, 1.36g/cm3 * (1cm3 / 1g) = 1.36cm3/g 이므로, 건조밀도가 1.36g/cm3일 때 cm3/g로 변환하면 1.36cm3/g가 되기 때문이다.
