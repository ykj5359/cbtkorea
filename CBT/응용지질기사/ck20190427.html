    비중 = 밀도 / 입자의 비중 = 2.083 kg/m3 / 2.7 = 0.771 kg/m3

    실제 부피 = 부피 / 함수비 = 0.012 m3 / 0.25 = 0.048 m3

    제방을 쌓기 위해 필요한 흙의 무게는 다음과 같다.

    무게 = 밀도 x 부피 = 2.083 kg/m3 x 0.048 m3 = 0.1 kg

    따라서, 간극률은 다음과 같이 계산할 수 있다.

    간극률(%) = (1 - (밀도/비중)) x 100 = (1 - (2.083 kg/m3 / 0.771 kg/m3)) x 100 = 38 %
