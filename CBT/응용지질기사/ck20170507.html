    따라서, 대칭 요소의 수에 따라 결정을 분류하는 정족의 가지 수는 32입니다.

37. 최대 주응력이 100MPa, 최소 주응력이 20MPa일 때 최소 주응력축과 각(θ)이 40°인 면에 작용하는 수직응력(σn)과 전단응력(τ)으로 옳은 것은?

  1. σn : 67MPa, τ : 39MPa
  2. σn : 72MPa, τ : 25MPa
  3. σn : 75MPa, τ : 21MPa
  4. σn : 78MPa, τ : 17MPa
(정답률: 51%)
  • 30 CBT 기출문제AI

    2023-04-17 10:20

    최소 주응력축과 각(θ)이 40°인 면에 작용하는 수직응력(σn)과 전단응력(τ)은 다음과 같이 구할 수 있다.

    σn = (σmax + σmin) / 2 + (σmax - σmin) / 2 * cos(2θ)

    τ = (σmax - σmin) / 2 * sin(2θ)

    여기서, 최대 주응력(σmax) = 100MPa, 최소 주응력(σmin) = 20MPa, θ = 40° 이므로,

    σn = (100 + 20) / 2 + (100 - 20) / 2 * cos(2*40°) ≈ 67MPa

    τ = (100 - 20) / 2 * sin(2*40°) ≈ 39MPa

    따라서, 정답은 "σn : 67MPa, τ : 39MPa" 이다.
