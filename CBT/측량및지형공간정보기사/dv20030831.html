4. 다음 그림에서와 같이 지구상의 두점 A,B에서 측량을 실시하여 다음과 같은 결과를 얻었다고 할때 지구의 원둘레는 얼마인가? (단, 지구는 구로 생각한다. AB의 지표면 거리 920km, ∠ACD = 7°)

  1. 약 36,783km
  2. 약 47,314km
  3. 약 58,432km
  4. 약 67,516km
(정답률: 74%)
  • 30 CBT 기출문제AI

    2023-04-18 11:42

    우선 지구는 구로 생각하므로, 지구의 반지름을 구해야 한다. 이를 위해 삼각형 ACD에서 코사인 법칙을 이용하여 CD를 구할 수 있다.

    cos(7°) = (지구반지름-920)/지구반지름
    지구반지름 - 920 = 지구반지름 * cos(7°)
    지구반지름 = 920 / (1 - cos(7°))

    이제 지구의 원둘레를 구하기 위해 2πr을 계산하면 된다.

    원둘레 = 2π * 지구반지름
    원둘레 = 2π * 920 / (1 - cos(7°))
    원둘레 ≈ 47,314km

    따라서 정답은 "약 47,314km"이다.

    2023-04-18 11:42

    시거측량에서는 다음과 같은 공식을 사용한다.

    H = ℓ tan α + Kd - Cd^2
    D = ℓ sec α

    여기서 ℓ은 협장, α는 연직각, K는 상수, C는 상수, d는 기울기거리, H는 고저차, D는 수평거리를 나타낸다.

    H = 1.8 tan 15° + 100d - 0.2d^2

    d = H / tan α

    따라서,

    d = (1.8 tan 15° + 100d - 0.2d^2) / tan 15°

    d = (100 ± √(100^2 - 4×0.2×1.8 tan 15°)) / (2×0.2)

    따라서,

    H = 1.8 tan 15° + 100×0.45 - 0.2×0.45^2 ≈ 45m
    D = 1.8 sec 15° ≈ 168m

    따라서 정답은 "H = 45m, D = 168m"이다.
