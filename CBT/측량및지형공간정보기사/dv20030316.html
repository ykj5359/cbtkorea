4. 반경 2m인 구면상의 구면삼각형 면적이 0.213m2일 때 이 구면삼각형의 구과량은?

    면적 = 반지름^2 x 구면각 / 2

    구면각 = 2 x 면적 / 반지름^2

    구면각 = 0.1065 x 57.3 = 6.1도

    6도 6.0 x 60 = 3분 0.0초

    따라서 정답은 "3° 03′ 04″"이다.

8. 적위가 +20° 인 별의 남중고도가 70° 였다면 관측지점의 위도는?

  2. 20° N
  3. 30° N
  4. 40° N
(정답률: 77%)
  • 30 CBT 기출문제AI

    2023-04-18 11:⑤

    적위가 +20° 인 별의 남중고도가 70° 이므로, 별은 적도에서 20°만큼 북쪽에 위치해 있고, 관측지점에서 별이 천정에 위치할 때의 높이는 70° 이다. 이를 이용하여 관측지점의 위도를 구할 수 있다.

    위도 = 90° - 별의 남중고도

    위 식에 값을 대입하면,

    위도 = 90° - 70° = 20°

    따라서, 관측지점의 위도는 20° N 이다. 따라서, 보기에서 정답은 "40° N"이 아니라 "20° N"이다.
