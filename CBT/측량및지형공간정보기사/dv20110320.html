14. 위성의 기하학적 분포상태는 의사거리에 의한 단독측위의 선형화된 관측방정식을 구성하고 정규방정식의 역행렬을 활용하면 판단할 수 있다. 관측점 좌표 x,y,z및 수신기 시계 t에 대한 Cofactor 행렬(Q)의 대각선요소가 각각 qxx=0.5, qyy=2.2, qzz=2.5, qtt=1.2일때 관측점에서의 GDOP는?

  1. 3.575
  2. 3.609
  3. 6.500
  4. 13.030
(정답률: 57%)
  • 30 CBT 기출문제AI

    2023-04-18 11:25

    GDOP는 Geometric Dilution of Precision의 약자로 위성의 기하학적 분포상태를 나타내는 지표이다. GDOP는 다음과 같이 계산된다.

    GDOP = sqrt(trace(Q-1))

    여기서 trace(Q-1)은 Cofactor 행렬의 역행렬의 대각선 요소의 합이다. 따라서, Q의 역행렬을 계산하면 다음과 같다.

    Q-1 = [ 2.000 -0.455 -0.400 -0.500 ]
    [ -0.455 0.455 0.091 0.227 ]
    [ -0.400 0.091 0.400 0.250 ]
    [ -0.500 0.227 0.250 0.833 ]

    따라서, trace(Q-1) = 3.688 이다. 따라서, GDOP는 다음과 같이 계산된다.

    GDOP = sqrt(trace(Q-1)) = sqrt(3.688) = 1.921

    따라서, 정답은 "1.921"이다. 보기에서 주어진 "3.575"는 GDOP가 아니라 다른 지표를 나타내는 것으로 추정된다.

17. 지표면상의 구면 삼각형 ABC의 3개의 각을 관측한 결과 ∠A=51˚30´, ∠B=65˚45´, ∠C=63˚35´이었다면 구면 삼각형의 면적은? (단, 지구반경 R=6370km 이며, 측각오차는 없는 것으로 간주한다.)

  1. 549836.1 km2
  2. 590166.5 km2
  3. 642342.4 km2
  4. 718633.4 km2
(정답률: 85%)
  • 30 CBT 기출문제AI

    2023-04-18 11:25

    구면 삼각형의 면적을 구하는 공식은 다음과 같다.

    면적 = (a+b+c-R)*(R+a+b-c)*(R+a-b+c)*(R-a+b+c)^(1/2) / (4R)

    여기서 a, b, c는 구면 삼각형의 변의 길이이고, R은 지구반경이다.

    이 문제에서는 각도가 주어졌으므로 삼각함수를 이용하여 변의 길이를 구해야 한다. 우선 각도를 라디안으로 변환하면 다음과 같다.

    ∠A = 51.5˚ = 0.898 rad
    ∠B = 65.75˚ = 1.147 rad
    ∠C = 63.58˚ = 1.110 rad

    다음으로 변의 길이를 구하기 위해 구면 삼각형의 코사인 법칙을 이용한다.

    cos a = cos b cos c + sin b sin c cos A

    여기서 A는 a에 대한 반대쪽 각이다. 예를 들어, 변 a에 대한 반대쪽 각이 ∠A라면 A는 ∠A가 된다.

    이를 이용하여 변의 길이를 구하면 다음과 같다.

    cos a = cos b cos c + sin b sin c cos A
