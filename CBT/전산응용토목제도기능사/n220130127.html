5. 그림과 같이 b=400mm, d=400mm, As=258mm2인 단철근직사각형 보의 중립축 위치 c는? (단, ƒ<>sub>ck=28MPa, ƒy=400MPa이다.)

  1. 108mm
  2. 128mm
  3. 215mm
  4. 210mm
(정답률: 46%)
  • 30 CBT 기출문제AI

    2023-04-12 18:53

    단면의 중립축 위치 c는 다음과 같이 구할 수 있다.

    c = (As * ys + Ac * yc) / (As + Ac)

    여기서, As는 단철근 면적, ys는 단철근 중립축 위치, Ac는 콘크리트 면적, yc는 콘크리트 중립축 위치이다.

    우선, 단철근의 중립축 위치 ys는 단면 높이 d/2인 곳에 위치한다. 따라서, ys = d/2 = 200mm이다.

    콘크리트의 중립축 위치 yc는 다음과 같이 구할 수 있다.

    yc = d - ys = 400mm - 200mm = 200mm

    콘크리트의 단면 2차 모멘트는 다음과 같이 구할 수 있다.

    Ic = (b * d3) / 12 = (400mm * 400mm3) / 12 = 21,333,333.33mm4

    콘크리트의 굽힘 응력은 다음과 같이 구할 수 있다.

    M = σb * Ic / yc = (0.85 * 28MPa * 21,333,333.33mm4) / 200mm = 3,623,333.33Nmm

    여기서, σb는 콘크리트의 굽힘 인장 강도이다. 0.85는 안전율이다.

    보의 굽힘 응력은 다음과 같이 구할 수 있다.

    σ = M / Z

    여기서, Z는 단면의 균심면에서의 단면 2차 모멘트이다. 즉, Z = I / yc이다.

    따라서, 보의 굽힘 응력은 다음과 같다.

    σ = (3,623,333.33Nmm) / (258mm3 / 2 * 400mm) = 70.31MPa

    보의 굽힘 응력이 단위 전단 인장 강도인 ƒy보다 작으므로, 단면이 안전하다.

    마지막으로, c를 구해보자.

    c = (As * ys + Ac * yc) / (As + Ac) = (258mm2 * 200mm + 400mm * 200mm) / (258mm2 + 400mm) = 128mm

    따라서, 중립축 위치 c는 128mm이다.
