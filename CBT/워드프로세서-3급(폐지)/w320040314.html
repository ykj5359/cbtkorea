    Windows 98에서 파일이나 폴더를 복사하려면 해당 파일이나 폴더를 선택한 후, 마우스 오른쪽 버튼을 클릭하여 나타나는 메뉴에서 "복사"를 선택하거나, Ctrl+C를 누르고 목적지 폴더를 선택한 후, 마우스 오른쪽 버튼을 클릭하여 나타나는 메뉴에서 "붙여넣기"를 선택하면 된다.

    이동은 파일만 가능하다는 것은 잘못된 설명이다. 파일과 폴더 모두 이동이 가능하다. 이동 방법은 복사와 유사하다. 해당 파일이나 폴더를 선택한 후, 마우스 오른쪽 버튼을 클릭하여 나타나는 메뉴에서 "잘라내기"를 선택하거나, Ctrl+X를 누르고 목적지 폴더를 선택한 후, 마우스 오른쪽 버튼을 클릭하여 나타나는 메뉴에서 "붙여넣기"를 선택하면 된다.
