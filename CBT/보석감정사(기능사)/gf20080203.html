32. 테이블과 스타 패싯에 의해 만들어지는 사각형의 윤곽이 일직선으로 보이고, 스타 패싯이 테이블 가장자리에서 거들까지의 길이의 2/3에 이른다면 추정되는 테이블의 크기는?

  1. 60%
  2. 66%
  3. 54%
  4. 72%
(정답률: 53%)
  • 30 CBT 기출문제AI

    2023-04-12 14:32

    스타 패싯이 테이블 가장자리에서 거들까지의 길이의 2/3에 이른다는 것은 스타 패싯의 길이가 테이블 가장자리에서 거들까지의 길이의 2/3이라는 뜻입니다. 따라서 스타 패싯의 길이를 x라고 하면, 테이블 가장자리에서 거들까지의 길이는 1.5x가 됩니다.

    그리고 테이블과 스타 패싯에 의해 만들어지는 사각형의 윤곽이 일직선으로 보인다는 것은 스타 패싯의 각이 90도라는 뜻입니다. 따라서 스타 패싯의 길이와 테이블 가장자리에서 거들까지의 길이를 이용해 사각형의 넓이를 구하면,

    넓이 = x * 1.5x = 1.5x^2

    사각형의 넓이는 테이블의 크기를 추정하는 데에 사용됩니다. 따라서 테이블의 크기를 100%로 놓고, 사각형의 넓이를 1.5x^2로 나누어 테이블 크기 대비 사각형의 크기 비율을 구합니다.

    사각형의 크기 비율 = (1.5x^2 / 100%) * (100% / 100%) = 1.5x^2

    따라서 스타 패싯의 길이가 테이블 가장자리에서 거들까지의 길이의 2/3이라는 조건을 이용해, 스타 패싯의 길이를 x로 놓고 사각형의 크기 비율을 구하면,

    사각형의 크기 비율 = 1.5x^2 = 1.5 * (2/3)^2 = 1.5 * 4/9 = 2/3 = 66%

    따라서 정답은 "66%"입니다.
