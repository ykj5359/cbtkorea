  2. 260m
  3. 520m
  4. 700m

    2023-04-17 06:41

    먼저, 수중에서 평형을 이루고 있는 어구는 중력과 부력이 서로 상쇄되어 있으므로 무게와 부피가 균형을 이루고 있습니다. 따라서, 어구의 부피를 구할 수 있습니다.

    어구의 부피 = 무게 / 밀도 = (1000 x 9.8) / 1025 = 9.76 m^3

    이제, 두 전개판 사이의 전개거리 D를 구하기 위해 삼각함수를 이용합니다.

    sin 15° = D / L

    D = L x sin 15° = 1000 x 0.26 = 260m

    하지만, 이것은 두 전개판 사이의 직선 거리이므로, 어구가 수중에서 평형을 이루고 있는 위치에서의 거리를 구하기 위해서는 피타고라스의 정리를 이용해야 합니다.

    어구와 물면 사이의 거리 = 어구의 부피 / (L x sin 15°) = 9.76 / 260 x 0.26 = 0.144m

    따라서, 어구가 수중에서 평형을 이루고 있는 위치에서의 거리는 1000m - 0.144m = 999.856m 입니다.

    마지막으로, 두 전개판 사이의 전개거리와 어구가 수중에서 평형을 이루고 있는 위치에서의 거리를 더해줍니다.

    D + 999.856m = 520m + 999.856m = 1519.856m

    따라서, 정답은 "520m"이 아니라 "1519.856m"입니다.
