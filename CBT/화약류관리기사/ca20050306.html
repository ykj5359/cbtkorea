  2. 32.2V
  3. 31.5V
  4. 39.0V
(정답률: 알수없음)

49. 직경이 5cm인 암석시편을 종방향으로 15000kg의 인장하중을 주었을 때 횡방향으로 0.0006cm 가늘어 졌다. 이 암석의 Poisson비는 얼마인가? (단, 이 암석의 탄성계수 E = 2.1×106kg/cm2 임)

  2. 0.29
  3. 0.33
  4. 0.36
(정답률: 28%)

    2023-04-18 02:06

    Poisson비는 횡방향 변형량(가늘어진 정도)을 종방향 변형량(인장하중으로 인한 늘어난 정도)으로 나눈 값이다. 따라서 Poisson비는 다음과 같이 구할 수 있다.

    Poisson비 = 횡방향 변형량 / 종방향 변형량

    주어진 문제에서는 종방향으로 15000kg의 인장하중을 가하였을 때, 횡방향으로 0.0006cm 가늘어졌다고 한다. 이때, 암석의 탄성계수 E는 2.1×10^6kg/cm^2이다.

    종방향 변형량 = 인장하중 / (탄성계수 × 단면적)

    단면적은 암석시편의 단면적으로, 반지름이 2.5cm인 원의 넓이인 πr^2을 구하면 된다.

    단면적 = πr^2 = 19.63cm^2

    따라서, 종방향 변형량은 다음과 같다.

    종방향 변형량 = 15000kg / (2.1×10^6kg/cm^2 × 19.63cm^2) = 0.00035cm

    횡방향 변형량은 문제에서 주어졌으므로 0.0006cm이다.

    따라서, Poisson비는 다음과 같다.

    Poisson비 = 0.0006cm / 0.00035cm ≈ 0.33

    따라서, 정답은 "0.33"이다.

    분사현상에 대한 안전율은 다음과 같이 계산할 수 있다.

    안전율 = (동수구배 - 최소동수구배) / 최소동수구배

    최소동수구배는 모래 지반의 압축성과 밀도 등에 따라 다르지만, 일반적으로 0.3 ~ 0.4 정도로 설정한다. 따라서 이 문제에서는 최소동수구배를 0.4로 가정하고 계산하면 된다.

    최소동수구배 = 0.4
    동수구배 = 0.5
    안전율 = (0.5 - 0.4) / 0.4 = 0.25

    하지만 이 문제에서는 모래 지반의 비중과 공극율도 주어졌기 때문에, 이를 이용하여 최소동수구배를 계산할 수 있다.

    모래 지반의 비중 = 2.6
    공극율 = 60%
    밀도 = 비중 / (1 + 공극율) = 2.6 / 1.6 = 1.625
    최소동수구배 = 0.5 x 밀도 = 0.5 x 1.625 = 0.8125

    따라서 이 값을 이용하여 안전율을 계산하면 다음과 같다.

    최소동수구배 = 0.8125
    동수구배 = 0.5
    안전율 = (0.5 - 0.8125) / 0.8125 = -0.385
