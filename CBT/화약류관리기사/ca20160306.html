4. PETN 의 1g 당 산소평형 값은?

  1. -0.101
  2. +0.035
  3. -0.387
  4. +0.200
(정답률: 83%)
  • 30 CBT 기출문제AI

    2023-04-18 01:40

    PETN은 폭발물질로서 산화제이며, 산화제는 연소 반응을 일으키기 위해 산소를 필요로 합니다. 따라서 PETN의 산소평형 값은 음수입니다. PETN의 분자식은 C5H8N4O12이며, 이 분자식으로부터 산소 원자의 수를 계산하면 12개입니다. 따라서 1g의 PETN에 대한 산소의 몰 수는 12/316.14mol/g = 0.0379mol/g입니다. PETN의 산소평형 상수는 다음과 같이 계산됩니다.

    K = [O2]^12/[PETN]^1

    여기서 [O2]는 산소의 분압, [PETN]은 PETN의 분압입니다. PETN은 고체이므로 분압은 일정합니다. 따라서 K는 [O2]^12에 비례합니다. 산소평형 값은 로그값으로 표현되며, 다음과 같이 계산됩니다.

    log K = 12log[O2] - log[PETN]

    log[O2]는 산소의 분압에 비례하므로, 산소평형 값은 음수입니다. 따라서 "-0.101"이 정답입니다.

5. 폭굉(爆轟)과 폭연(爆燃)의 연소속도 관계를 옳게 나타낸 것은?

  1. 폭굉 + 폭연 = 0
  2. 폭굉 = 폭연
  3. 폭굉 < 폭연
  4. 폭굉 > 폭연
(정답률: 94%)
  • 30 CBT 기출문제AI

    2023-04-18 01:40

    정답은 "폭굉 > 폭연"이다.

    폭굉은 매우 빠른 연소속도를 가지며, 폭발적인 화학반응으로 인해 매우 높은 온도와 압력이 발생한다. 따라서 연소속도가 매우 빠르고 폭발적인 특성을 가진다.

    반면에 폭연은 폭발적인 화학반응보다는 느린 연소속도를 가지며, 연소과정에서 발생하는 열과 가스가 확산되면서 연소가 일어난다. 따라서 연소속도가 상대적으로 느리고, 폭발적인 특성보다는 확산적인 특성을 가진다.

    따라서 폭굉은 폭연보다 더 빠른 연소속도를 가지므로, "폭굉 > 폭연"이라는 정답이 된다.

16. 뇌관 1개의 저항이 1.4Ω 인 전기뇌관 30발을 직렬로 결선하여 제발하자면 최저 몇 V의 전압이 필요한가? (단, 단선 1m 의 저항 0.02Ω, 총연장 100m로 하고, 발파기의 내부저항은 0이며, 뇌관 1개당 소요전류는 2A로 한다.)

  2. 50V
  3. 66V
  4. 88V
(정답률: 89%)

    2023-04-18 01:40

    30개의 전기뇌관을 직렬로 연결하면 전기뇌관의 총 저항은 1.4Ω x 30 = 42Ω 이다. 이때 전류는 고정된 2A 이므로, 전압은 전류 x 저항 = 2A x 42Ω = 84V 가 필요하다. 하지만, 전선의 저항과 길이로 인한 손실이 발생하므로, 이 값을 더해줘야 한다. 전선 1m의 저항이 0.02Ω 이므로, 100m의 전선의 저항은 0.02Ω x 100 = 2Ω 이다. 따라서, 총 저항은 42Ω + 2Ω = 44Ω 이다. 이를 이용하여 전압을 다시 계산하면, 전압 = 전류 x 저항 = 2A x 44Ω = 88V 가 된다. 따라서, 정답은 "88V" 이다.

23. 다이너마이트가 폭발 시 폭발온도가 약 3,000°K, 생성가스량은 850ℓ/kg이다. 이 때 화약의 힘으로 표시되는 비에너지(specific energy , f)는?

  1. 3.53 atm-ℓ
  2. 3,530 atm-ℓ
  3. 9,340 atm-ℓ
  4. 13,000 atm-ℓ
(정답률: 24%)
  • 30 CBT 기출문제AI

    2023-04-18 01:40

    화약의 힘은 폭발 시 생성된 가스의 압력과 부피에 비례한다. 따라서, 생성가스량과 폭발온도는 화약의 힘을 계산하는 데 필요한 정보이다.

    화약의 힘(f)은 다음과 같이 계산된다.

    f = (P * V) / m

    여기서,
    P = 폭발 시 생성된 가스의 압력
    V = 폭발 시 생성된 가스의 부피
    m = 사용된 화약의 질량

    위 문제에서, 생성가스량은 850ℓ/kg이므로, 1kg의 화약이 폭발할 때 생성되는 가스의 부피는 850ℓ이다. 또한, 폭발온도는 3,000°K이므로, 생성된 가스의 압력은 기체 상태 방정식을 이용하여 다음과 같이 계산할 수 있다.

    P = (n * R * T) / V

    여기서,
    n = 생성된 가스의 몰 수
    R = 기체 상수 (8.31 J/mol·K)
    T = 폭발온도 (K)

    생성된 가스의 몰 수는 다음과 같이 계산할 수 있다.

    n = m / M

    여기서,
    M = 생성된 가스의 분자량

    다이너마이트가 폭발할 때 생성되는 가스는 대부분 N2, CO2, H2O 등으로 이루어져 있으므로, 분자량은 대략 28g/mol 정도이다. 따라서, 1kg의 화약이 폭발할 때 생성되는 가스의 몰 수는 다음과 같다.

    n = 1000g / 28g/mol = 35.7 mol

    이를 이용하여 생성된 가스의 압력을 계산하면 다음과 같다.

    P = (35.7 mol * 8.31 J/mol·K * 3,000 K) / 850ℓ
    = 93,400 J/ℓ
    = 93,400 atm-ℓ

    따라서, 정답은 "9,340 atm-ℓ"이다.

43. Mohr-Coulomb의 파괴식을 σ-r좌표계에서 도시한 결과 점착력(c)이 10MPa, 내부마찰각(ø)이 45°라면 주응력공간(σ1-σ3)좌표계에 도시하였을 때의 기울기 값은?

  1. 3.83
  2. 4.83
  3. 5.83
  4. 6.83
(정답률: 23%)
  • 30 CBT 기출문제AI

    2023-04-18 01:40

    Mohr-Coulomb의 파괴식은 다음과 같다.

    τ = c + σn tan ø

    여기서, τ는 전단응력, c는 점착력, σn은 수직주응력, ø는 내부마찰각이다.

    σ-r 좌표계에서의 파괴식은 다음과 같다.

    τ = (σ - r) tan ø + c

    여기서, σ는 주응력, r은 중심축이다.

    주어진 문제에서, c = 10MPa, ø = 45°이다. 따라서,

    τ = (σ - r) tan 45° + 10MPa
    τ = σ - r + 10MPa

    주응력공간(σ1-σ3) 좌표계에서의 기울기는 다음과 같다.

    기울기 = (τ1 - τ3) / (σ1 - σ3)

    주어진 문제에서, τ1과 τ3는 다음과 같다.

    τ1 = σ1 - r + 10MPa
    τ3 = σ3 - r + 10MPa

    따라서,

    기울기 = (σ1 - r + 10MPa - σ3 + r + 10MPa) / (σ1 - σ3)
    기울기 = 20MPa / (σ1 - σ3)
    기울기 = 20 / (σ1 - σ3) (단위: MPa)

    따라서, 정답은 5.83이다.

95. 그림과 같이 반무한 탄성암체 표면의 한점 P에 200톤의 집중하중이 수직방향으로 작용할 경우 P점의 수직방향과 30°, 직선거리 20m 되는 지점 A의 수직응력 σZ는?

  1. 155kg/m2
  2. 15.5kg/m2
  3. 775kg/m2
  4. 77.5kg/m2
(정답률: 37%)
  • 30 CBT 기출문제AI

    2023-04-18 01:40

    먼저, 반무한 탄성암체는 수직응력과 수평응력이 같으므로 P점에서의 수평응력은 0이다. 따라서, P점에서의 총 응력은 수직응력만 고려하면 된다.

    P점에서의 수직응력 σZ는 다음과 같이 구할 수 있다.

    σZ = F/A

    여기서, F는 200톤, A는 P점에서의 단면적이다. P점에서의 단면적은 A = 2πrLcosθ 이다. 여기서, r은 지면과의 거리, L은 지면에 수직인 길이, θ은 수직방향과 30°이므로 θ = 60°이다.

    따라서, A = 2π(20m)cos60° = 20πm2 이다.

    따라서, σZ = 200톤 / 20πm2 = 31.83kg/m2 이다.

    하지만, 이 문제에서 요구하는 것은 A점에서의 수직응력이므로, A점에서의 수직응력을 구해야 한다. A점에서의 수직응력은 P점에서의 수직응력과 A점에서의 수직거리 h를 이용하여 다음과 같이 구할 수 있다.

    σZ = F/(πr2) = F/(πh2tanθ)

    여기서, h = 20m, θ = 30° 이므로,

    σZ = 200톤 / (π(20m)2tan30°) = 155kg/m2

    따라서, 정답은 "155kg/m2" 이다.
