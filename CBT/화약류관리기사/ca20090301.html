  4. +3.52g

    니트로글리세린의 화학식은 C3H5N3O9이다. 이것을 완전폭발시키면 다음과 같은 반응이 일어난다.

    4C3H5N3O9 + 21O2 → 12CO2 + 10H2O + 6N2 + O2

    이 반응식에서 니트로글리세린 1몰(227g)이 소모되면 산소 21몰이 소모된다. 따라서 100g의 니트로글리세린이 소모하는 산소의 몰 수는 다음과 같다.

    100g / 227g/mol = 0.44mol

    이에 따라 소모되는 산소의 몰 수는 다음과 같다.

    0.44mol × 21mol/mol = 9.24mol

    그러나 반응식에서 이미 1몰의 산소가 생성되므로, 실제로 필요한 산소의 몰 수는 다음과 같다.

    9.24mol - 1mol = 8.24mol

    따라서 산소의 과부족량은 다음과 같다.

    8.24mol - 6mol = 2.24mol

    마지막으로, 질소의 몰 수는 다음과 같다.

    4 × 0.44mol = 1.76mol

    질소의 원자량이 14이므로, 질소의 질량은 다음과 같다.

    1.76mol × 14g/mol = 24.64g

    따라서 산소의 과부족량은 다음과 같다.

    2.24mol × 32g/mol = 71.68g

    마지막으로, 산소의 과부족량을 뺀 값이 정답인 +3.52g이 된다.

    71.68g - 24.64g = 47.04g
    47.04g / 2 = 23.52g
    23.52g - 20g(1mol의 산소 질량) = +3.52g

93. 다음 그림에 주어진 사면의 평면파괴(plane failure)가능성을 평가하고자 한다. 예상 파괴면의 경사각은 50°, 점착력 0.1MPa, 마찰각 30°, 파괴면 면적 10m2이고, 예상 파괴면 상부 암괴의 체적은 20m3, 암석의 단위중량은 0.027MN/m3라면 이 사면의 안전율은? (단, 선형 Mohr-Coulomb 파괴기준 적용)

  1. 0.73
  2. 3.17
  3. 0.54
  4. 2.90
(정답률: 0%)
  • 30 CBT 기출문제AI

    2023-04-18 02:11

    선형 Mohr-Coulomb 파괴기준에서 안전율은 다음과 같이 계산된다.

    안전율 = 절편강도 / 예상 파괴면의 인장강도

    절편강도는 다음과 같이 계산된다.

    절편강도 = c + σn tan φ

    여기서 c는 강도 상수, σn은 예상 파괴면의 수직 압력, φ는 마찰각이다.

    먼저, 예상 파괴면의 수직 압력을 구해보자.

    예상 파괴면의 상부 암괴 체적은 20m³이고, 암석의 단위중량은 0.027MN/m³이므로, 상부 암괴의 무게는 다음과 같다.

    상부 암괴의 무게 = 20m³ × 0.027MN/m³ × 9.81m/s² = 5.56MN

    이 무게가 예상 파괴면의 면적 10m²에 분산되므로, 예상 파괴면의 수직 압력은 다음과 같다.

    예상 파괴면의 수직 압력 = 5.56MN / 10m² = 0.556MPa

    따라서, 절편강도는 다음과 같이 계산된다.

    절편강도 = 0.1MPa + 0.556MPa × tan 30° = 0.1MPa + 0.321MPa = 0.421MPa

    예상 파괴면의 인장강도는 다음과 같이 계산된다.

    예상 파괴면의 인장강도 = σn tan φ + σn / tan φ = 0.556MPa × tan 50° + 0.556MPa / tan 50° = 0.921MPa

    따라서, 안전율은 다음과 같이 계산된다.

    안전율 = 0.421MPa / 0.921MPa = 0.457

    즉, 안전율은 0.457이다. 이 값을 역수로 취한 값이 보기에서 제시된 값들 중에서 가장 가까운 값인 2.90이다.
