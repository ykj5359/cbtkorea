16. 니트로글리세린 100g이 완전폭발 하였을 경우 산소의 과부족량은 얼마인가? (단, 질소의 원자량은 14이다.)

  1. -3.52g
  2. -1.76g
  3. +1.76g
  4. +3.52g
(정답률: 91%)
  • 30 CBT 기출문제AI

    2023-04-18 01:36

    니트로글리세린의 화학식은 C3H5N3O9이다. 이것을 완전폭발시키면 다음과 같은 반응이 일어난다.

    4C3H5N3O9 + 21O2 → 12CO2 + 10H2O + 6N2 + O2

    이 반응식에서 니트로글리세린 1몰(227g)에 대해 산소가 21몰 필요하다. 그러나 이 문제에서는 100g의 니트로글리세린이 완전폭발했으므로, 필요한 산소의 몰 수는 다음과 같다.

    (21 mol O2 / 4 mol C3H5N3O9) × (100 g / 227 g/mol) = 9.27 mol O2

    그러나 이 반응에서 생성된 산소의 몰 수는 다음과 같다.

    1 mol O2 / 4 mol C3H5N3O9 × (100 g / 227 g/mol) = 0.11 mol O2

    따라서 산소의 과부족량은 다음과 같다.

    9.27 mol - 0.11 mol = 9.16 mol

    이를 그램으로 환산하면 다음과 같다.

    9.16 mol × 32 g/mol = 293.12 g

    따라서 산소의 과부족량은 약 +3.52g이다.

17. 어떤 폭약(지름 32mm, 무게 112.5g)의 사상순폭 시험을 한 결과 최대순폭거리가 160mm였다. 이 때의 순폭도는?

  1. 6
  2. 5
  3. 4
  4. 3
(정답률: 100%)
  • 30 CBT 기출문제AI

    2023-04-18 01:36

    순폭도는 폭약이 폭발할 때 발생하는 충격파의 세기를 나타내는 지표이다. 순폭거리가 160mm이고, 폭약의 무게와 지름이 주어졌으므로 이를 이용하여 순폭도를 계산할 수 있다.

    먼저, 폭약의 부피를 구한다. 폭약의 지름이 32mm이므로 반지름은 16mm이다. 따라서 폭약의 부피는 다음과 같다.

    부피 = (4/3)πr^3 = (4/3)π(16mm)^3 ≈ 17,136mm^3

    다음으로, 폭약의 밀도를 구한다. 폭약의 무게가 112.5g이므로, 밀도는 다음과 같다.

    밀도 = 무게 / 부피 = 112.5g / 17,136mm^3 ≈ 0.00655g/mm^3

    마지막으로, 순폭도를 계산한다. 순폭도는 다음과 같은 공식으로 계산된다.

    순폭도 = (최대순폭거리 / 폭약의 지름) * √(폭약의 밀도)

    최대순폭거리는 160mm이고, 폭약의 지름은 32mm이다. 폭약의 밀도는 위에서 구한 값인 0.00655g/mm^3이다. 따라서 순폭도는 다음과 같다.

    순폭도 = (160mm / 32mm) * √(0.00655g/mm^3) ≈ 5

    따라서 정답은 "5"이다.

56. 암석의 내부마찰각을 ø, 최소주응력이 작용하는 면과 파괴면이 이루는 각을 α라 할 때, 옳은 관계식은? (단, Mohr-Coulomb 파괴조건식에 의함)

  1. α=45°-ø/2
  2. α=45°+ø/2
  3. α=60°-ø/2
  4. α=60°+ø/2
(정답률: 12%)
  • 30 CBT 기출문제AI

    2023-04-18 01:36

    Mohr-Coulomb 파괴조건식은 다음과 같다.

    τ = c + σn tan ø

    여기서 τ는 최대 전단응력, c는 코헨 압축강도, σn은 수직응력, ø는 내부마찰각을 나타낸다.

    최소주응력이 작용하는 면에서의 전단응력은 다음과 같다.

    τmin = σn tan α

    파괴면에서의 전단응력은 최대 전단응력과 같으므로,

    τmax = c + σn tan ø

    파괴면에서의 최소주응력은 다음과 같다.

    σn = -τmax + c / tan ø

    따라서 최소주응력이 작용하는 면과 파괴면이 이루는 각은 다음과 같다.

    tan α = τmin / σn = -tan ø + c / τmax - c

    이를 정리하면,

    tan α = (c - τmax) / (τmax + c) tan ø
