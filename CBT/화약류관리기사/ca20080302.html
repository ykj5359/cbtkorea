16. 저항 1.4Ω의 전기뇌관 10발을 직렬결선하여 제발시키려면 몇 V의 전압이 필요한가? (단, 단선 1m의 저항이 0.021Ω인 발파 모선은 총 연장 100m이며 발파기의 내부저항은 없고, 뇌관 1개당 소요전류는 2A이다.)

  1. 21.5
  2. 32.2
  3. 39.0
  4. 45.5
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-18 02:10

    10개의 전기뇌관을 직렬결선하면 전압은 각 뇌관에서 소모되는 전압의 합과 같습니다. 따라서 전압은 다음과 같이 계산할 수 있습니다.

    전압 = (10개의 뇌관에서 소모되는 전압) + (발파 모선에서 소모되는 전압)

    10개의 뇌관에서 소모되는 전압은 각 뇌관에서 소모되는 전압의 합과 같습니다. 각 뇌관에서 소모되는 전압은 저항과 전류를 알고 있으므로 오므로 전압 = 저항 x 전류를 사용하여 계산할 수 있습니다.

    각 뇌관에서 소모되는 전압 = 1.4Ω x 2A = 2.8V
    10개의 뇌관에서 소모되는 전압 = 2.8V x 10 = 28V

    발파 모선에서 소모되는 전압은 발파 모선의 저항과 전류를 알고 있으므로 마찬가지로 전압 = 저항 x 전류를 사용하여 계산할 수 있습니다.

    발파 모선에서 소모되는 전압 = 0.021Ω x 20A x 100m = 42V

    따라서 전압은 28V + 42V = 70V가 필요합니다. 하지만 이 문제에서는 뇌관 10개를 직렬결선하였으므로, 전압은 70V / 10 = 7V가 필요합니다.

    하지만 이 문제에서는 발파기의 내부저항이 없다고 가정하였으므로, 실제로는 발파기의 내부저항이 전압을 더 소모할 것입니다. 따라서 실제로는 더 높은 전압이 필요합니다. 이 문제에서는 발파기의 내부저항을 고려하지 않았으므로, 더 높은 전압이 필요합니다. 따라서 정답은 32.2V가 됩니다.

    자승근 환산식은 다음과 같다.

    V = Kd^(-n/2)

    여기서 V는 지반진동속도, d는 폭원과 측정지점 사이의 거리, K는 상수이며, n은 지반의 지발력 지수이다.

    V1 = Kd1^(-n/2)
    V2 = Kd2^(-n/2)

    V1/V2 = (d2/d1)^(-n/2)

    이 식에서 d1 = 50m, d2 = 100m, V1 = 6mm/sec, V2 = 2mm/sec 이므로,

    6/2 = (100/50)^(-n/2)

    3 = 2^(-n/2)

    n/2 = log2(3)

    n = 2log2(3)

    n = 2.585

  1. Jv=4.7개/m3, 평균적인 블록(Medium)
  2. Jv=3.5개/m3, 큰 블록(Large)
  3. Jv=2.7개/m3, 매우 큰 블록(Very large)
  4. Jv=1.2개/m3, 작은 블록(Small)

    체적절리계수 Jv는 다음과 같이 계산된다.

    Jv = (절리수 총합) / (체적 총합)

    절리수 총합은 다음과 같이 계산된다.

    절리수 총합 = (절리 1군의 절리수) + (절리 2군의 절리수) + (절리 3군의 절리수) + (불규칙 절리의 절리수)

    = (10m × 8개) + (10m × 24개) + (5m × 7개) + (10m × 1개)

    = 8개 + 240개 + 35개 + 1개

    = 284개

    체적 총합은 다음과 같이 계산된다.

    체적 총합 = (절리 1군의 체적) + (절리 2군의 체적) + (절리 3군의 체적) + (불규칙 절리의 체적)

    = (10m × 10m × 1m × 8/100) + (10m × 10m × 1m × 24/100) + (5m × 10m × 1m × 7/100) + (10m × 10m × 1m × 1/100)

    = 0.8m3 + 2.4m3 + 0.35m3 + 0.1m3

    = 3.65m3

    따라서,

    Jv = 284개 / 3.65m3 ≈ 4.7개/m3

    - 절리군 1: 10m × 10m × 1m
