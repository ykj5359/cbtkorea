  2. 4600

  4. 6000
(정답률: 88%)

    = 57⑤ × (0.062 ÷ 0.1)

    = 3538.9

    따라서, 가장 가까운 정답은 4600이다.

    여기서 Δr은 압력 변화에 따른 시추공 반경의 증가량, r은 시추공 반경, Δp는 압력 변화, ν는 포아송비이다.

    주어진 값들을 대입하면,

    ν = 0.004 / 4 / 10 / (1 - 2 x 0.2) = 0.12

    따라서 암반의 변형계수는 0.12이다.

    보기에서 정답이 "12GPa"인 이유는, 변형계수와 압축탄성계수(E)는 다음과 같은 관계가 있기 때문이다.

    E = 2G(1 + ν)

    여기서 G는 전단탄성계수이다. 따라서,

    G = E / 2 / (1 + ν) = 12GPa

    즉, 암반의 전단탄성계수는 12GPa이다.

  1. 1.428ton/m2
  2. 1.73ton/m2
  3. 2.00ton/m2
  4. 2.37ton/m2
(정답률: 16%)
  • 30 CBT 기출문제AI

    2023-04-18 01:38

    이 문제는 라메의 방정식을 이용하여 해결할 수 있다. 라메의 방정식은 다음과 같다.

    σr = (σh + σv) / 2 + ((σh - σv) / 2)cos2θ + τhvsin2θ

    여기서 σr은 반경방향 응력, σh은 수평방향 응력, σv은 수직방향 응력, θ는 반경방향과 수평방향 사이의 각도, τhv는 수평방향과 수직방향 사이의 전단응력이다.

    이 문제에서는 반경방향과 수평방향이 직각이므로 cos2θ는 0이 되고, sin2θ는 1이 된다. 따라서 라메의 방정식은 다음과 같이 간단해진다.

    σr = (σh + σv) / 2 + τhv

    주어진 값에 대입하면,

    σr = (2.8 + 4) / 2 + 0 = 3.4ton/m2

    따라서 반경방향의 수직응력은 3.4 - 4 = -0.6ton/m2이다. 하지만 이 값은 음수이므로, 실제로는 반경방향으로 압축되는 응력이다. 따라서 절댓값을 취하면 0.6ton/m2이 된다.

  4. 3.1

    τf = c + σn tan φ = 0.1 + (20 × 0.025) tan 30° = 0.85 MPa
