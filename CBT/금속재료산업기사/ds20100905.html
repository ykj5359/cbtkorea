80. 시험편의 지름 14mm, 평행부 길이 60mm, 표점거리 50mm, 최대하중이 9930kgf일 때 인장강도 약 몇 kgf/mm2인가?

  1. 43.9
  2. 54.3
  3. 64.5
  4. 74.8
(정답률: 46%)
  • 30 CBT 기출문제AI

    2023-04-15 ⑤:40

    인장강도 = 최대하중 / (평행부 면적 x 안전율)

    평행부 면적 = π x (지름/2)^2 = 153.94mm^2

    안전율은 일반적으로 4~6 정도로 설정하는데, 문제에서 주어지지 않았으므로 4로 가정하자.

    인장강도 = 9930kgf / (153.94mm^2 x 4) = 16.15kgf/mm^2

    따라서, 보기에서 정답은 "64.5"가 아니라 "43.9"이다.
