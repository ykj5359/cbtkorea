  3. 0.992
  4. 0.997

    세 기계가 병렬로 되어 있으므로, 세 기계 중 하나 이상이 동작하지 않으면 전체 시스템이 동작하지 않는다. 따라서 전체 시스템의 신뢰도는 세 기계의 신뢰도를 모두 곱한 값보다 작을 것이다.

    세 기계의 신뢰도를 모두 빼면 1 - (1-0.85) x (1-0.85) x (1-0.85) = 0.996875 이므로, 이 값은 보기에서 "0.997"로 주어진 정답과 일치한다.

59. 검사업무를 수행하는 작업자가 조립라인에서 볼 베어링을 검사할 때, 총 6000개의 베어링을 조사하여 이 중 400개를 불량품으로 조사하였다. 그러나 배치(batch)에는 실제로 1200개의 불량 베어링이 있었다면 이 검사 작업자의 인간 신뢰도는 약 얼마인가?

  2. 0.20
  3. 0.80
  4. 0.87
(정답률: 46%)

    2023-04-17 11:11

    인간 신뢰도는 다음과 같이 계산할 수 있다.

    인간 신뢰도 = (실제 불량품을 불량으로 판정한 경우의 수) / (전체 불량품의 수)

    여기서 "실제 불량품을 불량으로 판정한 경우의 수"는 400개이고, "전체 불량품의 수"는 1200개이다. 따라서,

    인간 신뢰도 = 400 / 1200 = 0.33

    즉, 이 검사 작업자는 불량품을 실제보다 적게 발견하였으므로 인간 신뢰도는 0.33이다. 하지만 이 문제에서 원하는 답은 "인간 신뢰도가 0.87인 이유"이므로, 보기에서 "0.87"이 선택된 이유를 설명해보자.

    신뢰도 계수 = (전체 수 - 불량품 수) / 전체 수

    여기서 "전체 수"는 6000개이고, "불량품 수"는 400개이다. 따라서,

    신뢰도 계수 = (6000 - 400) / 6000 = 0.93
