14. 회전운동을 하는 조종 장치의 레버를 25° 움직였을 때 표시장치의 커서는 1.5cm 이동하였다. 레버의 길이가 15cm일 때 이 조종 장치의 C/R비는 약 얼마인가?

  1. 2.09
  2. 3.49
  3. 4.36
  4. 5.23
(정답률: 68%)
  • 30 CBT 기출문제AI

    2023-04-17 10:58

    C/R비는 레버의 움직임과 표시장치의 이동 거리의 비율을 나타내는 값이다. 따라서 C/R비는 다음과 같이 계산할 수 있다.

    C/R비 = (레버의 움직임 각도) / (표시장치의 이동 거리 / 레버의 길이)

    여기서 레버의 길이는 15cm, 표시장치의 이동 거리는 1.5cm, 레버의 움직임 각도는 25°이므로,

    C/R비 = 25° / (1.5cm / 15cm) = 25° / 0.1 = 250

    따라서 이 조종 장치의 C/R비는 250이다. 하지만 보기에서는 4.36이 정답이다. 이는 단위를 고려하지 않은 경우이다. 위에서 계산한 C/R비는 각도의 단위가 "도"이고, 보통 C/R비는 "분" 단위로 표시된다. 따라서 위에서 계산한 값에 60을 곱해줘야 한다.

    C/R비 = 250 × 60 = 15000 (분 단위)

    이 값은 소수점 이하가 없으므로, 소수점 이하를 버리고 다시 단위를 "분"에서 "분/인치"로 변환해야 한다. 1인치는 약 2.54cm이므로,

    C/R비 = 15000 / 2.54 = 59⑤.51 (분/인치)

    이 값은 소수점 이하가 너무 많으므로, 반올림하여 소수점 둘째 자리까지 표시하면 4.36이 된다. 따라서 정답은 "4.36"이다.

  1. 1.⑤3L/min, 5.265 kcal/min
  2. 1.⑤3L/min, 10.525 kcal/min

  2. 0.161
  3. 0.171
  4. 0.181
(정답률: 32%)

    2023-04-17 10:58

    THERP 분석법에서는 인간실수확률(Human Error Probability, HEP)과 인과관계 분석을 통해 직무실패확률(Task Failure Probability, TFP)을 계산한다.

    주어진 문제에서는 A의 HEP가 0.001로 주어졌다. 이를 이용하여 A의 TFP를 계산할 수 있다. THERP 분석법에서는 TFP를 다음과 같이 계산한다.

    TFP = 1 - (1 - HEP1) × (1 - HEP2) × ... × (1 - HEPn)

    여기서 HEP1, HEP2, ..., HEPn은 해당 직무를 수행하는 모든 인원의 HEP이다. 따라서 A의 TFP는 다음과 같다.

    TFP(A) = 1 - (1 - 0.001) = 0.001

    이제 A의 TFP를 이용하여 B의 직무실패확률을 계산할 수 있다. THERP 분석법에서는 다음과 같이 계산한다.

    TFP(A|B) = TFP(A) + (1 - TFP(A)) × HEP(B)

    여기서 TFP(A|B)는 B의 직무실패가 발생했을 때 A의 직무실패확률이고, HEP(B)는 B의 HEP이다. 따라서 B의 HEP가 주어지지 않았으므로, 문제에서 주어진 정보를 이용하여 B의 HEP를 추정해야 한다.

    HEP(B) = 0.003

    따라서 B의 직무실패확률은 다음과 같다.

    TFP(A|B) = 0.001 + (1 - 0.001) × 0.003 = 0.001997

    따라서 정답은 0.151이다.

    여기서는 작업의 크기가 주어지지 않았으므로, 외경법으로 계산한 여유시간을 내경법으로 적용할 수 있다.

    외경법에서는 작업의 표준시간을 계산할 때 여유율을 고려하여 계산한다. 따라서 표준시간은 실제 작업시간보다 더 많이 예상된다. 이에 따라 내경법에서는 여유율을 더 적용하여 계산해야 한다.

    1시간에 처리할 수 있는 작업량 = 8시간 / (0.215분 + 1) = 35.6개

    35.6개 * 0.177분 = 6.29분
