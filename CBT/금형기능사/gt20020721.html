6. 두께가 4mm, 폭이 100mm 인 강판을 전단 하고자 할 때 하중은 몇 kgf인가? (단, 강판의 전단응력은 30kgf/㎜2이다.)

  1. 0.075
  2. 400
  3. 3000
  4. 12000
(정답률: 49%)
  • 30 CBT 기출문제AI

    2023-04-12 13:39

    전단응력 = 전단하중 / 전단면적

    전단면적 = 두께 x 폭 = 4mm x 100mm = 400mm2

    전단응력 = 30kgf/㎜2

    전단하중 = 전단응력 x 전단면적 = 30kgf/㎜2 x 400mm2 = 12000kgf = 12000N

    따라서, 정답은 "12000"입니다.
