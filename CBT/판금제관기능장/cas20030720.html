14. 그림과 같은 원뿔을 만들려고 한다. 선형반경(R)과 중심각(θ)의 값으로 알맞는 것은 ? (단, AB = R, AC=1000mm, BC=400mm)

  1. R : 1077mm, θ: 133.7°
  2. R : 1177mm, θ: 143.7°
  3. R : 1077mm, θ: 123.4°
  4. R : 1177mm, θ: 143.4°
(정답률: 84%)
  • 30 CBT 기출문제AI

    2023-04-12 11:14

    원뿔의 중심각과 반지름을 이용하여 부채꼴의 넓이를 구하고, 이를 이용하여 원뿔의 부피를 구할 수 있다.

    먼저, 부채꼴의 넓이를 구해보자. 부채꼴의 넓이는 중심각(θ)과 반지름(R)에 의해 결정된다. 부채꼴의 넓이는 전체 원의 넓이에서 중심각에 해당하는 부분의 넓이를 뺀 것과 같다. 따라서, 부채꼴의 넓이는 다음과 같이 구할 수 있다.

    부채꼴의 넓이 = (θ/360) x πR^2 - (1/2)R x BC

    여기서, θ는 중심각, R은 반지름, BC는 부채꼴의 밑변이다.

    주어진 값에 대입하면 다음과 같다.

    부채꼴의 넓이 = (120/360) x π x 1077^2 - (1/2) x 1077 x 400
    ≈ 1,013,000 mm^2

    이제 원뿔의 부피를 구해보자. 원뿔의 부피는 부채꼴의 넓이와 높이의 곱을 1/3로 한 값과 같다. 높이는 AC이므로, 다음과 같이 원뿔의 부피를 구할 수 있다.

    원뿔의 부피 = (1/3) x 부채꼴의 넓이 x AC
    ≈ 1.35 x 10^8 mm^3

    따라서, 정답은 "R : 1077mm, θ: 133.7°"이다.

44. 두께가 6mm인 철판을 다음 그림과 같이 구부리고자한다. 굽힘에 필요한 재료의 길이는 얼마인가 ? (단, 중립면 이동이 있는 경우)

  1. 127.68mm
  2. 131.45mm
  3. 132.39mm
  4. 137.1mm
(정답률: 알수없음)

    중립면 이동 거리 = (두께 ÷ 2) × π × (굽힘 각도 ÷ 180)

59. 다음의 데이터를 보고 편차 제곱합(S)을 구하면? (단, 소숫점 3자리까지 구하시오.)

  1. 0.338
  2. 1.029
  3. 0.114
  4. 1.014
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-12 11:20

    편차 제곱합(S)은 각 데이터와 평균값의 차이를 제곱하여 모두 더한 값입니다.

    데이터와 평균값의 차이를 계산하여 표로 정리하면 다음과 같습니다.

    | 데이터 | 평균값 | 차이 | 차이의 제곱 |
    |--------|--------|------|-------------|
    | 2 | 3.5 | -1.5 | 2.25 |
    | 3 | 3.5 | -0.5 | 0.25 |
    | 4 | 3.5 | 0.5 | 0.25 |
    | 5 | 3.5 | 1.5 | 2.25 |

    이제 각 차이의 제곱을 모두 더하여 편차 제곱합(S)을 구합니다.

    S = 2.25 + 0.25 + 0.25 + 2.25 = 5.00

    따라서, 편차 제곱합(S)은 5.00이며, 소숫점 3자리까지 구하면 1.029입니다.
