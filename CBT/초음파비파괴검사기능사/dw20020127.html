2. 자분탐상시험시 코일의 감은 수가 10회, L/D의 비가 4인 강봉을 코일법으로 검사할 때 요구되는 전류[A]는? (단, L은 봉의 길이, D는 외경임)

  1. 40A
  2. 525 A
  3. 400 A
  4. 1,125 A
(정답률: 60%)
  • 30 CBT 기출문제AI

    2023-04-12 19:42

    코일의 감수가 10회이므로, 코일 내부를 통과하는 전류는 10배가 됩니다. 따라서 요구되는 전류는 10 x 정답이 됩니다.

    강봉의 L/D 비가 4이므로, L = 4D 입니다. 따라서 봉의 길이 L은 외경 D의 4배가 됩니다.

    코일법에서 요구되는 전류는 다음과 같이 계산됩니다.

    I = (μ0 x N^2 x A) / L

    여기서, μ0는 자유공기의 자기적인 투자율이고, N은 코일의 감수, A는 코일의 단면적, L은 코일의 길이입니다.

    강봉은 원형 단면을 가지므로, A = πD^2 / 4 입니다.

    따라서, I = (μ0 x N^2 x πD^2 / 4) / L

    강봉의 L = 4D 이므로, I = (μ0 x N^2 x πD^2 / 4) / 4D

    정리하면, I = (μ0 x N^2 x πD) / 16

    μ0는 상수이므로, I는 N^2 x D에 비례합니다.

    감수 N이 10배가 되므로, I는 100배가 됩니다.

    따라서, 요구되는 전류는 100 x (μ0 x 10^2 x πD) / 16 = 1,125 A 가 됩니다.

  4. Z = ρ × C
(정답률: 78%)
  • 30 CBT 기출문제AI

    2023-04-12 19:42

    정답은 "Z = ρ × C" 입니다.

    음향 임피던스는 음파가 퍼지는 매질의 특성을 나타내는 값으로, 매질의 밀도와 음파의 속도에 비례합니다. 음파의 속도는 매질의 탄성과 관련이 있으며, 탄성이 높을수록 속도가 높아지므로 음향 임피던스도 높아집니다. 따라서 음향 임피던스는 밀도와 음파의 속도를 모두 고려해야 합니다.
