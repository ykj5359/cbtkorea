6. 종파속도가 6,000m/sec이고 주파수가 5MHz인 경우 파장은 얼마인가?

  1. 1.2m
  2. 1.2cm
  3. 1.2mm
  4. 0.12mm
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-12 19:41

    파장 = 속도 ÷ 주파수

    주어진 종파속도와 주파수를 이용하여 파장을 계산하면:

    파장 = 6,000 ÷ 5,000,000 = 0.0012m = 1.2mm

    따라서 정답은 "1.2mm"이다.

  3. URL(Uniform Resource Location)
  4. DNS(Domain Name Server)

    2023-04-12 19:45

    DNS(Domain Name Server)은 인터넷 상에서 도메인 이름을 IP 주소로 변환해주는 서비스입니다. 인터넷 상에서 컴퓨터는 IP 주소를 통해 서로 통신하게 되는데, 이때 IP 주소는 숫자로 이루어져 있어서 기억하기 어렵습니다. 따라서 DNS는 도메인 이름을 입력하면 해당 도메인 이름에 대응하는 IP 주소를 찾아서 사용자에게 제공해주는 역할을 합니다. 이를 통해 사용자는 기억하기 쉬운 도메인 이름으로 웹사이트에 접속할 수 있습니다.
