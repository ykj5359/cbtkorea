8. CD음질 수준의 스테레오 사운드를 10초간 저장하는데 필요한 최소한의 메모리 공간은? (CD음질 : 44.1KHz, 16bit 샘플링 데이터)

  1. 0.88Mbyte
  2. 1.76Mbyte
  3. 3.52Mbyte
  4. 10Mbyte
(정답률: 68%)
  • 30 CBT 기출문제AI

    2023-04-12 08:54

    CD음질은 44.1KHz, 16bit 샘플링 데이터를 사용합니다. 이를 10초간 저장하기 위해서는 다음과 같이 계산할 수 있습니다.

    1초당 필요한 데이터 양 = 44.1KHz x 16bit = 7⑤.6Kbit
    10초간 필요한 데이터 양 = 7⑤.6Kbit x 10 = 7.⑤6Mbit

    하지만, 1byte는 8bit이므로 7.⑤6Mbit를 byte로 변환하면 다음과 같습니다.

    7.⑤6Mbit / 8 = 882KB

  1. 매개변수 질의
  2. UNION 질의
  3. 하위질의
  4. 크로스탭 질의
(정답률: 70%)
  • 30 CBT 기출문제AI

    2023-04-12 08:54

    UNION 질의는 두 개의 테이블을 합쳐서 하나의 테이블로 만들어주는 질의입니다. 이 때, 두 테이블의 컬럼 수와 데이터 타입이 동일해야 합니다. 따라서 성격이 유사한 두 개의 테이블을 합치기에 가장 적합한 질의입니다. 매개변수 질의는 사용자로부터 입력받은 매개변수를 이용하여 질의를 수행하는 것이며, 하위질의는 다른 질의의 결과를 이용하여 질의를 수행하는 것입니다. 크로스탭 질의는 행과 열을 바꾸어서 데이터를 출력하는 것으로, 성격이 유사한 두 개의 테이블을 합치는 것과는 관련이 없습니다.

60. 가장 적절하지 않은 것은?

  1. 특정 필드의 값에 대한 페이지별 누적 총계를 계산하여 표시하는 속성
  2. 아니오(기본값)를 선택하면 레코드에서 원본으로 사용하는 필드의 값을 표시
  3. '그룹'을 선택하면 동일한 그룹 내에서의 누적 총계를 표시
  4. '모두'를 선택하면 그룹에 관계없이 전체 데이터에 대한 누적 총계를 표시
