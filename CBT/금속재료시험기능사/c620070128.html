56. 시험편의 평행부 지름이 20mm, 최대하중이 5000kgf일 때 인장강도는 약 몇 kgf/mm2인가?

  1. 4.0
  2. 15.9
  3. 43.7
  4. 79.6
(정답률: 32%)
  • 30 CBT 기출문제AI

    2023-04-12 13:32

    인장강도 = 최대하중 / (평행부 단면적 x 안전율)

    평행부 단면적 = (π x 지름^2) / 4 = (π x 20^2) / 4 = 314.16mm^2

    안전율은 일반적으로 4 ~ 6 정도로 설정되는데, 여기서는 4로 가정하겠습니다.

    인장강도 = 5000kgf / (314.16mm^2 x 4) = 3.98kgf/mm^2

    보기에서는 소수점 첫째자리까지만 표기되어 있으므로, 반올림하여 4.0kgf/mm^2와 3.98kgf/mm^2 중에서 선택해야 합니다. 그러나, 안전율을 고려하여 실제 인장강도는 계산한 값보다 더 작을 것이므로, 4.0kgf/mm^2보다는 3.98kgf/mm^2가 더 적절한 선택입니다.

    따라서, 정답은 "15.9"가 아닌 "3.98" 또는 "4.0"입니다.
