3. LC 발진 회로에서 L = 200[μH], C = 200[pF]이면 발진 주파수 fo는?

  1. 400[kHz]
  2. 455[kHz]
  3. 600[kHz]
  4. 800[kHz]
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-12 14:13

    LC 발진 회로에서 발진 주파수는 다음과 같이 계산됩니다.

    fo = 1 / (2π√(LC))

    여기서 L = 200[μH], C = 200[pF]를 대입하면,

    fo = 1 / (2π√(200[μH] × 200[pF]))

    = 1 / (2π√(0.04))

    = 1 / (2π × 0.2)

    ≈ 800[kHz]

    따라서, 정답은 "800[kHz]"입니다. 이유는 L과 C의 값에 의해 발진 주파수가 결정되기 때문입니다. 다른 보기들은 L과 C의 값이 다르기 때문에 발진 주파수도 다르게 계산됩니다.

  2. X = ⋅
  3. X = A + B
  4. X = A ⋅ B
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-12 14:13

    정답은 "X = A + B"입니다.

    AND 게이트와 OR 게이트를 조합하여 만든 논리회로이며, 입력 A와 B를 OR 게이트로 연결하여 출력 Y를 만들고, Y와 입력 A를 AND 게이트로 연결하여 출력 X를 만듭니다.
