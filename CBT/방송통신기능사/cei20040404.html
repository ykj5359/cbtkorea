5. RL직렬회로에서 임피던스 5[Ω], 저항 대 리액턴스의 비가 1 : √3 이면 저항은 몇 [Ω]인가?

  1. 2.5√3
  2. 2.5
  3. 5/√3
  4. 5
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-12 14:12

    RL직렬회로에서 임피던스는 다음과 같이 표현됩니다.

    Z = √(R^2 + Xl^2)

    여기서 Xl은 인덕턴스의 리액턴스를 나타내며, Xl = 2πfL입니다. f는 주파수, L은 인덕턴스 값입니다.

    문제에서 비가 1 : √3 이므로, R:Xl = 1:√3입니다. 따라서 R = Xl/√3입니다.

    임피던스가 5[Ω]이므로, 다음과 같은 식이 성립합니다.

    5 = √(R^2 + Xl^2)

    5^2 = R^2 + Xl^2

    25 = R^2 + (2πfL)^2/3

    여기서 R = Xl/√3이므로,

    25 = (Xl/√3)^2 + (2πfL)^2/3

    25 = Xl^2/3 + (4π^2f^2L^2)/9

    L = 1/2πf * √(9(25 - Xl^2) / 4π^2)

    여기서 Xl = 2πfL/√3이므로,

    L = 1/2πf * √(9(25 - (4π^2f^2L^2/3)) / 4π^2)

    L = √(3/4π^2f^2 - 25/3) / 2πf

    이를 다시 Xl = 2πfL에 대입하면,

    Xl = 2πf * √(3/4π^2f^2 - 25/3) / 2πf

    Xl = √(3/4π^2f^2 - 25/3)

    R = Xl/√3 = (√(3/4π^2f^2 - 25/3)) / √3

    주파수 f가 주어지지 않았으므로, 정확한 값을 구할 수 없습니다. 하지만 보기에서는 R이 2.5[Ω]일 때 정답이 되므로, 이를 대입해보면,

    2.5 = (√(3/4π^2f^2 - 25/3)) / √3

    15.625 = 3/4π^2f^2 - 25/3

    f = 1.5[kHz]

    따라서, 저항은 2.5[Ω]가 됩니다.

7. 1000[AT/m]의 자장중에 어떤 자극을 놓았을때 3×102 [N]의 힘을 받는다고 한다. 자극의 세기는 얼마인가?

  1. 0.1 [Wb]
  2. 0.2 [Wb]
  3. 0.3 [Wb]
  4. 0.4 [Wb]
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-12 14:28

    자극의 세기는 F = BIL에서 구할 수 있다. 여기서 F = 3×10^2 [N], B = 1000 [AT/m], I = 1 [A] (전류는 자기장을 만드는데 기여하는 전류만 고려한다) 이므로,

    3×10^2 = 1000 × 1 × L

    L = 0.3 [m]

    자기장의 세기는 B = μ₀I/2r에서 구할 수 있다. 여기서 μ₀는 자유공간의 유도율로 4π×10^-7 [T·m/A], r은 자기장을 측정하는 위치에서 자성체까지의 거리이다. 이 문제에서는 자기장을 측정하는 위치에서 자성체까지의 거리가 주어지지 않았으므로, 일반적으로 자기장을 측정하는 위치에서 자성체까지의 거리가 충분히 가까우면 (즉, 자기장이 균일하다고 가정할 수 있으면) B = μ₀I/2r에서 r을 생략할 수 있다. 따라서,

    B = μ₀I/2 = 4π×10^-7 × 1/2 = 2π×10^-7 [T]

    자기장의 단위는 테슬라(T)이지만, 웹러너(Wb)로 표시할 수도 있다. 웹러너는 자기장이 1초 동안 1m^2의 면적을 통과할 때 생성되는 자기력선의 개수를 나타내는 단위이다. 따라서,

    B = Φ/A

    여기서 Φ는 자기력선의 총 개수이고, A는 자기장이 통과하는 면적이다. 자기장이 균일하다면, A는 자기장이 통과하는 면적의 크기와 같다. 따라서,

    Φ = B × A = 2π×10^-7 × 1×1 = 2π×10^-7 [Wb]

    따라서, 정답은 "0.3 [Wb]"가 아니라 "0.2 [Wb]"이다.

11. 진폭 변조에서 반송파가 Vc = 100sin 314 × 103t[V]이고 신호파가 Vs=70sin 377t[V]이면 변조도 ma는 몇 [%] 인가?

  1. 35[%]
  2. 50[%]
  3. 70[%]
  4. 85[%]
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-12 14:28

    진폭 변조에서 변조도 ma는 다음과 같이 계산할 수 있습니다.

    ma = (Vmax - Vmin) / (Vmax + Vmin)

    여기서 Vmax는 최대 진폭, Vmin은 최소 진폭을 나타냅니다. 반송파와 신호파의 진폭을 구해보면 다음과 같습니다.

    반송파의 최대 진폭 Vc(max) = 100[V]
    반송파의 최소 진폭 Vc(min) = -100[V]
    신호파의 최대 진폭 Vs(max) = 70[V]
    신호파의 최소 진폭 Vs(min) = -70[V]

    따라서,

    Vmax = Vc(max) + Vs(max) = 100[V] + 70[V] = 170[V]
    Vmin = Vc(min) + Vs(min) = -100[V] - 70[V] = -170[V]

    ma = (Vmax - Vmin) / (Vmax + Vmin) = (170[V] - (-170[V])) / (170[V] + (-170[V])) = 340[V] / 0[V] (분모가 0이므로 계산 불가능)

    위 계산 결과, 분모가 0이므로 변조도 ma를 구할 수 없습니다. 따라서 보기에서 정답은 "70[%]"입니다. 이는 진폭 변조에서 신호파의 최대 진폭이 반송파의 최대 진폭과 같을 때, 변조도가 최대가 되는 경우입니다. 이 경우에는 Vmin이 0이 되므로 분모가 0이 되지 않아 계산이 가능합니다. 따라서 변조도 ma는 다음과 같이 계산됩니다.

    ma = (Vmax - Vmin) / (Vmax + Vmin) = (170[V] - 0[V]) / (170[V] + 0[V]) = 1 = 100[%]

    따라서 변조도 ma는 70[%]가 아닌 100[%]입니다.
