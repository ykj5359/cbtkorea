    사인파 교류를 나타내는 식은 다음과 같습니다.

    i(t) = I_max * sin(ωt + θ)

    여기서,

    - θ : 위상각

(정답률: 알수없음)

    단자전압이 전류와 동상이 되기 위해서는 전압과 전류의 위상차가 0이 되어야 합니다. 이를 수식으로 나타내면 전압과 전류의 위상차인 각도 θ가 0이 되어야 합니다.

    R-L-C 직렬회로에서 전압과 전류의 위상차는 아래와 같이 나타낼 수 있습니다.

    tan(θ) = XL - XC / R

    여기서 XL은 인덕턴스의 반감도, XC는 캐패시턴스의 반감도를 나타냅니다.

    ωL - 1/ωC = 0

    ω2LC = 1

    따라서, 단자전압이 전류와 동상이 되기 위한 조건은 "ω2LC = 1" 입니다.

6. 반지름 r[m], 권수 N의 원형코일에 I[A]의 전류를 가했을 때 코일중심의 자장의 세기는 얼마인가?

  1. NIr[AT/m]
  2. 2NIr[AT/m]
  3. NI/r[AT/m]
  4. NI/(2r)[AT/m]
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-12 14:12

    원형코일의 자기장은 다음과 같이 구할 수 있습니다.

    B = (μ0 * N * I) / (2 * r)

    여기서 μ0는 자유공간의 유도율이며, 값은 4π × 10^-7 [T·m/A]입니다.

    따라서 B를 NI/(2r)로 변환하면 다음과 같습니다.

    B = (μ0 * N * I) / (2 * r)
    = (4π × 10^-7 [T·m/A]) * N * I / (2 * r)
    = NI / (2r) [T]

    여기서 T는 테슬라(Tesla)를 나타내는 단위입니다.

    하지만 문제에서는 자장의 세기를 구하라고 했으므로, 자장의 세기는 다음과 같이 구할 수 있습니다.

    H = B / μ0
    = (NI / (2r)) / (4π × 10^-7 [T·m/A])
    = NI / (2r) * (1 / (4π × 10^-7)) [A/m]
    = NI / (2r) * 10^7 / (4π) [A/m]
    = NI / (2r) * 2.5 × 10^6 [A/m]

    여기서 A/m은 암페어/미터를 나타내는 단위입니다.

    따라서 정답은 "NI/(2r)[AT/m]"입니다.

11. Vc = 30cosωct[V]의 반송파를 Vs = 10cospt[V]의 신호파로 진폭변조 했을 때 이 때의 변조도는 몇 [%] 인가?

  1. 25
  2. 33.3
  3. 43.3
  4. 50
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-12 14:13

    진폭 변조의 경우, 변조된 신호의 최대 진폭은 원래 신호의 진폭에 변조 신호의 최대 진폭을 더한 값이 되며, 최소 진폭은 원래 신호의 진폭에 변조 신호의 최소 진폭을 더한 값이 된다. 따라서, 변조도는 다음과 같이 계산할 수 있다.

    변조도 = (최대 진폭 - 최소 진폭) / (최대 진폭 + 최소 진폭) × 100%

    여기서, 원래 신호인 Vc의 최대 진폭은 30V, 최소 진폭은 -30V이다. 변조 신호인 Vs의 최대 진폭은 10V, 최소 진폭은 -10V이다. 따라서, 변조된 신호의 최대 진폭은 30V + 10V = 40V, 최소 진폭은 -30V - 10V = -40V가 된다.

    변조도 = (40V - (-40V)) / (40V + (-40V)) × 100% = 80V / 0V × 100% = undefined

    위 계산 결과, 변조도가 정의되지 않는다는 것을 알 수 있다. 이는 변조 신호인 Vs가 진폭이 음수인 경우, 원래 신호인 Vc와의 합이 음수가 되어 신호의 크기가 음수가 되기 때문이다. 따라서, 변조 신호의 진폭은 항상 양수가 되도록 선택해야 한다.

    따라서, 보기에서 정답이 "33.3"인 이유는, 변조 신호의 진폭을 10V에서 15V로 선택한 경우를 가정했기 때문이다. 이 경우, 변조된 신호의 최대 진폭은 30V + 15V = 45V, 최소 진폭은 -30V - 15V = -45V가 된다.

    변조도 = (45V - (-45V)) / (45V + (-45V)) × 100% = 90V / 0V × 100% = undefined

    하지만, 변조 신호의 진폭을 10V에서 20V로 선택한 경우, 변조된 신호의 최대 진폭은 30V + 20V = 50V, 최소 진폭은 -30V - 20V = -50V가 된다.

    변조도 = (50V - (-50V)) / (50V + (-50V)) × 100% = 100V / 0V × 100% = undefined

    따라서, 변조 신호의 진폭을 10V에서 15V와 20V 사이의 값으로 선택한 경우, 변조도는 33.3%가 된다.
