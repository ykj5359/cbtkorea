3. 다음 그림과 같은 스프링 연결에서 스프링 상수값이 k2 = 2k1, k3 = k1 일 때 상당 스프링 상수 k값은?

  1. 4k1
  2. 3k1
  3. 1/4k1
  4. 1/k1 + 1/k2 + 1/k3
(정답률: 33%)
  • 30 CBT 기출문제AI

    2023-04-13 00:03

    스프링 상수값이 k2 = 2k1, k3 = k1 이므로, k2과 k3을 이용하여 상당 스프링 상수 k를 구할 수 있다.
    먼저, k2과 k3을 병렬 연결하여 k'1을 구한다.
    1/k'1 = 1/k2 + 1/k3
    1/k'1 = 1/2k1 + 1/k1
    1/k'1 = 3/2k1
    k'1 = 2/3k1
    그리고, k1과 k'1을 직렬 연결하여 k를 구한다.
    k = k1 + k'1
    k = k1 + 2/3k1
    k = 5/3k1
    따라서, 상당 스프링 상수 k는 "4k1"이 아닌 "5/3k1"이다.

    연삭력은 F = P / r로 계산할 수 있습니다. 여기서 r은 숫돌의 반지름입니다. 따라서 F = 20 / (r) kgf입니다. 이때 일의 양은 W = F x d x n입니다. 여기서 d는 연삭 깊이, n은 분당 회전수입니다. 연삭기에서는 일반적으로 d는 매우 작기 때문에 무시할 수 있습니다. 따라서 일의 양은 W = F x n입니다.

    입력인 소요동력은 P = W / t로 계산할 수 있습니다. 여기서 t는 작업 시간입니다. 따라서 t = W / P입니다.

    연삭기의 효율은 출력 / 입력으로 계산할 수 있습니다. 여기서 출력은 W x V / 60으로 계산할 수 있습니다. 따라서 효율은 (W x V / 60) / (P x t)입니다.

    이제 이 식에 값을 대입해 계산하면 효율은 약 65%가 됩니다. 이유는 연삭기에서는 일반적으로 연삭력이 입력으로 들어가는데, 이는 작업에 사용되는 일의 양과 직접적으로 관련이 있기 때문입니다. 따라서 연삭기의 효율은 일의 양과 직접적으로 관련이 있는 연삭력을 고려해야 합니다.
