12. 한 변의 길이가 20㎜인 정사각형 단면의 강재에 4000N의 압축하중이 작용할 때 강재의 내부에 발생하는 압축 응력은 몇 N/㎜2인가?

  1. 2
  2. 4
  3. 10
  4. 20
(정답률: 52%)
  • 30 CBT 기출문제AI

    2023-04-13 00:06

    압축 응력은 압력(P)을 단면적(A)으로 나눈 값으로 계산됩니다.

    압력은 압축하중(F)을 단면적(A)으로 나눈 값으로 계산됩니다.

    따라서,

    압력(P) = 압축하중(F) / 단면적(A)

    단면이 정사각형이므로, 단면적(A) = 한 변의 길이(l) x 한 변의 길이(l) = l^2

    압축하중(F) = 4000N

    한 변의 길이(l) = 20mm = 0.02m

    따라서,

    압력(P) = 4000N / (0.02m x 0.02m) = 4000N / 0.0004m^2 = 10,000,000N/m^2 = 10N/㎜^2

    따라서, 정답은 "10"입니다.

20. 지름이 50㎜인탄소강으로 스퍼기어를 가공할 때 절삭속도가 60m/min 이고 밀링커터의 지름이 35㎜일 때 회전수는 약 얼마인가?

  1. 546rpm
  2. 645rpm
  3. 725rpm
  4. 1000rpm
(정답률: 34%)
  • 30 CBT 기출문제AI

    2023-04-13 00:01

    회전속도(n)는 다음과 같이 구할 수 있습니다.

    n = (1000 x V) / (π x D)

    여기서, V는 절삭속도, D는 밀링커터의 지름입니다.

    따라서, n = (1000 x 60) / (π x 35) ≈ 546rpm

    1㎰은 1초에 1,000번의 처리를 할 수 있는 속도를 의미합니다. 따라서 1초를 1,000으로 나눈 값인 0.001초가 1㎰이 됩니다. 따라서 "1㎰ = 10-3 초"가 올바른 답입니다.

    1㎰ = 10-12초는 나노초 단위이며, 1㎱ = 10-6 초는 마이크로초 단위, 1㎲ = 10-9 초는 나노초 단위, 1㎳ = 10-2 초는 밀리초 단위입니다.
