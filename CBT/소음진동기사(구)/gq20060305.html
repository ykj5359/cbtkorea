5. 500Hz의 음이 수직 입사할 때 투과손실이 40dB인 단일 벽체의 면밀도는 몇 kg/m2인가?

  4. 64.2
(정답률: 알수없음)

    면밀도는 다음과 같은 공식으로 구할 수 있다.

    면밀도 = (2πfρd) / TL

    여기서, f는 주파수, ρ는 매질의 밀도, d는 벽체의 두께, TL은 투과손실을 나타내는 손실인자이다.

    주어진 값으로 공식을 대입하면,

    40 = 10log(TL)
    TL = 10^4

    면밀도 = (2πfρd) / TL
    = (2π × 500 × ρ × 1) / 10^4
    = 0.0314ρ

    따라서, 0.0314ρ = 28.3
    ρ = 28.3 / 0.0314
    = 900 kg/m^2

    따라서, 면밀도는 900 kg/m^2이다.

8. 다음 중 음압레벨의 대수비와 음의 세기레벨의 대수비와의 관계식으로 맞는 것은?

(정답률: 알수없음)

    2023-04-16 08:47

    정답은 ""이다.

    음압레벨과 음의 세기레벨은 모두 로그함수를 사용하여 계산된다. 음압레벨은 압력의 제곱에 비례하며, 음의 세기레벨은 파동의 에너지에 비례한다. 따라서, 음압레벨의 대수비와 음의 세기레벨의 대수비는 다음과 같은 관계식을 가진다.

    음압레벨 대수비 = 20log(P₁/P₂)

    음압레벨 대수비 = 2 × 음의 세기레벨 대수비

    이는 압력의 제곱이 파동의 에너지에 비례하기 때문에 성립한다.

  2. 60dB
  3. 63dB
  4. 67dB
(정답률: 알수없음)

    2023-04-16 08:47

    진동가속도레멜(VAL)은 다음과 같은 공식으로 계산된다.

    VAL = 20log10(a/a0)

    여기서 a는 측정된 진동가속도 진폭이고, a0은 기준 진동가속도 진폭이다. 일반적으로 a0은 1×10-6(m/sec2)으로 설정된다.

    따라서, 이 문제에서는 다음과 같이 계산할 수 있다.

    VAL = 20log10(2×10-2/1×10-6)
    = 20log10(2×104)
    = 20×4
    = 80

  1. 0.⑤
  2. 0.0785
  3. 0.1
  4. 0.125
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-16 08:47

    진동전달율은 진동의 크기가 얼마나 크게 전달되는지를 나타내는 비율이다. 이 문제에서는 정적처짐량이 주어졌으므로, 진동전달율을 구하기 위해서는 기계의 진동크기를 알아야 한다.

    진동크기는 기진력과 진동시스템의 물리적 특성에 의해 결정된다. 이 문제에서는 감쇠의 영향을 무시하므로, 진동크기는 기진력의 크기와 진동시스템의 고유진동수에 의해 결정된다.

    고유진동수는 진동시스템의 물리적 특성에 의해 결정되는 값으로, 이 문제에서는 주어지지 않았다. 하지만 각진동수가 주어졌으므로, 고유진동수와 각진동수 사이의 관계식을 이용하여 고유진동수를 구할 수 있다.

    고유진동수는 다음과 같이 구할 수 있다.

    ω = 2πf = 2π/T = 2π/√(k/m)

    여기서 k는 진동시스템의 탄성계수, m은 진동시스템의 질량이다. 이 식을 변형하면,

    k/m = (2π/ω)^2

    고유진동수는 탄성계수와 질량에 의해 결정되므로, 이 식을 이용하여 고유진동수를 구할 수 있다.

    고유진동수 = √(k/m) = √((2π/ω)^2) = 2π/ω

    따라서, 고유진동수는 2π/210 = 0.03 rad/sec이다.

    진동크기는 기진력과 고유진동수에 의해 결정되므로, 다음과 같이 구할 수 있다.

    진동크기 = 기진력/√(k/m)

    여기서, 기진력은 주어지지 않았지만, 정적처짐량이 주어졌으므로, 이를 이용하여 기진력을 구할 수 있다.

    기진력 = kx = mω^2x

    여기서, x는 정적처짐량이다. 따라서, 기진력은 다음과 같이 구할 수 있다.

    기진력 = mω^2x = (2π/210)^2 * 2 = 0.0009 N

    따라서, 진동크기는 다음과 같이 구할 수 있다.

    진동크기 = 기진력/√(k/m) = 0.0009/√((2π/0.03)^2) = 0.018 m

    진동전달율은 진동크기와 정적처짐량의 비율로 정의되므로, 다음과 같이 구할 수 있다.

    진동전달율 = 진동크기/x = 0.018/0.002 = 0.09

    따라서, 정답은 0.1이다.
