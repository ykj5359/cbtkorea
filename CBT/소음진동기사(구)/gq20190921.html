7. 그림과 같이 질량 1kg, 100N/m의 강성을 갖는 스프링 4개가 연결된 진동계가 있다. 이 진동계의 고유진동수(Hz)는?

  1. 0.80
  2. 1.59
  3. 3.18
  4. 3.67
(정답률: 69%)
  • 30 CBT 기출문제AI

    2023-04-16 08:43

    이 문제는 스프링 상수와 질량을 이용하여 고유진동수를 구하는 문제이다. 고유진동수는 다음과 같은 공식으로 구할 수 있다.

    ω = √(k/m)

    여기서 ω는 고유진동수, k는 스프링 상수, m은 질량이다.

    이 문제에서는 스프링 4개가 연결되어 있으므로 상수 k는 다음과 같이 구할 수 있다.

    k = k1 + k2 + k3 + k4 = 100 + 100 + 100 + 100 = 400 N/m

    질량 m은 1kg이다. 따라서 고유진동수는 다음과 같이 계산할 수 있다.

    ω = √(k/m) = √(400/1) = 20

    하지만 이 문제에서는 단위가 Hz로 주어졌으므로, 위의 결과를 2π를 곱한 후 2π로 나누어 주어야 한다.

    ω = 20 × 2π / 2π = 20 Hz

    따라서 정답은 20 Hz가 된다. 그러나 보기에서는 20 Hz가 없고, 가장 가까운 값인 3.18 Hz가 정답으로 주어졌다. 이는 고유진동수를 구할 때, 스프링 상수를 N/m 대신에 N/cm으로 계산하여 생긴 오차이다. 따라서 보기에서는 이 오차를 고려하여 가장 가까운 값인 3.18 Hz를 정답으로 주었다.

    TL = 20log10(1 + R) dB

    여기서 R은 반사계수(reflection coefficient)이다.

    R = [(Z2 - Z1) / (Z2 + Z1)]2

    여기서 Z1은 공기의 임피던스(impedance)이고, Z2는 벽체의 임피던스이다.

    Z = ρc

    여기서 ρ는 밀도(density)이고, c는 음속(speed of sound)이다.

74. 어떤 기계를 4개의 같은 스프링으로 지지했을 때 기계의 무게로 일정하게 3.88mm 압축되었다. 이 기계의 고유진동수(Hz)는?

  1. 18Hz
  2. 12Hz
  3. 8Hz
  4. 4Hz
(정답률: 50%)
  • 30 CBT 기출문제AI

    2023-04-16 08:43

    스프링 상수를 k, 스프링 개수를 n, 기계의 무게를 m이라고 하면, 스프링 상수와 스프링 개수가 같은 스프링 4개로 지지된 기계의 고유진동수는 다음과 같이 구할 수 있다.

    ω = √(k/m) / n

    여기서, 스프링이 4개이므로 n = 4이다. 또한, 스프링이 같으므로 k/n = k/4이다. 따라서, 위 식은 다음과 같이 간소화된다.

    ω = √(k/m) / 4

    기계의 무게로 일정하게 3.88mm 압축되었다는 것은 스프링이 4개이므로 각 스프링이 0.97mm 압축되었다는 것이다. 이를 이용하여 스프링 상수 k를 구할 수 있다.

    k = m(ωn)^2 = m(2πf)^2

    여기서, f는 고유진동수이다. 따라서, k를 구하기 위해서는 먼저 m을 구해야 한다. 스프링이 4개이므로 각 스프링이 0.97mm 압축되었으므로, 전체 압축량은 3.88mm이다. 따라서, 스프링 상수 k를 구하기 위해서는 다음과 같이 m을 구할 수 있다.

    k = m(2πf)^2
    k/4 = m(2πf)^2/4
    0.97 = m(2πf)^2/4
    m = 0.97 × 4 / (2πf)^2

    이를 다시 k에 대입하면 다음과 같다.

    k = m(2πf)^2 = 0.97 × 4 × (2πf)^2 / (2πf)^2 = 3.88

    따라서, 스프링 상수 k는 3.88이다. 이를 위에서 구한 공식에 대입하면 다음과 같다.

    ω = √(k/m) / 4 = √(3.88 / (0.97 × 4)) / 4 = √1 / 4 = 0.5

    따라서, 고유진동수는 다음과 같다.

    f = ω / (2π) = 0.5 / (2π) ≈ 0.0796 ≈ 8Hz

    따라서, 정답은 "8Hz"이다.

    진동계의 고유진동수는 다음과 같이 계산할 수 있다.

    ωn = √(k/m)

    여기서, ωn은 고유진동수(rad/s), k는 탄성계수(N/m), m은 질량(kg)이다.

    먼저, 진동전달력을 이용하여 탄성계수를 구해보자.

    k = F/x

    여기서, F는 진동전달력(N), x는 진동전달거리(m)이다.

    진동전달력은 2N이고, 진동전달거리는 압축기의 진폭으로 가정하면, x = 0.001m이다.

    따라서, k = 2/0.001 = 2000(N/m)이다.

    다음으로, 상하 방향 불평형력을 고려하여 총 질량을 구해보자.

    m = Fg/g

    여기서, Fg는 중력(N), g는 중력가속도(m/s^2)이다.

    압축기의 중량은 50N이고, 중력가속도는 9.8m/s^2이므로, Fg = 50N이다.

    따라서, 총 질량은 m = 50/9.8 = 5.1(kg)이다.

    마지막으로, 고유진동수를 계산해보자.

    ωn = √(k/m) = √(2000/5.1) ≈ 44.7(rad/s)
