14. 소음원의 PWL이 각각 69dB, 75dB, 79dB, 84dB일 때 소음의 POWER평균치는?

  1. 77dB
  2. 80dB
  3. 84dB
  4. 86dB
(정답률: 73%)
  • 30 CBT 기출문제AI

    2023-04-16 08:55

    각 소음원의 PWL은 데시벨로 표시되어 있으므로, 이를 파워로 변환해야 한다. 데시벨과 파워 간의 관계는 다음과 같다.

    PWL = 10 log(Power/10^-12)

    따라서, 파워는 다음과 같이 구할 수 있다.

    Power = 10^(PWL/10) x 10^-12

    각 소음원의 파워를 구하면 다음과 같다.

    Power1 = 10^(69/10) x 10^-12 = 1.995 x 10^-8
    Power2 = 10^(75/10) x 10^-12 = 1.995 x 10^-7
    Power3 = 10^(79/10) x 10^-12 = 7.943 x 10^-7
    Power4 = 10^(84/10) x 10^-12 = 6.310 x 10^-6

    이제 이들 파워의 평균값을 구하면 된다.

    (Power1 + Power2 + Power3 + Power4) / 4 = (1.995 x 10^-8 + 1.995 x 10^-7 + 7.943 x 10^-7 + 6.310 x 10^-6) / 4 = 1.998 x 10^-6

    이 파워를 다시 데시벨로 변환하면 다음과 같다.

    PWL = 10 log(1.998 x 10^-6 / 10^-12) = 10 log(1.998 x 10^6) = 80.0 dB
