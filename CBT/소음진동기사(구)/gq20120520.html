10. 10Hz 진동수를 갖는 조화진동의 속도 진폭이 5×10-3였다. 이 때, 수직진동레벨(VL, dB(V))은?

  1. 76
  2. 85
  3. 87
  4. 91
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-16 08:50

    VL(dB) = 20log10(A/A0) + 20log10(f/f0) + 94

    여기서 A는 진폭, f는 주파수, A0은 기준진폭(20μPa), f0은 기준주파수(1kHz)이다.

    따라서, 주어진 조건에서 VL을 계산하면:

    VL = 20log10((5×10-3)/20×10-6) + 20log10(10/1000) + 94

    = 20log10(250) + 20log10(0.01) + 94

    = 54 + (-20) + 94

    = 128 - 20

    = 108 dB

    하지만, 이것은 기준진폭이 20μPa일 때의 값이므로, 기준진폭이 1μPa일 때로 변환해야 한다.

    VL = 108 - 20log10(20/1)

    = 108 - 26

    = 82 dB

    따라서, 정답은 "85"가 아닌 "82"이다.

14. 가로, 세로, 높이가 각각 5m인 실내의 1차원 모드의 고유진동수는? (단, 실내의 벽체는 모두 강벽이고, 공기의 온도는 20℃ 이다.)

  1. 17.2Hz
  2. 21.5Hz
  3. 34.3Hz
  4. 42.9Hz
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-16 08:50

    1차원 모드에서 고유진동수는 다음과 같이 계산할 수 있다.

    f = (c/2L) * sqrt(n^2 + m^2 + p^2)

    여기서 c는 소리의 속도, L은 공간의 길이, n, m, p는 각각 x, y, z 방향의 진폭에 해당하는 자연수이다.

    따라서 이 문제에서는 다음과 같이 계산할 수 있다.

    c = 343m/s (20℃ 일 때의 속도)
    L = 5m
    n = 1, m = 0, p = 0 (1차원 모드에서는 한 방향으로만 진동하기 때문에)

    f = (343/2*5) * sqrt(1^2 + 0^2 + 0^2) = 34.3Hz

    따라서 정답은 "34.3Hz"이다.
