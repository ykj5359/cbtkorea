7. 등감각곡선에 기초하여 정해진 보정회로를 통한 진동레벨을 산출할 때 주파수대역이 1≤f≤4Hz인 경우 수직보정곡선의 보정치의 물리량(a)은?

  1. 0.315×10-5×f(m/s2)
  2. 10-5＞(m/s2)
  3. 0.125×10-5×f-0.25(m/s2)
  4. 2×10-5×f-0.5(m/s2)
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-16 08:54

    주어진 등감각곡선에서 1≤f≤4Hz인 주파수대역에서의 진동레벨을 산출하기 위해서는 수직보정곡선의 보정치를 알아야 한다. 수직보정곡선은 다음과 같은 식으로 주어진다.

    a = k1 + k2f + k3f^2

    여기서 k1, k2, k3은 상수이다. 주어진 보기 중에서 수식을 대입해보면,

    - 첫 번째 보기: a = 0.315×10^-5×f + k2f + k3f^2
    - 두 번째 보기: a = 10^-5 > 0.5 (f=0일 때 a가 0.5보다 크므로 불가능)
    - 세 번째 보기: a = 0.125×10^-5×f - 0.25 + k3f^2 (k2가 없으므로 불가능)
    - 네 번째 보기: a = 2×10^-5×f - 0.5

    따라서 정답은 "2×10^-5×f-0.5(m/s^2)"이다. 이는 주파수가 증가할수록 보정치가 증가하고, f=0일 때 보정치가 -0.5(m/s^2)인 것을 의미한다.

13. 음압이 35Pa이면 소리의 세기로 몇 W/m2인가?(단, 공기밀도는 1.2kg/m3, 음속은 344m/sec이다.)

  1. 4.5
  2. 3
  3. 1.5
  4. 1
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-16 08:54

    음압과 소리의 세기는 다른 물리량이므로 직접적인 변환은 불가능하다. 하지만 음압과 소리의 세기는 비례 관계에 있다. 따라서 음압이 2배가 되면 소리의 세기는 4배가 된다.

    음압이 35Pa일 때, 소리의 세기는 다음과 같이 구할 수 있다.

    음압의 크기는 소리의 압력 변화를 나타내므로, 소리의 압력 변화를 구하기 위해 음압에 -1을 곱해준다.

    압력 변화 = -1 x 35Pa = -35Pa

    소리의 압력 변화와 소리의 세기는 다음과 같은 관계가 있다.

    소리의 세기 = (압력 변화의 제곱) / (공기밀도 x 음속)

    공기밀도와 음속은 문제에서 주어졌으므로, 압력 변화의 제곱만 구하면 된다.

    압력 변화의 제곱 = (-35Pa)2 = 1225Pa2

    따라서, 소리의 세기 = 1225 / (1.2 x 344) = 3 W/m2

    정답은 "3"이다.
