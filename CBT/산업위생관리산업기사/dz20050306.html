14. PWC가 16kcal/min인 근로자가 1일 8시간 동안 물체 운반작업을 하고 있다. 이때의 작업대사량은 9kcal/min 이고, 휴식시의 대사량은 1.5 kcal/min 일 때 적절한 휴식시간은? (단, Hertig 식 적용)

  1. 14분 휴식, 46분 작업
  2. 18분 휴식, 42분 작업
  3. 22분 휴식, 38분 작업
  4. 29분 휴식, 31분 작업
(정답률: 50%)
  • 30 CBT 기출문제AI

    2023-04-16 06:59

    작업대사량이 9kcal/min 이므로, 8시간 동안의 작업량은 8 x 60 x 9 = 4,320 kcal 입니다. 이를 PWC로 환산하면 4,320 / 16 = 270 분이 됩니다.

    Hertig 식에 따라 적절한 휴식시간은 작업시간의 20~30% 정도이므로, 270분에 20~30%를 곱해보면 54~81분이 됩니다.

    하지만 이 문제에서는 휴식시의 대사량이 1.5 kcal/min 이므로, 실제 휴식시간은 더 길어져야 합니다. 따라서 29분 휴식, 31분 작업이 가장 적절한 휴식시간입니다.

    즉, 29분 동안 대사량은 1.5 kcal/min으로 계산되며, 이는 29 x 1.5 = 43.5 kcal 입니다. 따라서 실제 작업량은 4,320 - 43.5 = 4,276.5 kcal 이 되고, 이를 PWC로 환산하면 4,276.5 / 16 = 267.28 분이 됩니다. 이를 31분씩 나누면 약 8.6 회의 작업이 가능하므로, 29분 휴식, 31분 작업이 가장 적절한 휴식시간입니다.

  1. 약 13m3/분
  2. 약 23m3/분
  3. 약 33m3/분
  4. 약 43m3/분
(정답률: 16%)

    2023-04-16 06:59

    먼저, 억제농도는 377mg/m3 이므로, 톨루엔의 억제농도에서의 농도를 계산해야 한다.

    농도 = (증기압 / 대기압) x 92

    톨루엔의 증기압은 인터넷 검색을 통해 28.4mmHg 이므로, 대기압인 760mmHg을 이용하여 계산하면,

    농도 = (28.4 / 760) x 92 = 3.44mg/m3

    따라서, 전체환기를 통해 평균농도를 100ppm(377mg/m3)에서 3.44mg/m3로 낮추기 위해서는 다음과 같은 식을 이용할 수 있다.

    필요환기량 = (현재농도 - 목표농도) x 실내부피 / (60 x 농도차)

    따라서, 필요환기량 = (377 - 3.44) x 실내부피 / (60 x 373.56)

    양변에 60 x 373.56을 곱하면,

    필요환기량 x 60 x 373.56 = (377 - 3.44) x 실내부피

    필요환기량 = (377 - 3.44) x 실내부피 / (60 x 373.56)
