70. 닥트내에 흐르는 공기의 속도압이 4mmH2O이다. 닥트내의 유속은? (단, 공기의 비중량은 1.2kg/m3이다.)

  1. 5.7 m/sec
  2. 7.2 m/sec
  3. 8.1 m/sec
  4. 9.6 m/sec
(정답률: 50%)
  • 30 CBT 기출문제AI

    2023-04-16 07:04

    유체 역학에서, 속도압과 유속은 다음과 같은 관계가 있다.

    속도압 = 0.5 x 밀도 x 유속2

    따라서, 유속 = √(속도압 / (0.5 x 밀도))

    여기서, 속도압은 4mmH2O = 0.004 x 9.81 Pa = 39.24 Pa 이다. 또한, 공기의 비중량은 1.2kg/m3 이므로, 밀도는 1.2 kg/m3 x (1 m / 1000 mm)3 = 0.0012 kg/mm3 이다.

    따라서, 유속 = √(39.24 Pa / (0.5 x 0.0012 kg/mm3)) = 8.1 m/sec 이다.

    따라서, 정답은 "8.1 m/sec" 이다.

74. 90° 곡관의 내경에 대한 곡률반경비가 2.0일 때 압력손실계수는 0.27이다. 속도압이 14㎜H2O라면 이 곡관의 압력손실(㎜H2O)은?

  1. 3.78
  2. 4.20
  3. 4.42
  4. 7.41
(정답률: 46%)
  • 30 CBT 기출문제AI

    2023-04-16 07:04

    압력손실계수는 다음과 같이 주어진다.

    $$C = frac{Delta P}{frac{1}{2}rho V^2}$$

    여기서 $Delta P$는 압력손실, $rho$는 유체의 밀도, $V$는 유체의 속도이다. 이 문제에서는 속도압이 14㎜H2O로 주어졌으므로, 이를 유체의 속도로 변환해야 한다. 속도압과 유체의 속도는 다음과 같은 관계가 있다.

    $$P = frac{1}{2}rho V^2$$

    여기서 $P$는 속도압이고, $rho$는 유체의 밀도, $V$는 유체의 속도이다. 따라서 유체의 속도는 다음과 같다.

    $$V = sqrt{frac{2P}{rho}} = sqrt{frac{2 times 14}{1000}} approx 0.53 text{ m/s}$$

    곡률반경비가 2.0이므로, 곡률반경은 다음과 같다.

    $$R = frac{D}{2C} = frac{D}{4}$$

    여기서 $D$는 곡관의 내경이다. 따라서 곡률반경은 다음과 같다.

    $$R = frac{D}{4} = frac{2}{4} = 0.5 text{ m}$$

    압력손실계수가 0.27이므로, 압력손실은 다음과 같다.

    $$Delta P = C times frac{1}{2}rho V^2 = 0.27 times frac{1}{2} times 1000 times 0.53^2 approx 3.78 text{ mmH}_2text{O}$$

    따라서 정답은 "3.78"이다.
