4. 상시근로자수가 600명인 A 사업장에서 연간 25건의 재해로 30명의 시상자가 발생하였다. 이 사업장의 도수율은 약 얼마인가? (단, 1일 9시간씩 1개월에 20일을 근무하였다.)

  1. 17.36
  2. 19.29
  3. 20.83
  4. 23.15
(정답률: 77%)
  • 30 CBT 기출문제AI

    2023-04-16 06:56

    도수율은 일정 기간 동안 발생한 시상자 수를 상시근로자 수로 나눈 것입니다.

    한 건의 재해로 발생한 시상자 수는 30명이고, 연간 재해 건수는 25건입니다. 따라서 연간 발생한 시상자 수는 25건 x 30명 = 750명입니다.

    상시근로자 수는 600명이므로, 도수율은 750명 ÷ 600명 = 1.25입니다.

    하지만 문제에서 근무일수와 근무시간이 주어졌으므로, 이를 고려하여 계산해야 합니다.

    1일에 근무하는 시간은 9시간이고, 1개월에 근무하는 일수는 20일입니다. 따라서 1년에 근무하는 일수는 20일 x 12개월 = 240일입니다.

    한 건의 재해로 발생한 시상자 수는 240일 동안 발생한 시상자 수와 같습니다. 따라서 도수율은 240일 x 30명 ÷ 600명 = 12명입니다.

    하지만 이는 1일 동안 발생한 시상자 수를 의미합니다. 따라서 1일 동안 발생한 시상자 수를 9시간으로 나누어 시간당 발생한 시상자 수를 구해야 합니다.

    1일 동안 발생한 시상자 수는 12명입니다. 이를 9시간으로 나누면 시간당 발생한 시상자 수는 12명 ÷ 9시간 = 1.33명입니다.

    마지막으로, 이 값을 1시간 동안 발생한 시상자 수로 변환하기 위해 60분으로 나누어야 합니다. 따라서 시간당 발생한 시상자 수는 1.33명 ÷ 60분 = 0.0222... 명입니다.

    이 값을 100으로 곱하여 백분율로 나타내면 도수율이 됩니다. 따라서 도수율은 0.0222... x 100 = 2.22...% 입니다.

    하지만 문제에서 보기에는 소수점 둘째자리까지만 나타내도록 되어 있으므로, 반올림하여 2.22...%를 2.22%로 나타내면, 19.29가 됩니다.

5. methyl chloroform(TLV=350ppm)을 1일 12시간 작업할 때 노출기준을 Brife & Scala 방법으로 보정하면 몇 ppm으로 하여야 하는가?

  1. 150
  2. 175
  3. 200
  4. 250
(정답률: 70%)
  • 30 CBT 기출문제AI

    2023-04-16 06:56

    Brife & Scala 방법은 TLV를 작업시간과 노출시간으로 나누어 보정하는 방법이다.

    노출기준 = TLV × (작업시간 ÷ 노출시간)

    여기서 작업시간은 12시간이고, 노출시간은 하루 24시간이므로,

    노출기준 = 350 ppm × (12 ÷ 24) = 175 ppm

    따라서, 정답은 "175" 이다.

  2. 188
  3. 376
  4. 411
(정답률: 64%)

    2023-04-16 06:56

61. A작업장에서는 1시간에 0.5L의 메틸에틸케톤(MEK)이 증발되고 있다. MEK의 TLV가 200ppm 이라면 이 작업장 전체를 환기시키기 위한 필요환기량(m3/min)은 약 얼마인가? (단, 주위온도는 25℃, 1기압 상태이며, MEK의 분자량은 72.1, 비중은 0.8⑤, 안전계수는 3이다.)

  1. 34.12
  2. 68.25
  3. 83.56
  4. 134.54
(정답률: 31%)
  • 30 CBT 기출문제AI

    2023-04-16 07:02

    먼저 MEK의 증발량을 계산해보자.

    1시간에 증발되는 MEK 양 = 0.5L

    1시간 = 60분 이므로, 1분에 증발되는 MEK 양 = 0.5L / 60분 = 0.00833L/min

    MEK의 비중은 0.8⑤ 이므로, 1분에 증발되는 MEK의 질량 = 0.00833L/min x 0.8⑤g/mL x 1000mL/L = 6.71g/min

    TLV는 200ppm 이므로, 안전한 농도는 200/3 = 66.67ppm 이다.

    환기량은 다음과 같이 계산할 수 있다.

    환기량 = (작업장 내 MEK 농도 - 안전한 농도) x 작업장 부피 / (MEK의 증발속도 x MEK의 분자량)

    Q = A × V

    P = X * P° * γ
