  2. 0.73mg/m3
  3. 0.78mg/m3
  4. 0.85mg/m3
(정답률: 65%)
  • 30 CBT 기출문제AI

    안전흡수량은 체중kg당 0.1mg이므로, 성인근로자의 경우 안전흡수량은 0.1 x 75 = 7.5mg이다. 작업시 폐환기율은 1.2m3/h이므로, 8시간 작업시 폐출량은 1.2 x 8 = 9.6m3이다. 따라서, 안전흡수량을 유지하려면 9.6m3의 공기 중에 최대 7.5mg의 구리가 포함되어 있어야 한다. 이를 구하기 위해 구리농도를 x mg/m3이라고 가정하면, 9.6m3 x x mg/m3 = 7.5mg 이므로, x = 7.5mg / 9.6m3 = 0.78mg/m3이다. 따라서, 정답은 "0.78mg/m3"이다.
