7. 작업대사율(RMR)=7로 격심한 작업을 하는 근로자의 실동율(%)은? (단. 사이또와 오시마의 식을 이용한다.)

  2. 30
  3. 40
  4. 50
(정답률: 76%)
  • 30 CBT 기출문제AI

    2023-04-16 06:51

    작업대사율(RMR)이 7이라는 것은 근로자가 격심한 작업을 하고 있다는 것을 의미합니다. 이 때, 사이또와 오시마의 식을 이용하여 실동율(%)을 계산하면 다음과 같습니다.

    실동율(%) = (RMR + 10) x 1.5

79. 건조 공기가 원형식 관내를 흐르고 있다. 속도압이 6mmH2O이면 풍속은 얼마인가? (단, 건조공기의 비중량 1.2kgf/m3이며, 표준상태이다.)

  1. 5m/sec
  2. 10m/sec
  3. 15m/sec
  4. 20m/sec
(정답률: 52%)
  • 30 CBT 기출문제AI

    2023-04-16 06:51

    속도압은 다음과 같이 정의된다.

    속도압 = (1/2) x 밀도 x 속도의 제곱

    여기서 밀도는 건조공기의 비중량인 1.2kgf/m^3이고, 속도압은 6mmH2O이므로 다음과 같이 풀 수 있다.

    6mmH2O = (1/2) x 1.2kgf/m^3 x 속도의 제곱

    속도의 제곱 = (6mmH2O x 2) / 1.2kgf/m^3 = 10m^2/sec^2

    따라서 속도는 다음과 같다.

    속도 = √(10m^2/sec^2) = 10m/sec

    즉, 속도압이 6mmH2O일 때 풍속은 10m/sec이다.

80. 사염화에틸렌 2000ppm이 공기 중에 존재한다면 공기와 사염화에틸렌 혼합물의 유효비 중(effective specific gravity)은 얼마인가? (단, 사염화에틸렌의 증기비중은 5.7이다.)(오류 신고가 접수된 문제입니다. 반드시 정답과 해설을 확인하시기 바랍니다.)

  1. 1.094
  2. 1.823
  3. 2.342
  4. 3.783
(정답률: 42%)
  • 30 CBT 기출문제AI

    2023-04-16 06:51

    유효비 중은 혼합물의 밀도를 공기의 밀도로 나눈 값이다. 따라서, 공기와 사염화에틸렌 혼합물의 유효비 중은 다음과 같이 계산할 수 있다.

    유효비 중 = (공기의 밀도 + 사염화에틸렌의 밀도) / 공기의 밀도

    공기의 밀도는 1.0으로 가정할 수 있다. 사염화에틸렌의 밀도는 증기비중과 공기의 밀도를 곱한 값이므로 다음과 같이 계산할 수 있다.

    사염화에틸렌의 밀도 = 증기비중 x 공기의 밀도 = 5.7 x 1.0 = 5.7

    따라서, 유효비 중 = (1.0 + 5.7) / 1.0 = 6.7 / 1.0 = 1.094 이다.
