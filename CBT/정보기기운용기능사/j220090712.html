4. 전가산기의 C(자리올림 수)를 논리적으로 나타낸 것은?

  1. C = x + y + z
  2. C = x · y · z
  3. C = xy + yz + xz
  4. C = xy + (x ⊕ y) · z
(정답률: 67%)
  • 30 CBT 기출문제AI

    2023-04-12 19:00

    전가산기는 덧셈 연산을 수행하는 회로로, 입력으로 3개의 비트(x, y, z)를 받아서 합(s)과 자리올림(c)을 출력합니다. 자리올림은 이전 비트의 연산 결과에 영향을 받기 때문에, 다음과 같은 식으로 나타낼 수 있습니다.

    C = xy + (x ⊕ y) · z

    여기서 ⊕는 XOR 연산을 의미합니다. 이 식은 x와 y가 모두 1일 때 자리올림이 발생하고, x와 y 중 하나만 1일 때는 z에 따라 자리올림이 발생하거나 발생하지 않습니다. 따라서 이 식은 전가산기의 동작을 정확하게 나타내며, 다른 보기들은 전가산기의 동작과는 관련이 없습니다.

13. 5Ω의 저항 10개를 직렬로 연결한 합성 저항 값은 이것들을 병렬로 연결한 합성 저항 값의 몇 배가 되는가?

  1. 10
  2. 50
  3. 100
  4. 150
(정답률: 56%)
  • 30 CBT 기출문제AI

    2023-04-12 19:00

    저항을 직렬로 연결한 경우, 전체 저항은 각 저항의 합과 같습니다. 따라서 5Ω의 저항 10개를 직렬로 연결한 합성 저항 값은 5Ω x 10 = 50Ω 입니다.

    반면, 저항을 병렬로 연결한 경우, 전체 저항은 각 저항의 역수의 합의 역수와 같습니다. 따라서 5Ω의 저항 10개를 병렬로 연결한 합성 저항 값은 1 / (1/5 + 1/5 + 1/5 + 1/5 + 1/5 + 1/5 + 1/5 + 1/5 + 1/5 + 1/5) = 1 / (10/5) = 0.5Ω 입니다.

    따라서, 50Ω / 0.5Ω = 100 이므로, 정답은 "100" 입니다.
