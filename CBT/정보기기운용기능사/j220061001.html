8. 다음 불대수의 기본 관계 중 틀린 것은?

  1. X+0 = X
  2. X · 0 = 0
  3. X+1 = X
  4. X · 1 = X
(정답률: 73%)
  • 30 CBT 기출문제AI

    2023-04-12 18:57

    틀린 것은 "X+1 = X" 입니다. 이는 항등원(identity element)이 아니기 때문입니다. 항등원은 어떤 연산을 해도 값이 변하지 않는 원소를 말합니다. 예를 들어, 덧셈에서의 항등원은 0이고, 곱셈에서의 항등원은 1입니다. 따라서 "X+1 = X"는 항등원의 성질을 만족하지 않습니다.

    간단한 예시를 들어보면, X가 2라고 가정하면 "2+1=3"이지만 "2"와 같지 않기 때문에 항등원의 성질을 만족하지 않습니다.

    하지만 인터프리터 방식은 문법 오류를 쉽게 수정할 수 있고, 일부가 수정되어도 프로그램 전체를 수정할 필요가 없다는 장점이 있습니다.

12. 아래 회로에 전류 I를 흘렸을 때 30[W]의 전력이 소모되었다. 도선에 인가한 전류 I는 얼마인가?

  1. 1.2[A]
  2. 2.12[A]
  3. 3[A]
  4. 4.5[A]
(정답률: 79%)
  • 30 CBT 기출문제AI

    2023-04-12 18:57

    전력의 공식은 P = VI = I^2R 이므로, R = P/I^2 로 구할 수 있다. 주어진 회로에서 R = 10Ω + 5Ω = 15Ω 이므로, I = √(P/R) = √(30/15) = 2[A] 이다. 따라서, 인가한 전류 I는 "2[A]" 이다. 정답이 "3[A]" 인 이유는 오답이므로 설명할 수 없다.

36. 데이터 전송설로의 감쇠량에 대한 극소 조건이 성립되었을 때 선로의 특성 임피던스(Zo)는?(단, R : 저항, L : 인덕턴스, C : 캐래시턴스)

(정답률: 52%)
  • 30 CBT 기출문제AI

    2023-04-12 18:57

    V(z) = V(0) * e^(-alpha * z)
    I(z) = I(0) * e^(-alpha * z)

    여기서 alpha는 감쇠 상수를 나타내며, z는 전송선로 상의 위치를 나타냅니다.

    Zo = V(0) / I(0) = (V(z) * e^(alpha * z)) / (I(z) * e^(alpha * z))
    = V(z) / I(z)
    = sqrt((R + jwL) / (G + jwC))
    = sqrt(L / C)
