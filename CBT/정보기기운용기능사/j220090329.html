8. 불 대수의 기본 정리 중 옳지 않은 것은?

  1. X + 0 = X
  2. X · 0 = X
  3. X + 1 = 1
  4. X · 1 = X
(정답률: 75%)
  • 30 CBT 기출문제AI

    2023-04-12 19:00

    정답: X + 1 = 1

    X + 1 = 1은 항등원 1을 더했을 때 X가 되는 것이 아니라, 항등원 1을 더했을 때 X + 1이 되는 것이 맞는 식입니다.

    X · 0 = X는 곱셈의 분배법칙에 의해 X · 0 = (X · 1) · 0 = X · (1 · 0) = X · 0 = 0이 되는데, 이는 0은 어떤 수를 곱해도 0이 되기 때문입니다. 따라서 X · 0 = X는 옳지 않은 식입니다.
1

14. 다음 중 2[J]과 같은 것은?

(정답률: 67%)
  • 30 CBT 기출문제AI

    2023-04-12 19:00

    2[J]은 일의 단위인 줄 알겠지만, 실제로는 일의 단위인 제곱미터-킬로그램-초(m²·kg·s⁻²)의 단위를 가지고 있습니다. 따라서, 보기 중에서 일의 단위인 제곱미터-킬로그램-초(m²·kg·s⁻²)의 단위를 가지고 있는 것은 "2[W · sec]" 뿐입니다. 여기서 W는 와트(Watt)로, 일의 단위인 제곱미터-킬로그램-초(m²·kg·s⁻²)의 단위를 가지는 에너지의 단위인 제곱미터-킬로그램-초(m²·kg·s⁻³)의 단위를 가지는 파워(Power)와 시간의 곱인 제곱미터-킬로그램-초(m²·kg·s⁻²)의 단위를 가지는 에너지량(Energy)의 단위인 제곱미터-킬로그램-초(m²·kg·s⁻²)의 단위를 가지고 있습니다. 따라서, 2[W · sec]는 일의 단위인 제곱미터-킬로그램-초(m²·kg·s⁻²)의 단위를 가지고 있으므로 정답입니다.
