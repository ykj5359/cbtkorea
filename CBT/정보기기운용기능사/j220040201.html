  2. A · (B + C)
  3. B · (A + C)
  4. C · (A + B)
(정답률: 86%)
  • 30 CBT 기출문제AI

    2023-04-12 19:06

    A · (A · B + C)를 분배법칙에 따라 간략화하면 A · A · B + A · C가 됩니다. 여기서 A · A는 A의 제곱이므로 A와 같습니다. 따라서 A · (A · B + C)는 A · B + A · C와 같습니다. 이를 다시 분배법칙에 따라 간략화하면 A · (B + C)가 됩니다. 따라서 정답은 "A · (B + C)"입니다.

17. 컴퓨터에서 프롬프트가 A일 때 C 디스크의 화일 목록을 보려 한다. 이때 사용해야 할 명령형식으로 맞는 것은?

  1. dir C:
  2. dir/p
  3. C:
  4. dir/w
(정답률: 81%)
  • 30 CBT 기출문제AI

    2023-04-12 19:06

    정답은 "dir C:"입니다.

    "dir"은 디렉토리(폴더) 내의 파일 목록을 보여주는 명령어입니다. "C:"는 C 드라이브를 의미합니다. 따라서 "dir C:"는 C 드라이브의 파일 목록을 보여주는 명령어입니다.

    다른 보기들은 다음과 같습니다.

    - "dir/p": 파일 목록을 페이지별로 보여줍니다.
    - "C:": C 드라이브로 이동하는 명령어입니다.
    - "dir/w": 파일 목록을 넓게(wide) 보여줍니다.
