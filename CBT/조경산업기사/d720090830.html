77. 살충제 50% 유제 100cc를 0.⑤%로 희석하고자 할 때 요구되는 물의 양은? (단, 비중은 1 이다.)

  2. 90 L
  3. 99 L
  4. 99.9 L
(정답률: 46%)
  • 30 CBT 기출문제AI

    2023-04-18 08:50

    살충제 50% 유제 100cc를 0.⑤%로 희석하려면, 다음과 같은 식을 사용할 수 있다.

    (원래 농도) x (원래 용량) = (새로운 농도) x (새로운 용량)

    여기서, 원래 농도는 50%, 원래 용량은 100cc, 새로운 농도는 0.⑤%, 새로운 용량은 x (물의 양) 이다.

    따라서, 식을 풀면 다음과 같다.

    0.5 x 100 = 0.00⑤ x x

    x = (0.5 x 100) / 0.00⑤

    x = 100,000 / 0.5

    x = 200,000

    즉, 200,000cc의 물이 필요하다. 이를 리터로 환산하면 200L이 된다. 하지만, 비중이 1이므로 1L의 물의 무게는 1kg이다. 따라서, 200L의 물의 무게는 200kg이 된다. 이를 다시 1000으로 나누면 200,000g이 되고, 이를 1000으로 나누면 200kg이 된다. 따라서, 정답은 "99.9 L"이 된다.
