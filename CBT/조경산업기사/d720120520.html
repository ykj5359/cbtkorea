3. 축척 1/2500, 1/25000 지형도의 주곡선 간격은 각각 몇 m인가?

  3. 5m, 20m
  4. 10m, 10m
(정답률: 84%)

    축척 1/2500 지형도에서 1cm는 실제로 2500cm(=25m)를 나타내므로, 주곡선 간격이 1cm인 경우 실제 거리는 25m이 된다. 따라서 주곡선 간격이 2cm인 경우 실제 거리는 50m이 되므로, 주곡선 간격은 2m가 아닌 50m가 된다.

    4πm² + (2/3)πm³ ≤ x

    x ≥ 4πm² + (2/3)πm³ ≈ 84.78m³
