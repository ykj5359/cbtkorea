5. 상업지역 이용인구 40,000명, 1인당 평균상면적 15m, 건폐율 50%, 공공용지율 40%, 평균층수가 10층인 경우 상업지역의 소요면적은?

  1. 20.0 ha
  2. 15.8 ha
  3. 12.5 ha
  4. 10.0 ha
(정답률: 59%)
  • 30 CBT 기출문제AI

    2023-04-15 17:43

    상업지역의 소요면적은 다음과 같이 계산할 수 있습니다.

    1. 건축면적 계산
    건축면적 = 이용인구 수 x 1인당 평균상면적
    건축면적 = 40,000명 x 15m²
    건축면적 = 600,000m²

    2. 용지면적 계산
    용지면적 = 건축면적 / 건폐율
    용지면적 = 600,000m² / 50%
    용지면적 = 1,200,000m²

    3. 공공용지 면적 계산
    공공용지 면적 = 용지면적 x 공공용지율
    공공용지 면적 = 1,200,000m² x 40%
    공공용지 면적 = 480,000m²

    4. 총 소요면적 계산
    총 소요면적 = 용지면적 + 공공용지 면적
    총 소요면적 = 1,200,000m² + 480,000m²
    총 소요면적 = 1,680,000m²

    5. 평형수 계산
    평형수 = 총 소요면적 / 10,000m²
    평형수 = 1,680,000m² / 10,000m²
    평형수 = 168

    따라서, 상업지역의 소요면적은 20.0 ha가 됩니다.
