11. 교류 용접기에서 2차 무부하 전압 80V, 아크전압 30V, 아크전류 300A라고 하면 역률은 약 몇 %인가? (단, 용접기의 2차측 내부손실(등손, 철손, 그 밖의 손)은 4kW로 한다.)

  1. 69
  2. 54
  3. 48
  4. 26
(정답률: 48%)
  • 30 CBT 기출문제AI

    2023-04-12 10:36

    역률은 유효전력과 피상전력의 비율로 정의된다. 여기서 유효전력은 실제로 용접에 사용되는 전력이고, 피상전력은 용접기에서 소비되는 전력이다. 따라서 역률은 다음과 같이 계산할 수 있다.

    유효전력 = 아크전압 x 아크전류 = 30V x 300A = 9000W
    피상전력 = 2차 무부하 전압 x 아크전류 + 내부손실 = 80V x 300A + 4000W = 244000W

    따라서 역률은 유효전력 / 피상전력 x 100% = 9000W / 244000W x 100% = 3.69% 이다.

    하지만 이 문제에서는 단순히 2차측 내부손실을 더해주면 된다고 하였으므로, 피상전력은 다음과 같이 계산할 수 있다.

    피상전력 = 2차 무부하 전압 x 아크전류 = 80V x 300A = 24000W

    따라서 역률은 유효전력 / 피상전력 x 100% = 9000W / 24000W x 100% = 37.5% 이다.

    하지만 이 문제에서는 교류 용접기의 역률을 구하는 것이므로, 역률은 보통 50% 이상이 된다. 따라서 가장 가까운 값인 54%가 정답이 된다.
