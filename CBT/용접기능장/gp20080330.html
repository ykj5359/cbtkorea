44. 그림과 같은 맞대기 용접시 P = 6000kgf의 하중으로 잡아당겼을 때 모재에 발생 되는 인장응력은 몇 kgf/mm2인가?

  1. 20
  2. 30
  3. 40
  4. 50
(정답률: 61%)
  • 30 CBT 기출문제AI

    2023-04-12 10:35

    맞대기 용접에서 인장응력은 하중(P)을 단면적(A)으로 나눈 값으로 구할 수 있습니다.

    인장응력 = P/A

    이때, 단면적은 맞대기 용접의 경우 용접면적으로 대체할 수 있습니다.

    따라서, 맞대기 용접의 용접면적을 구해보겠습니다.

    용접면적 = (a+b) × t

    = (50+50) × 10

    = 1000mm²

    맞대기 용접의 용접면적은 1000mm²입니다.

    그리고 주어진 하중은 6000kgf이므로,

    인장응력 = P/A

    = 6000kgf / 1000mm²

    = 6kgf/mm²

    따라서, 모재에 발생되는 인장응력은 6kgf/mm²이며, 보기 중에서 이에 해당하는 답은 "30"이 아닌 "20"입니다.

55. C 관리도에서 k = 20인 군의 총부적합(결점)수 합계는 58이었다. 이 관리도의 UCL, LCL을 구하면 약 얼마인가?

  1. UCL = 6.92, LCL = 0
  2. UCL = 4.90, LCL = 고려하지 않음
  3. UCL = 6.92, LCL = 고려하지 않음
  4. UCL = 8.01, LCL = 고려하지 않음
(정답률: 53%)
  • 30 CBT 기출문제AI

    2023-04-12 10:35

    C 관리도에서 k = 20이므로, 평균적으로 부적합(결점)수는 k/2 = 10이다. 따라서 이 관리도에서는 군의 총부적합수가 평균보다 많이 발생한 것으로 볼 수 있다.

    C 관리도의 UCL과 LCL은 다음과 같이 계산된다.

    UCL = 평균 + 3*표준편차
    LCL = 평균 - 3*표준편차

    하지만 이 문제에서는 LCL을 구할 수 없다고 가정한다. 그 이유는 LCL은 항상 0 또는 음수가 되기 때문이다. 만약 LCL이 0보다 큰 양수가 나온다면, 그것은 이 관리도가 잘못된 것이다.

    따라서 정답은 "UCL = 8.01, LCL = 고려하지 않음"이다.
