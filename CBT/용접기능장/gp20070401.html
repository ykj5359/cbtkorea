59. 다음 중 관리의 사이클을 가장 올바르게 표시한 것은?(단, A: 조치. C: 검토, D: 실행, P: 계획)

  1. P → C → A → D
  2. P → A → C → D
  3. A → D → C → P
  4. P → D → C → A
(정답률: 68%)
  • 30 CBT 기출문제AI

    2023-04-12 10:34

    정답은 "P → D → C → A" 입니다.

    이유는 다음과 같습니다.

    1. 계획 (Plan) : 목표를 설정하고, 그 목표를 달성하기 위한 계획을 수립합니다.
    2. 실행 (Do) : 계획에 따라 실제로 일을 수행합니다.
    3. 검토 (Check) : 일을 수행한 결과를 평가하고, 문제점을 파악합니다.
    4. 조치 (Act) : 문제점을 해결하기 위한 조치를 수립하고, 다시 계획 단계로 돌아가서 개선합니다.
