    - SIGTSTP: Ctrl + Z를 누르면 발생하는 시그널로, 현재 실행 중인 프로세스를 일시 중지시키는 시그널입니다. 이후에 해당 프로세스를 다시 실행시키기 위해서는 "fg" 명령어를 사용해야 합니다.

    - SIGTERM: 프로세스에게 종료를 요청하는 시그널로, 해당 프로세스가 종료될 때까지 기다립니다.

    - SIGQUIT: Ctrl + 를 누르면 발생하는 시그널로, 해당 프로세스를 종료시키고 코어 덤프(core dump) 파일을 생성합니다.

    따라서, 할당된 번호 값이 가장 큰 시그널은 SIGQUIT이지만, 일시 중지시키는 시그널을 찾는 문제이므로 SIGTSTP가 정답입니다.
