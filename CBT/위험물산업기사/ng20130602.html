3. 730mmHg, 100℃에서 257mL 부피의 용기 속에 어떤 기체가 채워져 있다. 그 무게는 1.671g 이다. 이 물질의 분자량은 약 얼마인가?

  1. 28
  2. 56
  3. 207
  4. 257
(정답률: 76%)
  • 30 CBT 기출문제AI

    2023-04-17 09:26

    이 문제는 이상기체 법칙을 이용하여 풀 수 있다.

    PV = nRT

    여기서 P는 압력, V는 부피, n은 몰수, R은 기체상수, T는 절대온도를 나타낸다.

    먼저 압력과 온도를 주어진 단위에 맞게 변환해준다.

    730mmHg = 0.961 atm
    100℃ = 373K

    그리고 부피를 리터 단위로 변환해준다.

    257mL = 0.257L

    이제 이상기체 법칙을 이용하여 몰수를 구할 수 있다.

    n = (PV) / (RT)
    n = (0.961 atm * 0.257L) / (0.0821 L·atm/mol·K * 373K)
    n = 0.0101 mol

    무게와 몰수를 이용하여 분자량을 구할 수 있다.

    분자량 = 무게 / 몰수
    분자량 = 1.671g / 0.0101 mol
    분자량 = 165.5 g/mol

    하지만 이 문제에서는 분자량이 보기에 없다. 그러므로 우리는 보기에서 분자량을 찾아야 한다.

    207은 분자량이다. 이것은 무엇을 의미할까?

    이 문제에서 사용된 물질은 탄소(C)와 수소(H)로 이루어진 화합물일 것이다. 이러한 화합물 중에서 분자량이 207인 것은 C14H9Cl5일 것이다. 그러나 이 화합물은 이 문제에서 언급되지 않았으므로 이것은 정답이 될 수 없다.

    따라서, 정답은 보기에서 찾을 수 없다.

18. CuSO4 수용액을 10A 의 전류로 32분 10초 동안 전지분해시켰다. 음극에서 석출되는 Cu 의 질량은 몇 g 인가? (단, Cu 의 원자량은 63.6이다.)

  1. 3.18
  2. 6.36
  3. 9.54
  4. 12.72
(정답률: 61%)
  • 30 CBT 기출문제AI

    2023-04-17 09:26

    전지분해 법칙에 따라 전류와 시간에 비례하여 전해되는 물질의 양이 결정된다. 따라서 전류와 시간을 곱한 값을 이용하여 CuSO4의 전해 양을 구할 수 있다.

    전류 = 전해 양 / 시간

    전해 양 = 전류 x 시간

    전류 = 10A, 시간 = 32분 10초 = 1930초

    전해 양 = 10A x 1930초 = 19300C

    CuSO4의 분자량 = 63.5 + 32.1 + 4x16.0 = 159.6g/mol

    CuSO4 1몰에 대한 Cu의 몰수는 1:1이므로 전해된 전하량을 Cu의 몰수로 환산하여 질량을 구할 수 있다.

    전하량 = 전해 양 / 전하의 양 = 19300C / 2 = 9650C (Cu의 전하량은 2)

    몰수 = 전하량 / 전하수 = 9650C / 96500C/mol = 0.1mol

    질량 = 몰수 x 분자량 = 0.1mol x 63.6g/mol = 6.36g

    따라서, CuSO4 수용액을 10A의 전류로 32분 10초 동안 전지분해시켰을 때 음극에서 석출되는 Cu의 질량은 6.36g이다.
