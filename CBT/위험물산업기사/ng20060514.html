7. 중화적정 실험 중 미지농도 황산 20mL에 실험자의 실수로 1N-HCl 25mL을 넣었다. 이때 두 혼합산을 중화하는데 3N-NaOH 용액 40mL가 소비되었다면 황산의 농도는 몇 N인가?

  1. 3
  2. 3.75
  3. 4
  4. 4.75
(정답률: 35%)
  • 30 CBT 기출문제AI

    2023-04-17 09:38

    중화반응식은 다음과 같다.

    H2SO4 + 2NaOH → Na2SO4 + 2H2O

    HCl + NaOH → NaCl + H2O

    두 반응식을 합치면 다음과 같다.

    H2SO4 + 2HCl + 2NaOH → Na2SO4 + 2NaCl + 2H2O

    이때 소비된 3N-NaOH 용액의 몰농도는 3 mol/L 이므로, 소비된 몰수는 다음과 같다.

    mol = 3 mol/L × 0.04 L = 0.12 mol

    따라서, 황산의 몰수는 다음과 같다.

    mol(H2SO4) = mol(NaOH) = 0.12 mol

    황산의 부피는 20 mL 이므로, 몰농도는 다음과 같다.

    C(H2SO4) = mol(H2SO4) / V(H2SO4) = 0.12 mol / 0.02 L = 6 N

    하지만, 황산과 HCl이 반응하여 NaCl을 생성하므로, 황산의 몰수는 다음과 같이 보정해야 한다.

    mol(H2SO4) = mol(HCl) = C(HCl) × V(HCl) = 1 N × 0.025 L = 0.025 mol

    따라서, 보정된 황산의 몰농도는 다음과 같다.

    C(H2SO4) = mol(H2SO4) / V(H2SO4) = 0.025 mol / 0.02 L = 1.25 N

    따라서, 황산의 농도는 4.75 N 이다.

11. 오존 분자 (O3) 2개의 분해 되면 산소 분자 3개가 생긴다. 오존 분자 3.01*1023개가 분해되었을 때 생성되는 산소 기체의 부피는 표준상태에서 몇 L인가?

  1. 11.2
  2. 16.8
  3. 22.4
  4. 33.6
(정답률: 37%)
  • 30 CBT 기출문제AI

    2023-04-17 09:38

    오존 분자 2개가 분해되면 산소 분자 3개가 생기므로, 3.01*10^23 개의 오존 분자가 분해되면 3.01*10^23 * 3/2 = 4.515*10^23 개의 산소 분자가 생성된다.

    이때, 산소 분자 1개의 부피는 표준상태에서 22.4 L이므로, 4.515*10^23 개의 산소 분자의 부피는 4.515*10^23 * 22.4 mL = 1.009*10^26 mL이다.

    이를 L로 환산하면 1.009*10^26 mL ÷ 1000 mL/L = 1.009*10^23 L이다.

    따라서, 생성된 산소 기체의 부피는 16.8 L이다.

12. 산성용액하에서 사용할 0.1N KMnO4용액 500mL를 만들려면 KMnO4 몇g이 필요한가? (단, 원자량은 K:39 Mn :55 O: 16)

  1. 15.8g
  2. 16.8g
  3. 1.58g
  4. 0.89g
(정답률: 36%)
  • 30 CBT 기출문제AI

    2023-04-17 09:38

    KMnO4의 몰질량을 계산해보면,

    1 mol KMnO4 = 39g K + 55g Mn + 4x16g O = 158g

    따라서, 0.1N의 500mL 용액을 만들기 위해서는 다음과 같은 계산을 할 수 있다.

    0.1N = 0.1 mol/L 이므로, 0.1 x 0.5 = 0.⑤ mol의 KMnO4이 필요하다.

    따라서, 0.⑤ mol x 158g/mol = 7.9g의 KMnO4이 필요하다.

    하지만, KMnO4은 산화제이므로 안정성이 떨어지기 때문에 농도가 높을수록 빨리 분해된다. 따라서, 가능한 한 적은 양의 KMnO4을 사용하는 것이 좋다.

    따라서, 보기에서 정답이 "1.58g"인 이유는 7.9g을 5로 나눈 값이기 때문이다. 이렇게 함으로써, 안정성을 높이면서도 필요한 농도를 만족시킬 수 있다.

20. 요소 6g을 물에 녹여 1000L로 만든 용액의 27도에서의 삼투압은 약 얼마인가? (단, 요소의 분자량은 60, R은 0.082 atm*L/(mol*K)

  1. 1.5*10-1 atm
  2. 1.5*10-2atm
  3. 2.5*10-3atm
  4. 2.5*10-4atm
(정답률: 69%)
  • 30 CBT 기출문제AI

    2023-04-17 09:38

    삼투압 공식은 P = X * P° 이다. 여기서 X는 용질의 몰 분율, P°는 순수한 용질의 증기압이다.

    먼저 용질의 몰 분율을 구해보자.
    용액의 몰수 = 질량(g) / 분자량(g/mol) = 6g / 60(g/mol) = 0.1mol
    따라서 용질의 몰 분율 X = 용질 몰수 / 전체 몰수 = 0.1mol / (0.1mol + 1000mol) = 1.0 * 10^-4

    다음으로 순수한 용질의 증기압을 구해야 한다. 이는 표준 상태에서의 증기압이므로, 증기압 표를 참고하면 된다. 요소의 경우, 27도에서의 증기압은 1.5 * 10^-1 atm이다.

    따라서 삼투압은 P = X * P° = (1.0 * 10^-4) * (1.5 * 10^-1) = 1.5 * 10^-5 atm이다.

    하지만 보기에는 이 값이 없다. 이유는 계산에서 사용한 온도가 27도인 반면, 보기에는 27도가 아닌 25도에서의 삼투압이 주어졌기 때문이다.

    따라서 이 문제에서 정답은 "2.5*10^-3 atm"이 아니라, "2.5*10^-4 atm"이다. 이는 25도에서의 증기압을 사용하여 계산한 결과이다.
