  1. 40
  2. 46
  3. 78
  4. 121

    이 문제는 기체상태방정식을 이용하여 풀 수 있습니다.

    PV = nRT

    여기서 P는 압력, V는 부피, n은 몰수, R은 기체상수, T는 온도입니다.

    먼저, 압력과 온도를 주어진 값으로 변환합니다.

    97℃ = 370K
    740mmHg = 98.7kPa

    n = PV/RT = (98.7 × 0.08) / (8.31 × 370) = 0.002

    몰질량 = 질량 / 몰수 = 0.2 / 0.002 = 100

    따라서, 이 액체의 분자량은 100/2 = 50입니다.

2. 원자량이 56인 금속 M 1.12g을 산화시켜 실험식이 MxOy인 산화물 1.60g을 얻었다. x, y는 각각 얼마인가?

  1. x = 1, y = 2
  2. x = 2, y = 3
  3. x = 3, y = 2
  4. x = 2, y = 1
(정답률: 79%)
  • 30 CBT 기출문제AI

    2023-04-17 09:21

    금속 M의 몰질량은 56g/mol이므로, 1.12g의 질량은 0.02몰에 해당한다. 산화물의 질량인 1.60g에서 산소의 질량을 빼면 금속의 질량이 된다. 산소의 질량은 실험식에서 M의 원자량을 y로 나눈 후, y에 16을 곱한 값이다. 따라서,

    금속의 질량 = 1.60g - (y/16) * 56g/mol

    실험에서 얻은 산화물의 질량은 1.60g이므로, 이를 실험식에서 각 원소의 몰질량으로 환산하면 다음과 같다.

    M의 몰질량 * x + 16 * y = 1.60g

    위 식에서 M의 몰질량은 56g/mol이므로,

    56g/mol * x + 16 * y = 1.60g

    이제 위 두 식을 연립하여 x와 y를 구할 수 있다.

    56g/mol * x + 16 * y = 1.60g
    56g/mol * x + 56g/mol * (y/16) * 2 = 1.60g
    56g/mol * x + 7g/mol * y = 0.20g

    여기서 x와 y는 모두 정수이므로, y를 1부터 차례대로 대입해보면서 x와 y가 모두 정수인 경우를 찾아볼 수 있다. y=2일 때, x=1.5가 나오므로 정수가 아니다. y=3일 때, x=2가 나오므로 x=2, y=3이 정답이다.

    따라서, x=2, y=3이 정답이다.

    농도는 몰농도를 의미하며, 몰농도는 몰질량을 용액의 부피로 나눈 값이다. 따라서, 황산의 몰질량을 계산해야 한다.

    황산의 몰질량 = 98g / 98g/mol = 1 mol

    용액의 부피 = 400mL = 0.4 L

    농도 = 몰질량 / 용액의 부피 = 1 mol / 0.4 L = 2.5 N

    따라서, 정답은 "5"가 아닌 "2.5"이다.

    OH⁻ 농도를 이용하여 pOH 구하기
    OH⁻ 농도가 1 × 10⁻⁵ mol/L이 주어졌을 때, pOH는 다음 공식을 통해 구할 수 있습니다:

    pOH = −log [OH−]

    pOH = −log (1×10-5)=5

    pH+pOH=14

    pH = 14 − pOH

  3. 27.4

    이 문제는 기체 상태 방정식을 이용하여 풀 수 있습니다. 기체 상태 방정식은 PV = nRT로 표현됩니다. 여기서 P는 압력, V는 부피, n은 몰수, R은 기체 상수, T는 절대온도를 나타냅니다.

    먼저, 문제에서 주어진 조건을 바탕으로 기체 상태 방정식을 적용해보겠습니다. 압력은 1기압, 온도는 27℃ = 300K입니다. 몰수는 아세톤의 질량을 분자량으로 나눈 값으로 계산할 수 있습니다. 아세톤의 분자량은 58g/mol이므로, 몰수는 58g/58g/mol = 1mol입니다. 기체 상수 R은 0.0821 L·atm/mol·K입니다.

    따라서, PV = nRT를 이용하여 부피 V를 구할 수 있습니다.

    V = nRT/P = (1mol)(0.0821 L·atm/mol·K)(300K)/(1atm) = 24.6 L

    따라서, 아세톤 58g을 완전히 기화시키면 부피는 약 24.6 L가 됩니다.
