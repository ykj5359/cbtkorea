  2. 8/5
  3. 12/5
  4. 16/5
(정답률: 55%)
  • 30 CBT 기출문제AI

    2023-04-17 09:29

    가스의 상태방정식인 PV=nRT를 이용하여 계산할 수 있다.

    먼저, 수소와 산소의 몰 수를 구해보자.
    수소의 경우, P=2기압, V=2L, T=일정 온도, R=기체상수이므로,
    n(H2) = (P x V) / (R x T) = (2 x 2) / (0.082 x T) = 48.78 / T (단위: mol)

    산소의 경우, P=3기압, V=4L, T=일정 온도, R=기체상수이므로,
    n(O2) = (P x V) / (R x T) = (3 x 4) / (0.082 x T) = 146.34 / T (단위: mol)

    따라서, 전체 몰 수는 n(H2) + n(O2) = 48.78/T + 146.34/T = 195.12/T (단위: mol) 이다.

    전체 용기의 부피는 5L 이므로, 전체 몰 수에 대한 전체 압력은 다음과 같다.
    P = (n(H2) + n(O2)) x (R x T) / V = (195.12/T) x (0.082 x T) / 5 = 16.136/5 (단위: 기압)

    따라서, 정답은 "16/5" 이다.

5. 0.1N HCl 100mL 용액에 수산화나트륨 0.32g 을 넣고 물을 첨가하여 1L로 만든 용액의 pH 값은 약 얼마인가?

  1. 1.7
  2. 2.7
  3. 3.7
  4. 4.7
(정답률: 41%)
  • 30 CBT 기출문제AI

    2023-04-17 09:30

    먼저, 수산화나트륨(NaOH)이 HCl와 반응하여 NaCl와 물(H2O)이 생성됩니다.

    NaOH + HCl → NaCl + H2O

    따라서, NaOH의 몰수를 계산해야합니다.

    0.32g NaOH ÷ 40g/mol NaOH = 0.008 mol NaOH

    그리고, 용액의 총 몰수를 계산해야합니다.

    0.1N HCl = 0.1 mol/L HCl

    따라서, 100mL 용액의 몰수는 다음과 같습니다.

    0.1 mol/L × 0.1 L = 0.01 mol HCl

    NaOH와 HCl의 몰비는 다음과 같습니다.

    0.008 mol NaOH ÷ 0.01 mol HCl = 0.8

    따라서, NaOH는 HCl보다 약 0.8배 많이 첨가되었습니다. 이는 용액의 pH를 산성에서 약간 더 중성으로 이동시킵니다.

    pH = -log[H+]

    HCl의 경우, 0.1N 용액에서 [H+]는 0.1 mol/L입니다.

    NaOH가 첨가되면, NaOH와 HCl의 반응으로 생성된 NaCl은 중성이므로 [H+]는 변하지 않습니다. 따라서, [H+]는 여전히 0.1 mol/L입니다.

    하지만, NaOH가 첨가되면 NaOH와 물(H2O)의 반응으로 [OH-]가 생성됩니다.

    NaOH + H2O → Na+ + OH-

    NaOH의 몰수는 0.008 mol이므로, [OH-]의 몰수는 0.008 mol/L입니다.

    따라서, pOH는 다음과 같습니다.

    pOH = -log[OH-] = -log(0.008) = 2.1

    pH와 pOH는 다음과 같은 관계가 있습니다.

    pH + pOH = 14

    따라서, pH는 다음과 같습니다.

    pH = 14 - pOH = 14 - 2.1 = 11.9

    따라서, 보기에서 정답은 "2.7"이 아닌 "11.9"입니다.

8. CuCl2의 용액에 5A 전류를 1시간 동안 흐르게 하면 몇 g의 구리가 석출되는가? (단, Cu의 원자량은 63.54 이며 전자 1개의 전하는 1.602×10-19이다.)

  1. 3.17
  2. 4.83
  3. 5.93
  4. 6.35
(정답률: 62%)
  • 30 CBT 기출문제AI

    2023-04-17 09:30

    전류량은 전하량과 시간의 곱으로 계산할 수 있습니다. 여기서 전하량은 전자의 개수와 전자의 전하는 곱으로 계산할 수 있습니다. 따라서 전류량은 다음과 같이 계산할 수 있습니다.

    전류량 = 전하량 ÷ 시간
    전하량 = 전자의 개수 × 전자의 전하는 값 = 2 × 1.602×10-19 C
    시간 = 1 hour = 3600 s

    전류량 = (2 × 1.602×10-19 C) ÷ (3600 s) = 8.9×10-23 A

    전류량과 전기 분해 반응식을 이용하여 구리의 질량을 계산할 수 있습니다. CuCl2 용액에서 전기 분해가 일어나면 Cu2+ 이온과 Cl- 이온이 생성됩니다. Cu2+ 이온은 전자를 받아 Cu(s)로 환원되며, Cl- 이온은 양극에서 방출되어 Cl2 가스를 생성합니다. 전기 분해 반응식은 다음과 같습니다.

    CuCl2(aq) → Cu(s) + Cl2(g)

    전기 분해 반응식에서 Cu2+ 이온 2개가 2개의 전자를 받아 Cu(s)로 환원되므로, 전류량의 2배만큼의 질량의 구리가 생성됩니다. 따라서 구리의 질량은 다음과 같이 계산할 수 있습니다.

    구리의 질량 = (전류량 × 전자의 전하는 값 × 전자의 개수 × 구리의 원자량) ÷ 2
    = (8.9×10-23 A) × (1.602×10-19 C) × 2 × 63.54 g/mol ÷ 2
    = 5.93 g

    따라서 정답은 "5.93"입니다.

    따라서 몰농도(M) = 0.25 / 0.1 = 2.5 mol/L입니다.

60. 1기압 27℃ 에서 아세톤 58g 을 완전히 기화시키면 부티는 약 몇 L 가 되는가?

  1. 22.4
  2. 24.6
  3. 27.4
  4. 58.0
(정답률: 63%)
  • 30 CBT 기출문제AI

    2023-04-17 09:40

    이 문제는 이상기체 상태방정식을 이용하여 풀 수 있습니다.

    PV = nRT

    여기서 P는 기압, V는 체적, n은 몰수, R은 기체상수, T는 절대온도를 나타냅니다.

    먼저, 아세톤의 몰수를 구해야 합니다.

    n = m/M

    여기서 m은 질량, M은 몰질량을 나타냅니다.

    M(아세톤) = 58.08 g/mol

    n(아세톤) = 58g / 58.08 g/mol = 0.998 몰

    다음으로, 체적을 구하기 위해 기체상태방정식을 변형합니다.

    V = nRT/P

    여기서 R은 0.0821 L·atm/mol·K 입니다.

    T는 절대온도이므로 27℃를 켈빈온도로 변환해야 합니다.

    T = 27℃ + 273.15 = 300.15 K

    V = (0.998 mol) x (0.0821 L·atm/mol·K) x (300.15 K) / (1 atm) = 24.6 L

    따라서, 아세톤을 완전히 기화시키면 부티는 약 24.6 L이 됩니다.

    정답이 "24.6" 인 이유는 이상기체 상태방정식을 정확하게 적용하여 계산했기 때문입니다.
