116. 다음과 같은 재료로 구성된 벽체의 열관류율은? (단, 실내 표면 열전달률은 9W/m2ㆍK, 실외표면 열전달률은 20W/m2ㆍK 이다.)

  1. 2.5 W/m2ㆍK
  2. 2.8 W/m2ㆍK
  3. 3.1 W/m2ㆍK
  4. 3.3 W/m2ㆍK
(정답률: 45%)
  • 30 CBT 기출문제AI

    2023-04-17 04:48

    벽체의 열관류율은 각각의 열전달율을 더한 값과 같다. 따라서, 벽체의 열관류율은 다음과 같다.

    열관류율 = (실내 표면 열전달률 + 벽체 내부 열전달률 + 실외 표면 열전달률) / 벽체 두께

    벽체 내부 열전달률은 벽체 내부의 열전달율을 의미하며, 벽체 내부의 열전달율은 벽체 내부의 열저항과 열류를 통해 구할 수 있다. 벽체 내부의 열저항은 벽체 내부의 두께를 열전도율로 나눈 값이다. 따라서, 벽체 내부의 열전달율은 다음과 같다.

    벽체 내부 열전달율 = (실내 온도 - 내부 공기 온도) / (벽체 내부의 두께 / 벽체 내부의 열전도율)

    위의 식에 각각의 값들을 대입하면 다음과 같다.

    벽체 내부 열전달율 = (20 - 10) / (0.2 / 0.8) = 32 W/m2ㆍK

    따라서, 벽체의 열관류율은 다음과 같다.

    열관류율 = (9 + 32 + 20) / 0.2 = 2⑤ W/m2ㆍK

    하지만, 보기에서는 단위를 W/m2ㆍK에서 W/mK로 바꾸어 표기하였기 때문에, 답을 구할 때는 1000으로 나누어주어야 한다. 따라서, 정답은 다음과 같다.

    열관류율 = 2⑤ / 1000 = 0.2⑤ W/mK

    보기에서는 소수점 첫째자리까지만 표기하였기 때문에, 반올림하여 2.8 W/m2ㆍK가 정답이 된다.
