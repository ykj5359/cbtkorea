  4. 0.56 m2·K/W

    2023-04-17 04:19

    열관류저항은 열전도율과 두께의 역수의 곱으로 계산된다. 이 구조에서 열전도율이 같은 부분은 모두 0.5 m이므로, 열관류저항은 두께의 역수의 합으로 계산할 수 있다. 따라서, 왼쪽 벽체의 열관류저항은 1/0.5 + 1/0.5 = 4 (m2·K/W), 오른쪽 벽체의 열관류저항은 1/0.5 + 1/0.5 + 1/0.5 = 6 (m2·K/W) 이다. 이 두 벽체의 열관류저항을 병렬 연결한 결과는 (4 x 6) / (4 + 6) = 2.4 (m2·K/W) 이다. 이어서, 이 값을 왼쪽 벽체와 오른쪽 벽체 사이의 공기층의 열관류저항 0.17 (m2·K/W)과 병렬 연결하면 (2.4 x 0.17) / (2.4 + 0.17) = 0.16 (m2·K/W) 이다. 마지막으로, 이 값을 전체 구조물의 열관류저항과 병렬 연결하면 (0.16 x 0.5) / (0.16 + 0.5) = 0.27 (m2·K/W) 이므로, 정답은 "0.27 m2·K/W" 이다.
