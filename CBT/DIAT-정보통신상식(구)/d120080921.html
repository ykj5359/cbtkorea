15. FAT의 특징에 대한 설명으로 틀린 것은?

  1. FAT는 대형 파일은 연속된 클러스터를 가질 필요가 없기 때문에, 디스크 공간을 효율적으로 활용할 수 있다.
  2. FAT는 파일이름을 255자까지 가질 수 있다.
  3. FAT는 이미 삭제된 파일을 쉽게 복원 할 수 있다.
  4. FAT는 MFT를 사용하여 대량의 데이터를 잃어버리는 일이 없이 문제 상황을 복구할 수 있다.
(정답률: 44%)

  • 2023-04-14 12:21

    정답은 "FAT는 MFT를 사용하여 대량의 데이터를 잃어버리는 일이 없이 문제 상황을 복구할 수 있다." 이다. 이유는 FAT는 MFT(Master File Table)를 사용하지 않고, 대신 파일 시스템의 루트 디렉토리에 파일 정보를 저장하기 때문이다. 따라서, FAT 파일 시스템에서는 대량의 데이터를 잃어버리는 일이 발생할 가능성이 높다.

41. TCP/IP 프로토콜에서 사용되는 포트번호와 프로토콜이 올바르게 연결된 것은?

  1. FTP : 21번
  2. SMTP : 33번
  3. TELNET : 55번
  4. DNS : 80번
(정답률: 44%)

  • 2023-04-14 12:21

    FTP는 파일 전송 프로토콜로, 파일을 전송하기 위해 사용되는 프로토콜입니다. 이 때, FTP는 21번 포트를 사용하여 데이터를 전송합니다. 따라서 "FTP : 21번"이 올바른 연결입니다. SMTP는 이메일 전송 프로토콜로, 이메일을 보내기 위해 사용되는 프로토콜입니다. 하지만 SMTP는 25번 포트를 사용합니다. TELNET은 원격 제어 프로토콜로, 다른 컴퓨터를 원격으로 제어하기 위해 사용되는 프로토콜입니다. TELNET은 23번 포트를 사용합니다. DNS는 도메인 이름 시스템으로, 도메인 이름을 IP 주소로 변환하기 위해 사용되는 프로토콜입니다. DNS는 53번 포트를 사용합니다. 따라서 "SMTP : 33번", "TELNET : 55번", "DNS : 80번"은 올바르지 않은 연결입니다.

42. 1개의 C클래스는 최대 몇 개의 호스트 주소를 가질 수 있는가?

  1. 128개
  2. 254개
  3. 256개
  4. 1,024개
(정답률: 44%)

  • 2023-04-14 12:21

    C 클래스는 24비트를 호스트 주소로 사용하므로, 2의 24승(=16,777,216)개의 호스트 주소를 가질 수 있습니다. 그러나 첫 번째 주소와 마지막 주소는 네트워크 주소와 브로드캐스트 주소로 사용되므로, 호스트 주소로 사용 가능한 주소는 2의 24승에서 2개를 뺀 16,777,214개입니다. 이를 2진수로 표현하면 11111111.11111111.11111110.00000000이며, 이는 8비트(=1바이트)로 표현하면 11111110(=254)입니다. 따라서 C 클래스는 최대 254개의 호스트 주소를 가질 수 있습니다.

43. 사설 IP에 대한 설명으로 틀린 것은?

  1. 전 세계 IP 주소를 관리하는 IANA가 사설 네트워크를 위해 미리 확보해둔 IP 주소이다.
  2. 사설 IP는 사용하면 인터넷 서비스 업체를 변경하고자 할 때 IP 주소 재설정이 불필요하다.
  3. 사설 IP는 동일한 사설 네트워크가 아니라면 중복해서 사용될 수 있다.
  4. IANA는 모든 클래스에 전부 사설 인터넷을 위한 주소 공간을 예약해 두었다.
(정답률: 44%)

  • 2023-04-14 12:21

    정답은 "IANA는 모든 클래스에 전부 사설 인터넷을 위한 주소 공간을 예약해 두었다."이다. 사설 IP는 특정 범위 내에서만 사용 가능한 IP 주소로, IANA는 사설 인터넷을 위한 주소 공간을 예약해 두었지만, 이는 모든 클래스에 대해 예약된 것은 아니다. 사설 IP는 사용하면 인터넷 서비스 업체를 변경하고자 할 때 IP 주소 재설정이 불필요하며, 동일한 사설 네트워크가 아니라면 중복해서 사용될 수 있다.

50. 전자 우편에 대한 설명으로 틀린 것은?

  1. 전자 우편을 수신하기 위해서는 POP 서버를 설정해야 한다.
  2. 전자 우편을 송신하기 위해서는 SMTP 서버를 설정해야 한다.
  3. 전자 우편의 암호화를 위해서 PGP 프로그램을 사용한다.
  4. IMAP4 프로토콜은 서버간 메일 전송을 위한 프로토콜이다.
(정답률: 44%)

  • 2023-04-14 12:21

    IMAP4 프로토콜은 서버간 메일 전송을 위한 프로토콜이 아니라, 이메일 클라이언트와 이메일 서버 간 통신을 위한 프로토콜이다. 이메일 클라이언트에서 이메일을 읽거나 삭제하면, 이메일 서버에도 반영되는 기능을 제공한다.
