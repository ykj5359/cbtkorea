3. 다음 중앙처리장치의 구성요소 중 CPU 내부에서 처리할 명령어나 연산의 중간 결과 값을 일시적으로 기억하는 임시 기억 장치는?

  1. 제어장치
  2. 레지스터
  3. 보조기억장치
  4. 연산장치
(정답률: 44%)

  • 2023-04-14 12:21

    레지스터는 CPU 내부에서 처리할 명령어나 연산의 중간 결과 값을 일시적으로 기억하는 임시 기억 장치이기 때문입니다. CPU가 명령어를 실행하면서 필요한 데이터를 레지스터에 저장하고, 연산을 수행하면서 중간 결과 값을 레지스터에 저장합니다. 이렇게 레지스터를 사용하여 데이터를 일시적으로 기억하면 CPU의 처리 속도가 빨라지고, 효율적인 연산이 가능해집니다.
