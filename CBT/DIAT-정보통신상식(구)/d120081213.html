  2. ms - ns - μs - ps
  3. ms - μs - ns - ps
  4. ps - ns - μs - ms
(정답률: 44%)

  • 2023-04-14 12:21

    정답은 "ms - μs - ns - ps"입니다.이유는 다음과 같습니다.- ps (피코초) : 1/1,000,000,000,000 초, 즉 1조 분의 1초- ns (나노초) : 1/1,000,000,000 초, 즉 10억 분의 1초- μs (마이크로초) : 1/1,000,000 초, 즉 백만 분의 1초- ms (밀리초) : 1/1,000 초, 즉 천 분의 1초따라서, 계산속도가 느린 것부터 빠른 순으로 나열하면 ms - μs - ns - ps가 됩니다. 즉, 밀리초 단위에서 나노초, 마이크로초, 피코초 순으로 계산속도가 빨라지는 것입니다.
