9. 다음 중 WindowsXP에서 지원하지 않는 파일 시스템은 무엇인가?

  1. CMOS
  2. FAT
  3. FAT32
  4. NTFS
(정답률: 44%)

  • 2023-04-14 12:21

    정답은 "CMOS"이다.CMOS는 파일 시스템이 아니라, 컴퓨터의 BIOS에 저장되는 설정값을 유지하기 위한 메모리 기술이다. 따라서 파일 시스템과는 관련이 없다.반면, FAT, FAT32, NTFS는 모두 Windows 운영체제에서 사용되는 파일 시스템이다. FAT은 초기 버전의 Windows에서 사용되었고, FAT32는 Windows 95 OSR2부터 사용되었다. NTFS는 Windows NT에서 처음 도입되었으며, 현재 Windows 운영체제에서 가장 많이 사용되는 파일 시스템이다.

  3. SMTP
  4. NNTP

  4. 동보 메일

  2. ID@Domain
  3. ID.Password@Domain.ID
  4. Domain.Password@ID
(정답률: 44%)

  • 2023-04-14 12:21
