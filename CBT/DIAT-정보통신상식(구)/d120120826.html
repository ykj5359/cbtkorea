44. 다음 중 TCP/IP 프로토콜과 포트 번호가 올바르게 연결된 것은?

  1. FTP : 20
  2. TELNET : 26
  3. DNS : 53
  4. HTTP : 88
(정답률: 44%)

  • 2023-04-14 12:21

    정답은 "DNS : 53"입니다.DNS는 Domain Name System의 약자로, 인터넷에서 도메인 이름을 IP 주소로 변환하는 역할을 합니다. 이때 DNS는 TCP/IP 프로토콜을 사용하며, 포트 번호 53을 사용합니다. 따라서 DNS와 포트 번호 53은 올바르게 연결된 것입니다.FTP는 파일 전송을 위한 프로토콜로 포트 번호 20과 21을 사용하며, TELNET은 원격 로그인을 위한 프로토콜로 포트 번호 23을 사용합니다. HTTP는 웹 페이지 요청을 위한 프로토콜로 포트 번호 80을 사용합니다.
