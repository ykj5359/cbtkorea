8. 단독운전 방지기능이 없는 10kW 태양광발전시스템이 380V, 60Hz의 계통전원에 연결되어 운전될 경우, 태양광발전시스템의 출력이 10kW, 부하가 유효전력 10kW, 지상무효전력이 +9.5kVar, 진상무효전력이 -10kVar 일 때 단독운전이 일어날 경우 예상되는 공진주파수는 약 몇 Hz 인가?

  1. 58.48
  2. 59.32
  3. 60.00
  4. 61.38
(정답률: 53%)
  • 30 CBT 기출문제AI

    2023-04-17 03:10

    단독운전이 일어날 경우, 태양광발전시스템의 지상무효전력과 진상무효전력이 상쇄되어야 한다. 따라서, 지상무효전력과 진상무효전력의 합이 0이 되는 주파수에서 공진이 발생할 것이다.

    지상무효전력과 진상무효전력의 합은 다음과 같다.

    지상무효전력 + 진상무효전력 = +9.5kVar - 10kVar = -0.5kVar

    이는 부하의 유효전력과 같으므로, 부하의 주파수에서 공진이 발생할 것이다.

    부하의 주파수는 다음과 같이 계산된다.

    주파수 = (출력 / (3 x 전압 x 전류)) x 1000

    여기서, 출력은 10kW, 전압은 380V, 전류는 (10kW / 380V) = 26.32A 이다.

    주파수 = (10kW / (3 x 380V x 26.32A)) x 1000 = 60.00Hz

    따라서, 부하의 주파수는 60.00Hz 이다.

    하지만, 부하의 주파수에서 공진이 발생하지 않고, 지상무효전력과 진상무효전력의 합이 0이 되는 주파수에서 공진이 발생할 것이므로, 이를 계산해야 한다.

    공진주파수 = (전압 x 전류) / (2 x pi x (지상무효전력 + 진상무효전력))

    여기서, 전압은 380V, 전류는 26.32A, 지상무효전력과 진상무효전력의 합은 -0.5kVar 이다.

    공진주파수 = (380V x 26.32A) / (2 x pi x (-0.5kVar)) = 58.48Hz

    따라서, 예상되는 공진주파수는 약 58.48Hz 이다.
