7. 필요 공기량을 산정하여 침실의 규모를 산정하려고 한다. 성인 2인용 침실의 최소 바닥면적은? (단, 실내 자연화기 횟수 2회/hr, 천장고 2.5m)

  1. 10m2
  2. 15m2
  3. 20m2
  4. 25m2
(정답률: 50%)
  • 30 CBT 기출문제AI

    2023-04-14 17:32

    필요 공기량은 다음과 같이 계산할 수 있다.

    필요 공기량 = 인원 수 x 실내 자연화기 횟수 x 침실 부피

    여기서 침실 부피는 바닥면적 x 천장고로 계산할 수 있다.

    따라서, 필요 공기량을 산정하기 위해서는 인원 수와 자연화기 횟수가 주어졌을 때 침실 부피를 계산할 수 있어야 한다.

    성인 1인의 평균 체적은 약 0.07m3이다. 따라서, 성인 2인의 체적은 약 0.14m3이다.

    자연화기 횟수가 1시간에 2회이므로, 1회당 30분이 지날 때마다 침실의 공기가 모두 교체된다고 가정할 수 있다. 따라서, 1시간에 필요한 침실 부피는 다음과 같다.

    침실 부피 = 2인 x 0.14m3/인 x 2회/시간 x 0.5시간/회 = 0.56m3/시간

    이제, 바닥면적을 구하기 위해 필요한 침실 높이를 알아야 한다. 천장고가 2.5m이므로, 침실 부피를 바닥면적으로 나누면 다음과 같다.

    바닥면적 = 침실 부피 / 천장고 = 0.56m3/시간 / 2.5m = 0.224m2/시간

    따라서, 1시간에 필요한 바닥면적은 0.224m2이다. 하지만, 이는 최소 바닥면적이므로, 실제로는 더 큰 바닥면적이 필요하다.

    따라서, 정답은 20m2이다.

71. 어떤 실내의 취득열량 중 현열이 35000W이고, 잠열이 9000W 였다. 실내의 공기조건을 25℃, 50%(RH)로 유지하기 위해서 취출온도 10℃로 송풍하고자 한다. 이 때 현열비는?

  1. 0.6
  2. 0.8
  3. 1.9
  4. 3.9
(정답률: 66%)
  • 30 CBT 기출문제AI

    2023-04-14 17:31

    취득열량 = 현열 + 잠열
    = 35000W + 9000W
    = 44000W

    취출온도가 10℃로 유지되어야 하므로, 실내의 열이 완전히 취출되었다고 가정하면, 취득열량과 취출열량이 같아진다.

    취출열량 = 공기의 질량 x 현열비 x (실내온도 - 취출온도)

    공기의 질량은 일정하므로, 현열비를 구할 수 있다.

    44000W = 공기의 질량 x 현열비 x (25℃ - 10℃)
    현열비 = 44000W / (공기의 질량 x 15℃)

    공기의 상대습도가 50%이므로, 공기의 비습량은 공기의 질량에 대한 상대습도의 비율이다.

    공기의 비습량 = 공기의 질량 x 0.5

    따라서, 현열비 = 44000W / (공기의 비습량 x 15℃)

    공기의 비습량을 구하기 위해서는, 공기의 상태방정식을 이용해야 한다.

    PV = mRT

    P : 압력
    V : 부피
    m : 질량
    R : 기체상수
    T : 온도

    상태방정식을 변형하면,

    m = PV / RT

    공기의 질량은 일정하므로, P, V, T가 변할 때마다 공기의 비습량도 변한다.

    공기의 상태방정식을 이용하여, 공기의 비습량을 구할 수 있다.

    P1V1 / T1 = P2V2 / T2

    P1 : 초기 압력 (실내 압력)
    V1 : 초기 부피 (실내 부피)
    T1 : 초기 온도 (25℃)
    P2 : 최종 압력 (취출 후 압력)
    V2 : 최종 부피 (취출 후 부피)
    T2 : 최종 온도 (10℃)

    공기의 비습량 = (P1V1 / T1) x (T2 / P2V2) x 0.5

    공기의 비습량을 현열비 식에 대입하면,

    현열비 = 44000W / [(P1V1 / T1) x (T2 / P2V2) x 0.5 x 15℃]

    따라서, 현열비는 0.8이 된다.

91. 6층 이상의 거실면적의 합계가 12000m2인 전시장 시설에 설치해야 할 승용승강기의 최소대수는? (단, 8인승 승강기 기준)

  1. 4대
  2. 5대
  3. 6대
  4. 7대
(정답률: 42%)
  • 30 CBT 기출문제AI

    2023-04-14 17:31

    8인승 승강기의 적재인원은 약 630kg이다. 이를 이용하여 6층 이상의 거실면적의 합계가 12000m2인 전시장 시설에 필요한 최소 승강기 대수를 구해보자.

    먼저, 6층 이상의 거실면적의 합계를 승강기의 적재인원으로 나누어 보면 다음과 같다.

    12000m2 ÷ 630kg ≈ 19대

    즉, 최소 19대의 승강기가 필요하다. 그러나 이 중에서 비상용 승강기를 제외하고 실제 사용할 수 있는 승강기 대수를 구해야 한다. 이를 위해 일반적으로 승강기 중 1대는 비상용으로 사용되므로, 실제 사용할 수 있는 승강기 대수는 19대 - 1대 = 18대이다.

    따라서, 8인승 승강기를 기준으로 최소대수를 구하면 18대 ÷ 3 = 6대이므로, 정답은 "6대"이다.
