  3. 4.0mm

    먼저 하중 작용점에서의 응력을 구해보자. 하중 작용점에서의 응력은 하중을 단면적으로 나눈 값으로 구할 수 있다.

    σ = F/A = 45,000N / 1cm² = 450,000N/cm²

    다음으로 응력에 대응하는 변형을 구해보자. 이를 위해서는 강봉의 탄성계수를 이용해 응력과 변형 사이의 관계식을 이용해야 한다.

    E = σ/ε

    ε = ΔL/L

    ΔL = εL = σL/E = (450,000N/cm²) x (200cm) / 200,000MPa = 4.5mm

    ΔL' = FL / AE = (45,000N) x (200cm) / (1cm² x 200,000MPa) = 0.45mm

    ΔL - ΔL' = 4.5mm - 0.45mm = 4.⑤mm
