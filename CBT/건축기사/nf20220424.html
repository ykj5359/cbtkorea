    급탕부하는 열량은 다음과 같이 계산할 수 있다.

    Q = m x c x ΔT

    여기서, Q는 열량, m은 물의 질량, c는 물의 비열, ΔT는 온도 차이이다.

    Q = 5,000 x 4.2 x (70 - 10) = 1,260,000 J/s = 1,260 kW

    보일러의 효율을 η라고 하면, 출력은 다음과 같이 계산할 수 있다.

    P = Q / η
