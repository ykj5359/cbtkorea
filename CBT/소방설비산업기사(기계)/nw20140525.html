15. 20℃의 물 1g을 100℃의 수증기로 변화시키는데 필요한 열량은 얼마인가?

  1. 699cal
  2. 619cal
  3. 539cal
  4. 80cal
(정답률: 68%)
  • 30 CBT 기출문제AI

    2023-04-16 08:08

    이 문제는 물의 비열과 상변화 열을 이용하여 계산할 수 있다.

    물의 비열은 1g당 1℃당 1cal이므로, 20℃의 물 1g을 100℃로 가열하는 데 필요한 열량은 다음과 같다.

    (100 - 20)℃ × 1g × 1cal/℃/g = 80cal

    하지만 이 문제에서는 수증기로 변화시키는 것이므로, 물이 수증기에서 증기로 상변화하는 과정에서 추가로 열이 필요하다.

    물의 상변화 열은 1g당 540cal이므로, 20℃의 물 1g이 수증기로 변화하는 데 필요한 열량은 다음과 같다.

    80cal + 1g × 540cal/g = 619cal

    따라서 정답은 "619cal"이다.

21. 동력이 2kW인 펌프를 사용하여 수면의 높이 차이가 40m 인 곳으로 물을 끌어 올리려고 한다. 관로 전체의 손실수두가 10m 라고 할 때 펌프의 유량은 약 몇 m3/s 인가? (단, 펌프의 효율은 90%이다.)

  1. 0.00294
  2. 0.00367
  3. 0.00408
  4. 0.00453
(정답률: 63%)
  • 30 CBT 기출문제AI

    2023-04-16 08:08

    먼저, 펌프의 출력은 2kW 이므로, 이를 유량과 수위차로 변환해주어야 한다. 1kW는 1000J/s 이므로, 2kW는 2000J/s 이다. 이를 수위차로 변환하면 다음과 같다.

    2000J/s = (무게력) x (유속) x (유량) x (중력가속도)
    유속 = (2000J/s) / (무게력 x 유량 x 중력가속도)

    여기서 무게력은 물의 밀도인 1000kg/m^3과 수위차 40m을 이용하여 구할 수 있다.

    무게력 = (1000kg/m^3) x (9.81m/s^2) x (40m) = 392400J/m^3

    따라서, 유속은 다음과 같다.

    유속 = (2000J/s) / (392400J/m^3 x 유량 x 9.81m/s^2) = 0.000⑤2m^3/s x (1/유량)

    여기서, 관로 전체의 손실수두가 10m 이므로, 유속에 대한 손실수두는 다음과 같다.

    손실수두 = (유속^2 / 2g) x (전체 관로 길이) x (전체 관로 마찰계수)
    10m = (유속^2 / 2g) x (전체 관로 길이) x (전체 관로 마찰계수)
