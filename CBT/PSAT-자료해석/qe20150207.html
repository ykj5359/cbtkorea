38. 아래 <그림>은 마을 A~E 간의 가능 이동로를 보여주며, <표>는 주어진 <조건>에 따라 '갑'이 매 회차 이동 후 각 마을에 숨어있을 확률을 구한 자료이다. 이에 대한 ＜보기＞의 설명 중 옳은 것만을 모두 고르면?

  1. ㄱ, ㄴ
  2. ㄱ, ㄷ
  3. ㄴ, ㄷ
  4. ㄴ, ㄹ
  5. ㄷ, ㄹ
(정답률: 알수없음)
  • 30 CBT 기출문제AI

    2023-04-14 06:39

    - 보기 중 옳은 것은 "ㄴ, ㄷ"이다.
    - "ㄴ"은 갑이 1회차 이동 후 마을 A에 있을 확률이다. 이는 초기 상태에서 갑이 마을 A에 있을 확률인 0.2와 마을 B에서 마을 A로 이동할 확률인 0.4를 곱한 값과 마을 C에서 마을 A로 이동할 확률인 0.1을 곱한 값의 합과 같다. 따라서 "ㄴ"은 0.2 x 0.4 + 0.2 x 0.1 = 0.1이 된다.
    - "ㄷ"는 갑이 2회차 이동 후 마을 D에 있을 확률이다. 이는 1회차 이동 후 갑이 마을 A, B, C, D, E에 있을 확률을 구한 후, 각 마을에서 마을 D로 이동할 확률을 곱한 값의 합과 같다. 따라서 "ㄷ"는 (0.1 x 0.3) + (0.3 x 0.2) + (0.2 x 0.5) + (0.1 x 0.4) + (0.3 x 0.1) = 0.16이 된다.
    - 나머지 보기들은 옳지 않은 설명을 포함하고 있거나, 정확한 값을 구하는 방법이 잘못되어 있기 때문에 선택할 수 없다.
